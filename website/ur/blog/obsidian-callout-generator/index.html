Obsidian callout جنریٹر: ہر قسم، متبادل نام اور فولڈنگ کا اختیار

قسم منتخب کریں، عنوان اور متن شامل کریں، فولڈنگ اور نیسٹنگ چنیں، اور درست > [!type] callout کاپی کریں، اقسام اور متبادل ناموں کی مکمل فہرست اور تہہ ہونے والے callout کے کام کرنے کے طریقے کے ساتھ۔

تحریر
Cody Bontecou
تازہ کاری
27 نومبر 2026
درکار ہے
کوئی بھی جدید براؤزر، بشمول iPhone پر Safari۔ اختیاری: callout کے لیے Obsidian، اور آواز یا متن سے نوٹس کیپچر کرنے کے لیے iPhone یا Mac کے لیے Vox.md۔
مختصر جواب

callout ایک بلاک کوٹ ہے جس کی پہلی لائن ہے > [!type] Optional title۔ اس کے بعد ہر لائن شروع ہوتی ہے > ۔ شامل کریں + یا - بریکٹس کے فوراً بعد لگائیں تاکہ یہ تہہ ہونے والا بن جائے۔ سابقے ٹائپ کیے بغیر بنانے کے لیے استعمال کریں callout جنریٹر نیچے۔

> [!warning]- Back up first
> Copy the vault before you change the plugin settings.
>
> Then restart Obsidian.

جنریٹر شامل کرتا ہے > سابقہ ہر لائن میں لگاتا ہے (نیسٹنگ کے لیے دہرایا جاتا ہے)، callout کے اندر خالی لائنیں برقرار رکھتا ہے، اور دوگنا نہیں کرتا > جو آپ نے پیسٹ کیا۔ یہ مکمل طور پر اس صفحے میں چلتا ہے: آپ کا متن کبھی اپ لوڈ نہیں ہوتا، اور صفحہ کوئی نیٹ ورک درخواست نہیں کرتا۔

1. اپنا callout بنائیں

callout جنریٹر کو JavaScript چاہیے۔ اس کے بغیر بھی نیچے کی نحو اور اقسام کی جدول بطور حوالہ کام کرتی ہیں۔

قسم

مواد

فولڈنگ
لے آؤٹ

ایک بالکل خالی لائن callout کو ختم کر دیتی ہے، اس لیے برقرار رکھی گئی خالی لائنیں > کے طور پر لکھی جاتی ہیں۔ خالی لائنیں ہٹانے کے لیے اسے بند کریں۔

آپ کا callout

اسے اس بیرونی callout کے متن میں پیسٹ کریں جس میں آپ اسے نیسٹ کر رہے ہیں۔

پیش منظر (تقریبی)

پیش منظر تقریبی ہے۔ حقیقی رنگ، آئیکن اور وقفہ آپ کا تھیم طے کرتا ہے۔

اقسام کی گیلری

اوپر لوڈ کرنے کے لیے کوئی قسم منتخب کریں۔

کلپ بورڈ پر کاپی ہو گیا۔ کاپی ناکام رہی۔ متن منتخب کریں اور خود کاپی کریں۔ مثال لوڈ ہو گئی۔ صاف ہو گیا۔ خالی ہونے پر ڈیفالٹ عنوان: {title} یہ بلٹ اِن قسم نہیں ہے۔ جب تک CSS snippet اسے متعین نہ کرے، Obsidian اسے note انداز میں دکھاتا ہے۔ قسم لوڈ ہو گئی۔

2. callout کی نحو

> [!type] Title
> Body line one.
> Body line two.
  • قسم۔ بلاک کوٹ کی پہلی لائن تعجبیہ نشان کے بعد بریکٹس میں قسم سے شروع ہوتی ہے: > [!info]. Obsidian مدد کہتا ہے کہ قسم کا شناخت کنندہ بڑے/چھوٹے حروف سے بے نیاز ہے، اور غیر معاون قسم اس پر واپس چلی جاتی ہے note.
  • عنوان۔ بریکٹس کے بعد کا متن عنوان کی جگہ لے لیتا ہے۔ اس کے بغیر Obsidian قسم کا شناخت کنندہ ٹائٹل کیس میں دکھاتا ہے، لہٰذا > [!tip] “Tip” دکھاتا ہے۔
  • متن۔ اس کے بعد ہر لائن شروع ہوتی ہے > ۔ متن میں Markdown، wikilinks اور ایمبیڈز ہو سکتے ہیں۔
  • صرف عنوان۔ آپ متن کو چھوڑ سکتے ہیں: > [!tip] Remember to save ایک مکمل callout ہے۔

3. تمام callout اقسام اور متبادل نام

Obsidian Help ان بلٹ اِن اقسام کی فہرست دیتا ہے۔ ہر متبادل نام اس قسم کے ساتھ درج ہے جس سے وہ تعلق رکھتا ہے، مثلاً tldr کے ساتھ abstract.

قسممتبادل نامعام استعمال
noteکوئی نہیںایک عمومی تبصرہ۔ نامعلوم قسم بھی اسی انداز پر واپس آتی ہے۔
abstractsummary, tldrنوٹ کے اوپر ایک خلاصہ۔
infoکوئی نہیںپس منظر کی معلومات۔
todoکوئی نہیںکوئی کام جو ابھی کرنا ہے۔
tiphint, importantمشورہ یا کلیدی نکتہ۔
successcheck, doneایک مکمل شدہ مرحلہ یا اچھا نتیجہ۔
questionhelp, faqایک کھلا سوال یا اکثر پوچھا جانے والا سوال۔
warningcaution, attentionکوئی چیز جس میں احتیاط ضروری ہے۔
failurefail, missingکیا غلط ہوا یا کیا کمی ہے۔
dangererrorکوئی سنگین خطرہ یا خرابی کا پیغام۔
bugکوئی نہیںایک معلوم بگ۔
exampleکوئی نہیںایک عملی مثال۔
quoteciteحوالے کے ساتھ ایک اقتباس۔

اقسام اور متبادل نام Obsidian Help سے لیے گئے ہیں۔ “عام استعمال” کا کالم ایک تجویز ہے، Obsidian کی تعریف نہیں۔ ڈیفالٹ انداز میں ہر قسم کا اپنا رنگ اور آئیکن ہوتا ہے؛ تھیمز دونوں بدل سکتے ہیں۔

4. تہہ ہونے والے callout: + بمقابلہ -

بند ہونے والے بریکٹ کے فوراً بعد پلس یا مائنس لگائیں:

> [!faq]+ Open by default
> This callout is foldable and starts expanded.

> [!faq]- Closed by default
> This callout is foldable and starts collapsed.

Obsidian Help بیان کرتا ہے + بطور تہہ ہونے والا اور بطور ڈیفالٹ کھلا، اور - بطور تہہ ہونے والا اور بطور ڈیفالٹ بند۔ دونوں نہ ہوں تو callout تہہ ہونے والا نہیں ہوتا۔ + یا - Markdown کا حصہ ہے، اس لیے یہ فائل میں رہتا ہے۔

5. نیسٹڈ callout، فہرستیں، کوڈ اور ایمبیڈز

نیسٹڈ callout کے لیے ایک اور شامل کریں > ہر سطح کے لیے:

> [!question] Can callouts be nested?
> > [!example] Yes
> > Add one more > for each level.

جنریٹر کی “دوسرے callout کے اندر نیسٹ کریں” ترتیب اضافی لکھتی ہے > ہر لائن پر، تین سطحوں تک۔ نتیجہ بیرونی callout کے متن میں پیسٹ کریں۔

فہرستیں، کوڈ اور دیگر Markdown متن کے اندر جاتے ہیں، اس سابقے کے ساتھ > سابقہ ہر لائن پر۔ Obsidian Help کے مطابق متن میں Markdown، wikilinks اور ایمبیڈز ہو سکتے ہیں، اور موجودہ مواد، بشمول فہرستیں اور کوڈ بلاکس، کو منتخب کر کے چلانے سے لپیٹا جا سکتا ہے callout داخل کریں کمانڈ۔ فہرست یا کوڈ بلاک کو جنریٹر کے متن کے خانے میں پیسٹ کریں اور وہ سابقے خود شامل کر دیتا ہے:

> [!info] Checklist
> - [ ] first
> - [ ] second
>
> ```
> code line
> ```

6. CSS snippet کے ساتھ حسبِ ضرورت callout اقسام

آپ کی ایجاد کردہ قسم note انداز میں دکھائی دیتی ہے۔ Obsidian Help کے مطابق حسبِ ضرورت callout CSS snippet یا کمیونٹی پلگ اِن میں متعین کیے جاتے ہیں۔ اس کی مثال:

.callout[data-callout="custom-question-type"] {
  --callout-color: #000000;
  --callout-icon: lucide-alert-circle;
}

Help صفحے کے مطابق، --callout-color کوئی بھی درست CSS رنگ قبول کرتا ہے، اور --callout-icon lucide.dev سے آئیکن ID یا SVG عنصر لیتا ہے۔ پھر لکھیں > [!custom-question-type] نوٹ میں۔ جنریٹر کے حسبِ ضرورت قسم کے خانے میں وہی نام ٹائپ کریں۔

7. GitHub alerts بمقابلہ Obsidian callout

GitHub میں اسی طرح کی ایک خصوصیت ہے جسے alerts کہتے ہیں۔ GitHub دستاویزات پانچ درج کرتا ہے: NOTE, TIP, IMPORTANT, WARNING اور CAUTION.

> [!NOTE]
> Useful information that users should know, even when skimming content.

اس صفحے میں فولڈنگ، حسبِ ضرورت عنوان اور حسبِ ضرورت اقسام کا ذکر نہیں؛ Obsidian callout میں تینوں ہیں۔ پہلی لائن ایک جیسی لگتی ہے، اس لیے بنیادی > [!note] یا > [!warning] اکثر دونوں میں کام کرتا ہے، لیکن صرف Obsidian کی قسم جیسے [!bug]، ایک +/- فولڈ یا عنوان GitHub کی دستاویزات سے باہر ہے۔ اگر فائل دونوں جگہ پڑھی جائے تو GitHub کی پانچ اقسام پر رہیں اور کوئی اضافی چیز نہ لگائیں۔

8. Vox.md کے ساتھ آواز یا متن سے Obsidian میں کیپچر کریں

Vox.md آپ کا کیپچر کیا ہوا مواد Obsidian والٹ فولڈر میں Markdown نوٹ کے طور پر محفوظ کرتا ہے۔ یہ ایک کیپچر ایپ ہے، اور یہ صفحہ یہ دعویٰ نہیں کرتا کہ یہ آپ کے لیے callout لکھتی ہے: بعد میں ایک شامل کریں، یہاں بنا کر پیسٹ کر کے، یا اوپر کی نحو خود ٹائپ کر کے۔ ٹرانسکرپٹ سے متن کے لیے، ٹیکسٹ کو جنریٹر میں پیسٹ کریں اور وہ سابقے شامل کر دیتا ہے۔

متعلقہ ٹولز اور گائیڈز: Markdown چیک لسٹ میکر اور Markdown ٹیبل میکر callout کے اندر رکھے جانے والے مواد کے لیے، پراپرٹیز جنریٹر، روزانہ نوٹ ٹیمپلیٹ اور میٹنگ نوٹس ٹیمپلیٹ نوٹ کی ساخت کے لیے، کیپچر ٹیمپلیٹس سابقوں اور راستوں کے لیے، اور iPhone پر Obsidian میں صوتی نوٹس.

Vox.md کے ساتھ آواز یا متن سے نوٹس اپنے والٹ میں کیپچر کریں

Vox.md آپ کے آلے پر ٹرانسکرائب کرتا ہے اور Markdown کو آپ کے Obsidian والٹ میں محفوظ کرتا ہے۔ ریکارڈنگ، ٹرانسکرپشن اور کیپچر کے لیے Vox.md Unlimited درکار ہے: اہل اکاؤنٹس کے لیے 7 دن کے مفت ٹرائل کے ساتھ ہفتہ وار یا سالانہ سبسکرپشن، یا ایک بار کی لائف ٹائم خریداری۔ App Store آپ کی مقامی قیمت دکھاتا ہے۔

9. سوالات

میرا callout رینڈر کیوں نہیں ہو رہا؟

تین چیزیں چیک کریں۔ پہلی لائن اس سے شروع ہونی چاہیے > اور پھر [!type]، تعجبیہ نشان کے ساتھ اور بریکٹس کے اندر خالی جگہ کے بغیر۔ متن کی ہر لائن کو اپنا ضرورت ہے >۔ ایک خالی لائن جس میں نہ ہو > بلاک کوٹ کو ختم کر دیتا ہے، اس لیے اس کے بعد کی لائنیں عام متن ہیں؛ اسے یوں لکھیں >۔ اگر یہ پھر بھی سادہ بلاک کوٹ کے طور پر دکھائی دے تو ان کے درمیان خالی جگہ یا ٹائپو چیک کریں > اور [!.

کیا callout بغیر عنوان کے ہو سکتا ہے؟

بالکل نہیں: عنوان چھوڑ دیں تو Obsidian اس کی جگہ قسم کا شناخت کنندہ ٹائٹل کیس میں دکھاتا ہے۔ عنوان چھپانے کے لیے CSS چاہیے؛ Obsidian Help کے مطابق مزید اسٹائلنگ، جیسے عنوان چھپانا، معیاری CSS سلیکٹرز سے ہو سکتی ہے۔ جب آپ ایسا کرتے ہیں تو جنریٹر عنوان خالی چھوڑ دیتا ہے، اس لیے آپ کو ڈیفالٹ ملتا ہے۔

Admonition پلگ اِن یا مقامی callout؟

مقامی callout کو پلگ اِن کی ضرورت نہیں اور یہ استعمال کرتے ہیں > [!type] نحو اس صفحے پر بیان کی گئی ہے۔ Admonition پلگ اِن ایک الگ کمیونٹی پلگ اِن ہے جس کی اپنی نحو ہے، جسے یہ صفحہ بیان نہیں کرتا۔ Obsidian Help کے مطابق حسبِ ضرورت callout اقسام کمیونٹی پلگ اِن سے بھی آ سکتی ہیں۔

کیا callout Obsidian موبائل اور Publish میں کام کرتے ہیں؟

Obsidian Help کے مطابق callout Obsidian Publish پر مقامی طور پر معاون ہیں۔ اس کے callout صفحے میں موبائل کا کسی طرف ذکر نہیں، اس لیے یہ صفحہ اس بارے میں کوئی دعویٰ نہیں کرتا۔

کیا جنریٹر میرا متن اپ لوڈ کرتا ہے؟

نہیں۔ اس صفحے میں ایک اسکرپٹ آپ کے آلے پر callout بناتا ہے، اور صفحہ کوئی نیٹ ورک درخواست نہیں کرتا۔ یہ کچھ محفوظ نہیں کرتا: صفحہ دوبارہ لوڈ کرنے سے سب صاف ہو جاتا ہے۔
