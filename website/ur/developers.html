عوامی معلومات API

مصنوعات کے حقائق اور دستاویزات دریافت کریں

Vox.md عوامی معلومات API مصنوعات اور جاری دستاویز روابط دیتی ہے۔ مفت، بغیر اکاؤنٹ، API کلید، OAuth یا ادائیگی ہے۔ یہ اسی عوامی ویب سائٹ کی معلومات لوٹاتی ہے۔ پڑھیے OpenAPI 3.1 معاہدہ نوع شدہ جواب اسکیموں، عمل شناخت، غلطیوں اور وضاحتوں کے لیے۔

مصنوعات کی معلومات لیں

GET https://vox.isolated.tech/api/v1/product مصنوعہ نام، وضاحت، معاون نظام، App Store صفحہ، دستاویز URL اور مدد URL لوٹاتا ہے۔ تعمیر یہ حقائق مرکزی منظم ڈیٹا سے لیتی ہے۔

curl https://vox.isolated.tech/api/v1/product

مصنوعہ JSON دیکھیں

دستاویز تلاش کریں

GET https://vox.isolated.tech/api/v1/documents عوامی صفحات کے عنوانات، خلاصے اور URL کی فہرست دیتا ہے۔ مواد طلب کرنے سے پہلے اسی سے متعلقہ خصوصیت کی رہنمائی، پالیسی، بلاگ مضمون یا معاونت کا صفحہ تلاش کریں۔

curl https://vox.isolated.tech/api/v1/documents

دستاویز فہرست JSON دیکھیں

صفحہ Markdown میں پڑھیں

کسی درج صفحے کو اس سے مانگیں Accept: text/markdown مرکزی مواد کے لیے۔ ان درخواستوں میں Accept: text/html HTML وصول کرتے رہتے ہیں۔ دونوں شکلوں میں شامل ہے Vary: Accept۔ یہ ایجنٹ رہنمائی Vox.md موزوں استعمال اور خصوصیت تفصیل بتاتا ہے۔

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

غلطیاں، کیش اور طریقے

JSON اینڈ پوائنٹس GET اور HEAD کی حمایت کرتے ہیں۔ نامعلوم API راستے HTTP 404 کے ساتھ یہ لوٹاتے ہیں: application/problem+json، مستقل code، وضاحت اور بحالی اشارہ۔ غیر معاون طریقے HTTP 405 اور یہ لوٹاتے ہیں: Allow: GET, HEAD۔ عوامی میٹا ڈیٹا جوابات بین ماخذ قرأت کی اجازت اور پانچ منٹ کی کیش مدت بتاتے ہیں۔ اسناد یا صارف کا مخصوص ڈیٹا شامل نہیں۔

نصب ایپ خودکار کریں

کیپچر، نقل، مقامی والٹ اور تحریر نصب Apple ایپ میں ہیں۔ دستاویزی لیں شارٹ کٹس اور URL اسکیم کا انضمام آلے کے مالک کی اجازت سے۔ عوامی معلومات API کیپچر کے اعمال، ریکارڈنگز، نقول، نجی نوٹس یا منزل کے فولڈرز ظاہر نہیں کرتی۔ رابطہ کریں Vox.md مدد سوالات کے لیے۔
