    Документація · Маршрути

    Поточне місцеположення, {location}, і метадані

    Використовуйте одну геопозицію на момент створення в оформленні запису без автоматичного додавання YAML чи вбудованих полів. Отримання геопозиції та вивід метаданих — окремі, явні параметри кожного маршруту.

    Оновлено 21 серпня 2026 року Разове отримання Без фонового відстеження Повний посібник функцій
    01 / Огляд

    Отримання геопозиції не означає вивід метаданих

    Кожен маршрут має два окремі параметри геолокації. Використовувати поточне місцезнаходження визначає, чи маршрут запитує одну геопозицію в момент створення. Записувати метадані місцезнаходження визначає, чи знімок також записується в frontmatter або вбудовані поля.

    Елемент керуванняЩо це означаєЧого це не означає
    Системний дозвіл геолокаціїДозволяє Vox.md запитувати геопозицію під час використання застосунку або підтримуваного інтерфейсу захоплення.Це не вмикає геолокацію жодного маршруту.
    Використовувати поточне місцезнаходженняЗапитує одну геопозицію для цього маршруту й робить її доступною для {location}.YAML чи вбудовані метадані автоматично не записуються.
    Записувати метадані місцезнаходженняЗаписує вибрані структуровані поля чи перевірений розширений YAML з отриманого знімка геопозиції.Не визначає, чи {location} може показати.
    Намір задає маршрут, а не дозвіл

    Дозвіл під час використання лише відкриває системний доступ. Vox.md усе одно запитує геопозицію тільки для незалежної дії поточного місцеположення на панелі або маршруту з увімкненим її використанням.

    02 / Налаштування

    Налаштуйте поточне місцеположення для одного маршруту

    1. Відкрийте маршрути.На iPhone чи iPad відкрийте Налаштування → Маршрути. На Mac відкрийте налаштування й виберіть маршрути.
    2. Змініть маршрут.Виберіть маршрут, якому потрібна вихідна геопозиція. Налаштування належить лише йому й не впливає на інші.
    3. Відкрийте місцеположення.Увімкніть Використовувати поточне місцезнаходження. Залиште Записувати метадані місцезнаходження вимкненим для самого токена.
    4. Виберіть точність.Використовуйте «Точний» для вихідних координат або «Місто» для округлення до двох десяткових знаків без назви об’єкта.
    5. Виберіть поведінку недоступності.Запитання, надсилання без геопозиції чи скасування визначає поведінку без вихідних координат.
    6. Додайте {location} за бажанням.Помістіть токен у шаблон запису, власний префікс чи суфікс або шаблон Markdown сховища.

    Спочатку ОС може запросити дозвіл геолокації. Після попередньої відмови дозвольте Vox.md місцеположення в параметрах iOS, iPadOS або macOS.

    03 / Типові конфігурації

    Виберіть найменший потрібний вивід геоданих

    Без геопозиції маршрутуВимкненоВимкненоНе використовуйте {location}, інакше він порожній.
    Лише клікабельне посиланняУвімк.ВимкненоДодайте {location}. Геополя не записуються.
    Лише метаданіУвімк.Увімк.Не зберігати {location}. Записуються лише налаштовані поля.

    Вимкнення геолокації блокує токен і метадані маршруту, навіть якщо попередні формати метаданих збережені на майбутнє.

    04 / Токен шаблону

    Використати {location} Без зміни метаданих нотатки

    Коли використання геопозиції ввімкнено й вихідний знімок доступний, {location} формує перевірене посилання Markdown на Google Maps:

    [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    Токен працює в багаторазових шаблонах запису, власних префіксах і суфіксах та Markdown-шаблонах сховища. Використовує ті самі точні чи міські координати маршруту.

    Приклад лише з токеном

    Для суфікса на кшталт:

    Captured from {location}

    Vox.md може створювати:

    Captured from [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    Коли запис геометаданих вимкнено, це посилання — єдині геодані маршруту. Без locations: колекції й без location.*:: поля записуються.

    Виправлення одним натисканням

    Якщо чинний префікс, суфікс або багаторазовий шаблон запису використовує {location} коли геолокацію маршруту вимкнено, редактор пояснює порожній токен і пропонує Використовувати поточне місцеположення для [Route]. Дія вмикає геопозицію маршруту, навмисно лишаючи метадані вимкненими: наступне надсилання розгорне токен без зміни метаданих нотатки. Шаблони сховища читаються лише при доставці, тому не викликають підказку; увімкніть геолокацію вручну для токена в них.

    Коли токен порожній

    {location} стає порожнім рядком, коли геолокацію вимкнено, вона недоступна чи захоплення триває без неї. Зважайте на навколишню пунктуацію й підписи необов’язкових рядків шаблону.

    Незалежна дія панелі захоплення

    Швидке захоплення Теперішнє місцезнаходження безпосередньо вставляє разове Google Maps до чернетки. Не залежить від маршрутів і не змінює використання геопозиції чи запис метаданих.

    05 / Вивід метаданих

    Записуйте структуровані поля лише за власним вибором

    Увімкніть геометадані для машинозчитуваних полів на додачу чи замість {location} посилання.

    Frontmatter нотатки

    Додає кожну геопозицію до колекції з назвою locations за замовчуванням, за ID захоплення. Наявні сторонні поля frontmatter зберігаються.

    Вбудовані поля запису

    Записує у стилі Dataview location.key:: value рядки поруч зі збереженим записом. Колекція frontmatter не додається.

    Структуровані поля

    Вибирайте й перейменовуйте координати, широту, довготу, місце, місто, регіон, країну, посилання провайдерів, geo URI, точність, час, джерело та ID.

    Розширений YAML

    Використовує перевірений обмежений шаблон YAML для frontmatter. Розширений YAML недоступний для вбудованих полів запису.

    Приклад структурованого frontmatter

    ---
title: Field Notes
locations:
  - id: "aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee"
    coordinates: [45.501235, -73.567890]
    place: "Café & Main"
    appleMapsURL: "https://maps.apple.com/?ll=45.501235%2C-73.567890&q=Caf%C3%A9%20%26%20Main"
    timestamp: "2023-11-14T22:13:20.000Z"
    source: "app"
---

    Періодичні нотатки можуть тримати кілька захоплень у колекції. Захист вбудовано в об’єднання: повтор з тим самим ID не додає геопозицію двічі. Несумісне користувацьке значення в ключі колекції зупиняє Vox.md замість перезапису.

    Приклад вбудованих полів запису

    location.id:: aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
location.coordinates:: [45.501235, -73.567890]
location.place:: "Café & Main"

Captured text

    Підстановки розширеного YAML

    Розширені шаблони можуть використовувати підстановки, наприклад {{coordinates}}, {{latitude}}, {{longitude}}, {{place}}, {{city}}, {{region}}, {{country}}, {{appleMapsURL}}, {{googleMapsURL}}, {{openStreetMapURL}}, {{geoURI}}, {{accuracy}}, {{timestamp}}, {{source}}, і {{id}}. Перед збереженням перегляньте конфігурацію в налаштуваннях маршруту.

    06 / Точність і підписи

    Точний і міський режими мають один узгоджений знімок

    ТочністьКоординатиПідписиПосилання й поля
    ТочнийЗберігає вихідну геопозицію з шістьма видимими десятковими знаками.Може мати назву об’єкта за потреби поля метаданих.Кожне похідне значення використовує точні координати.
    МістоОкруглює широту й довготу до двох десяткових знаків перед збереженням знімка.Прибирає назви об’єктів; місто, регіон і країна можуть лишитися.Кожен URL провайдера, geo URI, токен і поле використовує округлені координати.

    Системний зворотний геокодер Apple використовується лише з увімкненим записом геометаданих, якщо вибраному структурованому полю або розширеному заповнювачу потрібні місце, місто, регіон чи країна. Маршрут лише з токеном пропускає зворотне геокодування. Якщо пошук підпису не вдається, результат на основі координат залишається доступним.

    07 / Джерела захоплення

    Знімок належить джерелу захоплення

    Поточне місцеположення визначається на межі, де виникає захоплення. Повторна спроба й відновлення використовують цей надійно збережений результат, а не непомітно запитують новішу геопозицію.

    Джерело захопленняМомент отримання
    Швидке захоплення iPhone та iPadвідправити
    Меню поширенняНадсилання в розширенні поширення
    Прямі наміри тексту, посилання й файлу в чергуВиклик наміру
    Команди, віджети, керування й глибокі посилання редактораНадсилання в редакторі
    Команда, віджет, керування, негайний голос і запис маршруту клавіатуроюЗупинка запису
    Звичайна доставка захоплення Apple WatchЗупинка запису на годиннику; iPhone не підставляє власну геопозицію
    Захоплення MacНадсилання або зупинка запису для негайної голосової доставки

    Лише запис годинника експортує вихідне M4A до «Файлів» без Markdown, тому не запитує геопозиції, навіть якщо маршрут зазвичай її використовує.

    08 / Недоступність і відновлення

    Виберіть поведінку кожного маршруту без геопозиції

    • Запитувати: інтерактивні захоплення можуть повторити, скасувати, раз надіслати без геопозиції чи вибрати постійне надсилання без неї для маршруту.
    • Надіслати без місцеположення: продовжує доставку без токена й метаданих.
    • Скасувати захоплення: зупиняє доставку замість нотатки без запитаної вихідної геопозиції.
    • Скинути вибір: скиньте вибір недоступної геопозиції в геоналаштуваннях маршруту.

    Фоновий запит запитання зберігає початковий результат недоступності для перевірки. Повтор черги чи збою не підставляє пізнішу геопозицію. Очікувана робота тримає лише скоригований знімок чи недоступність для локального відновлення.

    09 / Наявні маршрути

    Оновлення зберігають попередню поведінку метаданих

    Поділ отримання й виводу безпечний під час міграції:

    • Нові маршрути: Використання геопозиції й запис геометаданих початково вимкнені.
    • Маршрути з раніше ввімкненою геолокацією: обидва параметри лишаються ввімкненими після оновлення для збереження попередніх метаданих.
    • Раніше вимкнені геомаршрути: обидва параметри лишаються вимкненими; оновлення не додає нового виводу метаданих.

    Щоб перевести наявний маршрут на токен без метаданих, залиште геолокацію ввімкненою й вимкніть запис геометаданих. Наявний Markdown не переписується й не видаляється.

    10 / Конфіденційність і зберігання

    Один явний знімок, жодного фонового відстеження

    • Vox.md не стежить за геопозицією постійно чи у фоні.
    • Геопозиція не надсилається на сервери Vox.md, до систем аналітики, реклами чи сторонніх сервісів ШІ.
    • Токени й URL провайдерів формуються локально. Apple Maps, Google Maps або OpenStreetMap отримує координати лише коли ви відкриваєте його посилання.
    • Системне зворотне геокодування Apple може робити мережевий запит лише коли вибраним метаданим потрібна назва місця. Геолокація лише через токен пропускає цей пошук.
    • Після доставки запити стають квитанціями без вмісту; завершена історія не містить координат, підписів, URL провайдерів чи геошаблонів.
    • Якщо геометадані або посилання токена записано до Markdown, вони стають частиною вибраного вами файлу. Ваш файловий провайдер синхронізації може обробляти цей файл на власних умовах.
    Дозвіл може лишатися ввімкненим без розкриття геопозиції маршрутами

    Можна залишити системний дозвіл для незалежної дії геопозиції й вимкнути її використання в усіх маршрутах.

    Див. Політика конфіденційності із повними відомостями обробки й зберігання даних.

    11 / Усунення несправностей

    Виправте типові проблеми геопозиції й шаблонів

    {location} порожній

    Перевірте, що чинний шаблон, префікс, суфікс чи шаблон сховища використовує точний токен у нижньому регістрі {location}. Потім увімкніть використання поточного місцеположення для маршруту доставки. Виправлення одним натисканням у редакторі робить це для виявленого вбудованого оформлення без метаданих; файли шаблонів сховища потребують ручного налаштування. Якщо дозвіл відхилено чи геопозиція недоступна, перевірте поведінку маршруту й системні налаштування геолокації.

    Посилання працює, метаданих немає

    Це очікувано для самого токена. У геоналаштуваннях маршруту ввімкніть запис метаданих, виберіть frontmatter нотатки чи вбудовані поля запису та потрібні поля.

    Метадані є, а посилання в записі немає

    Метадані не вставляють посилання автоматично. Додайте {location} до чинного оформлення чи шаблону Markdown сховища.

    Немає місця чи міста

    Підтвердьте вибір поля підпису. Геокодування Apple може дати збій при доступних координатах. Точність «Місто» навмисно прибирає назви об’єктів.

    Доставка frontmatter повідомляє про конфлікт

    Налаштований ключ колекції, locations типово, має бути сумісним списком геопозицій. Перейменуйте колекцію в маршруті або виправте користувацький frontmatter. Vox.md не перезапише несумісне значення.

    Під час повторної спроби місцеположення застаріле чи недоступне

    Так задумано. Запит зберігає початковий результат, щоб пізній повтор не підставив інше місце непомітно. Для нового знімка почніть нове захоплення.

    Геолокацію дозволено, але маршрут її не запитує

    Системний дозвіл лише відкриває доступ. Відредагуйте маршрут і ввімкніть використання поточного місцеположення. Сам дозвіл ніколи не вмикає геолокацію маршруту.
