SRT and VTT to text or Markdown converter

Paste or open a caption file from Zoom, Microsoft Teams, YouTube or a transcription service and get readable text, a Markdown transcript, or the other subtitle format. The file is read on your device and never uploaded.

Cody Bontecou
Updated

Requires
Any modern browser, including Safari on iPhone. Optional: Obsidian for the Markdown output, and Vox.md for iPhone or Mac if you are starting from audio.
The short answer

Paste or open an .srt or .vtt file, choose Plain text or Markdown, then copy or download. The file stays on your device.

The converter removes cue numbers and timecodes, merges the lines into paragraphs, and turns speaker names into bold speaker turns for a note. It also converts SRT to VTT and VTT to SRT. It reads the file with the browser’s FileReader API, and this page makes no network requests, so nothing you paste or open is sent anywhere.

1. Use the converter

  1. Add the file. Paste the contents into the box, or choose a .srt, .vtt or .txt file. The tool detects the format and shows the cue count.
  2. Pick an output. Plain text, Markdown, SRT or VTT.
  3. Adjust the clean-up options. Merge lines into paragraphs, start a new paragraph after a pause, remove repeated rolling lines, strip tags, and keep or drop sound cues such as [Music].
  4. Copy or download. The download uses the right extension: .txt, .md, .srt or .vtt.

2. SRT vs VTT: what they are and how they differ

Both are plain-text caption formats: a list of cues, each with a start time, an end time and some text. The Library of Congress describes the SubRip (SRT) format as a simple text format in which each caption has a sequential number, start and end times separated by -->, one or more lines of text, and a blank line. Its timecode is hours:minutes:seconds,milliseconds. The W3C’s WebVTT specification defines the newer format that browsers use for captions.

.srt.vtt
First lineThe number of the first cueWEBVTT
Millisecond separatorComma: 00:00:01,000Period: 00:00:01.000
HoursAlways writtenOptional: 00:01.000 is allowed
Cue numbersA sequential number for every cueOptional identifier
Cue settingsNonePosition and alignment can follow the timestamp, such as align:start
SpeakerNo standard marker; people write Name:Voice span: <v Name>text</v>
CommentsNoneNOTE, STYLE and REGION blocks

What the converter does when it changes format:

  • SRT to VTT: adds the WEBVTT header and changes each comma in a timestamp to a period.
  • VTT to SRT: drops the header, NOTE, STYLE and REGION blocks and the cue settings, changes periods to commas, and renumbers the cues from 1. SRT has no voice span, so <v Name>text</v> becomes Name: text.
  • Text encoding: the Library of Congress notes that SRT has no character encoding standard, and parsers have to detect it. The converter reads files as UTF-8. If accented letters look wrong, open the file in a text editor and save it as UTF-8 first.

3. Where to get the file: Zoom, Teams and YouTube

Check each vendor’s page for your plan and settings, because admins and account types change what you can download.

Zoom cloud recordings

Zoom’s support article on audio transcription for cloud recordings says that once the transcript has been processed it appears as a separate VTT file with the recording. It applies to cloud recordings, and audio transcription has to be enabled for them. The file formats a recording can produce are listed in Zoom’s guide to recording file formats.

Microsoft Teams transcripts

Microsoft’s support article on downloading Teams transcripts says that, by default, organizers and co-organizers can download the transcript as a .docx or .vtt file, and that your IT admin’s policies can change who may download it. Choose .vtt and open it here. To fix mistakes before you convert, see Microsoft’s guide to editing a Teams transcript.

YouTube captions

YouTube Help’s page on editing and removing captions describes downloading a caption track from YouTube Studio for a video on your own channel. It does not name the file format the download produces, so paste or open the file and let the converter detect it. YouTube’s list of supported caption file types includes SubRip (.srt) and WebVTT (.vtt).

Only download captions you have the right to use. This page does not cover other people’s videos.

4. Put the transcript in an Obsidian note

  1. Choose Markdown. Speaker names become **Name:**, and consecutive cues from the same speaker merge into one turn. Turn on Add a [mm:ss] timestamp if you want to find your place in the recording later.
  2. Turn on Obsidian properties to add a block at the top with title, date, source and tags. It is valid YAML written the way the properties generator writes it. Obsidian reads the lines between the two --- markers at the very top of a note as properties; see the Obsidian Help page on properties.
  3. Paste into a new note in your vault, for example in a Meetings folder. If you download the .md file instead, move it into the vault folder.
  4. Link it to the meeting note. Build a note with the meeting notes template generator, then add a line such as Transcript: [[Team sync transcript]] to it. If you link from a property, the link must be in quotes: transcript: "[[Team sync transcript]]".

Text is escaped so that characters such as *, $ and a leading # do not turn into formatting, math or tags in Obsidian. Speaker names come from the file, so check them before you share the note.

If you also keep a table in the note, such as a list of speakers or decisions, the Markdown table maker builds one from pasted spreadsheet cells and escapes pipes for Obsidian.

6. Questions

Does this upload my file?

No. A file you open is read in your browser with the FileReader API, and a file you paste stays in the text box. The conversion is a script in this page, and the page makes no network requests while you use it. When you close or reload the page, the text is gone.

Why are lines repeated?

Automatic captions often roll: each new cue repeats the line before it and adds a new one, so the same words appear two or three times. Turn on Remove repeated rolling lines. It removes a line that is identical to a line in the cue before it. If a speaker really says the same line twice in a row, that repeat is removed too, so leave the option off for clean human-made captions.

Can I keep timestamps?

Yes. With Plain text or Markdown, turn on the timestamp option and each paragraph starts with the time of its first cue as [mm:ss], or [h:mm:ss] after an hour. For every cue time, convert to SRT or VTT instead.

How do I turn text back into SRT?

This tool does not do that. Plain text has no timings, so an SRT needs a tool that aligns the text with the audio. Converting between SRT and VTT keeps the timings, because both formats contain them.

Does it work on iPhone?

Yes. It uses ordinary form controls and the browser’s file picker, and it was written to work in Safari on iPhone. Copy uses the clipboard when Safari allows it and otherwise asks you to select the text.
