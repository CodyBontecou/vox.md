Capture into an Obsidian Daily Note from iPhone

Vox.md sends text, links, scans, photos, and on-device voice transcripts into an Obsidian vault or Markdown folder. Set up one Capture Preset to append entries to a daily note under a chosen heading.

By Cody Bontecou · October 25, 2026

Before you start

Install Vox.md and open your vault in Obsidian on the same iPhone. Identify that vault's folder in Files. No Obsidian plugin or Vox.md account is required. This guide covers the iPhone workflow; file-provider availability and app labels can vary.

1. Create a daily-note Capture Preset

  1. Open Settings → Capture Presets in Vox.md. Create a preset called Daily Inbox.
  2. For a first test, choose Keep Original and leave typed-text processing off. This makes it easier to compare the text you send with the saved note.
  3. Set up the destination and select the folder of the vault you opened in Obsidian.
  4. Choose Rolling Note with a daily period. Use a path such as Journal/{period}.md, or match your vault's actual daily-note folder and naming convention.
  5. Choose heading placement, enter Inbox, and set the heading level to 2. Use bottom placement instead if you do not want a heading.

See destination options and placement rules. Existing Note is for one fixed file; Rolling Note follows the selected period.

2. Send one test and inspect the file

Select Daily Inbox in Quick Capture, type Book dentist appointment, then tap Send. Wait for Capture Sent. In Obsidian, open the note for that day and check the heading and entry. Verify the folder in Files too if you have similarly named vaults.

This illustrative output uses a synthetic capture and a daily note dated October 25. Your template, metadata, and placement settings determine the exact file contents.

The example path is Journal/2026-10-25.md. Match the preview and saved filename to your own daily-note convention rather than creating a second daily-note series by accident.

3. Add voice after text delivery works

Record a short voice capture using the same preset. Transcription runs on the device. A local model may need downloading before first use; Apple Speech availability depends on the device, system, and language. Check the transcript and destination before relying on unattended capture. See models and transcription.

Then add the Share Sheet, widgets, or Shortcuts to the workflow. Keep one verified destination as the starting point.

If a capture does not arrive

  • Check the selected preset and any one-capture destination override.
  • If the folder moved or access expired, select it again. Make sure your file provider is available.
  • Review History for queued or failed work and use its recovery options after fixing the destination. Repeatedly sending a new capture can create separate entries.
  • If transcription fails, check that the selected model is downloaded and appropriate for the language.
