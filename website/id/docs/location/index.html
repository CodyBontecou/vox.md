    Lokasi saat ini, {location}, dan Metadata

    Gunakan satu lokasi saat asal dalam pemformatan entri tanpa otomatis menambahkan YAML atau bidang sebaris. Pengambilan lokasi dan keluaran metadata adalah pilihan eksplisit yang terpisah pada setiap Rute.

    Diperbarui 21 Agustus 2026 Pengambilan sekali Tanpa pelacakan latar belakang Panduan Fitur Lengkap
    01 / Ikhtisar

    Pengambilan Lokasi Tidak Berarti Keluaran Metadata

    Setiap Rute memiliki dua kontrol lokasi terpisah. Gunakan Lokasi Saat Ini menentukan apakah rute meminta satu lokasi pada saat asal. Tulis Metadata Lokasi menentukan apakah cuplikan yang diperoleh juga ditulis sebagai frontmatter atau bidang sebaris.

    KontrolArtinyaYang tidak dimaksud
    Izin lokasi sistemMemungkinkan Vox.md meminta lokasi saat aplikasi atau antarmuka pencatatan yang didukung sedang digunakan.Ini tidak mengaktifkan lokasi untuk Rute mana pun.
    Gunakan Lokasi Saat IniMeminta satu lokasi untuk rute ini dan menyediakannya bagi {location}.Ini tidak otomatis menulis YAML atau metadata sebaris.
    Tulis Metadata LokasiMenulis bidang terstruktur pilihan atau YAML lanjutan tervalidasi dari cuplikan yang diperoleh.Ini tidak mengontrol apakah {location} dapat dirender.
    Sinyal niatnya adalah rute, bukan izin

    Memberikan izin Saat Digunakan hanya membuka gerbang sistem operasi. Vox.md tetap hanya meminta lokasi untuk tindakan Lokasi saat ini mandiri pada Bilah Tangkapan atau Rute dengan Gunakan Lokasi Saat Ini yang Anda aktifkan.

    02 / Penyiapan

    Atur Lokasi Saat Ini untuk Satu Rute

    1. Buka Rute.Di iPhone atau iPad, buka Pengaturan → Rute. Di Mac, buka Pengaturan lalu pilih Rute.
    2. Sunting rute.Pilih rute yang harus memakai lokasi asalnya. Pengaturan milik rute tersebut dan tidak memengaruhi rute lain.
    3. Buka Lokasi.Aktifkan Gunakan Lokasi Saat Ini. Pertahankan Tulis Metadata Lokasi nonaktif untuk perilaku token saja.
    4. Pilih presisi.Gunakan Exact untuk lokasi asal, atau City untuk koordinat yang dibulatkan ke dua angka desimal tanpa label tempat menarik.
    5. Pilih perilaku saat tidak tersedia.Tanya, Kirim Tanpa Lokasi, atau Batalkan Tangkapan menentukan tindakan jika lokasi asal tidak dapat diperoleh.
    6. Tambahkan {location} jika diinginkan.Taruh token dalam Templat Entri, awalan atau akhiran entri kustom, atau templat Markdown vault.

    Penggunaan pertama mungkin menampilkan permintaan izin lokasi sistem operasi. Jika izin pernah ditolak, aktifkan akses lokasi Vox.md di pengaturan sistem iOS, iPadOS, atau macOS.

    03 / Konfigurasi Umum

    Pilih Cakupan Lokasi Sekecil yang Anda Butuhkan

    Hasil yang diinginkanGunakan Lokasi Saat IniTulis Metadata LokasiKuilnya
    Tanpa lokasi ruteMatiMatiJangan gunakan {location}, atau hasilnya kosong.
    Hanya tautan yang dapat diklikAktifMatiTambahkan {location}. Tidak ada bidang lokasi yang ditulis.
    Hanya metadataAktifAktifHilangkan {location}. Hanya bidang yang dikonfigurasi yang ditulis.
    Tautan dan metadataAktifAktifTambahkan {location} dan atur bidang metadata.

    Menonaktifkan Gunakan Lokasi Saat Ini mencegah render token dan keluaran metadata rute itu, meski pilihan format metadata sebelumnya tetap dikonfigurasi untuk dipakai nanti.

    04 / Token Templat

    Gunakan {location} Tanpa Mengubah Metadata Catatan

    Ketika Gunakan Lokasi Saat Ini aktif dan cuplikan asal tersedia, {location} menghasilkan tautan Markdown Google Maps tervalidasi:

    [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    Token bekerja dalam Templat Entri pakai ulang, awalan dan akhiran entri kustom, serta templat Markdown vault. Memakai koordinat Exact atau City yang sama dengan pilihan rute.

    Contoh token saja

    Untuk akhiran seperti:

    Captured from {location}

    Vox.md dapat menghasilkan:

    Captured from [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    Dengan Write Location Metadata nonaktif, tautan ini satu-satunya konten lokasi yang ditambahkan rute. Tidak ada locations: sebagai koleksi dan tanpa location.*:: sebagai bidang yang ditulis.

    Perbaikan sekali ketuk penyusun

    Jika awalan, akhiran, atau Templat Entri pakai ulang yang berlaku menggunakan {location} ketika rute pilihan menonaktifkan Lokasi saat ini, penyusun menjelaskan bahwa token akan kosong dan menawarkan Gunakan Lokasi Saat Ini untuk [Route]. Tindakan itu mengaktifkan Lokasi saat ini untuk rute sambil sengaja membiarkan Tulis Metadata Lokasi nonaktif, sehingga Kirim berikutnya dapat mengisi token tanpa mengubah metadata catatan. Berkas templat vault langsung hanya dibaca saat pengiriman, jadi isinya tidak dapat memicu petunjuk penyusun ini; aktifkan Lokasi saat ini secara manual jika templat vault memakai token.

    Saat token kosong

    {location} menjadi string kosong ketika Lokasi saat ini nonaktif, lokasi tidak tersedia, atau tangkapan berlanjut tanpa lokasi. Perhatikan tanda baca dan label di sekitarnya saat merancang baris templat opsional.

    Tindakan Bilah Tangkapan mandiri

    Fitur Cepat menangkap Lokasi saat ini langsung menyisipkan tautan Google Maps sekali ambil ke draf saat ini. Terpisah dari Rute dan tidak mengubah Gunakan Lokasi Saat Ini maupun Write Location Metadata.

    05 / Keluaran Metadata

    Tulis Bidang Terstruktur Hanya Jika Anda Memilihnya

    Aktifkan Tulis Metadata Lokasi jika catatan harus menerima bidang lokasi yang dapat dibaca mesin sebagai tambahan atau pengganti {location} tautan.

    Frontmatter Catatan

    Menambahkan setiap lokasi ke koleksi bernama locations secara default, dengan ID Tangkapan sebagai kunci. Frontmatter lain yang sudah ada dipertahankan.

    Bidang Entri Sebaris

    Menulis bentuk bergaya Dataview location.key:: value di samping entri tangkapan. Tidak ada koleksi frontmatter yang ditambahkan.

    Bidang Terstruktur

    Pilih dan ganti nama koordinat, lintang, bujur, tempat, kota, wilayah, negara, tautan penyedia, URI geo, akurasi, cap waktu, sumber, dan ID.

    YAML Lanjutan

    Memakai templat YAML tervalidasi dan terbatas untuk Frontmatter Catatan. YAML lanjutan tidak tersedia bagi bidang entri sebaris.

    Contoh frontmatter terstruktur

    ---
title: Field Notes
locations:
  - id: "aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee"
    coordinates: [45.501235, -73.567890]
    place: "Café & Main"
    appleMapsURL: "https://maps.apple.com/?ll=45.501235%2C-73.567890&q=Caf%C3%A9%20%26%20Main"
    timestamp: "2023-11-14T22:13:20.000Z"
    source: "app"
---

    Catatan bergulir dapat menyimpan beberapa tangkapan dalam koleksi. Perlindungan percobaan ulang dibangun dalam penggabungan lokasi: percobaan ulang dengan ID Tangkapan sama tidak dapat menambahkan lokasi sama dua kali. Jika kunci koleksi pilihan sudah berisi nilai buatan pengguna yang tidak kompatibel, Vox.md berhenti alih-alih menimpanya.

    Contoh entri sebaris

    location.id:: aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
location.coordinates:: [45.501235, -73.567890]
location.place:: "Café & Main"

Captured text

    Placeholder YAML lanjutan

    Templat lanjutan dapat memakai placeholder seperti {{coordinates}}, {{latitude}}, {{longitude}}, {{place}}, {{city}}, {{region}}, {{country}}, {{appleMapsURL}}, {{googleMapsURL}}, {{openStreetMapURL}}, {{geoURI}}, {{accuracy}}, {{timestamp}}, {{source}}, dan {{id}}. Pratinjau konfigurasi di pengaturan rute sebelum menyimpan.

    06 / Presisi & Label

    Exact dan City Memakai Satu Cuplikan Konsisten

    PresisiKoordinatLabelTautan dan bidang
    TepatMempertahankan lokasi asal dengan enam angka desimal yang ditampilkan.Dapat menyertakan label tempat menarik jika bidang metadata pilihan membutuhkannya.Setiap nilai turunan menggunakan koordinat Exact.
    KotaMembulatkan lintang dan bujur ke dua angka desimal sebelum cuplikan disimpan.Menghapus label tempat menarik; kota, wilayah, dan negara mungkin tetap ada.Setiap URL penyedia, URI geo, token, dan bidang memakai koordinat yang dibulatkan.

    Geocoder balik sistem Apple hanya dipakai jika Write Location Metadata aktif dan bidang terstruktur pilihan atau placeholder lanjutan memerlukan tempat, kota, wilayah, atau negara. Rute token saja melewati geocoding balik. Jika pencarian label gagal, keluaran berbasis koordinat tetap tersedia.

    07 / Sumber Tangkapan

    Cuplikan Milik Asal Tangkapan

    Lokasi saat ini dievaluasi ketika tangkapan berasal. Percobaan ulang dan pemulihan memakai kembali hasil yang tersimpan tersebut, bukan diam-diam mengambil lokasi baru.

    Sumber tangkapanBatas pengambilan
    Cepat menangkap di iPhone dan iPadKirim
    Lembar BerbagiKirim dari ekstensi berbagi
    Intent teks, tautan, dan berkas yang langsung diantrekanPemanggilan intent
    Shortcuts, widget, kontrol, dan tautan dalam yang membuka Cepat menangkapKirim dari penyusun
    Pintasan, widget, kontrol, suara langsung, dan perekaman rute melalui papan ketikPenghentian perekaman
    Pengiriman Tangkapan normal Apple WatchPerekaman berhenti di Watch; iPhone tidak menggantinya dengan lokasi sendiri
    Tangkapan MacKirim, atau penghentian perekaman untuk pengiriman suara langsung

    Hanya Rekaman Watch mengekspor audio M4A mentah ke Files tanpa wadah Markdown, sehingga tidak meminta lokasi meski rute memakai Lokasi saat ini untuk keluaran lain.

    08 / Tidak Tersedia & Pemulihan

    Pilih Cara Setiap Rute Menangani Lokasi yang Tidak Tersedia

    • Tanya: tangkapan interaktif dapat mencoba ulang, membatalkan, mengirim sekali tanpa lokasi, atau memilih Selalu Kirim Tanpa Lokasi untuk rute tersebut.
    • Kirim Tanpa Lokasi: melanjutkan pengiriman tanpa nilai token atau keluaran metadata.
    • Batalkan Tangkapan: menghentikan pengiriman, bukan membuat catatan tanpa lokasi asal yang diminta.
    • Atur ulang pilihan tersimpan: gunakan Atur Ulang Pilihan Lokasi Tidak Tersedia di pengaturan Lokasi rute.

    Permintaan Tanya tanpa pengawasan menyimpan hasil tidak tersedia saat asal untuk ditinjau nanti. Percobaan ulang tangkapan antrean atau gagal tidak pernah mengganti dengan lokasi kemudian. Pekerjaan tertunda hanya menyimpan cuplikan yang disesuaikan demi privasi atau hasil tidak tersedia yang diperlukan untuk pemulihan lokal.

    09 / Rute yang Ada

    Pembaruan Mempertahankan Perilaku Metadata Sebelumnya

    Pemisahan pengambilan dan keluaran aman untuk migrasi:

    • Rute baru: Gunakan Lokasi Saat Ini dan Tulis Metadata Lokasi awalnya sama-sama nonaktif.
    • Rute lokasi yang sebelumnya aktif: kedua kontrol tetap aktif setelah pembaruan, mempertahankan metadata yang sudah ditulis rute tersebut.
    • Rute lokasi yang sebelumnya nonaktif: kedua kontrol tetap nonaktif; pembaruan tidak memperkenalkan keluaran metadata baru.

    Untuk mengubah rute penulis metadata menjadi perilaku token saja, biarkan Gunakan Lokasi Saat Ini aktif dan nonaktifkan Write Location Metadata. Markdown yang ada tidak ditulis ulang atau dihapus.

    10 / Privasi & Retensi

    Satu Cuplikan Eksplisit, Tanpa Pelacakan Latar Belakang

    • Vox.md tidak memantau lokasi terus-menerus atau melacak lokasi di latar belakang.
    • Lokasi tidak dikirim ke server Vox.md, analitik, sistem iklan, atau layanan AI pihak ketiga.
    • URL token dan penyedia diformat secara lokal. Apple Maps, Google Maps, atau OpenStreetMap menerima koordinat hanya saat Anda membuka tautannya.
    • Geocoder balik sistem Apple mungkin membuat permintaan jaringan hanya jika metadata pilihan memerlukan label tempat. Lokasi berbasis token saja melewati pencarian ini.
    • Setelah pengiriman berhasil, permintaan yang dapat dipulihkan dipangkas menjadi tanda terima tanpa konten, dan riwayat Tangkapan selesai tidak menyimpan koordinat, label, URL penyedia, atau templat lokasi.
    • Jika metadata lokasi atau tautan token ditulis ke Markdown, itu menjadi bagian dari berkas pilihan Anda. Penyedia sinkronisasi berkas dapat memproses berkas itu menurut ketentuannya.
    Izin boleh tetap aktif sementara rute tetap privat

    Anda dapat membiarkan izin sistem tersedia untuk tindakan Lokasi saat ini mandiri sambil tetap menonaktifkan Gunakan Lokasi Saat Ini pada setiap Rute.

    Lihat Kebijakan Privasi untuk detail lengkap penanganan dan retensi data.

    11 / Pemecahan Masalah

    Perbaiki Masalah Umum Lokasi dan Templat

    {location} menghasilkan teks kosong

    Pastikan Templat Entri, awalan, akhiran, atau templat vault yang berlaku memakai token huruf kecil persis {location}. Lalu aktifkan Gunakan Lokasi Saat Ini untuk rute pengiriman. Perbaikan sekali ketuk penyusun dapat melakukannya untuk format entri sebaris yang terdeteksi tanpa mengaktifkan metadata; berkas templat vault langsung perlu penyiapan rute manual. Jika izin ditolak atau lokasi tidak tersedia, tinjau perilaku rute saat lokasi tidak tersedia dan pengaturan lokasi sistem.

    Tautan berfungsi, tetapi metadata tidak muncul

    Ini wajar pada konfigurasi token saja. Buka pengaturan Lokasi rute dan aktifkan Write Location Metadata, lalu pilih Frontmatter Catatan atau Bidang Entri Sebaris dan pilih bidang yang diinginkan.

    Metadata muncul, tetapi tautan tidak muncul di entri

    Keluaran metadata tidak menyisipkan tautan otomatis. Tambahkan {location} ke pemformatan entri yang berlaku atau templat Markdown vault.

    Tempat atau kota tidak ada

    Pastikan bidang label dipilih. Geocoder balik Apple dapat gagal meski koordinat tetap tersedia. Presisi City sengaja menghapus label tempat menarik.

    Pengiriman frontmatter melaporkan benturan

    Kunci koleksi yang dikonfigurasi, locations secara default, harus berupa daftar lokasi kompatibel. Ganti nama koleksi di pengaturan rute atau sesuaikan frontmatter buatan pengguna yang ada. Vox.md tidak akan menimpa nilai yang tidak kompatibel.

    Percobaan ulang memiliki lokasi lama atau lokasi yang tidak tersedia

    Ini disengaja. Permintaan mempertahankan hasil saat asal agar percobaan ulang nanti tidak diam-diam mengklaim lokasi tangkapan berbeda. Mulai tangkapan baru jika perlu cuplikan baru.

    Izin lokasi diberikan, tetapi rute tidak memintanya

    Izin sistem hanya gerbang. Sunting Rute tersebut dan aktifkan Gunakan Lokasi Saat Ini. Izin saja tidak pernah mengaktifkan fitur untuk rute.
