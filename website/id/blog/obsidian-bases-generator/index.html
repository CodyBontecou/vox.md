Generator Obsidian Bases: filter, tampilan, dan formula

Buat YAML untuk base Obsidian tanpa perlu mempelajari skemanya dulu: pilih filter, tambahkan tampilan, salin berkas .base atau blok kode, dan lihat fungsi setiap kunci beserta tautan ke dokumentasi resmi Obsidian.

Oleh
Cody Bontecou
Diperbarui
28 November 2026
Memerlukan
Browser modern apa pun, termasuk Safari di iPhone. Opsional: Obsidian dengan plugin inti Bases, dan Vox.md untuk iPhone atau Mac untuk merekam catatan lewat suara atau teks.
Jawaban singkat

Base adalah tampilan bergaya basis data atas catatan Anda, ditulis sebagai YAML dengan hingga lima kunci tingkat atas: filters, formulas, properties, summaries dan views. Simpan YAML sebagai .base berkas, atau tempel ke dalam catatan di dalam base blok kode. Bagian pembuat di bawah menuliskannya untuk Anda. Versi Obsidian yang diperlukan bergantung pada jenis tampilan: halaman tampilan mencantumkan Table dan Cards sejak 1.9, List dan Map sejak 1.10, serta Kanban sejak 1.14.

filters:
  and:
    - file.hasTag("project")
properties:
  status:
    displayName: "Status"
views:
  - type: table
    name: "Projects by status"
    groupBy:
      property: status
      direction: ASC
    order:
      - file.name
      - status
      - file.mtime

Generator berjalan sepenuhnya di halaman ini. Tidak ada yang Anda ketik diunggah, dan halaman ini tidak melakukan permintaan jaringan.

    2. Sekilas sintaks Bases

    Ini adalah kunci-kunci yang halaman sintaks Obsidian dokumentasikan. Tidak ada skema lain yang perlu dipelajari.

    KunciFungsinyaContoh
    filtersMempersempit catatan untuk setiap tampilan.file.hasTag("project")
    formulasMendefinisikan properti terhitung, digunakan sebagai formula.name.total: 'price * qty'
    propertiesPengaturan per properti. displayName mengatur header kolom.displayName: "Status"
    summariesMendefinisikan rumus ringkasan Anda sendiri, menggunakan values.Kustom, opsional
    viewsDaftar tampilan atas catatan yang sama.- type: table
    type (tampilan)Tata letak tampilan.table, cards, list
    name (tampilan)Nama tampilan.name: "Projects"
    filters (tampilan)Filter hanya untuk tampilan ini.file.inFolder("Work")
    groupBy (tampilan)Mengelompokkan baris menurut property dalam direction.direction: DESC
    order (tampilan)Properti yang ditampilkan, berurutan.- file.name
    limit (tampilan)Membatasi jumlah baris.limit: 10
    summaries (tampilan)Memetakan properti ke ringkasan.price: Sum

    Generator tidak menuliskan setiap kunci yang terdokumentasi. Halaman sintaks juga menjelaskan groupOrder, dan tampilan dapat menyimpan status tambahan seperti kolom pengurutan, yang dikelola Obsidian sendiri. Tambahkan secara manual jika perlu: YAML ini milik Anda untuk diedit.

    3. Filter: and, or, not

    Filter adalah pernyataan teks yang bernilai benar atau salah untuk setiap catatan, atau objek dengan and, or atau not yang berisi daftar filter lainnya. Global filters berlaku untuk setiap tampilan. Milik tampilan sendiri filters hanya berlaku untuk tampilan itu, dan keduanya digabungkan dengan AND.

    filters:
  or:
    - file.hasTag("meeting")
    - file.inFolder("Meetings")

    Tidak ada from atau source kunci seperti di SQL atau Dataview. Tanpa filter, base menyertakan semua berkas di vault, jadi selalu tetapkan satu kecuali Anda memang menginginkannya.

    Nilai teks memerlukan tanda kutip di dalam pernyataan, sehingga YAML memerlukan tanda kutip bersarang: 'status == "done"'. Generator melakukannya untuk Anda. Filter fungsi seperti file.hasTag(), file.inFolder() dan file.hasLink() ada di halaman fungsi.

    4. Formula dan ringkasan

    Setiap entri di bawah formulas menjadi properti yang dapat Anda gunakan di setiap tampilan sebagai formula.name. Sebuah formula dapat menggunakan formula lain, tetapi referensi melingkar tidak diizinkan, sehingga formula tidak dapat merujuk dirinya sendiri. Hasilnya disimpan sebagai string YAML, itulah sebabnya ekspresi ditulis di dalam tanda kutip.

    formulas:
  formatted_price: 'if(price, price.toFixed(2) + " dollars")'

    Milik tampilan summaries memetakan properti ke ringkasan. Halaman sintaks mencantumkan default berikut:

    • Angka: Average, Min, Max, Sum, Range, Median, Stddev
    • Tanggal: Earliest, Latest, Range
    • Boolean (benar/salah): Checked, Unchecked
    • Apa pun: Empty, Filled, Unique

    Untuk perhitungan tanggal, halaman sintaks menyatakan file.mtime > now() - "1 week" bernilai benar untuk berkas yang diubah dalam seminggu terakhir.

    5. Artinya

    Dalam filter atau formula, this adalah berkas tempat base ditampilkan. Halaman sintaks menyebutkan bahwa ini adalah berkas base itu sendiri saat base dibuka di area konten utama, berkas yang menyematkan saat base disematkan di catatan atau Canvas, dan berkas aktif di area konten utama saat base berada di bilah samping. Halaman tersebut memberikan file.hasLink(this.file) sebagai cara untuk meniru panel backlink.

    6. Contoh yang dapat Anda salin

    Ini adalah preset generator dalam bentuk kode biasa, sehingga berfungsi tanpa JavaScript. Ganti nama folder, tag, dan properti dengan milik Anda. Simpan teks ini sebagai .base berkas, atau bungkus dalam base blok kode. Lihat Buat base untuk perintahnya, dan sematkan berkas tersimpan dengan ![[Name.base]] atau ![[Name.base#View]] untuk memilih tampilan default.

    Daftar bacaan

    filters:
  and:
    - file.inFolder("Reading")
    - 'status == "to read"'
properties:
  status:
    displayName: "Status"
views:
  - type: cards
    name: "Reading list"
    order:
      - file.name
      - status

    Catatan dengan tag, diubah minggu ini

    filters:
  and:
    - file.hasTag("project")
    - 'file.mtime > now() - "1 week"'
views:
  - type: table
    name: "Modified this week"
    order:
      - file.name
      - file.mtime

    Backlink catatan ini

    filters:
  and:
    - file.hasLink(this.file)
views:
  - type: table
    name: "Backlinks"
    order:
      - file.name
      - file.folder

    Catatan suara yang direkam dengan Vox.md

    filters:
  and:
    - file.inFolder("Vox")
    - file.hasTag("voice")
views:
  - type: table
    name: "Voice notes"
    order:
      - file.ctime
      - file.name
      - file.tags

    Bagian order list memilih kolom. Urutan sortir adalah pengaturan tampilan yang Anda ubah di bilah alat tampilan Obsidian, sehingga contoh tidak menuliskannya.

    7. Tampilkan hasil Capture Anda di base

    Vox.md menyimpan hasil Capture Anda sebagai catatan Markdown di sebuah folder di vault Anda. Dokumentasi metadata menyatakan bahwa Route dapat menambahkan metadata statis sebagai key: value baris, seperti tags: [journal, idea], dan itu Frontmatter Catatan menuliskannya pada cakupan dokumen. Juga dijelaskan metadata lokasi opsional. Base yang difilter pada folder atau tag tersebut, seperti contoh terakhir di atas, kemudian mendaftar hasil Capture Anda dalam satu tabel. Buat metadata dengan generator properti, dan lihat catatan suara ke Obsidian di iPhone untuk penyiapannya.

    Alat terkait: generator templat catatan harian untuk membuat catatan bertanggal, pembuat callout dan Pembuat tabel Markdown untuk isi catatan.

    Ingin catatan yang layak dikueri?

    Vox.md merekam suara dan teks di iPhone dan Mac langsung ke vault Anda sebagai Markdown, dengan properti yang Anda pilih. Perekaman, Transcription, dan Capture memerlukan Vox.md Unlimited; akun yang memenuhi syarat mendapat uji coba gratis 7 hari.

    Tangkap catatan lewat suara

    Generator di atas berfungsi penuh tanpa aplikasinya.

    8. Pemecahan masalah

    • Base menampilkan semua catatan. Filter sumber belum ditetapkan. Secara default base mencakup seluruh vault, jadi tambahkan file.inFolder() atau file.hasTag() penyaring.
    • Kolom properti kosong. Namanya tidak cocok, termasuk huruf besar/kecil, atau catatan tidak memiliki properti itu di frontmatter-nya. Periksa Properties catatan dan nama kolom.
    • Kesalahan YAML. Periksa indentasi, yang menggunakan spasi, dan tanda kutip. Filter yang berisi teks memerlukan tanda kutip bersarang: 'status == "done"'.
    • Tampilan map kosong. Tata letak map memerlukan plugin Maps, menurut halaman tampilan.

    9. Pertanyaan

    Apakah Bases plugin inti?

    Ya. Bantuan Obsidian menyatakan: “Bases adalah plugin inti yang memungkinkan Anda membuat tampilan catatan seperti basis data.”

    Bases atau Dataview?

    Keduanya terpisah. Dataview adalah plugin komunitas dengan bahasa kueri sendiri. Base adalah YAML yang dibaca Obsidian sendiri, tanpa from kunci: Anda mempersempit catatan dengan filter. Halaman ini tidak membandingkan fitur keduanya lebih jauh.

    Bisakah saya mengedit YAML secara manual?

    Ya. .base berkas berupa teks YAML, dan halaman sintaks mendokumentasikan kunci-kuncinya. Buka berkas yang dihasilkan di editor apa pun, atau tempel blok kode ke dalam catatan dan edit di sana.

    Apakah generator mengunggah data saya?

    Tidak. Skrip di halaman ini membuat YAML di perangkat Anda, dan halaman ini tidak melakukan permintaan jaringan. Memuat ulang akan menghapus semuanya.
