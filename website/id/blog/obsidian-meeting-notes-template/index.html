2. Tambahkan templat ke Obsidian

Plugin Core Templates. Aktifkan Templates di Pengaturan → Plugin inti, lalu atur Template folder location, misalnya Templates. Simpan templat di sana sebagai berkas .md . Di catatan baru, jalankan Templates: Insert template dari palet perintah lalu pilih templatnya. Obsidian mengganti {{title}}, {{date}} dan {{time}} saat Anda menyisipkan templat. Format setelah titik dua, seperti {{date:YYYY-MM-DD}}, memakai token Moment.js. Lihat bantuan plugin Templates dan token format Moment.js.

Plugin Templater. Instal Templater dari Plugin komunitas lalu atur Template folder location. Sisipkan templat dengan Templater: Open insert template modal. Agar setiap catatan baru di Meetings/ memakai templat ini, aktifkan Trigger Templater on new file creation, atur Template matching mode ke templat folder, lalu petakan folder Meetings ke berkas tersebut. Dokumentasi pengaturan Templater menjelaskan templat folder, dan modul tanggal mendokumentasikan tp.date.now.

Properti. Frontmatter di antara baris --- menjadi properti catatan. Tautan di dalam properti harus diberi tanda kutip, itulah sebabnya bidang project ditulis "[[Project name]]". Lihat Properti di Obsidian Help. Untuk memeriksa frontmatter yang sudah Anda miliki, gunakan generator dan pemeriksa properti.

3. Satu catatan per rapat

Simpan rapat dalam satu folder, seperti Meetings/, dan cantumkan tanggal serta waktu mulai di nama berkas: Meetings/2026-11-19 1430 Design review.md. Nama dengan urutan ini terurut menurut tanggal, dan dua rapat pada hari yang sama tidak pernah berbagi berkas.

Aktifkan Tautan ke catatan harian di generator untuk menambahkan baris Daily note: yang menautkan ke catatan hari itu. Tautan ini memakai YYYY-MM-DD; jika catatan harian Anda memakai format tanggal lain, ubah agar sesuai; generator templat catatan harian menampilkan pratinjau nama berkas yang dihasilkan sebuah format. Untuk mencantumkan rapat hari itu di catatan harian juga, tautkan dari sana; menambahkan ke catatan harian Obsidian menunjukkan cara Vox.md menambahkan entri ke sana.

4. Butir tindakan dan tindak lanjut

Tulis setiap butir tindakan sebagai tugas Obsidian, - [ ] Send the release notes, lalu centang menjadi - [x] jika sudah selesai; lihat Sintaks pemformatan dasar. Tulis penanggung jawabnya lebih dulu agar setiap baris terbaca sebagai siapa melakukan apa.

Jika item tindakan Anda sudah berupa daftar biasa, Pembuat daftar periksa Markdown mengubahnya menjadi tugas dan menambahkan tenggat dalam format Tasks, Dataview, atau Reminder.

Gaya opsional menambahkan tanggal tenggat dalam format plugin komunitas Tasks: 📅 diikuti YYYY-MM-DD. Generator mengisi tanggal rapat; ubah ke tanggal tenggat yang sebenarnya. Tanpa plugin Tasks, emoji dan tanggal hanya teks biasa dan tugas tetap berfungsi.

Untuk mengumpulkan butir yang belum selesai dari setiap rapat di satu tempat, tambahkan kueri Tasks ke sebuah catatan:

```tasks
not done
path includes Meetings
```

Kueri ini menampilkan tugas yang belum selesai dari catatan yang jalurnya mengandung Meetings. Dataview dapat membuat daftar serupa jika Anda sudah memakainya.

5. Isi catatan dari rekaman

Templat memberi Anda judul-judulnya. Vox.md dapat menulis catatannya sendiri: aplikasi ini merekam rapat, mentranskripsikannya di perangkat Anda, dan menyimpan berkas Markdown ke vault Anda melalui Rute.

  1. Rekam. Di Mac, Vox.md dapat merekam satu aplikasi panggilan dan mikrofon Anda sebagai trek terpisah; ikuti transkripsikan rapat Mac secara lokal ke Obsidian. Untuk rapat tatap muka di ruangan, rekam dengan mikrofon di iPhone atau iPad; lihat simpan catatan suara iPhone ke Obsidian.
  2. Pilih tujuan. Di Rute, pilih vault Anda, pilih Catatan Baru, lalu masukkan jalur seperti Meetings/{date}-{hour}{minute}.md. {date} ditulis sebagai 2026-11-19 dan {hour}{minute} sebagai 1430. Ini adalah token Vox.md, bukan format Moment.js. Lihat templat tangkapan Obsidian untuk resep jalur lainnya.
  3. Pilih mode. Atur mode pemrosesan Rute ke Catatan Rapat. Mode ini menghasilkan bagian ## Notes dan, jika transkrip berisi butir tindakan, bagian ## Action Items berupa daftar periksa. Mode ini memakai Apple Intelligence pada perangkat keras yang kompatibel dengan macOS 26 atau iOS 26; jika tidak, formatter deterministik menyusun strukturnya.

Catatan Rapat tidak mengisi agenda, peserta, atau keputusan untuk Anda. Jika Anda ingin judul-judul itu di atas catatan, pilih Markdown polos di generator, hapus centang Catatan dan Butir tindakan, lalu simpan hasilnya di vault Anda. Kemudian pilih berkas itu sebagai templat vault Rute. Vox.md mengisi token kurung kurawal tunggalnya di templat dan menulis transkrip yang telah diproses di bawahnya. Periksa catatan pertama sebelum mengandalkan tata letaknya; dokumentasi Rute membahas tujuan dan templat.

Jika rapat berlangsung di Zoom atau Teams dan Anda mengunduh transkripnya sebagai file .srt atau .vtt, ubah menjadi Markdown dengan giliran bicara menggunakan Konverter SRT dan VTT, lalu tempel di bawah ## Transcript judul templat ini.

Beri tahu semua orang dalam rapat bahwa Anda merekam dan mentranskripsikan, dan minta persetujuan mereka terlebih dahulu. Aturannya berbeda menurut tempat dan lingkungan kerja; lihat beri tahu orang bahwa Anda merekam.

6. Pertanyaan

Sebaiknya pakai Core Templates atau Templater?

Core Templates sudah tersedia di Obsidian dan mencakup judul, tanggal, dan waktu. Templater adalah plugin komunitas yang menambahkan skrip, pergeseran tanggal, dan templat folder, sehingga catatan baru di Meetings/ bisa mendapat templat secara otomatis. Jika Anda hanya butuh bidang di halaman ini, Core Templates sudah cukup.

Mengapa {{date}} tidak berubah kemudian?

Obsidian mengganti variabel templat sekali saja, saat Anda menyisipkan templat. Setelah itu catatan berisi teks biasa, seperti 2026-11-19, dan tetap begitu. Itulah yang Anda inginkan untuk catatan rapat.

Bisakah Vox.md memakai templat Obsidian saya?

Sebagian. Rute dapat memakai berkas Markdown dari vault Anda sebagai templatnya. Vox.md mengisi token kurung kurawal tunggalnya sendiri, seperti {date}, serta perintah tanggal Templater tp.date.now dan tp.file.creation_date. Aplikasi ini tidak menjalankan perintah Templater lain, seperti tp.file.title, dan tidak memperluas variabel Templates inti seperti {{title}}, jadi jangan masukkan itu ke templat Rute. Gunakan keluaran Markdown polos untuk Rute Vox.md.

Apakah generator mengirim pilihan saya ke suatu tempat?

Tidak. Templat dibuat oleh skrip di halaman ini. Skrip menyimpan pilihan terakhir Anda di penyimpanan lokal browser, sehingga pilihan itu masih ada lain kali, dan Atur ulang menghapusnya.
