Pembuat callout Obsidian: semua tipe, alias, dan opsi pelipatan

Pilih tipe, tambahkan judul dan isi, pilih pelipatan dan penyarangan, lalu salin callout > [!type] yang valid, lengkap dengan daftar semua tipe dan alias serta cara kerja callout yang dapat dilipat.

Memerlukan
Peramban modern apa pun, termasuk Safari di iPhone. Opsional: Obsidian untuk callout, dan Vox.md untuk iPhone atau Mac untuk menangkap catatan lewat suara atau teks.
Jawaban singkat

Callout adalah blockquote yang baris pertamanya adalah > [!type] Optional title. Setiap baris berikutnya diawali dengan > . Tambahkan + atau - tepat setelah tanda kurung untuk membuatnya dapat dilipat. Untuk membuatnya tanpa mengetik awalan, gunakan pembuat callout di bawah.

> [!warning]- Back up first
> Copy the vault before you change the plugin settings.
>
> Then restart Obsidian.

Pembuat callout menambahkan > awalan ke setiap baris (diulang untuk penyarangan), mempertahankan baris kosong di dalam callout, dan tidak menggandakan > yang Anda tempel. Semuanya berjalan sepenuhnya di halaman ini: teks Anda tidak pernah diunggah, dan halaman ini tidak membuat permintaan jaringan.

2. Sintaks callout

> [!type] Title
> Body line one.
> Body line two.
  • Tipe. Baris pertama blockquote diawali dengan tipe dalam tanda kurung setelah tanda seru: > [!info]. Bantuan Obsidian menyebutkan bahwa pengenal tipe tidak peka huruf besar-kecil, dan tipe yang tidak didukung akan kembali ke note.
  • Judul. Teks setelah tanda kurung menggantikan judul. Tanpa itu, Obsidian menampilkan pengenal tipe dengan huruf awal kapital, jadi > [!tip] menampilkan “Tip”.
  • Isi. Setiap baris berikutnya diawali dengan > . Isi dapat memuat Markdown, wikilink, dan sematan.
  • Hanya judul. Anda boleh mengosongkan isi: > [!tip] Remember to save adalah callout yang lengkap.

3. Semua tipe callout dan alias

Bantuan Obsidian mencantumkan tipe bawaan ini. Setiap alias dicantumkan bersama tipe asalnya, misalnya tldr dengan abstract.

4. Callout yang dapat dilipat: + vs -

Tambahkan plus atau minus tepat setelah tanda kurung penutup:

> [!faq]+ Open by default
> This callout is foldable and starts expanded.

> [!faq]- Closed by default
> This callout is foldable and starts collapsed.

Bantuan Obsidian menjelaskan + sebagai dapat dilipat dan terbuka secara bawaan, dan - sebagai dapat dilipat dan tertutup secara bawaan. Tanpa keduanya, callout tidak dapat dilipat. Tanda + atau - adalah bagian dari Markdown, jadi tetap ada di dalam file.

5. Callout bersarang, daftar, kode, dan sematan

Untuk callout bersarang, tambahkan lagi > untuk setiap tingkat:

> [!question] Can callouts be nested?
> > [!example] Yes
> > Add one more > for each level.

Pengaturan “Sarangkan di dalam callout lain” pada pembuat callout menuliskan tambahan > di setiap baris, hingga tiga tingkat. Tempel hasilnya di dalam isi callout luar.

Daftar, kode, dan Markdown lainnya ditaruh di dalam isi, dengan awalan > awalan di setiap baris. Bantuan Obsidian menyebutkan isi dapat memuat Markdown, wikilink, dan sematan, dan Anda bisa membungkus konten yang sudah ada, termasuk daftar dan blok kode, dengan memilihnya lalu menjalankan perintah Sisipkan callout perintah. Tempel daftar atau blok kode ke kolom isi pembuat callout dan awalannya akan ditambahkan untuk Anda:

> [!info] Checklist
> - [ ] first
> - [ ] second
>
> ```
> code line
> ```

6. Tipe callout kustom dengan snippet CSS

Tipe yang Anda buat sendiri ditampilkan dengan gaya note. Bantuan Obsidian menyebutkan callout kustom didefinisikan dalam snippet CSS atau plugin komunitas. Contohnya:

.callout[data-callout="custom-question-type"] {
  --callout-color: #000000;
  --callout-icon: lucide-alert-circle;
}

Menurut halaman Bantuan, --callout-color menerima warna CSS yang valid, dan --callout-icon menerima ID ikon dari lucide.dev atau elemen SVG. Lalu tulis > [!custom-question-type] di sebuah catatan. Ketik nama yang sama di kolom tipe kustom pembuat callout.

7. Peringatan GitHub vs callout Obsidian

GitHub memiliki fitur serupa bernama alert. Dokumen GitHub mencantumkan lima: NOTE, TIP, IMPORTANT, WARNING dan CAUTION.

> [!NOTE]
> Useful information that users should know, even when skimming content.

Halaman itu tidak mendokumentasikan pelipatan, judul kustom, maupun tipe kustom; callout Obsidian memiliki ketiganya. Baris pertamanya sama, jadi > [!note] atau > [!warning] sering berfungsi di keduanya, tetapi tipe khusus Obsidian seperti [!bug], +/- pelipatan atau judul berada di luar yang didokumentasikan GitHub. Jika file dibaca di keduanya, tetap gunakan lima tipe GitHub tanpa tambahan.

9. Pertanyaan

Mengapa callout saya tidak tampil?

Periksa tiga hal. Baris pertama harus diawali dengan > lalu [!type], dengan tanda seru dan tanpa spasi di dalam tanda kurung. Setiap baris isi memerlukan >. Baris kosong tanpa > mengakhiri blockquote, sehingga baris setelahnya menjadi teks biasa; tulis sebagai >. Jika masih tampil sebagai blockquote biasa, periksa apakah ada spasi atau salah ketik di antara > dan [!.

Bisakah callout tanpa judul?

Tidak sepenuhnya: jika judul dihilangkan, Obsidian menampilkan pengenal tipe dengan huruf awal kapital. Untuk menyembunyikan judul diperlukan CSS; Bantuan Obsidian menyebutkan bahwa penataan lebih lanjut, seperti menyembunyikan judul, bisa memakai selektor CSS standar. Pembuat callout membiarkan judul kosong jika Anda melakukannya, sehingga Anda mendapat judul bawaan.

Plugin Admonition atau callout bawaan?

Callout bawaan tidak memerlukan plugin dan menggunakan sintaks > [!type] sintaks di halaman ini. Plugin Admonition adalah plugin komunitas terpisah dengan sintaksnya sendiri, yang tidak dibahas di halaman ini. Bantuan Obsidian menyebutkan bahwa tipe callout kustom juga bisa berasal dari plugin komunitas.

Apakah callout berfungsi di Obsidian seluler dan di Publish?

Bantuan Obsidian menyebutkan callout didukung secara bawaan di Obsidian Publish. Halaman callout-nya tidak menyebut seluler, baik ya maupun tidak, jadi halaman ini tidak mengklaim apa pun tentang itu.

Apakah pembuat callout mengunggah teks saya?

Tidak. Skrip di halaman ini membuat callout di perangkat Anda, dan halaman ini tidak membuat permintaan jaringan. Tidak ada yang disimpan: memuat ulang halaman akan menghapusnya.
