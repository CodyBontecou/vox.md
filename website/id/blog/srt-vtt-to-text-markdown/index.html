Tempel atau buka file keterangan dari Zoom, Microsoft Teams, YouTube, atau layanan transkripsi, lalu dapatkan teks yang mudah dibaca, transkrip Markdown, atau format subtitel lainnya. File dibaca di perangkat Anda dan tidak pernah diunggah.

Jawaban singkat

Tempel atau buka file .srt atau .vtt, pilih Teks biasa atau Markdown, lalu salin atau unduh. File tetap ada di perangkat Anda.

Konverter menghapus nomor cue dan kode waktu, menggabungkan baris menjadi paragraf, dan mengubah nama pembicara menjadi giliran bicara tebal untuk catatan. Konverter ini juga mengubah SRT ke VTT dan VTT ke SRT. File dibaca dengan FileReader API browser, dan halaman ini tidak membuat permintaan jaringan, jadi tidak ada yang Anda tempel atau buka yang dikirim ke mana pun.

1. Gunakan konverter

  1. Tambahkan file. Tempel isinya ke kotak, atau pilih file .srt, .vtt atau .txt file. Alat ini mendeteksi formatnya dan menampilkan jumlah cue.
  2. Pilih keluaran. Teks biasa, Markdown, SRT, atau VTT.
  3. Atur opsi pembersihan. Gabungkan baris menjadi paragraf, mulai paragraf baru setelah jeda, hapus baris bergulir yang berulang, buang tag, dan simpan atau buang petunjuk suara seperti [Music].
  4. Salin atau unduh. Unduhan memakai ekstensi yang tepat: .txt, .md, .srt atau .vtt.

Konverter memerlukan JavaScript. Tanpanya, penjelasan di bawah tetap berguna sebagai referensi.

2. SRT vs VTT: apa itu dan apa bedanya

Keduanya adalah format keterangan teks biasa: daftar cue, masing-masing dengan waktu mulai, waktu selesai, dan teks. Perpustakaan Kongres menggambarkan format SubRip (SRT) sebagai format teks sederhana di mana setiap keterangan punya nomor berurutan, serta waktu mulai dan selesai yang dipisahkan oleh -->, satu baris teks atau lebih, dan satu baris kosong. Kode waktunya adalah hours:minutes:seconds,milliseconds. Spesifikasi WebVTT dari W3C mendefinisikan format lebih baru yang digunakan browser untuk teks.

Yang dilakukan konverter saat mengubah format:

  • SRT ke VTT: menambahkan WEBVTT header dan mengubah setiap koma pada stempel waktu menjadi titik.
  • VTT ke SRT: menghapus header, NOTE, STYLE dan REGION dan pengaturan cue, mengubah titik menjadi koma, dan menomori ulang cue mulai dari 1. SRT tidak punya voice span, jadi <v Name>text</v> menjadi Name: text.
  • Encoding teks: Perpustakaan Kongres mencatat bahwa SRT tidak punya standar encoding karakter, sehingga parser harus mendeteksinya. Konverter membaca file sebagai UTF-8. Jika huruf beraksen terlihat salah, buka file di editor teks dan simpan sebagai UTF-8 terlebih dahulu.

3. Di mana mendapatkan file: Zoom, Teams, dan YouTube

Periksa halaman masing-masing vendor untuk paket dan pengaturan Anda, karena admin dan jenis akun memengaruhi apa yang dapat Anda unduh.

Rekaman cloud Zoom

Artikel dukungan Zoom tentang transkripsi audio untuk rekaman cloud menyatakan bahwa setelah transkrip diproses, transkrip muncul sebagai file VTT terpisah bersama rekaman. Ini berlaku untuk rekaman cloud, dan transkripsi audio harus diaktifkan untuk rekaman tersebut. Format file yang dapat dihasilkan rekaman tercantum di panduan Zoom tentang format file rekaman.

transkrip Microsoft Teams

artikel dukungan Microsoft tentang mengunduh transkrip Teams menyatakan bahwa secara default penyelenggara dan ko-penyelenggara dapat mengunduh transkrip sebagai .docx atau .vtt file, dan bahwa kebijakan admin IT Anda dapat mengubah siapa yang boleh mengunduhnya. Pilih .vtt dan buka di sini. Untuk memperbaiki kesalahan sebelum konversi, lihat panduan Microsoft untuk mengedit transkrip Teams.

teks YouTube

Halaman Bantuan YouTube tentang mengedit dan menghapus teks menjelaskan cara mengunduh trek teks dari YouTube Studio untuk video di kanal Anda sendiri. Artikel itu tidak menyebut format file hasil unduhan, jadi tempel atau buka file lalu biarkan konverter mendeteksinya. Halaman YouTube daftar jenis file teks yang didukung mencakup SubRip (.srt) dan WebVTT (.vtt).

Unduh hanya keterangan yang Anda berhak gunakan. Halaman ini tidak mencakup video milik orang lain.

4. Masukkan transkrip ke catatan Obsidian

  1. Pilih Markdown. Nama pembicara menjadi **Name:**, dan cue berurutan dari pembicara yang sama digabung menjadi satu giliran. Aktifkan Tambahkan stempel waktu [mm:ss] jika Anda ingin menemukan posisi Anda dalam rekaman nanti.
  2. Aktifkan properti Obsidian untuk menambahkan blok di bagian atas dengan title, date, source dan tags. Ini YAML yang valid, ditulis seperti cara generator properti menuliskannya. Obsidian membaca baris di antara dua --- di bagian paling atas catatan sebagai properti; lihat halaman Bantuan Obsidian tentang properti.
  3. Tempel ke catatan baru di vault Anda, misalnya di Meetings folder. Jika Anda mengunduh .md file, pindahkan ke folder vault.
  4. Tautkan ke catatan rapat. Buat catatan dengan generator template catatan rapat, lalu tambahkan baris seperti Transcript: [[Team sync transcript]] ke sana. Jika Anda menautkan dari properti, tautan harus diberi tanda kutip: transcript: "[[Team sync transcript]]".

Teks di-escape agar karakter seperti *, $ dan # tidak berubah menjadi pemformatan, matematika, atau tag di Obsidian. Nama pembicara berasal dari file, jadi periksa dulu sebelum membagikan catatan.

5. Mulai dari audio, bukan file keterangan

Jika Anda hanya punya rekaman, Anda tidak memerlukan file subtitel sama sekali. Vox.md mentranskripsi di perangkat dan menulis Markdown langsung ke vault Anda. Menurut dokumentasi model, transkripsi berjalan di perangkat Apple dengan Apple Speech pada perangkat dan bahasa iOS 26 yang didukung, atau dengan model Whisper atau Parakeet opsional yang Anda unduh; lihat Whisper atau Parakeet untuk perbedaannya. 6. Pertanyaan

Apakah file saya diunggah?

Tidak. File yang Anda buka dibaca di browser dengan FileReader API, dan file yang Anda tempel tetap berada di kotak teks. Konversi adalah skrip di halaman ini, dan halaman tidak membuat permintaan jaringan saat Anda memakainya. Saat halaman ditutup atau dimuat ulang, teksnya hilang.

Mengapa baris berulang?

Keterangan otomatis sering bergulir: setiap cue baru mengulang baris sebelumnya dan menambahkan baris baru, sehingga kata yang sama muncul dua atau tiga kali. Aktifkan Hapus baris bergulir yang berulang. Opsi ini menghapus baris yang identik dengan baris di cue sebelumnya. Jika pembicara memang mengucapkan baris yang sama dua kali berturut-turut, pengulangan itu ikut terhapus, jadi biarkan opsi ini mati untuk keterangan buatan manusia yang sudah bersih.

Bisakah saya mempertahankan stempel waktu?

Bisa. Dengan Teks biasa atau Markdown, aktifkan opsi stempel waktu dan setiap paragraf diawali waktu cue pertamanya sebagai [mm:ss], atau [h:mm:ss] setelah satu jam. Untuk waktu setiap cue, konversi ke SRT atau VTT.

Bagaimana mengubah teks kembali menjadi SRT?

Alat ini tidak melakukannya. Teks biasa tidak punya penentuan waktu, jadi SRT memerlukan alat yang menyelaraskan teks dengan audio. Konversi antara SRT dan VTT mempertahankan waktu, karena kedua format memuatnya.

Apakah bisa dipakai di iPhone?

Bisa. Konverter ini memakai kontrol formulir biasa dan pemilih file browser, dan dibuat agar berfungsi di Safari pada iPhone. Salin memakai papan klip jika Safari mengizinkan, dan jika tidak, Anda diminta memilih teksnya.
