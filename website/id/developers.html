API Informasi Publik

Temukan fakta produk dan dokumentasi

API Informasi Publik Vox.md menyajikan informasi produk dan tautan dokumentasi terbitan. Gratis dibaca tanpa akun, kunci API, alur OAuth, atau pembayaran. Endpoint ini mengembalikan informasi yang sudah tersedia di situs publik ini. Baca kontrak OpenAPI 3.1 untuk skema respons bertipe, pengenal operasi, galat, dan deskripsi.

Dapatkan informasi produk

GET https://vox.isolated.tech/api/v1/product mengembalikan nama produk, deskripsi, sistem operasi yang didukung, halaman App Store, URL dokumentasi, dan URL dukungan. Build mengambil fakta ini dari data terstruktur beranda.

curl https://vox.isolated.tech/api/v1/product

Lihat JSON produk

Temukan dokumen

GET https://vox.isolated.tech/api/v1/documents mencantumkan judul halaman publik, ringkasan, dan URL. Gunakan untuk mencari panduan fitur, kebijakan, artikel blog, atau halaman dukungan terkait sebelum meminta kontennya.

curl https://vox.isolated.tech/api/v1/documents

Lihat JSON indeks dokumen

Baca halaman sebagai Markdown

Minta halaman mana pun yang terdaftar dengan Accept: text/markdown untuk konten utamanya. Permintaan dengan Accept: text/html tetap menerima HTML. Kedua representasi menyertakan Vary: Accept. Bagian panduan agen menjelaskan penggunaan yang cocok untuk Vox.md dan menunjuk detail fitur.

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

Galat, cache, dan metode

Endpoint JSON mendukung GET dan HEAD. Jalur API yang tidak dikenal mengembalikan HTTP 404 dengan application/problem+json, nilai stabil code, penjelasan, dan petunjuk pemulihan. Metode yang tidak didukung mengembalikan HTTP 405 dan Allow: GET, HEAD. Respons metadata publik mengizinkan pembacaan lintas asal dan menyatakan masa cache lima menit. Tidak melibatkan kredensial atau data khusus pengguna.

Otomatiskan aplikasi terpasang

Tangkapan, transkripsi, akses vault lokal, dan penulisan catatan berjalan di aplikasi Apple terpasang. Gunakan dokumentasi Integrasi Shortcuts dan skema URL dengan izin pemilik perangkat. API informasi publik tidak mengekspos tindakan tangkapan, rekaman, transkrip, catatan privat, atau folder tujuan. Hubungi dukungan Vox.md untuk pertanyaan.
