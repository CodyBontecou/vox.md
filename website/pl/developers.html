API informacji publicznych

Odkryj fakty produktu i dokumentację

Publiczne API informacji Vox.md udostępnia informacje o produkcie i linki do opublikowanej dokumentacji. Odczyt jest bezpłatny i nie wymaga konta, klucza API, procesu OAuth ani płatności. Te punkty końcowe zwracają informacje już dostępne na tej publicznej stronie. Przeczytaj Kontrakt OpenAPI 3.1 dla typowanych schematów odpowiedzi, ID operacji, błędów i opisów.

Pobierz informacje produktu

GET https://vox.isolated.tech/api/v1/product zwraca nazwę i opis produktu, obsługiwane systemy operacyjne, stronę App Store, URL dokumentacji i URL wsparcia. Proces budowania wyprowadza te informacje ze strukturalnych danych strony głównej.

curl https://vox.isolated.tech/api/v1/product

Zobacz JSON produktu

Znajdź dokument

GET https://vox.isolated.tech/api/v1/documents wylicza publiczne tytuły, opisy i URL. Znajdź funkcję, politykę, artykuł lub wsparcie przed żądaniem treści.

curl https://vox.isolated.tech/api/v1/documents

Zobacz JSON indeksu dokumentów

Czytaj stronę jako Markdown

Żądaj dowolnej strony z Accept: text/markdown dla głównej treści. Żądania z Accept: text/html nadal otrzymują HTML. Oba formaty zawierają Vary: Accept. poradnik agenta wyjaśnia zastosowania Vox.md i szczegóły funkcji.

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

Błędy, cache i metody

Punkty końcowe JSON obsługują GET i HEAD. Nieznane ścieżki API zwracają HTTP 404 z application/problem+json, stabilny code, wyjaśnienie i wskazówkę naprawy. Nieobsługiwane metody zwracają HTTP 405 i Allow: GET, HEAD. Publiczne odpowiedzi metadanych pozwalają czytać między źródłami i deklarują pięciominutowy cache. Bez poświadczeń i danych indywidualnych.

Automatyzuj zainstalowaną aplikację

Przechwytywanie, transkrypcja, lokalny dostęp do skarbca i zapis notatek działają w zainstalowanej aplikacji na urządzeniu Apple. Użyj udokumentowanego Integracje Skrótów i schematu URL za zgodą właściciela urządzenia. Publiczne API nie udostępnia działań zapisu, nagrań, tekstów, prywatnych notatek ani folderów. Kontakt: wsparcie Vox.md z pytaniami.
