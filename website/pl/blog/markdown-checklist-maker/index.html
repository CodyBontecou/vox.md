Kreator list kontrolnych Markdown: zamień dowolną listę w zadania z terminami

Wklej zwykłe wiersze, punktory, numerowane elementy lub istniejącą listę zadań i skopiuj poprawne zadania - [ ] z zachowanym zagnieżdżeniem, opcjonalnym terminem i liczbą ukończonych.

Autor:
Cody Bontecou
Aktualizacja
24 listopada 2026 r.
Wymaga
Dowolna nowoczesna przeglądarka, także Safari na iPhone. Opcjonalnie: Obsidian dla list kontrolnych i Vox.md na iPhone lub Mac do przechwytywania zadań głosem.
Krótka odpowiedź

Zadanie Markdown to łącznik, spacja, nawiasy, spacja i tekst. Zapisz - [ ] task dla zadania otwartego i - [x] done dla zadania ukończonego. Aby zamienić całą listę w zadania, wklej ją do kreatora list kontrolnych poniżej.

- [ ] buy milk
	- [ ] oat
- [ ] call Sam
- [x] send invoice

Kreator usuwa istniejące punktory, numery i pola wyboru, żeby nic się nie dublowało, zachowuje wcięcia jako zagnieżdżenie i może dodać termin w formacie, który odczytuje Twoja wtyczka Obsidian. Działa w całości na tej stronie: lista nigdy nie jest przesyłana, a strona nie wysyła żądań sieciowych.

2. Składnia list kontrolnych w Markdown

- [ ] unchecked task
- [x] checked task
- [ ] parent task
	- [ ] nested task

Każde zadanie to element listy: łącznik i spacja, a potem [ ] ze spacją między nawiasami, a potem tekst. Obsidian Help strona i GitHub Docs strona opisują to jako łącznik i spację, po których następuje [ ]. Aby oznaczyć zadanie jako ukończone, GitHub Docs każe użyć [x].

Spacje mają znaczenie. specyfikacja GitHub Flavored Markdown definiuje znacznik pola wyboru jako lewy nawias, biały znak lub literę xoraz nawias zamykający, a przed tekstem po nim wymagany jest biały znak. Zatem [] z pustym środkiem lub - [ ]text bez spacji po nawiasie, nie spełnia definicji. Łącznik i jego spacja sprawiają, że wiersz w ogóle jest elementem listy.

Listy zadań nie należą do podstawowego Markdown. Ta sama specyfikacja oznacza je jako rozszerzenie CommonMark, a jej wstęp mówi, że funkcje spoza oryginalnej specyfikacji CommonMark są oznaczone jako rozszerzenia. Renderer, który nie implementuje tego rozszerzenia, pokazuje nawiasy jako zwykły tekst, co jest zwykłym powodem, dla którego pole wyboru wyświetla się jako [ ] na stronie.

3. Listy kontrolne w Obsidian

Strona Obsidian Help podstawowa składnia formatowania omawia listy zadań:

  • Zadanie zaczyna się od łącznika i spacji, po których następuje [ ].
  • Możesz użyć dowolnego znaku w nawiasach, aby oznaczyć zadanie jako ukończone, więc [x], [-] i [?] liczą się jako ukończone.
  • Zagnieżdżasz listę zadań, dodając wcięcia do elementów listy. Użyj Tab lub Shift+Tab aby wciąć lub cofnąć wcięcie zaznaczonych elementów.
  • W widoku czytania możesz przełączyć zadanie, zaznaczając jego pole wyboru.

Strona Help opisuje, że dowolny znak kończy zadanie. Nie opisuje innego wyglądu dla każdego znaku. Jeśli [-] lub [?] wygląda inaczej niż [x] w Twoim sejfie, wynika to z motywu lub fragmentu CSS, który zainstalowałeś, a nie z samego Markdown.

Licznik postępu w kreatorze liczy tak samo: każdy znak w nawiasach inny niż spacja oznacza ukończone zadanie, więc [x], [X], [-] i [?] są ukończone, a [ ] jest otwarte. Wiersze zaczynające się od „done:” lub „x ” to zwykły tekst; narzędzie nie zgaduje, że oznaczają ukończone zadanie.

4. Terminy: Tasks, Dataview i Reminder

Składnia list zadań w Obsidian nie ma własnego terminu: strona Help go nie opisuje. Trzy wtyczki odczytują datę zapisaną w treści zadania, każda w swoim formacie. Kreator zapisuje datę w formacie ISO YYYY-MM-DD we wszystkich wtyczkach. Bez wtyczki data jest zwykłym tekstem.

FormatOdczytujePrzykładowy wiersz
Termin: 📅 YYYY-MM-DDTasks, która mówi, że data musi być w formacie YYYY-MM-DD .- [ ] send invoice 📅 2026-11-25
Zaplanowano: ⏳ YYYY-MM-DDTasks- [ ] send invoice ⏳ 2026-11-25
Rozpoczęcie: 🛫 YYYY-MM-DDTasks- [ ] send invoice 🛫 2026-11-25
Pole wbudowane: [due:: YYYY-MM-DD]Dataview dokumentacja, która odczytuje pola zapisane w zadaniu, takie jak [completion:: 2021-08-15]- [ ] send invoice [due:: 2026-11-25]
Wtyczka Reminder: (@YYYY-MM-DD) lub (@YYYY-MM-DD HH:mm)obsidian-reminder wtyczka, której README pokazuje (@2021-08-14) i (@2021-08-14 09:37) przy niezaznaczonych zadaniach- [ ] send invoice (@2026-11-25 09:30)

Wybierz jedną wtyczkę, której używasz. Strona Dataview wymienia też własne skróty emoji dla dat i mówi, że tylko te skróty są obsługiwane; kreator zamiast tego zapisuje nawiasową formę Dataview. README Reminder mówi, że nie dostaniesz powiadomień o przypomnieniach przy zadaniach, które już zaznaczyłeś jako ukończone.

5. Różnice między GitHub a Obsidian

GitHub Docs opisuje [ ] dla zadania otwartego i [x] aby oznaczyć zadanie jako ukończone. Specyfikacja GFM definiuje znacznik jako biały znak lub literę x między nawiasami. Obsidian akceptuje dowolny znak. Zatem zadanie takie jak - [-] skipped lub - [?] unsure jest ukończone w Obsidian, ale wykracza poza definicję znacznika w specyfikacji, a renderer zgodny ze specyfikacją może pokazać je jako zwykły tekst. Jeśli plik jest czytany także w GitHub, używaj wyłącznie [ ] i [x] .

GitHub Docs dodaje jedną regułę: jeśli opis zadania zaczyna się od nawiasu, poprzedź go ukośnikiem wstecznym, jak w - [ ] \(Optional) Open a followup issue. Kreator nie dodaje ukośnika za Ciebie; ostrzega, gdy zadanie zaczyna się od nawiasu.

Tabele to druga składnia, w której liczą się szczegóły Obsidian i GitHub. Aby zamienić komórki arkusza lub CSV w tabelę działającą w Obsidian i na GitHub, użyj Kreator tabel Markdown.

Wyróżnij podsumowanie lub ostrzeżenie nad listą zadań za pomocą calloutu; narzędzie Generator calloutów Obsidiana tworzy > [!type] w Markdownie, także zwijany.

6. Przechwytuj zadania głosem lub tekstem na iPhone i Mac z Vox.md

Tryb przetwarzania Lista zadań w Vox.md tworzy z przechwycenia elementy zadań Markdown - [ ] z przechwycenia, a rozwiązaniem zapasowym jest deterministyczny formater list kontrolnych. Głos jest transkrybowany na Twoim urządzeniu. Na Pasku przechwytywania Checklistę dodaje - [ ] jako prefiks, a Dwie daty wstawia (@yyyy-MM-dd) lub formę z godziną. Zobacz Szybkie złapanie i Routes i tryby przetwarzania w dokumentacji.

Route może dodawać elementy do notatki dziennej pod nagłówkiem takim jak ## Tasks; Dodawaj do notatki dziennej Obsidian krok po kroku opisuje konfigurację, a generator szablonu notatki dziennej zapisuje strukturę notatki. Zadania ze spotkania znajdziesz w szablonie notatek ze spotkań; przepis na prefiks listy zadań znajdziesz w szablony przechwytywania.

Vox.md zapisuje formę (@yyyy-MM-dd) pokazaną w dokumentacji. Nie zapisuje dat emoji wtyczki Tasks ani pól Dataview. Jeśli używasz któregoś z tych formatów, wklej przechwycone zadania do kreatora powyżej i wybierz ten format albo później popraw datę. Aby zbudować właściwości na górze notatki, użyj generator właściwości.

7. Pytania

Dlaczego moje pole wyboru wyświetla się jako tekst [ ]?

Renderer nie rysuje list zadań. Listy zadań są rozszerzeniem CommonMark, więc renderer bez niego pokazuje nawiasy. Sprawdź, czy wiersz zaczyna się od łącznika i spacji, czy między nawiasami jest spacja lub x między nawiasami oraz że po nawiasie zamykającym jest spacja. W Obsidian zadanie w bloku kodu lub w komórce tabeli może nie wyświetlać się jako pole wyboru, tak jak element listy.

Jak zagnieździć zadania?

Dodaj wcięcie do zadania podrzędnego. W Obsidian naciśnij Tab aby wciąć zaznaczone elementy, oraz Shift+Tab aby cofnąć wcięcie. Kreator zamienia 2 lub 4 spacje z Twojej listy na jedną tabulację na poziom albo, jeśli wolisz, na 2 lub 4 spacje.

Jak zaznaczyć pole znakiem innym niż x?

Obsidian Help mówi, że dowolny znak w nawiasach oznacza zadanie jako ukończone, więc - [-] task i - [?] task są ukończone. Kreator zachowuje wklejony znak, dopóki nie zresetujesz listy. W plikach czytanych także w GitHub używaj [x].

Jak dodać termin, który odczytuje wtyczka Tasks?

Dodaj 📅 oraz datę YYYY-MM-DD na końcu zadania, na przykład - [ ] send invoice 📅 2026-11-25. Wybierz powyżej „Wtyczka Tasks: termin”, aby dodać go do każdego zadania. Użyj ⏳ dla daty planowanej, a 🛫 dla daty rozpoczęcia.

Czy kreator przesyła moją listę?

Nie. Listę konwertuje skrypt na tej stronie, na Twoim urządzeniu, a strona nie wysyła żadnych żądań sieciowych. Nie zapisuje Twojej listy: zamknięcie lub odświeżenie strony ją czyści.
