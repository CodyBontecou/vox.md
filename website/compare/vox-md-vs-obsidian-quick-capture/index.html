Vox.md vs Obsidian Quick Capture: which workflow fits?

Keep Obsidian as your notes workspace. Choose how you want thoughts to reach it.

By
Cody Bontecou
Updated
October 26, 2026
Scope
Documented iPhone workflows
The short answer

Start with native Obsidian capture if its available controls already do what you need. Consider Vox.md when you want its combination of Capture Presets, local speech backend choices, mixed media, and direct Markdown-folder delivery. Both can be part of the same vault workflow.

This comparison is published by Vox.md. It describes documented capabilities as of October 26, 2026, rather than a device benchmark. It does not rank transcription accuracy, battery use, or capture speed. Check your installed versions before choosing a workflow.

When native Obsidian is enough

Obsidian 1.14 documents Quick Capture on iOS 26 and later. It can create a note or add text to a daily or existing note. If you only need that, try the built-in workflow first. See Obsidian’s iOS guide.

The October 22 announcement for Obsidian 1.15 mobile early access adds live voice transcription and saved recordings, including Lock Screen capture on iOS 26. That release is labeled early access as of this comparison. Voice support should not be treated as absent from Obsidian simply because it is missing from an older installed build.

Obsidian’s core app is free, and Sync and Publish are optional paid services. Early-access builds are associated with Catalyst support. See Obsidian’s current pricing for the applicable terms. You do not need to buy another capture app just to keep using Obsidian.

When to add Vox.md

A Capture Preset combines the intended processing and output. For example, an Inbox preset can keep prose as written, while a Tasks preset can format entries and route them beneath a Tasks heading. Text processing is separately optional, so a typed note does not need to be rewritten.

The same composer can include text, a link, an attachment, a scan, a sketch, or voice. Vox.md writes Markdown and attachments into the folder you choose. That is useful when the note belongs in your existing file structure or when you want capture into a Markdown folder without requiring Obsidian.

For recording from the wrist, Vox.md has a documented Watch-to-iPhone workflow: record locally on Watch, then transcribe and deliver through the paired phone. This is not independent speech processing on Watch, and a queued recording is not a delivered Markdown note.

Vox.md includes 15 free transcription minutes and 10 successful Capture deliveries. Unlimited use is a one-time lifetime purchase; the App Store supplies the regional price. Those allowances let you check your destination before committing to a longer workflow.

Check file access and sync first

A vault visible inside Obsidian is not automatically available to Vox.md. The folder must appear in the Files picker and allow writes. Vox.md does not authenticate to the Obsidian Sync service. If your vault cannot be selected, native capture may be the more practical option for that setup.

Obsidian describes its local storage and the optional Sync service’s encryption on its pricing page. Vox.md transcribes on device, but a selected cloud-backed folder can still sync completed notes through its provider. Neither the phrase “local transcription” nor a Markdown export tells you how a separate sync provider handles the resulting file.

If you choose Vox.md, prepare its speech backend while connected and verify a short write. Cloud-backed folder availability and later sync are separate from on-device recognition. Avoid changing your vault’s sync arrangement or combining providers just to test a capture app.

Try a small workflow before deciding

  1. Pick one real destination, such as an Inbox note or today’s journal.
  2. Try the native capture option available in your installed Obsidian version. Check the resulting file and formatting.
  3. If you need Vox.md’s workflow, connect the same accessible folder and send one short capture. Compare the final Markdown, setup effort and review steps.
  4. For voice, review the transcript and retained audio settings. For Watch, confirm actual phone delivery before relying on unattended capture.

Keep the built-in option if it meets the need. Add another tool when a specific route or capture behavior makes the extra setup worthwhile.
