Markdown চেকলিস্ট মেকার: যেকোনো তালিকাকে শেষ তারিখসহ কাজে রূপান্তর করুন

সাধারণ লাইন, বুলেট, ক্রমিক আইটেম বা বিদ্যমান কাজের তালিকা পেস্ট করুন এবং বৈধ - [ ] কাজ কপি করুন, নেস্টিং অক্ষত রেখে, ঐচ্ছিক শেষ তারিখ ও কতটি সম্পন্ন তার গণনাসহ।

Markdown কাজ হলো একটি হাইফেন, একটি স্পেস, বন্ধনী, একটি স্পেস ও লেখা। লিখুন - [ ] task খোলা কাজের জন্য এবং - [x] done সম্পন্ন কাজের জন্য। পুরো তালিকাকে কাজে রূপান্তর করতে ব্যবহার করুন চেকলিস্ট মেকার নিচে।

- [ ] buy milk
	- [ ] oat
- [ ] call Sam
- [x] send invoice

মেকার বিদ্যমান বুলেট, সংখ্যা ও চেকবক্স সরিয়ে দেয় যাতে কিছু দ্বিগুণ না হয়, ইন্ডেন্টেশনকে নেস্টিং হিসেবে রাখে, এবং আপনার Obsidian প্লাগইন যে ফরম্যাটে পড়ে সেই ফরম্যাটে শেষ তারিখ যোগ করতে পারে। এটি পুরোপুরি এই পাতায় চলে: তালিকা কখনো আপলোড হয় না, এবং পাতাটি কোনো নেটওয়ার্ক অনুরোধ করে না।

1. আপনার চেকলিস্ট বানান

চেকলিস্ট মেকার চালাতে JavaScript লাগে। এটি ছাড়াও নিচের সিনট্যাক্স রেফারেন্স হিসেবে কাজ করে।

আপনার তালিকা
কী করবেন
নেস্টিং

আপনার তালিকার একটি ট্যাব সবসময় এক স্তর গণ্য হয়। শিরোনাম শিরোনামই থাকে।

প্রতিটি কাজের জন্য শেষ তারিখ

আপনার চেকলিস্ট

প্রিভিউ

ফলাফল দেখতে একটি তালিকা পেস্ট করুন। {total}-এর মধ্যে {done} সম্পন্ন এই তালিকায় কোনো কাজ নেই। ক্লিপবোর্ডে কপি হয়েছে। কপি করা যায়নি। টেক্সট নির্বাচন করে নিজে কপি করুন। উদাহরণ লোড হয়েছে। মুছে ফেলা হয়েছে। আপনার চেকলিস্ট চেকবক্স ছাড়া আপনার তালিকা শেষ তারিখ যোগ করতে একটি বৈধ তারিখ বেছে নিন। কোনো তারিখ যোগ হয়নি। 09:30-এর মতো একটি সময় দিন। তারিখটি সময় ছাড়াই যোগ হয়েছে। যেসব কাজে আগে থেকেই এই ধরনের তারিখ আছে সেগুলো যেমন ছিল তেমনই রাখা হয়েছে। GitHub-এ বন্ধনী দিয়ে শুরু হওয়া কাজের বিবরণের আগে একটি ব্যাকস্ল্যাশ লাগে।

2. Markdown চেকলিস্টের সিনট্যাক্স

- [ ] unchecked task
- [x] checked task
- [ ] parent task
	- [ ] nested task

প্রতিটি কাজ একটি তালিকা আইটেম: একটি হাইফেন ও একটি স্পেস, তারপর [ ] বন্ধনীর মাঝে একটি স্পেস দিয়ে, তারপর লেখা। Obsidian Help পৃষ্ঠা এবং GitHub Docs পৃষ্ঠা দুটিই এটিকে বর্ণনা করে একটি হাইফেন ও একটি স্পেস, তারপর [ ]। কোনো কাজ সম্পন্ন চিহ্নিত করতে GitHub Docs ব্যবহার করতে বলে [x].

স্পেসগুলো গুরুত্বপূর্ণ। GitHub Flavored Markdown স্পেসিফিকেশন চেকবক্স মার্কারকে সংজ্ঞায়িত করে একটি বাম বন্ধনী, একটি ফাঁকা স্থানের অক্ষর বা অক্ষর xএবং একটি ডান বন্ধনী, আর এর পরের লেখার আগে ফাঁকা স্থান লাগে। তাই [] যার ভেতরে কিছু নেই, অথবা - [ ]text বন্ধনীর পরে স্পেস না থাকলে সংজ্ঞার সঙ্গে মেলে না। হাইফেন ও তার স্পেসই লাইনটিকে তালিকা আইটেম বানায়।

কাজের তালিকা মূল Markdown-এর অংশ নয়। একই স্পেসিফিকেশন এগুলোকে CommonMark-এর এক্সটেনশন হিসেবে চিহ্নিত করে, এবং এর ভূমিকায় বলা আছে মূল CommonMark স্পেসিফিকেশনে নেই এমন ফিচার এক্সটেনশন হিসেবে চিহ্নিত। যে রেন্ডারার এক্সটেনশনটি বাস্তবায়ন করে না, সেটি বন্ধনীগুলো হুবহু লেখা হিসেবে দেখায়, আর এটিই সাধারণত চেকবক্সের বদলে [ ] পাতায় দেখা যাওয়ার কারণ।

3. Obsidian-এ চেকলিস্ট

Obsidian Help-এর মৌলিক ফরম্যাটিং সিনট্যাক্স পাতায় কাজের তালিকা নিয়ে আলোচনা আছে:

  • কাজ শুরু হয় একটি হাইফেন ও একটি স্পেস দিয়ে, তারপর [ ].
  • কাজটি সম্পন্ন চিহ্নিত করতে বন্ধনীর ভেতরে যেকোনো অক্ষর ব্যবহার করতে পারেন, তাই [x], [-] এবং [?] সবই গণ্য হয়।
  • তালিকা আইটেম ইনডেন্ট করে কাজের তালিকা নেস্ট করেন। ব্যবহার করুন Tab অথবা Shift+Tab নির্বাচিত আইটেম ইনডেন্ট বা আনইনডেন্ট করতে।
  • Reading view-এ কাজের চেকবক্স নির্বাচন করে সেটি টগল করতে পারেন।

সহায়তা পাতায় বলা আছে যেকোনো অক্ষরই কাজ সম্পন্ন করে। প্রতিটি অক্ষরের আলাদা চেহারার কথা সেখানে নেই। যদি [-] অথবা [?] দেখতে [x] থেকে আপনার ভল্টে আলাদা দেখালে, তা আসে আপনার ইনস্টল করা থিম বা CSS স্নিপেট থেকে, Markdown থেকে নয়।

মেকারের অগ্রগতির লাইনও একইভাবে গোনে: বন্ধনীর ভেতরে স্পেস ছাড়া যেকোনো অক্ষর থাকলে কাজটি সম্পন্ন ধরা হয়, তাই [x], [X], [-] এবং [?] সম্পন্ন, আর [ ] খোলা। যে লাইন “done:” বা “x ” দিয়ে শুরু হয় তা সাধারণ লেখা; টুলটি অনুমান করে না যে সেগুলো সম্পন্ন কাজ বোঝায়।

4. শেষ তারিখ: Tasks বনাম Dataview বনাম Reminder

Obsidian-এর কাজের তালিকার সিনট্যাক্সে নিজস্ব শেষ তারিখ নেই: সহায়তা পাতায় এর কোনো উল্লেখ নেই। তিনটি প্লাগইন কাজের লেখায় লেখা তারিখ পড়ে, প্রতিটির নিজস্ব ফরম্যাটে। জেনারেটর তারিখটি লেখে ISO YYYY-MM-DD তিনটিতেই। প্লাগইন ছাড়া তারিখ শুধু লেখা।

তারিখের ফরম্যাটযা পড়েউদাহরণ লাইন
শেষ তারিখ: 📅 YYYY-MM-DDTasks প্লাগইন, যেখানে বলা আছে তারিখ অবশ্যই YYYY-MM-DD ফরম্যাটে হতে হবে- [ ] send invoice 📅 2026-11-25
সময়সূচি: ⏳ YYYY-MM-DDTasks প্লাগইন- [ ] send invoice ⏳ 2026-11-25
শুরু: 🛫 YYYY-MM-DDTasks প্লাগইন- [ ] send invoice 🛫 2026-11-25
ইনলাইন ফিল্ড: [due:: YYYY-MM-DD]Dataview ডকুমেন্টেশন, যা কাজের গায়ে লেখা ফিল্ড পড়ে, যেমন [completion:: 2021-08-15]- [ ] send invoice [due:: 2026-11-25]
রিমাইন্ডার: (@YYYY-MM-DD) অথবা (@YYYY-MM-DD HH:mm)obsidian-reminder প্লাগইন, যার README দেখায় (@2021-08-14) এবং (@2021-08-14 09:37) টিক না দেওয়া কাজে- [ ] send invoice (@2026-11-25 09:30)

আপনি যে প্লাগইনটি ব্যবহার করেন সেটিই বেছে নিন। Dataview-এর পাতায় তারিখের জন্য নিজস্ব ইমোজি শর্টহ্যান্ডও তালিকাভুক্ত, এবং সেখানে বলা আছে কেবল সেগুলোই সমর্থিত; মেকার তার বদলে Dataview-এর বন্ধনী ফর্ম লেখে। Reminder-এর README বলে, আপনি যেসব কাজ ইতিমধ্যে টিক দিয়েছেন সেগুলোর রিমাইন্ডারের নোটিফিকেশন পাবেন না।

5. GitHub ও Obsidian-এর পার্থক্য

GitHub Docs বর্ণনা করে [ ] খোলা কাজের জন্য এবং [x] সম্পন্ন চিহ্নিত করতে। GFM স্পেসিফিকেশন মার্কারকে সংজ্ঞায়িত করে ফাঁকা স্থান বা অক্ষর x বন্ধনীর মধ্যে। Obsidian যেকোনো অক্ষর মেনে নেয়। তাই এমন কাজ, - [-] skipped অথবা - [?] unsure Obsidian-এ সম্পন্ন, কিন্তু এটি স্পেসিফিকেশনের মার্কার সংজ্ঞার বাইরে, এবং স্পেসিফিকেশন মেনে চলা রেন্ডারার এটি হুবহু লেখা হিসেবে দেখাতে পারে। ফাইলটি GitHub-এও পড়া হলে ব্যবহার করুন [ ] এবং [x] শুধু।

GitHub Docs একটি অতিরিক্ত নিয়ম দেয়: কাজের বিবরণ বন্ধনী দিয়ে শুরু হলে তার আগে ব্যাকস্ল্যাশ বসান, যেমন - [ ] \(Optional) Open a followup issue। মেকার আপনার জন্য ব্যাকস্ল্যাশ যোগ করে না; কোনো কাজ বন্ধনী দিয়ে শুরু হলে সতর্ক করে।

টেবিলই আরেকটি সিনট্যাক্স যেখানে Obsidian ও GitHub-এর খুঁটিনাটি গুরুত্বপূর্ণ। স্প্রেডশিটের সেল বা CSV থেকে এমন টেবিল বানাতে যা Obsidian ও GitHub উভয়ে কাজ করে, ব্যবহার করুন Markdown টেবিল মেকার.

6. iPhone ও Mac-এ Vox.md দিয়ে ভয়েস বা টেক্সটে কাজ ক্যাপচার করুন

Vox.md-এর Todo Checklist প্রসেসিং মোড ক্যাপচার থেকে Markdown - [ ] কাজের আইটেম তৈরি করে, এবং এর বিকল্প হলো একটি ডিটারমিনিস্টিক চেকলিস্ট ফরম্যাটার। ভয়েস আপনার ডিভাইসেই ট্রান্সক্রাইব হয়। Capture Bar-এ, চেকলাইজ প্রিফিক্স হিসেবে - [ ] প্রয়োগ করে, আর দুই তারিখের যোগ করে: (@yyyy-MM-dd) বা সময়সহ রূপ। দেখুন দ্রুত আটকে এবং Routes ও প্রসেসিং মোড ডকুমেন্টেশন।

একটি Route আইটেমগুলো আপনার দৈনিক নোটের এমন শিরোনামের নিচে যোগ করতে পারে, যেমন ## Tasks; Obsidian দৈনিক নোটে যোগ করুন সেটআপ ধাপে ধাপে দেখায়, আর দৈনিক নোট টেমপ্লেট জেনারেটর নোটের কাঠামো লেখে। মিটিংয়ের অ্যাকশন আইটেমের জন্য দেখুন মিটিং নোট টেমপ্লেট; কাজের তালিকার প্রিফিক্স রেসিপির জন্য দেখুন ক্যাপচার টেমপ্লেট.

Vox.md লেখে (@yyyy-MM-dd) রূপ, যা এর ডকুমেন্টেশনে দেখানো আছে। এটি Tasks প্লাগইনের ইমোজি তারিখ বা Dataview ফিল্ড লেখে না। এগুলোর কোনোটি ব্যবহার করলে ক্যাপচার করা কাজগুলো উপরের মেকারে পেস্ট করে সেই ফরম্যাট বেছে নিন, অথবা পরে তারিখ সম্পাদনা করুন। নোটের শুরুর প্রপার্টি বানাতে ব্যবহার করুন প্রপার্টি জেনারেটর.

iPhone, iPad বা Mac-এ ভয়েসে কাজ ক্যাপচার করুন।

Vox.md আপনার বলা কথাকে ডিভাইসেই একটি Markdown চেকলিস্টে পরিণত করে এবং আপনার Obsidian নোটে যোগ করে। রেকর্ডিং, প্রতিলিখন আর Capture-এর জন্য Vox.md Unlimited লাগে: যোগ্য অ্যাকাউন্টের জন্য ৭ দিনের ফ্রি ট্রায়ালসহ সাপ্তাহিক বা বার্ষিক সাবস্ক্রিপশন, অথবা একবারের আজীবন কেনা। App Store আপনার স্থানীয় দাম দেখায়।

ভয়েসে কাজ ক্যাপচার করুন

উপরের চেকলিস্ট মেকার অ্যাপ ছাড়াই পুরোপুরি কাজ করে।

৭. প্রশ্ন

আমার চেকবক্স [ ] লেখা হিসেবে দেখাচ্ছে কেন?

রেন্ডারার কাজের তালিকা আঁকছে না। কাজের তালিকা CommonMark-এর একটি এক্সটেনশন, তাই এটি ছাড়া রেন্ডারার বন্ধনীগুলো যেমন আছে তেমনই দেখায়। যাচাই করুন লাইনটি হাইফেন ও স্পেস দিয়ে শুরু হয়েছে, একটি স্পেস বা x বন্ধনীর মধ্যে আছে এবং বন্ধ বন্ধনীর পরে একটি স্পেস আছে কিনা। Obsidian-এ কোড ব্লক বা টেবিলের ঘরের ভেতরের কাজ তালিকার আইটেমের মতো চেকবক্স হিসেবে নাও দেখা যেতে পারে।

কাজ কীভাবে নেস্ট করব?

সন্তান কাজটি ইনডেন্ট করুন। Obsidian-এ চাপুন Tab নির্বাচিত আইটেম ইনডেন্ট করতে এবং Shift+Tab আনইনডেন্ট করতে। মেকার আপনার তালিকার 2 বা 4টি স্পেসকে প্রতি স্তরে একটি ট্যাবে রূপান্তর করে, অথবা আপনি চাইলে 2 বা 4টি স্পেসে।

x ছাড়া অন্য অক্ষর দিয়ে কীভাবে বক্স টিক দেব?

Obsidian Help বলে বন্ধনীর ভেতরে যেকোনো অক্ষর কাজটিকে সম্পন্ন চিহ্নিত করে, তাই - [-] task এবং - [?] task সম্পন্ন। তালিকা রিসেট না করলে মেকার আপনার পেস্ট করা অক্ষর রেখে দেয়। যেসব ফাইল GitHub-এও পড়া হয়, সেগুলোতে ব্যবহার করুন [x].

Tasks প্লাগইন পড়তে পারে এমন শেষ তারিখ কীভাবে যোগ করব?

কাজের শেষে 📅 এবং একটি YYYY-MM-DD তারিখ বসান, যেমন - [ ] send invoice 📅 2026-11-25। প্রতিটি কাজে যোগ করতে উপরে “Tasks প্লাগইন: শেষ তারিখ” বেছে নিন। ব্যবহার করুন ⏳ সময়সূচির তারিখের জন্য এবং 🛫 শুরুর তারিখের জন্য।

মেকার কি আমার তালিকা আপলোড করে?

না। তালিকাটি এই পাতার একটি স্ক্রিপ্ট আপনার ডিভাইসেই রূপান্তর করে, এবং পাতাটি কোনো নেটওয়ার্ক অনুরোধ করে না। এটি আপনার তালিকা সংরক্ষণ করে না: পাতা বন্ধ করলে বা রিলোড করলে তা মুছে যায়।
