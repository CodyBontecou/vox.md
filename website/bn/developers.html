Vox.md · ডেভেলপার

সর্বজনীন তথ্য API

পণ্যের তথ্য ও নথি খুঁজুন

Vox.md সর্বজনীন তথ্য API পণ্যের তথ্য ও প্রকাশিত নথির লিঙ্ক দেয়। বিনামূল্যে পড়তে অ্যাকাউন্ট, API কী, OAuth বা পেমেন্ট লাগে না। এন্ডপয়েন্টে এই প্রকাশ্য সাইটের আগে থেকেই থাকা তথ্য ফেরে। পড়ুন OpenAPI 3.1 চুক্তি টাইপযুক্ত রেসপন্স স্কিমা, অপারেশন শনাক্তকারী, ত্রুটি ও বিবরণের জন্য।

পণ্যের তথ্য নিন

GET https://vox.isolated.tech/api/v1/product পণ্যের নাম, বিবরণ, সমর্থিত সিস্টেম, App Store তালিকা, নথির URL ও সহায়তার URL দেয়। বিল্ড হোমের স্ট্রাকচার্ড ডেটা থেকে তথ্য নেয়।

curl https://vox.isolated.tech/api/v1/product

পণ্যের JSON দেখুন

নথি খুঁজুন

GET https://vox.isolated.tech/api/v1/documents প্রকাশ্য পৃষ্ঠার শিরোনাম, সারাংশ ও URL তালিকাভুক্ত করে। লেখা চাওয়ার আগে সংশ্লিষ্ট সুবিধা, নীতি, ব্লগ বা সহায়তার পৃষ্ঠা খুঁজুন।

curl https://vox.isolated.tech/api/v1/documents

নথির সূচির JSON দেখুন

পৃষ্ঠাটি Markdown হিসেবে পড়ুন

তালিকাভুক্ত যেকোনো পৃষ্ঠার অনুরোধ করুন এটি দিয়ে: Accept: text/markdown মূল বিষয়বস্তুর জন্য। এভাবে অনুরোধ করলে: Accept: text/html এখনো HTML পায়। উভয় রূপেই রয়েছে Vary: Accept. এটি এজেন্ট গাইড Vox.md কোন কাজে মানানসই ব্যাখ্যা করে এবং সুবিধার বিবরণ দেখায়।

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

ত্রুটি, ক্যাশিং ও পদ্ধতি

JSON এন্ডপয়েন্ট GET ও HEAD সমর্থন করে। অজানা API পাথ HTTP 404 ফেরত দেয়, সঙ্গে application/problem+json, একটি স্থায়ী code, ব্যাখ্যা ও পুনরুদ্ধারের ইঙ্গিত। অসমর্থিত পদ্ধতি HTTP 405 ফেরত দেয়, সঙ্গে Allow: GET, HEAD. সর্বজনীন মেটাডেটা রেসপন্স অন্য উৎস থেকে পড়া যায় এবং পাঁচ মিনিট ক্যাশের মেয়াদ জানায়। পরিচয়পত্র বা ব্যবহারকারীভিত্তিক ডেটা নেই।

ইনস্টল করা অ্যাপ স্বয়ংক্রিয় করুন

ক্যাপচার, প্রতিলিখন, স্থানীয় ভল্ট খোলা ও নোট লেখা ইনস্টল Apple অ্যাপে চলে। নথিভুক্তটি নিন শর্টকাট ও URL স্কিম সমন্বয় ডিভাইসের মালিকের অনুমতিতে। প্রকাশ্য তথ্য API ক্যাপচার অ্যাকশন, রেকর্ডিং, প্রতিলিপি, ব্যক্তিগত নোট বা গন্তব্য ফোল্ডার দেয় না। যোগাযোগ করুন Vox.md সহায়তা প্রশ্নের জন্য।
