أداة مجانية

أداة قوائم المراجعة في Markdown: حوّل أي قائمة إلى مهام مع تواريخ استحقاق

الصق أسطرًا عادية أو نقاطًا أو عناصر مرقمة أو قائمة مهام موجودة، وانسخ مهام - [ ] صالحة مع الحفاظ على التداخل وتاريخ استحقاق اختياري وعدّ ما أُنجز.

بقلم
Cody Bontecou
حُدّث
24 نوفمبر 2026
يتطلب
أي متصفح حديث، بما في ذلك Safari على iPhone. اختياري: Obsidian لقوائم المراجعة، وتطبيق Vox.md على iPhone أو Mac لالتقاط المهام بالصوت.
الإجابة المختصرة

مهمة Markdown هي شرطة ومسافة وقوسان ومسافة ثم النص. اكتب - [ ] task لمهمة مفتوحة و - [x] done لمهمة منجزة. ولتحويل قائمة كاملة إلى مهام، الصقها في أداة قوائم المراجعة أدناه.

- [ ] buy milk
	- [ ] oat
- [ ] call Sam
- [x] send invoice

تزيل الأداة النقاط والأرقام وخانات الاختيار الموجودة حتى لا يتكرر شيء، وتحافظ على المسافة البادئة كتداخل، ويمكنها إضافة تاريخ استحقاق بالصيغة التي تقرؤها إضافة Obsidian لديك. وتعمل بالكامل في هذه الصفحة: لا تُرفع القائمة أبدًا، ولا تُجري الصفحة أي طلبات شبكة.

تاريخ استحقاق لكل مهمة

قائمة المراجعة الخاصة بك

معاينة

الصق قائمة لتظهر النتيجة. اكتمل {done} من {total} لا توجد مهام في هذه القائمة. تم النسخ إلى الحافظة. فشل النسخ. حدّد النص وانسخه بنفسك. تم تحميل المثال. تم المسح. قائمة المراجعة الخاصة بك قائمتك بدون خانات اختيار اختر تاريخًا صالحًا لإضافة تواريخ الاستحقاق. لم تُضف أي تاريخ. أدخل وقتًا مثل 09:30. أُضيف التاريخ دون وقت. المهام التي تحمل هذا النوع من التواريخ تُركت كما هي. في GitHub، يحتاج وصف المهمة الذي يبدأ بقوس إلى شرطة مائلة عكسية قبله.

2. صيغة قوائم المراجعة في Markdown

- [ ] unchecked task
- [x] checked task
- [ ] parent task
	- [ ] nested task

كل مهمة هي عنصر قائمة: شرطة ومسافة، ثم [ ] مع مسافة بين القوسين، ثم النص. Obsidian Help صفحة و GitHub Docs صفحة كلتاهما تصفانها بأنها شرطة ومسافة تليهما [ ]. ولتحديد مهمة كمكتملة، تنص وثائق GitHub على استخدام [x].

المسافات مهمة. تُعرّف مواصفات GitHub Flavored Markdown علامة خانة الاختيار بأنها قوس أيسر، ثم حرف مسافة فارغة أو الحرف x، ثم قوس أيمن، وتحتاج إلى مسافة فارغة قبل النص الذي يليها. لذلك [] بلا أي شيء داخلهما، أو - [ ]text بلا مسافة بعد القوس، لا تطابق التعريف. الشرطة ومسافتها هما ما يجعل السطر عنصر قائمة أصلًا.

قوائم المهام ليست جزءًا من Markdown الأساسي. تصنفها المواصفات نفسها امتدادًا لـ CommonMark، وتقول مقدمتها إن الميزات غير الموجودة في مواصفات CommonMark الأصلية موسومة كامتدادات. المُعرِض الذي لا ينفذ هذا الامتداد يعرض الأقواس كنص حرفي، وهذا هو السبب المعتاد لظهور خانة الاختيار على شكل [ ] في الصفحة.

3. قوائم المراجعة في Obsidian

في Obsidian Help، تتناول صفحة صيغة التنسيق الأساسية قوائم المهام:

  • تبدأ المهمة بشرطة ومسافة تليهما [ ].
  • يمكنك استخدام أي حرف داخل القوسين لتحديد المهمة كمكتملة، لذلك [x], [-] و [?] كلها تُحتسب.
  • تُدخل قائمة المهام متداخلة بإزاحة عناصر القائمة إلى الداخل. استخدم Tab أو Shift+Tab لإزاحة العناصر المحددة إلى الداخل أو إلى الخارج.
  • يمكنك تبديل حالة المهمة في عرض القراءة بتحديد خانة الاختيار الخاصة بها.

توضح صفحة المساعدة أن أي حرف يكمل المهمة. ولا تصف مظهرًا مختلفًا لكل حرف. إذا كان [-] أو [?] يبدو مختلفًا عن [x] في خزنتك، فهذا يأتي من سمة أو مقتطف CSS ثبّتّه، لا من Markdown نفسه.

يحتسب سطر التقدم في الأداة بالطريقة نفسها: أي حرف داخل القوسين غير المسافة يعني أن المهمة منجزة، لذلك [x], [X], [-] و [?] منجزة، و [ ] مفتوحة. الأسطر التي تبدأ بـ «done:» أو «x » نص عادي؛ والأداة لا تخمّن أنها تعني مهمة منجزة.

4. تواريخ الاستحقاق: Tasks مقابل Dataview مقابل Reminder

لا تتضمن صيغة قوائم المهام في Obsidian تاريخ استحقاق خاصًا بها: فصفحة المساعدة لا تذكر أيًا منها. تقرأ ثلاث إضافات تاريخًا مكتوبًا في نص المهمة، ولكل منها صيغتها. تكتب الأداة التاريخ بصيغة ISO YYYY-MM-DD في جميعها. وبدون الإضافة يبقى التاريخ مجرد نص.

الصيغةتقرؤهسطر مثال
الاستحقاق: 📅 YYYY-MM-DDإضافة Tasks المجتمعية، التي تنص على أن التاريخ يجب أن يكون بصيغة YYYY-MM-DD تحديدًا- [ ] send invoice 📅 2026-11-25
مجدولة: ⏳ YYYY-MM-DDإضافة Tasks المجتمعية- [ ] send invoice ⏳ 2026-11-25
البدء: 🛫 YYYY-MM-DDإضافة Tasks المجتمعية- [ ] send invoice 🛫 2026-11-25
حقل مضمّن: [due:: YYYY-MM-DD]Dataview وثائق، التي تقرأ حقولًا مكتوبة في المهمة، مثل [completion:: 2021-08-15]- [ ] send invoice [due:: 2026-11-25]
التذكير: (@YYYY-MM-DD) أو (@YYYY-MM-DD HH:mm)obsidian-reminder إضافة، التي يعرض README الخاص بها (@2021-08-14) و (@2021-08-14 09:37) في المهام غير المحددة- [ ] send invoice (@2026-11-25 09:30)

اختر الإضافة الواحدة التي تستخدمها. تسرد صفحة Dataview أيضًا اختصاراتها بالرموز التعبيرية للتواريخ، وتقول إنها الاختصارات الوحيدة التي تدعمها؛ أما الأداة فتكتب صيغة الأقواس المربعة الخاصة بـ Dataview بدلًا منها. ويذكر README الخاص بـ Reminder أنك لا تتلقى إشعارات عن تذكيرات المهام التي حددتها بالفعل كمنجزة.

5. الفروق بين GitHub وObsidian

تصف وثائق GitHub [ ] لمهمة مفتوحة و [x] لتحديد مهمة كمكتملة. وتعرّف مواصفات GFM العلامة بأنها مسافة فارغة أو الحرف x بين القوسين. يقبل Obsidian أي حرف. لذا فمهمة مثل - [-] skipped أو - [?] unsure مكتملة في Obsidian، لكنها خارج تعريف العلامة في المواصفات، وقد يعرضها مُعرِض يتبع المواصفات كنص حرفي. إذا كان الملف يُقرأ أيضًا على GitHub، فاستخدم [ ] و [x] فقط.

تضيف وثائق GitHub قاعدة واحدة: إذا بدأ وصف المهمة بقوس، فضع قبله شرطة مائلة عكسية، كما في - [ ] \(Optional) Open a followup issue. لا تضيف الأداة الشرطة المائلة العكسية نيابةً عنك؛ بل تنبّهك عندما تبدأ مهمة بقوس.

6. التقط المهام بالصوت أو النص على iPhone وMac مع Vox.md

ينتج وضع المعالجة Todo Checklist في Vox.md من كل التقاط عناصر مهام Markdown بالبادئة - [ ] ، وبديله الاحتياطي منسّق قوائم مراجعة حتمي. يُفرَّغ الصوت إلى نص على جهازك. في Capture Bar، قائمة التحقق تطبّق البادئة - [ ] ، و إعداد 2 موعد يُدرج (@yyyy-MM-dd) أو صيغة مع وقت. راجع السماح بسرعة و Routes وأوضاع المعالجة في الوثائق.

يمكن لـ Route إضافة العناصر إلى ملاحظتك اليومية تحت عنوان مثل ## Tasks; الإضافة إلى ملاحظة Obsidian اليومية يشرح خطوات الإعداد، و مولّد قالب الملاحظة اليومية يكتب بنية الملاحظة. ولبنود العمل من اجتماع، راجع قالب ملاحظات الاجتماعات؛ ولوصفة بادئة قائمة المهام، راجع قوالب الالتقاط.

يكتب Vox.md صيغة (@yyyy-MM-dd) الموضحة في وثائقه. ولا يكتب تواريخ إضافة Tasks بالرموز التعبيرية ولا حقول Dataview. إذا كنت تستخدم إحداها، فالصق المهام الملتقطة في الأداة أعلاه واختر تلك الصيغة، أو عدّل التاريخ بعد ذلك. ولإنشاء الخصائص في أعلى الملاحظة، استخدم مولّد الخصائص.

التقط المهام بالصوت على iPhone أو iPad أو Mac.

يحوّل Vox.md ما تقوله إلى قائمة مهام بتنسيق Markdown على الجهاز ويضيفها إلى ملاحظتك في Obsidian. يتطلب التسجيل والتفريغ وCapture اشتراك Vox.md Unlimited: اشتراك أسبوعي أو سنوي مع تجربة مجانية لمدة 7 أيام للحسابات المؤهلة، أو شراء مدى الحياة لمرة واحدة. يعرض App Store السعر المحلي لك.

7. أسئلة

لماذا تظهر خانة الاختيار عندي كنص [ ]؟

المُعرِض لا يرسم قوائم المهام. قوائم المهام امتداد لـ CommonMark، لذا يعرض أي مُعرِض بدونه الأقواس كما هي. تحقق من أن السطر يبدأ بشرطة ومسافة، وأن بين القوسين مسافة أو x بين القوسين، وأن مسافة تلي القوس الأيمن. في Obsidian قد لا تظهر المهمة داخل كتلة برمجية أو خلية جدول كخانة اختيار كما يحدث مع عنصر القائمة.

كيف أُدخل المهام متداخلة؟

أزِح المهمة الفرعية إلى الداخل. في Obsidian اضغط Tab لإزاحة العناصر المحددة إلى الداخل، و Shift+Tab لإلغاء المسافة البادئة. تحوّل الأداة كل مسافتين أو 4 مسافات في قائمتك إلى علامة Tab واحدة لكل مستوى، أو إلى مسافتين أو 4 مسافات إن فضّلت.

كيف أحدد خانة بحرف غير x؟

يذكر Obsidian Help أن أي حرف داخل القوسين يحدد المهمة كمكتملة، لذلك - [-] task و - [?] task منجزة. تحتفظ الأداة بالحرف الذي لصقته ما لم تعد ضبط القائمة. وللملفات التي تُقرأ أيضًا على GitHub، استخدم [x].

كيف أضيف تاريخ استحقاق تقرأه إضافة Tasks؟

ضع 📅 وتاريخًا بصيغة YYYY-MM-DD في نهاية المهمة، على سبيل المثال - [ ] send invoice 📅 2026-11-25. اختر «إضافة Tasks: الاستحقاق» أعلاه لإضافته إلى كل مهمة. واستخدم ⏳ لتاريخ مجدول و 🛫 لتاريخ البدء.

هل ترفع الأداة قائمتي؟

لا. يحوّل نص برمجي في هذه الصفحة القائمة على جهازك، ولا تُجري الصفحة أي طلبات شبكة. ولا تحفظ قائمتك: إغلاق الصفحة أو إعادة تحميلها يمسحها.
