API ข้อมูลสาธารณะ

ค้นพบข้อมูลผลิตภัณฑ์และเอกสาร

API ข้อมูลสาธารณะ Vox.md ให้ข้อมูลผลิตภัณฑ์และลิงก์เอกสารที่เผยแพร่ อ่านฟรี ไม่ต้องมีบัญชี คีย์ API ขั้นตอน OAuth หรือจ่ายเงิน ปลายทางนี้คืนข้อมูลที่มีบนเว็บสาธารณะนี้แล้ว อ่าน สัญญา OpenAPI 3.1 เพื่อดูโครงสร้างคำตอบแบบมีชนิด รหัสการทำงาน ข้อผิดพลาด และคำอธิบาย

รับข้อมูลผลิตภัณฑ์

GET https://vox.isolated.tech/api/v1/product ส่งคืนชื่อผลิตภัณฑ์ คำอธิบาย OS ที่รองรับ หน้า App Store URL เอกสาร และ URL ช่วยเหลือ กระบวนการสร้างดึงข้อมูลเหล่านี้จากข้อมูลมีโครงสร้างของหน้าแรก

curl https://vox.isolated.tech/api/v1/product

ดู JSON ผลิตภัณฑ์

ค้นหาเอกสาร

GET https://vox.isolated.tech/api/v1/documents แสดงชื่อ สรุป และ URL หน้าสาธารณะ ใช้หาคู่มือฟีเจอร์ นโยบาย บทความบล็อก หรือหน้าช่วยเหลือที่เกี่ยวข้องก่อนขอเนื้อหา

curl https://vox.isolated.tech/api/v1/documents

ดู JSON ดัชนีเอกสาร

อ่านหน้าเป็น Markdown

ร้องขอหน้าที่ระบุด้วย Accept: text/markdown สำหรับเนื้อหาหลัก คำขอที่มี Accept: text/html ยังรับ HTML ทั้งสองรูปแบบมี Vary: Accept ส่วน คู่มือเอเจนต์ อธิบายการใช้งานที่เหมาะกับ Vox.md และชี้รายละเอียดฟีเจอร์

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

ข้อผิดพลาด แคช และเมธอด

ปลายทาง JSON รองรับ GET และ HEAD เส้นทาง API ที่ไม่รู้จักจะส่งคืน HTTP 404 พร้อม application/problem+json ค่าคงที่ code คำอธิบาย และคำแนะนำกู้คืน เมธอดที่ไม่รองรับส่งคืน HTTP 405 และ Allow: GET, HEAD คำตอบข้อมูลเมตาสาธารณะอนุญาตการอ่านข้ามต้นทางและระบุอายุแคชห้านาที ไม่เกี่ยวข้องกับข้อมูลรับรองหรือข้อมูลเฉพาะผู้ใช้

ทำแอปที่ติดตั้งให้อัตโนมัติ

การจด ถอดเสียง เข้าคลังในเครื่อง และเขียนโน้ตทำในแอป Apple ที่ติดตั้ง ใช้สิ่งที่อธิบายในเอกสาร การผสาน Shortcuts และรูปแบบ URL โดยได้รับอนุญาตจากเจ้าของอุปกรณ์ API สาธารณะไม่เปิดการจด เสียงบันทึก ข้อความถอดเสียง โน้ตส่วนตัว หรือโฟลเดอร์ปลายทาง ติดต่อ ช่วยเหลือ Vox.md หากมีคำถาม
