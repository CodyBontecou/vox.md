iPhone · แผ่นแชร์ · จดสื่อ

เก็บลิงก์ รูปภาพ และสแกนเข้า Obsidian จาก iPhone

เก็บแหล่งข้อมูลไว้ข้างความคิด ส่งลิงก์ ภาพ หรือสแกนไปปลายทาง Markdown ที่เลือก

โดย
Cody Bontecou
ปรับปรุง
26 ตุลาคม 2026
ต้องใช้
iOS 17.6+ · โฟลเดอร์คลังเขียนได้
คำตอบสั้น ๆ

เชื่อม การจับภาพ Preet ของ Vox.md เข้าคลังที่เขียนได้ เพิ่ม URL รูป ไฟล์ หรือสแกนใน การจับภาพอย่างรวดเร็ว แล้วส่ง ชุดนั้นเลือกโน้ตและตำแหน่งไฟล์แนบ ตรวจ Markdown ที่ส่งและยืนยันไฟล์แนบเปิดใน Obsidian ได้

เก็บลิงก์กับเก็บบทความเป็นคนละงาน Vox.md รับ URL เว็บเป็นลิงก์ Markdown อย่าสมมติว่าเพิ่ม URL แล้วดาวน์โหลดหรือดึงทั้งหน้า เลือกวิธีจดตามสิ่งที่ต้องการเก็บ

ในคู่มือนี้
  1. เตรียมปลายทางคลัง
  2. เก็บลิงก์เว็บ
  3. เพิ่มรูปภาพ ภาพหน้าจอ หรือไฟล์
  4. สแกนเอกสารและตรวจ OCR
  5. ตรวจไฟล์แนบและซิงค์

1. เตรียมปลายทางคลัง

ใน การตั้งค่า → ค่าจับภาพที่ตั้งไว้ สร้างหรือเลือกชุดที่เปิดใช้และเชื่อมปลายทางผ่าน Files เลือกโฟลเดอร์ไฟล์ Markdown ของคลัง หากโฟลเดอร์ไม่เปิดให้แอปอื่น Vox.md เขียนไม่ได้เพียงเพราะมองเห็นใน Obsidian

ตัวอย่างแรกให้เลือก หมายเหตุใหม่ และ เก็บต้นฉบับ โฟลเดอร์กล่องรับเข้าแยกทำให้หาข้อมูลผสมง่าย ภายหลังเลือก หมายเหตุโรล หรือ หมายเหตุที่มีอยู่ เมื่อต้องการเพิ่มลงไฟล์เดิม

กำหนดโฟลเดอร์ย่อยของไฟล์แนบในการตั้งค่าปลายทาง ค่าเริ่มต้นคือ attachments ตรวจเส้นทางโน้ตที่คำนวณและกฎไฟล์แนบก่อนส่ง สำหรับสมุดรายวัน ทำตาม คู่มือเส้นทางโน้ตรายวัน.

2. เก็บลิงก์เว็บ

คัดลอก URL ที่ต้องการเก็บ ใน การจับภาพอย่างรวดเร็ว ใช้ตัวควบคุมลิงก์เว็บและตรวจข้อความกับที่อยู่ลิงก์ เพิ่มคำอธิบายสั้นว่าทำไมเก็บ แล้วส่ง

โน้ตธรรมดาอาจมี Markdown ตัวอย่างดังนี้:

Read before planning the trip:
[Trail information](https://example.com/trail)

ที่อยู่ข้างต้นเป็นตัวอย่าง ไม่ใช่คำแนะนำแหล่งข้อมูล แทนด้วยหน้าจริง ลิงก์ให้ทางกลับต้นทาง ไม่รักษาเนื้อหาต้นทางหากเว็บเปลี่ยนหรือหายไป

แผ่นแชร์ Vox.md รับเนื้อหาที่รองรับจากแอปอื่นด้วย แอปอาจแชร์ URL ข้อความ หรือไฟล์ ตรวจสิ่งที่รับและค่าที่ตั้งไว้ แทนสมมติว่ารวมทุกอย่างที่เห็นบนหน้าจอต้นทาง

3. เพิ่มรูปภาพ ภาพหน้าจอ หรือไฟล์

  1. เลือกค่าที่ตั้งไว้สำหรับกล่องรับเข้าหรือโน้ตโครงการ
  2. ใช้ตัวเลือกรูปหรือภาพหน้าจอ กล้อง หรือเพิ่มไฟล์เพื่อเลือกสื่อ
  3. เพิ่มชื่อหรือคำอธิบายสั้นในตัวเขียน
  4. ส่ง แล้วเปิดโน้ตใน Obsidian ตรวจภาพฝังหรือลิงก์ไฟล์

ภาพฝังในผล Markdown ไฟล์ชนิดอื่นใช้ลิงก์ เช่น โน้ตอ้างเส้นทางไฟล์แนบที่ตั้งได้ดังนี้:

4. สแกนเอกสารและตรวจ OCR

เลือกสแกนเอกสารในแถบจดแล้วทำตามตัวสแกน Vox.md เก็บภาพหน้า สร้าง PDF และรู้จำข้อความบนอุปกรณ์ตามความสามารถ ตรวจคำก่อนส่ง โดยเฉพาะชื่อ วัน จำนวน และลายมือ

สำหรับรูปสมุด ขั้นตอนดึงข้อความแยกรองรับหน้าที่ถ่ายหรือเลือกเอง OCR อาจพลาดโครงสร้างหรืออ่านคำผิดแม้ภาพชัด เก็บภาพหรือสแกนต้นทางเมื่อต้องตรวจข้อความภายหลัง

เลือก เก็บต้นฉบับ หากไม่ต้องการให้การประมวลผลเสริมเขียนข้อความใหม่ การประมวลผลข้อความพิมพ์กับผสมต้องเลือกเปิดแยกในค่าที่ตั้งไว้ ส่วน อ้างอิงการจด อธิบายข้อมูลนำเข้าที่รองรับและ ขีดจำกัดข้อมูลนำเข้า.

ตรวจไฟล์แนบและซิงค์

หลังส่ง เปิดโน้ตใน Obsidian ตามแต่ละลิงก์และยืนยันไฟล์ที่ต้องการ โน้ตปรากฏบนอุปกรณ์อื่นไม่ได้พิสูจน์ว่าทุกไฟล์แนบซิงค์เสร็จ ตรวจภาพหรือ PDF บนอุปกรณ์นั้นด้วย

การเขียนล้มเหลวอาจค้างใน Vox.md แก้สิทธิ์ปลายทางและลองรายการเดิมใหม่ก่อนสร้างสำเนาอื่น ไฟล์กับผู้ให้บริการคลาวด์อาจต้องเชื่อมต่อเพื่อเข้าถึงหรือซิงค์ แม้การประมวลผลสิ่งที่จดเองอยู่ในเครื่อง

หากต้องการดึงเนื้อหาทั้งหน้าเว็บ ให้เปรียบเทียบเครื่องมือที่เกี่ยวข้องโดยตรง Obsidian อธิบายตัวเลือกแชร์ในตัวไว้ใน คู่มือ iOS ทางการ ใช้การแชร์ในตัวกับงานหนึ่งและค่าที่ตั้งไว้ Vox.md กับอีกงานได้
