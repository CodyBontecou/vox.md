ปลั๊กอิน Core Templates: บันทึกไฟล์ไว้ในโฟลเดอร์เทมเพลตแล้วแทรกด้วย Templates: Insert template. {{title}} จะกลายเป็นชื่อโน้ต และวันที่ใช้รูปแบบ Moment.js ในวงเล็บปีกกา

ปลั๊กอิน Templater: บันทึกไฟล์ไว้ในโฟลเดอร์เทมเพลตของ Templater แล้วแทรกด้วย Templater: Open insert template modal หรือใช้เป็นเทมเพลตโฟลเดอร์ ปลั๊กอิน Templates หลักไม่รัน <% %> ซึ่งเป็นคำสั่งของ Templater

Markdown ธรรมดา: หัวข้อและฟิลด์ที่มีโทเค็นของ Vox.md ในวงเล็บปีกกาเดี่ยว Obsidian จะคงโทเค็นเหล่านี้ไว้ตามที่พิมพ์ Vox.md จะเติมค่าเมื่อเส้นทางใช้ไฟล์นี้เป็นเทมเพลตคลัง ดู เติมโน้ตจากเสียงบันทึก.

หัวข้อและชื่อพร็อพเพอร์ตี้เป็นภาษาอังกฤษเพื่อให้ตรงกับตัวอย่างในหน้านี้ เปลี่ยนชื่อได้หลังจากวาง

2. เพิ่มเทมเพลตลงใน Obsidian

ปลั๊กอิน Core Templates เปิด Templates ใน Settings → Core plugins แล้วตั้งค่า Template folder locationเช่น Templates บันทึกเทมเพลตไว้ที่นั่นเป็นไฟล์ .md ในโน้ตใหม่ ให้รัน Templates: Insert template จากแถบคำสั่งแล้วเลือกเทมเพลตนี้ Obsidian จะแทนค่า {{title}}, {{date}} และ {{time}} เมื่อคุณแทรกเทมเพลต รูปแบบที่อยู่หลังเครื่องหมายทวิภาค เช่น {{date:YYYY-MM-DD}}ใช้โทเค็นของ Moment.js ดู วิธีใช้ปลั๊กอิน Templates และ โทเค็นรูปแบบของ Moment.js.

ปลั๊กอิน Templater ติดตั้ง Templater จาก Community plugins แล้วตั้งค่า Template folder location แทรกเทมเพลตด้วย Templater: Open insert template modal หากต้องการให้โน้ตใหม่ทุกโน้ตใน Meetings/ ใช้เทมเพลตนี้ ให้เปิด Trigger Templater on new file creationตั้งค่า Template matching mode เป็นเทมเพลตโฟลเดอร์ แล้วจับคู่โฟลเดอร์ Meetings เข้ากับไฟล์นั้น เอกสารการตั้งค่า Templater อธิบายเทมเพลตโฟลเดอร์ และ โมดูลวันที่ อธิบาย tp.date.now.

พร็อพเพอร์ตี้ frontmatter ระหว่างบรรทัด --- จะกลายเป็นพร็อพเพอร์ตี้ของโน้ต ลิงก์ในพร็อพเพอร์ตี้ต้องอยู่ในเครื่องหมายคำพูด ฟิลด์โปรเจกต์จึงเขียนเป็น "[[Project name]]" ดู พร็อพเพอร์ตี้ ในวิธีใช้ Obsidian

3. หนึ่งโน้ตต่อหนึ่งการประชุม

เก็บการประชุมไว้ในโฟลเดอร์เดียว เช่น Meetings/และใส่วันที่กับเวลาเริ่มไว้ในชื่อไฟล์: Meetings/2026-11-19 1430 Design review.md ชื่อตามลำดับนี้เรียงตามวันที่ และการประชุมสองครั้งในวันเดียวกันจะไม่ใช้ไฟล์ร่วมกัน

เปิด ลิงก์ไปยังโน้ตรายวัน ในตัวสร้างเพื่อเพิ่มบรรทัด Daily note: ที่ลิงก์ไปยังโน้ตของวันนั้น ลิงก์ใช้รูปแบบ YYYY-MM-DD; หากบันทึกประจำวันของคุณใช้รูปแบบวันที่อื่น ให้เปลี่ยนให้ตรงกัน เครื่องมือสร้างเทมเพลตบันทึกประจำวัน แสดงตัวอย่างชื่อไฟล์ที่รูปแบบสร้างขึ้น หากต้องการแสดงรายการประชุมของวันในบันทึกประจำวันด้วย ให้ลิงก์จากที่นั่น; ต่อท้ายลงโน้ตรายวัน Obsidian แสดงวิธีที่ Vox.md เพิ่มรายการลงในโน้ตนั้น

4. รายการงานที่ต้องทำและการติดตามผล

เขียนรายการงานที่ต้องทำแต่ละข้อเป็นงานของ Obsidian - [ ] Send the release notesและทำเครื่องหมายเป็น - [x] เมื่อทำเสร็จ ดู ไวยากรณ์การจัดรูปแบบพื้นฐาน ใส่ชื่อผู้รับผิดชอบไว้ก่อน เพื่อให้แต่ละบรรทัดอ่านได้ว่าใครทำอะไร

รูปแบบเสริมจะเพิ่มวันครบกำหนดตามรูปแบบของปลั๊กอินชุมชนอย่าง ปลั๊กอิน Tasks: 📅 ตามด้วย YYYY-MM-DD ตัวสร้างจะใส่วันที่ประชุมให้ ให้เปลี่ยนเป็นวันครบกำหนดจริง หากไม่มีปลั๊กอิน Tasks อีโมจิและวันที่จะเป็นข้อความธรรมดา และงานยังใช้ได้ตามปกติ

หากต้องการรวมงานที่ค้างจากทุกการประชุมไว้ที่เดียว ให้เพิ่มคิวรี Tasks ลงในโน้ต:

```tasks
not done
path includes Meetings
```

คิวรีนี้แสดงงานที่ยังไม่เสร็จจากโน้ตที่พาธมีคำว่า Meetings หากใช้ Dataview อยู่แล้ว ก็สร้างรายการแบบเดียวกันได้

5. เติมโน้ตจากเสียงบันทึก

เทมเพลตให้หัวข้อแก่คุณ ส่วน Vox.md เขียนโน้ตให้ได้เลย โดยบันทึกเสียงการประชุม ถอดเสียงบนอุปกรณ์ของคุณ และบันทึกไฟล์ Markdown ลงในคลังผ่านเส้นทาง

  1. บันทึกเสียง บน Mac นั้น Vox.md บันทึกเสียงแอปโทรหนึ่งแอปและไมโครโฟนของคุณเป็นแทร็กแยกกันได้ ทำตาม ถอดเสียงการประชุมบน Mac ภายในเครื่องลง Obsidian สำหรับการประชุมในห้อง ให้บันทึกเสียงด้วยไมโครโฟนของ iPhone หรือ iPad ดู เก็บโน้ตเสียง iPhone ไป Obsidian.
  2. เลือกปลายทาง ในเส้นทาง ให้เลือกคลังของคุณ เลือก หมายเหตุใหม่แล้วป้อนพาธ เช่น Meetings/{date}-{hour}{minute}.md. {date} จะเขียนเป็น 2026-11-19 และ {hour}{minute} เป็น 1430 นี่คือโทเค็นของ Vox.md ไม่ใช่รูปแบบ Moment.js ดู เทมเพลตการจดบันทึก Obsidian สำหรับสูตรพาธเพิ่มเติม
  3. เลือกโหมด ตั้งโหมดประมวลผลของเส้นทางเป็น บันทึกการประชุม โหมดนี้สร้างส่วน ## Notes และเมื่อบทถอดเสียงมีรายการงานที่ต้องทำ จะสร้างรายการตรวจสอบ ## Action Items ฟีเจอร์นี้ใช้ Apple Intelligence บนฮาร์ดแวร์ที่รองรับซึ่งใช้ macOS 26 หรือ iOS 26 มิฉะนั้นตัวจัดรูปแบบแบบกำหนดแน่นอนจะสร้างโครงสร้างให้

บันทึกการประชุมไม่ได้เติมวาระ ผู้เข้าร่วม หรือข้อตัดสินใจให้ หากต้องการหัวข้อเหล่านั้นไว้เหนือโน้ต ให้เลือก Markdown ธรรมดา ในตัวสร้าง เอาเครื่องหมายออกจากโน้ตและรายการงานที่ต้องทำ แล้วบันทึกผลลัพธ์ไว้ในคลัง จากนั้นเลือกไฟล์นั้นเป็นเทมเพลตคลังของเส้นทาง Vox.md จะเติมโทเค็นวงเล็บปีกกาเดี่ยวของตนในเทมเพลตและเขียนบทถอดเสียงที่ประมวลผลแล้วไว้ด้านล่าง ตรวจโน้ตแรกก่อนจะเชื่อถือเลย์เอาต์นี้ เอกสารเรื่องเส้นทาง อธิบายเรื่องปลายทางและเทมเพลต

แจ้งทุกคนในการประชุมว่าคุณกำลังบันทึกเสียงและถอดเสียง และขอความยินยอมก่อน กฎแตกต่างกันไปตามสถานที่และที่ทำงาน ดู แจ้งผู้อื่นว่าคุณกำลังบันทึกเสียง.

6. คำถาม

ควรใช้ Core Templates หรือ Templater?

Core Templates มาพร้อม Obsidian และรองรับชื่อเรื่อง วันที่ และเวลา Templater เป็นปลั๊กอินชุมชนที่เพิ่มการเขียนสคริปต์ การเลื่อนวันที่ และเทมเพลตโฟลเดอร์ ทำให้โน้ตใหม่ใน Meetings/ ได้รับเทมเพลตโดยอัตโนมัติ ถ้าต้องการแค่ฟิลด์ในหน้านี้ Core Templates ก็เพียงพอ

ทำไม {{date}} ถึงไม่เปลี่ยนในภายหลัง?

Obsidian แทนค่าตัวแปรเทมเพลตเพียงครั้งเดียวเมื่อคุณแทรกเทมเพลต จากนั้นโน้ตจะเก็บเป็นข้อความธรรมดา เช่น 2026-11-19และคงไว้อย่างนั้น ซึ่งเป็นสิ่งที่ต้องการสำหรับบันทึกการประชุม

Vox.md ใช้เทมเพลต Obsidian ของฉันได้ไหม?

ได้บางส่วน เส้นทางสามารถใช้ไฟล์ Markdown จากคลังเป็นเทมเพลตได้ Vox.md เติมโทเค็นวงเล็บปีกกาเดี่ยวของตนเอง เช่น {date}และคำสั่งวันที่ของ Templater tp.date.now และ tp.file.creation_date แต่ไม่รันคำสั่ง Templater อื่น เช่น tp.file.titleและไม่แทนค่าตัวแปรของ Templates หลัก เช่น {{title}}ดังนั้นอย่าใส่สิ่งเหล่านี้ในเทมเพลตของเส้นทาง ใช้เอาต์พุต Markdown ธรรมดาสำหรับเส้นทางของ Vox.md

ตัวสร้างส่งตัวเลือกของฉันไปที่ไหนหรือไม่?

ไม่ เทมเพลตสร้างโดยสคริปต์ในหน้านี้ ซึ่งบันทึกตัวเลือกล่าสุดไว้ในพื้นที่เก็บข้อมูลภายในเบราว์เซอร์ เพื่อให้ยังอยู่ในครั้งหน้า และปุ่มรีเซ็ตจะล้างค่าเหล่านั้น

ไม่ต้องพิมพ์เอง

บันทึกเสียงการประชุม แล้วให้ Vox.md เขียนโน้ตลงในคลังของคุณ
