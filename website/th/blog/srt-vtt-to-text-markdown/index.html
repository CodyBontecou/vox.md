ตัวแปลง SRT และ VTT เป็นข้อความหรือ Markdown

วางหรือเปิดไฟล์คำบรรยายจาก Zoom, Microsoft Teams, YouTube หรือบริการถอดเสียง แล้วรับข้อความที่อ่านง่าย ทรานสคริปต์ Markdown หรือรูปแบบคำบรรยายอีกแบบ ไฟล์จะถูกอ่านบนอุปกรณ์ของคุณและไม่เคยถูกอัปโหลด

Cody Bontecou

23 พฤศจิกายน 2026

วางหรือเปิดไฟล์ .srt หรือ .vtt เลือกข้อความล้วนหรือ Markdown แล้วคัดลอกหรือดาวน์โหลด ไฟล์จะอยู่บนอุปกรณ์ของคุณ

ตัวแปลงจะลบหมายเลขคิวและไทม์โค้ด รวมบรรทัดเป็นย่อหน้า และเปลี่ยนชื่อผู้พูดเป็นตาพูดตัวหนาสำหรับโน้ต นอกจากนี้ยังแปลง SRT เป็น VTT และ VTT เป็น SRT ด้วย โดยอ่านไฟล์ด้วย FileReader API ของเบราว์เซอร์ และหน้านี้ไม่ส่งคำขอเครือข่าย ดังนั้นสิ่งที่คุณวางหรือเปิดจะไม่ถูกส่งไปที่ใด

1. ใช้ตัวแปลง

  1. เพิ่มไฟล์ วางเนื้อหาลงในกล่อง หรือเลือก .srt, .vtt หรือ .txt ไฟล์ เครื่องมือจะตรวจจับรูปแบบและแสดงจำนวนคิว
  2. เลือกเอาต์พุต ข้อความล้วน, Markdown, SRT หรือ VTT
  3. ปรับตัวเลือกการล้างข้อมูล รวมบรรทัดเป็นย่อหน้า เริ่มย่อหน้าใหม่หลังหยุดพัก ลบบรรทัดเลื่อนที่ซ้ำ ลบแท็ก และเก็บหรือทิ้งสัญญาณเสียง เช่น [Music].
  4. คัดลอกหรือดาวน์โหลด การดาวน์โหลดใช้นามสกุลที่ถูกต้อง: .txt, .md, .srt หรือ .vtt.

ตัวแปลงต้องใช้ JavaScript หากไม่มี คำอธิบายด้านล่างยังใช้เป็นข้อมูลอ้างอิงได้

ผลลัพธ์

ไฟล์ SRT ไฟล์ WebVTT ตรวจพบ {format} จำนวน {count} คิว ตรวจพบ {format} จำนวน 1 คิว วางไฟล์คำบรรยายหรือเปิดไฟล์เพื่อดูผลลัพธ์ ไม่พบคิว คิวมีบรรทัดเวลา เช่น 00:00:01,000 --> 00:00:04,000 (SRT) หรือ 00:00:01.000 --> 00:00:04.000 (VTT) นี่ไม่เหมือนไฟล์ SRT หรือ VTT อ่านไฟล์นั้นไม่ได้ ลองวางข้อความของไฟล์แทน ตัวเลือกการล้างข้อมูลลบทุกคิวออกหมดแล้ว ปิดหนึ่งตัวเลือกเพื่อดูข้อความ คัดลอกไปยังคลิปบอร์ดแล้ว คัดลอกไม่สำเร็จ เลือกข้อความแล้วคัดลอกเอง ดาวน์โหลด {name} แล้ว โหลดตัวอย่างแล้ว ล้างแล้ว ข้อความล้วน Markdown คำบรรยาย SRT คำบรรยาย VTT

Vox.md ถอดเสียงบน iPhone หรือ Mac ของคุณ และบันทึก Markdown ลงใน Obsidian ไม่ต้องอัปโหลด ไม่มีไฟล์คำบรรยาย

ตัวแปลงด้านบนใช้งานได้เต็มรูปแบบโดยไม่ต้องมีแอป

2. SRT กับ VTT: คืออะไรและต่างกันอย่างไร

ทั้งสองเป็นรูปแบบคำบรรยายแบบข้อความล้วน คือรายการคิว แต่ละคิวมีเวลาเริ่ม เวลาสิ้นสุด และข้อความ หอสมุดรัฐสภาอธิบาย รูปแบบ SubRip (SRT) เป็นรูปแบบข้อความแบบง่ายที่แต่ละคำบรรยายมีหมายเลขลำดับ เวลาเริ่มและสิ้นสุดคั่นด้วย --> ข้อความหนึ่งบรรทัดขึ้นไป และบรรทัดว่าง รหัสเวลาของมันคือ hours:minutes:seconds,milliseconds. ข้อมูลจำเพาะของ W3C ข้อมูลจำเพาะ WebVTT กำหนดรูปแบบใหม่ที่เบราว์เซอร์ใช้สำหรับคำบรรยาย

.srt.vtt
บรรทัดแรกหมายเลขของคิวแรกWEBVTT
ตัวคั่นมิลลิวินาทีจุลภาค: 00:00:01,000จุด: 00:00:01.000
ชั่วโมงเขียนเสมอไม่บังคับ: 00:01.000 ได้
หมายเลขคิวหมายเลขลำดับสำหรับทุกคิวตัวระบุ (ไม่บังคับ)
การตั้งค่าคิวไม่มีตำแหน่งและการจัดแนวอาจตามหลังไทม์สแตมป์ เช่น align:start
ผู้พูดไม่มีเครื่องหมายมาตรฐาน ผู้คนเขียน Name:แท็กเสียง: <v Name>text</v>
ความคิดเห็นไม่มีNOTE, STYLE และ REGION บล็อก

สิ่งที่ตัวแปลงทำเมื่อเปลี่ยนรูปแบบ:

  • SRT เป็น VTT: เพิ่ม WEBVTT ส่วนหัว และเปลี่ยนจุลภาคทุกตัวในไทม์สแตมป์เป็นจุด
  • VTT เป็น SRT: ลบส่วนหัว NOTE, STYLE และ REGION บล็อกและการตั้งค่าคิว เปลี่ยนจุดเป็นจุลภาค และเรียงหมายเลขคิวใหม่ตั้งแต่ 1 SRT ไม่มี voice span ดังนั้น <v Name>text</v> กลายเป็น Name: text.
  • การเข้ารหัสข้อความ: หอสมุดรัฐสภาระบุว่า SRT ไม่มีมาตรฐานการเข้ารหัสอักขระ และตัวแยกวิเคราะห์ต้องตรวจจับเอง ตัวแปลงอ่านไฟล์เป็น UTF-8 หากตัวอักษรที่มีเครื่องหมายแสดงผิด ให้เปิดไฟล์ในโปรแกรมแก้ไขข้อความและบันทึกเป็น UTF-8 ก่อน

3. หาไฟล์ได้จากที่ไหน: Zoom, Teams และ YouTube

โปรดตรวจสอบหน้าของแต่ละผู้ให้บริการสำหรับแพ็กเกจและการตั้งค่าของคุณ เพราะผู้ดูแลระบบและประเภทบัญชีมีผลต่อสิ่งที่ดาวน์โหลดได้

การบันทึกบนคลาวด์ของ Zoom

บทความสนับสนุนของ Zoom เรื่องการถอดเสียงสำหรับการบันทึกบนคลาวด์ ระบุว่าเมื่อประมวลผลทรานสคริปต์เสร็จแล้ว จะปรากฏเป็นไฟล์ VTT แยกต่างหากพร้อมกับการบันทึก ซึ่งใช้กับการบันทึกบนคลาวด์ และต้องเปิดการถอดเสียงสำหรับการบันทึกเหล่านั้นไว้ รูปแบบไฟล์ที่การบันทึกสร้างได้มีรายการอยู่ใน คู่มือของ Zoom เกี่ยวกับรูปแบบไฟล์การบันทึก.

ทรานสคริปต์ Microsoft Teams

บทความสนับสนุนของ Microsoft เรื่องการดาวน์โหลดทรานสคริปต์ Teams ระบุว่า โดยค่าเริ่มต้น ผู้จัดและผู้ร่วมจัดสามารถดาวน์โหลดทรานสคริปต์เป็น .docx หรือ .vtt ไฟล์ และนโยบายของผู้ดูแลระบบไอทีอาจเปลี่ยนว่าใครดาวน์โหลดได้ เลือก .vtt แล้วเปิดที่นี่ หากต้องการแก้ไขข้อผิดพลาดก่อนแปลง ดู คู่มือของ Microsoft เรื่องการแก้ไขทรานสคริปต์ Teams.

คำบรรยาย YouTube

หน้า YouTube Help เรื่องการแก้ไขและลบคำบรรยาย อธิบายวิธีดาวน์โหลดแทร็กคำบรรยายจาก YouTube Studio สำหรับวิดีโอในช่องของคุณเอง แต่ไม่ได้ระบุรูปแบบไฟล์ที่ดาวน์โหลด ดังนั้นให้วางหรือเปิดไฟล์แล้วให้ตัวแปลงตรวจหารูปแบบเอง ส่วนของ YouTube รายการประเภทไฟล์คำบรรยายที่รองรับ รองรับ SubRip (.srt) และ WebVTT (.vtt)

ดาวน์โหลดเฉพาะคำบรรยายที่คุณมีสิทธิ์ใช้ หน้านี้ไม่ครอบคลุมวิดีโอของผู้อื่น

4. นำทรานสคริปต์ไปไว้ในโน้ต Obsidian

  1. เลือก Markdown ชื่อผู้พูดจะกลายเป็น **Name:** และคิวที่ต่อกันของผู้พูดคนเดียวกันจะรวมเป็นตาพูดเดียว เปิด เพิ่มเวลา [mm:ss] หากต้องการหาตำแหน่งในการบันทึกภายหลัง
  2. เปิดคุณสมบัติ Obsidian เพื่อเพิ่มบล็อกที่ด้านบนพร้อมกับ title, date, source และ tags เป็น YAML ที่ถูกต้อง เขียนตามแบบที่ ตัวสร้างคุณสมบัติ เขียนไว้ Obsidian อ่านบรรทัดระหว่าง --- ที่ด้านบนสุดของโน้ตเป็นคุณสมบัติ ดู หน้าวิธีใช้ของ Obsidian เกี่ยวกับพร็อพเพอร์ตี.
  3. วางลงในโน้ตใหม่ ใน vault ของคุณ เช่นใน Meetings โฟลเดอร์ หากคุณดาวน์โหลด .md ไฟล์แทน ให้ย้ายไปไว้ในโฟลเดอร์ vault
  4. ลิงก์ไปยังโน้ตการประชุม สร้างโน้ตด้วย ตัวสร้างเทมเพลตบันทึกการประชุม แล้วเพิ่มบรรทัดอย่าง Transcript: [[Team sync transcript]] ไปยังโน้ตนั้น หากคุณลิงก์จากคุณสมบัติ ลิงก์ต้องอยู่ในเครื่องหมายคำพูด: transcript: "[[Team sync transcript]]".

ข้อความจะถูก escape เพื่อไม่ให้อักขระอย่าง *, $ และ # ไม่กลายเป็นการจัดรูปแบบ สูตรคณิตศาสตร์ หรือแท็กใน Obsidian ชื่อผู้พูดมาจากไฟล์ ดังนั้นโปรดตรวจสอบก่อนแชร์โน้ต

5. เริ่มจากเสียงแทนไฟล์คำบรรยาย

หากคุณมีแค่การบันทึก ก็ไม่ต้องมีไฟล์คำบรรยายเลย Vox.md ถอดเสียงบนอุปกรณ์และเขียน Markdown ลงใน vault ของคุณโดยตรง ตาม เอกสารเกี่ยวกับโมเดล การถอดเสียงทำงานบนอุปกรณ์ Apple ด้วย Apple Speech บนอุปกรณ์ iOS 26 และภาษาที่รองรับ หรือด้วยโมเดล Whisper หรือ Parakeet ที่คุณดาวน์โหลดเพิ่มเอง ดู Whisper เทียบกับ Parakeet เพื่อดูความแตกต่าง ป้ายชื่อผู้พูดเป็นขั้นตอน Route ที่เลือกเปิดได้ ชื่อว่า การระบุผู้พูด และเป็นแบบไม่ระบุตัวตนและทำเต็มที่เท่าที่ทำได้

  • ถอดเสียงไฟล์เสียงบน Mac ในเครื่อง เป็น Markdown
  • ถอดเสียงการประชุมบน Mac ภายในเครื่องลง Obsidian

เอกสารของ Vox.md ไม่ได้อธิบายการนำเข้าหรือส่งออกไฟล์ SRT หรือ VTT ดังนั้นตัวแปลงนี้จึงเป็นเครื่องมือแยกต่างหากและใช้งานได้โดยไม่ต้องมีแอป

เพื่อตรวจว่าผู้พูดพูดเร็วแค่ไหน ให้แปลงคำบรรยายเป็นข้อความธรรมดาที่นี่ แล้ววางข้อความและความยาวของวิดีโอลงใน เครื่องคำนวณเวลาพูด ซึ่งหารคำด้วยนาทีเพื่อให้ได้คำต่อนาที

6. คำถาม

อัปโหลดไฟล์ของฉันไหม

ไม่ ไฟล์ที่คุณเปิดจะถูกอ่านในเบราว์เซอร์ด้วย FileReader API และข้อความที่วางจะอยู่ในกล่องข้อความ การแปลงเป็นสคริปต์ในหน้านี้ และหน้านี้ไม่ส่งคำขอเครือข่ายใดๆ ขณะที่คุณใช้งาน เมื่อคุณปิดหรือโหลดหน้าซ้ำ ข้อความจะหายไป

ทำไมบรรทัดจึงซ้ำ

คำบรรยายอัตโนมัติมักเลื่อน: คิวใหม่แต่ละคิวจะทวนบรรทัดก่อนหน้าแล้วเพิ่มบรรทัดใหม่ ทำให้คำเดียวกันปรากฏสองหรือสามครั้ง เปิด ลบบรรทัดเลื่อนที่ซ้ำกัน ตัวเลือกนี้ลบบรรทัดที่เหมือนกับบรรทัดในคิวก่อนหน้า หากผู้พูดพูดบรรทัดเดิมซ้ำสองครั้งติดกันจริงๆ การซ้ำนั้นจะถูกลบด้วย ดังนั้นควรปิดตัวเลือกนี้สำหรับคำบรรยายที่มนุษย์ทำไว้อย่างสะอาด

เก็บไทม์สแตมป์ไว้ได้ไหม

ได้ เมื่อใช้ข้อความล้วนหรือ Markdown ให้เปิดตัวเลือกไทม์สแตมป์ แล้วแต่ละย่อหน้าจะขึ้นต้นด้วยเวลาของคิวแรกในรูปแบบ [mm:ss] หรือ [h:mm:ss] หลังจากหนึ่งชั่วโมง หากต้องการเวลาของทุกคิว ให้แปลงเป็น SRT หรือ VTT แทน

จะแปลงข้อความกลับเป็น SRT ได้อย่างไร

เครื่องมือนี้ทำไม่ได้ ข้อความล้วนไม่มีเวลา ดังนั้น SRT ต้องใช้เครื่องมือที่จัดข้อความให้ตรงกับเสียง การแปลงระหว่าง SRT และ VTT คงเวลาไว้ เพราะทั้งสองรูปแบบมีเวลาอยู่แล้ว

ใช้บน iPhone ได้ไหม

ได้ ใช้ตัวควบคุมฟอร์มทั่วไปและตัวเลือกไฟล์ของเบราว์เซอร์ และเขียนมาให้ใช้งานได้ใน Safari บน iPhone การคัดลอกใช้คลิปบอร์ดเมื่อ Safari อนุญาต มิฉะนั้นจะขอให้คุณเลือกข้อความ
