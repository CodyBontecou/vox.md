เครื่องมือฟรี

ตัวสร้าง callout ของ Obsidian: ทุกชนิด ชื่อแทน และตัวเลือกการพับ

เลือกชนิด ใส่หัวข้อและเนื้อความ เลือกการพับและการซ้อน แล้วคัดลอก callout > [!type] ที่ถูกต้อง พร้อมรายการชนิดและชื่อแทนทั้งหมด และวิธีทำงานของ callout แบบพับได้

callout คือบล็อกคำพูดที่บรรทัดแรกเป็น > [!type] Optional title. ทุกบรรทัดถัดไปขึ้นต้นด้วย > . เพิ่ม + หรือ - ต่อท้ายวงเล็บทันทีเพื่อให้พับได้ หากต้องการสร้างโดยไม่ต้องพิมพ์คำนำหน้า ให้ใช้ ตัวสร้าง callout ด้านล่าง

> [!warning]- Back up first
> Copy the vault before you change the plugin settings.
>
> Then restart Obsidian.

ตัวสร้างจะเติม > คำนำหน้าทุกบรรทัด (ซ้ำตามระดับการซ้อน) คงบรรทัดว่างไว้ใน callout และไม่ซ้ำ > ที่คุณวางไว้ ทั้งหมดทำงานในหน้านี้: ข้อความของคุณไม่ถูกอัปโหลด และหน้านี้ไม่ส่งคำขอเครือข่ายใด ๆ

1. สร้าง callout ของคุณ

ตัวสร้าง callout ต้องใช้ JavaScript หากไม่มี ไวยากรณ์และตารางชนิดด้านล่างยังใช้เป็นข้อมูลอ้างอิงได้

ชนิด

เนื้อหา

การพับ
เลย์เอาต์

บรรทัดว่างจริง ๆ จะจบ callout ดังนั้นบรรทัดว่างที่คงไว้จะเขียนเป็น > ปิดตัวเลือกนี้เพื่อตัดบรรทัดว่างออกแทน

callout ของคุณ

วางสิ่งนี้ไว้ในเนื้อความของ callout ชั้นนอกที่คุณจะซ้อนลงไป

ตัวอย่าง (โดยประมาณ)

ตัวอย่างนี้เป็นการประมาณ สี ไอคอน และระยะห่างจริงขึ้นอยู่กับธีมของคุณ

แกลเลอรีชนิด

เลือกชนิดเพื่อโหลดไว้ด้านบน

คัดลอกไปยังคลิปบอร์ดแล้ว คัดลอกไม่สำเร็จ เลือกข้อความแล้วคัดลอกเอง โหลดตัวอย่างแล้ว ล้างแล้ว หัวข้อเริ่มต้นเมื่อว่าง: {title} นี่ไม่ใช่ชนิดที่มีมาในตัว Obsidian จะแสดงด้วยสไตล์ของ note เว้นแต่จะมี CSS snippet กำหนดไว้ โหลดชนิดแล้ว

2. ไวยากรณ์ของ callout

> [!type] Title
> Body line one.
> Body line two.
  • ชนิด บรรทัดแรกของบล็อกคำพูดขึ้นต้นด้วยชนิดในวงเล็บหลังเครื่องหมายอัศเจรีย์: > [!info]. ความช่วยเหลือของ Obsidian ระบุว่าตัวระบุชนิดไม่สนใจตัวพิมพ์ใหญ่เล็ก และชนิดที่ไม่รองรับจะถอยกลับไปใช้ note.
  • หัวข้อ ข้อความหลังวงเล็บจะแทนที่หัวข้อ หากไม่มี Obsidian จะแสดงตัวระบุชนิดในรูปแบบตัวพิมพ์ใหญ่ต้นคำ ดังนั้น > [!tip] จะแสดงเป็น “Tip”
  • เนื้อความ ทุกบรรทัดถัดไปขึ้นต้นด้วย > . เนื้อความใส่ Markdown, wikilink และการฝังได้
  • หัวข้ออย่างเดียว คุณเว้นเนื้อความไว้ได้: > [!tip] Remember to save เป็น callout ที่สมบูรณ์

3. ชนิดของ callout และชื่อแทนทั้งหมด

วิธีใช้ของ Obsidian แสดงชนิดที่มีมาในตัวเหล่านี้ ชื่อแทนแต่ละชื่อจะอยู่คู่กับชนิดที่มันเป็นของ เช่น tldr กับ abstract.

ชนิดชื่อแทนการใช้งานทั่วไป
noteไม่มีหมายเหตุทั่วไป และเป็นสไตล์ที่ชนิดที่ไม่รู้จักถอยกลับไปใช้
abstractsummary, tldrบทสรุปที่ด้านบนของโน้ต
infoไม่มีข้อมูลเบื้องหลัง
todoไม่มีสิ่งที่ยังต้องทำ
tiphint, importantคำแนะนำหรือประเด็นสำคัญ
successcheck, doneขั้นตอนที่เสร็จแล้วหรือผลลัพธ์ที่ดี
questionhelp, faqคำถามปลายเปิดหรือคำถามที่พบบ่อย
warningcaution, attentionสิ่งที่ต้องระวัง
failurefail, missingอะไรผิดพลาดหรือขาดหายไป
dangererrorความเสี่ยงร้ายแรงหรือข้อความแสดงข้อผิดพลาด
bugไม่มีบั๊กที่ทราบแล้ว
exampleไม่มีตัวอย่างที่ใช้งานจริง
quoteciteคำพูดอ้างอิงพร้อมแหล่งที่มา

ชนิดและชื่อแทนมาจากวิธีใช้ของ Obsidian คอลัมน์ “การใช้งานทั่วไป” เป็นเพียงข้อเสนอแนะ ไม่ใช่สิ่งที่ Obsidian กำหนดไว้ แต่ละชนิดมีสีและไอคอนของตัวเองในรูปลักษณ์เริ่มต้น ธีมสามารถเปลี่ยนได้ทั้งสองอย่าง

4. callout แบบพับได้: + เทียบกับ -

เพิ่มเครื่องหมายบวกหรือลบทันทีหลังวงเล็บปิด:

> [!faq]+ Open by default
> This callout is foldable and starts expanded.

> [!faq]- Closed by default
> This callout is foldable and starts collapsed.

วิธีใช้ของ Obsidian อธิบาย + ว่าพับได้และกางออกเป็นค่าเริ่มต้น และ - ว่าพับได้และพับเก็บเป็นค่าเริ่มต้น หากไม่มีทั้งสองอย่าง callout จะพับไม่ได้ + หรือ - เป็นส่วนหนึ่งของ Markdown จึงอยู่ในไฟล์ต่อไป

5. callout ซ้อน รายการ โค้ด และการฝัง

สำหรับ callout ซ้อน ให้เพิ่มอีกหนึ่ง > สำหรับแต่ละระดับ:

> [!question] Can callouts be nested?
> > [!example] Yes
> > Add one more > for each level.

การตั้งค่า “ซ้อนใน callout อื่น” ของตัวสร้างจะเขียนส่วนเพิ่มเติม > ที่ทุกบรรทัด สูงสุดสามระดับ วางผลลัพธ์ไว้ในเนื้อความของ callout ชั้นนอก

รายการ โค้ด และ Markdown อื่น ๆ อยู่ในเนื้อความ โดยมี > ทุกบรรทัด วิธีใช้ของ Obsidian ระบุว่าเนื้อความใส่ Markdown, wikilink และการฝังได้ และคุณห่อเนื้อหาที่มีอยู่ รวมถึงรายการและบล็อกโค้ด ได้โดยเลือกแล้วเรียกใช้คำสั่ง แทรก callout คำสั่ง วางรายการหรือบล็อกโค้ดลงในช่องเนื้อความของตัวสร้าง แล้วระบบจะเติมคำนำหน้าให้:

> [!info] Checklist
> - [ ] first
> - [ ] second
>
> ```
> code line
> ```

6. ชนิด callout แบบกำหนดเองด้วย CSS snippet

ชนิดที่คุณคิดขึ้นเองจะแสดงด้วยสไตล์ของ note วิธีใช้ของ Obsidian ระบุว่า callout แบบกำหนดเองกำหนดได้ใน CSS snippet หรือปลั๊กอินชุมชน ตัวอย่างของหน้านั้น:

.callout[data-callout="custom-question-type"] {
  --callout-color: #000000;
  --callout-icon: lucide-alert-circle;
}

ตามหน้าวิธีใช้, --callout-color รับสี CSS ที่ถูกต้องทุกแบบ และ --callout-icon รับ ID ไอคอนจาก lucide.dev หรือองค์ประกอบ SVG จากนั้นเขียน > [!custom-question-type] ในโน้ต แล้วพิมพ์ชื่อเดียวกันลงในช่องชนิดแบบกำหนดเองของตัวสร้าง

7. GitHub alerts เทียบกับ callout ของ Obsidian

GitHub มีฟีเจอร์คล้ายกันที่เรียกว่า alerts เอกสาร GitHub ระบุไว้ห้าชนิด: NOTE, TIP, IMPORTANT, WARNING และ CAUTION.

> [!NOTE]
> Useful information that users should know, even when skimming content.

หน้านั้นไม่ได้อธิบายการพับ หัวข้อแบบกำหนดเอง หรือชนิดแบบกำหนดเอง ส่วน callout ของ Obsidian มีครบทั้งสามอย่าง บรรทัดแรกหน้าตาเหมือนกัน ดังนั้น > [!note] หรือ > [!warning] มักใช้ได้ทั้งสองที่ แต่ชนิดเฉพาะของ Obsidian เช่น [!bug], การพับด้วย +/- หรือหัวข้อ อยู่นอกขอบเขตที่ GitHub ระบุไว้ หากไฟล์ถูกอ่านในทั้งสองที่ ให้ใช้เฉพาะห้าชนิดของ GitHub และไม่เพิ่มอะไรอีก

8. บันทึกลง Obsidian ด้วยเสียงหรือข้อความด้วย Vox.md

Vox.md บันทึกสิ่งที่คุณจับไว้เป็นโน้ต Markdown ในโฟลเดอร์คลัง Obsidian ของคุณ แอปนี้เป็นแอปสำหรับบันทึก และหน้านี้ไม่ได้อ้างว่าแอปเขียน callout ให้คุณ: ให้เพิ่มเองภายหลังโดยสร้างที่นี่แล้ววาง หรือพิมพ์ไวยากรณ์ข้างต้น หากต้องการเนื้อความจากข้อความถอดเสียง ให้วางข้อความลงในตัวสร้างแล้วระบบจะเติมคำนำหน้าให้

เครื่องมือและคู่มือที่เกี่ยวข้อง: ตัวสร้างเช็กลิสต์ Markdown และ ตัวสร้างตาราง Markdown สำหรับเนื้อหาที่จะใส่ใน callout ตัวสร้างคุณสมบัติ, เทมเพลตโน้ตรายวัน และ เทมเพลตบันทึกการประชุม สำหรับโครงสร้างโน้ต, เทมเพลตการจับข้อมูล สำหรับคำนำหน้าและเส้นทาง และ โน้ตเสียงไปยัง Obsidian บน iPhone.

บันทึกโน้ตลงคลังของคุณด้วยเสียงหรือข้อความด้วย Vox.md

Vox.md ถอดเสียงบนอุปกรณ์ของคุณและบันทึก Markdown ลงในคลัง Obsidian ของคุณ การบันทึกเสียง การถอดเสียง และ Capture ต้องใช้ Vox.md Unlimited: การสมัครสมาชิกรายสัปดาห์หรือรายปีพร้อมทดลองใช้ฟรี 7 วันสำหรับบัญชีที่มีสิทธิ์ หรือซื้อขาดแบบตลอดชีพครั้งเดียว App Store จะแสดงราคาในประเทศของคุณ

บันทึกโน้ตด้วยเสียง

ตัวสร้าง callout ด้านบนใช้งานได้เต็มรูปแบบโดยไม่ต้องมีแอป

9. คำถาม

ทำไม callout ของฉันจึงไม่แสดงผล

ตรวจสามอย่าง บรรทัดแรกต้องขึ้นต้นด้วย > แล้วจึง [!type] โดยมีเครื่องหมายอัศเจรีย์และไม่มีช่องว่างในวงเล็บ ทุกบรรทัดของเนื้อความต้องมี >. บรรทัดว่างที่ไม่มี > จะจบบล็อกคำพูด ทำให้บรรทัดหลังจากนั้นเป็นข้อความธรรมดา ให้เขียนเป็น >. หากยังแสดงเป็นบล็อกคำพูดธรรมดา ให้ตรวจดูว่ามีช่องว่างหรือพิมพ์ผิดระหว่าง > และ [!.

callout ไม่มีหัวข้อได้หรือไม่

ไม่เชิง: หากไม่ใส่หัวข้อ Obsidian จะแสดงตัวระบุชนิดในรูปแบบตัวพิมพ์ใหญ่ต้นคำแทน การซ่อนหัวข้อต้องใช้ CSS วิธีใช้ของ Obsidian ระบุว่าการจัดสไตล์เพิ่มเติม เช่น การซ่อนหัวข้อ ใช้ตัวเลือก CSS มาตรฐานได้ ตัวสร้างจะเว้นหัวข้อว่างไว้เมื่อคุณล้างหัวข้อ คุณจึงได้หัวข้อเริ่มต้น

ปลั๊กอิน Admonition หรือ callout ในตัว

callout ในตัวไม่ต้องใช้ปลั๊กอิน และใช้ไวยากรณ์ > [!type] ที่อยู่ในหน้านี้ ปลั๊กอิน Admonition เป็นปลั๊กอินชุมชนแยกต่างหากที่มีไวยากรณ์ของตัวเอง ซึ่งหน้านี้ไม่ได้ครอบคลุม วิธีใช้ของ Obsidian ระบุว่าชนิด callout แบบกำหนดเองอาจมาจากปลั๊กอินชุมชนได้เช่นกัน

callout ใช้ได้บน Obsidian มือถือและใน Publish หรือไม่

วิธีใช้ของ Obsidian ระบุว่า callout รองรับแบบเนทีฟบน Obsidian Publish หน้า callout ไม่ได้พูดถึงมือถือทั้งสองทาง หน้านี้จึงไม่ได้อ้างอะไรเกี่ยวกับเรื่องนี้

ตัวสร้างอัปโหลดข้อความของฉันหรือไม่

ไม่ สคริปต์ในหน้านี้สร้าง callout บนอุปกรณ์ของคุณ และหน้านี้ไม่ส่งคำขอเครือข่ายใด ๆ ไม่มีการบันทึกอะไรทั้งสิ้น: โหลดหน้าใหม่ก็จะล้างทุกอย่าง

ตั้งค่าต่อ

  • ตัวสร้างตาราง Markdown
  • ตัวสร้างและตัวตรวจสอบคุณสมบัติ Obsidian
  • เครื่องมือสร้างเทมเพลตบันทึกประจำวัน Obsidian
