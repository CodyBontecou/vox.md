1. สร้างตารางของคุณ

ตัวสร้างตารางต้องใช้ JavaScript หากไม่มี ไวยากรณ์ด้านล่างยังใช้เป็นข้อมูลอ้างอิงได้

ตารางของคุณ

    ตัวอย่าง

    วางข้อมูลของคุณเพื่อดูตาราง

    คัดลอกไปยังคลิปบอร์ดแล้ว คัดลอกไม่สำเร็จ เลือกข้อความแล้วคัดลอกเอง โหลดตัวอย่างแล้ว ล้างแล้ว เริ่มดาวน์โหลดแล้ว ตาราง Markdown ของคุณ CSV ของคุณ TSV ของคุณ ตรวจพบ: {format} {rows} แถว {cols} คอลัมน์ ตาราง Markdown คั่นด้วยแท็บ คั่นด้วยจุลภาค คั่นด้วยอัฒภาค คั่นด้วย pipe หนึ่งคอลัมน์ ขีดตั้งที่เอสเคปเป็น \|: {n} โดย {m} อยู่ภายใน wikilink หรือลิงก์รูปภาพ บรรทัดที่ {line}: ไม่มีแถวตัวคั่น จึงเพิ่มแถวตัวคั่นต่อจากส่วนหัว บรรทัดที่ {line}: แถวตัวคั่นมี {found} เซลล์ แต่ส่วนหัวมี {expected} เซลล์ ข้อกำหนด GFM ไม่ถือว่านี่เป็นตาราง ผลลัพธ์ใช้ {expected} บรรทัดที่ {line}: มี {found} เซลล์ แต่ส่วนหัวมี {expected} เซลล์ จึงเติมเซลล์ว่างให้แล้ว บรรทัดที่ {line}: มี {found} เซลล์ แต่ส่วนหัวมี {expected} เซลล์ จึงขยายตารางเป็น {max} คอลัมน์ บรรทัดที่ {line} ว่างเปล่า ตารางจะสิ้นสุดที่บรรทัดว่างแรก ดังนั้นแถวที่อยู่หลังบรรทัดนี้จะไม่เป็นส่วนของตาราง และมีอีก {n} แถวที่มีจำนวนเซลล์ไม่เท่ากัน คอลัมน์ {n}: {name} ไม่มี ซ้าย กึ่งกลาง ขวา (ไม่มีส่วนหัว)

    2. ไวยากรณ์ตาราง Markdown

    | Name   | Qty | Price |
| :----- | :-: | ----: |
| Apple  |   3 |  1.20 |
| Pear   |  12 |  0.80 |

    ส่วน สเปก GitHub Flavored Markdown กำหนดตารางว่าประกอบด้วยแถวส่วนหัวหนึ่งแถว แถวตัวคั่นที่แยกส่วนหัวออกจากข้อมูล และแถวข้อมูลศูนย์แถวขึ้นไป เซลล์ถูกคั่นด้วยขีดตั้ง

    • แถวตัวคั่น เซลล์ในแถวนี้มีเพียงขีดกลาง และอาจมีเครื่องหมายทวิภาคที่ปลายซ้าย ขวา หรือทั้งสองด้านเพื่อกำหนดการจัดแนวชิดซ้าย ชิดขวา หรือกึ่งกลาง ความช่วยเหลือของ Obsidian ระบุว่าคุณเพิ่มเครื่องหมายทวิภาคในแถวส่วนหัวเพื่อจัดแนวข้อความ และแถวส่วนหัวต้องมีขีดกลางอย่างน้อยสองตัว
    • ขีดตั้งด้านนอก ข้อกำหนดระบุว่าขีดตั้งทั้งสองด้านเป็นทางเลือก Obsidian Help แนะนำให้ใส่เพื่อให้อ่านง่าย และตัวสร้างตารางจะเขียนให้เสมอ
    • การเว้นระยะ ตาม Obsidian Help เซลล์ไม่จำเป็นต้องเรียงตรงกันอย่างสมบูรณ์ รูปแบบ “Pad columns” ของตัวสร้างตารางจัดต้นฉบับให้เรียงตรงกันเพื่อให้อ่านง่ายขึ้นเท่านั้น ส่วน “Compact” จะข้ามขั้นตอนนี้
    • จำนวนที่ตรงกัน ข้อกำหนดระบุว่าแถวส่วนหัวต้องมีจำนวนเซลล์เท่ากับแถวตัวคั่น หากไม่เท่ากัน บรรทัดเหล่านั้นจะไม่ใช่ตารางและจะแสดงผลเป็นย่อหน้า แถวข้อมูลที่มีเซลล์น้อยกว่าจะถูกเติมเซลล์ว่าง และเซลล์ที่เกินมาจะถูกละเว้น
    • ภายในเซลล์ ข้อกำหนดอนุญาตให้จัดรูปแบบแบบอินไลน์ แต่ไม่อนุญาตเนื้อหาระดับบล็อก จึงใส่รายการหรือหัวข้อในเซลล์ไม่ได้ Obsidian Help ระบุว่าคุณใช้ไวยากรณ์การจัดรูปแบบพื้นฐานเพื่อจัดรูปแบบเนื้อหาในตารางได้
    • จุดสิ้นสุดของตาราง ข้อกำหนดระบุว่าตารางจะสิ้นสุดที่บรรทัดว่างแรก หรือที่จุดเริ่มต้นของโครงสร้างระดับบล็อกอื่น

    ตัวสร้างตารางเขียนขีดกลางอย่างน้อยสามตัวในทุกเซลล์ตัวคั่น ซึ่งเป็นไปตามขั้นต่ำสองตัวของ Obsidian และสามตัวที่ เอกสาร GitHub กำหนด

    3. ตารางใน Obsidian

    • Insert Table Obsidian Help ระบุว่าคุณแทรกตารางได้ด้วยคำสั่ง Insert Table จาก Command Palette หากต้องการสร้างจากข้อมูลที่มีอยู่แล้ว ให้วางลงในตัวสร้างตารางด้านบน
    • นามแฝงและขนาดรูปภาพ นามแฝงของ wikilink เช่น [[Note|Alias]] และขนาดรูปภาพ เช่น ![[image.png|300]] ทั้งสองมีเส้นแนวตั้ง Obsidian Help ระบุว่าภายในตารางคุณต้องเพิ่ม \ ก่อนขีดตั้ง ดังนั้นให้เขียน [[Note\|Alias]] และ ![[image.png\|300]] ตัวสร้างตารางทำให้คุณโดยอัตโนมัติ และเอสเคปที่คุณเขียนไว้แล้วจะไม่ถูกซ้ำ
    • ขีดตั้งอื่น ๆ ข้อกำหนด GFM ระบุว่าขีดตั้งภายในเซลล์ต้องเอสเคปด้วยแบ็กสแลช แม้อยู่ในโค้ดสแปน ตัวสร้างตารางเอสเคปทุกขีดตั้งที่ยังไม่ถูกเอสเคปเป็น \|.
    • การขึ้นบรรทัดใหม่ แถวถูกเขียนในบรรทัดเดียว ดังนั้นการขึ้นบรรทัดใหม่ภายในเซลล์ต้องกลายเป็นอย่างอื่น ตัวสร้างตารางเขียน HTML <br> หรือเชื่อมบรรทัดด้วยช่องว่างหากคุณเลือกเช่นนั้น ทั้งหัวข้อตารางของ Obsidian Help และ GitHub Docs ไม่ได้อธิบายการขึ้นบรรทัดใหม่ในเซลล์ ดังนั้นโปรดตรวจสอบว่า <br> แสดงผลในห้องนิรภัยของคุณเอง และเลือกตัวเลือกช่องว่างหากคุณไม่ต้องการให้มีแท็กในต้นฉบับ
    • ปลั๊กอิน มีปลั๊กอินจากชุมชนที่ช่วยแก้ไขตาราง หน้านี้ไม่ได้ประเมินหรือรับรองปลั๊กอินใด ๆ

    สำหรับเช็กลิสต์ ดู ตัวสร้างเช็กลิสต์ Markdown สำหรับพร็อพเพอร์ตีที่ด้านบนของโน้ต ตัวสร้างคุณสมบัติ ตารางเหมาะกับรายการการตัดสินใจและผู้รับผิดชอบในโน้ตจาก เทมเพลตบันทึกการประชุม.

    4. จาก Excel, Google Sheets หรือ CSV

    เลือกเซลล์ในสเปรดชีตของคุณ คัดลอก แล้ววางลงในช่องด้านบน หากเซลล์ถูกวางโดยมีแท็บคั่น ตัวสร้างตารางจะตรวจพบ นอกจากนี้ยังตรวจพบจุลภาค อัฒภาค และขีดตั้ง และอ่านช่อง CSV ที่อยู่ในเครื่องหมายคำพูดได้ ดังนั้น "Lee, Sam" ยังคงเป็นเซลล์เดียว และ "" ภายในเครื่องหมายคำพูดจะกลายเป็นเครื่องหมายคำพูด ใช้เมนู Separator หากการเดาไม่ถูกต้อง ติ๊กหรือเลิกติ๊ก “The first row is the header” เพื่อกำหนดว่าแถวแรกจะเป็นแถวส่วนหัวหรือไม่ หากไม่ติ๊ก ระบบจะเพิ่มแถวส่วนหัวว่าง เพราะตาราง Markdown ต้องมีส่วนหัว

    • การรวมเซลล์ ข้อกำหนดและหน้าความช่วยเหลือทั้งสองอธิบายว่าแถวคือรายการเซลล์ที่คั่นด้วยขีดตั้ง และไม่มีหน้าใดอธิบายวิธีรวมเซลล์ ให้ใส่ค่าในทุกเซลล์ที่การรวมครอบคลุมก่อนคัดลอก
    • สูตร ตัวสร้างตารางอ่านเฉพาะข้อความที่คุณวาง หากเซลล์ที่วางแสดงสูตรแทนผลลัพธ์ ให้คัดลอกค่าในแอปสเปรดชีตแล้ววางอีกครั้ง
    • แถวที่ไม่เท่ากัน หากแถวใดมีจำนวนเซลล์ต่างจากส่วนหัว ตัวสร้างตารางจะแจ้งเตือนพร้อมหมายเลขบรรทัดของแถวนั้น และเติมเซลล์ว่างให้ตาราง แถวที่มีเซลล์มากกว่าส่วนหัวจะทำให้ตารางกว้างขึ้นแทนที่จะทิ้งข้อมูล
    • ย้อนกลับและซ่อมแซม วางตาราง Markdown ที่มีอยู่เพื่อจัดแนวใหม่ หรือตั้ง Output as เป็น CSV หรือ TSV เพื่อส่งออก ตัวสร้างตารางจะแจ้งเตือนพร้อมหมายเลขบรรทัดเมื่อไม่มีแถวตัวคั่น เมื่อจำนวนเซลล์ไม่ตรงกับส่วนหัว หรือเมื่อบรรทัดว่างจะทำให้ตารางสิ้นสุด

    เครื่องหมายทวิภาคสำหรับการจัดแนวจากตาราง Markdown ที่วางไว้จะถูกเก็บไว้ และคุณเปลี่ยนแต่ละคอลัมน์ได้ด้วยเมนู Column alignment

    5. ความแตกต่างระหว่าง GitHub กับ Obsidian

    Obsidian Help และ GitHub Docs ต่างอธิบายตารางแบบ pipe ที่มีแถวส่วนหัว ขีดกลาง และเครื่องหมายทวิภาคสำหรับการจัดแนวที่ไม่บังคับ ความแตกต่างที่หน้าเหล่านั้นระบุมีเพียงเล็กน้อย:

    หัวข้อความช่วยเหลือของ ObsidianGitHub Docs และข้อกำหนด GFM
    ขีดกลางแถวส่วนหัวต้องมีขีดกลางอย่างน้อยสองตัวGitHub Docs: ต้องมีขีดกลางอย่างน้อยสามตัวในแต่ละคอลัมน์ส่วนหัว
    บรรทัดว่างก่อนตารางหัวข้อตารางไม่ได้กล่าวถึงGitHub Docs: ต้องมีบรรทัดว่างก่อนตารางของคุณ
    ขีดตั้งตามตัวอักษรในเซลล์เพิ่ม \ ก่อนขีดตั้งในนามแฝงและขนาดรูปภาพเอสเคปเป็น \| แม้อยู่ในโค้ดสแปน
    ขีดตั้งด้านนอกไม่บังคับ แต่แนะนำเพื่อให้อ่านง่ายไม่บังคับ

    เพื่อให้ปลอดภัยทั้งสองที่ ให้เขียนขีดกลางสามตัวขึ้นไป เว้นบรรทัดว่างเหนือตาราง และเอสเคปทุกขีดตั้ง ซึ่งเป็นสิ่งที่ตัวสร้างตารางทำ นามแฝงของ wikilink เป็นไวยากรณ์ของ Obsidian บน GitHub จะเป็นเพียงข้อความที่มีขีดตั้งอยู่ในนั้น คู่มือตัวสร้างเช็กลิสต์ครอบคลุม ความแตกต่างของรายการงาน ในลักษณะเดียวกัน

    หากต้องการเน้นตารางหรือโน้ตเกี่ยวกับตาราง ให้ห่อด้วย callout: ตัวสร้าง callout ของ Obsidian เพิ่ม > คำนำหน้าให้คุณ

    6. นำตารางและโน้ตเข้าสู่ห้องนิรภัยของคุณด้วย Vox.md

    Vox.md ไม่ได้สร้างตารางเอง และตัวสร้างตารางด้านบนใช้งานได้โดยไม่ต้องมีแอป สิ่งที่ Vox.md ทำคือบันทึกข้อความลงใน Obsidian: Quick Capture ให้คุณวางข้อความที่มีอยู่ และ Route จะส่งไปยังปลายทาง Markdown ดู การจับภาพอย่างรวดเร็ว และ เส้นทาง ในเอกสาร

    1. สร้างตารางของคุณด้านบนแล้วกด Copy
    2. ใน Vox.md บน iPhone, iPad หรือ Mac เปิด Quick Capture แล้ววางตารางลงในตัวแก้ไขข้อความ
    3. ส่งด้วย Route ที่เก็บข้อความต้นฉบับไว้ เอกสารระบุ เก็บต้นฉบับ เป็นโหมดประมวลผลที่เก็บข้อความที่บันทึกไว้โดยไม่ให้ AI เขียนใหม่ และระบุว่าข้อความที่บันทึกจะถูกส่งโดยไม่เปลี่ยนแปลงเมื่อ ใช้ Apple Intelligence ปิดอยู่ ซึ่งเป็นค่าเริ่มต้น การประมวลผลข้อความที่พิมพ์เป็นการตั้งค่าแบบเลือกเปิดในแต่ละ Route
    4. ปลายทางของ Route เป็นตัวกำหนดว่าข้อความจะไปอยู่ที่ใด ได้แก่ โน้ตใหม่ โน้ตต่อเนื่อง เช่นโน้ตรายวันของคุณ หรือโน้ตที่มีอยู่แล้ว โดยวางไว้ท้ายโน้ต ต้นโน้ต หรือใต้หัวข้อที่เลือก

    เว้นบรรทัดว่างเหนือตารางที่วางหากปลายทางมีข้อความอยู่ด้านบนแล้ว สำหรับสูตร Route ดู เทมเพลตการจับข้อมูล และหากต้องการเปลี่ยนไฟล์คำบรรยาย Zoom, Teams หรือ YouTube เป็นโน้ตถอดเสียงก่อน ดู SRT และ VTT เป็น Markdown.

    บันทึกลง Obsidian จาก iPhone, iPad หรือ Mac ด้วย Vox.md

    Vox.md บันทึกเสียงและข้อความลงในโน้ต Obsidian ของคุณ การบันทึกเสียง การถอดเสียง และ Capture ต้องใช้ Vox.md Unlimited ซึ่งเป็นการสมัครรายสัปดาห์หรือรายปีพร้อมทดลองใช้ฟรี 7 วันสำหรับบัญชีที่มีสิทธิ์ หรือซื้อแบบครั้งเดียวตลอดชีพ App Store จะแสดงราคาในประเทศของคุณ

    บันทึกลง Obsidian

    ตัวสร้างตารางด้านบนใช้งานได้เต็มรูปแบบโดยไม่ต้องใช้แอป

    7. คำถาม

    ทำไมตารางของฉันจึงไม่แสดงผลใน Obsidian

    ตรวจสอบสามอย่าง ต้องมีแถวตัวคั่นที่เป็นขีดกลางอยู่ใต้ส่วนหัวทันที และแถวส่วนหัวกับแถวตัวคั่นต้องมีจำนวนเซลล์เท่ากัน มิฉะนั้นตามข้อกำหนดบรรทัดเหล่านั้นจะแสดงผลเป็นย่อหน้า Obsidian Help ระบุว่าแถวส่วนหัวต้องมีขีดกลางอย่างน้อยสองตัว และเว้นบรรทัดว่างก่อนตาราง ซึ่ง GitHub Docs กำหนดไว้ และไม่มีผลเสียใน Obsidian วางตารางลงในตัวสร้างตาราง: ตัวสร้างจะแจ้งเตือนพร้อมหมายเลขบรรทัดเมื่อไม่มีแถวตัวคั่นหรือจำนวนเซลล์ไม่ตรงกัน

    ฉันจะขึ้นบรรทัดใหม่ในเซลล์ได้อย่างไร

    เก็บแถวไว้ในบรรทัดเดียวและใช้ HTML <br> ภายในเซลล์ ซึ่งเป็นสิ่งที่ตัวสร้างตารางเขียนสำหรับเซลล์หลายบรรทัด หน้าที่อ้างอิงไม่ได้อธิบายการขึ้นบรรทัดใหม่ในเซลล์ ดังนั้นโปรดทดสอบในห้องนิรภัยของคุณ อีกทางเลือกหนึ่งคือเชื่อมบรรทัดด้วยช่องว่าง

    ฉันจะใส่ขีดตั้งหรือนามแฝง wikilink ในเซลล์ได้อย่างไร

    ใส่แบ็กสแลชไว้หน้าขีดตั้ง: [[Note\|Alias]], ![[image.png\|300]] หรือ a \| b Obsidian Help กำหนดให้ทำเช่นนี้สำหรับนามแฝงและการปรับขนาดรูปภาพภายในตาราง และข้อกำหนด GFM กำหนดให้ทำกับทุกขีดตั้งในเซลล์

    ฉันรวมเซลล์ได้หรือไม่

    ไม่มีไวยากรณ์สำหรับสิ่งนี้ในข้อกำหนดหรือใน Obsidian Help ให้ใส่ค่าซ้ำในแต่ละเซลล์แทน

    ตารางกว้างได้แค่ไหน

    ไม่มีหน้าที่อ้างอิงหน้าใดระบุจำนวนคอลัมน์หรือแถวสูงสุด และตัวสร้างตารางไม่จำกัด ตารางที่กว้างมากอ่านยากในต้นฉบับ ให้ใช้รูปแบบ Compact หรือแยกเป็นสองตาราง

    ตัวสร้างตารางอัปโหลดข้อมูลของฉันหรือไม่

    ไม่ ตารางถูกสร้างโดยสคริปต์ในหน้านี้บนอุปกรณ์ของคุณ และหน้านี้ไม่ส่งคำขอเครือข่ายใด ๆ หน้านี้ไม่บันทึกข้อมูลของคุณ การปิดหรือโหลดหน้าซ้ำจะล้างข้อมูล ปุ่ม Download จะบันทึกไฟล์จากหน้านี้ลงในอุปกรณ์ของคุณ
