L041 · how.md

##สามจุดแวะ ไม่มีอันไหนของเรา

เปิดคลัง หาโน้ต และเลือกจุดที่ถูกต้องยุ่งยากเกินไปสำหรับความคิดชั่ววูบ ตั้งเส้นทางครั้งเดียวแล้วจด

  1. 01โฟลเดอร์ของคุณ

    เชื่อมคลัง

    เลือกคลัง Obsidian หรือโฟลเดอร์ที่เขียนได้ใน Files Vox.md ทำงานกับไฟล์ Markdown ที่คุณเป็นเจ้าของอยู่แล้ว

  2. 02กระเป๋าคุณ

    จดได้ทุกอย่าง

    เขียน วางลิงก์ เพิ่มสื่อหรือไฟล์ สแกนเอกสาร วาด หรือบันทึกโน้ตเสียงส่วนตัว ถอดเสียงตรงนั้นได้เลย

  3. 03ไฟล์ของคุณ

    เส้นทางจัดเก็บให้

    สร้างโน้ต อัปเดตโน้ตต่อเนื่อง หรือเลือกโน้ตเดิม วางต้น ท้าย หรือใต้หัวข้อ

จุดแวะ 2.5: คลาวด์ของคนอื่น ข้ามไป การซิงค์เป็นไปตามที่โฟลเดอร์ทำอยู่แล้วภายใต้ข้อกำหนดผู้ให้บริการ

##มันคือ เพียง ไฟล์

ไม่ต้องใช้ปลั๊กอิน บัญชีคลาวด์ Vox.md หรือรูปแบบเฉพาะ Vox.md เขียน Markdown ที่อ่านได้และลิงก์แบบ Obsidian ลงโฟลเดอร์ที่คุณควบคุม โน้ตจึงไม่ผูกติดกับแอป

  • .mdโน้ตพิมพ์และข้อความถอดเสียงในรูป Markdown มาตรฐาน
  • [[ ]]wikilink และไฟล์แนบฝังที่ Obsidian เข้าใจ
  • imgรูปภาพ ไฟล์ และสแกนเอกสารพร้อมข้อความที่ดึงออกมา คู่มือจดสื่อ
  • urlลิงก์จากทุกที่ที่แชร์ได้
  • drawภาพร่างที่แก้ไขได้
  • voiceเสียงส่วนตัวจากตัวเขียนหรือคีย์บอร์ด ไม่เคยอัปโหลดเสียง คู่มือโน้ตเสียง iPhone
  • ---Markdown หรือ YAML ใช้ซ้ำพร้อมโทเคนวัน เวลา แหล่ง และรหัส

##ตั้งค่าเส้นทางครั้งเดียว แล้วแค่พูด

เส้นทางจดจำวิธีประมวลผลและจัดรูปแบบการจด รวมถึงคลัง โน้ตเป้าหมาย ตำแหน่งวาง ไฟล์แนบ พฤติกรรมลองใหม่ และตำแหน่งปัจจุบันครั้งเดียวที่เลือกใช้ได้

เส้นทางตัวอย่าง
เส้นทางไฟล์ตรงไหนในนั้นครอบด้วย
โน้ตรายวัน · TasksJournal/{date}.mdท้าย ## Tasks- {text}
บันทึกการประชุมMeetings/{date}.mdใต้ ## Notes### {time} · {title}
รายการอ่านInbox/Reading.mdต้นไฟล์### {time}
ไอเดียProjects/Ideas.mdท้ายไฟล์> {text}
โน้ตใหม่Inbox/{timestamp}.mdไฟล์ใหม่frontmatter YAML + เนื้อหา
โน้ตที่มีอยู่ Projects/Ideas.md
เพิ่มลงเอกสารที่มีในคลังต่อไป
โน้ตต่อเนื่อง Journal/{period}.md
โน้ตรายวัน สัปดาห์ เดือน ไตรมาส หรือปี ตั้งโน้ตรายวันและตำแหน่งหัวข้อ
โน้ตใหม่ Inbox/{timestamp}.md
สร้างไฟล์ใหม่สะอาดทุกครั้งที่จด
ตำแหน่งแม่นยำ Top · Bottom · Heading
ใต้หัวข้อทุกระดับ สร้างให้เมื่อยังไม่มี
โบสถ์ Markdown · YAML · Tokens
คงรูปแบบการจดซ้ำโดยไม่จัดใหม่
ตำแหน่งปัจจุบัน {location}
ลิงก์แผนที่หนึ่งครั้ง ณ เวลาต้นทางโดยไม่มีข้อมูลเมตา หรือเปิด frontmatter และฟิลด์ในบรรทัด อ่านคู่มือ

L214 · faq.md

##เปิด คำถาม

Vox.md ทำงานโดยตรงกับโฟลเดอร์ Markdown ที่คุณเลือก Obsidian เข้ากันได้ดีแต่ไม่จำเป็นต้องใช้ ติ๊กหนึ่งข้อเพื่ออ่านคำตอบ

Vox.md ใช้กับ Obsidian ได้หรือไม่?

ได้ สร้างเส้นทางและเลือกคลัง Obsidian เป็นปลายทาง Vox.md เขียน Markdown มาตรฐาน wikilink และไฟล์แนบฝังลงคลังโดยตรง ไม่ต้องใช้ปลั๊กอิน Obsidian เปรียบเทียบ Vox.md กับการจดบันทึกในตัวของ Obsidian ตั้งค่าขั้นตอนจดลงโน้ตรายวัน

จดอะไรได้บ้าง?

ตัวเขียนรับข้อความ ลิงก์เว็บ รูปภาพ ไฟล์ สแกนเอกสาร ภาพร่าง และเสียง สแกนมีข้อความที่ดึงได้ และเสียงถอดในเครื่องได้

สิ่งที่จดส่งไปไหนได้บ้าง?

แต่ละเส้นทางมีปลายทางที่สร้างโน้ตใหม่ อัปเดตโน้ตรายวันหรือรายช่วงแบบต่อเนื่อง หรือเขียนลง Markdown ที่มีได้ การจดหนึ่งครั้งเลือกโน้ตอื่นชั่วคราวได้โดยไม่เปลี่ยนเส้นทาง

Vox.md แทรกใต้หัวข้อได้หรือไม่?

ได้ เส้นทางแทรกข้างหน้า ต่อท้าย หรือใต้หัวข้อระดับหนึ่งถึงหกได้ เลือกได้ว่าหัวข้อที่ไม่มีจะหยุดส่งหรือสร้างอัตโนมัติ และให้รายการใหม่ลงใต้หัวข้อทันทีหรือท้ายส่วนนั้น

ใช้โดยไม่มี Obsidian ได้หรือไม่?

ได้ เส้นทางใช้โฟลเดอร์ที่เขียนได้ซึ่งเข้าถึงผ่าน Files ได้ทุกแห่ง ผลลัพธ์เป็น Markdown ธรรมดาพร้อมไฟล์แนบทั่วไป โน้ตจึงไม่ผูกติดกับ Vox.md

Vox.md อัปโหลดโน้ตหรือเสียงหรือไม่?

ไม่มีเนื้อหาที่จดส่งไปเซิร์ฟเวอร์ Vox.md ฉบับร่างและประมวลผลเสียงอยู่บนอุปกรณ์ ไฟล์สำเร็จเขียนโฟลเดอร์ที่เลือก หากโฟลเดอร์เป็นของผู้ให้บริการซิงค์ บริการจัดการตามข้อกำหนดของตน ตรวจข้อกำหนดตั้งค่าออฟไลน์

ใช้ตำแหน่งในเทมเพลตโดยไม่เพิ่มข้อมูลเมตาได้หรือไม่?

ได้ เปิด ใช้ตำแหน่งปัจจุบัน สำหรับเส้นทางนั้น ปิด เขียนข้อมูลเมตาตำแหน่ง ไว้ แล้วเพิ่ม {location} ในการจัดรูปแบบรายการ Vox.md แทรกลิงก์แผนที่ครั้งเดียวโดยไม่เพิ่ม frontmatter หรือฟิลด์ตำแหน่งในบรรทัด อ่านคู่มือตำแหน่งทั้งหมด

จดนอกแอปได้หรือไม่?

ได้ Vox.md มีวิดเจ็ต การทำงาน Shortcuts ส่วนขยายแชร์ และคีย์บอร์ดเสียง จุดเริ่มเหล่านี้เข้าระบบจดในเครื่องเดียวกัน

Vox.md ราคาเท่าไร?

Vox.md ให้ถอดเสียงฟรี 15 นาทีและส่งสำเร็จ 10 ครั้ง ถอดเสียงและจดไม่จำกัดด้วยซื้อครั้งเดียวตลอดชีพ ไม่มีสมาชิกหรือโฆษณา ข้อความเสียงที่ส่ง Markdown ใช้โควตาถอดเสียง ไม่ใช้โควตาจดซ้ำ App Store แสดงราคาปัจจุบันตามภูมิภาค

วางความคิดถัดไป ในไฟล์

เชื่อมคลังหรือโฟลเดอร์ในเครื่องครั้งเดียว ไอเดียถัดไปลงโน้ต หัวข้อ และรูปแบบที่เลือกได้ตรง ๆ
