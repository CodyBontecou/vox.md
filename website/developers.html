Public Information API

Discover product facts and documentation

The Vox.md Public Information API serves product information and links to published documentation. It is free to read and requires no account, API key, OAuth flow, or payment. These endpoints return information already available on this public website. Read the OpenAPI 3.1 contract for typed response schemas, operation identifiers, errors, and descriptions.

Get product information

GET https://vox.isolated.tech/api/v1/product returns the product name, description, supported operating systems, App Store listing, documentation URL, and support URL. The build derives these facts from the homepage structured data.

curl https://vox.isolated.tech/api/v1/product

View product JSON

Find a document

GET https://vox.isolated.tech/api/v1/documents lists public page titles, summaries, and URLs. Use this to find the relevant feature guide, policy, blog article, or support page before requesting the content.

curl https://vox.isolated.tech/api/v1/documents

View document index JSON

Read the page as Markdown

Request any listed page with Accept: text/markdown for its main content. Requests with Accept: text/html continue to receive HTML. Both representations include Vary: Accept. The agent guide explains which use cases fit Vox.md and points to feature details.

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

Errors, caching, and methods

The JSON endpoints support GET and HEAD. Unknown API paths return HTTP 404 with application/problem+json, a stable code, an explanation, and a recovery hint. Unsupported methods return HTTP 405 and Allow: GET, HEAD. Public metadata responses permit cross-origin reading and advertise a five minute cache lifetime. No credentials or user-specific data are involved.

Automate the installed app

Capture, transcription, local vault access, and note writes run in the installed Apple app. Use the documented Shortcuts and URL scheme integrations with the device owner's permission. The public information API does not expose capture actions, recordings, transcripts, private notes, or destination folders. Contact Vox.md support for questions.
