##Three stops. None of them ours.

Opening a vault, finding a note, and choosing the right spot is too much work for a fleeting thought. Set the route once, then capture.

  1. 01your folder

    Connect a vault

    Choose an Obsidian vault or any writable folder in Files. Vox.md works with the Markdown files you already own.

  2. 02your pocket

    Capture anything

    Write, paste a link, add media or a file, scan a document, sketch, or record a private voice note. Voice is transcribed right there.

  3. 03your file

    The route files it

    Create a note, update a rolling note, or target an existing one. Place it at the top, bottom, or under a heading.

Stop 2.5: someone else’s cloud. Skipped. Sync is whatever your folder already does, under that provider’s terms.

L214 · faq.md

##Open questions

Vox.md works directly with Markdown folders you choose. Obsidian is a natural fit, but it is not required. Tick one to read the answer.

Does Vox.md work with Obsidian?

Yes. Create a Route and choose your Obsidian vault as its destination. Vox.md writes standard Markdown, wikilinks, and attachment embeds directly into the vault. It does not require an Obsidian plugin. Compare Vox.md with native Obsidian capture. Set up a daily-note capture workflow.

What can I capture?

The composer accepts text, web links, photos, files, document scans, sketches, and voice. Scans can include extracted text, and voice can be transcribed locally.

Where can a capture go?

Each Route owns a destination that can create a new note, update a rolling daily or periodic note, or write to an existing Markdown file. A single capture can temporarily choose another note without changing the route.

Can Vox.md insert beneath a heading?

Yes. A route can prepend, append, or insert beneath a heading from level one through six. You can choose whether a missing heading should stop delivery or be created automatically, and whether new entries land directly beneath the heading or at the end of that heading's section.

Can I use it without Obsidian?

Yes. A Route can use any writable folder exposed through Files. The output is plain Markdown with ordinary attachments, so the notes are not locked to Vox.md.

Does Vox.md upload my notes or audio?

No capture content is sent to Vox.md servers. Drafts and voice processing stay on the device, while completed files are written to the folder you selected. If that folder belongs to a sync provider, the provider handles it under its own terms. Check the offline setup requirements.

Can I use location in a template without adding metadata?

Yes. Turn on Use Current Location for that Route, keep Write Location Metadata off, and add {location} to its entry formatting. Vox.md inserts a one-shot map link without adding frontmatter or inline location fields. Read the complete location guide.

Can I capture outside the app?

Yes. Vox.md includes widgets, Shortcuts actions, a share extension, and a voice keyboard. These entry points feed the same local capture system.

What does Vox.md cost?

Vox.md includes 15 minutes of transcription and 10 successful Capture deliveries free. Unlimited transcription and Capture are available with a one-time lifetime purchase, with no subscription or ads. Voice transcripts sent to Markdown use the transcription allowance rather than a second Capture allowance. The App Store shows the current price for your region.
