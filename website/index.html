01 / How it works

Get it into your notes before the moment passes

Opening a vault, finding a note, and choosing the right spot is too much work for a fleeting thought. Set the route once, then capture.

  1. 1

    Connect a vault or folder

    Choose an Obsidian vault or any writable folder in Files. Vox.md works with the Markdown files you already own.

  2. 2

    Capture what you have

    Write, paste a link, add media or a file, scan a document, sketch, or record a private voice note.

  3. 3

    Let the route file it

    Create a note, update a rolling note, or target an existing one. Place the capture at the top, bottom, or under a heading.

02 / Capture

A capture tool for Markdown people

Vox.md treats your notes as files. It writes readable Markdown and Obsidian-style links directly into folders you control.

001 · Vaults

Obsidian ready

Choose an Obsidian vault through Files and write to it directly. You do not need a plugin or a Vox.md cloud account.

002 · Placement

Precise note placement

Insert at the top or bottom of a note, or place the capture beneath a heading that Vox.md can create when needed.

003 · Inputs

More than text

Capture links, photos, files, document scans with extracted text, editable sketches, and voice alongside typed notes.

004 · Rolling notes

Daily notes and beyond

Route captures into daily, weekly, monthly, quarterly, or yearly notes with predictable filename templates.

005 · Templates

Reusable entry formats

Wrap each capture in reusable Markdown or YAML. Add date, time, source, and identifier tokens automatically.

006 · Voice

Private voice when you want it

Record from the composer or keyboard. Transcription runs on the device, and Vox.md does not upload the audio.

06 / FAQ

Questions about vaults, files, and privacy

Vox.md works directly with Markdown folders you choose. Obsidian is a natural fit, but it is not required.

Does Vox.md work with Obsidian?

Yes. Create a Route and choose your Obsidian vault as its destination. Vox.md writes standard Markdown, wikilinks, and attachment embeds directly into the vault. It does not require an Obsidian plugin. Set up a daily-note capture workflow.

What can I capture?

The composer accepts text, web links, photos, files, document scans, sketches, and voice. Scans can include extracted text, and voice can be transcribed locally.

Where can a capture go?

Each Route owns a destination that can create a new note, update a rolling daily or periodic note, or write to an existing Markdown file. A single capture can temporarily choose another note without changing the route.

Can Vox.md insert beneath a heading?

Yes. A route can prepend, append, or insert beneath a heading from level one through six. You can choose whether a missing heading should stop delivery or be created automatically, and whether new entries land directly beneath the heading or at the end of that heading's section.

Can I use it without Obsidian?

Yes. A Route can use any writable folder exposed through Files. The output is plain Markdown with ordinary attachments, so the notes are not locked to Vox.md.

Does Vox.md upload my notes or audio?

No capture content is sent to Vox.md servers. Drafts and voice processing stay on the device, while completed files are written to the folder you selected. If that folder belongs to a sync provider, the provider handles it under its own terms.

Can I use location in a template without adding metadata?

Yes. Turn on Use Current Location for that Route, keep Write Location Metadata off, and add {location} to its entry formatting. Vox.md inserts a one-shot map link without adding frontmatter or inline location fields. Read the complete location guide.

Can I capture outside the app?

Yes. Vox.md includes widgets, Shortcuts actions, a share extension, and a voice keyboard. These entry points feed the same local capture system.

What does Vox.md cost?

Vox.md is a free download from the App Store. Check the App Store listing for the current purchase options shown by Apple.
