API di informazioni pubbliche

Scopri informazioni e documentazione del prodotto

L’API di informazioni pubbliche Vox.md fornisce informazioni sul prodotto e link alla documentazione pubblicata. La lettura è gratuita e non richiede account, chiave API, flusso OAuth o pagamento. Questi endpoint restituiscono informazioni già disponibili sul sito pubblico. Leggi la Contratto OpenAPI 3.1 per schemi di risposta tipizzati, ID operazioni, errori e descrizioni.

Ottieni informazioni prodotto

GET https://vox.isolated.tech/api/v1/product restituisce nome, descrizione, sistemi, scheda App Store, URL documentazione e supporto. La build deriva i dati dai dati strutturati della Home.

curl https://vox.isolated.tech/api/v1/product

Vedi JSON del prodotto

Trova un documento

GET https://vox.isolated.tech/api/v1/documents elenca titoli, riepiloghi e URL pubblici. Trova guida, informativa, articolo o supporto prima di richiedere il contenuto.

curl https://vox.isolated.tech/api/v1/documents

Vedi indice documenti JSON

Leggi la pagina in Markdown

Richiedi una pagina elencata con Accept: text/markdown per il contenuto principale. Richieste con Accept: text/html continuano a ricevere HTML. Entrambe le rappresentazioni includono Vary: Accept. La guida per agenti spiega gli usi adatti e i dettagli delle funzioni Vox.md.

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

Errori, cache e metodi

Gli endpoint JSON supportano GET e HEAD. I percorsi API sconosciuti restituiscono HTTP 404 con application/problem+json, un identificatore stabile code, spiegazione e suggerimento di recupero. I metodi non supportati restituiscono HTTP 405 e Allow: GET, HEAD. Le risposte pubbliche consentono lettura cross-origin e dichiarano una cache di cinque minuti. Nessuna credenziale o dato specifico dell’utente.

Automatizza l’app installata

Acquisizione, trascrizione, vault locale e scrittura avvengono nell’app Apple installata. Usa lo schema documentato Integrazioni Comandi Rapidi e schema URL col permesso del proprietario. L’API pubblica non espone azioni, registrazioni, trascrizioni, note private o cartelle. Contatta supporto Vox.md per domande.
