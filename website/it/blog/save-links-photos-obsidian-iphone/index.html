Salva link, foto e scansioni in Obsidian da iPhone

Tieni la fonte accanto al pensiero. Invia link, immagine o scansione alla destinazione Markdown scelta.

Di
Cody Bontecou
Aggiornato
26 ottobre 2026
Richiede
iOS 17.6+ · vault scrivibile
La risposta breve

Collega un Cattura di preset Vox.md a una cartella del vault scrivibile, aggiungi un URL, una foto, un file o una scansione in Rapida cattura e invia. Il preset sceglie la nota e la posizione degli allegati. Rileggi il Markdown inviato e conferma che i suoi allegati si aprano in Obsidian.

Link e articolo sono cose diverse. Vox.md accetta URL come link Markdown; non presumere che aggiungere un URL scarichi o estragga l’intera pagina. Scegli il metodo per il materiale voluto.

In questa guida
  1. Prepara la destinazione del vault
  2. Salva un link web
  3. Aggiungi foto, screenshot o file
  4. Scansiona un documento e verifica l’OCR
  5. Verifica allegati e sincronizzazione

1. Prepara la destinazione del vault

In Impostazioni → Cattura di preset crea o scegli un preset attivo e collega la destinazione tramite File. Scegli la cartella Markdown del vault. Se non è esposta ad altre app, Vox.md non può scriverci solo perché Obsidian la mostra.

Nel primo esempio scegli Nuova nota e Mantieni originale. Una cartella di raccolta separata facilita trovare contenuti misti. Dopo puoi usare Rolling note o Nota esistente per aggiungere allo stesso file.

Imposta una sottocartella per gli allegati nella destinazione; il valore predefinito è attachments. Verifica percorso e allegati prima d’inviare. Per un diario segui la guida percorsi giornalieri.

2. Salva un link web

Copia l’URL. In Rapida cattura usa Link web e verifica testo e indirizzo. Aggiungi una breve spiegazione, poi inviare.

Una nota semplice potrebbe contenere questo Markdown illustrativo:

Read before planning the trip:
[Trail information](https://example.com/trail)

L’indirizzo è un esempio, non una raccomandazione. Sostituiscilo con la pagina reale. Il link riporta alla sorgente, ma non conserva il contenuto se cambia o scompare.

Il foglio di condivisione Vox.md accetta anche contenuti supportati da altre app. Ciò che un’app condivide può essere un URL, testo o un file. Verifica il contenuto ricevuto e il preset selezionato, senza presumere che sia incluso tutto ciò che appare sullo schermo di origine.

3. Aggiungi foto, screenshot o file

  1. Scegli il preset di raccolta o progetto.
  2. Usa selettore foto o screenshot, fotocamera o Aggiungi file per scegliere il materiale.
  3. Aggiungi titolo o spiegazione nell’editor.
  4. Invia, apri in Obsidian e verifica immagine o link allegato.

Le immagini sono incorporate nel Markdown, gli altri file collegati. Una nota può referenziare un percorso allegato configurato così:

## Reference
![[attachments/whiteboard.png]]
[[attachments/brief.pdf]]

Nomi e percorsi sono illustrativi; l’output Vox.md dipende dai file e dalle regole. Conserva i file referenziati con il vault. Spostare solo Markdown può rompere i link relativi.

Prova 10 invii di acquisizione riusciti e 15 minuti di trascrizione. L’uso illimitato è un acquisto unico a vita.

4. Scansiona e verifica OCR

Scegli Scansione Documenti nella Barra di acquisizione e segui lo scanner. Vox.md conserva le immagini delle pagine, crea un PDF e include il riconoscimento del testo sul dispositivo al meglio delle sue possibilità. Rileggi le parole riconosciute prima di inviare, soprattutto nomi, date, importi e scrittura a mano.

Per le foto del diario, il flusso separato Estratto di testo supporta pagine acquisite manualmente o selezionate. L’OCR può perdere la struttura o leggere male una parola anche quando l’immagine sembra chiara. Conserva l’immagine o la scansione originale se devi verificare il testo in seguito.

Scegli Mantieni originale per evitare riscritture facoltative. Il testo digitato e misto si attiva separatamente per preset. La riferimento acquisizione descrive input supportati e la limiti di input.

Verifica allegati e sincronizzazione

Dopo l’invio apri la nota in Obsidian, segui ogni link e verifica il file. Vederla su un altro dispositivo non prova che tutti gli allegati siano sincronizzati: verifica anche immagine o PDF lì.

Una scrittura fallita può restare pendente in Vox.md. Correggi l’accesso e riprova prima di creare copie. I file cloud possono richiedere rete per accesso o sincronizzazione, anche con elaborazione locale.

Per estrarre pagine web intere, confronta direttamente gli strumenti. Obsidian documenta le opzioni native di condivisione nella guida iOS ufficiale. Puoi usare condivisione nativa per una cosa e preset Vox.md per un’altra.
