L041 · how.md

##Tre tappe. Nessuna nostra.

Aprire il vault, cercare la nota e scegliere il punto è troppo per un pensiero fugace. Configura una volta, poi acquisisci.

  1. 01la tua cartella

    Collega un vault

    Scegli un vault Obsidian o una cartella scrivibile in File. Vox.md usa i file Markdown che già possiedi.

  2. 02la tua tasca

    Acquisisci qualsiasi cosa

    Scrivi, incolla un link, aggiungi media o file, scansiona, disegna o registra una nota privata. La voce è trascritta lì.

  3. 03il tuo file

    Il percorso lo archivia

    Crea una nota, aggiorna una periodica o scegli un’esistente. Inserisci all’inizio, alla fine o sotto titolo.

Tappa 2,5: il cloud di altri. Omessa. La sincronizzazione è quella della cartella, secondo i termini del provider.

L077 · files.md

##È solo file.

Niente plugin, account cloud Vox.md o formati proprietari. Vox.md scrive Markdown leggibile e link Obsidian in cartelle che controlli: le note non restano vincolate all’app.

  • .mdNote digitate e trascrizioni in Markdown standard
  • [[ ]]Wikilink e allegati incorporati compresi da Obsidian
  • imgFoto, file e scansioni con testo estratto. Guida acquisizione media
  • urlLink da qualsiasi luogo che consente condivisione
  • drawSchizzi modificabili
  • voiceVoce privata dall’editor o tastiera; audio mai caricato. guida alle note vocali iPhone
  • ---Markdown o YAML riutilizzabile con token data, ora, fonte e ID

L214 · faq.md

##aperto domande

Vox.md lavora direttamente con le cartelle Markdown che scegli. Obsidian è una scelta naturale, ma non obbligatoria. Spunta una domanda per leggere la risposta.

Vox.md funziona con Obsidian?

Sì. Crea un Percorso e scegli il vault Obsidian. Vox.md scrive Markdown standard, wikilink e allegati incorporati direttamente nel vault. Non serve un plugin Obsidian. Confronta Vox.md con l’acquisizione nativa di Obsidian. Configura un flusso di note giornaliere.

Cosa posso acquisire?

L’editor accetta testo, link, foto, file, scansioni, schizzi e voce. Le scansioni possono includere testo estratto e la voce può essere trascritta localmente.

Dove può andare un’acquisizione?

Ogni Percorso ha una destinazione che crea note, aggiorna note giornaliere o periodiche o scrive in Markdown esistente. Una singola acquisizione può scegliere temporaneamente un’altra nota senza cambiare il percorso.

Vox.md può inserire sotto un titolo?

Sì. Un percorso può aggiungere all’inizio o alla fine oppure inserire sotto un titolo di livello da uno a sei. Puoi scegliere se un titolo mancante deve bloccare l’invio o essere creato automaticamente e se le nuove voci vanno subito sotto il titolo o alla fine della sezione di quel titolo.

Posso usarlo senza Obsidian?

Sì. Un Percorso usa qualsiasi cartella scrivibile esposta da File. L’output è Markdown semplice con allegati ordinari: le note non sono vincolate a Vox.md.

Vox.md carica note o audio?

Nessun contenuto va ai server Vox.md. Bozze e voce restano locali, i file completi nella cartella. Il provider di sync la gestisce secondo i termini. Controlla i requisiti offline.

Posso usare posizione senza metadati nel modello?

Sì. Attiva Usa posizione corrente per il Percorso, lascia spento Scrivi metadati sulla posizione e aggiungi {location} al formato della voce. Vox.md inserisce un link mappa singolo senza metadati iniziali o inline. Leggi la guida completa alla posizione.

Posso acquisire fuori dall’app?

Sì. Vox.md include widget, Comandi Rapidi, condivisione e tastiera vocale: tutti alimentano lo stesso sistema locale.

Quanto costa Vox.md?

Vox.md include gratis 15 minuti di trascrizione e 10 invii di acquisizione riusciti. Trascrizione e acquisizione illimitate sono disponibili con un acquisto unico a vita, senza abbonamenti o pubblicità. Le trascrizioni vocali inviate in Markdown usano la quota di trascrizione, senza consumare anche una seconda quota di acquisizione. L’App Store mostra il prezzo attuale per la tua regione.
