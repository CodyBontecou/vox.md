公開資訊 API

查找產品資訊與文件

Vox.md 公開資訊 API 提供產品資訊及已發佈文件的連結。免費讀取，無需帳號、API 金鑰、OAuth 流程或付款。這些端點返回的資訊均已在本公開網站提供。請閱讀 OpenAPI 3.1 契約 查看帶類型的響應架構、操作標識符、錯誤和說明。

獲取產品資訊

GET https://vox.isolated.tech/api/v1/product 返回產品名稱、說明、支援的作業系統、App Store 頁面、文件 URL 和支援 URL。構建過程從首頁結構化資料中提取這些資訊。

curl https://vox.isolated.tech/api/v1/product

查看產品 JSON

查找文件

GET https://vox.isolated.tech/api/v1/documents 列出公開頁面標題、摘要和 URL。請求內容前，可據此查找相關功能指南、政策、部落格文章或支援頁面。

curl https://vox.isolated.tech/api/v1/documents

查看文件索引 JSON

以 Markdown 閱讀頁面

使用以下方式請求任一列出的頁面： Accept: text/markdown 作為主要內容。帶有以下內容的請求： Accept: text/html 仍會收到 HTML。兩種表示均包含 Vary: Accept。該 代理指南 說明哪些使用場景適合 Vox.md，並指向功能詳情。

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

錯誤、快取和方法

JSON 端點支援 GET 和 HEAD。未知 API 路徑返回 HTTP 404，並附帶 application/problem+json、穩定的 code、說明和恢復提示。不支援的方法返回 HTTP 405 和 Allow: GET, HEAD。公開後設資料響應允許跨域讀取，並聲明五分鐘快取有效期。不涉及憑據或使用者特定資料。

自動操作已安裝App

擷取、轉錄、本地儲存庫取用和筆記寫入在已安裝的 Apple App中執行。請使用文件所述的 捷徑與 URL 協議集成 需經裝置所有者許可。公開資訊 API 不公開擷取操作、錄音、轉錄、私密筆記或目標資料夾。聯繫 Vox.md 支援 咨詢問題。
