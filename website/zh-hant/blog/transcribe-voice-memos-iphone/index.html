iPhone · 語音備忘錄 · Markdown

將 iPhone 語音備忘錄轉錄為 Markdown

Apple 轉錄夠用時，就從它開始。需要 Vox.md 本地轉錄和 Markdown 目標位置時，再匯入音訊。

作者：
Cody Bontecou
更新於
2026 年 10 月 30 日
需要
已儲存錄音 · 後端已就緒
簡短回答

要將 iPhone 語音備忘錄轉成文字，先檢查語音備忘錄是否已有轉錄。如果複製即可完成任務，就直接複製。若要使用 Vox.md 裝置端轉錄和 Markdown 路線，請將錄音匯出到檔案，把音訊匯入 Vox.md，核對轉錄並儲存到所選資料夾。

本指南從 Apple 語音備忘錄中的現有錄音開始。要直接在 Vox.md 中新錄音，請使用 語音筆記存入 Obsidian 指南。操作說明基於文件與源代碼審閱，並非新執行的裝置匯出。

本指南中
  1. 試用 Apple 轉錄文字
  2. 匯出錄音
  3. 準備 Vox.md
  4. 匯入並核對
  5. 驗證 Markdown 檔案
  6. 檢查限制與恢復

1. 檢查語音備忘錄是否已有文字

Apple 文件列出了支援轉錄的 iPhone、語言和地區。在語音備忘錄中選擇錄音，打開其 更多 選單，查找 查看轉錄 或 拷貝逐字稿。如果只需要文字，複製完整轉錄或所選文字，再貼上到筆記即可。

僅為複製 Apple 已提供的轉錄文字，你不需要另裝App。請查閱 Apple 轉錄指南 瞭解目前可用情況。缺少某個選項可能與裝置、系統、語言或地區支援有關；這並不能證明音訊已損壞。

2. 需要 Vox.md 轉錄時匯出音訊

Apple 的 語音備忘錄匯出說明 說明如何選擇錄音、打開 更多 → 共享，並選擇 儲存到檔案。選擇能再次找到的資料夾，再儲存。

普通匯出為 .m4a 錄音。某些選項可以用不同形式保留可編輯圖層或效果。此工作流程先使用普通的扁平化音訊匯出；本指南並不保證每一種分層或可編輯匯出都適用於每個轉錄後端。請保留原始語音備忘錄。

共享音訊檔案與複製 Apple 轉錄文字不同。將音訊匯入 Vox.md 會再次執行其所選轉錄後端；不會匯入 Apple 的轉錄文字，也不保證措辭一致。

3. 準備後端和 Markdown 目標位置

獲取 iPhone 版 Vox.md

  1. 在 Vox.md 中選擇支援裝置和錄音語言的轉錄後端。聯網完成所需模型下載。
  2. 建立或選擇帶可寫 Markdown 資料夾的擷取預設。使用 新筆記 用於首次匯入，方便辨認生成檔案。
  3. 選擇 保留原文 處理，適合只要識別文字、不需要可選 AI 改寫時。
  4. 在快速捕捉語音控制項中選擇 加入草稿 在匯入前選擇，以便核對首次轉錄。

保留原文保留識別文字，不會讓識別變成逐字準確或毫無錯誤。自動模式、Apple Speech 和下載模型有不同裝置與語言要求。請檢查 模型參考 以及已安裝App目前的購買或取用要求，再進行較長音訊的匯入。

使用 Obsidian 時，請選擇通過檔案開放的實際儲存庫資料夾。Vox.md 不直接連接 Obsidian Sync 服務。普通可寫 Markdown 資料夾也適用。

4. 匯入已儲存錄音並核對草稿

  1. 開放 匯入音訊或影片 位於快速捕捉的語音控制項中。
  2. 從檔案中選擇匯出的錄音，等待匯入和轉錄完成。
  3. 選擇加入草稿後，在編輯器中核對轉錄。對照源音訊修正姓名、日期、數字和其他重要措辭。
  4. 確認所選預設和目標位置，然後輕點 發送.

請使用轉錄匯入控制項，不要通過通用檔案附件操作附加檔案。筆記中的音訊附件本身不是轉錄文字。

使用 立即傳送 改為選中時，完成的轉錄可通過所選預設繼續，不經過相同的草稿核對步驟。首次檢查先設定加入草稿。開始匯入前結束任何正在進行的錄音。

5. 檢查實際 Markdown 檔案

等待傳送完成。在檔案或 Obsidian 中打開目標位置，確認檔案、文字和檔名。編輯器中可見轉錄僅證明識別生成了文字，不證明資料夾寫入成功。

虛構錄音可能生成以下筆記正文：

Review the garden plan on Saturday.
Bring the updated measurements.

這是範例輸出，不是真實錄音或準確度測試。檔名、後設資料和格式由預設控制。新匯入的日期或檔名不自動等於原始語音備忘錄的錄音日期。需要時請有意補充該上下文。

一次新筆記匯入成功後，請按照 每日筆記指南 用於滾動目標位置，或 模板方案 用於收件匣或任務條目。將舊錄音傳送到每日日誌前，請匹配目標筆記的日期和路徑。

限制、隱私權和匯入失敗

  • 無法匯入： 完成目前錄音，檢查App取用要求，確認所選預設已啟用。
  • 識別失敗： 檢查後端是否就緒、語言、本地儲存及檔案音訊能否解碼。保留原件，先嘗試簡短普通音訊匯出，再處理較長或特殊檔案。
  • 傳送待處理： 恢復資料夾取用權限，然後重試保留下來的失敗傳送。重新匯入同一備忘錄可能產生第二條擷取記錄。
  • 還需要原始音訊： 單獨配置並驗證音訊保留。不要僅因預設生成文字，就假定它儲存音訊附件。

Vox.md 在裝置上執行轉錄。首次準備後端可能需要下載，檔案提供程式可能需要聯網獲取源檔案或寫入目標位置。如果將音訊或 Markdown 儲存在同步資料夾中，該提供商會自行處理同步。完整的斷網工作流程請按照 離線準備與驗證指南.

此路線不是語音備忘錄資料庫自動同步、批量歸檔匯入器，也不承諾保留 Apple 的編輯、圖層、轉錄時間或錄音後設資料。先從一段錄音開始，保留原件，驗證儲存的文字後再擴展工作流程。
