在 Mac 上本地轉錄音訊檔案為 Markdown

先看免費的內建選項，再看一條本地路徑：從你已有的檔案到 Obsidian 或任意資料夾中的 Markdown 筆記。

作者：
Cody Bontecou
更新於
2026年11月22日
需要
Vox.md：macOS 14 或更新版本 · 已下載的語音模型。Apple 內建轉錄：請參閱 Apple 支援頁面，了解適用於你的 Mac 和語言的情況。
簡短回答

Apple 的語音備忘錄和備忘錄可以在 Mac 上免費轉錄音訊，對許多人來說這就夠了。要把現有的音訊或影片檔案變成 Markdown 筆記，請開啟適用於 Mac 的 Vox.md，選擇 匯入音訊… 從選單列（或在擷取工作區中匯入檔案），讓本地 Whisper 或 Parakeet 模型進行轉錄，檢查文字，然後傳送到路線的筆記。

以下 Apple 的詳情來自 Apple 支援頁面 在 Mac 的語音備忘錄中檢視轉錄 和 在 Mac 的備忘錄中錄製並轉錄音訊，查閱於 2026 年 11 月 22 日。Apple 的頁面可能會變動，請針對你的 Mac 核對。Vox.md 的步驟依據 Mac 文件.

Mac 上已有的免費選項

語音備忘錄

Apple 的語音備忘錄頁面說，你可以按一下 轉錄 按鈕可在錄音時即時檢視文字，或選取已完成的錄音後按一下同一按鈕。你可以在錄音列表中搜尋標題或轉錄中的文字，也可以選取轉錄文字後按住 Control 並按一下，然後選擇 複製。Apple 表示，如果你開啟在 macOS 14 或更早版本中、或在不支援轉錄的裝置上製作的錄音，語音備忘錄會自動轉錄它；音訊轉錄並非在所有國家或地區都可用。

筆記

Apple 的備忘錄頁面介紹了在筆記中錄音：按一下「附件」按鈕，選擇 錄製音訊，錄音，然後按一下「轉錄」按鈕檢視轉錄文字。頁面說明，音訊轉錄適用於搭載 M1 或更新晶片的 Mac，並且裝置語言需在 Apple 該頁面列出的範圍內。如果沒有出現「轉錄」按鈕，Apple 表示你的 Mac 不符合最低要求，或未偵測到支援的語言。

限制

文字會留在這些 App 內，直到你把它複製出來。Apple 表示，在備忘錄中刪除音訊錄音也會刪除轉錄文字。兩款 App 能匯入哪些檔案類型，我們無法從 Apple 的頁面查證，請針對你的錄音自行檢查；本指南對此不作任何說明。

萬不得已時，有人會播放音訊並對著文字編輯器聽寫。這只是變通辦法，不是檔案轉錄；請參閱 Mac 聽寫 了解聽寫本身。

準備適用於 Mac 的 Vox.md

  1. 安裝。 適用於 Mac 的 Vox.md 需要 macOS 14 或更新版本。請透過下方的 App Store 連結取得。
  2. 下載模型。 開放 設定 → 模型 並下載一個：Whisper 從 Tiny (75 MB) 到 Large v3 Turbo (1.6 GB)，Parakeet v2（約 800 MB，英語）或 Parakeet v3（約 800 MB，25 種語言）。在同一畫面上設定轉錄語言。Whisper 在支援的 Mac 上使用 Metal 加速。下載模型是唯一需要連網的步驟。請參閱 Whisper 與 Parakeet 來選擇。 whisper.cpp 執行 Whisper 模型，而 FluidAudio 執行 Parakeet。
  3. 選擇或建立一條路線。 路線包含目標資料夾或儲存庫以及目標筆記：新筆記、滾動的每日筆記，或某個標題下的現有筆記。請參閱 文件中的路線.

已經有字幕檔(.srt 或 .vtt)而不是音訊?你無需轉錄任何內容: SRT 和 VTT 轉文字或 Markdown 轉換器 在瀏覽器中將其清理乾淨。

匯入並轉錄檔案

  1. 匯入。 在 Vox.md 選單列中選擇 匯入音訊…，或將音訊匯入或拖入擷取工作區。文件說明音訊與影片檔案皆可接受，且與錄音使用相同的本機轉錄。關於影片檔案，請參閱 將影片轉錄成文字.
  2. 選擇加入草稿或立即傳送。 使用 立即傳送 轉錄完成後會遞送。使用 加入草稿 你可以先檢查。請對照音訊核對姓名、數字和日期。
  3. 選用：識別演講者。 開啟 識別演講者 在路線上取得匿名、盡力而為的說話人標籤。它首次會準備一個獨立的模型。如果無法執行，會保留純文字轉錄，原因顯示在資料庫中。
  4. 選用：處理模式。 路線可以使用保留原文、潤飾文字、會議記錄、工作清單或自訂指示。Apple Intelligence 模式需要相容 macOS 26 的硬體。沒有時，工作清單和會議記錄使用內建格式化器，而潤飾文字和自訂指示會保留原始文字。
  5. 傳送。 按 Command-Return，將擷取內容傳送到路線的筆記。

檢查 Markdown 筆記

選擇 顯示上次匯出 從選單列，或在資料庫中找到該項目並在 Finder 中顯示，然後在 Obsidian 中開啟檔案。如果只需要文字，請選擇 複製上次轉錄。如需一個可由錄音填入的筆記結構，請參閱 會議記錄範本產生器.

如果錄音是演講的排練，請把逐字稿和錄音長度貼到 演講時間計算器 以測量你自己的每分鐘字數，以及你的講稿依你自己語速所需的說話時間。

哪些內容會離開你的 Mac

轉錄在 Mac 上執行，Vox.md 不會把擷取內容傳送到 Vox.md 伺服器。下載模型會連線到 Hugging Face 或 FluidAudio 的基礎架構。如果目標資料夾透過 iCloud 或其他服務同步，該服務會依其自身條款處理檔案。請參閱 隱私權政策.

故障排查

  • 沒有轉錄，或語言不對。 在設定 → 模型中，檢查模型已下載並選取，且語言已設定。
  • 沒有出現筆記。 檢查路線的目標資料夾，並確認 Vox.md 有權存取它。
  • 較長的檔案需要一些時間。 較大的模型處理長錄音需要更多時間。先試較小的模型，再比較。
  • 沒有有效方案。 錄音、轉錄和擷取需要 Vox.md Unlimited。以 App Store 價格為準；請參閱 方案與價格.
