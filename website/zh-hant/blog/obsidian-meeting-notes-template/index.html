2. 將範本加入 Obsidian

Core Templates 外掛。 在「設定 → 核心外掛」中開啟 Templates，然後設定 Template folder location，例如 Templates。將範本以 .md 檔案格式儲存在那裡。在新筆記中，從命令面板執行 Templates: Insert template ，然後選擇該範本。Obsidian 會在你插入範本時替換 {{title}}, {{date}} 和 {{time}} 。冒號後的格式，例如 {{date:YYYY-MM-DD}}，使用 Moment.js 令牌。參閱 Templates 外掛說明 以及 Moment.js 格式令牌.

Templater 外掛。 從社群外掛安裝 Templater，並設定其 Template folder location。使用以下命令插入範本： Templater: Open insert template modal。要讓 Meetings/ 中的每則新筆記都使用此範本，請開啟 Trigger Templater on new file creation，將 Template matching mode 設為資料夾範本，並將 Meetings 資料夾對應到該檔案。 Templater 設定文件 介紹了資料夾範本，而 date 模組 記錄了 tp.date.now.

屬性。 位於 --- 行之間的 frontmatter 會成為筆記屬性。屬性中的連結必須加上引號，所以 project 欄位寫成 "[[Project name]]"。參閱 屬性 見 Obsidian 幫助。若要檢查你已有的 frontmatter，請使用 屬性產生器和檢查器.

3. 每場會議一則筆記

把會議放在同一個資料夾中，例如 Meetings/，並在檔名中寫入日期和開始時間： Meetings/2026-11-19 1430 Design review.md。按這種順序命名的檔案會依日期排序，同一天的兩場會議也絕不會共用一個檔案。

開啟 連結到每日筆記 （在產生器中），即可新增一行 Daily note: ，連結到當天的筆記。連結使用 YYYY-MM-DD；如果你的每日筆記使用其他日期格式，請改成一致； 每日筆記範本產生器 可預覽某個格式產生的檔案名稱。若還想在每日筆記中列出當天的會議，請從那里連結它們； 追加到 Obsidian 每日筆記 介紹了 Vox.md 如何向每日筆記加入條目。

4. 待辦事項與後續追蹤

把每個待辦事項寫成 Obsidian 任務，例如 - [ ] Send the release notes，完成後將其勾選為 - [x] ；參閱 基本格式語法。把負責人放在最前面，這樣每一行讀起來就是誰做什麼。

如果你的待辦事項已經是普通清單, Markdown 清單產生器 會把它們變成任務,並添加 Tasks、Dataview 或 Reminder 格式的到期日。

如果要整理決議與負責人，而不是工作清單，請把試算表中的列貼到 Markdown 表格產生器 ，然後把結果複製到筆記中。

在筆記中用標註突顯摘要或警告： Obsidian 標註產生器 會寫入 > [!type] 語法，可選擇摺疊。

選用樣式會加入截止日期，格式來自社群 Tasks 外掛: 📅 後接 YYYY-MM-DD。產生器會填入會議日期；請改為實際截止日期。沒有 Tasks 外掛時，表情符號和日期只是一般文字，任務仍然有效。

要把所有會議中未完成的事項彙整到一處，請在筆記中加入一個 Tasks 查詢：

```tasks
not done
path includes Meetings
```

該查詢會列出路徑包含 Meetings的筆記中未完成的任務。如果你已經在用 Dataview，它也能產生類似的清單。

5. 用錄音填入筆記

範本為你提供標題。Vox.md 可以直接寫出筆記：它會錄下會議，在你的裝置上轉錄，並透過路線把 Markdown 檔案儲存到你的儲存庫。

  1. 錄音。 在 Mac 上，Vox.md 可以把一個通話 App 和你的麥克風錄製為獨立的音軌；請依照 在本機將 Mac 會議轉錄到 Obsidian。對於實體會議，請用 iPhone 或 iPad 的麥克風錄音；參閱 將 iPhone 語音筆記儲存到 Obsidian.
  2. 選擇目標位置。 在路線中選擇你的儲存庫，選擇 新筆記，並輸入路徑，例如 Meetings/{date}-{hour}{minute}.md. {date} 會寫成 2026-11-19 和 {hour}{minute} 寫成 1430。這些是 Vox.md 令牌，不是 Moment.js 格式。參閱 Obsidian 擷取範本 ，了解更多路徑範例。
  3. 選擇模式。 將路線的處理模式設為 會議記錄。它會產生 ## Notes 段落，並在轉錄文字包含待辦事項時產生 ## Action Items 清單。在搭載 macOS 26 或 iOS 26 的相容硬體上，它使用 Apple Intelligence；否則由確定性的格式器建立結構。

會議記錄不會替你填寫議程、與會者或決策。如果你想在筆記上方保留這些標題，請在產生器中選擇 純 Markdown ，取消勾選「筆記」和「待辦事項」，然後將結果儲存到你的儲存庫。接著把該檔案選為路線的儲存庫範本。Vox.md 會填入範本中的單大括號令牌，並把處理後的轉錄文字寫在範本下方。在依賴這個版面之前，請先檢查第一則筆記； 路線文件 介紹了目標位置和範本。

如果會議在 Zoom 或 Teams 上進行,而且你已將其逐字稿下載為 .srt 或 .vtt 檔案,請將其轉換為 Markdown(含發言人輪次),使用 SRT 和 VTT 轉換器,然後將其貼到 ## Transcript 此範本的標題。

告訴會議中的每個人你正在錄音和轉錄，並事先徵得他們的同意。規則因地區和工作場所而異；參閱 告知他人你正在錄音.

6. 常見問題

我應該使用 Core Templates 還是 Templater？

Core Templates 隨 Obsidian 提供，涵蓋標題、日期和時間。Templater 是一個社群外掛，增加了指令碼、日期偏移和資料夾範本，因此 Meetings/ 中的新筆記可以自動套用範本。如果你只需要本頁中的欄位，Core Templates 就足夠了。

為什麼 {{date}} 之後不會變化？

Obsidian 只在插入範本時替換一次範本變數。之後筆記中保存的是純文字，例如 2026-11-19，並會一直保持不變。這正是會議記錄所需要的。

Vox.md 可以使用我的 Obsidian 範本嗎？

部分可以。路線可以使用儲存庫中的 Markdown 檔案作為範本。Vox.md 會填入它自己的單大括號令牌，例如 {date}，以及 Templater 日期命令 tp.date.now 和 tp.file.creation_date。它不會執行其他 Templater 命令，例如 tp.file.title，也不會展開核心 Templates 變數，例如 {{title}}，所以不要把它們放進路線的範本。Vox.md 路線請使用純 Markdown 輸出。

產生器會把我的選擇傳送到任何地方嗎？

不會。範本由本頁面中的指令碼產生。它會把你上次的選擇儲存在瀏覽器的本機儲存空間中，下次仍會保留；點按「重設」即可清除。

省去打字的麻煩。

錄下會議，讓 Vox.md 把筆記寫入你的儲存庫。
