從 iPhone 將連結、照片和掃描件儲存到 Obsidian

將源材料放在想法旁邊。把連結、圖片或掃描件傳送到你選擇的 Markdown 目標位置。

作者：
Cody Bontecou
更新於
2026 年 10 月 26 日
需要
iOS 17.6+ · 可寫儲存庫資料夾
簡短回答

將 Vox.md 擷取預設連接到可寫儲存庫資料夾，在快速捕捉中添加 URL、照片、檔案或掃描件，再傳送。預設選擇筆記和附件位置。檢查傳送的 Markdown，確認附件能在 Obsidian 中打開。

儲存連結和儲存文章是不同任務。Vox.md 將網頁 URL 作為 Markdown 連結接收；不要假定添加 URL 就會下載或提取整頁。請按要儲存的材料選擇擷取方式。

本指南中
  1. 準備儲存庫目標位置
  2. 儲存網頁連結
  3. 添加照片、截圖或檔案
  4. 掃描文件並核對 OCR
  5. 檢查附件與同步

1. 準備儲存庫目標位置

在設定 → 擷取預設中建立或選擇已啟用預設，通過檔案連接其目標位置。選擇包含儲存庫 Markdown 檔案的資料夾。如果該資料夾未對其他App開放，Vox.md 不會僅因它在 Obsidian 內可見就能寫入。

第一個範例選擇新筆記和保留原文處理。單獨的收件匣資料夾便於查找混合擷取。以後要將內容加入同一檔案時，可選擇滾動筆記或現有筆記。

在目標位置設定中指定附件子資料夾；預設是 attachments。傳送前檢查解析後的筆記路徑和附件規則。每日日誌請按照 每日筆記路線指南.

2. 儲存網頁連結

複製要保留的 URL。在快速捕捉中使用網頁連結控制項，核對連結文字和地址。簡短說明儲存原因，然後傳送。

一條簡單筆記可能包含以下範例 Markdown：

Read before planning the trip:
[Trail information](https://example.com/trail)

上方地址僅為範例，不是資源推薦。請替換為實際頁面。連結提供返回來源的路徑；如果網站更改或消失，它不會保留來源內容。

Vox.md 分享表單也接受其他App的受支援內容。App共享的可能是 URL、文字或檔案。請檢查收到的內容和所選預設，不要假定來源螢幕上的所有可見內容都已包含。

3. 添加照片、截圖或檔案

  1. 選擇收件匣或項目筆記的預設。
  2. 使用照片或截圖選擇器、相機或添加檔案控制項選擇材料。
  3. 在編輯器中添加簡短標題或說明。
  4. 傳送後在 Obsidian 中打開筆記，檢查嵌入圖片或檔案連結。

圖片嵌入 Markdown 輸出，其他檔案類型使用連結。例如筆記可這樣引用已配置的附件路徑：

## Reference
![[attachments/whiteboard.png]]
[[attachments/brief.pdf]]

這些是範例檔名和路徑；Vox.md 實際輸出取決於所選檔案和目標位置規則。請將引用檔案與儲存庫放在一起。只把 Markdown 檔案移到其他資料夾可能破壞相對連結。

4. 掃描文件並核對 OCR

在擷取列選擇掃描文件，按掃描器操作。Vox.md 保留頁面圖像、建立 PDF，並盡力進行裝置端文字識別。傳送前核對識別文字，尤其是姓名、日期、金額和手寫內容。

對於日誌照片，獨立的提取文字流程支援手動拍攝或選擇的頁面。即使圖像清晰，OCR 也可能遺漏結構或誤讀詞語。以後需核對文字時，請保留源圖片或掃描件。

不希望可選處理改寫擷取文字時，請選擇保留原文。鍵入和混合文字處理需在預設中單獨啟用。 擷取參考 介紹支援的輸入，以及 輸入限制.

檢查附件與同步

傳送後在 Obsidian 中打開筆記，逐個打開連結，確認所需檔案存在。筆記出現在另一裝置上，不證明每個附件都已同步完成。也請在該裝置上檢查圖片或 PDF。

寫入失敗後可在 Vox.md 中保持待處理狀態。建立副本前，先修復目標位置取用並重試現有擷取。即使擷取處理本身在本地進行，雲端提供商儲存的檔案仍可能需要聯網才能取用或同步。

如果需要提取完整網頁，請直接比較相關工具。Obsidian 在以下文件中介紹其原生共享選項： 官方 iOS 指南。可為一項任務用原生共享，為另一項任務用 Vox.md 預設。
