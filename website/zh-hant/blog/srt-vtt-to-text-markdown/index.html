SRT 和 VTT 轉文字或 Markdown 轉換器

貼上或開啟來自 Zoom、Microsoft Teams、YouTube 或轉錄服務的字幕檔,即可取得易讀的文字、Markdown 逐字稿,或另一種字幕格式。檔案在你的裝置上讀取,絕不上傳。

作者：
Cody Bontecou
更新於
2026年11月23日
需要
任何現代瀏覽器,包括 iPhone 上的 Safari。選用:用於 Markdown 輸出的 Obsidian,以及(如果從音訊開始)適用於 iPhone 或 Mac 的 Vox.md。
簡短回答

貼上或開啟 .srt 或 .vtt 檔案,選擇「純文字」或 Markdown,然後複製或下載。檔案始終保留在你的裝置上。

轉換器會移除字幕編號和時間碼,將各行合併為段落,並把說話者姓名轉為筆記中的粗體說話者輪次。它也能在 SRT 與 VTT 之間互相轉換。它使用瀏覽器的 FileReader API 讀取檔案,本頁不會發出任何網路請求,因此你貼上或開啟的內容不會被傳送到任何地方。

1. 使用轉換器

  1. 加入檔案。 將內容貼到方塊中,或選擇一個 .srt, .vtt 或 .txt 檔案。工具會偵測格式並顯示字幕數量。
  2. 選擇輸出。 純文字、Markdown、SRT 或 VTT。
  3. 調整清理選項。 將各行合併為段落、在停頓後另起段落、移除重複的捲動行、移除標籤,並保留或捨棄音效提示,例如 [Music].
  4. 複製或下載。 下載時會使用正確的副檔名: .txt, .md, .srt 或 .vtt.

轉換器需要 JavaScript。未啟用時,下方的說明仍可作為參考。

2. SRT 與 VTT:它們是什麼以及有何不同

兩者都是純文字字幕格式:一系列字幕條目,每則都有開始時間、結束時間和一些文字。美國國會圖書館將其描述為 SubRip (SRT) 格式 作為一種簡單的文字格式,其中每則字幕都有順序編號、開始和結束時間,兩者以 -->,一行或多行文字,以及一個空行。其時間碼為 hours:minutes:seconds,milliseconds。W3C 的 WebVTT 規格 定義了瀏覽器用於字幕的較新格式。

.srt.vtt
第一行第一則字幕的編號WEBVTT
毫秒分隔符號逗號: 00:00:01,000句點: 00:00:01.000
小時一律寫入選用: 00:01.000 允許
字幕編號每則字幕的順序編號選用識別碼
字幕設定無位置和對齊方式可以接在時間戳記之後,例如 align:start
說話者沒有標準標記;人們會寫 Name:語音範圍: <v Name>text</v>
註解無NOTE, STYLE 和 REGION 區塊

轉換格式時,轉換器會執行以下操作:

  • SRT 轉 VTT: 加入 WEBVTT 標頭,並將時間戳記中的每個逗號改為句點。
  • VTT 轉 SRT: 會移除標頭、 NOTE, STYLE 和 REGION 區塊和字幕設定,將句點改為逗號,並從 1 開始重新編號。SRT 沒有語音範圍,因此 <v Name>text</v> 變為 Name: text.
  • 文字編碼: 美國國會圖書館指出,SRT 沒有字元編碼標準,剖析器必須自行偵測。轉換器以 UTF-8 讀取檔案。如果帶重音的字母顯示不正確,請先用文字編輯器開啟檔案並另存為 UTF-8。

3. 從哪裡取得檔案:Zoom、Teams 和 YouTube

請查看各廠商針對你的方案和設定的頁面,因為管理員和帳號類型會影響你能下載的內容。

Zoom 雲端錄影

Zoom 的支援文章 關於雲端錄製的音訊轉錄 指出,逐字稿處理完成後,會以獨立的 VTT 檔案與錄影一同出現。這適用於雲端錄影,且必須為其啟用音訊轉錄。錄影可產生的檔案格式列於 Zoom 的錄製檔案格式指南.

Microsoft Teams 逐字稿

Microsoft 關於下載 Teams 逐字稿的支援文章 指出,預設情況下,主辦者和共同主辦者可以將逐字稿下載為 .docx 或 .vtt 檔案,而且你的 IT 管理員的政策可能會改變誰可以下載它。請選擇 .vtt 並在此處開啟。若要在轉換前修正錯誤,請參見 Microsoft 關於編輯 Teams 逐字稿的指南.

YouTube 字幕

YouTube 說明頁面 關於編輯和移除字幕 說明如何從 YouTube Studio 下載您自己頻道影片的字幕軌。它沒有說明下載產生的檔案格式，因此請貼上或開啟檔案，讓轉換器自動偵測。YouTube 的 支援的字幕檔案類型清單 包含 SubRip (.srt) 和 WebVTT (.vtt)。

請僅下載你有權使用的字幕。本頁不涵蓋他人的影片。

4. 將逐字稿放入 Obsidian 筆記

  1. 選擇 Markdown。 說話者姓名變為 **Name:**,同一說話者的連續字幕會合併為一個輪次。啟用 加入 [mm:ss] 時間戳記 如果你之後想在錄音中找到自己所在的位置。
  2. 啟用 Obsidian 屬性 在頂部加入一個區塊,包含 title, date, source 和 tags. 它是有效的 YAML,寫法遵循 屬性產生器 寫入。Obsidian 會將兩個 --- 標記作為筆記最頂部的屬性;參見 Obsidian 說明中關於屬性的頁面.
  3. 貼到新筆記 在你的資料庫中,例如在 Meetings 資料夾。如果你下載了 .md 檔案,請將其移入資料庫資料夾。
  4. 將其連結到會議筆記。 建立筆記,使用 會議記錄範本產生器,然後加入一行,例如 Transcript: [[Team sync transcript]] 到它。如果從屬性中連結,連結必須加上引號: transcript: "[[Team sync transcript]]".

文字會經過跳脫,因此 *, $ 以及開頭的 # 在 Obsidian 中不會變成格式、數學公式或標籤。說話者姓名來自檔案,分享筆記前請先檢查。

如果筆記中還有表格，例如講者或決議清單，則 Markdown 表格產生器 可根據貼上的試算表儲存格建立表格，並為 Obsidian 跳脫直線字元。

5. 從音訊而非字幕檔開始

如果你只有錄音,根本不需要字幕檔。Vox.md 在裝置上轉錄,並將 Markdown 直接寫入你的資料庫。根據 模型文件,轉錄在 Apple 裝置上執行:在支援的 iOS 26 裝置和語言上使用 Apple Speech,或使用你下載的選用 Whisper 或 Parakeet 模型;參見 Whisper 與 Parakeet 瞭解差異。說話者標籤是 Route 中可選用的步驟,名為 識別演講者,它們是匿名的,而且盡力而為。

  • 在 Mac 上本地轉錄音訊檔案為 Markdown
  • 在本機將 Mac 會議轉錄到 Obsidian

Vox.md 文件並未描述匯入或匯出 SRT 或 VTT 檔案，因此這個轉換器是獨立工具，無需 App 即可使用。沒有字幕檔？你可以 轉錄影片本身 在你的裝置上。

要檢查說話者說得有多快，請先在這裡把字幕轉換成純文字，再把文字和影片長度貼到 演講時間計算器，它用字數除以分鐘數，得出每分鐘字數。

6. 常見問題

這會上傳我的檔案嗎?

不會。你開啟的檔案由瀏覽器透過 FileReader API 讀取,貼上的內容則留在文字方塊中。轉換由本頁中的指令碼完成,使用時頁面不會發出任何網路請求。關閉或重新整理頁面後,文字即消失。

為什麼有重複的行?

自動字幕經常捲動顯示:每則新字幕都會重複上一則的內容再加一行新內容,因此相同的字詞會出現兩三次。請啟用 移除重複的捲動行. 它會移除與上一則字幕中某行完全相同的行。如果說話者確實連續說了兩遍同一句話,該重複也會被移除,因此對於乾淨的人工字幕請保持關閉此選項。

可以保留時間戳記嗎?

可以。選擇「純文字」或 Markdown 後,啟用時間戳記選項,每個段落會以其第一則字幕的時間開頭,形式為 [mm:ss]，或 [h:mm:ss] 一小時之後。若要保留每個字幕時間,請改為轉換成 SRT 或 VTT。

如何把文字轉回 SRT?

本工具不支援這樣做。純文字沒有時間資訊,因此產生 SRT 需要能將文字與音訊對齊的工具。SRT 與 VTT 之間的轉換會保留時間資訊,因為兩種格式都包含時間資訊。

能在 iPhone 上使用嗎?

可以。它使用一般的表單控制項和瀏覽器的檔案選擇器,並且是為了在 iPhone 上的 Safari 中運作而編寫。複製會在 Safari 允許時使用剪貼簿,否則會請你選取文字。
