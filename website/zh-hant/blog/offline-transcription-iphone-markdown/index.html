iPhone · 本地轉錄 · Markdown

在 iPhone 上離線將音訊轉錄為 Markdown

需要之前先準備語音後端和本地目標位置。將轉錄和檔案同步視為獨立選擇。

作者：
Cody Bontecou
更新於
2026年11月8日
需要
後端已就緒 · 資料夾可寫
簡短回答

Vox.md 使用可用的 Apple Speech 後端，或明確下載的 Whisper 或 Parakeet 模型，在裝置上轉錄。離線儲存 Markdown 轉錄文字還需要本地可用、可寫的資料夾。斷網前請準備好兩者。

“本地轉錄”描述識別執行的位置，不承諾模型已安裝、支援所有語言，或雲端資料夾離線可用。本指南解釋設定及你可在自己手機上執行的檢查，並非對每款受支援裝置進行飛行模式測試的報告。

本指南中
  1. 準備語音後端
  2. 選擇 Markdown 目標位置
  3. 錄制或匯入音訊
  4. 離線檢查完整工作流程
  5. 瞭解隱私權與可用性限制

1. 聯網準備語音後端

打開 Vox.md 模型設定，選擇裝置和語言可用的後端。自動模式在支援的 iOS 26 裝置和語言上優先使用 Apple Speech。可選 Whisper 和 Parakeet 模型會在你選擇時下載。

離線前完成模型下載或系統語言準備。自動模式不會悄悄下載 Whisper 或 Parakeet 備用模型，只能使用你已選擇下載的備用模型。如果後端未就緒，斷網並不會讓它變得可用。

明確選擇 Whisper 和 Parakeet 時，錄音停止後轉錄。即時 Apple Speech 可在支援裝置上顯示暫定與定稿文字。生成 Markdown 轉錄無需即時預覽。

模型選擇影響儲存用量、處理時間、語言覆蓋和識別品質。請檢查 模型參考 不要假定更大模型受支援，或某個選項能識別所有語言。

2. 選擇 Markdown 目標位置

建立或選擇擷取預設，並通過檔案連接資料夾。首次測試使用新筆記目標，方便辨認輸出。需要轉錄文字而無需可選改寫時，保留原文處理是不錯的起點。

確保目標位置本地可用且允許寫入。檔案中出現資料夾名，不一定代表內容已下載。若選擇 Obsidian 儲存庫，它必須可通過選擇器供 Vox.md 取用；Vox.md 不直接連接 Obsidian Sync 服務。

詳細資料夾設定請按照 將 iPhone 語音筆記儲存到 Obsidian。普通可寫 Markdown 資料夾也適用；轉錄不要求 Obsidian。

免費下載 Vox.md

試用 15 分鐘轉錄和 10 次成功擷取傳送。無限使用為一次購買、終身有效。請聯網完成購買或模型準備，不要指望新設定能離線完成。

從 Apple 語音備忘錄開始？請按照 語音備忘錄轉錄和音訊匯出選擇器 再匯入錄音。

3. 錄制或匯入音訊

  1. 打開快速捕捉，選擇已準備好目標位置的預設。選擇 加入草稿 在開始前於語音控制項中選擇，以便核對首次轉錄。
  2. 錄制一段簡短語音筆記，或使用 匯入音訊或影片 在語音控制項中選擇現有的受支援檔案。
  3. 等待所選後端完成識別，在草稿中核對轉錄，再輕點傳送。
  4. 檢查傳送已完成，再在目標位置打開 Markdown 檔案。

一段簡短錄音可能生成以下範例筆記正文：

Review the outline before the next meeting.

實際措辭和標點取決於識別和處理。需要參考時請保留源音訊，並對照核對重要轉錄。可選整理功能有自身的裝置要求和回退方式；裝置端轉錄不意味著所有受支援手機都能使用 Apple Intelligence 處理。

離線檢查完整工作流程

聯網擷取成功後，斷網重復一次小測試。使用飛行模式時，也請確認 Wi-Fi 已關閉。

  1. 確認所選後端已準備好，目標位置在本地可用。
  2. 斷網，新錄一段簡短內容，等待轉錄。
  3. 核對併傳送轉錄文字。保持斷網，檢查完成的 Markdown 檔案。
  4. 準備好後重新聯網，單獨檢查同步到其他裝置的情況。

匯入錄音前，也要準備好來源檔案：連線時下載，然後確認離線時仍能開啟。使用一段不含敏感內容的簡短樣本，重複檢查匯入和儲存流程；成功完成一次新錄音，並不能驗證是否可以存取現有檔案。

成功意味著識別和本地寫入均已完成。草稿中可見轉錄文字只證明識別成功；擷取已排隊尚不能證明目標寫入成功。傳送失敗時，保留可恢復的擷取，恢復資料夾取用後重試，不要再複製一份錄音。

瞭解隱私權與可用性限制

Vox.md 不上傳音訊進行轉錄。如果你有意將生成的轉錄或保留音訊儲存到雲端資料夾，提供商可按自身條款同步。不想通過提供商同步該檔案時，請使用本地目標位置。

長錄音、可用儲存、音訊品質和模型支援影響實際結果。本指南不對轉錄速度或準確度作普遍承諾。使用前請核對敏感或可能產生重大影響的措辭。

對於手錶錄音， 仍由配對的 iPhone 執行轉錄和傳送。手機不可用時將錄音留在手錶上，屬於延遲傳送，而不是獨立的手錶轉錄。
