隱私權政策

生效：2026 年 2 月 9 日 · 最後更新：2026 年 10 月 26 日

簡而言之

Vox.md 將擷取草稿、附件、轉錄文字和筆記路線保留在裝置上。完成的檔案僅傳送到你選擇的目標位置，絕不將擷取內容傳送至 Vox.md 伺服器。正式版本傳送下述粗粒度第一方引導分析資料。

概覽

本隱私權政策說明你使用 Vox.md（“我們”“我們的”或“本App”）的 iOS 和 macOS App及其擴展時，我們如何處理資訊。音訊、轉錄文字、按鍵記錄、擷取草稿、附件、匯出檔案內容和使用者輸入文字均在本地處理。檔案僅寫入你選擇的位置；所選儲存提供商可能按其自身條款同步這些檔案。

我們不收集的資訊

Vox.md 不為開發者、分析、廣告或跟蹤收集以下任何內容。下述粗粒度引導後設資料可自動離開裝置。擷取內容僅通過你選擇的功能離開裝置，例如寫入同步資料夾或打開地圖提供商連結，詳見下文。

  • 音訊錄音或語音資料
  • 轉錄文字或轉錄歷史記錄
  • 按鍵記錄、鍵入文字或鍵盤輸入
  • 姓名、電子郵件或電話號碼等個人資訊
  • 供開發者、分析、廣告或跟蹤使用的位置資料
  • 你為本地擷取明確選擇的照片、掃描件、草圖、音訊和檔案
  • 檔名、資料夾路徑、模板文字、匯出筆記內容或模型檔案路徑
  • 廣告標識符、原始 IP 地址儲存或第三方跟蹤標識符

保護隱私權的引導流程分析

正式版本會傳送少量第一方事件，以瞭解引導流程、設定阻礙以及購買或恢復結果。開發版本需明確啟用，才用於設定測試。這些事件刻意保持粗粒度，不用於廣告或跨App跟蹤。

引導流程分析可能包含：

  • 僅用於統計漏斗進度的匿名 Vox.md 安裝 ID
  • 事件名稱，例如引導開始、麥克風權限完成、模型設定完成、付費牆顯示、購買或恢復結果，以及引導完成
  • App版本、構建號、平台和實驗變體
  • 粗粒度的設定狀態，例如麥克風權限狀態、模型引擎和大小分組、檔案匯出格式/模式、免費分鐘數和成功擷取用量分組，以及付費牆上下文

這些分析資料絕不包含音訊、轉錄文字、聽寫文字、按鍵記錄、檔案/資料夾路徑、模板文字、模型檔案路徑、姓名、電子郵件地址、原始日期、原始 IP 地址或裝置名稱。

裝置端處理

所有語音轉文字完全在裝置上進行。在受支援的 iOS 26 裝置上，自動模式使用 Apple 系統管理的 Speech 框架。你也可主動下載本地 Whisper 或 Parakeet 模型。麥克風擷取的音訊由所選裝置端後端處理，絕不通過網路連接傳輸。

如果明確為路線啟用擷取文字處理，符合條件的鍵入文字、裝置端 OCR 和語音轉錄可通過 Apple Intelligence 在本地整理或格式化。裝置端智能不可用時，處理回退到確定性格式或原始文字。Vox.md 不會將擷取文字傳送至自身伺服器或第三方 AI API。

轉錄結果、擷取草稿和重試請求在本地儲存於App沙盒容器及共享 App Group 中。只有簽名的 Vox.md 元件，如App、鍵盤、小工具和共享擴展可取用這些資料。任何 Vox.md 服務或伺服器都無法取用。

鍵盤擴展

Vox.md 包含自訂鍵盤擴展，可在裝置上各App中啟用語音轉文字輸入。Apple 要求我們披露以下鍵盤擴展資訊：

  • 目前鍵盤工作流程需要允許完全取用。 它讓鍵盤使用共享 App Group 狀態，並與 Vox.md 主App協調錄音。
  • Vox.md 不使用完全取用權限上傳、出售或分析按鍵記錄、聽寫文字、轉錄文字或麥克風音訊。鍵盤不會將這些內容傳輸至 Vox.md 或第三方伺服器。
  • 鍵盤擴展通過裝置上的共享 App Group 容器與簽名的 Vox.md App元件通信。

麥克風使用

Vox.md 請求麥克風權限，以擷取音訊進行語音轉錄。麥克風音訊：

  • 由 Apple Speech 或可選下載的 Whisper/Parakeet 模型在本地處理
  • 僅在本地轉錄需要檔案時臨時寫入
  • 絕不傳輸至任何伺服器、API 或第三方服務
  • 轉錄後移除，除非你明確配置路線保留音訊，或將語音錄音插入擷取草稿

位置使用

Vox.md 有兩項明確的位置功能。獨立的擷取列目前位置操作會請求一次位置，並在本地草稿中插入 Google Maps 連結。另外，目前位置預設關閉，可按路線啟用，適用於 iOS/iPadOS、分享表單、捷徑與意圖、語音及鍵盤驅動的路線錄音、小工具與控制項、路線到 Markdown 的 Apple Watch 擷取，以及 Mac。路線可將這一次位置快照用於 {location} 條目模板連結，而無需寫入額外後設資料；寫入位置後設資料需要單獨啟用。手錶僅錄音仍是將原始音訊匯出至檔案，不提供 Markdown 位置內容，也不請求位置。

已啟用的路線根據擷取來源，在傳送、調用或停止錄音時請求一次發起時位置。準確為預設選項。城市精度會在保留結果前將經緯度四捨五入到小數點後兩位，並移除興趣點名稱；所有派生欄位、模板連結和提供商連結都使用同一組按隱私權設定調整後的座標。Vox.md 不持續監測位置，不執行後台位置跟蹤，不在分析或日誌中包含位置，也不將位置傳送至 Vox.md 伺服器。

如果啟用的後設資料需要地點、城市、地區或國家，Vox.md 會使用 Apple 系統反向地理編碼器。僅令牌的目前位置會跳過該查詢。服務免費且無需 API 金鑰，但可能按 Apple 條款向 Apple 發起網路請求。反向地理編碼失敗不會阻止擷取；僅座標後設資料仍可用。Vox.md 可在不聯繫提供商的情況下生成 Apple Maps、Google Maps 和 OpenStreetMap 連結。只有打開連結時，才會向該提供商披露精確或捨入後的座標。

位置不可用時，交互界面可重試、取消、僅本次不帶位置傳送，或為該路線儲存始終不帶位置傳送；已儲存的行為可在路線設定中重置。無人值守的詢問請求會保留發起時位置不可用的結果，供稍後決定，重試時絕不獲取更新的位置。待處理和失敗的請求可能保留已按隱私權設定調整的結果，以供本地恢復。寫入 Markdown 的任何座標都會成為所選筆記的一部分，而你選擇的檔案同步提供商可能按其自身條款處理該檔案。

配置範例和擷取來源行為請參閱 目前位置、 {location}，以及後設資料.

語音模型

Vox.md 不捆綁語音模型權重。Apple 支援的語言資源由 iOS 管理。可選 Whisper、Parakeet 和語音停頓模型僅在你選擇後開始下載，並儲存於裝置本地。準備或下載模型無需帳號或個人資訊。

第三方服務

Vox.md 不集成第三方分析 SDK、廣告網路、崩潰報告 SDK 或跨App跟蹤服務。使用者主動發起的 Whisper 和 Parakeet 模型下載，會直接或通過 FluidAudio 連接 Hugging Face 托管的模型分發設施。模型請求絕不包含擷取草稿、鍵入文字、音訊、轉錄、附件、檔案路徑或位置，但提供商可能按自身條款接收普通 HTTPS 連接資料及請求的模型標識符。

擷取編輯器從以下服務批量請求勵志名言： ZenQuotes API ，並從裝置端快取輪換顯示。這些請求絕不包含擷取草稿、鍵入文字、音訊、附件、檔案路徑、位置、安裝標識符或分析資料。與其他 HTTPS 服務一樣，ZenQuotes 可能按其自身條款接收 IP 地址和使用者代理等技術連接資料。第一方引導流程事件直接傳送至 Vox.md Cloudflare Worker，並依據上述嚴格白名單儲存在其 D1 資料庫中。

資料儲存與刪除

擷取內容和本地App資料——包括轉錄歷史、擷取草稿、暫存附件、已下載模型、模板、設定和免費用量記錄——儲存於裝置本地或你明確選擇的檔案目標位置。不含內容的成功擷取台帳，僅包含最多十次成功請求的計數和隨機標識符，在本地App資料保留期間防止重試被重復扣額。它不包含擷取文字、檔名、目標位置或附件後設資料，絕不存入系統鑰匙圈，也絕不傳送給 Vox.md。

本政策變更前發佈的版本可能在系統鑰匙圈中留下一個不再使用且不含內容的免費用量項目。目前版本不會取用它；可通過鑰匙圈取用將其移除，不影響擷取、轉錄或購買。

本地最近擷取列表僅包含傳送後設資料：結果、來源、路線標識符和顯示名稱、目標位置標識符和顯示名稱、相對筆記路徑、附件數量、時間戳和粗粒度失敗類別。它絕不複製筆記文字、連結、座標、位置標籤或模板、書籤、絕對路徑或附件檔名。待處理和失敗擷取僅保留本地恢復所需內容，其中可能包括已按隱私權設定調整的位置快照或持久化的不可用結果。成功傳送後，可恢復擷取請求立即替換為僅含標識符和時間戳的墓碑記錄；已完成的手錶隊列項同樣會清理，升級會清除舊版已完成請求中的相關資料。

你可以通過以下方式刪除本地儲存的使用者內容和設定：

  • 在App內歷史視圖中刪除單條轉錄或清除最近擷取後設資料
  • 在設定中移除已下載的模型
  • 移除 Vox.md 及其本地App資料。這也會重置免費使用額度；符合條件的 StoreKit 購買仍可通過 Apple 恢復。

兒童隱私權

Vox.md 不會故意收集任何人的個人資訊，包括 13 歲以下兒童。上述保護隱私權的引導流程分析無意識別或聯繫兒童，且絕不包含音訊、轉錄文字、按鍵記錄或使用者輸入的內容。

本政策的變更

我們可能不時更新本隱私權政策。任何變更都會在本頁反映，並更新“最後更新”日期。
