適用於 Mac 和 iPhone 的裝置端 Otter.ai 替代方案

比較雲端機器人方式與裝置端擷取，了解 Vox.md 適合的情境，以及何時 Otter 是更好的選擇。

作者：
Cody Bontecou
更新於
2026年11月23日
範圍
macOS 14+ 或 iOS 17.6+ · 已下載的語音模型
簡短回答

如果你想要在自己的 Apple 裝置上執行、不加入任何通話、並把 Markdown 儲存到你自己的資料夾或 Obsidian 儲存庫的會議與語音轉錄，Vox.md 是一個選擇。如果你需要共用的團隊工作區、網頁入口、Android 或 Windows，請繼續使用 Otter 或其他雲端工具。

本比較由 Vox.md 發布，而這是一款競爭產品。關於 Otter 的陳述僅限於 Otter 自己的 價格頁面 和 說明中心 所述，以 2026 年 11 月 23 日查閱的內容為準，並且由於 Otter 的價格和限制會變動，我們不在此提供。關於 Vox.md 的陳述依據 Vox.md 文件。我們沒有進行任何準確度或速度測試。

Otter 運作方式簡介

Otter 的說明中心介紹，其會議助理名為 Otter Notetaker（早期稱為 OtterPilot），可加入 Zoom、Microsoft Teams 和 Google Meet 會議。連接行事曆後，它可以加入帶有會議連結的行程，你也可以貼上會議連結來加入它。它無法匿名加入：它會以訪客參與者的身分出現在會議中，主持人可能需要放行。請參閱 Otter Notetaker 概覽 和 手動將 Otter Notetaker 加入會議.

Otter 的 價格頁面 列出了多級方案（撰寫時為 Basic、Pro、Business 和 Enterprise）。每個方案都標明了每月轉錄分鐘數、單次對話的最長時間以及同時進行的會議數。這些限制因方案而異且可能變動，因此在決定之前請查看 Otter 的價格頁面了解目前限制。同一頁面還列出了適用於 Mac、Windows、iOS 和 Android 的 Otter App、Chrome 擴充功能以及網頁錄音。

人們尋找替代方案的常見原因

這些是讀者可能有的理由，並非關於 Otter 使用者的統計數據：

  • 通話中出現可見的機器人。 有些人不希望在敏感或非正式的通話中多出一位參與者。
  • 方案限制。 每月分鐘數和單次對話長度因方案而異，用量大的月份或很長的會議可能超出你目前的方案。
  • 音訊在哪裡處理。 有些人更希望錄音保留在自己的電腦或手機上。
  • 筆記就是純檔案。 有些人想要資料夾或 Obsidian 儲存庫裡的 Markdown 檔案，而不是供應商 App 裡的轉錄。

如果以上都不適用於你，你可能不需要切換。

Vox.md 作為裝置端選項

在 Mac 上， 將輸入模式切換為 會議。Vox.md 使用 Apple 的 ScreenCaptureKit 框架 將恰好一個 App 的音訊和你的麥克風錄成兩條獨立音軌，然後在你的 Mac 上用 Whisper（透過 whisper.cpp）或 Parakeet（透過 FluidAudio）。你的麥克風被標記為 你。選用 識別演講者 會為多個遠端聲音加入匿名的盡力而為式標籤。沒有機器人加入通話，也不需要帳號。macOS 會要求螢幕和系統音訊錄製權限，Apple 在以下文件中有說明： 在 Mac 上控制螢幕與系統錄音的取用權限。詳情見 Mac 會議擷取文件 以及 逐步會議指南.

在 iPhone 上， 你可以現場錄音，或匯入音訊和影片，在裝置上轉錄，並可選擇加入說話者標籤。請參閱 將 iPhone 語音筆記存入 Obsidian 和 在 Mac 上轉錄音訊檔.

筆記是標準的 Markdown 檔案，透過路線儲存到 Obsidian 儲存庫或你選擇的「檔案」資料夾。 會議記錄 模式會寫入一個 ## Notes 段落，並在文字包含待辦事項時產生 ## Action Items 清單。它在可用時使用 Apple Intelligence，否則使用確定性格式化器。對於議程和決定等標題， 產生會議記錄範本.

需要了解的 Vox.md 限制：會議擷取無法暫停，且一次只能錄製一個 App；說話者標籤是匿名且盡力而為的；準確度取決於模型和音訊。 Whisper 與 Parakeet 可幫助你選擇模型。

何時應繼續使用 Otter

  • 你需要 Windows 或 Android。 Vox.md 只能在 Apple 裝置上執行；Otter 在其價格頁面上列出了 Windows 和 Android App。
  • 你需要網頁入口或團隊工作區。 Vox.md 沒有共用工作區、網頁入口或即時協作轉錄。其筆記是檔案，需要你自己分享。
  • 你希望有助理替你參加你本人不出席的會議。 Vox.md 沒有從行事曆自動加入的記錄員功能，因為它是在你自己的 Mac 上錄音。
  • 你的會議在 Otter 裡已經運作良好 而且你能接受其方案對時數和長度的處理方式。

用一場會議試試

  1. 從 App Store 下載適用於 Mac 的 Vox.md。
  2. 開啟「模型」畫面，下載一個 Whisper 或 Parakeet 模型。這是唯一需要連線的一次。請參閱 Whisper 與 Parakeet.
  3. 建立一個 會議 寫入你儲存庫中某個資料夾的路線，如果需要 Notes 區段和待辦事項，可搭配會議記錄模式。
  4. 在通話中所有人都同意後錄一次簡短的測試通話，輸入模式設為 會議 並選好通話 App。
  5. 開啟 Markdown 筆記，對照實際發言檢查標籤和措辭。

完整步驟見 在本機將 Mac 會議轉錄到 Obsidian。如果你只有來自 Zoom 或 Teams 的字幕檔， 將 SRT 或 VTT 轉換為 Markdown 在你的瀏覽器中。

錄音禮儀與同意

各地的錄音法規和職場政策各不相同。請告知其他參與者你正在錄音和轉錄，並先取得他們的同意。這不是法律建議。請參閱 告知他人你正在錄音.

常見問題

下載模型後可以離線使用嗎？

可以。錄音和轉錄都在裝置上執行。下載 Whisper 或 Parakeet 模型需要連線一次，說話者模型也只需下載一次。儲存到雲端同步資料夾時，同步依該服務的條款進行。

會加入 Zoom 嗎？

不會。沒有任何東西加入通話。在 Mac 上，Vox.md 會錄製你所選 App（例如 Zoom）的音訊以及你的麥克風。

我能匯入既有的 Otter 匯出檔或音訊檔嗎？

你可以匯入音訊或影片檔進行本機轉錄。文件中沒有說明如何匯入 Otter 匯出檔，因此我們對此不作斷言。對於字幕檔， SRT 和 VTT 轉換器 在你的瀏覽器中執行。

能在 Windows 上執行嗎？

不能。Vox.md 僅適用於 Apple 裝置：iOS 和 iPadOS 17.6+、macOS 14+ 以及 watchOS 10+。
