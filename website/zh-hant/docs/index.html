    01 / 入門

    擷取到 Markdown，不另建筆記孤島

    Vox.md 是本地優先的快速擷取App。它將標準 Markdown 和附件寫入 Obsidian 儲存庫，或你通過檔案選擇的其他可寫資料夾。無需 Vox.md 帳號、外掛程式或托管筆記資料庫。

    完整語音工作流程請 按照 iPhone 語音筆記存入 Obsidian 指南操作，從選擇資料夾到檢查生成的 Markdown。

    正在選擇擷取方式？請閱讀 iPhone 擷取選擇指南 或 比較 Vox.md 與原生 Obsidian.

    平台要求可用內容
    iPhone 和 iPadiOS/iPadOS 17.6+快速捕捉、鍵盤、分享表單、小工具、捷徑、即時活動、歷史記錄和設定
    MacmacOS 14+擷取工作區、錄音/匯入、路線、模型、歷史、選單列和全域快速鍵
    Apple WatchwatchOS 10+本地錄音、路線選擇、同步隊列、僅錄音傳送和複雜功能
    控制中心控制項iOS 18+快速捕捉與識別路線的錄音控制項
    Apple Speech 自動後端受支援的 iOS 26 裝置和語言系統管理的裝置端即時和批量轉錄
    Apple Intelligence 處理相容的 iOS/macOS 26 裝置裝置端整理、結構化輸出和帶回退的自訂指令

    基本工作流程。 選擇路線、連接目標位置，在快速捕捉中鍵入或添加內容，再輕點傳送。路線決定內容如何處理、格式化及放入筆記。

    進行首次擷取

    1. 打開 Vox.md。App直接打開持久化 Markdown 編輯器。
    2. 選擇路線。內置預設路線不可刪除，但可停用。至少保持一個路線啟用，並為它設定目標位置。
    3. 設定其目標位置。輕點 設定目的地，選擇 Obsidian 儲存庫或檔案資料夾，然後選擇新筆記、滾動筆記或現有筆記。
    4. 添加內容。鍵入 Markdown，或添加連結、照片、檔案、掃描件、草圖、位置或語音錄音。
    5. 輕點傳送。Vox.md 儲存到所選路線，並報告 抓捕 送。失敗或排隊中的工作仍可恢復。

    權限與系統取用

    • 麥克風： 語音錄制、本地轉錄、鍵盤聆聽和音訊擷取。快速捕捉可能在首次打開工作區時、開始錄音前顯示此請求。
    • 語音識別： 受支援系統上的 Apple Speech。
    • 檔案資料夾取用權限： 目標位置、模板、匯入和手錶僅錄音輸出。
    • 相機與所選照片： 僅在添加媒體、螢幕截圖、日記照片或掃描件時。
    • 使用期間的位置權限： 僅用於獨立的擷取列目前位置命令，或已啟用位置的路線需要一次發起時位置時。Vox.md 從不持續或在後台跟蹤位置。
    • 通知： 可選的傳送狀態，包括無人值守時的 Apple Watch 失敗記錄。
    • 鍵盤允許完全取用： 是 Vox.md 鍵盤使用共享裝置端App工作流程所必需的。參閱 鍵盤設定.
    02 / 快速捕捉

    一個持久編輯器，容納文字、媒體、檔案和語音

    快速捕捉是 iOS 和 iPadOS 主工作區。路線選單更改目前工作流程；目標位置選單預覽或臨時覆蓋此草稿的傳送位置。底欄也可打開資料庫和設定，並顯示或收起軟體鍵盤。

    持久草稿與安全傳送

    • 文字、附件、所選路線、目標位置覆蓋設定和擷取來源在App掛起及重啓後保留。
    • 編輯在短暫防抖延遲後儲存，App切到後台時立即觸發儲存。
    • 傳送過程中繼續編輯時，新編輯會儲存在新草稿中，不會丟棄。
    • 傳送前必須配置目標位置。編輯器會顯示 目的地未配置 並在需要時提供設定操作。
    • 可安全重試的擷取請求記錄於本地日誌，因此權限、檔案提供商或同步失敗後可以重試。
    • 空編輯器會顯示快取的勵志名言，直到添加文字；即使已選擇路線或附加檔案也一樣。名言請求絕不包含你的草稿。

    以任務為中心的操作演示請參閱 將連結、照片和掃描件儲存到 Obsidian.

    擷取類型

    文字與 Markdown

    在支援感知選區的 Markdown 編輯器中直接寫作，貼上現有文字，並將文字與其他載荷組合。

    網頁連結

    以 Markdown 連結格式添加 HTTP 或 HTTPS URL。

    照片與相機

    選擇照片或截圖，或拍攝新照片。圖片會暫存，並嵌入傳送的筆記。

    檔案

    選擇多個檔案項目。圖片變為嵌入內容，音訊保留為音訊載荷，其他檔案使用 Obsidian 風格連結。

    文件掃描

    用 VisionKit 掃描頁面。Vox.md 保留頁面圖像、建立 PDF，並盡力進行裝置端 OCR。

    日誌 OCR

    手動按快門擷取最多 10 頁日誌，或選擇日誌照片。準確的 Vision OCR 使用自動語言檢測。

    草圖

    在白色 PencilKit 畫布上用黑色畫筆繪圖。Vox.md 儲存可編輯繪圖資料和 PNG 預覽。

    目前位置操作

    請求一次位置，並在草稿中插入經過驗證的 Google Maps Markdown 連結。此獨立擷取列操作不更改任何按路線設定的位置控制項。

    語音與匯入音訊

    在編輯器中錄音或匯入音訊/影片，本地轉錄，再將結果加入草稿或立即傳送。

    無障礙：OCR 顯示“正在此裝置上提取文字”進度橫幅；VoiceOver 會在擷取流程中播報 OCR 進度與完成狀態、“擷取已傳送”和“轉錄已添加到擷取”。

    擷取列

    設定 → 擷取列可調整操作順序或隱藏操作。預設所有操作都可見。

    動作行為
    添加媒體打開草圖、相機、照片、截圖和網頁連結選項。
    添加文件從檔案中選擇多個檔案，與草稿一同暫存。
    掃描文件擷取多頁掃描、PDF、頁面圖像，並盡力進行 OCR。
    摘取文本提供擷取日誌頁面和選擇日誌照片，用於側重 OCR 的擷取。
    九 個撤銷上一次編輯器操作。
    格式 Markdown套用粗體、斜體、井號標籤，或標題 1 至標題 6。
    Markdown 鏈接插入 [link text](url) 並選中可編輯部分。
    內部鏈接插入 Obsidian 風格的 [[Target]] wikilink。
    兩日期設置使用今天、明天或本週末；可選時間；以及 ±15m、±30m 或 ±1h 調整。插入 (@yyyy-MM-dd) 或帶時間的形式。
    檢查名單App Markdown 任務前綴 - [ ].
    子彈列表App Markdown 項目符號前綴。
    麵包將剪貼簿文字貼上到目前選區。
    草圖打開可編輯的 PencilKit 草圖擷取。
    目前位置請求一次位置，並插入 Google Maps 連結。
    插入時刻表將本地時間和日期插入為 h:mm a yyyy-MM-dd.
    插入日期插入 yyyy-MM-dd.
    修改案例文本提供小寫、大寫、句首大寫、每詞首字母大寫和轉為 slug。

    格式處理尊重目前選區、規範化換行、限制無效選區範圍，並避免拆開 emoji 等組合字符。

    內嵌語音控制項

    • 輕點語音按鈕開始或停止。長按約 0.45 秒顯示詳細控制項。
    • 錄音時， 暫停 按鈕位於語音按鈕旁邊——輕點一次暫停，再點一次繼續。最終筆記仍為一段錄音，不包含暫停期間的音訊和時長。暫停也會停止即時轉錄預覽和語音自動停止功能，直到你繼續錄音。
    • 加入草稿 追加完成的轉錄文字。 立即傳送 執行所選路線及其目標位置。
    • 預設選擇立即傳送 位於 iOS 和 Mac 擷取工作區中。通過以下方式打開 iOS 語音操作： voxboard://capture?action=voice 將該錄音切換為加入草稿。
    • 該 音頻 選項可按要求將源錄音保留為草稿的一部分。
    • 音頻進口 接受音訊或影片檔案，並使用相同的本地轉錄管線。
    • 識別演講者 是針對錄音和匯入音訊、需主動啟用的路線語音處理步驟。首次使用會準備獨立說話人模型，在本地盡力添加匿名標籤；無法執行時保留純轉錄，並在資料庫顯示原因。
    • 自動模式可在錄音時，直接在可編輯的編輯器中顯示 Apple Speech 已定稿和暫定的文字。明確選擇的 Whisper 和 Parakeet 模型在錄音停止後轉錄。
    • 轉錄失敗不會破壞源錄音；它仍可恢復。
    • 只有明確啟用時，持續鍵盤聆聽才會跨啓動保留。一次性App錄音會將音訊會話恢復為空閒狀態。

    擷取輸入限制

    每次請求最多包含 100,000 個字符 共享文字， 10 個共享項目，以及 250 MB 的暫存資源總量。照片和截圖選擇器最多接受 10 項；日誌擷取最多接受 10 頁。Vox.md 會拒絕超限輸入，而不會悄悄丟棄項目。

    03 / 路線

    儲存完整工作流程，不只是資料夾

    路線儲存擷取的含義、是否處理文字、如何處理後設資料和音訊，以及 Markdown 的確切寫入位置。路線適用於鍵入文字、連結、媒體、掃描件、檔案、草圖、語音、捷徑、小工具、分享表單、手錶和 Mac。

    建立和管理路線

    • 打開設定 → 路線，建立、重命名、啟用、停用自訂路線，為其選擇圖示或刪除。
    • 可搜尋圖示選擇器將符號分為寫作、語音、任務、個人和工作類別。
    • 已停用的路線不在常規選擇器中顯示。內置預設路線不可刪除。
    • 內置預設路線使用波形符號，提示為 擷取想法、任務、連結、檔案、掃描件或錄音。, type: capture 後設資料、整理行文處理，關閉鍵入文字處理，關閉音訊儲存。
    • 新的自訂路線初始為 自訂路線，使用滑塊圖示和 想擷取什麼？ 提示，初始選擇自訂指令，但關閉鍵入/混合文字處理。

    處理模式

    模式結果回退行為
    保留原文保留擷取文字，不進行 AI 改寫。傳送原始文字。
    潤飾文字整理大小寫和標點，同時保留含義與 Markdown。裝置端增強不可用時保留原文。
    工作清單生成 Markdown - [ ] 任務項。確定性的清單格式器。
    會議記錄生成 ## Notes 節，以及存在時的 ## Action Items.確定的會議筆記結構。
    自訂指示可用時使用裝置端 Apple Intelligence 遵循你的指令。指令無法在本地執行時保留原文。

    語音轉錄使用所選路線模式。 應用於捕捉文本 是預設關閉、需單獨啟用的選項，允許處理鍵入的 Markdown、OCR 和其他帶文字的混合擷取。保持關閉可防止意外改寫已編寫的 Markdown。傳送前儲存確切的已處理請求，因此重試不會依據變化後的設定重新處理。

    元素

    • 將靜態後設資料輸入為一個 key: value 鍵值對，每行一對，例如 tags: [journal, idea].
    • 筆記 frontmatter 在文件範圍寫入後設資料。
    • 行內條目欄位 寫入 key:: value 欄位放在滾動筆記的每個條目旁邊。
    • 可用時，裝置端增強可在靜態路線後設資料之外添加標題、標籤、類別和整理後文字。

    主動啟用的位置功能

    目前位置預設關閉，且屬於各個路線。啟用後，Vox.md 在擷取發起時請求一次位置：iOS/iPadOS、分享表單、深層連結/編輯器、Mac 及打開編輯器的系統操作在傳送時請求；直接入隊的文字、連結和檔案意圖在調用時請求；即時語音、鍵盤驅動路線錄音、小工具/控制項錄音或通過普通擷取傳送的 Apple Watch 錄音在停止時請求。手錶僅錄音是原始音訊檔案匯出，沒有 Markdown 位置內容，也不請求位置。Vox.md 絕不持續監測位置，絕不執行後台位置跟蹤。

    設定項行為
    使用目前位置為此路線請求一次發起時位置，並支援 {location}。它不會自動寫入後設資料。
    準確（預設）保留按隱私權設定調整的原始定位結果，所選後設資料需要時可包含興趣點名稱。
    城市將經緯度四捨五入到小數點後兩位，並省略興趣點名稱。所有派生欄位和連結使用這些捨入座標。
    寫入位置後設資料單獨啟用結構化或進階後設資料，除此之外還可使用任何 {location} 條目模板連結。
    結構化字段選擇並重命名座標、緯度、經度、地點、城市、地區、國家、Apple Maps、Google Maps、OpenStreetMap、 geo: URI、精度、時間戳、來源和擷取 ID。
    進階 YAML 模板為筆記 frontmatter 使用經過驗證且有邊界限制的 YAML。它無法替換無關 frontmatter，也不適用於行內條目欄位。

    啟用寫入位置後設資料後，文件範圍將各結果按擷取 ID 追加至配置的 frontmatter 集合。同一筆記可保留多個位置，而冪等重試不會重復追加同一位置。條目範圍則將所選結構化欄位渲染為 key:: value 放在該擷取條目旁邊。

    只有啟用的後設資料欄位需要時，地點、城市、地區和國家才使用 Apple 系統反向地理編碼器。僅令牌位置會跳過反向地理編碼。該服務免費且無需 API 金鑰，但可能需要網路連接；查詢失敗時，擷取繼續使用僅座標後設資料。條目前後綴和儲存庫 Markdown 模板可使用 {location} 從路線可用且已按隱私權設定調整的快照插入可點擊的 Google Maps 連結，無需啟用後設資料輸出；目前位置關閉或不可用時，令牌為空。生成提供商連結不會聯繫 Apple、Google 或 OpenStreetMap。打開連結會向該提供商披露連結中儲存的同一組精確或捨入後的座標。

    新路線和此前停用位置的路線保持兩項控制項關閉。原來寫入位置後設資料的路線在升級後保持兩項開啟，以保留現有輸出。

    完整目前位置指南

    參閱 目前位置、 {location}，以及後設資料 瞭解設定方案、範例、擷取來源時機、遷移行為、隱私權和故障排查。

    位置不可用

    交互界面可重試、取消、僅本次不帶位置傳送，或選擇 始終不帶位置傳送 為該路線設定。在路線位置設定中重置已儲存的選擇。無人值守的 詢問 擷取會持久保留發起時位置不可用的結果，直到你決定；重試和恢復絕不重新獲取稍後位置。

    Markdown 目標位置

    每個路線都有一個以 Obsidian 儲存庫或可寫的檔案資料夾為根的目標位置。

    新筆記

    為每次擷取建立獨立 Markdown 檔案，可使用令牌，例如 {timestamp}, {date}, {time}, {year}, {YR}, {month}, {day}, {id8}，以及 {id}.

    滾動筆記

    追加到每日、每周、每月、每季度或每年筆記。路徑也支援 {period} 和 {week}。新目標位置的預設值為 Journal/{period}.md 以每日為週期。

    現有筆記

    選擇所選儲存庫或資料夾內已有的 Markdown 檔案。Vox.md 會驗證目標始終安全地位於該根目錄內。

    完整路線方案請參閱 向 Obsidian 每日筆記追加文字和語音.

    使用收件匣、日誌或任務模板方案 以保持條目格式可預測。

    放置位置、標題和模板

    • 底部 追加； 頂部 前置插入； 頭條 插入到所選的 1 至 6 級標題下。
    • 如果缺少標題，請選擇 顯示錯誤 或 創建頭條.
    • 使用儲存庫中的即時 Markdown 模板檔案、可重複使用條目模板，或自訂前後綴文字。
    • 條目格式支援 {date}, {time}, {hour}, {minute}, {second}, {timestamp}, {year}, {YR}, {month}, {day}, {week}, {source}, {id8}, {id}，以及 {location}.
    • 預設附件子資料夾為 attachments.
    • 保護迴歸，預設關閉，會寫入可見的 vox-capture HTML 注釋，以便檢測重復重試。
    • Vox.md 拒絕絕對路徑、反斜槓、路徑遍歷、不安全名稱和符號連結越界。

    單次擷取覆蓋設定

    目標位置控制項可使用路線預設值、將本次擷取放在頂部或底部、套用一次性條目模板，或選擇同一儲存庫中的另一筆記。 使用路線的目標位置預設設定 移除覆蓋設定。這些選擇僅影響目前草稿，絕不修改路線。

    音訊保留與相容匯出

    • 音訊儲存模式為 關閉, 筆記旁邊，或 附件文件夾.
    • Markdown 可在頂部或底部嵌入保留音訊，使用 Obsidian 語法，例如 ![[recording.m4a]].
    • 對於未使用統一 Markdown 目標位置的舊版直接語音配置， 將筆記儲存至檔案 支援 TXT、MD、JSON 和 YAML；新建檔案或追加；包含模型和語言的檔名令牌；Markdown 模板；Obsidian Bases 選項；可選 YAML 屬性；以及可選的 .md 擴展名，用於 YAML。
    • 相容匯出設定僅適用於路線沒有統一擷取目標位置時的直接語音執行。
    04 / 模型與轉錄

    選擇系統後端或可選本地模型

    所有轉錄都在 Apple 裝置上執行。自動是 iOS 預設模式。可選的 Whisper 和 Parakeet 模型檔案僅在你請求時下載，可選擇、在下載中取消或之後刪除。

    準備離線轉錄工作流程 使用本地後端和可寫目標位置。

    可用轉錄選項

    選項大致大小最適合
    自動化系統管理在受支援的 iOS 26 裝置和語言上優先使用 Apple Speech；僅回退到你明確下載的本地模型。
    Whisper Tiny75 MB下載最小、速度最快的 Whisper 選項。
    Whisper Base142 MB均衡的小型本地模型；舊版 Mac 預設模型。
    Whisper Small466 MB更高準確度，代價是更多儲存和處理開銷。
    Whisper Medium1.5 GB較大的多語言 Whisper 模型。
    Whisper Large v3 Turbo1.6 GB可用的最大 Whisper 選項。
    Parakeet v2~800 MB針對英語優化的 Core ML/FluidAudio 模型。
    Parakeet v3~800 MB支援 25 種語言的 Core ML/FluidAudio 模型。

    自動模式如何工作

    • 在受支援的 iOS 26 裝置上，自動模式檢查 Apple 系統管理的所選語言語音識別器，並在需要時準備語言資源。
    • 系統語言 遵循裝置語言。錄音使用其他語言時，請選擇具體語言。
    • 自動模式絕不悄悄下載 Whisper 或 Parakeet 備用模型。它只能使用你之前選擇下載的模型。
    • 即時 Apple Speech 區分可安全插入的已定稿文字與仍可能變化的暫定文字。
    • 明確選擇 Whisper 和 Parakeet 時，音訊段結束後批量轉錄。

    語言

    • Whisper: 自動檢測、英語、西班牙語、法語、德語、意大利語、葡萄牙語、荷蘭語、波蘭語、俄語、中文、日語、韓語、阿拉伯語、印地語、土耳其語、越南語、泰語、烏克蘭語、瑞典語、丹麥語、挪威語和芬蘭語。
    • 自動： 系統語言，以及 Whisper 明確列出的語言，前提是 Apple 支援該語言區域。
    • Parakeet v2: 英語。
    • Parakeet v3: 保加利亞語、克羅地亞語、捷克語、丹麥語、荷蘭語、英語、愛沙尼亞語、芬蘭語、法語、德語、希臘語、匈牙利語、意大利語、拉脫維亞語、立陶宛語、馬耳他語、波蘭語、葡萄牙語、羅馬尼亞語、斯洛伐克語、斯洛文尼亞語、西班牙語、瑞典語、俄語和烏克蘭語。Parakeet 工作流程會自動檢測語言。

    Parakeet 鍵盤自動停止

    可選的約 1 MB 語音休息檢測器 模型可在靜音後停止明確選擇的 Parakeet v2 或 v3 鍵盤錄音。啟用 讓 Parakeet 在停頓後停止 ，選擇約 0.5、0.75、1、1.5 或 2 秒。輔助模型可用後預設啟用，暫停閾值為 0.75 秒。自動和 Whisper 仍需手動停止。

    本地音訊行為

    • Whisper 輸入會規範化為 16 kHz 單聲道、16 位音訊。
    • iOS 持續聆聽使用 10 分鐘環形緩衝區，音訊段開始時包含兩秒預錄。
    • Whisper 使用 whisper.cpp；Parakeet 使用 FluidAudio 和 Core ML。Whisper 在 Mac 上使用 Metal 加速。
    • 模型下載需要網路連接，但所選後端就緒後，轉錄在本地執行。
    05 / iOS 鍵盤

    直接在正在編輯的文字框中聽寫

    Vox.md 鍵盤可用於資訊、備忘錄、郵件、Safari、Slack 及其他接受標準 iOS 鍵盤的App。語音工具欄位於 KeyboardKit 佈局上方，通過私有共享 App Group 與 Vox.md 主App通信。

    設定鍵盤

    1. 在 Vox.md 中準備轉錄。在受支援裝置上保持選擇自動，或在設定 → 模型中下載並選擇 Whisper 或 Parakeet。
    2. 添加鍵盤。打開 iOS 設定 → 通用 → 鍵盤 → 鍵盤 → 添加新鍵盤，選擇 Vox.md。
    3. 開啟允許完全取用。目前鍵盤工作流程需要此權限，以使用共享 App Group 狀態，並與主App協調錄音。
    4. 切換鍵盤。打開文字框，用地球鍵選擇 Vox.md，再輕點麥克風。
    完全取用在這裡做什麼

    iOS 對該權限的描述很寬泛。Vox.md 將它用於裝置端App/鍵盤工作流程、共享狀態和可選觸覺回饋。Vox.md 不會將按鍵記錄、聽寫文字、轉錄文字或麥克風音訊上傳至 Vox.md 伺服器。請參閱 隱私權政策.

    語音工具欄與插入

    • 工具欄顯示目前後端、狀態、錄音時長、即時波形和麥克風/停止操作。
    • 上一個和下一個控制項可循環切換可用的已下載後端。
    • 如果尚未開始聆聽，鍵盤會打開 Vox.md 一次，開始聆聽，並可讓你返回原始文字框。
    • 自動模式會在你說話時插入已定稿的轉錄增量；暫定詞語僅供顯示，直到 Apple 將其定稿。
    • 使用 Whisper 或 Parakeet 時，停止或自動停止該段後才會插入完整轉錄。
    • 插入中斷或掛起時，待處理文字會持久儲存，在下次鍵盤出現時重試。
    • 工具欄報告的狀態包括 開放 Vox.md, 轉載...，以及 啟用完全取用.

    鍵盤自訂

    • 觸覺回饋 預設啟用，可在 Vox.md 設定中更改。
    • 英語、德語、西班牙語、法語、意大利語、葡萄牙語、荷蘭語、瑞典語、丹麥語和挪威語支援長按顯示替代字符。
    • 明確選擇 Parakeet 的使用者可在設定 → 模型中添加基於停頓的自動停止。
    • 15 分鐘免費轉錄額度同時適用於鍵盤聽寫、App錄音和匯入。
    06 / 系統集成

    從分享表單、主畫面、鎖定畫面或捷徑開始擷取

    共享擴展

    iOS 分享表單操作名為 擷取至 Vox.md。它接受文字、HTTP/HTTPS URL、圖像、檔案和影片，受共享項目與資源限制約束。選擇路線和目標位置，可選添加備注，然後傳送。如果路線使用目前位置，共享會在此次傳送時請求一次發起時位置，無論是否啟用後設資料輸出。內容暫存於私有 App Group，持久排隊，並在 Vox.md 中打開以傳送。如果傳送需要主App，請使用 開放 Vox.md.

    主畫面與鎖定畫面小工具

    快速捕捉

    打開持久化 Markdown 草稿。中型和大型小工具提供筆記、照片、截圖、相機、檔案、連結、掃描、草圖和語音操作。

    快速記錄

    啓動配置的錄音流程，並在支援的主畫面和鎖定畫面系列中反映就緒、聆聽或停用狀態。

    在設定中關閉鎖定畫面錄音按鈕，即可顯示關閉狀態，而不立即開始錄音。

    控制中心、即時活動和靈動島

    • 在 iOS 18+ 上，從控制中心添加可用的 Vox.md 擷取和錄音控制項。配置已安裝版本提供的路線和選項。
    • 使用錄音控制項前，請先在 Vox.md 中完成麥克風、模型和目標位置設定。根據 iOS 和已安裝App的版本，錄音操作可能會打開App。依賴後台擷取前，請先在裝置上測試一段簡短錄音。
    • 該 即時動態監控 設定控制鎖定畫面和靈動島上的錄音狀態及錄音/停止操作。
    • 即時活動狀態包括錄音中、計時器、處理中、就緒、錄音和停止。
    • 即時活動從 iOS 17 起可用；控制中心控制項需要 iOS 18。

    捷徑與 App Intents

    路線在捷徑和受支援控制項中顯示為可選實體。啟用使用目前位置後，直接入隊的文字、連結和檔案意圖在調用時請求位置；打開快速捕捉的操作在傳送時請求；錄音操作在停止錄音時請求。後設資料輸出不改變這一時機。如果無人值守的 詢問 請求無法獲取位置時，會保留其發起時位置不可用的結果，以供稍後決定，而不會重新獲取。請使用已安裝 Vox.md 版本提供的操作。擷取操作包括：

    • 快速捕獲
    • 記錄捕獲
    • 拍攝一個屏幕
    • 收集文本到 Markdown
    • 抓住鏈接 Markdown
    • 捕捉文件 Markdown

    操作按鈕錄音設定

    先打開 Vox.md，授予麥克風權限、準備轉錄後端並將路線連接到目標位置。在捷徑中添加可用的 Vox.md 擷取操作並選擇路線。手機解鎖時執行捷徑，確認儲存到預期筆記，再通過設定 → 操作按鈕 → 捷徑分配它。

    可用操作和後台錄音行為取決於已安裝版本及 iOS。使用裝置捷徑中顯示的操作。如果錄音需要App打開，請打開 Vox.md 錄音。捷徑出現在選擇器中，並不保證可在鎖定手機上錄音。

    深層連結

    Vox.md 註冊了 voxboard:// URL 協議。查詢值請使用 URL 編碼。

    URL行為
    voxboard://capture打開持久化快速捕捉編輯器。
    voxboard://capture?action=photos打開照片選擇器。其他操作： screenshots, camera, files, scan, sketch, link，以及 voice.
    voxboard://capture?text=...打開帶有限長度文字的草稿。
    voxboard://capture?url=https%3A%2F%2F...打開帶 HTTP/HTTPS 連結的草稿。
    voxboard://capture?route=...選擇已啟用路線。它可與受支援的操作、文字或 URL 組合。
    voxboard://capture-request?id=...領取系統擴展或意圖建立的持久請求。
    voxboard://listen啓動鍵盤聆聽啓動流程。
    voxboard://record舊版錄音入口已重定向到聆聽。
    voxboard://widget-record舊版小工具錄音入口。

    未知或重復參數、格式錯誤的 UUID、不安全路線標識符、非 HTTP URL 和超過共享限制的文字會被拒絕。

    07 / Apple Watch

    在手錶本地錄音，再通過 iPhone 傳送

    按照 Apple Watch 到 Obsidian 設定指南操作 瞭解路線選擇、傳輸和傳送檢查。

    錄音工作流程

    • 手錶App顯示就緒、錄音中、已暫停、同步中、已排隊、轉錄中、儲存中、已傳送和需要關注等狀態。
    • 使用錄音、暫停/繼續、停止、取消、同步和重新整理。暫停讓你整理思路而不拆分筆記——暫停期間計時器凍結，且該時段不計入錄音。取消會明確刪除本地錄音，而非同步。
    • 錄音在本地以日誌方式記錄，中斷或崩潰後可恢復。
    • 錄音會保留在手錶上，直到 iPhone 確認傳送或丟棄。
    • 對於啟用使用目前位置且通過普通擷取傳送的路線，手錶會在錄音停止時請求一次源自手錶的位置，並將按隱私權設定調整後的結果隨路線快照一同傳輸。iPhone 絕不替換為自身位置。僅錄音會跳過位置，因為它只匯出原始音訊，沒有 Markdown 內容。

    手錶上的路線

    從手錶的以下位置選擇已啟用的 iPhone 路線： 路線 卡片。Vox.md 隨錄音傳輸安全快照。如果 iPhone 不可用，請求的選擇會保持待定，最近確認的路線仍處於活動狀態。

    iPhone 上的手錶錄音隊列

    iPhone 隊列顯示錄音時間、時長、路線、處理狀態和傳送操作。失敗項目可重試、更換路線、丟棄或不帶轉錄文字進行擷取。丟棄會移除保留的音訊和排隊傳送。

    僅錄音輸出

    • 將路線輸出設為 僅錄音 將 M4A 音訊複製到檔案資料夾，不進行轉錄或 AI 處理，也不消耗轉錄額度。
    • 預設檔名模板為 recording-{timestamp}-{id8}.
    • 使用路線前，先在 iPhone 上選擇一次錄音資料夾。
    • iOS 可能延遲後台傳送。強制退出 Vox.md 會阻止傳送，直到再次打開App。

    複雜功能與小工具

    該 音頻記錄 複雜功能支援圓形、矩形、行內和角落系列。它可打開或切換手錶本地錄音，並顯示計時器或隨狀態變化的標籤。

    08 / Mac 配套App

    在 macOS 上使用同一擷取系統

    Mac App有擷取、資料庫和設定頁面，並共享 iOS 所用的本地模型、路線、路線、匯出和重試架構。

    擷取工作區

    • 鍵入和編輯 Markdown，貼上或拖放檔案、圖像和音訊。
    • 使用內置、外接或連續互通相機裝置的相機輸入。
    • 匯入掃描件或 PDF，用滑鼠、觸控板或連接的數位板畫草圖，並添加連結、wikilink、截止日期和文字轉換。
    • 使用以下方式錄音： 加入草稿 或 立即傳送；可選在草稿模式下保留音訊。
    • 暫停 和 繼續 在狀態欄操作麥克風錄音。暫停音訊不計入錄音，因此一條最終筆記可以分段錄制。會議擷取不支援暫停。
    • 匯入音訊或影片進行本地轉錄。
    • 按 Command-Return 傳送擷取。啟用使用目前位置的路線會在傳送或停止錄音時請求一次 Mac 發起的位置，無論是否啟用後設資料輸出。
    • 目標位置設定橫幅和路線檢查器顯示所選路線解析出的筆記及放置位置。

    分軌擷取會議

    將輸入模式選擇器從 麥克風 到 會議 將 Mac 上某個App播放的聲音和自己的麥克風錄為兩路清晰分離的音軌。Vox.md 以單App模式使用 ScreenCaptureKit，因此你只選擇一個App，且絕不會擷取 Vox.md 自身。

    • 錄音時，狀態欄顯示系統和麥克風即時電平表、各來源狀態，以及擷取警告。
    • 兩路音軌都以持久分塊和恢復清單寫入，因此即使中斷——資料流停止、麥克風拔出或強制退出——也能安全收尾，會議仍可轉錄。下次錄音隊列恢復時，會自動恢復中斷的會話。
    • 停止後，各音軌在裝置上獨立轉錄，結果在同一時間線上交錯排列：你的麥克風顯示為 你，App音軌則標記為遠端說話人。可選的說話人識別還能進一步區分多個遠端聲音。
    • 兩路音軌的回放混音儲存為錄音音訊，完成的轉錄與其他錄音一樣，遵循你的路線、加入草稿或立即傳送及剪貼簿設定。

    全域快速鍵

    設定 → 全域快速鍵可為以下操作分配快速鍵： 轉載到 Clipboard, 所選路線，或任意已啟用路線。快速鍵預設關閉，需要非修飾鍵加 Control、Option 或 Command，也可包含 Shift，且會拒絕衝突。再次按活動快速鍵可停止錄音。

    轉載到 Clipboard 不建立筆記、資料庫項目或保留音訊。它用於向任意 Mac App快速聽寫。

    選單列與App可見性

    • 可見性選項為 門戶 + 菜單 （預設）， 菜單 只 酒吧, 只用Dock，以及 隱藏.
    • 選單列顯示錄音、轉錄和匯出狀態。
    • 選單操作包括開始錄音、停止 + 轉錄、匯入音訊…、複製上次轉錄、顯示上次匯出、路線選擇、顯示擷取、顯示資料庫、顯示資料資料夾和退出 Vox.md。
    • 在 Mac App中按 Control-B，在可點擊控制項上顯示鍵盤提示。

    Mac 歷史與模型

    搜尋、重新載入、清除、複製或刪除本地歷史；打開整理後和原始轉錄詳情；在 Finder 中顯示已傳送筆記。模型界面可下載、選擇和刪除 Whisper 或 Parakeet 模型，並更改轉錄語言。Whisper 在受支援的 Mac 上使用 Metal 加速。

    09 / 資料庫、設定與隱私權

    恢復工作、管理本地資料、解鎖無限使用

    iOS 統一資料庫

    • 資料庫將本地語音轉錄和擷取傳送記錄整合為一個可搜尋列表。
    • 搜尋原始文字、整理後文字、標題、標籤和類別；下拉重新整理。
    • 複製整理後或原始轉錄文字，編輯轉錄後設資料和文字，或通過分享表單匯出 Markdown 副本。
    • 刪除一條轉錄，或清除所有本地歷史記錄。清除歷史不會刪除已寫入目標位置的 Markdown 筆記或附件。
    • 重試排隊擷取，檢查粗粒度來源、路線、目標位置、筆記路徑、附件數量、時間、結果和失敗類別。
    • 轉錄編輯包含標題、標籤、類別、整理後文字和原始轉錄。

    私人活動國家

    打開設定 → 活動 → 統計，查看累計用量：錄音與擷取總數、錄音時長和附件數量，以及最近七天圖表和擷取來源細分（App、鍵盤、分享表單、小工具、捷徑、Apple Watch、Mac、深層連結、檔案匯入和語音）。

    • 統計僅計算已傳送擷取；新活動後下拉重新整理。
    • 台帳保留在裝置上，不儲存擷取內容、檔名或目標位置。

    哪些內容留在本地

    擷取內容

    草稿、文字、連結、模板、路線、附件、音訊、OCR 和轉錄文字不會傳送到 Vox.md 伺服器。

    處理

    Apple Speech、Whisper、Parakeet、Vision OCR 和受支援的 Apple Intelligence 處理在裝置上執行。

    你的目標位置

    完成的檔案僅存入你選擇的資料夾。第三方檔案提供商可能按其自身條款同步。

    • 成功傳送後，可恢復擷取請求變為不含內容的回執，已完成手錶隊列項僅保留粗粒度最終傳送欄位。兩者都不保留座標、標籤、提供商 URL、位置模板或路線載荷。
    • 已完成擷取歷史僅儲存傳送後設資料，不儲存筆記文字、URL、座標、位置標籤或模板、書籤、絕對路徑或附件檔名。
    • 待處理和失敗項目僅保留本地恢復所需內容，可能包括路線快照及其已按隱私權設定調整的位置或不可用結果。
    • 正式版引導分析預設禁用。App不包含第三方分析 SDK、廣告網路或跨App跟蹤器。
    • 編輯器從 ZenQuotes 獲取並快取勵志名言，不傳送草稿內容或標識符。

    完整的資料處理、保留和第三方服務詳情請閱讀 隱私權政策.

    10 / 故障排查

    常見設定與傳送問題

    擷取無法傳送

    打開目標位置控制項，配置所選路線。如果資料夾已移動或取用權限過期，請重新選擇儲存庫/資料夾。排隊工作仍可在資料庫中找到。

    鍵盤提示啟用完全取用

    打開 iOS 設定 → 通用 → 鍵盤 → 鍵盤 → Vox.md，開啟允許完全取用。返回App一次，讓 Vox.md 恢復共享聆聽工作流程。

    自動模式不可用

    Apple Speech 自動模式需要受支援的 iOS 26 裝置和語言。選擇並下載 Whisper 或 Parakeet 模型，再明確選擇它，或返回自動模式讓它成為使用者批准的備用模型。

    轉錄失敗

    確認所選模型已完整下載，且語言適用。Vox.md 會盡可能保留可恢復的源音訊，讓你更換模型後重試。

    標題路線失敗

    編輯路線目標位置，確認標題文字和級別。如果希望傳送時建立缺少的標題而不是停止，請選擇建立標題。

    手錶錄音已排隊

    在 iPhone 上打開 Vox.md，再打開手錶錄音。重新整理或重試，按提示選擇有效路線，保持App已安裝且可用於後台交接。強制退出會阻止後台傳送，直到重新打開。

    {location} 渲染為空

    為執行傳送的路線開啟使用目前位置；對於檢測到的條目前綴、後綴和可重複使用條目模板，編輯器的一鍵修復可完成此操作，而不啟用後設資料。即時儲存庫模板檔案需要手動設定路線。如果權限不可用，或擷取選擇不帶位置繼續，令牌會按設計渲染為空。請參閱 完整位置指南.

    路線位置不可用

    僅在仍處理原始交互式傳送時使用重試。也可取消、僅本次不帶位置傳送，或為該路線始終不帶位置傳送。已儲存的選擇可在路線位置設定中重置。排隊的無人值守請求保留原始不可用結果，不會獲取更新的位置。

    仍有困難？

    打開設定 → 查看調試日誌，再使用傳送回饋，即可包含App版本、平台、系統和裝置詳情。你也可以加入 Isolated Tech 的 Discord 社區.
