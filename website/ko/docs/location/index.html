    현재 위치, {location}, 메타데이터

    YAML이나 인라인 필드를 자동 추가하지 않고 항목 서식에 시작 시점 위치 한 건을 사용하세요. 각 루트에서 위치 획득과 메타데이터 출력은 별개로 명시적으로 선택합니다.

    2026년 8월 21일 업데이트 일회성 획득 백그라운드 추적 없음 전체 기능 가이드
    01 / 개요

    위치 획득이 메타데이터 출력을 뜻하지는 않습니다

    각 루트에는 별도의 위치 컨트롤 두 개가 있습니다. 현재 위치 사용 루트가 시작 시점의 위치를 한 번 요청할지 결정합니다. 위치 메타데이터 작성 가 획득 스냅샷을 프런트매터나 인라인 필드로도 쓸지 결정합니다.

    컨트롤의미의미하지 않는 것
    시스템 위치 권한앱이나 지원 캡처 화면 사용 중 Vox.md가 위치를 요청하도록 허용합니다.어떤 루트의 위치 기능도 켜지 않습니다.
    현재 위치 사용이 루트에 대해 위치를 한 번 요청하여 다음에서 사용할 수 있게 합니다: {location}.YAML이나 인라인 메타데이터를 자동 작성하지 않습니다.
    위치 메타데이터 작성획득한 스냅샷에서 선택한 구조화 필드나 검증된 고급 YAML을 씁니다.다음 여부를 제어하지는 않습니다: {location} 를 출력할 수 있습니다.
    의도 신호는 권한이 아닌 루트

    사용 중 권한은 운영체제의 문만 열어줍니다. Vox.md는 독립적인 캡처 바의 현재 위치 작업이나 현재 위치 사용을 켠 루트에서만 위치를 요청합니다.

    02 / 설정

    한 루트의 현재 위치 설정

    1. 루트를 여세요.iPhone이나 iPad에서는 설정 → 루트를 여세요. Mac에서는 설정을 열고 루트를 선택하세요.
    2. 루트를 편집하세요.시작 위치를 사용할 루트를 선택하세요. 설정은 해당 루트에만 적용되며 다른 루트에는 영향이 없습니다.
    3. 위치를 여세요.켜세요: 현재 위치 사용. 다음을 유지하세요: 위치 메타데이터 작성 을 꺼 토큰 전용으로 사용하세요.
    4. 정밀도를 선택하세요.원래 위치 좌표를 사용하려면 정확함을, 관심 장소 이름 없이 소수점 둘째 자리로 반올림한 좌표를 사용하려면 도시를 선택하세요.
    5. 사용 불가 동작을 선택하세요.원래 위치를 얻지 못하면 '물어보세요', '위치 없이 보내기', '캡처 취소'가 다음 동작을 결정합니다.
    6. 추가 {location} 원한다면 사용하세요.토큰을 항목 템플릿, 사용자 설정 항목 접두사나 접미사, 보관함 Markdown 템플릿에 넣으세요.

    첫 사용에는 OS 위치 권한 창이 보일 수 있습니다. 전에 거부했다면 iOS, iPadOS, macOS 설정에서 Vox.md 위치 접근을 켜세요.

    03 / 일반 설정

    필요한 최소한의 위치 정보 선택

    원하는 결과현재 위치 사용위치 메타데이터 작성템플
    루트 위치 없음끔끔사용하지 마세요: {location}, 그렇지 않으면 비어 있게 출력됩니다.
    클릭 가능한 링크만켬끔추가 {location}. 위치 필드는 쓰지 않습니다.
    메타데이터만켬켬생략 {location}. 설정된 필드만 기록됩니다.
    링크 및 메타데이터켬켬추가 {location} 을 선택하고 메타데이터 필드를 설정하세요.

    현재 위치 사용을 끄면 이전 메타데이터 서식이 나중 사용용으로 남아 있어도 해당 루트의 토큰 출력과 메타데이터 출력 모두 막습니다.

    04 / 템플릿 토큰

    사용: {location} 노트 메타데이터 변경 없이

    현재 위치 사용이 켜져 있고 시작 스냅샷이 있다면 {location} 검증된 Google Maps Markdown 링크를 출력합니다:

    [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    토큰은 재사용 항목 템플릿, 사용자 설정 항목 접두사·접미사, 보관함 Markdown 템플릿에서 작동합니다. 루트에서 고른 정확함 또는 도시 좌표를 동일하게 사용합니다.

    토큰 전용 예시

    다음과 같은 접미사:

    Captured from {location}

    Vox.md가 만들 수 있는 것:

    Captured from [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    위치 메타데이터 작성을 끄면 이 링크만 루트의 위치 콘텐츠로 추가됩니다. 다음은 없습니다: locations: 컬렉션도 다음도 없습니다: location.*:: 필드가 기록됩니다.

    작성 화면 한 번 탭 수정

    유효한 항목 접두사, 접미사, 재사용 항목 템플릿이 다음을 사용하면 {location} 을 사용하지만 선택 루트의 현재 위치가 꺼져 있으면 작성 화면이 토큰이 빈 값이 됨을 설명하고 다음을 제안합니다: [Route]의 현재 위치 사용. 이 작업은 루트 현재 위치를 켜고 위치 메타데이터 작성은 의도적으로 꺼두므로 다음 보내기는 노트 메타데이터 변경 없이 토큰을 해석합니다. 보관함 실시간 템플릿은 전송 중에만 읽어 이 힌트를 트리거할 수 없습니다. 해당 템플릿에 토큰이 있으면 현재 위치를 수동으로 켜세요.

    토큰이 비어 있을 때

    {location} 는 현재 위치가 꺼져 있거나 사용 불가이거나 위치 없이 계속하면 빈 문자열이 됩니다. 선택적 템플릿 줄을 설계할 때 주변 문장부호와 표시명을 고려하세요.

    독립 캡처 바 작업

    빠른 캡처 현재 위치 작업은 현재 초안에 일회성 Google Maps 링크를 직접 삽입합니다. 루트와 독립적이며 현재 위치 사용이나 위치 메타데이터 작성을 바꾸지 않습니다.

    05 / 메타데이터 출력

    원할 때만 구조화 필드 작성

    노트에 다음 정보 외에, 또는 그 대신 기계 판독 가능한 위치 필드가 필요하면 위치 메타데이터 작성을 켜세요: {location} 링크.

    노트 프런트매터

    각 위치를 다음 이름의 컬렉션에 추가합니다: locations 기본적으로 캡처 ID를 키로 사용합니다. 관련 없는 기존 프런트매터는 유지됩니다.

    인라인 항목 필드

    Dataview 스타일의 다음을 씁니다: location.key:: value 줄이 캡처 항목 옆에 놓입니다. 프런트매터 컬렉션은 추가되지 않습니다.

    구조화된 필드

    좌표, 위도, 경도, 장소, 도시, 지역, 국가, 제공자 링크, geo URI, 정확도, 타임스탬프, 소스, ID를 선택하고 이름을 바꾸세요.

    고급 YAML

    노트 프런트매터에 검증되고 범위가 제한된 YAML 템플릿을 사용합니다. 고급 YAML은 인라인 항목 필드에 사용할 수 없습니다.

    구조화된 프런트매터 예시

    ---
title: Field Notes
locations:
  - id: "aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee"
    coordinates: [45.501235, -73.567890]
    place: "Café & Main"
    appleMapsURL: "https://maps.apple.com/?ll=45.501235%2C-73.567890&q=Caf%C3%A9%20%26%20Main"
    timestamp: "2023-11-14T22:13:20.000Z"
    source: "app"
---

    롤링 노트는 컬렉션에 여러 캡처를 보관합니다. 위치 병합에는 재시도 보호가 내장되어 같은 캡처 ID로 같은 위치를 두 번 추가하지 않습니다. 선택 컬렉션 키에 호환되지 않는 사용자 값이 있으면 Vox.md는 덮어쓰지 않고 중단합니다.

    인라인 항목 예시

    location.id:: aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
location.coordinates:: [45.501235, -73.567890]
location.place:: "Café & Main"

    고급 YAML 자리표시자

    고급 템플릿에서는 다음과 같은 자리표시자를 사용할 수 있습니다: {{coordinates}}, {{latitude}}, {{longitude}}, {{place}}, {{city}}, {{region}}, {{country}}, {{appleMapsURL}}, {{googleMapsURL}}, {{openStreetMapURL}}, {{geoURI}}, {{accuracy}}, {{timestamp}}, {{source}}, 그리고 {{id}}. 저장하기 전에 루트 설정에서 구성을 미리 확인하세요.

    06 / 정밀도 및 표시명

    정확함과 도시는 같은 스냅샷을 사용합니다

    정밀도좌표표시명링크 및 필드
    정확함원래 위치를 소수점 여섯 자리로 표시합니다.선택 메타데이터 필드에 필요하면 관심 장소 이름을 포함합니다.모든 파생 값은 정확함 좌표를 사용합니다.
    도시스냅샷을 보관하기 전에 위도와 경도를 소수점 둘째 자리로 반올림합니다.관심 장소 이름을 제거합니다. 도시, 지역, 국가는 남을 수 있습니다.모든 제공자 URL, geo URI, 토큰, 필드는 반올림 좌표를 사용합니다.

    위치 메타데이터 작성이 켜져 있고 선택 구조화 필드나 고급 자리표시자에 장소, 도시, 지역, 국가가 필요할 때만 Apple 시스템 역지오코더를 사용합니다. 토큰 전용 루트는 역지오코딩을 건너뜁니다. 이름 조회에 실패해도 좌표 기반 출력은 가능합니다.

    07 / 캡처 소스

    스냅샷은 캡처 시작점에 속합니다

    현재 위치는 캡처가 시작되는 경계 시점에 결정됩니다. 재시도와 복구에서는 새 위치를 몰래 가져오지 않고 영구 저장된 결과를 다시 사용합니다.

    캡처 소스획득 경계
    iPhone 및 iPad 빠른 캡처보내기
    공유 시트공유 확장에서 보내기
    직접 대기열에 넣는 텍스트·링크·파일 인텐트인텐트 호출
    빠른 캡처를 여는 단축어, 위젯, 컨트롤, 딥 링크작성 화면에서 보내기
    단축어, 위젯, 컨트롤, 즉시 음성, 키보드 기반 루트 녹음녹음 중지
    Apple Watch 일반 캡처 전송Watch에서 녹음을 중지한 시점; iPhone은 자체 위치로 대체하지 않음
    Mac 캡처보내기 시점, 또는 즉시 음성 전송의 녹음 중지 시점

    Watch 녹음만 는 Markdown 없이 원본 M4A 오디오를 파일 앱으로 내보내므로 다른 경우 루트가 현재 위치를 사용하더라도 위치를 요청하지 않습니다.

    08 / 사용 불가 및 복구

    위치를 얻지 못할 때 각 루트의 처리 방식 선택

    • 물어보세요: 대화형 캡처는 재시도, 취소, 한 번만 위치 없이 보내기, 루트의 항상 위치 없이 보내기를 선택할 수 있습니다.
    • 위치 없이 보내기: 는 토큰 값이나 메타데이터 없이 전송을 계속합니다.
    • 캡처 취소: 는 요청한 시작 위치 없이 노트를 만드는 대신 전송을 중단합니다.
    • 저장된 선택 초기화: 루트 위치 설정의 위치 사용 불가 선택 초기화를 쓰세요.

    무인 '물어보세요' 요청은 시작 시점 위치 사용 불가 결과를 나중 검토용으로 저장합니다. 대기/실패 캡처를 재시도해도 나중 위치로 바꾸지 않습니다. 대기 작업에는 로컬 복구에 필요한 개인정보 보호 스냅샷이나 사용 불가 결과만 남습니다.

    09 / 기존 루트

    업그레이드는 기존 메타데이터 동작을 유지합니다

    획득과 출력의 분리는 마이그레이션에도 안전합니다:

    • 새 루트: 현재 위치 사용과 위치 메타데이터 작성은 처음에는 둘 다 꺼져 있습니다.
    • 이전에 위치가 활성화된 루트: 는 업그레이드 후 둘 다 켜져 기존 루트 메타데이터를 유지합니다.
    • 이전에 위치가 꺼진 루트: 두 컨트롤 모두 꺼진 상태로 유지되며 업그레이드로 새 메타데이터 출력이 생기지 않습니다.

    메타데이터를 쓰는 기존 루트를 토큰 전용으로 바꾸려면 현재 위치 사용을 켜두고 위치 메타데이터 작성을 끄세요. 기존 Markdown은 재작성되거나 삭제되지 않습니다.

    10 / 개인정보 보호 및 보관

    명시적인 스냅샷 한 번, 백그라운드 추적 없음

    • Vox.md는 지속 위치 모니터링이나 백그라운드 위치 추적을 하지 않습니다.
    • 위치는 Vox.md 서버, 분석, 광고 시스템, 타사 AI 서비스에 전송되지 않습니다.
    • 토큰과 제공자 URL은 로컬에서 서식화됩니다. Apple Maps, Google Maps, OpenStreetMap은 해당 링크를 열 때만 좌표를 받습니다.
    • 선택한 메타데이터에 장소 이름이 필요할 때만 Apple 시스템 역지오코더가 네트워크를 요청할 수 있습니다. 토큰 전용 위치는 이 조회를 건너뜁니다.
    • 전송 성공 후 복구 요청은 콘텐츠 없는 영수증으로 줄어들고 완료 캡처 기록에 좌표, 이름, 제공자 URL, 위치 템플릿은 남지 않습니다.
    • 위치 메타데이터나 토큰 링크를 Markdown에 쓰면 선택한 파일 일부가 됩니다. 동기화 제공자가 자체 약관으로 파일을 처리할 수 있습니다.
    권한을 켜두어도 루트는 비공개로 유지됩니다

    독립적인 현재 위치 작업의 시스템 권한은 허용해두면서 모든 루트의 현재 위치 사용은 꺼둘 수 있습니다.

    다음을 참조하세요: 개인정보 처리방침 에서 전체 데이터 처리 및 보관 세부 사항을 확인하세요.

    11 / 문제 해결

    흔한 위치 및 템플릿 문제 해결

    {location} 빈 값으로 출력됨

    유효한 항목 템플릿, 접두사, 접미사, 보관함 템플릿이 정확한 소문자 토큰을 사용하는지 확인하세요: {location}. 전송할 루트의 현재 위치 사용을 켜세요. 감지된 인라인 항목 서식은 작성 화면의 한 번 탭 수정으로 메타데이터 활성화 없이 처리할 수 있습니다. 보관함의 실시간 템플릿은 수동 루트 설정이 필요합니다. 권한 거부나 위치 사용 불가 시 루트의 불가 동작과 시스템 위치 설정을 확인하세요.

    링크는 되지만 메타데이터가 없음

    토큰 전용 설정의 정상 동작입니다. 루트 위치 설정에서 위치 메타데이터 작성을 켜고 노트 프런트매터나 인라인 항목 필드를 고른 다음 필요한 필드를 선택하세요.

    메타데이터는 있지만 항목에 링크가 없음

    메타데이터 출력은 링크를 자동 삽입하지 않습니다. 다음을 추가하세요: {location} 을 유효한 항목 서식이나 보관함 Markdown 템플릿에 추가하세요.

    장소나 도시 누락

    이름 필드가 선택되었는지 확인하세요. 좌표가 있어도 Apple 역지오코더는 실패할 수 있습니다. 도시 정밀도는 의도적으로 관심 장소 이름을 제거합니다.

    프런트매터 전송에서 충돌 보고

    설정된 컬렉션 키인 locations 가 기본값이며 호환되는 위치 목록이어야 합니다. 루트 설정에서 컬렉션 이름을 바꾸거나 사용자가 작성한 기존 프런트매터를 조정하세요. Vox.md는 호환되지 않는 값을 덮어쓰지 않습니다.

    재시도 시 위치가 오래되었거나 사용 불가로 표시됨

    의도된 동작입니다. 나중 재시도가 다른 위치를 몰래 주장하지 못하도록 요청은 시작 시점 결과를 유지합니다. 새 스냅샷이 필요하면 새 캡처를 만드세요.

    위치 권한은 허용되었지만 루트가 요청하지 않음

    시스템 권한은 문을 열어줄 뿐입니다. 해당 루트를 편집해 현재 위치 사용을 켜세요. 권한만으로 루트의 위치 기능이 활성화되지는 않습니다.
