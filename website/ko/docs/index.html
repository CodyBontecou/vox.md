    01 / 시작하기

    새 노트 저장소를 만들지 않고 Markdown으로 캡처

    Vox.md는 로컬 우선 빠른 캡처 앱입니다. 표준 Markdown과 첨부파일을 Obsidian 보관함이나 파일 앱에서 선택한 쓰기 가능한 폴더에 씁니다. Vox.md 계정, 플러그인, 호스팅 노트 데이터베이스가 필요하지 않습니다.

    전체 음성 워크플로는 iPhone 음성 노트를 Obsidian으로 보내는 가이드를 따르세요, 폴더 선택부터 생성된 Markdown 확인까지 안내합니다.

    캡처 방법을 고르고 있나요? 다음을 읽으세요: iPhone 캡처 선택 가이드 또는 Vox.md와 Obsidian 기본 기능 비교.

    MacmacOS 14+캡처 작업 공간, 녹음/가져오기, 루트, 모델, 기록, 메뉴 막대, 전역 단축키

    Apple Intelligence 처리호환되는 iOS/macOS 26 기기기기 내 정리, 구조화 출력, 대체 동작이 있는 사용자 지침

    기본 워크플로. 루트를 고르고 대상을 연결해 빠른 캡처에 입력하거나 콘텐츠를 추가한 뒤 보내기를 탭하세요. 루트가 처리, 서식, 노트 배치를 정합니다.

    첫 캡처 만들기

    1. Vox.md를 여세요.앱이 영속 Markdown 작성 화면으로 바로 열립니다.
    2. 루트를 고르세요.내장 기본 루트는 삭제 불가지만 비활성화할 수 있습니다. 루트 하나 이상을 활성화하고 대상을 지정하세요.
    3. 대상을 설정하세요.탭하세요: 목적지 설정, Obsidian 보관함이나 파일 폴더를 고른 뒤 새 노트, 롤링 노트, 기존 노트를 선택하세요.
    4. 콘텐츠를 추가하세요.Markdown을 입력하거나 링크, 사진, 파일, 스캔, 스케치, 위치, 음성 녹음을 추가하세요.
    5. 보내기를 탭하세요.Vox.md는 선택 루트에 저장하고 다음을 알립니다: 캡처 견적. 실패하거나 대기 중인 작업은 계속 복구할 수 있습니다.

    권한 및 시스템 접근

    • 마이크: 음성 녹음, 로컬 전사, 키보드 듣기, 오디오 캡처용입니다. 빠른 캡처는 녹음 전 작업 공간을 처음 열 때 요청할 수 있습니다.
    • 음성 인식: 지원 시스템의 Apple Speech.
    • 파일 폴더 접근: 대상, 템플릿, 가져오기, Watch의 녹음 전용 출력입니다.
    • 카메라 및 선택 사진: 미디어, 스크린샷, 일지 사진 또는 스캔을 추가할 때만 사용합니다.
    • 사용 중 위치: 독립적인 캡처 바의 현재 위치 명령이나 활성화된 루트에 시작 시점 위치 한 건이 필요할 때만 사용합니다. Vox.md는 지속적으로 또는 백그라운드에서 위치를 추적하지 않습니다.
    • 알림: 무인 Apple Watch 작업 실패를 포함한 선택적 전송 상태입니다.
    • 키보드 전체 접근 허용: 이 Vox.md 키보드의 공유 기기 내 앱 워크플로에 필요합니다. 참조: 키보드 설정.
    02 / 빠른 캡처

    텍스트, 미디어, 파일, 음성을 위한 영속 작성 화면 하나

    빠른 캡처는 iOS 및 iPadOS 주 작업 공간입니다. 루트 메뉴는 현재 흐름을, 대상 메뉴는 이번 초안의 전송 위치 미리보기·임시 재정의를 제공합니다. 아래 막대에서 라이브러리, 설정, 소프트웨어 키보드 표시·숨김을 사용할 수 있습니다.

    영속 초안 및 안전 전송

    • 텍스트, 첨부, 선택 루트, 대상 재정의, 캡처 소스는 일시 중단과 재시작 후에도 남습니다.
    • 짧은 디바운스 후 편집이 저장되며 앱이 백그라운드로 가면 즉시 저장됩니다.
    • 전송 중 편집을 계속하면 새 수정은 버려지지 않고 새 초안에 보관됩니다.
    • 전송 전에 대상 설정이 필요합니다. 작성 화면 표시: 설정되지 않은 목적지 와 필요 시 설정 작업을 표시합니다.
    • 재시도에 안전한 캡처 요청은 로컬 저널에 기록되어 권한, 파일 제공자, 동기화 실패 후 재시도할 수 있습니다.
    • 빈 작성 화면은 텍스트를 추가할 때까지 캐시된 영감을 주는 인용문을 표시합니다. 루트를 고르거나 파일을 첨부해도 마찬가지입니다. 인용문 요청에는 초안이 포함되지 않습니다.

    작업 중심 안내는 다음을 참조하세요: 링크, 사진, 스캔을 Obsidian에 저장.

    캡처 유형

    텍스트 및 Markdown

    선택 영역을 인식하는 Markdown 편집기에 직접 쓰고 기존 텍스트를 붙여넣고 다른 데이터와 조합하세요.

    웹 링크

    HTTP 또는 HTTPS URL을 Markdown 링크 서식으로 추가하세요.

    사진 및 카메라

    사진이나 스크린샷을 고르거나 새 사진을 찍으세요. 이미지는 준비된 뒤 전송 노트에 임베드됩니다.

    파일

    파일 항목을 여러 개 선택하세요. 이미지는 임베드, 오디오는 오디오 데이터로 남고 다른 파일은 Obsidian 스타일 링크를 사용합니다.

    문서 스캔

    VisionKit으로 페이지를 스캔하세요. Vox.md는 페이지 이미지를 보관하고 PDF를 만들며 가능한 범위에서 기기 내 OCR을 수행합니다.

    일지 OCR

    수동 셔터로 최대 10페이지 일지를 캡처하거나 사진을 고르세요. 정밀 Vision OCR은 자동 언어 감지를 사용합니다.

    스케치

    흰색 PencilKit 캔버스에 검정 펜으로 그리세요. Vox.md는 편집 가능한 그림 데이터와 PNG 미리보기를 저장합니다.

    현재 위치 작업

    위치를 한 번 요청하고 검증된 Google Maps Markdown 링크를 초안에 삽입합니다. 독립적인 캡처 바 작업은 루트별 위치 컨트롤을 바꾸지 않습니다.

    음성 및 가져온 오디오

    작성 화면에서 녹음하거나 오디오/비디오를 가져와 로컬 전사한 뒤 초안에 추가하거나 즉시 보내세요.

    접근성: OCR은 '이 기기에서 텍스트 추출 중' 배너를 표시합니다. VoiceOver는 캡처 흐름에서 OCR 진행과 완료, '캡처 전송 완료', '전사를 캡처에 추가함'을 알립니다.

    캡처 바

    설정 → 캡처 바에서 작업 순서를 바꾸거나 숨길 수 있습니다. 기본적으로 모든 작업이 보입니다.

    작업동작
    미디어 추가스케치, 카메라, 사진, 스크린샷, 웹 링크 선택지를 엽니다.
    파일 추가파일 앱에서 여러 파일을 선택해 초안과 함께 준비합니다.
    스캔 문서여러 페이지 스캔, PDF, 페이지 이미지, 가능한 범위의 OCR을 캡처합니다.
    텍스트 추출OCR 중심 캡처에 일지 페이지 캡처와 일지 사진 선택을 제공합니다.
    9개마지막 편집 작업을 실행 취소합니다.
    형식 Markdown굵게, 기울임, 해시태그, 제목 1~6을 적용합니다.
    Markdown 링크삽입: [link text](url) 하고 편집 가능한 부분을 선택합니다.
    내부 링크Obsidian 스타일의 다음을 삽입합니다: [[Target]] 위키링크.
    두번째 날짜를 설정오늘, 내일, 이번 주말, 선택적 시간, ±15m·±30m·±1h 조정을 사용합니다. 삽입: (@yyyy-MM-dd) 또는 시간이 있는 형식입니다.
    체크리스트Markdown 할 일 접두사를 적용합니다: - [ ].
    총알 리스트Markdown 글머리표 접두사를 적용합니다.
    파스타현재 선택 영역에 클립보드 텍스트를 붙여넣습니다.
    스케치편집 가능한 PencilKit 스케치 캡처를 엽니다.
    현재 위치위치를 한 번 요청하고 Google Maps 링크를 넣습니다.
    타임스탬프를 입력로컬 시각과 날짜를 다음 형식으로 삽입합니다: h:mm a yyyy-MM-dd.
    날짜를 입력삽입: yyyy-MM-dd.
    Text Case 변경하기소문자, 대문자, 문장 첫 글자 대문자, 단어 첫 글자 대문자, 슬러그 변환을 제공합니다.

    서식은 현재 선택을 존중하고 줄바꿈을 정규화하며 잘못된 선택 범위를 제한하고 이모지 같은 조합 문자를 나누지 않습니다.

    인라인 음성 컨트롤

    • 음성 버튼을 탭해 시작하거나 중지하세요. 약 0.45초 길게 누르면 상세 컨트롤이 표시됩니다.
    • 녹음 중에는 일시 정지 버튼은 음성 버튼 옆에 표시됩니다. 한 번 탭하면 일시 정지하고, 다시 탭하면 재개합니다. 최종 노트는 하나의 녹음으로 유지되며 일시 정지 중의 오디오와 시간은 제외됩니다. 재개할 때까지 실시간 전사 미리보기와 음성 자동 중지도 일시 정지됩니다.
    • 초안에 추가 는 완성 전사를 추가합니다. 즉시 전송 선택한 루트와 대상을 실행합니다.
    • 즉시 전송이 기본 선택입니다 iOS와 Mac 캡처 작업 공간에서 사용합니다. 다음으로 iOS 음성 작업을 열면 voxboard://capture?action=voice 로 해당 녹음을 초안에 추가로 전환합니다.
    • 해당 오디오 옵션은 요청 시 원본 녹음을 초안 일부로 보관합니다.
    • 오디오 수입 는 오디오·동영상 파일을 받고 같은 로컬 전사 파이프라인을 사용합니다.
    • 연설자들의 식별 는 녹음 및 가져온 오디오에 적용하는 선택적 루트 음성 처리입니다. 첫 사용 시 별도 화자 모델을 준비해 로컬에서 가능한 범위로 익명 표시를 붙입니다. 실행할 수 없으면 일반 전사를 유지하고 라이브러리에 이유를 표시합니다.
    • 자동은 녹음 중 편집 가능한 작성 화면에 Apple Speech의 확정 및 잠정 텍스트를 직접 표시할 수 있습니다. 명시적으로 선택한 Whisper와 Parakeet 모델은 녹음이 끝난 뒤 전사합니다.
    • 전사 실패로 원본 녹음이 파괴되지는 않으며 복구할 수 있습니다.
    • 지속 키보드 듣기는 명시적으로 켠 경우에만 앱 재시작 후 유지됩니다. 일회성 앱 녹음은 오디오 세션을 유휴로 돌립니다.

    캡처 입력 제한

    한 요청에는 최대 다음을 포함할 수 있습니다: 100,000자 의 공유 텍스트, 공유 항목 10개, 그리고 250 MB 의 전체 준비 자산입니다. 사진 및 스크린샷 선택기는 최대 10개 항목, 일지 캡처는 최대 10페이지를 받습니다. Vox.md는 조용히 항목을 빼지 않고 초과 입력을 거부합니다.

    03 / 루트

    폴더만이 아닌 전체 워크플로 저장

    루트는 캡처 의미, 텍스트 처리 여부, 메타데이터·오디오 처리, 정확한 Markdown 저장 위치를 보관합니다. 입력 텍스트, 링크, 미디어, 스캔, 파일, 스케치, 음성, 단축어, 위젯, 공유 시트, Watch, Mac에 적용됩니다.

    루트 생성 및 관리

    • 설정 → 루트에서 사용자 루트 생성, 이름 변경, 활성화, 비활성화, 아이콘 선택, 삭제를 할 수 있습니다.
    • 검색 가능한 아이콘 선택기는 쓰기, 음성, 할 일, 개인, 업무로 기호를 묶습니다.
    • 비활성 루트는 일반 선택기에 표시되지 않습니다. 내장 기본 루트는 삭제할 수 없습니다.
    • 내장 기본 루트는 파형 기호와 다음 프롬프트를 사용합니다: 아이디어, 할 일, 링크, 파일, 스캔, 녹음을 캡처하세요., type: capture 메타데이터, 문장 다듬기 처리, 입력 텍스트 처리 끔, 오디오 저장 끔입니다.
    • 새 사용자 설정 루트의 초기 상태: 사용자 설정 루트, 슬라이더 아이콘과 다음을 사용합니다: 무엇을 캡처할까요? 프롬프트를 사용하고 사용자 지정 지침이 선택되지만 입력/혼합 텍스트 처리는 꺼진 상태로 시작합니다.

    처리 모드

    모드결과대체 동작
    원본 유지AI 재작성 없이 캡처 텍스트를 유지합니다.원문을 전송합니다.
    문장 다듬기의미와 Markdown을 유지하며 대소문자와 문장부호를 정리합니다.기기 내 정보 보강이 불가하면 원문 사용.
    할 일 체크리스트Markdown 생성 - [ ] 할 일 항목입니다.일관된 체크리스트 서식기.
    회의 메모생성: ## Notes 섹션과, 있는 경우 다음을 ## Action Items.일관된 회의 노트 구조.
    사용자 지정 지침가능한 경우 기기 내 Apple Intelligence로 지침을 따릅니다.명령을 로컬에서 실행할 수 없으면 원문을 사용합니다.

    음성 전사는 선택한 루트 모드를 사용합니다. 텍스트 캡처를 사용하기 는 기본적으로 꺼진 별도 선택 기능으로 입력 Markdown, OCR, 텍스트를 포함한 혼합 캡처를 처리합니다. 꺼두면 작성한 Markdown의 예상치 못한 재작성을 막습니다. 정확한 처리 요청을 전송 전에 저장하므로 재시도는 변경 설정으로 처리를 다시 실행하지 않습니다.

    메타데이터

    • 정적 메타데이터를 다음처럼 한 개씩 입력하세요: key: value 쌍을 한 줄에 하나씩 입력하세요. 예: tags: [journal, idea].
    • 노트 프런트매터 는 문서 범위에 메타데이터를 씁니다.
    • 인라인 항목 필드 기록합니다: key:: value 필드를 롤링 노트의 각 항목 옆에 씁니다.
    • 가능한 경우 기기 내 보강으로 정적 루트 메타데이터 외에 제목, 태그, 카테고리, 정리 텍스트를 추가합니다.

    선택적 위치 기능

    현재 위치는 루트별이며 기본적으로 꺼져 있습니다. 활성화하면 Vox.md는 캡처 시작 위치를 한 번 요청합니다. iOS/iPadOS, 공유 시트, 딥 링크/작성 화면, Mac, 작성 화면을 여는 시스템 작업은 보내기 시점, 직접 대기열에 넣는 텍스트·링크·파일 인텐트는 호출 시점, 즉시 음성·키보드 루트 녹음·위젯/컨트롤 녹음·일반 캡처로 전송하는 Apple Watch 녹음은 중지 시점입니다. Watch 녹음만은 Markdown 위치 없는 원본 오디오 파일 내보내기이므로 위치를 요청하지 않습니다. Vox.md는 지속 위치 모니터링이나 백그라운드 추적을 하지 않습니다.

    설정 항목동작
    현재 위치 사용루트에 시작 시점 위치 한 건을 요청해 다음에 사용합니다: {location}. 메타데이터를 자동으로 쓰지는 않습니다.
    정확함(기본값)개인정보 보호 설정이 적용된 원래 위치를 유지하며 선택 메타데이터에 필요하면 관심 장소 이름도 포함할 수 있습니다.
    도시위도·경도를 소수점 둘째 자리로 반올림하고 관심 장소 이름을 빼며 모든 파생 필드와 링크에 같은 좌표를 씁니다.
    위치 메타데이터 작성다음 외에 구조화된 또는 고급 메타데이터를 별도로 선택해 추가합니다: {location} 항목 템플릿 링크.
    구조화된 필드좌표, 위도, 경도, 장소, 도시, 지역, 국가, Apple Maps, Google Maps, OpenStreetMap을 선택하고 이름을 바꾸세요. 또한 geo: URI, 정확도, 타임스탬프, 소스, 캡처 ID.
    고급 YAML 템플릿노트 프런트매터에 검증되고 범위가 제한된 YAML을 씁니다. 관련 없는 프런트매터를 대체할 수 없고 인라인 항목 필드에는 사용할 수 없습니다.

    위치 메타데이터 작성이 켜져 있으면 문서 범위는 캡처 ID를 키로 설정된 프런트매터 컬렉션에 결과를 추가합니다. 노트 하나에 여러 위치를 보관하며 멱등 재시도로 같은 위치가 두 번 추가되지 않습니다. 항목 범위는 대신 선택한 구조화 필드를 다음 형식으로 표시합니다: key:: value 해당 캡처 항목 옆에 둡니다.

    장소, 도시, 지역, 국가는 활성 메타데이터 필드가 필요로 할 때만 Apple 시스템 역지오코더를 사용합니다. 토큰 전용 위치는 역지오코딩을 건너뜁니다. 무료이고 API 키도 필요 없지만 네트워크를 사용할 수 있습니다. 조회 실패 시 좌표 전용 메타데이터로 캡처를 계속합니다. 항목 접두사, 접미사, 보관함 Markdown 템플릿은 다음을 사용할 수 있습니다: {location} 으로 메타데이터 출력 없이 루트의 개인정보 보호 스냅샷에서 클릭 가능한 Google Maps 링크를 삽입하세요. 현재 위치가 꺼져 있거나 사용할 수 없으면 토큰은 비어 있습니다. 제공자 링크를 생성할 때 Apple, Google, OpenStreetMap에 접속하지 않습니다. 링크를 열면 저장된 정확한 또는 반올림된 좌표가 해당 제공자에게 공개됩니다.

    새 루트와 이전에 꺼둔 루트는 두 컨트롤이 모두 꺼진 상태를 유지합니다. 이미 위치 메타데이터를 쓰던 루트는 업그레이드 후 둘 다 켜두어 기존 출력을 유지합니다.

    전체 현재 위치 가이드

    참조: 현재 위치, {location}, 메타데이터 에서 설정 패턴, 예시, 캡처 소스 시점, 마이그레이션 동작, 개인정보 보호, 문제 해결을 확인하세요.

    위치 사용 불가

    대화형 화면은 재시도, 취소, 한 번만 위치 없이 보내기 또는 다음 선택을 제공합니다: 항상 위치 없이 보내기 을 해당 루트에 설정하세요. 저장 선택은 루트 위치 설정에서 초기화하세요. 무인 물어보세요 캡처는 결정할 때까지 시작 시점 사용 불가 결과를 유지합니다. 재시도와 복구는 나중 위치를 다시 가져오지 않습니다.

    Markdown 대상

    각 루트에는 Obsidian 보관함이나 쓰기 가능한 파일 폴더를 루트로 삼는 대상 하나가 있습니다.

    새 노트

    다음 토큰 등으로 캡처마다 별도 Markdown 파일을 만드세요: {timestamp}, {date}, {time}, {year}, {YR}, {month}, {day}, {id8}, 그리고 {id}.

    롤링 노트

    일별, 주별, 월별, 분기별, 연별 노트에 추가하세요. 경로는 다음도 지원합니다: {period} 및 {week}. 새 대상의 기본값: Journal/{period}.md 에 일별 주기를 사용하세요.

    기존 노트

    선택한 보관함이나 폴더 안에 있는 Markdown 파일을 고르세요. Vox.md는 대상이 루트 안에 안전하게 남는지 검증합니다.

    전체 루트 예제 참조: Obsidian 일일 노트에 텍스트와 음성 추가.

    받은 편지함, 일지, 할 일 템플릿 예제 사용 로 항목 서식을 예측 가능하게 유지하세요.

    배치, 제목, 템플릿

    • 아래 뒤에 추가; TOP 앞에 추가합니다; 이 로 선택한 1~6단계 제목 아래에 삽입합니다.
    • 제목이 없다면 다음을 선택하세요: 실수 표시 또는 이를 만들기.
    • 보관함의 실시간 Markdown 템플릿 파일, 재사용 항목 템플릿, 사용자 설정 접두사와 접미사를 사용하세요.
    • 항목 서식은 다음을 지원합니다: {date}, {time}, {hour}, {minute}, {second}, {timestamp}, {year}, {YR}, {month}, {day}, {week}, {source}, {id8}, {id}, 그리고 {location}.
    • 기본 첨부 하위 폴더: attachments.
    • 보호를 반환는 기본적으로 꺼져 있으며 다음을 눈에 보이게 씁니다: vox-capture HTML 주석으로 중복 재시도를 감지합니다.
    • Vox.md는 절대 경로, 역슬래시, 경로 탐색, 위험한 이름, 심볼릭 링크 이탈을 거부합니다.

    캡처 한 번에만 적용되는 재정의

    대상 컨트롤은 루트 기본값 사용, 이번 캡처 맨 위/아래 배치, 일회성 항목 템플릿 적용, 같은 보관함의 다른 노트 선택을 지원합니다. 루트의 기본 저장 위치 사용 는 재정의를 해제합니다. 선택은 현재 초안에만 적용되며 루트를 바꾸지 않습니다.

    오디오 보관 및 호환성 내보내기

    • 오디오 저장 모드: 끔, 노트 옆, 또는 첨부 파일.
    • Markdown은 Obsidian 문법으로 보관 오디오를 맨 위나 아래에 임베드할 수 있습니다. 예: ![[recording.m4a]].
    • 통합 Markdown 대상이 없는 기존 직접 음성 설정에서는 메모를 파일에 저장 는 TXT, MD, JSON, YAML, 새 파일/추가, 모델 및 언어 파일명 토큰, Markdown 템플릿, Obsidian Bases 옵션, 선택 가능한 YAML 속성, 선택적인 다음을 지원합니다: .md 확장자는 YAML용입니다.
    • 호환 내보내기는 루트에 통합 캡처 대상이 없는 직접 음성 실행에만 적용됩니다.
    04 / 모델 및 전사

    시스템 백엔드 또는 선택적 로컬 모델 선택

    모든 전사는 Apple 기기에서 실행됩니다. iOS 기본값은 자동입니다. 선택적 Whisper와 Parakeet 모델 파일은 요청할 때만 다운로드하며 선택, 다운로드 중 취소, 나중에 삭제가 가능합니다.

    오프라인 전사 워크플로 준비 에서 로컬 백엔드와 쓰기 가능한 대상을 사용하세요.

    사용 가능한 전사 옵션

    옵션대략적인 크기가장 적합한 용도
    자동시스템 관리지원되는 iOS 26 기기와 언어에서 Apple Speech를 우선하고 명시적으로 다운로드한 로컬 모델로만 대체합니다.
    Whisper Tiny75 MB다운로드가 가장 작고 가장 빠른 Whisper 옵션.
    Whisper Base142 MB균형 잡힌 소형 로컬 모델. 이전 Mac 기본값.
    Whisper Small466 MB더 높은 정확도, 더 큰 저장 및 처리 비용.
    Whisper Medium1.5 GB더 큰 다국어 Whisper 모델.
    Whisper Large v3 Turbo1.6 GB사용 가능한 가장 큰 Whisper 옵션.
    Parakeet v2~800 MB영어에 최적화된 Core ML/FluidAudio 모델.
    Parakeet v3~800 MB25개 언어를 지원하는 Core ML/FluidAudio 모델.

    자동 작동 방식

    • 지원되는 iOS 26 기기에서 자동은 선택 언어의 Apple 시스템 관리 Speech 인식기를 확인하고 필요 시 언어 자산을 준비합니다.
    • 시스템 언어 는 기기 언어를 따릅니다. 다른 언어 녹음에는 특정 언어를 고르세요.
    • 자동은 Whisper나 Parakeet 대체 모델을 몰래 다운로드하지 않습니다. 이전에 선택 다운로드한 모델만 사용할 수 있습니다.
    • 실시간 Apple Speech는 삽입해도 되는 확정 텍스트와 아직 변할 수 있는 잠정 텍스트를 구분합니다.
    • Whisper와 Parakeet을 명시 선택하면 구간이 끝난 후 일괄 전사합니다.

    언어

    • Whisper: 자동 감지, 영어, 스페인어, 프랑스어, 독일어, 이탈리아어, 포르투갈어, 네덜란드어, 폴란드어, 러시아어, 중국어, 일본어, 한국어, 아랍어, 힌디어, 터키어, 베트남어, 태국어, 우크라이나어, 스웨덴어, 덴마크어, 노르웨이어, 핀란드어.
    • 자동: 시스템 언어와, Apple이 해당 로캘을 지원할 경우 Whisper에 명시된 언어.
    • Parakeet v2: 영어.
    • Parakeet v3: 불가리아어, 크로아티아어, 체코어, 덴마크어, 네덜란드어, 영어, 에스토니아어, 핀란드어, 프랑스어, 독일어, 그리스어, 헝가리어, 이탈리아어, 라트비아어, 리투아니아어, 몰타어, 폴란드어, 포르투갈어, 루마니아어, 슬로바키아어, 슬로베니아어, 스페인어, 스웨덴어, 러시아어, 우크라이나어. Parakeet 워크플로에서 언어를 자동 감지합니다.

    Parakeet 키보드 자동 중지

    06 / 시스템 통합

    공유 시트, 홈 화면, 잠금 화면, 단축어에서 캡처 시작

    공유 확장

    iOS 공유 시트 작업 이름: Vox.md에 캡처. 공유 항목 및 자산 제한 내에서 텍스트, HTTP/HTTPS URL, 이미지, 파일, 동영상을 받습니다. 루트와 대상을 선택하고 선택적으로 메모를 넣고 보내세요. 루트가 현재 위치를 사용하면 공유는 메타데이터 출력 여부와 상관없이 이 보내기 시점에 시작 위치를 한 번 요청합니다. 콘텐츠는 비공개 App Group에서 준비되어 영속 대기열에 들어가며 전송을 위해 Vox.md에서 열립니다. 본 앱이 필요하면 다음을 사용하세요: 오픈 Vox.md.

    홈 화면 및 잠금 화면 위젯

    빠른 캡처

    영속 Markdown 초안을 엽니다. 중형·대형 위젯은 노트, 사진, 스크린샷, 카메라, 파일, 링크, 스캔, 스케치, 음성 작업을 제공합니다.

    빠른 기록

    설정한 녹음을 시작하고 지원되는 홈 화면 및 잠금 화면 유형에 준비, 듣기, 비활성 상태를 표시합니다.

    위젯 안전 설정

    설정에서 잠금 화면 녹음 버튼을 끄면 녹음이 즉시 시작되지 않고 꺼짐 상태가 표시됩니다.

    제어 센터, 실시간 현황, Dynamic Island

    • iOS 18+ 제어 센터에서 사용 가능한 Vox.md 캡처 및 녹음 컨트롤을 추가하세요. 설치 버전이 제공하는 루트와 옵션을 설정하세요.
    • 녹음 컨트롤을 사용하기 전에 Vox.md에서 마이크, 모델, 대상 설정을 완료하세요. iOS 및 설치된 앱 버전에 따라 녹음 시 앱이 열릴 수 있습니다. 백그라운드 캡처에 의존하기 전에 기기에서 짧은 녹음을 확인하세요.
    • 해당 실시간 현황 모니터 설정은 잠금 화면과 Dynamic Island의 녹음 상태 및 녹음/중지 작업을 제어합니다.
    • 실시간 현황에는 녹음 중, 타이머, 처리 중, 준비, 녹음, 중지 상태가 있습니다.
    • 실시간 현황은 iOS 17부터 사용 가능하며 제어 센터 컨트롤은 iOS 18이 필요합니다.

    단축어 및 App Intents

    루트는 단축어와 지원 컨트롤에서 선택 가능합니다. 현재 위치 사용이 켜지면 직접 대기열에 넣는 텍스트·링크·파일 인텐트는 호출 시, 빠른 캡처를 여는 작업은 보내기 시, 녹음 작업은 중지 시 위치를 요청합니다. 메타데이터 출력은 이 시점을 바꾸지 않습니다. 무인 물어보세요 요청이 위치를 얻지 못하면 다시 가져오지 않고 시작 시점의 위치 사용 불가 결과를 보관해 나중에 결정하도록 합니다. 설치된 Vox.md 버전에서 제공하는 작업을 사용하세요. 캡처 작업은 다음과 같습니다:

    • 빠른 캡처
    • 캡처 기록
    • 스크린샷을 캡처하기
    • 텍스트 캡처 to Markdown
    • 링크 to Markdown
    • 파일을 캡처하기 Markdown

    동작 버튼 녹음 설정

    Vox.md를 한 번 열어 마이크 권한, 전사 백엔드, 대상 연결을 준비하세요. 단축어에 사용 가능한 Vox.md 캡처 작업을 추가하고 루트를 고르세요. 설정 → 동작 버튼 → 단축어에 지정하기 전에 잠금 해제 상태에서 실행해 올바른 노트 저장을 확인하세요.

    작업 및 백그라운드 녹음 동작은 설치 버전과 iOS에 따라 다릅니다. 기기 단축어에 보이는 작업을 사용하세요. 앱을 열어야 녹음된다면 Vox.md를 여세요. 선택기에 단축어가 있다고 잠긴 휴대폰 녹음이 보장되지는 않습니다.

    딥 링크

    Vox.md는 다음을 등록합니다: voxboard:// URL 스킴. 쿼리 값은 URL 인코딩하세요.

    URL동작
    voxboard://capture영속 빠른 캡처 작성 화면을 엽니다.
    voxboard://capture?action=photos사진 선택기를 여세요. 다른 작업: screenshots, camera, files, scan, sketch, link, 그리고 voice.
    voxboard://capture?text=...제한된 길이의 텍스트로 초안을 엽니다.
    voxboard://capture?url=https%3A%2F%2F...HTTP/HTTPS 링크가 있는 초안을 엽니다.
    voxboard://capture?route=...활성 루트를 선택하세요. 지원 작업, 텍스트, URL과 조합할 수 있습니다.
    voxboard://capture-request?id=...시스템 확장이나 인텐트가 만든 영속 요청을 가져옵니다.
    voxboard://listen키보드 듣기 시작 흐름을 엽니다.
    voxboard://record이전 녹음 진입점이 듣기로 연결됩니다.
    voxboard://widget-record이전 위젯 녹음 진입점.

    알 수 없는/중복 매개변수, 잘못된 UUID, 위험한 루트 식별자, 비 HTTP URL, 공유 제한 초과 텍스트는 거부됩니다.

    • Watch 앱에는 준비, 녹음 중, 일시 정지, 동기화 중, 대기, 전사 중, 저장 중, 전송 완료, 확인 필요 상태가 표시됩니다.

    • 대상 설정 배너와 루트 검사기에 선택한 루트의 해석된 노트와 배치가 표시됩니다.

    스템을 분리한 회의 캡처

    입력 모드 선택기를 다음에서 전환하세요: 마이크 대상: 회의 으로 Mac 앱 재생음과 마이크를 두 개의 명확히 분리된 트랙으로 녹음하세요. Vox.md는 ScreenCaptureKit 단일 앱 모드로 정확히 한 앱만 선택하며 Vox.md 자체는 녹음하지 않습니다.

    • 녹음 중 상태 막대에는 실시간 시스템 및 마이크 레벨, 소스별 상태, 캡처 경고가 표시됩니다.
    • 두 트랙은 복구 명세와 함께 영속적인 청크로 기록되므로 스트림 중지, 마이크 분리, 강제 종료 같은 중단에도 안전하게 마무리되어 회의를 전사할 수 있습니다. 다음에 녹음 대기열이 재개될 때 중단된 세션을 자동 복구합니다.
    • 중지 후 기기에서 트랙별 전사하여 공통 타임라인에 교차 배치합니다. 마이크 표시: 나, 앱 트랙은 원격 화자로 표시됩니다. 선택적 화자 식별로 여러 원격 음성을 더 구분할 수 있습니다.
    • 두 트랙의 재생 믹스를 녹음 오디오로 보관합니다. 완성 전사는 다른 녹음과 마찬가지로 루트, 초안에 추가/즉시 전송, 클립보드 설정을 따릅니다.

    전역 단축키

    설정 → 전역 단축키에서 다음에 단축키를 지정할 수 있습니다: Clipboard에 대한 리뷰 보기, 선택한 루트, 또는 활성 루트에 지정합니다. 단축키는 기본적으로 꺼져 있고 일반 키와 Control, Option, Command 중 하나가 필요하며 Shift를 더할 수 있습니다. 충돌은 거부됩니다. 활성 단축키를 다시 누르면 녹음이 멈춥니다.

    Clipboard에 대한 리뷰 보기 노트, 라이브러리 항목, 보관 오디오를 만들지 않습니다. 모든 Mac 앱에 빠르게 받아쓰기 위한 기능입니다.

    메뉴 막대 및 앱 표시

    • 표시 옵션: 듀크 + 메뉴 바 (기본값), Menu Bar Only 근처 오락거리, Dock Only, 그리고 숨기기.
    • 메뉴 막대가 녹음, 전사, 내보내기 상태를 표시합니다.
    • 메뉴 작업은 녹음 시작, 중지 + 전사, 오디오 가져오기…, 마지막 전사 복사, 마지막 내보내기 보기, 루트 선택, 캡처 보기, 라이브러리 보기, 데이터 폴더 보기, Vox.md 종료입니다.
    • Mac 앱에서 Control-B 키를 누르면 클릭 가능한 컨트롤에 키보드 힌트가 보입니다.

    Mac 기록 및 모델

    로컬 기록 검색, 새로 고침, 지우기, 복사, 삭제, 정리 및 원본 전사 상세 보기, Finder에서 전송 노트 보기가 가능합니다. 모델들 화면에서 Whisper나 Parakeet 모델을 다운로드, 선택, 삭제하고 전사 언어를 바꿉니다. 지원되는 Mac에서 Whisper는 Metal 가속을 사용합니다.

    작업 복구, 로컬 데이터 관리, 무제한 사용 잠금 해제

    • 라이브러리는 로컬 음성 전사와 캡처 전송 기록을 검색 가능한 목록 하나로 모읍니다.
    • 원본 및 정리 텍스트, 제목, 태그, 카테고리 검색. 당겨서 새로고침.
    • 정리 또는 원본 전사를 복사하고 메타데이터와 텍스트를 편집하거나 공유 시트로 Markdown 사본을 내보내세요.
    • 전사 하나를 삭제하거나 로컬 기록 전체를 지우세요. 기록을 지워도 대상에 이미 쓴 Markdown 노트와 첨부파일은 삭제되지 않습니다.
    • 대기 캡처를 재시도하고 대략적인 소스, 루트, 대상, 노트 경로, 첨부 수, 시간, 결과, 실패 종류를 확인하세요.
    • 전사 편집은 제목, 태그, 카테고리, 정리 텍스트, 원본 전사를 포함합니다.

    • 통계는 전송 완료 캡처만 계산합니다. 새 활동 후 당겨서 새로고침하세요.
    • 장부는 기기에 남으며 캡처 내용, 파일명, 대상을 저장하지 않습니다.

    무료 사용 및 평생 잠금 해제

    • 무료 사용에는 다음이 포함됩니다: 전사 15분 및 성공 캡처 전송 10회.
    • 이미 전사 시간이 차감된 음성 전사는 Markdown으로 라우팅할 때 별도 캡처 할당량을 사용하지 않습니다.
    • 쓰기 실패와 멱등 재시도는 성공 캡처 전송을 차감하지 않습니다.
    • 무제한은 구독, 갱신, 광고 없는 일회성 평생 구매입니다. 지역별 App Store 가격이 기준이며 미국 가격은 개인 $19.99, 가족 $39.99, 가족 업그레이드 $19.99입니다. 다른 스토어에는 구매력 기준 가격이 적용됩니다.
    • 구매 복원으로 적격 구매를 복구합니다. 조건에 맞는 이전 유료 빌드 사용자는 기존 권리로 무제한 사용이 가능합니다.
    • 콘텐츠 없는 App Group 장부는 로컬 앱 데이터가 남아 있는 동안 재시도 이중 차감을 막습니다. 키체인에 저장되지 않으며 로컬 앱 데이터를 지우면 새 무료 할당량이 시작됩니다.

    로컬에 남는 정보

    캡처 내용

    초안, 텍스트, 링크, 템플릿, 루트, 첨부파일, 오디오, OCR, 전사는 Vox.md 서버에 보내지 않습니다.

    처리

    Apple Speech, Whisper, Parakeet, Vision OCR, 지원 Apple Intelligence 처리는 기기에서 실행됩니다.

    저장 대상

    완성된 파일은 선택한 폴더에만 저장됩니다. 타사 파일 제공자는 자체 약관에 따라 동기화할 수 있습니다.

    • 전송 성공 후 복구 캡처는 콘텐츠 없는 영수증이 되며 완료 Watch 항목에는 대략적인 최종 전송 필드만 남습니다. 좌표, 이름, 제공자 URL, 위치 템플릿, 루트 데이터는 남지 않습니다.
    • 완료된 캡처 기록에는 전송 메타데이터만 저장하며 노트 텍스트, URL, 좌표, 위치 이름이나 템플릿, 책갈피, 절대 경로, 첨부파일명은 저장하지 않습니다.
    • 대기/실패 항목에는 로컬 복구에 필요한 것만 남으며 루트 스냅샷과 개인정보 보호가 적용된 위치 또는 사용 불가 결과가 포함될 수 있습니다.
    • 출시 온보딩 분석은 기본적으로 꺼져 있습니다. 앱에는 타사 분석 SDK, 광고 네트워크, 앱 간 추적기가 없습니다.
    • 작성 화면은 초안 내용이나 식별자를 보내지 않고 ZenQuotes에서 영감을 주는 인용문을 가져와 캐시합니다.

    10 / 문제 해결

    일반 설정 및 전송 문제

    캡처를 보낼 수 없음

    대상 컨트롤을 열어 선택 루트를 설정하세요. 폴더 이동이나 접근 만료 시 보관함/폴더를 다시 고르세요. 대기 작업은 라이브러리에 남습니다.

    키보드가 전체 접근 활성화를 요청함

    iOS 설정 → 일반 → 키보드 → 키보드 → Vox.md를 열고 전체 접근 허용을 켜세요. 앱으로 한 번 돌아가면 Vox.md가 공유 듣기 워크플로를 재개할 수 있습니다.

    자동을 사용할 수 없음

    Apple Speech 자동은 지원 iOS 26 기기와 언어가 필요합니다. Whisper나 Parakeet을 다운로드해 직접 선택하거나 자동으로 돌아가 사용자 승인 대체 모델로 쓰세요.

    전사 실패

    선택한 모델이 완전히 다운로드되었고 언어가 적절한지 확인하세요. Vox.md는 가능한 경우 복구할 수 있는 원본 오디오를 보관하므로 다른 모델로 재시도할 수 있습니다.

    제목 루트 실패

    루트 대상을 편집해 제목 텍스트와 수준을 확인하세요. 제목이 없으면 중단 대신 생성하려는 경우 이를 만들기를 고르세요.

    Watch 녹음이 대기 중

    iPhone에서 Vox.md와 녹음보기를 여세요. 새로고침이나 재시도하고 요청 시 유효 루트를 고르세요. 백그라운드 인계용으로 앱을 설치 상태로 유지하세요. 강제 종료는 다시 열 때까지 백그라운드 전송을 막습니다.

    {location} 빈 값으로 출력됨

    전송할 루트의 현재 위치 사용을 켜세요. 감지된 항목 접두사, 접미사, 재사용 항목 템플릿에는 작성 화면의 한 번 탭 수정으로 메타데이터를 켜지 않고 적용할 수 있습니다. 보관함의 실시간 템플릿 파일은 루트 수동 설정이 필요합니다. 권한을 사용할 수 없거나 위치 없이 계속하면 토큰은 의도적으로 비어 있게 출력됩니다. 다음을 참조하세요: 전체 위치 가이드.

    루트 위치를 사용할 수 없음

    원래의 대화형 보내기를 해결하는 중에만 재시도를 사용하세요. 취소, 한 번만 위치 없이 보내기, 해당 루트의 항상 위치 없이 보내기도 가능합니다. 저장한 선택은 루트 위치 설정에서 초기화하세요. 대기 중인 무인 요청은 원래 사용 불가 결과를 유지하며 새 위치를 가져오지 않습니다.

    여전히 막히나요?

    설정 → 디버그 로그 보기를 열고 피드백 보내기를 사용하면 앱 버전, 플랫폼, OS, 기기 정보를 포함할 수 있습니다. 다음에도 참여할 수 있습니다: Isolated Tech Discord 커뮤니티.
