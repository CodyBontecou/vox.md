속도가 중요한 영어에는 Parakeet v2를, 25개 유럽 언어에는 Parakeet v3를 사용하세요. Parakeet에 없는 언어나 Auto Detect에는 Whisper를 사용하세요. 아무것도 받고 싶지 않다면 iOS 26 지원 기기에서 자동을 유지하세요. Apple Speech를 사용합니다.

Whisper와 Parakeet이란

Whisper 은(는) OpenAI의 음성 인식 모델 제품군입니다. 저장소는 여러 음성 작업으로 학습된 Transformer 시퀀스-투-시퀀스 모델로 설명하며, 코드와 가중치를 MIT 라이선스로 공개합니다. 다음을 참고하세요: github.com/openai/whisper 그리고 논문 “대규모 약지도 학습을 통한 강건한 음성 인식”. Vox.md는 Whisper를 다음을 통해 실행합니다: whisper.cpp.

Parakeet TDT 모델 은(는) NVIDIA에서 제공합니다. 모델 카드에 따르면 6억 개 파라미터의 FastConformer 인코더와 TDT 디코더를 사용하며 CC-BY-4.0 라이선스로 공개되어 있습니다: parakeet-tdt-0.6b-v2 은(는) 영어이며, parakeet-tdt-0.6b-v3 은(는) 25개 유럽 언어를 지원합니다. Vox.md는 Parakeet을 다음을 통해 실행합니다: FluidAudio. Core ML을 사용해 Apple 기기에서 로컬 오디오 모델을 실행하는 Swift SDK입니다.

세 번째 옵션은 Apple의 자체 Speech 프레임워크입니다. iOS 26에서 Apple은 다음을 문서화합니다: SpeechAnalyzer 온디바이스 인식용입니다. Vox.md의 자동 모드는 지원되는 기기와 언어에서 이를 우선 사용합니다.

언어

  • Vox.md의 Whisper: 자동 감지, 영어, 스페인어, 프랑스어, 독일어, 이탈리아어, 포르투갈어, 네덜란드어, 폴란드어, 러시아어, 중국어, 일본어, 한국어, 아랍어, 힌디어, 터키어, 베트남어, 태국어, 우크라이나어, 스웨덴어, 덴마크어, 노르웨이어, 핀란드어.
  • Parakeet v3: 불가리아어, 크로아티아어, 체코어, 덴마크어, 네덜란드어, 영어, 에스토니아어, 핀란드어, 프랑스어, 독일어, 그리스어, 헝가리어, 이탈리아어, 라트비아어, 리투아니아어, 몰타어, 폴란드어, 포르투갈어, 루마니아어, 슬로바키아어, 슬로베니아어, 스페인어, 스웨덴어, 러시아어, 우크라이나어.
  • Parakeet v2: 영어 전용.

Vox.md에서는 Whisper만 중국어, 일본어, 한국어, 아랍어, 힌디어, 튀르키예어, 베트남어, 태국어, 노르웨이어를 지원합니다. Parakeet v3는 불가리아어, 크로아티아어, 체코어, 에스토니아어, 그리스어, 헝가리어, 라트비아어, 리투아니아어, 몰타어, 루마니아어, 슬로바키아어, 슬로베니아어 등 Vox.md의 Whisper 목록에 없는 여러 언어를 지원합니다. 자동은 시스템 언어를 따르며, Apple이 해당 로캘을 지원하면 Whisper 목록의 언어도 포함합니다.

속도와 정확도: 공개된 내용

이 수치는 각 게시자가 직접 측정한 것이며 2026년 11월 20일에 확인했습니다. Vox.md의 결과가 아니며 iPhone이나 Mac에서의 동작을 예측하지 않습니다.

  • Parakeet v2 모델 카드 (NVIDIA): Hugging Face Open ASR Leaderboard 데이터셋에서 평균 단어 오류율 6.05%(그리디 디코딩, 외부 언어 모델 없음). 모델 카드에 따르면 RTFx는 배치 크기 128에서 약 3,380이며 “데이터셋 오디오 길이와 배치 크기에 따라 달라질 수 있습니다.” 이 수치에 사용된 GPU는 명시되어 있지 않습니다.
  • Parakeet v3 모델 카드 (NVIDIA): 같은 리더보드 데이터셋에서 평균 WER 6.34%, 다국어 세트에서는 평균 11.97% (Fleurs), 7.83% (MLS), 11.98% (CoVoST).
  • Whisper 저장소 (OpenAI): 다음 turbo 모델은 최적화된 다음과 같이 설명됩니다: large-v3 더 빠른 전사와 최소한의 정확도 손실로, 속도는 약 8배입니다. 비교 대상: large, “A100에서 영어 음성을 전사”하여 측정.
  • FluidAudio README 문서: 은(는) M4 Pro에서 Parakeet v3 일괄 전사의 실시간 배율이 약 190배라고 보고합니다.

해당 Open ASR 리더보드 은(는) 더 많은 모델과 데이터셋을 나열합니다. 내용이 바뀌므로 최신 수치는 그곳에서 확인하세요. 리더보드 데이터셋은 내 녹음이 아닙니다. 결과는 기기, 억양, 배경 소음, 마이크, 오디오 길이, 선택한 모델 크기에 따라 달라집니다. 데이터센터 GPU에서 측정한 속도 배율은 휴대폰에 대해 알려 주는 바가 거의 없습니다. 출처 없는 “X배 빠름” 주장은 주의해서 받아들이세요.

저장 공간과 다운로드

Whisper 모델은 75 MB(Tiny)부터 1.6 GB(Large v3 Turbo)까지입니다. Parakeet 모델은 각각 약 800 MB입니다. 자동은 사용자가 모델을 받을 필요가 없으며, 지원되는 기기에서는 Apple 언어 에셋을 준비할 수 있습니다.

다운로드는 요청할 때만 이루어지고, 진행 중에 취소할 수 있으며, 나중에 삭제할 수 있습니다. 다운로드에는 네트워크 연결이 한 번 필요합니다. 선택한 백엔드가 준비되면 전사는 로컬에서 실행됩니다.

iPhone과 Mac 비교

  • iPhone: 자동(iOS 26 지원 기기와 언어에서는 Apple Speech), Whisper, Parakeet을 사용할 수 있습니다. iOS에서는 자동이 기본값입니다.
  • Mac: 모델 화면에서 Whisper 또는 Parakeet 모델을 다운로드, 선택, 삭제하고 전사 언어를 변경할 수 있습니다. Whisper는 지원되는 Mac에서 Metal 가속을 사용합니다. Whisper Base는 이전 Mac 기본값입니다.
  • 일시 정지 시 자동 중지(모든 백엔드 공통): 선택 사항인 약 ~1 MB의 Voice Pause 검출 모델은 말을 마친 뒤 실시간 녹음을 멈출 수 있습니다. 설정 → 모델에서 Voice Auto-Stop 사용 가능 를 켜고 휴식시간 길이 을 선택하세요(0.5, 0.75, 1, 1.5 또는 2초). 앱에서는 Automatic, Whisper, Parakeet 모두에서 동작한다고 설명하므로 선택 기준이 되지 않습니다. 일시 정지 시간은 대략적입니다. 참고: 음성 키보드 가이드.

Mac 모델 화면은 다음에 설명되어 있습니다: Mac 기록 및 모델. 통화 녹음은 다음을 참고하세요: Mac 회의를 Obsidian으로.

두 모델 모두 내 오디오로 테스트

실제로 녹음하는 종류의 음성으로 60~120초 분량의 클립을 사용하세요. 신경 쓰는 이름, 숫자, 억양을 포함하세요. 민감하지 않은 오디오를 고르세요. 무료 플랜(전사 15분, 전달 성공 10회)에서 실행할 수 있습니다.

  1. 인터넷에 연결한 상태에서 다음을 여세요: 설정 → 모델 를 열고 비교할 후보 두 개를 다운로드하세요. 예를 들면 Parakeet v3와 Whisper Small입니다. 내 언어를 지원하지 않는 옵션은 제외하세요.
  2. 다음을 만들거나 선택하세요: 루트 쓰기 가능한 Markdown 폴더를 지정하고, 결과를 쉽게 찾을 수 있도록 새 노트 대상을 사용하세요. 처리에는 원본 유지를 사용하면 AI 재작성 없이 인식된 텍스트가 노트에 담깁니다.
  3. Quick Capture의 음성 컨트롤에서 다음을 선택하세요: 초안에 추가. 초안에 추가는 완료된 전사를 보내지 않고 하나의 초안에 계속 덧붙입니다.
  4. 다음에서 첫 번째 모델을 선택하세요: 설정 → 모델, 그런 다음 클립을 녹음하거나 다음을 사용하세요: 오디오 또는 비디오 가져오기 기존 파일로. 두 모델이 동일한 오디오를 듣게 되므로 파일 하나를 가져오는 것이 가장 좋습니다.
  5. 초안에 모델 이름 같은 짧은 라벨 줄을 입력하세요. 다음에서 두 번째 모델을 선택하세요: 설정 → 모델 그리고 같은 클립을 다시 가져오세요.
  6. 탭하세요: 보내기 를 사용해 두 전사를 하나의 Markdown 노트로 전달하세요. (즉시 전송 는 각 전사를 끝나는 대로 전달하므로 노트가 두 개 생깁니다.)
  7. 노트를 열고 오디오와 비교하세요: 고유명사, 숫자와 날짜, 구두점, 빠지거나 반복된 구절. 또한 기기에서 각 전사에 걸린 시간도 기록하세요.
  8. 사용하지 않을 모델은 다음에서 삭제하세요: 설정 → 모델 저장 공간을 확보하세요.

자동을 기기에서 사용할 수 있다면 세 번째 실행으로 추가하세요. 자동을 선택하고 같은 클립을 가져오세요. 다음을 참고하세요: 가져온 오디오 전사 가져오기 세부 정보는 오프라인 전사 설정 그리고 연결 없이 워크플로를 확인하려면 다음을 참고하세요:

내 녹음으로 두 모델을 모두 써 보세요

개인정보 보호

전사는 기기에서 실행됩니다. Whisper 또는 Parakeet 모델을 다운로드할 때는 직접 또는 FluidAudio를 통해 Hugging Face에 연결합니다. 자세한 내용은 다음을 참고하세요: 개인정보 처리방침. 이 다운로드에는 캡처 내용이 전송되지 않습니다. 노트를 클라우드 기반 폴더에 저장하면 해당 제공업체가 자체 약관에 따라 완성된 파일을 동기화합니다.

제한 사항

  • 모든 경우에 가장 좋은 선택은 없습니다. 언어, 목소리, 마이크, 기기, 저장 공간 사용에 대한 허용 범위에 따라 달라집니다.
  • 위에 게시된 수치는 각 게시자가 자체 데이터셋과 하드웨어에서 측정한 것입니다.
  • Apple Speech는 지원되는 iOS 26 기기와 언어가 필요합니다. 그렇지 않으면 자동은 이미 다운로드한 로컬 모델만 사용합니다.
  • 어떤 백엔드를 선택하든 중요한 전사는 오디오와 대조해 검토하세요.

자주 묻는 질문

Parakeet이 Whisper보다 나은가요?

일반적으로는 그렇지 않습니다. NVIDIA는 Open ASR Leaderboard 데이터셋에서 Parakeet의 낮은 영어 단어 오류율을 발표했지만, 이것이 내 억양, 마이크, 방 환경까지 반영하지는 않습니다. Parakeet은 영어와 유럽 언어에 적합하고 Whisper는 더 많은 언어를 지원합니다. 두 모델 모두 내 클립으로 테스트하세요.

Parakeet은 다른 언어도 지원하나요?

Parakeet v2는 영어 전용입니다. Parakeet v3는 위에 나열된 25개 유럽 언어를 지원합니다. Vox.md에서는 중국어, 일본어, 한국어, 아랍어, 힌디어, 튀르키예어, 베트남어, 태국어, 노르웨이어를 지원하지 않으므로 이 언어에는 Whisper를 사용하세요.

iPhone에서 Whisper를 오프라인으로 실행할 수 있나요?

네, 모델을 한 번 다운로드한 뒤에는 가능합니다. 연결된 상태에서 Settings → Models에서 Whisper 모델을 다운로드하면 이후 전사는 기기에서 실행됩니다. Markdown을 오프라인으로 저장하려면 로컬에서 사용할 수 있고 쓰기 가능한 폴더도 필요합니다.

모델을 꼭 다운로드해야 하나요?

자동이 잘 맞는다면 필요 없습니다. iOS 26 지원 기기와 언어에서는 Apple Speech를 사용하며 실시간 텍스트가 표시됩니다. 언어나 기기가 지원되지 않거나 테스트에서 더 나은 결과가 나오면 Whisper나 Parakeet을 다운로드하세요.

내 녹음으로 두 모델을 모두 써 보세요.
