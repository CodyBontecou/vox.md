서비스 약관

시행일: 2026년 2월 9일 · 최종 업데이트: 2026년 10월 29일

요약

캡처 내용과 음성 전사는 Vox.md 서버에 전송되지 않습니다. 완성된 파일은 선택한 대상에만 쓰며 출시 빌드는 개인정보 처리방침에 설명한 대략적인 자사 온보딩 분석을 보냅니다.

약관 동의

Vox.md(이하 '앱', '당사')를 다운로드, 설치 또는 사용하면 본 서비스 약관의 구속을 받는 데 동의합니다. 동의하지 않으면 앱을 사용하지 마세요.

서비스 설명

Vox.md는 키보드, 공유, 위젯, 단축어가 통합된 iOS 및 macOS용 빠른 캡처 앱입니다. 텍스트, 링크, 이미지, 파일, 스캔, 스케치, 음성 캡처를 Obsidian 보관함을 포함한 사용자가 선택한 Markdown 폴더에 씁니다. 선택적인 음성 텍스트 변환에는 기기의 로컬 음성 인식 모델을 사용합니다.

라이선스

Vox.md 소스 코드는 다음 라이선스로 배포됩니다: GNU Affero 일반 공중 사용 허가서 버전 3.0. 타사 구성 요소는 각자의 라이선스를 유지합니다. 해당 라이선스는 소프트웨어의 복사, 수정, 재배포 등 권리에 적용됩니다.

Apple의 표준 사용 허가된 응용 프로그램 최종 사용자 사용권 계약 은 App Store 이용에 적용됩니다. 이 보충 약관은 별도 라이선스가 없는 Vox.md 운영 서비스, 구매, 자료에 적용되며 관련 오픈 소스 라이선스나 강행법이 부여한 권리를 제한하지 않습니다. 앱은 적법한 용도로만 사용하세요.

음성 모델

지원 기기에서 Vox.md는 Apple의 시스템 관리형 기기 내 음성 인식을 사용할 수 있습니다. Vox.md에서는 MIT 라이선스의 OpenAI Whisper 또는 지원 로컬 모델을 직접 선택해 다운로드할 수도 있습니다. Vox.md는 음성 모델 가중치를 번들로 제공하지 않습니다. 모델과 시스템 서비스는 '있는 그대로' 제공되며 전사 출력의 정확성, 완전성, 신뢰성을 보장하지 않습니다.

시스템 자산 준비와 선택적 로컬 모델 다운로드에는 인터넷 연결과 기기 저장 공간이 필요할 수 있습니다. 선택한 백엔드가 준비되면 로컬 전사가 가능합니다. 선택적 다운로드의 저장 공간 및 데이터 사용량 관리는 사용자 책임입니다.

사용자 책임

Vox.md 사용 시 다음에 동의합니다:

  • 모든 관련 법규를 준수해 앱을 사용합니다
  • 법이 요구하는 경우 녹음 대상자 모두의 동의 없이 오디오를 전사하지 않습니다
  • 캡처 내용, 대상, 전사 출력 사용 방식은 전적으로 사용자 책임입니다
  • 선택한 기능에 필요한 파일, 사진, 카메라, 마이크, 위치 권한만 부여합니다
  • 중요한 캡처에 의존하기 전에 원하는 노트에 도착했는지 확인합니다

정확성 고지

음성 텍스트 변환은 머신러닝 모델이 수행하며 본질적으로 불완전합니다. Vox.md는 어떤 전사의 정확성도 보장하지 않습니다. 품질에 영향을 주는 요소:

  • 선택한 Whisper 모델 크기(Tiny부터 Large v3 Turbo까지)
  • 오디오 품질, 배경 소음, 마이크 하드웨어
  • 화자의 억양, 말의 리듬, 언어
  • 기기 처리 성능

중대한 법률, 의료, 안전 관련 전사에는 Vox.md에 의존하지 마세요 출력을 독립적으로 검증하지 않은 채 사용하지 마세요.

지식재산권

디자인, 코드, 인터페이스, 브랜딩을 포함한 Vox.md 앱의 지식재산권은 개발자에게 있습니다. whisper.cpp 엔진과 Whisper 모델은 각 라이선스를 따르는 오픈 소스 소프트웨어입니다.

캡처한 텍스트, 링크, 미디어, 파일, 스캔, 스케치, 오디오, 생성된 전사에 대한 모든 소유권은 사용자에게 있습니다. 당사는 사용자 콘텐츠에 대한 권리를 주장하지 않습니다.

개인정보 보호

다음을 검토하세요: 개인정보 처리방침 에서 세부 사항을 확인하세요. 캡처 초안, 첨부파일, 파일 루트, 오디오, 전사, 키 입력, 내보낸 내용은 로컬 처리됩니다. 출시 빌드는 개인정보 처리방침의 대략적 자사 온보딩 분석을 보냅니다.

보증 부인

Vox.md는 다음 상태로 제공됩니다: “있는 그대로” 및 “제공 가능한 상태로” 명시적·묵시적 보증을 일절 제공하지 않으며 상품성, 특정 목적 적합성, 비침해의 묵시적 보증 등을 포함하되 이에 한정되지 않습니다.

당사는 앱의 무중단, 무오류, 유해 구성 요소 부재, 결함 수정을 보증하지 않습니다.

책임 제한

관련 법이 허용하는 최대 범위에서 Vox.md와 개발자는 다음으로 인한 간접적, 부수적, 특별, 결과적, 징벌적 손해에 어떠한 경우에도 책임을 지지 않습니다:

  • 앱의 사용 또는 사용 불능
  • 전사 출력의 부정확성
  • 실패, 지연, 중복, 잘못된 루트의 캡처
  • Obsidian, 파일 앱, 타사 저장 제공자에 의한 변경
  • 기기 데이터에 대한 무단 접근이나 변경
  • 앱에 관한 기타 사항

App Store 약관

Vox.md는 Apple의 App Store를 통해 배포됩니다. 앱 사용에는 사용 허가된 응용 프로그램 최종 사용자 사용권 계약을 비롯한 Apple의 표준 이용 약관도 적용됩니다. Apple은 앱이나 콘텐츠에 책임이 없으며 앱의 유지보수, 지원, 보증 서비스를 제공할 의무가 없습니다.

종료

본 약관은 종료될 때까지 유효합니다. 조항을 준수하지 않으면 본 약관에 따른 권리가 자동 종료됩니다. 종료 시 앱 사용을 모두 중단하고 기기에서 삭제해야 합니다.

약관 변경

당사는 언제든 본 약관을 수정할 권리를 보유합니다. 수정 약관은 '최종 업데이트' 날짜를 바꾸어 이 페이지에 게시합니다. 변경 게시 후 앱을 계속 사용하면 수정 약관에 동의한 것으로 간주합니다.

준거법
