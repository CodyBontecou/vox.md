개인정보 처리방침

시행일: 2026년 2월 9일 · 최종 업데이트: 2026년 10월 26일

요약

Vox.md는 캡처 초안, 첨부파일, 전사, 노트 루트를 기기에 보관합니다. 완성된 파일만 선택 대상에 보내며 캡처 내용을 Vox.md 서버에 보내지 않습니다. 출시 빌드는 아래의 대략적 자사 온보딩 분석을 보냅니다.

개요

본 개인정보 처리방침은 iOS 및 macOS 앱과 확장을 사용할 때 Vox.md(이하 '당사' 또는 '앱')가 정보를 처리하는 방식을 설명합니다. 오디오, 전사, 키 입력, 캡처 초안, 첨부파일, 내보낸 파일 내용, 사용자가 입력한 텍스트는 로컬에서 처리합니다. 파일은 선택한 위치에만 쓰며 선택한 저장 제공자는 자체 약관에 따라 파일을 동기화할 수 있습니다.

수집하지 않는 정보

Vox.md는 개발자, 분석, 광고, 추적을 위해 아래 정보를 수집하지 않습니다. 아래의 대략적인 온보딩 메타데이터는 자동으로 기기를 떠날 수 있습니다. 캡처 내용은 동기화 폴더에 쓰기나 지도 제공자 링크 열기 등 사용자가 선택한 기능으로만 기기를 떠납니다. 자세한 내용은 아래와 같습니다.

  • 오디오 녹음 또는 음성 데이터
  • 전사 텍스트 또는 전사 기록
  • 키 입력, 입력된 텍스트, 키보드 입력
  • 이름, 이메일, 전화번호 등의 개인정보
  • 개발자, 분석, 광고, 추적용 위치 데이터
  • 로컬 캡처를 위해 직접 선택한 사진, 스캔, 스케치, 오디오, 파일
  • 파일명, 폴더 경로, 템플릿 텍스트, 내보낸 노트 내용, 모델 파일 경로
  • 광고 식별자, 원본 IP 주소 저장, 타사 추적 식별자

개인정보 보호형 온보딩 분석

출시 빌드는 온보딩, 설정 장애 요인, 구매 또는 복원 결과를 파악하기 위한 소량의 자사 이벤트를 보냅니다. 개발 빌드는 설정 테스트를 위해 명시적으로 활성화해야 합니다. 이벤트는 의도적으로 대략적이며 광고나 앱 간 추적에 사용하지 않습니다.

온보딩 분석에 포함될 수 있는 것:

  • 퍼널 진행 집계에만 사용되는 익명의 Vox.md 설치 ID
  • 온보딩 시작, 마이크 권한 완료, 모델 설정 완료, 결제 화면 표시, 구매 또는 복원 결과, 온보딩 완료 같은 이벤트 이름
  • 앱 버전, 빌드 번호, 플랫폼, 실험 변형
  • 마이크 권한 상태, 모델 엔진 및 크기 구간, 파일 내보내기 형식/모드, 무료 시간 및 성공한 캡처 사용 구간, 결제 화면 맥락 같은 대략적인 설정 상태

분석에는 오디오, 전사, 받아쓴 텍스트, 키 입력, 파일/폴더 경로, 템플릿 텍스트, 모델 경로, 이름, 이메일, 원시 날짜, 원시 IP 주소, 기기 이름이 포함되지 않습니다.

기기 내 처리

모든 음성 텍스트 변환은 전적으로 기기에서 실행됩니다. 지원 iOS 26 기기의 자동은 Apple 시스템 관리 Speech 프레임워크를 사용합니다. 로컬 Whisper나 Parakeet을 선택 다운로드할 수도 있습니다. 마이크 오디오는 선택한 기기 내 백엔드가 처리하며 네트워크로 전송되지 않습니다.

루트의 캡처 텍스트 처리를 직접 켜면 해당 입력 텍스트, 기기 내 OCR, 음성 전사를 Apple Intelligence로 로컬 정리·서식화할 수 있습니다. 기기 내 지능이 없으면 정해진 서식이나 원문으로 대체합니다. Vox.md는 캡처 텍스트를 자체 서버나 타사 AI API에 보내지 않습니다.

전사 결과, 캡처 초안, 재시도 요청은 앱의 샌드박스 컨테이너와 공유 App Group에 로컬 저장됩니다. 앱, 키보드, 위젯, 공유 확장 등 서명된 Vox.md 구성 요소만 접근할 수 있습니다. Vox.md 서비스나 서버는 접근할 수 없습니다.

키보드 확장

Vox.md는 기기의 모든 앱에서 음성 텍스트 입력을 제공하는 사용자 키보드 확장을 포함합니다. Apple 요구에 따라 다음을 공개합니다:

  • 현재 키보드 워크플로에는 전체 접근 허용이 필요합니다. 키보드가 공유 App Group 상태를 쓰고 Vox.md 본 앱과 녹음을 조율하게 합니다.
  • Vox.md는 전체 접근으로 키 입력, 받아쓴 텍스트, 전사, 마이크 오디오를 업로드, 판매, 분석하지 않습니다. 키보드는 해당 콘텐츠를 Vox.md나 타사 서버에 전송하지 않습니다.
  • 키보드 확장은 기기의 공유 App Group 컨테이너로 서명된 Vox.md 앱 구성 요소와 통신합니다.

마이크 사용

Vox.md는 음성 전사용 오디오 캡처를 위해 마이크 접근을 요청합니다. 마이크 오디오:

  • Apple Speech 또는 선택 다운로드한 Whisper/Parakeet 모델이 로컬 처리
  • 로컬 전사에 파일이 필요할 때만 임시 기록
  • 서버, API, 타사 서비스로 전송하지 않음
  • 루트에 오디오 보관을 명시적으로 설정하거나 캡처 초안에 음성 녹음을 삽입하지 않는 한 전사 후 삭제됩니다

위치 사용

Vox.md에는 명시적인 위치 기능이 두 가지 있습니다. 독립적인 캡처 바의 현재 위치 작업은 위치를 한 번 요청하여 로컬 초안에 Google Maps 링크를 삽입합니다. 별도로 현재 위치는 기본적으로 꺼져 있으며 iOS/iPadOS, 공유 시트, 단축어와 인텐트, 음성 및 키보드 기반 루트 녹음, 위젯과 컨트롤, Markdown으로 라우팅되는 Apple Watch 캡처, Mac에서 루트별로 활성화할 수 있습니다. 루트는 이 단일 스냅샷을 다음에 사용할 수 있습니다: {location} 항목 템플릿 링크를 추가 메타데이터 작성 없이 사용할 수 있습니다. 위치 메타데이터 작성은 별도로 선택해야 합니다. Watch의 녹음만 모드는 Markdown 위치 정보 없이 원본 오디오를 파일로 내보내며 위치를 요청하지 않습니다.

활성 루트는 캡처 소스에 따라 보내기, 호출, 녹음 중지 시 시작 시점 위치를 한 번 요청합니다. 기본값은 정확함입니다. 도시는 결과 보관 전에 위도와 경도를 소수점 둘째 자리로 반올림하고 관심 장소 이름을 제거합니다. 모든 파생 필드, 템플릿 링크, 제공자 링크는 같은 개인정보 보호 좌표를 사용합니다. Vox.md는 위치를 지속 모니터링하거나 백그라운드 추적하거나 분석 및 로그에 포함하거나 Vox.md 서버에 전송하지 않습니다.

활성 메타데이터에 장소, 도시, 지역, 국가가 필요하면 Vox.md는 Apple 시스템 역지오코더를 사용합니다. 토큰 전용 현재 위치는 이 조회를 건너뜁니다. 무료이며 API 키가 필요 없지만 Apple 약관에 따라 Apple에 네트워크 요청을 할 수 있습니다. 역지오코딩 실패로 캡처가 막히지는 않으며 좌표 전용 메타데이터는 사용 가능합니다. Vox.md는 제공자 접속 없이 Apple Maps, Google Maps, OpenStreetMap 링크를 만들 수 있습니다. 링크를 열 때만 정확한 또는 반올림된 좌표가 제공자에게 공개됩니다.

위치가 없으면 대화형 화면에서 재시도, 취소, 한 번만 위치 없이 보내기, 해당 루트에 항상 위치 없이 보내기 저장을 선택할 수 있습니다. 저장한 동작은 루트 설정에서 초기화할 수 있습니다. 무인 요청의 '물어보세요' 모드는 시작 시점의 위치 사용 불가 결과를 보관해 나중에 결정하도록 하며 재시도 중 새 위치를 가져오지 않습니다. 대기 및 실패 요청에는 로컬 복구에 필요한, 이미 개인정보 보호 설정이 적용된 결과가 남을 수 있습니다. Markdown에 기록된 좌표는 선택한 노트의 일부가 되며 파일 동기화 제공자가 자체 약관에 따라 파일을 처리할 수 있습니다.

설정 예시와 캡처 소스 동작은 다음을 참조하세요: 현재 위치, {location}, 메타데이터.

음성 모델

Vox.md는 음성 모델 가중치를 번들로 제공하지 않습니다. Apple 지원 언어 자산은 iOS가 관리합니다. 선택적 Whisper, Parakeet, 음성 멈춤 모델은 선택한 후에만 다운로드되어 기기에 저장됩니다. 모델 준비나 다운로드에는 계정이나 개인정보가 필요하지 않습니다.

타사 서비스

Vox.md는 타사 분석 SDK, 광고 네트워크, 충돌 보고 SDK, 앱 간 추적 서비스와 통합하지 않습니다. 사용자가 시작한 Whisper 및 Parakeet 다운로드는 직접 또는 FluidAudio를 통해 Hugging Face의 모델 배포 인프라에 연결됩니다. 요청에는 초안, 입력 텍스트, 오디오, 전사, 첨부, 경로, 위치가 없지만 제공자는 자체 약관에 따라 일반 HTTPS 연결 데이터와 요청 모델 식별자를 받을 수 있습니다.

캡처 편집기는 다음에서 영감을 주는 인용문을 묶음으로 요청합니다: ZenQuotes API 에서 받아 기기 캐시에서 번갈아 표시합니다. 요청에는 캡처 초안, 입력 텍스트, 오디오, 첨부파일, 파일 경로, 위치, 설치 식별자, 분석 데이터가 포함되지 않습니다. 다른 HTTPS 서비스처럼 ZenQuotes도 자체 약관에 따라 IP 주소와 사용자 에이전트 등 기술적 연결 데이터를 받을 수 있습니다. 자사 온보딩 이벤트는 Vox.md Cloudflare Worker로 직접 전송되며 위의 엄격한 허용 목록에 따라 D1 데이터베이스에 저장됩니다.

데이터 저장 및 삭제

전사 기록, 캡처 초안, 준비된 첨부파일, 다운로드 모델, 템플릿, 설정, 무료 사용 기록을 포함한 캡처 내용과 로컬 앱 데이터는 기기 또는 명시적으로 선택한 파일 대상에 저장됩니다. 콘텐츠 없는 성공 캡처 장부에는 최대 열 개의 성공 요청 수와 임의 식별자만 들어 있어 로컬 앱 데이터가 남아 있는 동안 재시도 이중 차감을 방지합니다. 캡처 텍스트, 파일명, 대상, 첨부파일 메타데이터는 없으며 시스템 키체인에 저장되거나 Vox.md로 전송되지 않습니다.

본 방침 변경 전 버전은 시스템 키체인에 비활성 상태이며 콘텐츠 없는 무료 사용 항목을 남겼을 수 있습니다. 현재 버전은 접근하지 않으며 키체인 접근에서 삭제해도 캡처, 전사, 구매에 영향이 없습니다.

로컬 최근 캡처 목록에는 결과, 소스, 루트 식별자 및 표시명, 대상 식별자 및 표시명, 상대 노트 경로, 첨부 수, 타임스탬프, 대략적인 실패 종류 등 전송 메타데이터만 있습니다. 노트 텍스트, 링크, 좌표, 위치 이름이나 템플릿, 책갈피, 절대 경로, 첨부파일명을 복제하지 않습니다. 대기/실패 캡처에는 로컬 복구용 콘텐츠만 남으며 개인정보 보호가 적용된 위치 스냅샷이나 영속 사용 불가 결과가 포함될 수 있습니다. 전송 성공 직후 복구 가능한 캡처 요청은 식별자와 타임스탬프만 있는 삭제 표식으로 바뀝니다. 완료된 Watch 대기열도 정리되고 업그레이드는 기존 완료 요청을 정제합니다.

로컬 사용자 콘텐츠와 설정을 삭제하는 방법:

  • 앱 내 기록에서 개별 전사 삭제 또는 최근 캡처 메타데이터 지우기
  • 설정에서 다운로드한 모델 삭제
  • Vox.md와 로컬 앱 데이터를 삭제합니다. 무료 사용 할당량도 초기화되며 적격한 StoreKit 구매는 Apple을 통해 계속 복원할 수 있습니다.
