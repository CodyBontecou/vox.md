Mac에서 오디오 파일을 로컬로 전사해 Markdown으로 저장하기

먼저 무료 내장 옵션을 소개하고, 이미 가진 파일에서 Obsidian이나 원하는 폴더의 Markdown 노트까지 이어지는 로컬 경로를 설명합니다.

필요 조건
Vox.md: macOS 14 이상 · 다운로드한 음성 모델. Apple 내장 전사: Mac과 언어에 대해서는 Apple 지원 페이지를 확인하세요.
짧은 답변

Apple의 음성 메모와 메모 앱은 Mac에서 오디오를 무료로 전사할 수 있으며, 많은 분들께는 그것으로 충분합니다. 기존 오디오 또는 비디오 파일을 Markdown 노트로 만들려면 Mac용 Vox.md를 열고 오디오 가져오기… 을 메뉴 막대에서 선택하고(또는 캡처 작업 공간에서 파일을 가져오고), 로컬 Whisper 또는 Parakeet 모델이 전사하게 한 다음, 텍스트를 검토하고 루트의 노트로 보내세요.

아래 Apple 관련 내용은 Apple 지원 페이지를 바탕으로 합니다 Mac의 음성 메모에서 전사 보기 및 Mac의 메모에서 오디오 녹음 및 전사, 2026년 11월 22일에 확인했습니다. Apple의 페이지는 바뀔 수 있으니 사용 중인 Mac에서 확인하세요. Vox.md 단계는 다음을 따릅니다: Mac 문서.

아직 녹음하지 않았나요? 다음을 참고하세요: Mac에서 오디오 녹음하는 방법.

Mac에 이미 있는 무료 옵션

음성 메모

Apple의 음성 메모 페이지에 따르면 다음 버튼을 클릭할 수 있습니다: 전사 버튼을 누르면 녹음 중에 텍스트를 실시간으로 볼 수 있고, 완료된 녹음을 선택해 같은 버튼을 클릭해도 됩니다. 녹음 목록에서 제목이나 전사본의 텍스트를 검색할 수 있으며, 전사본 텍스트는 선택한 뒤 Control 키를 누른 채 클릭하고 다음을 선택해 복사할 수 있습니다: 복사. Apple에 따르면 macOS 14 이전 버전에서 만든 녹음이나 전사를 지원하지 않는 기기에서 만든 녹음을 열면 음성 메모가 자동으로 전사하며, 오디오 전사는 모든 국가나 지역에서 사용할 수 있는 것은 아닙니다.

메모

Apple의 메모 페이지에는 노트 안에서 오디오를 녹음하는 방법이 설명되어 있습니다. 첨부 파일 버튼을 클릭하고 오디오 녹음를 선택하고 녹음한 다음, 전사 버튼을 클릭하면 전사본이 표시됩니다. 오디오 전사는 해당 페이지에 Apple이 나열한 기기 언어에 대해 M1 이상의 Mac에서 사용할 수 있다고 합니다. 전사 버튼이 나타나지 않으면, Apple에 따르면 Mac이 최소 요구 사항을 충족하지 않거나 지원되는 언어를 감지하지 못한 것입니다.

한계

텍스트는 복사해서 꺼내기 전까지 해당 앱 안에 남아 있습니다. 메모에서는 오디오 녹음을 삭제하면 전사본도 삭제된다고 Apple이 설명합니다. 두 앱이 어떤 파일 형식을 가져올 수 있는지는 Apple의 페이지에서 확인할 수 없으므로 사용하는 녹음으로 직접 확인하세요. 이 가이드는 이에 대해 아무 주장도 하지 않습니다.

최후의 수단으로 오디오를 재생하면서 텍스트 편집기에 받아쓰는 사람도 있습니다. 이는 우회 방법일 뿐 파일 전사가 아닙니다. 자세한 내용은 Mac 받아쓰기 를 참고하세요. 받아쓰기 자체에 대한 내용입니다.

어떤 방법이 맞을까요?

이 표에는 Apple의 페이지나 Vox.md 문서에 명시된 내용만 담았습니다. “문서화되지 않음”은 인용한 출처에 해당 내용이 없다는 뜻입니다. 정확도나 속도에 대한 주장은 하지 않습니다.

작은 화면에서는 표를 옆으로 스와이프하세요.

Mac용 Vox.md 준비하기

  1. 설치. Mac용 Vox.md에는 macOS 14 이상이 필요합니다. 아래 App Store 링크에서 받으세요.
  2. 모델 다운로드. 오픈 설정 → 모델 을 선택하고 모델을 하나 다운로드하세요. Whisper는 Tiny(75 MB)부터 Large v3 Turbo(1.6 GB)까지, Parakeet v2(약 800 MB, 영어), Parakeet v3(약 800 MB, 25개 언어) 중에서 고를 수 있습니다. 전사 언어는 같은 화면에서 설정합니다. 지원되는 Mac에서는 Whisper가 Metal 가속을 사용합니다. 네트워크를 사용하는 단계는 모델 다운로드뿐입니다. 자세한 내용은 Whisper 대 Parakeet 를 참고하세요. whisper.cpp 는 Whisper 모델을 실행하고 FluidAudio 는 Parakeet를 실행합니다.
  3. 루트를 선택하거나 새로 만드세요. 루트는 대상 폴더 또는 볼트와 대상 노트를 담습니다. 대상 노트는 새 노트, 계속 이어지는 데일리 노트, 또는 제목 아래의 기존 노트입니다. 자세한 내용은 문서의 루트.

오디오 대신 자막 파일(.srt 또는 .vtt)이 이미 있나요? 음성을 변환할 필요가 없습니다: SRT 및 VTT를 텍스트 또는 Markdown으로 변환 브라우저에서 정리합니다.

파일 가져오기 및 전사

  1. 가져오기. Vox.md 메뉴 막대에서 다음을 선택하세요: 오디오 가져오기…, 또는 오디오를 캡처 작업 공간으로 가져오거나 끌어다 놓으세요. 문서에 따르면 오디오와 동영상 파일이 허용되며 녹음과 같은 로컬 받아쓰기를 거칩니다. 비디오 파일에 대해서는 다음을 참조하세요. 비디오를 텍스트로 받아쓰기.
  2. 초안에 추가 또는 즉시 전송을 선택하세요. 다음을 사용하면 즉시 전송 전사가 끝나면 전달됩니다. 초안에 추가 먼저 검토할 수 있습니다. 이름, 숫자, 날짜는 오디오와 대조해 확인하세요.
  3. 선택 사항: 연설자들의 식별. 켜세요: 연설자들의 식별 를 루트에서 켜면 익명의 최선형 화자 라벨이 붙습니다. 처음에는 별도의 모델을 준비합니다. 실행할 수 없으면 일반 전사본은 그대로 보관되고 이유는 보관함에 표시됩니다.
  4. 선택 사항: 처리 모드. 루트에서는 원본 유지, 문장 다듬기, 회의 메모, 할 일 체크리스트, 사용자 지정 지침을 사용할 수 있습니다. Apple Intelligence 모드에는 macOS 26을 지원하는 하드웨어가 필요합니다. 지원되지 않으면 할 일 체크리스트와 회의 메모는 내장 포매터를 사용하고, 문장 다듬기와 사용자 지정 지침은 원본 텍스트를 유지합니다.
  5. 전송. Command-Return 키를 눌러 캡처를 루트의 노트로 보냅니다.

Markdown 노트 확인

선택: 마지막 내보내기 표시 을 메뉴 막대에서 선택하거나, 보관함에서 항목을 찾아 Finder에서 표시한 다음 Obsidian에서 파일을 여세요. 텍스트만 필요하다면 마지막 전사 복사. 녹음으로 채울 노트 구조는 다음을 참고하세요: 회의 메모 템플릿 생성기.

녹음이 발표 연습이라면 변환된 텍스트와 녹음 길이를 다음에 붙여 넣으세요: 연설 시간 계산기 에 붙여 넣어 분당 단어 수와 본인 속도로 말할 때 대본의 말하기 시간을 측정하세요.

Mac에서 나가는 것

전사는 Mac에서 실행되며, Vox.md는 캡처 내용을 Vox.md 서버로 보내지 않습니다. 모델 다운로드는 Hugging Face 또는 FluidAudio 인프라에 연결합니다. 대상 폴더가 iCloud 등의 서비스로 동기화되는 경우, 해당 서비스가 자체 약관에 따라 파일을 처리합니다. 다음을 참고하세요: 개인정보 처리방침.

문제 해결

  • 전사본이 없거나 언어가 잘못됨. 설정 → 모델에서 모델이 다운로드되어 선택되어 있는지, 언어가 설정되어 있는지 확인하세요.
  • 노트가 나타나지 않음. 루트의 대상 폴더를 확인하고 Vox.md가 해당 폴더에 접근할 수 있는지 확인하세요.
  • 긴 파일은 시간이 걸립니다. 큰 모델일수록 긴 녹음에는 시간이 더 걸립니다. 먼저 작은 모델로 시도한 다음 비교해 보세요.
  • 무료 사용량을 모두 사용함. 전사 15분과 성공적인 전달 10회가 포함되며, 이후 일회성 평생 잠금 해제입니다. 공식 가격은 App Store에 표시된 가격입니다. 자세한 내용은 무료 사용과 평생 잠금 해제.

녹음을 내가 소유하는 노트로 바꾸세요.
