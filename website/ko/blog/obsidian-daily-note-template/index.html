1. 템플릿 생성

생성기에는 JavaScript가 필요합니다. 사용할 수 없으면 위의 기본 템플릿을 그대로 쓰면 됩니다.

템플릿 시스템
속성(YAML 프런트매터)
섹션

위로 및 아래로 버튼으로 순서를 바꿀 수 있습니다.

날짜와 링크

이전 날/다음 날 링크와 파일 이름에서 날짜 읽기에는 Templater가 필요합니다. 코어 Templates 페이지에는 날짜 오프셋이 설명되어 있지 않으므로 코어 Templates에서는 이 옵션이 꺼집니다.

Templater에서는 날짜 속성을 노트를 만든 날 대신 노트의 파일 이름에서 가져올 수 있습니다. 두 옵션 모두 파일 이름이 아래 날짜 형식과 일치한다고 가정합니다.

일반 Markdown에는 변수가 없으므로 이 옵션은 꺼지고 날짜 속성은 직접 채울 수 있도록 비워 둡니다.

Templater 플러그인: 이 <% %> 명령은 Templater가 노트를 처리할 때 실행됩니다. 코어 Templates 플러그인은 이를 실행하지 않으므로, 일일 노트로 만드는 노트에는 Templater 전용 템플릿 폴더를 사용하거나 Templater의 새 파일 생성 시 트리거를 켜세요.

일반 Markdown: 제목과 빈 속성만 들어 있습니다. 자동으로 채워지는 내용은 없습니다.

날짜 형식이 기본 YYYY-MM-DD이(가) 아닙니다. 일 단위 주기의 Vox.md 롤링 노트는 {period} 을(를) 예를 들어 2026-11-21와 같은 날짜로 바뀌므로, 경로는 Obsidian이 만드는 파일과 같은 파일을 가리켜야 합니다. 가장 간단한 해결책은 YYYY-MM-DD 형식의 파일 이름을 유지하는 것입니다. 다른 형식을 쓰려면 지원되는 경로 토큰을 루트 문서 에서 확인한 다음 다른 형식을 사용하세요.

템플릿을 클립보드에 복사했습니다. 복사하지 못했습니다. 템플릿을 선택해 직접 복사하세요. 다운로드 완료: daily-template.md 선택 항목을 기본 템플릿으로 초기화했습니다. {section}을(를) 위로 옮겼습니다. {section}을(를) 아래로 옮겼습니다. {section}을(를) 위로 이동 {section}을(를) 아래로 이동 위로 아래로 여기서는 미리 볼 수 없음: {tokens}. Moment.js 형식 문서에서 확인하세요. 다음 문자는 모든 시스템에서 파일 이름에 쓸 수 있는 것은 아닙니다: {chars} 날짜 형식의 슬래시는 하위 폴더를 만듭니다. 여기서는 설정되지 않음 Obsidian이 만드는 파일과 다릅니다. 아래 참고를 확인하세요.

2. 일일 노트가 템플릿을 사용하도록 설정

생성된 텍스트를 템플릿 폴더에 노트로 저장하세요. 예를 들어 Templates/Daily.md. 그런 다음 설정 → 일일 노트 을(를) 열고 플러그인 옵션에서 다음 세 가지를 설정하세요:

  1. 날짜 형식: Obsidian이 일일 노트의 이름과 경로를 정하는 방식입니다. 미리 보기 위에 표시된 값을 복사하세요.
  2. 새 파일 위치: 일일 노트를 다른 노트와 분리하고 싶을 때 Obsidian이 새 일일 노트를 만드는 폴더입니다.
  3. 템플릿 파일 위치: 방금 저장한 노트입니다.

Obsidian은 설정한 뒤 새 일일 노트를 만들 때만 템플릿을 사용하므로 이미 있는 노트는 바뀌지 않습니다. 테스트하려면 아직 노트가 없는 날짜를 여세요. 자세한 내용은 일일 노트 (Obsidian 도움말)

날짜, 요일, 태그를 --- 줄 사이에 넣으면 노트 속성이 됩니다. 자세한 내용은 속성. mood와 energy는 비어 있으므로 텍스트로 채울 수 있습니다. 다른 속성을 검사하거나 만들려면 다음을 사용하세요: 속성 생성기 및 검사기. 이미 가지고 있는 목록으로 Tasks 섹션을 채우려면 다음을 사용하세요: Markdown 체크리스트 메이커.

3. 날짜 형식과 폴더

날짜 형식에는 Moment.js 서식 토큰. 생성기는 자주 쓰는 다음 항목을 영어로 미리 보여 줍니다:

토큰의미예시
YYYY네 자리 연도2026
YY두 자리 연도26
MM월 번호(두 자리)11
M월 번호11
MMM월 약어11월
MMMM월 전체 이름11월
DD일(두 자리)21
D일21
ddd요일 약어토
dddd요일 전체 이름토요일
ww연중 주 번호(두 자리, 영어권 주 규칙: 주는 일요일에 시작하고 1주차에 1월 1일이 포함됨)47
Q분기4

대괄호 안의 텍스트, 예를 들어 [Week]은(는) 그대로 출력됩니다. 그 밖의 Moment 토큰은 미리 보기에 표시되지 않으며, 생성기가 목록으로 알려 주고 자세한 내용은 Moment.js 문서에 있습니다.

날짜 형식에 슬래시를 넣으면 하위 폴더가 만들어집니다. Obsidian 자체 예시는 YYYY/MMMM/YYYY-MMM-DD을(를) 쓰면 예를 들어 2023/January/2023-Jan-01와 같은 노트가 만들어집니다(연도 폴더, 월 폴더, 파일 이름 순서). 새 파일 위치도 설정하면 날짜 폴더는 그 안에 만들어집니다. 예를 들어 Journal 에 YYYY/MM/YYYY-MM-DD 을(를) 함께 쓰면 경로는 Journal/2026/11/2026-11-21.md.

미리 보기에서는 요일 이름과 월 이름이 영어로 표시됩니다. Obsidian은 사용자의 언어로 표시할 수 있으며, 주 번호는 로케일의 주 규칙을 따를 수 있습니다.

4. Core Templates와 Templater 비교

코어 Templates 은(는) Obsidian에 기본 포함되어 있으며 다음을 지원합니다: {{title}}, {{date}} 및 {{time}}, 그리고 콜론 뒤에 형식을 붙이는 방식, 예를 들어 {{date:YYYY-MM-DD}}. {{date}} 은(는) 템플릿을 삽입한 날짜이며 노트 이름에서 읽은 날짜가 아닙니다. Templates 도움말 페이지 에는 날짜 오프셋이 설명되어 있지 않으므로 코어 Templates에서는 이전 날/다음 날 링크를 생성하지 않습니다.

Templater 플러그인 는 커뮤니티 플러그인입니다. 이 플러그인의 tp.date.now 은(는) 형식, 일 단위 오프셋(선택), 노트 제목 같은 기준 날짜(선택), 그 기준 날짜를 읽는 데 쓰는 형식을 받습니다. 생성기의 이전 날/다음 날 링크는 이 형태를 사용합니다:

[[<% tp.date.now("YYYY-MM-DD", -1, tp.file.title, "YYYY-MM-DD") %>]]
[[<% tp.date.now("YYYY-MM-DD", 1, tp.file.title, "YYYY-MM-DD") %>]]

파일 이름을 읽기 때문에 다른 날짜의 노트를 만들어도 그 노트의 날짜와 일치합니다. 마지막 인수의 형식은 파일 이름 형식과 같아야 합니다. 날짜 형식에 슬래시가 있으면 생성기는 마지막 슬래시 뒤의 부분, 즉 파일 이름을 사용합니다. 자세한 내용은 Templater의 date 모듈.

5. iPhone 또는 Mac에서 오늘 노트에 추가

템플릿은 노트의 틀을 만들어 줍니다. Vox.md는 하루 동안 여기에 내용을 추가할 수 있습니다. 생각을 말하거나 입력하면 그날의 노트에 저장됩니다. 음성은 기기에서 전사됩니다. 캡처 프리셋에서 롤링 노트 다음과 함께 매일 주기와 다음과 같은 경로를 선택하세요: Journal/{period}.md. 일 단위 주기에서는 {period} 는 다음과 같은 날짜로 해석됩니다: 2026-11-21.

선택: 이 배치를 선택하고, 제목은 템플릿에 있는 것, 예를 들어 ## Inbox을(를) 고르면 새 항목이 그 아래에 추가됩니다. 제목이 없을 때는 실수 표시 또는 제목 만들기을(를) 선택하세요. 항목 접두사로 예를 들어 - 을(를) 추가하면 각 캡처가 목록 항목이 됩니다. 생성기의 Inbox 섹션도 같은 글머리 기호를 사용합니다.

Vox.md는 파일에 쓸 때 Obsidian 템플릿을 적용하지 않습니다. 템플릿이 필요하면 먼저 Obsidian에서 오늘 노트를 연 다음 캡처를 보내세요. 경로는 Obsidian이 사용하는 파일을 가리켜야 하므로 YYYY-MM-DD 형식의 파일 이름을 유지하세요. 다른 형식은 일치하는지 확인한 뒤에 사용하세요. Obsidian 일일 노트에 텍스트와 음성 추가하기 에서 전체 설정을 다루며, 루트 참고 자료 에 옵션이 정리되어 있습니다.

6. 자주 묻는 질문

템플릿이 적용되지 않는 이유는 무엇인가요?

Obsidian은 새 일일 노트를 만들 때만 템플릿을 사용하므로 이미 있는 노트는 바뀌지 않습니다. 템플릿 파일 위치 이(가) 설정 → 일일 노트에서 올바른 노트를 가리키는지 확인하세요. 템플릿에 <% %> 명령이 텍스트로 그대로 남아 있다면 Templater 명령입니다. 일일 노트 폴더에는 Templater의 폴더 템플릿을 사용하거나 코어 Templates 버전을 생성하세요.

일일 노트가 엉뚱한 폴더에 만들어지는 이유는 무엇인가요?

경로는 두 가지 설정으로 정해집니다: 새 파일 위치 와(과) 날짜 형식의 슬래시입니다. 위 미리 보기에서 두 가지가 함께 적용된 결과를 볼 수 있습니다. 예를 들어 YYYY/MM/YYYY-MM-DD 처럼 원하지 않는 연도 및 월 폴더가 만들어진다면, 단순한 형식을 쓰고 폴더만 설정하세요.

Dataview를 쓸 수 있나요?

템플릿은 일반 Markdown이므로 붙여 넣은 뒤 원하는 플러그인용 코드 블록을 직접 추가할 수 있습니다. 생성기는 플러그인 코드를 작성하지 않습니다.

생성기가 선택한 내용을 어딘가로 전송하나요?

아니요. 템플릿은 이 페이지의 스크립트가 만듭니다. 마지막 선택 항목은 브라우저의 로컬 저장소에 저장되어 다음에도 남아 있으며, 초기화를 누르면 지워집니다.

하루 종일 노트를 채우세요.

음성이나 텍스트로 생각을 캡처하면 Vox.md가 그날의 Markdown 노트에 추가합니다.
