Obsidian 회의록 템플릿 생성기

원하는 속성과 섹션을 고른 다음, 사용하는 템플릿 시스템의 구문으로 작성된 템플릿을 복사하거나 다운로드하세요.

작성자
Cody Bontecou
업데이트
2026년 11월 19일
필요 조건
Obsidian(모든 플랫폼). 선택 사항: 녹음으로 노트를 채우려면 iPhone, iPad 또는 Mac용 Vox.md.

일반 Markdown: Vox.md 토큰을 단일 중괄호로 쓴 제목과 필드입니다. Obsidian은 이 토큰을 입력한 그대로 둡니다. 루트가 이 파일을 보관함 템플릿으로 사용하면 Vox.md가 토큰을 채웁니다. 참고: 녹음으로 노트 채우기.

2. Obsidian에 템플릿 추가

Core Templates 플러그인. 설정 → 코어 플러그인에서 Templates를 켠 다음 이 항목을 설정하세요: Template folder location(예: Templates). 템플릿을 그 폴더에 .md 파일로 저장하세요. 새 노트에서 명령 팔레트로 Templates: Insert template 을(를) 실행하고 템플릿을 고르세요. Obsidian은 {{title}}, {{date}} 및 {{time}} 을(를) 템플릿을 삽입할 때 바꿉니다. 콜론 뒤에 형식을 붙인 경우(예: {{date:YYYY-MM-DD}})에는 Moment.js 토큰이 사용됩니다. 참고: Templates 플러그인 도움말 및 다음을 Moment.js 서식 토큰.

Templater 플러그인. 커뮤니티 플러그인에서 Templater를 설치하고 다음을 설정하세요: Template folder location. 다음 명령으로 템플릿을 삽입하세요: Templater: Open insert template modal. 폴더 Meetings/ 의 모든 새 노트에 이 템플릿을 적용하려면 Trigger Templater on new file creation을(를) 켜고, Template matching mode 을(를) 폴더 템플릿으로 설정한 뒤 Meetings 폴더를 이 파일에 연결하세요. Templater 설정 문서 에서 폴더 템플릿을 설명하고, date 모듈 에서는 다음을 설명합니다: tp.date.now.

속성. 프런트매터는 --- 줄 사이에 있으며 노트 속성이 됩니다. 속성 안의 링크는 따옴표로 묶어야 하므로 project 필드는 다음과 같이 작성됩니다: "[[Project name]]". 참조: 속성 (Obsidian 도움말). 가지고 있는 프런트매터를 검사하려면 다음을 사용하세요: 속성 생성기 및 검사기. 노트에 속성이 생기면 base로 조회할 수 있습니다: Obsidian Bases 생성기 이 필터와 보기를 만듭니다.

3. 회의마다 노트 하나

회의는 한 폴더(예: Meetings/)에 모으고, 파일 이름에 날짜와 시작 시간을 넣으세요: Meetings/2026-11-19 1430 Design review.md. 이 순서로 이름을 지으면 날짜순으로 정렬되고, 같은 날의 두 회의가 한 파일을 공유하는 일도 없습니다.

켜세요: 일일 노트 링크 (생성기에서). 그러면 다음 줄이 추가됩니다: Daily note: . 이 줄은 그날의 노트로 연결됩니다. 링크는 YYYY-MM-DD. 일일 노트에 다른 날짜 형식을 쓴다면 그에 맞게 바꾸세요. 일일 노트 템플릿 생성기 은(는) 형식으로 만들어지는 파일 이름을 미리 보여 줍니다. 그날의 회의도 일일 노트에 나열하고 싶다면 그 노트에서 링크하세요. Obsidian 일일 노트에 추가 에서 Vox.md로 일일 노트에 항목을 추가하는 방법을 볼 수 있습니다.

4. 할 일 항목과 후속 조치

각 할 일 항목은 Obsidian 작업으로 작성하고(예: - [ ] Send the release notes) 완료되면 - [x] (으)로 체크하세요. 참고: 기본 서식 구문. 담당자를 맨 앞에 쓰면 각 줄이 누가 무엇을 하는지로 읽힙니다.

할 일 항목이 이미 일반 목록이라면 Markdown 체크리스트 메이커 이(가) 작업으로 바꾸고 Tasks, Dataview 또는 Reminder 형식의 마감일을 추가합니다.

작업 목록이 아니라 결정 사항과 담당자 표를 만들려면 스프레드시트의 행을 다음에 붙여넣으세요: Markdown 표 만들기 를 누르고 결과를 노트에 복사하세요.

노트의 요약이나 경고는 콜아웃으로 강조할 수 있습니다. Obsidian 콜아웃 생성기 는 > [!type] 형식의 구문을 접기 옵션까지 포함해 만들어 줍니다.

선택 스타일은 커뮤니티 Tasks 플러그인: 📅 뒤에 YYYY-MM-DD이(가) 오는 형식으로 마감일을 추가합니다. 생성기는 회의 날짜를 넣으므로 실제 마감일로 바꾸세요. Tasks 플러그인이 없으면 이모지와 날짜는 일반 텍스트가 되지만 작업은 그대로 동작합니다.

모든 회의의 미완료 항목을 한곳에 모으려면 노트에 Tasks 쿼리를 추가하세요:

```tasks
not done
path includes Meetings
```

이 쿼리는 경로에 다음이 포함된 노트의 미완료 작업을 나열합니다: Meetings. 이미 Dataview를 쓰고 있다면 Dataview로도 비슷한 목록을 만들 수 있습니다.

5. 녹음으로 노트 채우기

템플릿은 제목을 제공합니다. 노트 자체는 Vox.md가 작성할 수 있습니다. 회의를 녹음하고 기기에서 전사한 뒤 루트를 통해 Markdown 파일을 보관함에 저장합니다.

  1. 녹음. Mac에서는 Vox.md가 통화 앱 하나와 마이크를 별도 트랙으로 녹음할 수 있습니다. 다음을 따라 하세요: Mac 회의를 로컬에서 전사해 Obsidian에 저장하기. 대면 회의는 iPhone 또는 iPad의 마이크로 녹음하세요. 참고: iPhone 음성 노트를 Obsidian에 저장.
  2. 대상 선택. 루트에서 보관함을 고르고 새 노트을(를) 선택한 뒤 다음과 같은 경로를 입력하세요: Meetings/{date}-{hour}{minute}.md. {date} 은(는) 2026-11-19 및 {hour}{minute} 은(는) 1430(으)로 기록됩니다. 이는 Moment.js 형식이 아니라 Vox.md 토큰입니다. 자세한 경로 예시는 Obsidian 캡처 템플릿 에서 더 많은 경로 예시를 확인하세요.
  3. 모드 선택. 루트의 처리 모드를 회의 메모(으)로 설정하세요. 이 모드는 ## Notes 섹션을 만들고, 전사문에 할 일 항목이 있으면 ## Action Items 체크리스트도 만듭니다. macOS 26 또는 iOS 26을 실행하는 호환 하드웨어에서는 Apple Intelligence를 사용하고, 그렇지 않으면 일관된 서식기가 구조를 만듭니다.

회의 메모는 안건, 참석자, 결정 사항을 대신 채워 주지 않습니다. 메모 위에 이런 제목을 두고 싶다면 생성기에서 일반 Markdown 을(를) 선택하고 메모와 할 일 항목의 선택을 해제한 뒤 결과를 보관함에 저장하세요. 그런 다음 해당 파일을 루트의 보관함 템플릿으로 선택하세요. Vox.md는 템플릿의 단일 중괄호 토큰을 채우고 처리된 전사문을 그 아래에 기록합니다. 이 레이아웃을 믿고 쓰기 전에 첫 번째 노트를 확인하세요. 루트 문서 에서 대상과 템플릿을 설명합니다.

회의가 Zoom 또는 Teams에서 진행되었고 녹취록을 .srt 또는 .vtt 파일로 다운로드했다면, 다음을 사용해 화자별 발언이 있는 Markdown으로 변환하세요: SRT 및 VTT 변환기, 그런 다음 다음 아래에 붙여넣으세요: ## Transcript 이 템플릿의 제목.

회의 참석자 모두에게 녹음과 전사를 한다는 사실을 알리고 먼저 동의를 받으세요. 규정은 지역과 직장마다 다릅니다. 참고: 녹음 중임을 알리기.

6. 자주 묻는 질문

Core Templates와 Templater 중 무엇을 써야 하나요?

Core Templates는 Obsidian에 기본 포함되며 제목, 날짜, 시간을 다룹니다. Templater는 스크립트, 날짜 오프셋, 폴더 템플릿을 추가하는 커뮤니티 플러그인이므로 Meetings/ 의 새 노트에 템플릿을 자동으로 적용할 수 있습니다. 이 페이지의 필드만 필요하다면 Core Templates로 충분합니다.

왜 {{date}} 은(는) 나중에 바뀌지 않나요?

Obsidian은 템플릿을 삽입할 때 템플릿 변수를 한 번만 바꿉니다. 그 후 노트에는 일반 텍스트(예: 2026-11-19)가 남아 그대로 유지됩니다. 회의 기록에는 이렇게 하는 것이 맞습니다.

Vox.md에서 내 Obsidian 템플릿을 쓸 수 있나요?

부분적으로 가능합니다. 루트는 보관함의 Markdown 파일을 템플릿으로 사용할 수 있습니다. Vox.md는 자체 단일 중괄호 토큰(예: {date})과 Templater 날짜 명령 tp.date.now 및 tp.file.creation_date을(를) 채웁니다. 다른 Templater 명령(예: tp.file.title)은 실행하지 않으며, 코어 Templates 변수(예: {{title}})도 확장하지 않으므로 루트 템플릿에는 넣지 마세요. Vox.md 루트에는 일반 Markdown 출력을 사용하세요.

생성기가 선택한 내용을 어딘가로 전송하나요?

아니요. 템플릿은 이 페이지의 스크립트가 만듭니다. 마지막 선택 항목은 브라우저의 로컬 저장소에 저장되어 다음에도 남아 있으며, 초기화를 누르면 지워집니다.

입력은 건너뛰세요.

회의를 녹음하면 Vox.md가 노트를 보관함에 작성합니다.
