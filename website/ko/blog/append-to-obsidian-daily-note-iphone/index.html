iPhone에서 Obsidian 일일 노트에 텍스트와 음성 추가

일일 파일과 제목은 한 번 고르세요. 캡처 프리셋으로 나중 생각도 같은 곳에 보내세요.

작성자
Cody Bontecou
업데이트
2026년 10월 26일
필요 조건
iPhone · 쓰기 가능한 보관함 폴더
짧은 답변

Vox.md 캡처 프리셋을 보관함에 연결하고 일별 롤링 노트를 골라 기존 일일 노트 파일명에 경로를 맞추세요. 맨 아래로 추가하거나 이 옵션으로 이름 있는 섹션 아래 삽입하세요. 같은 대상은 텍스트와 음성을 받습니다.

이 가이드는 라우팅과 서식에 집중합니다. 녹음 및 모델 설정은 다음부터 시작하세요: iPhone 음성 노트를 Obsidian으로. Obsidian에도 일일 노트 캡처 도구가 있으므로 모든 추가 워크플로에 Vox.md가 필요하지는 않습니다.

이 가이드에서
  1. 일일 노트 경로 맞추기
  2. 배치 위치와 제목 선택
  3. 연속 캡처 두 건 확인
  4. 할 일 목록 서식 지정
  5. 파일 중복 및 잘못 배치된 항목 방지
  6. Obsidian 기본 캡처 고려

1. 일일 노트 경로 맞추기

기존 일일 노트의 폴더와 파일명을 확인하세요. 이 예제의 가정: Journal/2026-10-26.md. 자신의 규칙이 다르다면 그대로 유지하세요.

  1. 오픈 설정 → 캡처 프리셋 을 Vox.md에서 여세요. Journal 같은 활성 프리셋을 만들거나 편집하세요.
  2. 파일 앱으로 대상을 보관함 폴더에 연결하세요. 해당 폴더는 Vox.md에 공개되어 있고 쓰기가 가능해야 합니다.
  3. 선택: 롤링 노트 및 다음을 매일 주기입니다.
  4. 예시 규칙을 따르려면 경로 패턴을 다음으로 설정하세요: Journal/{period}.md. 보내기 전에 해석된 대상을 확인하세요.

일별 주기에서는 {period} 는 다음과 같은 날짜로 해석됩니다: 2026-10-26. 루트에 일일 파일을 저장하는 보관함은 대신 다음을 사용합니다: {period}.md. 이는 Vox.md 경로 토큰이며 Obsidian 템플릿 표현식이 아닙니다.

Vox.md는 Daily Notes 플러그인 설정을 자동 읽지 않습니다. 다른 폴더나 파일명은 다른 대상을 만듭니다. 경로는 파일 앱에서 선택한 폴더 기준이므로 실제 하위 폴더가 아니면 보관함 이름을 반복하지 마세요.

Vox.md 무료 다운로드

성공한 캡처 전송 10회와 전사 15분을 무료로 체험하세요. 무제한 사용은 일회성 평생 구매이며 가격은 지역별로 다릅니다.

2. 배치 위치와 제목 선택

선택: 아래 으로 일일 노트 끝에 추가하거나, TOP 을 선택해 앞에 추가하세요. 캡처를 한 섹션에 모으려면 다음을 선택하세요: 이, 제목을 입력하고 수준을 정하세요.

아래 예제에는 다음 이름의 2단계 제목을 사용하세요: Inbox. 해당 제목의 섹션 끝에 삽입하도록 선택하면 새 항목이 이전 항목 뒤에 놓입니다. 제목이 없을 때의 동작을 다음으로 설정하세요: 이를 만들기 Vox.md가 추가해야 한다면 선택하거나, 실수 표시 노트를 직접 수정하려면 사용하세요.

일반 항목은 다음을 선택하세요: 원본 유지 처리입니다. 항목 서식에는 다음과 같은 글머리 기호 접두사를 사용하세요: - 을 쓰면 짧은 캡처마다 목록 항목이 됩니다. 접두사는 서식 선택입니다. 해당 동작을 설정하지 않으면 일반 전사가 체크리스트로 바뀌지 않습니다.

3. 연속 캡처 두 건 확인

빠른 캡처에 '등산로 안내 읽기'를 입력해 Journal 프리셋으로 보내세요. '우비 챙기기'도 같은 프리셋으로 보내세요. Obsidian에서 해석된 일일 노트를 열어 두 항목 모두 Inbox 아래 있는지 확인하세요.

위의 일별 경로, 제목, 글머리표 접두사를 적용한 다음 파일의 섹션: Journal/2026-10-26.md 의 예시:

## Inbox
- Read the trail guide
- Pack a rain jacket

해당 설정의 예시 출력입니다. 항목 템플릿, 처리, 기존 노트 내용에 따라 달라질 수 있습니다. 음성 인식을 더하기 전에 짧은 입력 캡처 두 건으로 라우팅을 확인하세요.

음성은 같은 프리셋으로 빠른 캡처에서 녹음하세요. 보내기 전에 검토하도록 전사를 초안에 추가하거나 루트에 익숙해지면 즉시 전송을 선택하세요. 키보드는 두 번째 Markdown 캡처를 내보내는 대신 호스트 앱에 텍스트를 삽입합니다.

할 일 목록 서식 지정

Tasks 섹션에는 다음 이름의 2단계 제목을 고르세요: Tasks 과 일관된 체크리스트 방식을 사용하세요. 텍스트 처리 없는 입력 캡처에는 원본 유지와 다음 접두사를 - [ ] 로 AI 재작성 없이 짧은 항목을 할 일로 만듭니다.

## Tasks
- [ ] Read the trail guide
- [ ] Pack a rain jacket

대신 할 일 체크리스트 처리를 활성화한다면 처리 단계가 할 일 표시를 담당하도록 하고 확인란 접두사를 중복 추가하지 마세요. 입력 및 혼합 텍스트 처리는 별도로 선택해야 합니다. 긴 노트나 목록에 프리셋을 적용하기 전에 결과 하나를 확인하세요. 다음을 참조하세요: 처리 모드 및 항목 서식.

재사용 항목 템플릿은 타임스탬프나 소스 필드를 추가할 수 있습니다. 문제의 원인이 대상, 처리, 서식 중 무엇인지 알 수 있도록 첫 설정은 단순하게 유지하세요.

파일 중복 및 잘못 배치된 항목 방지

두 번째 일일 노트가 생김

해석된 폴더·파일명을 기존 Obsidian 파일과 비교하세요. 보관함 루트, 일별 주기, 날짜 규칙, 경로 패턴을 확인하세요. 새 노트는 개별 파일을 만들며 일일 롤링 노트로 캡처를 모으지 않습니다.

항목이 다른 제목 아래에 들어감

제목 텍스트와 수준을 확인하세요. 2단계 Inbox와 3단계 Inbox는 다릅니다. 섹션 앞·뒤 삽입과 누락 제목 생성 여부를 검토하세요.

쓰기 실패 또는 대기

선택한 폴더 접근을 복원하고 기존 대기 캡처를 재시도하세요. 전송이 해결되지 않은 동안 같은 콘텐츠를 다시 수동 전송하지 마세요. 선택적인 보호를 반환 반복 요청을 식별하기 위한 표시 가능한 HTML 주석을 쓰며 기본적으로 꺼져 있습니다. 별도로 생성되었지만 우연히 문구가 같은 두 캡처는 감지하지 않습니다.

초안 하나의 대상을 변경했어요

작성 화면에서는 프리셋을 변경하지 않고 한 번의 캡처 대상을 재정의할 수 있습니다. 다음으로 돌아가세요: 미리 미리보기가 설정한 루트와 다를 때 사용하세요.

폴더에 네트워크가 필요함

로컬 캡처와 전사라고 해서 모든 파일 제공자가 오프라인에서 사용 가능한 것은 아닙니다. 일일 파일과 폴더의 로컬 가용성을 확인하고 선택한 동기화 제공자에게 동기화를 맡기세요.

Obsidian 기본 캡처 고려

Obsidian의 공식 iOS 가이드 에서 일일 노트 앞이나 뒤에 텍스트를 추가하는 빠른 캡처 위치를 설명합니다. 기본 빠른 캡처에는 Obsidian 1.14 이상과 iOS 26 이상이 필요합니다. 워크플로를 충족한다면 기본 옵션으로 시작하세요.

Vox.md는 Markdown 대상에 자체 프리셋 처리, 항목 서식, 미디어 캡처, 로컬 음성 백엔드 선택을 더합니다. 일일 노트 추가에 별도 앱이 꼭 필요하다고 생각하기보다 필요한 전체 워크플로를 위해 선택하세요.
