iPhone 음성 노트를 Obsidian에 저장하는 방법

생각을 말하고 iPhone에서 전사해 원하는 보관함, 노트, 제목에 넣으세요.

작성자
Cody Bontecou
업데이트
2026년 10월 26일
필요 조건
iPhone · iOS 17.6+
짧은 답변

Vox.md에서 캡처 프리셋을 Obsidian 보관함 폴더에 연결하고 로컬 전사 백엔드를 준비한 뒤 빠른 캡처에서 녹음하세요. 전사 내용을 새 Markdown 노트로 보내거나 기존 노트 또는 일일 노트에 추가하세요. Obsidian 플러그인이나 Vox.md 계정은 필요하지 않습니다.

Obsidian에도 기본 캡처 도구가 있습니다. 아래 기본 옵션 확인 을 다른 앱을 설치하기 전에 확인하세요. 캡처 프리셋, 로컬 음성 모델 선택, 같은 워크플로의 텍스트·미디어·음성이 필요할 때 Vox.md가 유용합니다.

Vox.md 무료 다운로드

전사 15분과 성공 캡처 전송 10회를 체험하세요. 무제한 사용은 일회성 평생 구매이며 App Store가 지역 가격을 표시합니다.

  7. 문제 해결 및 오프라인 사용

시작 전

  • iOS 17.6 이상인 iPhone. 음성 백엔드는 기기, OS, 언어에 따라 다릅니다. 실시간 Apple Speech에는 지원되는 iOS 26 기기와 언어가 필요합니다.
  • 파일 앱에서 고를 수 있는 보관함 폴더. Vox.md는 해당 폴더 쓰기 권한이 필요합니다. Obsidian 안에서 보이는 보관함도 파일 앱에서 다른 앱에 공개되지 않을 수 있습니다.
  • 준비된 전사 백엔드. 자동은 언어 준비가 필요할 수 있고 선택적 Whisper나 Parakeet 모델은 최초 다운로드가 필요합니다. 오프라인 전사에 의존하기 전에 연결된 상태에서 준비하세요.
  • 마이크 권한. 이 가이드에서 키보드는 선택 사항입니다. 사용자 키보드나 전체 접근 없이 본 앱에서 녹음할 수 있습니다.

Obsidian Sync를 쓴다면 보관함 폴더를 파일 선택기로 접근할 수 있는지 확인하세요. Vox.md는 파일을 쓰며 Obsidian Sync 서비스에 연결하지 않습니다. 이 가이드 때문에 기존 동기화 설정을 바꾸거나 제공자를 혼용하지 마세요.

1. Obsidian 보관함 연결

  1. Vox.md를 열어 빠른 캡처에서 프리셋을 고르세요. 기존 프리셋을 쓰거나 다음에서 만드세요: 설정 → 캡처 프리셋.
  2. 선택: 목적지 설정 프리셋에 대상이 없을 때 사용하세요. 파일 선택기로 보관함의 Markdown 파일이 있는 폴더를 고르세요.
  3. 다음으로 시작하세요: 새 노트 대상으로 각 캡처가 별도 파일을 만들도록 하세요. 노트를 한곳에 모으려면 받은 편지함 하위 폴더를 선택하세요.
  4. 저장 전에 대상 미리보기를 확인하세요. 첫 캡처에는 다음을 쓰세요: 원본 유지 처리로 선택적 단계의 전사 재작성을 막으세요.

프리셋이 대상을 기억합니다. 이후에도 같은 루트를 쓰세요. 참조: 프리셋 및 대상 참조 에서 템플릿, 첨부 폴더, 삽입 규칙을 확인하세요.

2. 로컬 전사 준비

모델 설정을 열고 휴대폰과 언어를 지원하는 백엔드를 선택하세요. Vox.md는 Apple Speech와 선택적인 Whisper 및 Parakeet 모델을 지원합니다. 첫 녹음 전에 준비나 모델 다운로드를 완료하세요.

지원되는 iOS 26 기기에서 자동을 사용하면 Apple Speech가 녹음 중 텍스트를 표시할 수 있습니다. 명시적으로 선택한 Whisper와 Parakeet 모델은 녹음이 끝난 뒤 전사합니다. 음성 노트를 저장하는 데 실시간 미리보기가 필요하지는 않습니다.

기기 내 전사에는 클라우드 전사 계정이 필요하지 않습니다. 모델 가용성, 인식 품질, 처리 시간은 다릅니다. 다음을 읽으세요: 모델 요건 및 준비 단계 선호하는 백엔드를 사용할 수 없을 때 사용하세요.

3. 음성 노트 녹음 및 저장

  1. 빠른 캡처에서 설정한 프리셋을 선택하세요. 녹음 전에 다음을 선택하세요: 초안에 추가 을 음성 컨트롤에서 골라 첫 전사를 검토할 수 있게 하고 녹음을 시작하세요.
  2. “치과 예약하는 것 잊지 말기”처럼 짧은 생각을 말하세요. 마치면 녹음을 중지하세요.
  3. 초안에 추가를 선택하고 전사를 기다려 작성 화면에서 인식 오류를 고친 뒤 다음을 탭하세요: 보내기. 다음을 선택하면 즉시 전송 을 녹음 전에 선택하면 녹음 완료 시 프리셋이 전사를 라우팅합니다.
  4. Vox.md에서 전송을 확인한 뒤 Obsidian에서 대상 폴더를 열어 새 노트를 확인하세요.

원본 유지 처리의 순수 전사 노트 본문은 다음과 같을 수 있습니다. 예시이며 정확히 같은 인식이나 문장부호를 보장하지 않습니다:

Remember to book the dentist.

파일명과 프런트매터는 프리셋에서 정합니다. 첨부파일이 필요하면 원본 오디오를 보관할 수 있지만 Obsidian에서 전사를 활용하는 데 오디오 첨부는 필요하지 않습니다.

키보드는 별도 경로로 받아쓴 텍스트를 활성 필드에 삽입합니다. 캡처 프리셋으로 음성을 Markdown 파일로 보내려면 여기의 캡처 흐름을 쓰세요. 참조: 비공개 iPhone 키보드 가이드 에서 다른 앱에 받아쓰세요.

음성을 일일 노트나 제목 아래로 보내기

새 노트 캡처가 작동하면 프리셋 대상을 편집해 다음을 사용하세요: 롤링 노트 에 일별 주기를 쓰세요. 기존 Obsidian 일일 노트의 폴더와 파일명 형식에 맞추세요. Vox.md는 Daily Notes 플러그인 설정을 자동 탐지하지 않습니다.

받아쓴 할 일을 모으려면 다음 2단계 제목 아래 삽입을 선택하세요: Tasks 제목을 선택하세요. 제목이 없으면 Vox.md가 만들지, 항목을 섹션 앞이나 끝에 둘지 정하세요. 할 일 프리셋은 할 일 체크리스트 처리, 일반 문장은 원본 유지를 사용하면 됩니다.

예를 들어 다음을 대상으로 하는 일일 할 일 프리셋: Journal/2026-10-26.md 의 결과 예시:

## Tasks
- Remember to book the dentist.

기본 형식이 아닌 설정된 출력 예시입니다. 두 번째 일일 노트를 만들지 않도록 기존 날짜 규칙을 유지하고 대상 미리보기를 확인하세요. 하나의 지속적인 받은 편지함을 원하면 다음을 고르세요: 기존 노트 을 선택해 그곳에 추가하세요.

Obsidian 기본 기능만으로 충분한 경우

Obsidian의 공식 iOS 가이드 는 iOS 26 이상에서 버전 1.14 이상의 기본 빠른 캡처를 설명합니다. 위젯과 단축어로 노트를 만들거나 업데이트합니다. 보관함에 기본 텍스트 캡처만 필요하면 여기서 시작하세요.

해당 Obsidian 1.15 모바일 얼리 액세스에 관한 2026년 10월 22일 발표 에는 iOS 26 잠금 화면 캡처를 포함한 음성 전사와 녹음 저장도 추가됩니다. 이 가이드의 10월 26일 업데이트 기준으로 해당 발표는 얼리 액세스 채널 대상입니다. 설치된 버전에서 사용 가능한지 확인하세요.

로컬 음성 백엔드 선택, 설정 가능한 캡처 처리와 라우팅, 텍스트·사진·스캔·파일·음성의 조합이 필요하다면 Vox.md를 선택하세요. Obsidian 보관함이 아닌 쓰기 가능한 Markdown 폴더에서도 사용할 수 있습니다. 어느 앱도 다른 앱을 대체할 필요가 없습니다. Obsidian은 계속 노트를 정리하고 읽는 공간으로 쓰세요.

문제 해결 및 오프라인 사용

보관함이 파일 앱에 나타나지 않음

사용 가능한 파일 제공자를 통해 폴더가 공개되어 다른 앱에서도 선택할 수 있는지 확인하세요. 접근할 수 없다면 쓰기 가능한 폴더를 사용하고, 샘플 Markdown 노트를 Obsidian으로 직접 옮겨 워크플로를 평가하세요. Vox.md가 Obsidian Sync 보관함에 접근할 수 있다고 가정하지 마세요.

전사가 없거나 부정확함

마이크 접근, 백엔드 준비, 언어 지원을 확인하세요. Apple Speech 실시간 텍스트는 지원 OS·기기 조합이 필요하며 다운로드 모델과 동작이 다를 수 있습니다. 보내기 전 중요한 글을 검토하세요. 참조: 모델 및 전사 에서 사용 가능한 옵션을 확인하세요.

캡처 대기 중 또는 저장 불가

대상 권한과 파일 제공자 가용성을 확인하세요. 같은 생각을 다시 캡처하기보다 대기/실패 항목을 검토해 대상을 수정한 뒤 재시도하세요. Vox.md는 복구용 대기 전송 데이터를 보관합니다. 참조: 전송 문제 해결.

오프라인에서도 할 수 있나요?

백엔드 준비 후 음성 전사는 기기에서 실행됩니다. 노트를 쓰려면 선택한 폴더도 로컬에서 사용 가능하고 쓰기가 허용되어야 합니다. 클라우드 기반 폴더는 파일 접근이나 이후 동기화에 연결이 필요할 수 있습니다. 로컬 전사라고 해서 선택한 동기화 제공자에게 완성된 노트가 절대 전달되지 않는 것은 아닙니다.

음성 노트는 무료 할당량 두 가지를 모두 쓰나요?

Markdown으로 라우팅된 음성 전사는 전사 할당량을 사용하며 캡처 전송을 추가로 사용하지 않습니다. 무료 다운로드에는 전사 15분과 다른 캡처 워크플로용 성공한 캡처 전송 10회가 포함됩니다. 무제한 사용은 한 번 구매하면 평생 이용할 수 있습니다.

다음 생각은 알맞은 노트에 도착할 수 있습니다.

세부적인 프리셋을 만들기 전에 폴더를 연결하고 로컬 전사를 준비해 짧은 음성 캡처를 시험하세요.
