Obsidian · iPhone · 캡처 가이드

iPhone에서 Obsidian으로 빠르게 캡처: 방법 선택

저장할 내용과 그 위치부터 정하세요. 그런 다음 해당 노트에 도달하는 가장 간단한 캡처 방법을 선택하세요.

작성자
Cody Bontecou
업데이트
2026년 10월 26일
필요 조건
iPhone · 설정은 상황에 따라 다름
짧은 답변

간단한 노트는 Obsidian 기본 캡처, 반복 작업 순서는 단축어, 프리셋 처리와 Markdown 폴더 라우팅은 Vox.md를 쓰세요. 특정 앱이나 위젯보다 마지막에 원하는 노트부터 정하세요.

이 가이드는 방법 선택을 돕습니다. 연결된 튜토리얼에 Vox.md 세부 설정이 있으므로 첫 캡처 전에 전체 참조 문서를 읽을 필요가 없습니다.

이 가이드에서
  1. 작업별 선택
  2. Obsidian 기본 캡처로 시작
  3. 반복 워크플로에 단축어 사용
  4. 프리셋 기반 캡처에 Vox.md 사용
  5. 캡처 한 건을 처음부터 끝까지 확인
  6. 자주 묻는 질문

작업별 선택

  • 짧게 입력한 생각: 별도 앱 추가 전에 Obsidian 기본 캡처를 시험하세요.
  • 매번 같은 작업 집합: 텍스트를 받아 원하는 대상으로 보내는 단축어를 살펴보세요.
  • 음성을 보관함으로: Obsidian 버전의 기본 음성 지원을 확인하거나 다음을 따르세요: Vox.md iPhone 음성 가이드.
  • Watch에서 녹음한 생각: 다음을 참조하세요: Watch 녹음 및 iPhone 전송 가이드.
  • 연결 없는 전사: 에서 백엔드와 대상을 준비하세요: 오프라인 전사 가이드.
  • 링크, 사진, 스캔: 다음을 따르세요: 미디어 캡처 가이드 을 사용하고 첨부 출력을 확인하세요.
  • 재사용 항목 형식: 다음으로 시작하세요: 받은 편지함, 일지, 할 일 예제.
  • 일일 노트 제목 아래 항목: 다음을 따르세요: 일일 노트 경로 및 배치 예제.

기본 앱과 Vox.md 직접 비교 읽기: Vox.md와 Obsidian 빠른 캡처 비교. 문서에 명시된 기능과 앱이 못 할 것이라는 가정을 구분합니다.

Obsidian 기본 캡처로 시작

Obsidian의 iOS 가이드 에서 빠른 캡처, 위젯, 공유를 설명합니다. 빠른 캡처에는 Obsidian 1.14+와 iOS 26+가 필요합니다. 추가 도구를 설정하기 전에 캡처 위치를 구성하고 짧은 노트를 시험해 보세요.

기본 음성 캡처는 다음에서 발표되었습니다: Obsidian 1.15 모바일 얼리 액세스, iOS 26 실시간 전사를 포함합니다. 설치 버전과 릴리스 채널을 확인하세요. 음성 튜토리얼이 있다고 모든 안정 빌드에 기능이 있는 것은 아닙니다.

다른 앱에서 페이지나 링크를 저장한다면 Obsidian 기본 공유 컨트롤도 확인하세요. 원하는 것이 URL 저장인지 페이지 콘텐츠 추출인지 구분하세요. 둘은 다른 출력이며 캡처 앱이 링크를 받는다고 기사 전체를 저장하는 것은 아닙니다.

반복 워크플로에 단축어 사용

Apple의 단축어 가이드 에서 작업을 워크플로로 연결하는 방법을 설명합니다. 매번 같은 입력 요청, 서식 단계, 앱 작업을 사용하고 싶다면 단축어가 유용합니다. 가능한 작업은 설치된 앱에서 제공하는 동작과 부여한 권한에 따라 달라집니다.

단축어에서 대상 앱이 현재 제공하는 작업을 찾으세요. 첫 버전은 텍스트 받기, 선택 노트로 보내기, 파일 확인으로 짧게 유지하세요. 기본 흐름이 작동한 뒤에 다른 트리거를 추가하세요.

사용자 통합용으로 Obsidian은 다음도 설명합니다: URI 스킴 으로 노트를 열고 생성하고 추가할 수 있습니다. URL 매개변수는 올바르게 인코딩해야 합니다. 사용자 지정 URI는 자동화 옵션일 뿐 앱이 닫힌 상태를 유지하거나 사용할 수 없는 보관함에 쓰기를 보장하지 않습니다.

잠금 화면, 동작 버튼, 무인 녹음은 설치 작업, 권한, OS에 따라 다릅니다. 실제 사용할 트리거를 테스트하세요. 작업이 목록에 있다는 것이 모든 기기의 백그라운드 녹음을 증명하지는 않습니다.

프리셋 기반 캡처에 Vox.md 사용

Vox.md는 프리셋에서 캡처, 선택 처리, 전송을 결합합니다. 보관함이나 쓰기 가능한 Markdown 폴더를 골라 새·롤링·기존 노트를 설정하고 배치 및 항목 서식을 고르세요.

한 프리셋은 가공하지 않은 생각을 받은 편지함에 추가하고 다른 프리셋은 Tasks 제목 아래 할 일을 서식화할 수 있습니다. 빠른 캡처 작성 화면은 텍스트, 미디어, 스캔, 스케치, 파일, 음성을 받으며 백엔드 준비 후 로컬 음성 전사를 사용합니다.

파일 앱에 공개된 폴더와 쓰기 권한이 필요합니다. Vox.md는 Obsidian Sync 서비스에 직접 연결하지 않습니다. Obsidian만 접근 가능한 보관함에는 기본 작업이 더 적합할 수 있습니다.

Vox.md는 무료로 다운로드할 수 있고 전사 15분과 성공한 캡처 전송 10회가 포함됩니다. 무제한 사용은 일회성 평생 구매입니다. 시험하지 않은 프리셋을 여러 개 만들지 말고 무료 할당량으로 시작해 루트를 확인하세요.

캡처 한 건을 처음부터 끝까지 확인

첫 시도에는 임시 노트나 이름이 분명한 받은 편지함을 쓰세요. 다음은 수락 확인 예시이지 측정된 속도에 대한 주장이 아닙니다:

  1. “기차 시간 확인하기” 같은 짧은 문장을 캡처하세요.
  2. 어느 앱이 받았고 어떤 파일을 썼는지 확인하세요.
  3. Obsidian에서 해당 파일을 열고 텍스트, 제목, 서식을 확인하세요.
  4. 두 번째 줄을 보내 의도대로 뒤에 추가되는지, 앞에 추가되는지, 다른 파일이 생성되는지 확인하세요.
  5. 음성은 인식과 오디오 보관을, Watch는 iPhone 전송 완료를 확인하세요.

간단하게 설정한 받은 편지함에는 다음과 같은 예시 결과가 들어갈 수 있습니다:

## Inbox
- Check the train times
- Pack a notebook

일일 노트에 이 패턴을 원하면 기존 폴더, 날짜 규칙, 제목에 맞추세요. 다음은 일일 노트 튜토리얼 에서 구체적인 루트를 안내합니다.

자주 묻는 질문

Obsidian 플러그인이 필요한가요?

Vox.md의 직접 Markdown 폴더 전송에는 필요하지 않습니다. 폴더 접근과 유효한 대상은 여전히 필요합니다. 별도 플러그인이나 사용자 단축어는 다른 워크플로에 유용할 수 있지만 이 루트의 선행 조건은 아닙니다.

다른 기기에도 노트가 동기화되나요?

캡처와 동기화는 별개입니다. 기존 보관함의 동기화 방식을 확인하고 캡처 파일이 다른 기기에 도착하는지 확인하세요. Vox.md는 동기화 제공자를 대체하지 않으며 로컬 전사도 선택한 제공자에게 완성된 노트가 전달되는 것을 막지 않습니다.

오프라인에서 캡처할 수 있나요?

Vox.md의 음성 백엔드를 먼저 준비하고 폴더가 로컬에서 쓰기 가능한지 확인하세요. 제공자는 접근이나 나중 동기화에 연결이 필요할 수 있습니다. 모든 캡처 방식이 같다고 가정하지 말고 실제 폴더와 선택한 모델로 오프라인 동작을 평가하세요.

여러 방법을 쓸 수 있나요?

네. 짧은 입력 항목에는 기본 위젯을, 다른 루트에는 Vox.md 프리셋을 사용할 수 있습니다. 두 방법이 원하는 파일을 가리키며 호환되는 날짜와 서식 규칙을 쓰는지 확인하세요.

루트 하나를 고르세요.
다음 캡처를 쉽게.

원하는 노트를 만드는 최소 워크플로로 시작하고 필요할 때 음성, 미디어, 진입점을 더하세요.
