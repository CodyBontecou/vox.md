iPad에서 음성-텍스트 변환을 켜는 방법

  1. 오픈 설정, 탭: 일반. 그다음 탭하세요 키보드.
  2. 켜세요: 받아쓰기 활성화. 안내가 나타나면 탭하세요 받아쓰기 활성화 다시.
  3. 텍스트 필드에서 탭하여 삽입 위치를 지정하세요.
  4. 다음을 탭하세요: 받아쓰기 버튼을 화면 키보드에서 탭하세요. 삽입 위치 근처에 받아쓰기 버튼이 나타나면 말하기 시작하세요.
  5. 중지: 받아쓰기 버튼을 다시 탭하거나, “받아쓰기 중지”라고 말하거나, 30초 동안 조용히 있으면 Apple에 따라 받아쓰기가 자동으로 멈춥니다.

Apple에 따르면 받아쓰는 동안 키보드(또는 도구 팔레트)를 열어 둘 수 있어 입력과 말하기를 섞어 쓸 수 있습니다. 받아쓰기를 끄려면 설정 > 일반 > 키보드로 돌아가 다음을 끄세요: 받아쓰기 활성화. Apple은 셀룰러 데이터 요금이 부과될 수 있다고도 안내합니다.

Magic Keyboard, Smart Keyboard 또는 다른 키보드로 받아쓰기

Apple에는 이를 위한 별도 페이지가 있습니다. iPad에서 Apple 외장 키보드를 사용하며 텍스트 받아쓰기. 2026년 11월 24일 기준 내용은 다음과 같습니다.

  1. 먼저 받아쓰기를 켜세요: 설정 > 일반 > 키보드 > 받아쓰기 활성화.
  2. 다음을 탭하세요: 받아쓰기 단축키 막대(화면 하단)의 버튼을 누른 다음 말하세요. Apple에 따르면 iPad는 문장 부호를 자동으로 넣으며, “행복 이모티콘”처럼 이름을 말해 이모티콘을 추가할 수 있습니다.
  3. 끝나면 다음을 탭하세요: 키보드 버튼(화면 하단).

단축키: Apple에 따르면 iPad용 Magic Keyboard나 Smart Keyboard에서 다음을 누를 수 있습니다: 키보드 전환 키와 D 을 눌러 빠르게 받아쓰기로 전환하세요. 각 키보드가 지원하는 iPad 모델은 Apple이 다음 페이지에 나열합니다: iPad Magic Keyboard 및 Smart Keyboard.

Apple 페이지는 Apple 외장 키보드만 설명합니다. 다른 브랜드를 사용하면서 단축키나 단축키 막대의 버튼이 나타나지 않으면 화면 키보드의 받아쓰기 버튼을 대신 사용하거나, 자체 마이크 버튼이 있는 Vox.md 빠른 캡처를 사용해 보세요( 아래). Vox.md는 하드웨어 키보드를 연결한 상태에서 키보드를 사용하는 방법을 문서화하지 않습니다.

문장 부호 및 서식

다음은 Apple의 텍스트를 받아쓰는 명령: “쉼표”, “물음표” 같은 부호 이름을 말하세요. 줄 바꿈은 “새 줄” 또는 “새 단락”, 다음 단어를 대문자로 쓰려면 “대문자”, 이모티콘은 “하트 이모티콘”, 실행 취소와 재실행은 “실행 취소”, “다시 실행”이라고 말하세요. 언어와 기기에 따라 다른 편집 명령을 포함한 전체 목록은 해당 페이지에 있습니다. iPhone 명령은 다음에서 다룹니다: iPhone 가이드.

iPad 받아쓰기는 오프라인에서 작동하나요?

Apple에 따르면 받아쓰기는 많은 언어에서 iPad에서 처리되며 인터넷 연결이 필요하지 않습니다. 검색 필드에서 받아쓰면 검색을 처리하기 위해 받아쓴 텍스트가 검색 엔진으로 전송될 수 있다고 Apple은 설명합니다. 또한 받아쓰기는 모든 언어나 국가 또는 지역에서 사용할 수 있는 것은 아니며 기능이 다를 수 있다고 합니다. Apple의 iOS 및 iPadOS 기능 제공 여부 사용하는 언어의 페이지.

Apple 페이지에는 iPadOS 27의 Apple Intelligence에서 받아쓰기가 온디바이스 모델을 사용해 철자, 문장 부호, 대소문자를 개선한다고 나와 있습니다. 이는 M4 이상 칩과 12GB 이상의 통합 메모리를 갖춘 iPad 모델의 영어에서 사용할 수 있습니다. Apple Intelligence는 모든 언어나 지역에서 사용할 수 있는 것은 아니며 사용 제한이 적용될 수 있습니다.

Apple 받아쓰기, Vox.md 키보드 또는 Vox.md 루트

Apple 받아쓰기는 기본 제공되며 많은 사람에게 충분합니다. 음성 모델을 직접 고르거나 음성을 Markdown으로 저장하고 싶다면 대안을 살펴보세요. 표는 문서화된 세 가지 구성을 비교하며, 정확도나 속도에 대한 주장은 하지 않습니다.

작은 화면에서는 표를 옆으로 스와이프하세요.

Vox.md 키보드로 모든 iPad 앱에서 로컬 모델 사용

해당 시작하기 문서 iPhone과 iPad 모두에 대해 키보드를 설명합니다.

  1. 전사를 준비하세요. Vox.md에서 지원되는 기기라면 자동을 유지하거나, 다음에서 Whisper 또는 Parakeet을 다운로드해 선택하세요 설정 > 모델.
  2. 키보드를 추가하세요. iPadOS 설정에서 일반 > 키보드 > 키보드 > 새로운 키보드 추가로 이동해 다음을 선택하세요 Vox.md.
  3. 전체 접근 허용을 켜세요. 필수입니다. 현재 키보드 워크플로가 공유 App Group 상태를 사용하고 메인 앱과 녹음을 조율하려면 필요합니다. iOS는 이 권한을 포괄적으로 표시하지만, Vox.md는 기기 내 앱 및 키보드 워크플로, 공유 상태, 선택적 햅틱에만 사용하며 키 입력, 받아쓴 텍스트, 전사본, 마이크 오디오를 Vox.md 서버로 업로드하지 않습니다. 다음을 참조하세요: 키보드 설정 문서.
  4. 전환해서 받아쓰세요. 텍스트 필드에서 지구본 키로 Vox.md를 선택한 다음 마이크를 탭하세요.

자동에서는 확정된 텍스트가 말하는 동안 입력됩니다. Whisper나 Parakeet에서는 말을 멈춘 뒤에 텍스트가 입력됩니다. 문서는 표준 iOS 키보드를 받는 앱에서의 키보드만 설명하며, 하드웨어 키보드를 연결했을 때나 Stage Manager, Split View, Slide Over에서의 사용은 다루지 않으므로 이런 경우에는 Apple 받아쓰기나 Vox.md 빠른 캡처를 사용하세요. 모델을 고르려면 다음을 읽어 보세요: Whisper 대 Parakeet.

음성을 텍스트로 변환해 Obsidian이나 Markdown 파일에 바로 넣기

텍스트가 다른 앱이 아니라 노트에 들어가야 할 때 이 방법을 선택하세요. 다음을 여세요: 빠른 캡처를 사용하세요. 문서에서는 iOS와 iPadOS의 주요 작업 공간이라고 설명하며, 인라인 음성을 사용합니다. 초안에 추가 완성된 전사를 초안에 덧붙입니다. 즉시 전송 은 선택한 루트와 그 대상을 실행합니다. 루트 은 일일 노트나 순환 노트, 제목, 처리 모드를 대상으로 지정할 수 있습니다. 다음으로 시작하세요: Obsidian으로 음성 메모 (iPad에서도 단계는 같습니다). 그런 다음 일일 노트에 추가하기. 기존 오디오는 다음을 참조하세요: Markdown으로 오프라인 전사. 빠른 캡처에는 PencilKit 스케치도 담을 수 있습니다. 종이 노트는 손글씨 노트를 Obsidian으로. 대상 계정은 7일 무료 체험을 받을 수 있습니다.

iPad에 남는 것

Vox.md는 캡처 콘텐츠를 Vox.md 서버로 보내지 않습니다. 전사는 iPad에서 실행됩니다. 네트워크를 사용하는 경우는 직접 시작하는 모델 다운로드뿐이며, 이때 Hugging Face 또는 FluidAudio 인프라를 사용합니다. 노트가 iCloud 또는 다른 서비스로 동기화되는 폴더에 저장되면 해당 서비스가 자체 약관에 따라 파일을 처리합니다. 다음을 참조하세요: 개인정보 처리방침.

iPad 받아쓰기가 작동하지 않음

Apple 받아쓰기 확인 사항

  • 받아쓰기 버튼이 없음. 설정 > 일반 > 키보드로 이동해 다음을 켜세요: 받아쓰기 활성화, Apple 페이지 에서 설명합니다.
  • 키보드가 연결되어 화면 키보드가 사라짐. 화면 하단 단축키 막대의 받아쓰기 버튼을 사용하거나, Magic Keyboard 또는 Smart Keyboard에서 키보드 전환 키와 D를 사용하세요. 출처: Apple의 외장 키보드 페이지. 끝나면 키보드 버튼을 탭하세요.
  • 언어. 받아쓰기는 모든 언어나 지역에서 사용할 수 없을 수 있습니다. Apple의 다음 페이지를 참고하세요 기능 제공 여부 페이지.
  • 중지되었습니다. Apple에 따르면 30초 동안 조용하면 받아쓰기가 자동으로 멈춥니다. 다시 시작하세요.

Vox.md 확인 사항

  • 키보드에 전체 접근 활성화라고 표시됩니다. 설정 > 일반 > 키보드 > 키보드 > Vox.md를 열고 전체 접근 허용을 켜세요.
  • 키보드에 Vox.md 열기라고 표시됩니다. 듣기가 활성화되어 있지 않으면 키보드가 Vox.md를 한 번 열어 듣기를 시작합니다.
  • 전사 결과가 없음. 설정 > 모델에서 모델이 완전히 다운로드되어 선택되어 있는지 확인하세요.

Apple 페이지에는 요금 언급이 없지만 셀룰러 데이터 요금이 부과될 수 있다고 안내합니다. Vox.md에는 Vox.md Unlimited가 필요합니다. 대상 계정에 7일 무료 체험이 제공되는 주간 또는 연간 구독, 또는 한 번 구매하는 평생 이용권 중에서 고를 수 있습니다.

인터넷이 필요한가요?

Apple에 따르면 받아쓰기는 많은 언어에서 인터넷 연결 없이 iPad에서 처리되지만, 검색 필드에 받아쓴 텍스트는 검색 엔진으로 전송될 수 있습니다. 모델을 다운로드한 후에는 Vox.md가 iPad에서 전사합니다.

Magic Keyboard로 받아쓸 수 있나요?

예. Apple에 따르면 단축키 막대의 받아쓰기 버튼을 탭하거나, Magic Keyboard 또는 Smart Keyboard에서 키보드 전환 키와 D를 누르세요. 다음을 참조하세요: 위 섹션.

iPad에서 Whisper나 Parakeet을 고를 수 있나요?

예. Vox.md 설정 > 모델에서 키보드와 루트에 대해 선택할 수 있습니다. 다음을 참조하세요: Whisper 대 Parakeet.

음성을 바로 Obsidian으로 보낼 수 있나요?

예. 보관함의 노트로 전달하는 루트와 함께 빠른 캡처의 인라인 음성을 사용하세요. 다음과 같습니다: 음성 메모 가이드.
