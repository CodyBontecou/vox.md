Obsidian · 캡처 템플릿 · Markdown

받은 편지함, 일지, 할 일 목록용 Obsidian 캡처 템플릿

예측 가능한 소수의 형식을 사용하세요. 저장할 생각의 종류에 맞게 노트, 제목, 항목 스타일을 정하세요.

작성자
Cody Bontecou
업데이트
2026년 10월 26일
필요 조건
설정된 Vox.md 대상
짧은 답변

Inbox 아래 글머리표, 타임스탬프 일지, Tasks 아래 확인란의 세 예제로 시작하세요. Vox.md 캡처 프리셋에서 대상과 항목 접두사를 설정하세요. 기존 일일 노트 경로를 유지하고 서식 표시는 각각 한 곳에서만 추가하세요.

아래 예시는 순수 Markdown 구조와 프리셋 설정이며 Vox.md 프리셋을 자동 가져오는 파일이 아닙니다. 필요하면 노트 구조를 붙여넣고 경로 및 접두사는 대상 편집기에 입력하세요. 결과는 예시입니다.

이 가이드에서
  1. 간단한 캡처 받은 편지함
  2. 타임스탬프가 있는 일일 일지
  3. 간결한 할 일 목록
  4. 올바른 토큰 문법 사용
  5. 프리셋 재사용 전 결과 확인

예제 1: 간단한 캡처 받은 편지함

다음과 같은 기존 노트 대상을 사용하세요: Inbox.md, 매일 새 받은 편지함 파일이 필요하다면 일별 롤링 노트를 사용하세요. 2단계 Inbox 제목 아래에 배치하도록 이 옵션을 선택하고 해당 섹션 끝에 삽입하세요.

최소 노트 구조는 다음과 같습니다:

## Inbox

원본 유지 처리를 선택하세요. 대상의 항목 서식에서 접두사를 대시와 공백으로 설정하세요:

-

'초안 개요 검토'를 담은 짧은 캡처 결과 예:

## Inbox
- Review the draft outline

접두사는 매번 생각에 쓰지 말고 설정에 넣으세요. 이미 글머리표로 시작하면 무작정 더하지 말고 출력을 확인하세요. 제목이 없을 때는 이를 만들기나 오류 표시를 선택하세요.

예제 2: 타임스탬프가 있는 일일 일지

일별 롤링 노트를 사용하고 기존 보관함의 파일명 규칙에 맞추세요. 다음과 같은 파일은 Journal/2026-10-26.md, 경로 패턴: Journal/{period}.md 에 일별 주기를 설정하세요. 2단계 Journal 제목과 섹션 끝 삽입을 선택하세요.

캡처 문장을 그대로 유지하고 간결한 타임스탬프에 다음 항목 접두사를 쓰세요:

- **{hour}:{minute}**

14:05에 캡처했다면 해당 섹션은 다음과 같을 수 있습니다:

## Journal
- **14:05** A short walk helped me settle on the next step.

시·분 토큰은 Vox.md 항목 서식기가 확장합니다. 노트 수준 템플릿 파일은 주변 제목을, 항목 접두사는 각 캡처 서식을 담당합니다. 나중 항목에 일일 노트 전체 구조가 반복 삽입되지 않도록 역할을 분리하세요.

자세한 루트 설정은 다음을 참조하세요: 일일 노트 경로 및 제목 배치.

예제 3: 간결한 할 일 목록

2단계 Tasks 제목이 있는 기존 노트나 일별 롤링 노트를 선택하세요. 텍스트 처리 없는 짧은 입력 할 일에는 원본 유지와 다음 접두사를 사용하세요:

- [ ]

두 캡처로 다음을 만들 수 있습니다:

## Tasks
- [ ] Review the draft outline
- [ ] Send the reading list

할 일 체크리스트 처리를 켠다면 처리 단계가 체크 표시를 담당하게 하세요. 확인란 접두사를 중복 설정하지 마세요. 입력/혼합 텍스트 처리는 별도 선택 사항이며 음성 처리와 입력 작성 화면 설정은 서로 대체하지 않습니다.

할 일은 문구가 정확해야 쓸모가 있습니다. 음성 캡처에서는 인식 오류가 지시를 바꿀 수 있다면 전사 내용을 확인하세요. iPhone 음성 가이드 에서 초안에 추가와 즉시 전송을 설명합니다.

무료 다운로드에는 성공한 캡처 전송 10회와 전사 15분이 포함됩니다. 무제한 사용은 일회성 평생 구매입니다.

올바른 토큰 문법 사용

Vox.md 경로와 항목 설정의 토큰 예: {period}, {date}, {hour} 및 {minute}. 이 예시는 Obsidian Core Templates나 Templater 표현식이 아닙니다. 템플릿 시스템 설정에서는 그 시스템의 고유 문법을 사용하세요.

사용: {hour}:{minute} 을 사용하면 여기에 나온 콜론 구분 시간을 표시할 수 있습니다. Vox.md의 {time} 토큰은 간결한 시간 값이므로 같은 표시 형식이라고 가정해 예제에 대체하면 안 됩니다.

캡처 내용은 템플릿 편집기가 아닙니다. 생각 안에 쓴 토큰은 그대로 텍스트로 남을 수 있습니다. 대상의 지원 서식 설정에서 토큰 확장을 설정하세요. 참조: 토큰 및 템플릿 참조 에서 사용 가능한 필드를 확인하세요.

YAML 메타데이터를 추가한다면 노트 수준 프런트매터와 각 롤링 노트 항목용 필드를 구분하세요. 파일 전체 속성이 각 일지 항목의 별도 속성이 되지는 않습니다. 추가 메타데이터 없이 시작해 조회 방식을 정한 뒤 추가하세요.

프리셋 재사용 전 결과 확인

  1. 대상 미리보기가 원하는 파일과 일치하는지 확인하세요.
  2. 선택한 프리셋으로 짧은 텍스트 캡처를 보내세요.
  3. Obsidian에서 파일을 열어 제목과 접두사를 확인하세요.
  4. 두 번째 캡처를 보내 순서, 간격, 반복 표시를 확인하세요.
  5. 그다음에 음성, 첨부파일, 선택적 처리나 메타데이터를 추가하세요.

이 예제는 일일 파일 하나의 서로 다른 제목 아래 공존할 수 있습니다. 접근 가능한 폴더라면 같은 프리셋으로 다음에서 전송된 전사도 받을 수 있습니다: Watch에서 iPhone으로 이어지는 캡처 워크플로. 대기 캡처에는 폴더 권한과 파일 제공자 가용성을 확인하세요.
