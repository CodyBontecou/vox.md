Mac에서 오디오 녹음하기: 내 음성 또는 앱의 소리

먼저 Apple의 기본 제공 녹음 도구와 각각의 Apple 지원 페이지를 소개하고, 이어서 앱 오디오, 보관되는 오디오 파일, 선택 사항인 기기 내 전사본을 위한 로컬 루트를 소개합니다.

작성자
Cody Bontecou

필요 조건
macOS 14 이상 · 마이크 접근 · 쓰기 가능한 폴더
짧은 답변

내 음성을 녹음하려면 둘 다 기본 제공되는 QuickTime Player(파일 → 새로운 오디오 녹음) 또는 음성 메모를 사용하세요. 앱이 재생하는 소리, 또는 앱과 마이크를 함께 녹음하려면 앱 오디오를 캡처하는 도구가 필요합니다. Mac용 Vox.md는 Mac에서 이를 수행하며 오디오를 Markdown 노트 및 전사본과 함께 저장할 수 있습니다.

아래 메뉴 이름은 각 섹션에 링크된 Apple 지원 페이지에서 가져온 것입니다. macOS 버전에 따라 메뉴가 조금 다를 수 있습니다. Vox.md 단계는 다음을 따릅니다: Mac 작업 공간 문서 및 다음을 회의 캡처 문서.

QuickTime Player로 오디오 녹음하기

이 단계는 Apple의 다음 페이지를 따릅니다: Mac의 QuickTime Player에서 오디오 녹음하기.

  1. QuickTime Player를 열고 파일 → 새로운 오디오 녹음.
  2. 녹음 버튼 옆의 화살표를 클릭하여 옵션 메뉴를 엽니다. 마이크에서 입력 장치가 둘 이상이면 선택합니다. 품질에서 설정을 선택합니다. Apple에 따르면 최고 품질은 압축되지 않은 파일을 만들며 저장 공간을 많이 사용할 수 있습니다.
  3. 다음 버튼을 클릭합니다: 녹음 버튼을 눌러 시작하고, 중지 버튼을 눌러 끝냅니다. Apple에 따르면 Option 키를 누른 채 버튼을 클릭하면 일시 정지하고, 다시 클릭하면 재개합니다.
  4. 선택: 파일 → 저장 를 선택하여 녹음 이름을 지정하고 저장 위치를 고릅니다.

QuickTime Player는 전사본을 만들지 않으며, Apple 페이지는 앱 소리 캡처가 아닌 마이크 선택을 설명합니다.

Mac의 음성 메모로 녹음하기

Apple의 Mac에서 녹음 만들기 에서 이 단계를 안내합니다.

  1. 음성 메모 앱을 엽니다.
  2. 다음 버튼을 클릭합니다: 녹음 버튼을 클릭합니다. 내장 마이크, 지원되는 헤드셋 또는 외장 마이크로 녹음할 수 있습니다.
  3. 를 클릭합니다: 일시 정지 를 눌러 일시 정지하고, 재개 를 눌러 계속합니다.
  4. 를 클릭합니다: 완료 를 클릭하여 녹음을 저장합니다.

음성 메모에서 iCloud를 켜고 각 기기에서 같은 Apple 계정을 사용하면 녹음이 Mac, iPhone, iPad에 나타납니다. Apple의 다음 페이지를 참고하세요: 모든 Apple 기기에서 녹음 보기. 메모를 텍스트로 바꾸려면 다음을 참고하세요: iPhone에서 음성 메모 전사하기. Apple은 다음에서 전사 보기도 설명합니다: Mac에서 음성 메모 전사 보기.

Shift-Command-5 단축키로 화면과 오디오 녹화하기

Apple의 Mac에서 스크린샷 또는 화면 녹화 만들기 에서는 다음을 누르라고 안내합니다: Shift-Command-5 를 눌러 스크린샷을 열고 도구를 표시합니다. 화면 녹화 도구를 선택한 다음 옵션 팝업 메뉴를 엽니다. 마이크에서 원하는 마이크 옆에 체크 표시가 나타나도록 선택합니다. 끄려면 없음 를 선택하면 꺼집니다. 옵션 메뉴에서는 녹음 저장 위치 같은 항목도 설정할 수 있습니다.

Apple 페이지는 마이크를 오디오 옵션으로 설명합니다. 앱 자체의 소리를 녹음하는 방법은 설명하지 않으므로, 이 가이드는 도구 막대로 가능하다고 주장하지 않습니다.

앱이 재생하는 소리 녹음하기

위의 기본 제공 녹음 도구는 Apple이 마이크 기준으로 설명합니다. 강의 스트림, 통화, 동영상처럼 특정 앱이 재생하는 소리가 필요하다면 앱 오디오를 캡처할 수 있는 소프트웨어가 필요합니다. 아래 루트는 가상 오디오 드라이버를 사용하지 않습니다.

macOS는 이 기능을 개인정보 보호 권한으로 제한합니다. Apple의 설명은 다음에 있습니다: Mac에서 화면 및 시스템 오디오 녹음에 대한 접근 제어하기: 일부 앱은 Mac에서 화면과 오디오를 녹화할 수 있으며, 허용할 앱은 다음에서 제어합니다: 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음.

Vox.md의 방식. 회의 모드는 Apple의 ScreenCaptureKit 프레임워크 단일 응용 프로그램 모드에서 사용합니다:

  1. 입력 모드를 다음에서 전환합니다: 마이크 대상: 회의.
  2. 녹음을 시작합니다. macOS에 콘텐츠 선택기가 표시되면 응용 프로그램을 정확히 하나만 선택합니다.
  3. 마이크는 별도의 트랙으로 녹음되며, Vox.md는 자체 오디오를 녹음하지 않습니다.
  4. 중지를 누릅니다. 각 트랙은 Mac에서 전사되고, 두 트랙의 재생용 믹스가 녹음의 오디오로 보관됩니다.

이는 선택한 앱 하나와 마이크이며, Mac에서 나는 모든 소리가 아닙니다. 회의 캡처는 일시 정지할 수 없습니다. 루트, 화자 라벨, 복구를 포함한 전체 설정은 다음을 참고하세요: Mac 회의를 로컬에서 전사해 Obsidian에 저장하기.

녹음하기 전에 먼저 물어보세요. 녹음 관련 법률과 직장 규칙은 지역마다 다릅니다. 다른 사람을 녹음할 때는 그 사실을 알리고 동의를 받으세요. 이는 법률 자문이 아닙니다.

Vox.md 무료 다운로드

녹음, 전사, Capture에는 Vox.md Unlimited가 필요합니다. 대상 계정에 7일 무료 체험이 제공되는 주간 또는 연간 구독, 또는 한 번 구매하는 평생 이용권 중에서 고를 수 있습니다. 지역 가격은 App Store에 표시됩니다.

Vox.md로 내 음성을 노트에 녹음하기

내 음성은 Mac용 Vox.md가 개별 파일이 아니라 노트에 마이크로 녹음합니다.

  1. 캡처 작업 공간에서 초안에 추가 를 녹음 전에 선택하면 전사본이 바로 전송되지 않고 검토를 위해 작성창에 들어갑니다.
  2. 녹음합니다. 일시 정지 및 재개 를 상태 막대에서 사용하면 노트 하나를 나누어 녹음할 수 있습니다. 일시 정지한 오디오는 녹음에서 제외됩니다.
  3. 루트에서 오디오를 저장 대상: 노트 옆 또는 첨부 파일 으로 설정해 오디오 파일을 보관합니다. 참고: 오디오 보관.
  4. 보관한 오디오는 다음과 같은 Obsidian 구문으로 노트에 삽입합니다: ![[recording.m4a]].

Whisper 또는 Parakeet 모델을 다운로드하면 Vox.md는 기기에서 전사본도 만들어 줍니다. 모델 참조 은(는) 크기와 언어를 나열하며, Whisper 대 Parakeet 가 선택에 도움이 됩니다. 텍스트를 말로 다른 앱에 입력하려는 것뿐이라면 다음을 참고하세요: Mac 받아쓰기. 설정 방법은 다음에 있습니다: Mac 작업 공간 문서, 요금제는 다음에서 설명합니다: 요금제 및 가격.

이미 녹음이 있나요?

오디오 파일은 다음을 참고하세요: Mac에서 오디오 파일 전사하기.

동영상은 다음을 참고하세요: 비디오를 텍스트로 받아쓰기. 인터뷰를 녹음하나요? 방법, 동의 및 검토.

소리가 없거나 무음 파일

  • 입력 장치. 선택: Apple 메뉴 → 시스템 설정 → 사운드 → 입력 에서 원하는 장치를 선택합니다. Apple의 다음 페이지를 참고하세요: Mac에서 사운드 입력 설정 변경하기.
  • 마이크 권한. 다음을 열고: 시스템 설정 → 개인정보 보호 및 보안 → 마이크에서 앱을 켭니다. Apple의 다음 페이지를 참고하세요: Mac에서 마이크 접근 제어하기.
  • 앱 소리. 다음을 열고: 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음에서 녹음 앱을 켭니다. 참고: Apple 페이지. Vox.md 회의 모드에서는 앱이 재생되는 동안 두 레벨 미터가 모두 움직이는지 확인하세요.
