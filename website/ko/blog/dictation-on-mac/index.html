Mac에서 받아쓰는 방법과 비공개 로컬 옵션

몇 단계로 받아쓰기를 설정하고, 작동하지 않을 때 해결한 다음, 로컬 모델과 Markdown 노트 중 무엇이 맞는지 정하세요.

짧은 답변

시스템 설정 > 키보드에서 Apple 받아쓰기를 켜고 아무 텍스트 필드에서 받아쓰기 단축키를 누르세요. 로컬 Whisper 또는 Parakeet 모델을 고르거나 받아쓴 내용을 Markdown 노트로 보내고 싶다면 Vox.md 전역 단축키를 지정하세요.

아래 Apple의 단계는 Apple 지원 페이지를 바탕으로 합니다: Mac에서 받아쓰기 사용, 2026년 11월 22일에 확인했습니다. 메뉴 이름은 macOS 버전에 따라 다를 수 있으니 해당 페이지에서 사용 중인 버전을 확인하세요. Vox.md 단계는 다음을 따릅니다: 전역 단축키 및 모델 문서.

Mac에서 받아쓰기를 켜는 방법

  1. 선택: Apple 메뉴 > 시스템 설정, 그런 다음 다음을 클릭하세요: 키보드 (사이드바에 있음).
  2. 이동: 받아쓰기 로 이동해 켜세요.
  3. 단축키: 같은 위치에서 다음을 클릭하세요: 단축키 팝업 메뉴에서 받아쓰기를 시작할 단축키를 선택하세요. Apple 페이지에는 기본값이 나와 있지 않으므로 Mac에 설정된 값을 확인하세요.
  4. 언어: 클릭: 편집 옆의 언어에서 언어와 지역을 선택하세요. 받아쓰는 동안에는 커서 옆의 언어를 클릭하거나, 키보드에 Globe 키가 있으면 눌러서 전환할 수 있습니다.
  5. 마이크: 다음을 사용하세요: 마이크 소스 팝업 메뉴에서 받아쓰기에 사용할 마이크를 선택하세요. 자동으로 설정하면 Mac이 가장 많이 쓸 만한 기기의 소리를 듣는다고 Apple은 설명합니다.
  6. 받아쓰기 시작: 텍스트 필드를 클릭한 다음, 기능 키 줄에 마이크 키가 있으면 누르거나, 받아쓰기 단축키를 사용하거나, 다음을 선택하세요: 편집 > 받아쓰기 시작.
  7. 중지: Escape 키, 마이크 키(있는 경우) 또는 받아쓰기 단축키를 누르세요.

처리와 제한에 대해 Apple이 설명하는 내용. Apple은 일반 텍스트 받아쓰기가 "기기에서 처리되고 Siri 서버로 전송되지 않는지" 키보드 설정에서 확인할 수 있다고 설명합니다. 페이지에는 받아쓰기가 오프라인에서 작동한다는 내용이 없습니다. 또한 Apple은 길이에 관계없이 시간 제한 없이 텍스트를 받아쓸 수 있고, 30초 동안 음성이 감지되지 않으면 받아쓰기가 자동으로 중지된다고 설명합니다. 오디오 녹음을 Apple과 공유하는 것은 선택 사항입니다(오디오 녹음 공유). Apple은 받아쓰기가 모든 언어나 지역에서 제공되는 것은 아니며 기능이 다를 수 있다고 밝힙니다. 다음 Apple 페이지를 참고하세요: 받아쓰기 페이지 및 해당 페이지에 연결된 macOS 기능 지원 페이지를 참고하세요. 음성 제어가 켜져 있으면 표준 macOS 받아쓰기를 사용할 수 없다고 Apple은 설명합니다.

Apple 받아쓰기 또는 로컬 받아쓰기 앱

Apple 받아쓰기는 이미 Mac에 들어 있고 많은 사람에게 충분합니다. 음성 모델을 직접 고르거나, 설계상 전사 내용을 Apple 서버에 두고 싶지 않거나, 음성을 Markdown으로 저장하고 싶다면 다른 방법을 고려하세요. 표는 문서에 나온 대로 세 가지 구성을 비교하며, 정확도나 속도에 대한 주장은 하지 않습니다.

작은 화면에서는 표를 옆으로 스와이프하세요.

Vox.md로 모든 Mac 앱에서 받아쓰기

Clipboard에 대한 리뷰 보기 은(는) 전역 단축키입니다. 누르고, 말하고, 다시 누르면 Vox.md가 Mac에서 전사해 텍스트를 클립보드에 넣고, 사용자가 Command-V 키로 붙여넣습니다. 맨 앞의 앱에 직접 입력하지는 않습니다. 노트도 Library 항목도 만들지 않으며 오디오도 보관하지 않습니다.

  1. 설치한 다음 모델을 다운로드하세요. Mac용 Vox.md(macOS 14 이상)를 설치하세요. 다음 모델들 화면에서 모델을 다운로드하세요. Whisper는 Tiny(75MB)부터 Large v3 Turbo(1.6GB)까지, 영어용 Parakeet v2, 25개 언어용 Parakeet v3(각각 약 800MB)가 있습니다. 모든 다운로드는 직접 시작하며, 나중에 모델을 삭제할 수 있습니다. Whisper는 지원되는 Mac에서 Metal 가속을 사용합니다. 전사 언어는 같은 화면에서 선택하세요. 다음을 참고하세요: Whisper 대 Parakeet (선택 방법 안내).
  2. 단축키를 지정하세요. 오픈 설정 > 전역 키 바인드 그리고 다음을 지정하세요: Clipboard에 대한 리뷰 보기. 단축키는 기본적으로 꺼져 있습니다. 단축키에는 보조 키가 아닌 키와 Control, Option 또는 Command가 필요하며 Shift도 포함할 수 있고, Vox.md는 충돌하는 단축키를 거부합니다.
  3. 녹음. 텍스트를 넣을 곳을 클릭하고 단축키를 누른 다음 말하세요.
  4. 중지. 같은 단축키를 다시 누르세요. 메뉴 막대에 전사가 끝났다고 표시될 때까지 기다리세요.
  5. 붙여넣기. Command-V 키를 누르세요.

텍스트가 다시 필요하면 다음을 선택하세요: 마지막 전사 복사 (Vox.md 메뉴 막대에서). 메뉴 막대 동작은 다음에 나와 있습니다: 메뉴 막대 문서. iPhone에서 이에 해당하는 것은 키보드입니다. 다음을 참고하세요: iPhone 음성 텍스트 변환 키보드 가이드 및 iPhone에서 음성을 텍스트로 변환하는 방법 또는 iPad에서.

Obsidian 노트나 Markdown 파일로 받아쓰기

말한 내용이 다른 앱이 아니라 노트에 들어가야 할 때 선택하세요. 다음에서 설정 > 전역 키 바인드에서 다음에 단축키를 지정하세요: 선택한 루트 또는 특정 Route에 지정하세요. 그러면 전사 결과는 그 Route를 따라, 거기서 설정한 데일리 노트, 제목 위치, 처리 모드로 전달됩니다. 이것은 붙여넣기가 아니며, Vox.md가 Route의 대상에 텍스트를 전달합니다. Route는 다음에서 설정하세요: 데일리 노트 템플릿 가이드 및 캡처 템플릿 가이드. 받아쓰기가 아니라 통화 녹음에 대해서는 다음을 참고하세요: Mac 회의를 Obsidian으로. 무료 사용량에는 Capture 전달 성공 10회가 포함됩니다.

Mac에 남는 것

Vox.md는 캡처 내용을 Vox.md 서버로 보내지 않습니다. 전사는 Mac에서 실행됩니다. 네트워크를 사용하는 경우는 사용자가 직접 시작하는 모델 다운로드뿐이며, Hugging Face 또는 FluidAudio 인프라를 사용합니다. 전사 자체는 Mac에서 실행됩니다. 노트가 iCloud나 다른 서비스로 동기화되는 폴더에 저장되면, 해당 서비스가 자체 약관에 따라 파일을 처리합니다. 다음을 참고하세요: 개인정보 처리방침 및 오프라인 전사 설정. Vox.md는 다음을 사용합니다: whisper.cpp (Whisper용) 및 FluidAudio (Parakeet용).

Mac 받아쓰기가 작동하지 않음

Apple 받아쓰기 확인 사항

Apple 페이지 Mac에서 받아쓰기가 기대대로 작동하지 않을 때 다음을 나열합니다:

  • 키보드 설정에서 받아쓰기가 켜져 있는지 확인하세요.
  • 올바른 언어와 지역을 선택하세요. 받아쓰기는 모든 언어나 지역에서 사용할 수 있는 것은 아닙니다.
  • 올바른 받아쓰기 키보드 단축키를 사용하고 있는지 확인하세요. 다른 단축키가 같은 키를 사용한다면 키보드 > 받아쓰기에서 받아쓰기 단축키를 변경하세요.
  • Mac에 내장 마이크가 없다면 외장 마이크가 연결되어 있고 사운드 또는 키보드 설정에서 선택되어 있는지, 입력 볼륨이 충분한지 확인하세요.
  • 마이크가 가려지지 않았는지 확인하고, 너무 작거나 크지 않은 볼륨으로 또렷하게 말하며, 배경 소음을 피하세요.
  • 인터넷 연결이 필요할 수 있습니다. 받아쓰기가 기기에서 처리되는지는 키보드 설정에서 확인하세요.

Vox.md 확인 사항

  • 단축키가 아무 동작도 하지 않음. 단축키는 기본적으로 꺼져 있습니다. 설정 > 전역 키 바인드에서 지정하세요. Vox.md는 충돌하는 단축키를 거부하므로 다른 키 조합을 선택하세요.
  • 전사 결과가 없음. Models 화면에서 모델이 다운로드되어 선택되어 있는지 확인하세요.
  • 언어가 잘못됨. Models 화면에서 언어를 선택하세요.
  • 붙여넣을 내용이 없음. 메뉴 막대에 전사가 끝났다고 표시될 때까지 기다린 다음 Command-V 키를 누르거나 마지막 전사 복사를 선택하세요.

자주 묻는 질문

Mac 받아쓰기는 오프라인에서 작동하나요?

Apple의 받아쓰기 사용 페이지에는 그런 내용이 없습니다. 일반 텍스트 받아쓰기가 기기에서 처리되고 Siri 서버로 전송되지 않는지는 키보드 설정에서 확인할 수 있다고 합니다. 문제 해결 페이지에는 인터넷 연결이 필요할 수 있다고 나와 있습니다. 모델을 다운로드한 후에는 Vox.md가 Mac에서 전사합니다.

시간 제한이 있나요?

Apple에 따르면 길이에 관계없이 시간 제한 없이 텍스트를 받아쓸 수 있으며, 30초 동안 음성이 없으면 받아쓰기가 중지됩니다. Vox.md는 무료 사용량에 15분의 전사가 포함되며, 그 이후에는 한 번만 결제하는 평생 잠금 해제를 이용할 수 있습니다.

단축키를 변경할 수 있나요?

네, 둘 다 가능합니다. Apple 받아쓰기는 시스템 설정 > 키보드 > 받아쓰기의 단축키 팝업 메뉴를 사용하세요. Vox.md는 설정 > 전역 키 바인드에서 보조 키가 아닌 키와 Control, Option 또는 Command를 조합해 지정하세요.

Vox.md에 계정이 필요한가요?

아니요.

로컬 모델로 Mac에서 받아쓰기.

무료 사용량은 15분의 전사와 Capture 전달 성공 10회입니다. 그 이후에는 현지 App Store 가격으로 표시되는 한 번만 결제하는 평생 잠금 해제로 제한이 없어집니다.
