화자 라벨을 붙여 인터뷰를 비공개로 전사하는 방법

동의, 녹음, 전사, 검토 단계, 그리고 참가자 오디오가 전사 서비스에 업로드되지 않는 온디바이스 루트.

작성자
Cody Bontecou
업데이트
2026년 11월 24일
필요 조건
Vox.md: iOS 또는 iPadOS 17.6+ 또는 macOS 14+ · Whisper 또는 Parakeet용으로 다운로드한 음성 모델 · 쓰기 가능한 대상 폴더
짧은 답변

다섯 단계: 1) 동의 받기 오디오가 어떻게 처리되고 저장되는지 설명하세요. 2) 또렷하게 녹음 먼저 테스트를 해 보고, 3) 전사; 4) 오디오와 대조하며 텍스트 검토; 5) 화자 라벨 지정 및 저장. Mac, iPhone, iPad의 Vox.md로 모든 과정을 내 기기에서 처리할 수 있으므로 녹음이 전사 서비스에 업로드되지 않습니다. 화자 라벨은 선택 사항이며 익명이고 최선의 노력으로 붙여집니다(“화자 1”, “화자 2”). 이름은 직접 바꿉니다.

이 방법은 어떤 도구로도 쓸 수 있습니다. Vox.md 단계는 다음을 따릅니다: 모델 및 Mac 문서와 앱의 실제 동작에 근거합니다. 외부 출처는 사용된 곳에 링크되어 있으며, 예시 노트는 실제 인터뷰가 아닌 설명용입니다.

녹음 전에

동의와 데이터 처리. 참가자에게 오디오가 어떻게 처리되고 저장되는지 알리고, 녹음하기 전에 동의를 받으세요. Centre College의 구술사 가이드 에서는 인터뷰어가 화자가 자발적으로 동의했는지 확인하고, 인터뷰 목적을 설명하고, 접근 제한이나 익명 선택 등 선택지를 분명히 해야 한다고 말합니다. 윤리위원회나 데이터 정책도 확인하세요. 참가자 오디오가 어디서 처리되고 저장되는지 묻는 곳이 많으므로, 첫 인터뷰 전에 답을 정해 두세요.

녹음 환경. Harvard Library의 녹음 및 전사 가이드는 전사가 쉬워지므로 먼저 좋은 오디오를 확보하는 데 시간을 쓰라고 조언합니다. 실제로는 다음과 같습니다:

  • 가능하면 화자마다 마이크를 하나씩 사용하고, 각 화자 가까이에 앉으세요.
  • 조용한 방을 고르고, 울리거나 윙윙거리는 것은 모두 끄세요.
  • 실제 인터뷰 전에 짧게 테스트 녹음을 하고 재생해 확인하세요.

축어록인가, 정리본인가?

스타일은 전사하기 전에 정하고 프로젝트 전체에서 동일하게 유지하세요. Centre College 가이드의 전사 중 페이지는 축어록을 군말, 멈춤, 끼어들기, 웃음을 포함해 말 그대로 옮긴 것이라 설명하며, 가장 많은 뉘앙스를 담기 때문에 역사학자들이 선호한다고 말합니다. “정리된 축어록”과 “편집본”은 더 가벼운 스타일의 일반적인 이름이며, 표는 보통 어떻게 다른지 보여 줍니다. 어느 쪽이 필요한지는 프로젝트, 출판사 또는 윤리위원회가 정합니다.

작은 화면에서는 표를 옆으로 스와이프하세요.

일반적인 전사 스타일
스타일보존하는 것적합한 용도
축어록말한 모든 것: 군말, 말 더듬기, 멈춤, 비언어 소리표현과 말투가 데이터인 구술사 및 연구
정리된 축어록말한 단어, 군말과 말 더듬기는 제거표현보다 의미가 중요한 대부분의 인터뷰 분석과 인용
편집본읽기 좋게 고친 글: 문법을 다듬고 일부 구절을 삭제출판용 초안, 프로젝트에서 요구하는 경우 발언자의 승인을 받은 뒤에만

자동 전사는 스타일을 대신 정해 주지 않습니다. 스타일은 검토 단계에서 직접 적용합니다.

전사 방법

이 표는 특정 제품이 아닌 범주를 비교하며, 문서화된 내용만 설명합니다. Apple 음성 메모에 관한 내용은 Apple 지원의 Mac의 음성 메모에서 전사 보기 및 그 iPhone 페이지; 사용 중인 기기, 언어, 지역에서 확인하세요.

작은 화면에서는 표를 옆으로 스와이프하세요.

인터뷰 전사 옵션
 오디오 처리 위치화자 라벨출력비용 모델
직접내 컴퓨터직접 입력모든 텍스트 파일여러분의 시간: 국립공원관리청 녹음 1시간당 약 6~8시간이라고 합니다
클라우드 전사 서비스제공업체의 서버, 각 제공업체의 약관을 확인하세요서비스마다 다름서비스마다 다름서비스마다 다름

Vox.mdiPhone, iPad 또는 Mac에서선택 가입, 익명, 최선의 노력내가 선택한 폴더의 Markdown 노트무료 전사 15분과 성공적인 전달 10회, 이후 일회성 평생 잠금 해제

음성 메모 안에서 빠른 텍스트만 필요하다면 그것을 사용하세요. 참고: 음성 메모를 Markdown으로 전사 녹음을 노트로 옮기는 용도입니다. Vox.md는 전사본을 내가 소유하는 일반 파일로 받고, 모델을 직접 고르고, 선택적으로 화자 라벨을 쓰고 싶을 때를 위한 것입니다.

iPhone 또는 iPad에서 대면으로

  1. 전사 모델 선택. 자동은 지원되는 iOS 26 기기와 언어에서 Apple Speech를 우선합니다. 대신 Whisper(Tiny~Large v3 Turbo), Parakeet v2(영어) 또는 Parakeet v3(25개 언어)를 다운로드할 수 있습니다. 모델 다운로드는 사용자의 선택이며 유일한 네트워크 단계입니다. Whisper 대 Parakeet 선택에 도움이 되며, iPhone에서의 오프라인 전사 준비 방법을 다룹니다.
  2. “Interviews” 루트 만들기. 설정 → 루트에서 Interviews라는 이름의 루트를 만드세요. 대상 폴더(Obsidian 보관함 또는 파일 폴더)를 선택하고 새 노트, 그러면 각 캡처가 별도의 파일이 됩니다. 선택적으로 고정 frontmatter를 추가하고, 항목은 key: value 한 줄에 하나씩, 예를 들면 project: housing-study. 해당 속성 생성기 은(는) 올바른 frontmatter를 만듭니다. 루트의 모든 노트에 적용되므로 참가자 코드는 고정 메타데이터에 넣지 마세요.
  3. 연설자들의 식별 켜기. 각 루트에서 선택해서 켜는 설정입니다. 처음 사용할 때 별도의 화자 모델을 준비하므로, 참가자 앞이 아니라 인터뷰 전에 미리 하세요. 이후에는 로컬에서 실행됩니다. 오픈 소스 FluidAudio 라이브러리는 로컬 화자 처리에 사용됩니다.
  4. 두 사람의 목소리로 30초 테스트를 하세요. 누군가와 짧게 대화를 녹음하고, 노트가 대상 폴더에 도착하며 라벨이 두 개 표시되는지 확인하세요.
  5. 녹음 또는 가져오기. Vox.md 작성기에서 녹음하거나, 기존 오디오 또는 비디오 파일에는 가져오기 컨트롤을 사용하세요 (비디오를 가져오는 방법). 선택: 초안에 추가 전달되기 전에 텍스트를 읽어 보고 싶다면, 또는 즉시 전송 전사가 끝나면 전달하도록.
  6. 라이브러리에서 검토하세요. 라이브러리에는 각 캡처가 표시되며, 화자 식별을 실행하지 못한 경우 그 이유도 표시됩니다.

연설자들의 식별을 켜면 저장된 텍스트에서 각 발언마다 라벨 줄이 붙고, 다음 줄에 그 발언의 텍스트가 오며, 발언 사이는 빈 줄로 구분됩니다:

Speaker 1:
Thanks for agreeing to talk with me today.

Speaker 2:
Happy to. Where would you like me to start?

라벨은 익명이며 최선의 노력으로 붙여집니다. Vox.md는 사람을 이름으로 인식하지 않습니다. Apple Watch 전사 전달과 Mac 앱에서도 사용할 수 있습니다.

짧은 녹음 하나로 시험해 보세요.

무료 사용량은 전사 15분과 성공적인 전달 10회입니다.

Mac에서

  • 기존 파일. 사용: 오디오 가져오기… Mac용 Vox.md에서 오디오와 동영상 파일을 받습니다. 단계는 다음에 있습니다: Mac에서 오디오 파일 전사하기. 익명 라벨을 사용하려면 루트에서 연설자들의 식별을 켜세요.
  • 원격 인터뷰. 회의 캡처는 한 앱의 오디오와 마이크를 별도의 스템으로 녹음합니다. 나는 “나”로 표시되고 상대방은 원격 화자로 라벨이 붙으며, 화자 식별이 여러 원격 목소리를 더 나눌 수 있습니다. 설정은 다음에 있습니다: Mac 회의를 전사해 Obsidian에 저장하기. 위의 동의 단계에서처럼 원격 참가자에게 녹음 중임을 알리세요.
  • 자막 파일. Zoom이나 Teams에서 이미 .srt 또는 .vtt 파일을 받았다면, SRT 및 VTT 변환기 이(가) 브라우저에서 텍스트 또는 Markdown으로 변환합니다.

회의 메모 처리 모드가 있지만 텍스트를 노트 형태로 재구성합니다. 축어 연구 전사본에는 루트를 원본 유지로 두세요.

검토 단계

자동 전사본은 확인이 필요합니다. Harvard의 가이드는 자동 생성된 모든 전사본과 마찬가지로 직접 수정해야 한다고 하며, Centre College 가이드는 자동 전사본이 사람의 작업을 대체하지 못한다고 말합니다.

  1. 다시 듣기 보통 속도 또는 더 느린 속도로 들으면서 읽고, 이름, 용어, 숫자, 날짜를 수정하세요.
  2. 스타일 적용 위에서 고른 축어록 또는 정리본 선택에서 정합니다.
  3. 화자 이름 바꾸기. 찾기 및 바꾸기를 사용해 Speaker 1 인터뷰어 코드에, Speaker 2 를 참가자 코드로 바꿉니다(예: P03).
  4. 익명화 이름, 장소 및 기타 식별 정보를 동의 내용과 데이터 계획이 요구하는 대로 처리합니다.
  5. 원본 오디오 보관 데이터 계획에 따라.

완성된 노트는 다음과 같은 모습일 수 있습니다(지어낸 예시 텍스트):

---
participant: P03
date: 2026-11-24
consent: recorded
---

Interviewer:
Thanks for agreeing to talk with me today.

P03:
Happy to. Where would you like me to start?

문제 해결

  • 화자 라벨이 없습니다. 일반 전사본은 항상 보관되며, 라이브러리에 식별을 건너뛴 이유가 표시됩니다. 이유로는 전사본에 타이밍 정보 없음, 타이밍이 전체 전사본을 포함하지 않음, 구별되는 화자가 감지되지 않음, 모델 저장 공간 없음, 모델을 준비하지 못함, 처리 실패 등이 있습니다. 루트에서 연설자들의 식별이 켜져 있고 화자 모델이 준비되었는지 확인하세요.
  • 화자가 잘못 합쳐지거나 나뉨. 각 목소리에 더 가까이서 녹음하고, 가능하면 별도의 마이크를 사용하고, 라벨은 직접 수정하세요.
  • 긴 녹음. 큰 모델일수록 시간이 더 걸립니다. 먼저 작은 모델을 시도하고, 기기를 충전해 두세요.
  • Parakeet v2가 지원하지 않는 언어. Parakeet v2는 영어 전용입니다. Parakeet v3(25개 언어) 또는 Whisper를 사용하세요. 참고: 모델들.
  • 무료 사용량을 모두 사용함. 전사 15분과 성공적인 전달 10회이며, 이후 일회성 평생 잠금 해제입니다. App Store 가격이 기준입니다.

자주 묻는 질문

인터뷰를 오프라인으로 전사할 수 있나요?

예, 모델이 준비된 후에는 가능합니다. 모델 다운로드와 화자 모델 준비에는 한 번 연결이 필요하며, 그 이후 전사는 기기에서 실행됩니다. 참고: iPhone에서의 오프라인 전사.

Vox.md가 내 녹음을 업로드하나요?

아니요. 전사와 화자 라벨 지정은 기기에서 실행되며, 파일은 선택한 폴더에만 기록됩니다. 해당 폴더가 동기화되는 경우(예: iCloud Drive) 동기화 제공업체가 자체 약관에 따라 파일을 보관합니다. 참고: 개인정보 처리방침.

말하는 사람을 이름으로 알 수 있나요?

아니요. 라벨은 익명(“화자 1”, “화자 2”)이며 최선의 노력으로 붙여집니다. 이름은 직접 바꿉니다.

인터뷰를 직접 전사하면 시간이 얼마나 걸리나요?

National Park Service의 인터뷰 전사 페이지에서는 인터뷰 녹음 1시간당 평균 6~8시간이 걸린다고 합니다.

다음 인터뷰도 내 기기에서 전사하세요.

무료 전사 15분으로 짧은 인터뷰 하나를 테스트한 다음 Markdown 파일을 여세요.
