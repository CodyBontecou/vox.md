iPhone · 공유 시트 · 미디어 캡처

iPhone에서 링크, 사진, 스캔을 Obsidian에 저장

생각 옆에 원본 자료를 두세요. 링크, 이미지, 스캔을 선택한 Markdown 대상으로 보내세요.

작성자
Cody Bontecou
업데이트
2026년 10월 26일
필요 조건
iOS 17.6+ · 쓰기 가능한 보관함 폴더
짧은 답변

Vox.md 캡처 프리셋을 쓰기 가능한 보관함 폴더에 연결하고 빠른 캡처에 URL, 사진, 파일, 스캔을 추가해 보내세요. 프리셋이 노트 및 첨부 위치를 고릅니다. 전달된 Markdown을 검토하고 첨부가 Obsidian에서 열리는지 확인하세요.

링크 저장과 기사 저장은 다릅니다. Vox.md는 웹 URL을 Markdown 링크로 받습니다. URL 추가로 전체 페이지가 다운로드·추출된다고 가정하지 마세요. 보관할 자료에 맞춰 캡처 방법을 고르세요.

이 가이드에서
  1. 보관함 대상 준비
  2. 웹 링크 저장
  3. 사진, 스크린샷, 파일 추가
  4. 문서 스캔 및 OCR 검토
  5. 첨부 및 동기화 확인

1. 보관함 대상 준비

설정 → 캡처 프리셋에서 활성 프리셋을 만들거나 고르고 파일 앱으로 대상을 연결하세요. 보관함의 Markdown 파일이 들어 있는 폴더를 선택하세요. 다른 앱에 공개되지 않은 폴더는 Obsidian 안에서 보인다는 이유만으로 Vox.md가 쓸 수 없습니다.

첫 예제에서는 새 노트와 원본 유지 처리를 선택하세요. 별도 받은 편지함 폴더로 혼합 캡처를 쉽게 찾을 수 있습니다. 나중에 같은 파일에 추가하려면 롤링 노트나 기존 노트를 선택하세요.

대상 설정에서 첨부파일 하위 폴더를 지정하세요. 기본값은 attachments. 보내기 전에 해석된 노트 경로와 첨부 규칙을 확인하세요. 일일 일지는 다음을 따르세요: 일일 노트 라우팅 가이드.

2. 웹 링크 저장

보관할 URL을 복사하세요. 빠른 캡처에서 웹 링크 컨트롤을 사용해 링크 텍스트와 주소를 확인하세요. 저장 이유를 짧게 덧붙인 다음 보내세요.

간단한 노트에는 다음과 같은 Markdown이 들어갈 수 있습니다:

Read before planning the trip:
[Trail information](https://example.com/trail)

위 주소는 예시이며 자료 추천이 아닙니다. 실제 페이지로 바꾸세요. 링크는 출처로 돌아갈 길을 제공하지만 사이트가 바뀌거나 사라져도 콘텐츠를 보존해주지는 않습니다.

Vox.md 공유 시트도 다른 앱의 지원 콘텐츠를 받습니다. 앱이 공유하는 것은 URL, 텍스트, 파일일 수 있습니다. 원본 화면의 모든 것이 포함된다고 생각하지 말고 받은 내용과 선택 프리셋을 확인하세요.

3. 사진, 스크린샷, 파일 추가

  1. 받은 편지함이나 프로젝트 노트의 프리셋을 선택하세요.
  2. 사진/스크린샷 선택기, 카메라, 파일 추가 컨트롤로 자료를 고르세요.
  3. 작성 화면에 짧은 제목이나 설명을 추가하세요.
  4. 보낸 뒤 Obsidian에서 노트를 열어 임베드 이미지나 파일 링크를 확인하세요.

이미지는 Markdown에 임베드되고 다른 파일은 링크로 표시됩니다. 설정된 첨부 경로를 노트에서 참조하는 예:

## Reference
![[attachments/whiteboard.png]]
[[attachments/brief.pdf]]

파일명과 경로는 예시입니다. Vox.md의 실제 출력은 선택한 파일과 대상 규칙에 따라 달라집니다. 참조 파일을 보관함과 함께 두세요. Markdown 파일만 다른 폴더로 옮기면 상대 링크가 깨질 수 있습니다.

성공 캡처 전송 10회와 전사 15분을 체험하세요. 무제한 사용은 일회성 평생 구매입니다.

4. 문서 스캔 및 OCR 검토

캡처 바의 스캔 문서를 선택하고 안내를 따르세요. Vox.md는 페이지 이미지를 보관하고 PDF와 가능한 범위의 기기 내 텍스트 인식을 제공합니다. 특히 이름, 날짜, 금액, 손글씨는 보내기 전에 확인하세요.

일지 사진의 별도 텍스트 추출 흐름은 수동 촬영·선택한 페이지를 지원합니다. 이미지가 선명해도 OCR은 구조나 단어를 오인할 수 있습니다. 나중 검증이 필요하면 원본 이미지나 스캔을 보관하세요.

선택적 처리가 캡처 텍스트를 재작성하지 않도록 하려면 원본 유지를 선택하세요. 입력 및 혼합 텍스트 처리는 프리셋에서 별도로 활성화합니다. 캡처 참조 는 지원 입력을, 다음은 입력 제한.

첨부 및 동기화 확인

전송 후 Obsidian에서 노트와 각 링크를 열고 원하는 파일이 있는지 확인하세요. 다른 기기에 노트가 보여도 모든 첨부 동기화 완료를 뜻하지 않습니다. 그 기기에서 이미지나 PDF도 확인하세요.

쓰기 실패는 Vox.md에서 대기 상태로 남을 수 있습니다. 다른 사본을 만들기 전에 대상 접근을 고치고 기존 캡처를 재시도하세요. 캡처 처리는 로컬이어도 클라우드 제공자의 파일은 접근이나 동기화에 연결이 필요할 수 있습니다.

웹페이지 전체 추출이 필요하다면 관련 도구를 직접 비교하세요. Obsidian의 기본 공유 옵션은 다음 문서에 나와 있습니다: 공식 iOS 가이드. 한 작업은 기본 공유로, 다른 작업은 Vox.md 프리셋으로 처리할 수 있습니다.

맥락을 유지하세요.
노트 옆에 두세요.

링크나 이미지 하나로 작은 캡처를 시험하고 전체 파일과 첨부파일 출력을 확인하세요.
