iPhone · 통화 녹음 · 기기 내 처리

iPhone에서 통화를 녹음하고 비공개로 전사하는 방법

Apple 기본 통화 녹음을 단계별로 설명하고, 통화를 업로드하지 않고도 직접 보관하는 전사본을 얻으려면 다음에 무엇을 해야 하는지 안내합니다.

작성자
Cody Bontecou
업데이트
2026년 11월 27일
필요 조건
통화 녹음을 지원하는 iPhone(Apple이 제공하는 곳의 iOS 18 이상) · Vox.md: iOS 17.6+ · 준비된 전사 백엔드
짧은 답변

통화를 시작하고 다음을 탭하세요: 더 보기. 그다음 탭하세요 통화 녹음. 두 사람 모두에게 안내음이 들립니다. 녹음과, 지원되는 경우 전사본은 Notes의 통화 녹음 폴더에 저장됩니다. 비공개 전사본을 Markdown 노트로 보관하려면 오디오를 Files에 저장하고 Vox.md로 가져오세요. iPhone에서 전사됩니다.

녹음 단계는 Apple의 공식 문서에서 가져왔으며, 사용된 곳에 링크가 있습니다. Vox.md 단계는 다음을 따릅니다: 인라인 음성 문서 및 앱의 실제 동작을 따릅니다. 이 내용은 문서와 소스를 통해 추적한 것이며, 새 기기에서 직접 실행해 확인한 것은 아닙니다.

녹음하기 전에: 동의와 법

Apple의 안내서는 통화 상대방이 녹음에 동의하는지 확인하라고 안내합니다. 통화 녹음에 관한 규정은 주와 국가마다 다르며, 일부 지역에서는 통화에 참여한 모든 사람의 동의가 필요합니다. 본인과 상대방이 있는 곳의 법을 확인하세요. 이는 일반적인 정보이며 법률 자문이 아닙니다.

간단한 습관이 있습니다. 시작할 때 녹음하고 싶다고 말하고 동의한다는 대답을 기다리세요. 인터뷰라면 오디오를 어떻게 보관하고 사용할지도 정해 두세요. 인터뷰 전사 가이드 는 전화 인터뷰를 녹음할 때의 동의와 검토를 다룹니다.

전화 앱으로 통화 녹음하기

Apple은 다음에서 이 단계를 설명합니다: iPhone에서 통화 녹음 및 전사:

  1. 다음을 여세요 전화 앱을 열고 전화를 거세요.
  2. 통화 중에 다음을 탭하세요: 더 보기. 그다음 탭하세요 통화 녹음.
  3. 통화 참여자 두 사람 모두에게 통화가 녹음되고 있다는 음성 안내가 들립니다.
  4. 중지하려면 중지 버튼을 탭하거나 전화를 끊으세요.
  5. iPhone은 녹음을 다음에 저장합니다: 통화 녹음 폴더에 저장됩니다. 다음을 탭하세요: 저장된 통화 보기 을(를) 열어 보세요.

요구 사항. Apple 지원 문서 iPhone에서 통화를 녹음하고 전사하는 방법 에 따르면 iOS 18부터 iPhone에서 전화 통화나 FaceTime 오디오 통화를 녹음할 수 있습니다. 통화 녹음은 모든 언어와 지역에서 제공되지는 않습니다. 시작하기 전에 Apple의 다음 문서를 확인하세요: iOS 및 iPadOS 기능 제공 여부 페이지에서 내 모델을 확인하세요.

Apple은 통화 녹음이 기본적으로 켜져 있으며 다음에서 끌 수 있다고도 설명합니다: 설정 → 앱 → 전화 → 통화 녹음. 통화 중에 이 옵션이 보이지 않으면 해당 설정, iOS 버전, 지원 여부 페이지를 확인하세요.

Notes에서 녹음과 Apple의 전사본 찾기

  1. 다음을 여세요 메모 앱.
  2. 다음을 여세요 통화 녹음 폴더를 열고 노트를 탭하세요.
  3. 녹음을 탭하면 재생됩니다.

Apple에 따르면 전사본은 일부 지역과 언어에서만 제공되며 바로 준비되지 않을 수 있습니다. 전사가 진행 중이라는 메시지가 표시될 수 있습니다. 전사본이 보이지 않는다면 Apple은 iPhone이 최소 요구 사항을 충족하지 않거나 지원되는 언어를 감지하지 못한 것이라고 설명합니다. Apple은 전사본을 믿고 쓰기 전에 정확도를 확인하라고 안내합니다. 전사본에서 Apple은 각 발언의 화자를 구분하며, 전사본을 복사하거나 노트에 추가할 수 있습니다.

Apple에 따르면 요약 옵션은 iPhone이 Apple Intelligence를 지원하는 경우에 나타납니다. 다음을 확인하세요: Apple 페이지 에서 지원되는 기기와 언어를 확인하세요.

통화 오디오를 Files에 저장하기

다른 앱에서 오디오를 쓰려면 Notes에서 꺼내야 합니다. Apple의 안내서에 따라 녹음을 연 상태에서 다음을 하세요.

  1. 탭하세요: 더 보기. 그다음 탭하세요 오디오 파일 저장을(를) 탭하고 녹음을 저장할 위치를 선택하세요. 나중에 다시 찾을 수 있는 Files의 폴더를 고르세요.
  2. 또는 다음을 탭하세요: 더 보기, 그다음 오디오 공유을(를) 탭한 다음 공유 방법을 선택하세요.

믿을 수 있는 사본을 확보하기 전에는 Notes의 오디오를 삭제하지 마세요. Apple에 따르면 오디오 녹음을 삭제하면 해당 전사본도 삭제됩니다. 저장이 멈추면 iPhone의 저장 공간이 충분한지, 대상 폴더를 사용할 수 있는지 확인한 뒤 다시 시도하세요.

Apple의 전사본으로 부족할 때

Apple의 전사본으로 충분하다면 그대로 쓰세요. Notes에서 복사하면 끝입니다. 다음과 같은 경우에는 다른 방법을 찾게 됩니다.

  • 해당 지역이나 언어에서는 전사본이 표시되지 않습니다.
  • 텍스트를 자신의 노트 앱이나 Obsidian 보관함에 일반 Markdown 파일로 두고 싶어 합니다.
  • 직접 고른 전사 백엔드를 쓰고, 화자에 자신이 정한 이름을 붙이고 싶어 합니다.
  • 통화 텍스트를 다른 노트 옆에 두고 싶어 합니다. 예를 들어 회의 노트 구조.

Vox.md로 iPhone에서 통화 전사하기

내보낸 뒤 가져오는 방식은 다음과 같습니다: 음성 메모 전사하기; 통화의 경우 오디오는 대신 Notes에서 가져옵니다.

  1. 백엔드를 선택하세요. 자동은 iOS 26을 지원하는 기기와 언어에서 Apple Speech를 사용합니다. 그렇지 않으면 연결되어 있을 때 Whisper 또는 Parakeet을 먼저 다운로드하세요. Whisper 대 Parakeet 이(가) 선택을 도와주고, 모델 참조 에 요구 사항이 나와 있습니다. iPhone에서의 오프라인 전사 에서 모델 준비 방법을 다룹니다.
  2. 선택 사항: 연설자들의 식별 켜기 을(를) 루트에서 켜세요. 라벨은 익명이며 최선의 노력으로 붙여집니다(“화자 1”, “화자 2”). 이름은 직접 바꿉니다. 처음 사용할 때는 별도의 화자 모델을 준비합니다. 실행할 수 없으면 일반 전사본이 유지됩니다.
  3. 파일을 가져오세요. 빠른 캡처의 음성 컨트롤에서 다음을 여세요: 오디오 또는 비디오 가져오기 을 탭하고 Files에서 저장된 통화 오디오를 선택하세요.
  4. 검토하고 보내세요. 사용: 초안에 추가 이름, 숫자, 날짜를 오디오와 대조해 확인한 다음, Obsidian 보관함 폴더나 Files 폴더처럼 루트의 대상으로 보내세요.
  5. 선택 사항: 오디오 보관하기 을(를) 탭하고 다음 문법으로 노트에 삽입하세요: ![[recording.m4a]]. 다음도 참고하세요: 문서 에서 오디오 보관 옵션을 확인하세요.

가져오면 오디오를 다시 전사합니다. Vox.md는 Apple의 전사본을 가져오지 않으므로 Notes에 표시되는 문구와 다를 수 있습니다.

iPhone 밖으로 나가는 것

Vox.md는 Apple Speech, Whisper 또는 Parakeet으로 기기에서 전사하며, 통화 오디오는 Vox.md 서버로 전송되지 않습니다. 모델을 다운로드할 때는 모델 호스트에 연결합니다. iCloud Drive처럼 대상 폴더가 동기화되는 경우, 해당 제공업체가 자체 약관에 따라 파일을 동기화합니다. 다음을 참고하세요: 개인정보 처리방침.

제한 사항

  • Vox.md는 통화를 녹음하지 않습니다. 녹음은 Apple이 통화 녹음을 제공하는 곳에서만 작동합니다.
  • Vox.md에는 통화 중 실시간 전사가 없습니다. 통화가 끝난 뒤 저장된 오디오 파일에서 전사합니다.
  • Vox.md는 Apple의 전사본을 가져오지 않습니다.
  • 정확도는 최선의 노력 수준이며 오디오, 언어, 백엔드에 따라 달라집니다. 텍스트를 녹음과 대조해 확인하세요.
  • 녹음, 전사, Capture에는 Vox.md Unlimited가 필요합니다. 주간 또는 연간 구독(대상 계정은 7일 무료 체험)이나 1회 평생 구매 중에서 선택할 수 있습니다. 자세한 내용은 문서의 가격 안내; App Store 가격이 기준입니다.

녹음을 전사하는 대신 아무 앱에나 말로 입력하려면 다음을 참고하세요: iPhone에서 음성-텍스트 변환.

자주 묻는 질문

상대방이 제가 녹음하는 것을 알게 되나요?

네. Apple에 따르면 통화 참여자 두 사람 모두에게 통화가 녹음되고 있다는 음성 안내가 들립니다.

통화 녹음이 왜 보이지 않나요?

사용 중인 언어와 지역에서는 제공되지 않을 수 있습니다(다음 참고: Apple의 지원 여부 페이지), iOS 버전이 iOS 18보다 낮거나 설정 → 앱 → 전화에서 이 기능이 꺼져 있을 수 있습니다.

통화 녹음은 어디에 저장되나요?

Notes 앱의 통화 녹음 폴더에 있습니다.

오디오 파일을 받을 수 있나요?

네. Notes에서 녹음을 열고 더 보기를 탭한 다음 오디오 파일 저장을 탭하고 위치를 선택하세요.
