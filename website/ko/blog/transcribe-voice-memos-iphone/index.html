iPhone 음성 메모를 Markdown으로 전사

Apple 전사로 충분하면 거기서 시작하세요. Vox.md 로컬 전사와 Markdown 대상이 필요할 때 오디오를 가져오세요.

작성자
Cody Bontecou
업데이트
2026년 10월 30일
필요 조건
저장된 녹음 · 준비된 백엔드
짧은 답변

iPhone 음성 메모를 텍스트로 바꾸려면 전사가 이미 있는지 확인하세요. 복사로 해결되면 그대로 복사하세요. Vox.md 기기 내 전사와 Markdown 라우팅은 녹음을 파일 앱으로 내보내고 Vox.md로 가져와 전사를 검토한 뒤 원하는 폴더에 저장하세요.

이 가이드는 Apple 음성 메모의 기존 녹음부터 시작합니다. Vox.md에서 직접 새로 녹음하려면 다음을 사용하세요: 음성 노트를 Obsidian으로 보내는 가이드. 안내는 문서와 소스 검토에 기반하며 새로 기기에서 내보내기한 결과가 아닙니다.

이 가이드에서
  1. Apple 전사 시험
  2. 녹음 내보내기
  3. Vox.md 준비
  4. 가져오기 및 검토
  5. Markdown 파일 확인
  6. 제한 및 복구 확인

1. 음성 메모에 텍스트가 이미 있는지 확인

Apple 문서에는 전사를 지원하는 iPhone, 언어, 지역이 나와 있습니다. 음성 메모에서 녹음을 선택하고 다음을 여세요: 더 보기 메뉴를 열고 다음을 찾으세요: 전사 보기 또는 전사본 복사. 텍스트만 필요하면 전체 전사나 선택 텍스트를 복사해 노트에 붙여넣으세요.

Apple에서 제공하는 전사 내용을 복사하기 위해 별도 앱이 필요하지는 않습니다. 다음을 확인하세요: Apple 전사 가이드 에서 현재 지원 여부를 확인하세요. 옵션이 없는 것은 기기, 시스템, 언어 또는 지역 지원 때문일 수 있으며 오디오 손상을 의미하지는 않습니다.

2. Vox.md에서 전사하려면 오디오 내보내기

Apple의 음성 메모 내보내기 안내 에서 녹음 선택 및 다음 열기를 설명합니다: 더 보기 → 공유, 다음 선택: 파일에 저장. 다시 찾을 수 있는 폴더를 고르고 저장하세요.

일반 내보내기 형식: .m4a 녹음입니다. 옵션에 따라 편집 가능한 레이어나 효과를 다른 표현으로 유지할 수 있습니다. 이 워크플로에서는 일반적인 단일 오디오 내보내기부터 사용하세요. 모든 레이어형 또는 편집 가능한 내보내기가 모든 전사 백엔드에서 작동한다고 보장하지 않습니다. 원본 음성 메모를 보관하세요.

오디오 파일 공유와 Apple 전사 내용 복사는 다릅니다. 오디오를 Vox.md로 가져오면 선택한 전사 백엔드를 다시 실행하며 Apple의 전사 내용을 가져오거나 동일한 문구를 보장하지 않습니다.

3. 백엔드와 Markdown 대상 준비

iPhone용 Vox.md 받기

  1. Vox.md에서 기기와 녹음 언어에 맞는 전사 백엔드를 고르세요. 연결 상태에서 모델 다운로드를 마치세요.
  2. 쓰기 가능한 Markdown 폴더가 있는 캡처 프리셋을 만들거나 선택하세요. 사용: 새 노트 을 첫 가져오기에 사용해 결과 파일을 쉽게 찾으세요.
  3. 선택: 원본 유지 처리를 사용하면 선택적인 AI 재작성 없이 인식된 텍스트를 얻을 수 있습니다.
  4. 빠른 캡처 음성 컨트롤에서 선택: 초안에 추가 을 가져오기 전에 선택해 첫 전사를 검토하세요.

원본 유지는 인식된 텍스트를 보존할 뿐 인식을 완벽한 축어나 무오류로 만들지 않습니다. 자동, Apple Speech, 다운로드 모델은 기기와 언어 요건이 다릅니다. 확인: 모델 참조 및 설치된 앱의 현재 구매 또는 접근 요건을 확인한 후 긴 녹음을 가져오세요.

Obsidian은 파일 앱에 공개된 실제 보관함 폴더를 선택하세요. Vox.md는 Obsidian Sync에 직접 연결하지 않습니다. 일반 쓰기 가능한 Markdown 폴더도 됩니다.

4. 저장된 녹음 가져오기 및 초안 검토

  1. 오픈 오디오 또는 비디오 가져오기 빠른 캡처 음성 컨트롤에서 사용하세요.
  2. 파일 앱에서 내보낸 녹음을 고르고 가져오기와 전사 완료를 기다리세요.
  3. 초안에 추가를 선택하고 작성 화면에서 전사를 검토하세요. 원본 오디오와 대조해 이름, 날짜, 숫자, 중요한 문구를 수정하세요.
  4. 선택한 프리셋과 대상을 확인한 뒤 다음을 탭하세요: 보내기.

일반 파일 첨부 대신 전사 가져오기 컨트롤을 쓰세요. 노트의 오디오 첨부 자체는 전사가 아닙니다.

다음을 사용하면 즉시 전송 을 대신 선택하면 같은 초안 검토 없이 완성 전사를 선택 프리셋으로 처리합니다. 첫 확인에는 초안에 추가부터 설정하세요. 가져오기 전에 진행 녹음을 마치세요.

5. 실제 Markdown 파일 확인

전송 완료를 기다리세요. 파일 앱이나 Obsidian에서 대상을 열어 파일, 텍스트, 파일명을 확인하세요. 작성 화면의 전사는 인식이 텍스트를 만들었음을 증명할 뿐 폴더 쓰기 성공은 아닙니다.

가상 녹음으로 다음 노트 본문을 만들 수 있습니다:

Review the garden plan on Saturday.
Bring the updated measurements.

예시 출력이며 실제 녹음이나 정확도 테스트가 아닙니다. 프리셋이 파일명, 메타데이터, 서식을 결정합니다. 새로 가져온 항목의 날짜나 파일명이 원래 음성 메모 녹음 날짜가 되지는 않습니다. 필요할 때 직접 해당 맥락을 추가하세요.

새 노트 가져오기 한 건이 작동하면 다음을 따르세요: 일일 노트 가이드 을 롤링 대상에 사용하거나 다음을 템플릿 예제 를 받은 편지함이나 할 일 항목에 사용하세요. 오래된 녹음을 일일 일지로 보내기 전에 대상 노트의 날짜와 경로를 맞추세요.

제한, 개인정보 보호, 가져오기 실패

  • 가져오기를 사용할 수 없음: 현재 녹음을 마치고 앱 접근 요건과 선택 프리셋 활성화를 확인하세요.
  • 인식 실패: 백엔드 준비, 언어, 로컬 공간, 오디오 디코딩 가능 여부를 확인하세요. 원본을 보관하고 길거나 특이한 파일 전에 짧은 일반 오디오 내보내기로 시험하세요.
  • 전송 대기 중: 폴더 접근 권한을 복구하고 보관된 실패 전송을 다시 시도하세요. 같은 메모를 다시 가져오면 두 번째 캡처가 생성될 수 있습니다.
  • 원본 오디오도 필요하다면: 오디오 보관은 별도로 설정하고 확인하세요. 텍스트가 나왔다고 모든 프리셋이 오디오 첨부를 저장한다고 가정하지 마세요.

Vox.md는 기기에서 전사합니다. 초기 백엔드 준비에는 다운로드가 필요할 수 있고 파일 제공자는 원본을 가져오거나 대상에 쓰기 위해 연결이 필요할 수 있습니다. 동기화 폴더에 오디오나 Markdown을 저장하면 해당 제공자가 동기화를 처리합니다. 완전한 연결 해제 워크플로는 다음을 따르세요: 오프라인 준비 및 확인 가이드.

이 루트는 음성 메모 라이브러리 자동 동기화나 일괄 보관 가져오기가 아니며 Apple의 편집, 레이어, 전사 시간, 녹음 메타데이터 보존을 약속하지 않습니다. 녹음 하나부터 시작해 원본을 보관하고 저장 텍스트를 검증한 뒤 확장하세요.
