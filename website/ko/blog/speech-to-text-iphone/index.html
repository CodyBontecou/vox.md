iPhone에서 음성을 텍스트로 변환 켜는 방법

  1. 다음을 여세요 설정 앱에서 탭하세요 일반. 그다음 탭하세요 키보드.
  2. 켜세요: 받아쓰기 활성화. 안내가 나타나면 탭하세요 받아쓰기 활성화 다시.
  3. 텍스트 필드에서 텍스트를 넣고 싶은 위치를 탭해 삽입 위치를 지정하세요.
  4. 마이크(받아쓰기) 키를 화면 키보드에서 탭하거나, 키가 나타나는 아무 텍스트 필드에서 탭하세요. 삽입 위치 근처에 마이크 표시가 나타나면 말하기 시작하세요.
  5. 중지: 마이크 키를 다시 탭하거나, “받아쓰기 중지”라고 말하거나, 30초 동안 조용히 있으면 받아쓰기가 자동으로 멈춥니다.

받아쓰기를 끄려면 설정 > 일반 > 키보드로 돌아가 다음을 끄세요 받아쓰기 활성화. Apple에 따르면 받아쓰기 중에도 키보드가 열려 있으므로 터치와 음성을 오갈 수 있습니다. 다른 언어의 키보드를 사용 중이면 그 언어로도 받아쓰기를 쓸 수 있다고 Apple은 설명합니다. 또한 받아쓰기를 사용할 때 셀룰러 데이터 요금이 부과될 수 있다고도 합니다.

문장 부호, 이모지, 줄 바꿈

  • 문장 부호: 기호의 이름을 말하세요. 예: “느낌표”.
  • 이모지: 이모지의 이름을 말하세요. 예: “하트 이모지”, “웃는 얼굴 이모지”.
  • 줄 바꿈: “새 줄” 또는 “새 단락”이라고 말하세요.
  • 철자: “Steven S-T-E-P-H-E-N을 초대하자”처럼 말하세요.
  • 편집: “선택” 또는 “삭제” 다음에 바꾸고 싶은 구절을 말하세요. 명령을 되돌리거나 다시 실행하려면 “실행 취소”, “다시 실행”이라고 말하세요.

지원되는 언어에서는 받아쓰기 중에 쉼표, 마침표, 물음표가 자동으로 입력된다고 Apple은 설명합니다. 이를 끄려면 설정 > 일반 > 키보드로 이동해 다음을 끄세요 자동 문장 부호. Apple은 전체 목록을 다음에 게시합니다 iPhone에서 텍스트를 받아쓰는 명령.

iPhone 받아쓰기는 오프라인에서 작동하나요?

Apple은 이렇게 설명합니다. “받아쓰기는 많은 언어에서 iPhone에서 처리되며 인터넷 연결이 필요하지 않습니다. 검색 필드에서 받아쓰면 검색을 처리하기 위해 받아쓴 텍스트가 검색 엔진으로 전송될 수 있습니다.” 또한 받아쓰기는 모든 언어나 국가 또는 지역에서 사용할 수 없을 수 있고 기능이 다를 수 있다고 합니다. Apple의 다음 페이지를 확인하세요 iOS 및 iPadOS 기능 제공 여부 사용하는 언어의 페이지.

Apple 페이지에는 iOS 27의 Apple Intelligence에서 받아쓰기가 온디바이스 모델을 사용해 철자, 문장 부호, 대소문자를 개선한다고 나와 있습니다. 이는 iPhone 17 Pro, iPhone 17 Pro Max, iPhone Air 이후 모델의 영어에서 사용할 수 있으며, iOS 27 이상의 Apple Intelligence는 Apple Intelligence가 활성화된 iPhone 15 Pro, iPhone 15 Pro Max 또는 iPhone 16 이후 모델에서 사용할 수 있다고 설명합니다. Apple Intelligence는 모든 언어나 지역에서 사용할 수 있는 것은 아니며 사용 제한이 적용될 수 있습니다.

Apple 받아쓰기, Vox.md 키보드 또는 Vox.md 루트

Apple 받아쓰기는 기본 제공되며 많은 사람에게 충분합니다. 음성 모델을 직접 고르거나 음성을 Markdown으로 저장하고 싶다면 대안을 살펴보세요. 표는 문서화된 세 가지 구성을 비교하며, 정확도나 속도에 대한 주장은 하지 않습니다.

작은 화면에서는 표를 옆으로 스와이프하세요.

Vox.md 키보드로 어떤 앱에서든 로컬 모델 사용하기

  1. 전사를 준비하세요. Vox.md에서 지원되는 기기라면 자동을 유지하거나, 다음에서 Whisper 또는 Parakeet을 다운로드해 선택하세요 설정 > 모델.
  2. 키보드를 추가하세요. iOS 설정에서 일반 > 키보드 > 키보드 > 새로운 키보드 추가로 이동해 다음을 선택하세요 Vox.md.
  3. 전체 접근 허용을 켜세요. Vox.md는 이를 온디바이스 앱과 키보드 워크플로, 공유 상태, 선택적 햅틱에 사용하며, 키 입력, 받아쓴 텍스트, 전사본, 마이크 오디오를 Vox.md 서버로 업로드하지 않습니다. 다음을 참고하세요 키보드 설정 문서.
  4. 전환해서 받아쓰세요. 텍스트 필드에서 지구본 키로 Vox.md를 선택한 다음 마이크를 탭하세요.

전체 안내는 다음을 참고하세요 iPhone 음성 텍스트 변환 키보드 가이드. 모델을 고르려면 다음을 읽어 보세요 Whisper 대 Parakeet.

음성을 텍스트로 변환해 Obsidian이나 Markdown 파일에 바로 넣기

말한 내용을 다른 앱이 아니라 노트에 남기고 싶을 때 선택하세요. Vox.md에서 녹음하면 루트가 전사본을 일일 노트, 제목 아래 또는 새 노트로 전달합니다. 다음으로 시작하세요 Obsidian으로 음성 메모. 그다음 다음을 참고하세요 일일 노트에 추가하기 또는 비공개 음성 일기. 긴 녹음이나 기존 오디오는 다음을 참고하세요 음성 메모 전사 및 Markdown으로 오프라인 전사. 무료 사용량에는 Capture 전달 성공 10회가 포함됩니다.

iPhone에 남는 것

Vox.md는 캡처 내용을 Vox.md 서버로 보내지 않습니다. 전사는 iPhone에서 실행됩니다. 네트워크를 쓰는 경우는 직접 시작하는 모델 다운로드뿐이며, Hugging Face 또는 FluidAudio 인프라를 사용합니다. 노트가 iCloud 등으로 동기화되는 폴더에 저장되면, 해당 서비스가 자체 약관에 따라 파일을 처리합니다. 다음을 참고하세요 개인정보 처리방침. Vox.md는 다음을 사용합니다: whisper.cpp (Whisper용) 및 FluidAudio (Parakeet용).

iPhone 받아쓰기가 작동하지 않음

Apple 받아쓰기 확인 사항

다음에서 가져온 내용입니다 iPhone에서 텍스트 받아쓰기:

  • 마이크 키가 보이지 않으면 설정 > 일반 > 키보드로 이동해 다음을 켜세요 받아쓰기 활성화. 안내가 나타나면 받아쓰기 활성화를 탭하세요.
  • 받아쓰기는 모든 언어나 지역에서 사용할 수 없을 수 있습니다. Apple의 다음 페이지를 참고하세요 기능 제공 여부 페이지.
  • 30초 동안 조용하면 받아쓰기가 자동으로 멈춥니다. 마이크 키를 탭하면 다시 시작합니다.
  • 검색 필드에서는 받아쓴 텍스트가 검색 엔진으로 전송될 수 있습니다.

Vox.md 확인 사항

  • 키보드에 전체 접근 활성화라고 표시됩니다. iOS 설정 > 일반 > 키보드 > 키보드 > Vox.md를 열어 전체 접근 허용을 켠 다음, 앱으로 한 번 돌아가세요.
  • 키보드에 Vox.md 열기라고 표시됩니다. 듣기가 활성화되어 있지 않으면 키보드가 Vox.md를 한 번 열어 듣기를 시작합니다.
  • 전사 결과가 없음. 설정 > 모델에서 모델이 완전히 다운로드되어 선택되어 있는지 확인하세요.
  • 자동을 사용할 수 없음. 지원되는 iOS 26 기기와 언어가 필요합니다. 대신 Whisper 또는 Parakeet 모델을 선택하세요.

더 보기 Vox.md 문제 해결 문서. 키보드를 연결한 iPad에서는 Magic Keyboard로 받아쓰기.

자주 묻는 질문

iPhone 받아쓰기는 무료인가요?

Apple 페이지에는 요금에 대한 언급이 없지만, 셀룰러 데이터 요금이 부과될 수 있다고 나와 있습니다. Vox.md에는 15분의 전사가 포함되어 있고, 이후에는 구독 없이 한 번만 결제하는 평생 잠금 해제가 있습니다.

오프라인에서도 작동하나요?

Apple에 따르면 받아쓰기는 많은 언어에서 iPhone에서 처리되며 인터넷 연결이 필요 없습니다. 다만 검색 필드에 받아쓴 텍스트는 검색 엔진으로 전송될 수 있습니다. 모델을 다운로드하고 나면 Vox.md는 iPhone에서 전사합니다.

시간 제한이 있나요?

Apple에 따르면 받아쓰기는 30초 동안 조용하면 자동으로 멈춥니다. 해당 페이지에는 최대 길이가 명시되어 있지 않습니다.

Vox.md 키보드에 전체 접근이 필요한 이유는 무엇인가요?

현재 키보드 워크플로가 공유 App Group 상태를 사용하고 메인 앱과 녹음을 조율하려면 필요합니다. Vox.md는 키 입력, 받아쓴 텍스트, 전사본, 마이크 오디오를 Vox.md 서버로 업로드하지 않습니다.

Obsidian에 받아쓰기할 수 있나요?

예. Vox.md 루트를 사용해 보관함의 노트로 전사본을 전달할 수 있습니다. 예 음성 메모 가이드.

로컬 모델을 고르거나 노트에 받아쓰기하세요.

무료 사용량은 15분의 전사와 Capture 전달 성공 10회입니다. 그 이후에는 현지 App Store 가격으로 표시되는 한 번만 결제하는 평생 잠금 해제로 제한이 없어집니다. 키보드 설정 문서.
