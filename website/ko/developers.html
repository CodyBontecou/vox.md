공개 정보 API

제품 정보 및 문서 찾기

Vox.md 공개 정보 API는 제품 정보와 게시된 문서 링크를 제공합니다. 무료이며 계정, API 키, OAuth 절차, 결제가 필요하지 않습니다. 엔드포인트는 이 공개 웹사이트에 이미 있는 정보를 반환합니다. 다음을 읽으세요: OpenAPI 3.1 계약 에서 형식이 지정된 응답 스키마, 작업 식별자, 오류, 설명을 확인하세요.

제품 정보 받기

GET https://vox.isolated.tech/api/v1/product 는 제품명, 설명, 지원 운영체제, App Store 페이지, 문서 URL, 지원 URL을 반환합니다. 빌드는 홈페이지 구조화 데이터에서 정보를 가져옵니다.

curl https://vox.isolated.tech/api/v1/product

제품 JSON 보기

문서 찾기

GET https://vox.isolated.tech/api/v1/documents 는 공개 페이지 제목, 요약, URL을 나열합니다. 콘텐츠 요청 전에 관련 기능 가이드, 방침, 블로그 글, 지원 페이지를 찾으세요.

curl https://vox.isolated.tech/api/v1/documents

문서 색인 JSON 보기

페이지를 Markdown으로 읽기

목록의 페이지를 다음으로 요청하세요: Accept: text/markdown 로 주요 콘텐츠를 제공합니다. 다음을 포함한 요청은 Accept: text/html 는 계속 HTML을 받습니다. 두 표현 모두 다음을 포함합니다: Vary: Accept. 해당 에이전트 가이드 에서 Vox.md에 맞는 용도와 기능 세부 정보를 안내합니다.

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

오류, 캐시, 메서드

JSON 엔드포인트는 GET과 HEAD를 지원합니다. 알 수 없는 API 경로는 HTTP 404와 함께 다음을 반환합니다. application/problem+json, 안정적인 code, 설명, 복구 힌트를 반환합니다. 지원하지 않는 메서드는 HTTP 405와 다음을 반환합니다: Allow: GET, HEAD. 공개 메타데이터 응답은 교차 출처 읽기를 허용하고 5분의 캐시 수명을 알립니다. 자격 증명이나 사용자별 데이터는 관련되지 않습니다.

설치 앱 자동화

캡처, 전사, 로컬 보관함 접근, 노트 쓰기는 설치된 Apple 앱에서 실행됩니다. 문서의 다음을 사용하세요: 단축어 및 URL 스킴 통합 을 기기 소유자 허가하에 사용하세요. 공개 정보 API는 캡처 작업, 녹음, 전사, 비공개 노트, 대상 폴더를 공개하지 않습니다. 문의: Vox.md 지원 로 질문하세요.
