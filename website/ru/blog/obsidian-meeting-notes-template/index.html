Плагин Core Templates: сохраните файл в папке шаблонов и вставьте его командой Templates: Insert template. {{title}} становится именем заметки, а даты используют форматы Moment.js, указанные в фигурных скобках.

2. Добавьте шаблон в Obsidian

Плагин Core Templates. Включите Templates в разделе Настройки → Основные плагины, затем задайте Template folder location, например Templates. Сохраните туда шаблон в виде .md файла. В новой заметке выполните Templates: Insert template из палитры команд и выберите шаблон. Obsidian заменяет {{title}}, {{date}} и {{time}} при вставке шаблона. Формат после двоеточия, например {{date:YYYY-MM-DD}}, использует токены Moment.js. См. справку по плагину Templates и токены формата Moment.js.

Плагин Templater. Установите Templater из раздела «Плагины сообщества» и задайте его параметр Template folder location. Вставьте шаблон командой Templater: Open insert template modal. Чтобы каждая новая заметка в Meetings/ получала этот шаблон, включите Trigger Templater on new file creation, задайте для Template matching mode значение «шаблоны папок» и сопоставьте папку Meetings с файлом. В документации по настройкам Templater описаны шаблоны папок, а раздел «Модуль даты» описывает tp.date.now.

Свойства. Frontmatter между строками --- становится свойствами заметки. Ссылку в свойстве нужно заключать в кавычки, поэтому поле project записано как "[[Project name]]". См. Свойства в справке Obsidian. Чтобы проверить уже имеющийся frontmatter, используйте генератор и проверка свойств.

3. Одна заметка на встречу

Храните встречи в одной папке, например Meetings/, а в имени файла указывайте дату и время начала: Meetings/2026-11-19 1430 Design review.md. Такие имена сортируются по дате, и две встречи в один день никогда не попадут в один файл.

Включите Ссылка на ежедневную заметку в генераторе, чтобы добавить строку Daily note: со ссылкой на заметку этого дня. Ссылка использует формат YYYY-MM-DD; если ваши ежедневные заметки используют другой формат даты, измените его, чтобы он совпадал; генератор шаблона ежедневной заметки показывает, какое имя файла даёт формат. Чтобы перечислить в ежедневной заметке и встречи дня, добавьте на них ссылки; руководство по добавлению записей в ежедневную заметку Obsidian показывает, как Vox.md может добавлять в неё записи.

4. Поручения и последующие действия

Записывайте каждое поручение как задачу Obsidian, - [ ] Send the release notes, а когда она будет выполнена, отметьте её как - [x] — см. Базовый синтаксис форматирования. Ставьте исполнителя первым, чтобы каждая строка читалась как «кто что делает».

Необязательный стиль добавляет срок выполнения в формате плагина сообщества Tasks: 📅 а за ним YYYY-MM-DD. Генератор подставляет дату встречи; замените её на реальный срок. Без плагина Tasks эмодзи и дата остаются обычным текстом, а задача всё равно работает.

Чтобы собрать открытые пункты со всех встреч в одном месте, добавьте в заметку запрос Tasks:

```tasks
not done
path includes Meetings
```

Запрос выводит невыполненные задачи из заметок, путь которых содержит Meetings. Если вы уже пользуетесь Dataview, он умеет строить похожие списки.

5. Заполните заметку по записи

Шаблон даёт вам заголовки. Vox.md может написать саму заметку: он записывает встречу, расшифровывает её на вашем устройстве и сохраняет файл Markdown в хранилище через Маршрут.

  1. Запишите. На Mac Vox.md может записывать одно приложение для звонков и ваш микрофон отдельными дорожками; см. локальная расшифровка встреч на Mac в Obsidian. Для очной встречи записывайте через микрофон iPhone или iPad; см. сохраняйте голосовые заметки iPhone в Obsidian.
  2. Выберите место назначения. В Маршруте укажите хранилище, выберите Новая нота, затем введите путь, например Meetings/{date}-{hour}{minute}.md. {date} записывается как 2026-11-19 и {hour}{minute} как 1430. Это токены Vox.md, а не форматы Moment.js. См. Шаблоны захвата для Obsidian — там больше рецептов путей.
  3. Выберите режим. Установите для Маршрута режим обработки Заметки встречи. Он создаёт раздел ## Notes и, если в расшифровке есть поручения, раздел ## Action Items с чек-листом. Используется Apple Intelligence на совместимом оборудовании с macOS 26 или iOS 26; в остальных случаях структуру строит детерминированный форматировщик.

Режим «Заметки встречи» не заполняет за вас повестку, участников и решения. Если вам нужны эти заголовки над заметками, выберите Простой Markdown в генераторе, снимите флажки «Заметки» и «Поручения в виде задач» и сохраните результат в хранилище. Затем выберите этот файл как шаблон хранилища для Маршрута. Vox.md заполняет в шаблоне свои токены в одинарных фигурных скобках и записывает обработанную расшифровку под ним. Проверьте первую заметку, прежде чем полагаться на эту структуру; документация по Маршрутам описывает места назначения и шаблоны.

Сообщите всем участникам встречи, что вы ведёте запись и расшифровку, и сначала получите их согласие. Правила зависят от места и организации; см. предупредите людей о записи.

6. Вопросы

Что выбрать: Core Templates или Templater?

Core Templates входит в Obsidian и покрывает заголовок, дату и время. Templater — плагин сообщества, который добавляет скрипты, смещения дат и шаблоны папок, поэтому новая заметка в Meetings/ может получать шаблон автоматически. Если вам нужны только поля с этой страницы, Core Templates достаточно.

Почему {{date}} не меняется позже?

Obsidian заменяет переменные шаблона один раз — при вставке шаблона. После этого в заметке хранится обычный текст, например 2026-11-19, и он больше не меняется. Именно это нужно для протокола встречи.

Может ли Vox.md использовать мой шаблон Obsidian?

Частично. Маршрут может использовать файл Markdown из вашего хранилища как шаблон. Vox.md заполняет свои токены в одинарных фигурных скобках, например {date}, а также команды дат Templater tp.date.now и tp.file.creation_date. Он не выполняет другие команды Templater, например tp.file.title, и не раскрывает переменные базового плагина Templates, например {{title}}, поэтому не используйте их в шаблоне Маршрута. Для Маршрута Vox.md используйте вариант «Простой Markdown».

Отправляет ли генератор мой выбор куда-либо?

Нет. Шаблон собирает скрипт на этой странице. Он сохраняет ваш последний выбор в локальном хранилище браузера, чтобы он сохранился до следующего раза, а кнопка «Сбросить» очищает его.
