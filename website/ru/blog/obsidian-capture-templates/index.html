Шаблоны захвата Obsidian для входящих, дневника и задач

Используйте небольшой набор предсказуемых форматов. Согласуйте заметку, заголовок и стиль записи с типом сохраняемой мысли.

Требуется
Настроенное место сохранения Vox.md
Короткий ответ

Начните с трёх простых рецептов: пункт под Inbox, запись дневника со временем и флажок под Tasks. Настройте место сохранения и префикс в пресете Vox.md. Сохраните прежний путь ежедневных заметок и добавляйте каждый маркер оформления только в одном месте.

Ниже — обычные структуры Markdown и настройки пресетов, а не файлы для автоматического импорта пресета Vox.md. При необходимости вставьте структуру в заметку; настройки пути и префикса введите в редакторе места сохранения. Показанные результаты — примеры.

В этом руководстве
  1. Простой файл входящих
  2. Ежедневный журнал с отметками времени
  3. Компактный список задач
  4. Используйте верный синтаксис токенов
  5. Проверьте результат перед повторным использованием пресета

Рецепт 1: простой файл входящих

Используйте цель «существующая запись», например Inbox.md, либо ежедневную «Ролинг нота», если нужен новый файл входящих на каждый день. Выберите размещение «Руководство» под заголовком Inbox второго уровня и вставку в конец этого раздела.

Минимальная структура заметки:

## Inbox

Выберите обработку «Сохранить оригинал». В оформлении записи места сохранения задайте префикс: дефис с пробелом:

-

Короткий захват «Проверить план черновика» может дать:

## Inbox
- Review the draft outline

Введите префикс в настройке, а не в каждой мысли. Если текст уже начинается с маркера списка, проверьте результат, а не добавляйте ещё один вслепую. Для отсутствующих заголовков выберите «Создать заголовки» или «Показать ошибку» по необходимости.

Рецепт 2: ежедневный журнал с отметками времени

Используйте ежедневную «Ролинг нота» и соглашение об именах, уже принятое в хранилище. Для файлов вида Journal/2026-10-26.md, шаблон пути — Journal/{period}.md с ежедневным периодом. Выберите заголовок Journal второго уровня и вставку в конец его раздела.

Оставьте текст без изменений и используйте этот префикс для краткой отметки времени:

- **{hour}:{minute}**

Для захвата в 14:05 пример раздела выглядит так:

## Journal
- **14:05** A short walk helped me settle on the next step.

Токены часов и минут разворачивает форматировщик записей Vox.md. Шаблон всей заметки может задавать окружающие заголовки, а префикс оформляет каждый захват. Разделяйте эти обязанности, чтобы новые записи не вставляли всю структуру ежедневной заметки повторно.

Подробная настройка маршрутов описана в пути ежедневных заметок и размещение под заголовком.

Рецепт 3: компактный список задач

Выберите «существующая запись» или ежедневную «Ролинг нота» с заголовком Tasks второго уровня. Для коротких печатных задач без обработки текста используйте «Сохранить оригинал» и префикс:

- [ ]

Тогда два захвата могут составить:

## Tasks
- [ ] Review the draft outline
- [ ] Send the reading list

Если вместо этого включаете обработку «Список задач», поручите ей маркеры задач. Не задавайте ещё и дублирующий префикс флажка. Обработка печатного и смешанного текста включается отдельно; голосовая обработка и печатный редактор — не взаимозаменяемые настройки.

Задача полезна, только если её текст верен. Для голосовых захватов проверяйте расшифровку, когда ошибка распознавания может изменить указание. руководство по голосу на iPhone объясняет параметры «Добавить в черновик» и «Отправить сразу».

Используйте верный синтаксис токенов

Настройки путей и записей Vox.md используют токены, например {period}, {date}, {hour} и {minute}. Эти примеры — не выражения Obsidian Core Templates или Templater. В настройках системы шаблонов используйте её собственный синтаксис.

Использовать {hour}:{minute} для времени с двоеточиями, показанного здесь. В Vox.md {time} — компактное значение времени, поэтому не подставляйте его в рецепт, предполагая то же представление.

Содержимое захвата — не редактор шаблона. Токен внутри мысли может остаться буквальным текстом; настройте его разворачивание в поддерживаемом оформлении места сохранения. См. справочник токенов и шаблонов со списком доступных полей.

При добавлении метаданных YAML различайте frontmatter всей заметки и поля каждой записи периодической заметки. Свойство всего файла автоматически не становится отдельным свойством каждой записи дневника. Начните без дополнительных метаданных и добавьте их, когда поймёте, как будете их запрашивать.

Проверьте результат перед повторным использованием пресета

  1. Убедитесь, что предпросмотр места сохранения соответствует нужному файлу.
  2. Отправьте короткий печатный захват с выбранным пресетом.
  3. Откройте файл в Obsidian и проверьте заголовок и префикс.
  4. Отправьте второй захват и проверьте порядок, интервалы и повторные маркеры.
  5. Лишь затем добавляйте голос, вложения, необязательную обработку или метаданные.

Эти рецепты могут сосуществовать в одном ежедневном файле под разными заголовками. Для доступной папки тот же пресет может принимать расшифровку, доставленную с Захват с часов через iPhone. Если захват остаётся ожидающим, учитывайте разрешения папки и доступность файлового провайдера.
