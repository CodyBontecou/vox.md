    Текущее местоположение, {location}, и метаданные

    Используйте одно местоположение на момент создания в оформлении записи без автоматического добавления YAML или встроенных полей. Получение геопозиции и вывод метаданных — отдельные, явно включаемые параметры каждого маршрута.

    Обновлено 21 августа 2026 года Разовое получение Без фонового отслеживания Полное руководство по функциям
    01 / Обзор

    Получение местоположения не означает вывод метаданных

    У каждого маршрута два отдельных параметра геолокации. Использовать текущее местоположение определяет, запрашивает ли маршрут местоположение один раз в момент создания. Записывать метаданные местоположения определяет, записывать ли полученный снимок также в frontmatter или встроенные поля.

    Элемент управленияЧто это означаетЧего это не означает
    Системное разрешение геолокацииРазрешает Vox.md запрашивать местоположение во время использования приложения или поддерживаемого интерфейса захвата.Ни для одного маршрута геолокация этим не включается.
    Использовать текущее местоположениеЗапрашивает местоположение один раз для этого маршрута и делает его доступным для {location}.YAML и встроенные метаданные автоматически не записываются.
    Записывать метаданные местоположенияЗаписывает выбранные структурированные поля или проверенный расширенный YAML из полученного снимка местоположения.Он не определяет, будет ли {location} может отобразиться.
    Намерение задаёт маршрут, а не разрешение

    Разрешение «При использовании» лишь открывает доступ на уровне ОС. Vox.md всё равно запрашивает геопозицию только для независимого действия «Текущее местоположение» на панели захвата или маршрута, где вы включили «Использовать текущее местоположение».

    02 / Настройка

    Настройте текущее местоположение для одного маршрута

    1. Откройте маршруты.На iPhone или iPad откройте «Настройки → Маршруты». На Mac откройте настройки и выберите маршруты.
    2. Измените маршрут.Выберите маршрут, которому нужно исходное местоположение. Настройка принадлежит только ему и не влияет на остальные.
    3. Откройте местоположение.Включите Использовать текущее местоположение. Оставьте Записывать метаданные местоположения выключенным для работы только с токеном.
    4. Выберите точность.Используйте «Точный» для исходных координат или «Город» для округления до двух знаков после запятой без названия объекта.
    5. Выберите поведение при недоступности.«Спросить», отправка без местоположения или отмена захвата определяют поведение, когда исходную геопозицию получить нельзя.
    6. Добавить {location} при желании.Поместите токен в шаблон записи, свой префикс или суффикс записи либо шаблон Markdown в хранилище.

    При первом использовании ОС может запросить разрешение геолокации. Если ранее оно отклонено, включите доступ Vox.md к местоположению в системных настройках iOS, iPadOS или macOS.

    03 / Типовые конфигурации

    Выберите минимально нужный вывод геоданных

    Нужный результатИспользовать текущее местоположениеЗаписывать метаданные местоположенияХрамы
    Без геопозиции маршрутаВыкл.Выкл.Не используйте {location}, иначе он останется пустым.
    Только кликабельная ссылкаВкл.Выкл.Добавить {location}. Поля местоположения не записываются.
    Только метаданныеВкл.Вкл.Не сохранять {location}. Записываются только настроенные поля.
    Ссылка и метаданныеВкл.Вкл.Добавить {location} и настройте поля метаданных.

    Отключение «Использовать текущее местоположение» запрещает и разворачивание токена, и вывод метаданных маршрута, даже если прежние настройки оформления метаданных сохранены на будущее.

    04 / Токен шаблона

    Использовать {location} Без изменения метаданных заметки

    Когда включён параметр «Использовать текущее местоположение» и доступен исходный снимок, {location} формирует проверенную ссылку Markdown на Google Maps:

    [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    Токен работает в многоразовых шаблонах записи, своих префиксах и суффиксах и шаблонах Markdown хранилища. Он использует те же координаты «Точный» или «Город», что выбраны для маршрута.

    Пример только с токеном

    Для суффикса вроде:

    Captured from {location}

    Vox.md может создавать:

    Captured from [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    При выключенном параметре «Записывать метаданные местоположения» эта ссылка — единственные геоданные, добавленные маршрутом. Без locations: коллекции и без location.*:: поля записываются.

    Исправление одним нажатием в редакторе

    Если действующий префикс, суффикс или многоразовый шаблон записи использует {location} при выключенном текущем местоположении маршрута редактор объясняет, что токен будет пустым, и предлагает Использовать текущее местоположение для [Route]. Действие включает текущее местоположение для маршрута, намеренно оставляя запись геометаданных выключенной: следующая отправка развернёт токен без изменения метаданных заметки. Файлы шаблонов хранилища читаются лишь при доставке, поэтому их содержимое не вызывает эту подсказку редактора; включите геолокацию вручную, если шаблон использует токен.

    Когда токен пуст

    {location} становится пустой строкой, когда текущее местоположение выключено, недоступно или захват продолжается без него. Учитывайте окружающую пунктуацию и подписи при создании необязательных строк шаблона.

    Независимое действие панели захвата

    «Быстрый захват» Текущее местоположение напрямую вставляет разовую ссылку Google Maps в текущий черновик. Оно не зависит от маршрутов и не меняет параметры «Использовать текущее местоположение» и «Записывать метаданные местоположения».

    05 / Вывод метаданных

    Записывайте структурированные поля только по своему выбору

    Включите «Записывать метаданные местоположения», если заметке нужны машиночитаемые геополя в дополнение или вместо {location} ссылка.

    Frontmatter заметки

    Добавляет каждую геопозицию в коллекцию с именем locations по умолчанию, с привязкой к ID захвата. Остальные существующие поля frontmatter сохраняются.

    Встроенные поля записи

    Записывает в стиле Dataview location.key:: value рядом с сохранённой записью. Коллекция frontmatter не добавляется.

    Структурированные поля

    Выбирайте и переименовывайте координаты, широту, долготу, место, город, регион, страну, ссылки провайдеров, geo URI, точность, время, источник и ID.

    Расширенный YAML

    Использует проверенный шаблон YAML с ограничениями для frontmatter заметки. Расширенный YAML недоступен для встроенных полей записи.

    Пример структурированного frontmatter

    ---
title: Field Notes
locations:
  - id: "aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee"
    coordinates: [45.501235, -73.567890]
    place: "Café & Main"
    appleMapsURL: "https://maps.apple.com/?ll=45.501235%2C-73.567890&q=Caf%C3%A9%20%26%20Main"
    timestamp: "2023-11-14T22:13:20.000Z"
    source: "app"
---

    Периодические заметки могут хранить несколько захватов в коллекции. Защита от повторов встроена в объединение геоданных: повтор с тем же ID захвата не добавит ту же геопозицию дважды. Если ключ коллекции уже содержит несовместимое пользовательское значение, Vox.md остановится вместо перезаписи.

    Пример встроенных полей записи

    location.id:: aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
location.coordinates:: [45.501235, -73.567890]
location.place:: "Café & Main"

Captured text

    Подстановки расширенного YAML

    Расширенные шаблоны могут использовать подстановки, например {{coordinates}}, {{latitude}}, {{longitude}}, {{place}}, {{city}}, {{region}}, {{country}}, {{appleMapsURL}}, {{googleMapsURL}}, {{openStreetMapURL}}, {{geoURI}}, {{accuracy}}, {{timestamp}}, {{source}}, и {{id}}. Перед сохранением просмотрите конфигурацию в настройках маршрута.

    06 / Точность и подписи

    «Точный» и «Город» используют один согласованный снимок

    ТочностьКоординатыПодписиСсылки и поля
    ТочныйСохраняет исходные координаты с шестью отображаемыми знаками после запятой.Может включать название объекта, если оно нужно выбранному полю метаданных.Каждое производное значение использует координаты режима «Точный».
    ГородОкругляет широту и долготу до двух знаков после запятой до сохранения снимка местоположения.Убирает названия объектов; город, регион и страна могут оставаться.Каждый URL провайдера, geo URI, токен и поле используют округлённые координаты.

    Системное обратное геокодирование Apple используется только при включённой записи геометаданных, если выбранному полю или расширенной подстановке нужны место, город, регион или страна. Маршрут только с токеном пропускает геокодирование. При сбое поиска подписи вывод координат остаётся доступен.

    07 / Источники захвата

    Снимок принадлежит источнику захвата

    Текущее местоположение определяется в момент создания захвата. При повторной попытке и восстановлении используется этот сохранённый результат, а не незаметно запрашивается новая геопозиция.

    Источник захватаМомент получения
    Быстрый захват на iPhone и iPadОтправить
    Меню «Поделиться»Отправка в расширении общего доступа
    Намерения текста, ссылок и файлов с прямой постановкой в очередьВызов намерения
    Команды, виджеты, элементы управления и глубокие ссылки, открывающие «Быстрый захват»Отправка в редакторе
    Команда, виджет, элемент управления, немедленная голосовая запись и запись маршрута с клавиатурыОстановка записи
    Обычная доставка захвата Apple WatchОстановка записи на часах; iPhone не подставляет своё местоположение
    Захват на MacОтправка либо остановка записи для немедленной голосовой доставки

    Только запись на часах экспортирует исходное аудио M4A в «Файлы» без вывода Markdown, поэтому не запрашивает местоположение, даже если маршрут обычно его использует.

    08 / Недоступность и восстановление

    Выберите поведение каждого маршрута при недоступной геопозиции

    • Спросить: в интерактивном захвате можно повторить попытку, отменить, отправить один раз без местоположения или выбрать для маршрута постоянную отправку без него.
    • Отправить без местоположения: продолжает доставку без значения токена и вывода метаданных.
    • Отменить захват: останавливает доставку вместо создания заметки без запрошенного исходного местоположения.
    • Сброс сохранённого выбора: сбросьте выбор поведения при недоступной геопозиции в геонастройках маршрута.

    Фоновый запрос «Спросить» сохраняет результат недоступности на момент создания для последующего решения. Повтор ожидающего или неудачного захвата никогда не подставляет более позднее местоположение. Ожидающая работа хранит лишь скорректированный снимок или результат недоступности, нужный для локального восстановления.

    09 / Существующие маршруты

    Обновления сохраняют прежнее поведение метаданных

    Разделение получения и вывода безопасно при миграции:

    • Новые маршруты: «Использовать текущее местоположение» и «Записывать метаданные местоположения» изначально выключены.
    • Маршруты с ранее включённой геолокацией: оба параметра остаются включёнными после обновления, сохраняя прежние метаданные маршрутов.
    • Маршруты с ранее отключённой геолокацией: оба параметра остаются выключенными; обновление не добавляет новый вывод метаданных.

    Чтобы перевести существующий маршрут с записью метаданных на использование только токена, оставьте «Использовать текущее местоположение» включённым и отключите «Записывать метаданные местоположения». Существующий Markdown не переписывается и не удаляется.

    10 / Конфиденциальность и хранение

    Один явный снимок, никакого фонового отслеживания

    • Vox.md не отслеживает местоположение непрерывно или в фоне.
    • Местоположение не отправляется на серверы Vox.md, в системы аналитики, рекламы или сторонние сервисы ИИ.
    • Токены и URL провайдеров формируются локально. Apple Maps, Google Maps или OpenStreetMap получает координаты только при открытии соответствующей ссылки.
    • Системное обратное геокодирование Apple может делать сетевой запрос только тогда, когда выбранным метаданным нужно название места. Геолокация только через токен пропускает этот поиск.
    • После доставки восстанавливаемые запросы превращаются в квитанции без содержимого, а история завершённых захватов не хранит координаты, подписи, URL провайдеров или шаблоны геопозиции.
    • Геометаданные или ссылка токена в Markdown становятся частью выбранного файла. Провайдер синхронизации может обрабатывать его на своих условиях.
    Разрешение может оставаться включённым без раскрытия геопозиции маршрутами

    Можно оставить системное разрешение доступным для независимого действия текущего местоположения и при этом отключить «Использовать текущее местоположение» у всех маршрутов.

    См. политика конфиденциальности с полными сведениями об обработке и хранении данных.

    11 / Устранение неполадок

    Исправьте типичные проблемы геолокации и шаблонов

    {location} остаётся пустым

    Убедитесь, что действующие шаблон записи, префикс, суффикс или шаблон хранилища используют точный токен в нижнем регистре {location}. Затем включите «Использовать текущее местоположение» для маршрута доставки. Исправление одним нажатием в редакторе делает это для обнаруженного встроенного оформления записи без включения метаданных; файлы шаблонов в хранилище требуют ручной настройки маршрута. Если разрешение отклонено или геопозиция недоступна, проверьте поведение маршрута при недоступности и системные настройки геолокации.

    Ссылка работает, но метаданных нет

    Это ожидаемо при настройке только токена. Откройте геонастройки маршрута и включите «Записывать метаданные местоположения», затем выберите frontmatter заметки или встроенные поля записи и нужные поля.

    Метаданные есть, но ссылки в записи нет

    Вывод метаданных не вставляет ссылку автоматически. Добавьте {location} в действующее оформление записи или шаблон Markdown хранилища.

    Отсутствует место или город

    Убедитесь, что поле подписи выбрано. Обратное геокодирование Apple может дать сбой при доступных координатах. Точность «Город» намеренно удаляет названия объектов.

    При доставке frontmatter обнаружен конфликт

    Настроенный ключ коллекции, locations по умолчанию, должна быть совместимым списком местоположений. Переименуйте коллекцию в настройках маршрута или исправьте существующий пользовательский frontmatter. Vox.md не перезаписывает несовместимое значение.

    При повторной попытке местоположение устарело или недоступно

    Так задумано. Запрос сохраняет результат на момент создания, чтобы поздний повтор не мог незаметно указать другое место захвата. Для нового снимка создайте новый захват.

    Доступ к геопозиции разрешён, но маршрут её не запрашивает

    Системное разрешение лишь даёт возможность доступа. Отредактируйте маршрут и включите «Использовать текущее местоположение». Одно разрешение никогда не включает геолокацию для маршрута.
