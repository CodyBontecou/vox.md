Vox.md について

すでに持っているノートへキャプチャ

Vox.md は、Obsidian の保管庫や Markdown フォルダを使う人のためのローカルキャプチャアプリです。開発者は、 Cody Bontecou にて Isolated Tech。考え、リンク、写真、ファイル、スキャン、スケッチ、音声メモをキャプチャし、ノートを探し回らずに指定した保存先へ送れます。

Vox.md は iPhone、iPad、Mac、Apple Watch で使えます。機能と最低システム要件は、次に記載しています。 全機能ガイド。キャプチャプリセットで、フォルダ、ノート、テンプレート、挿入位置を定義します。アプリは標準の Markdown と添付ファイルを書き込むため、選んだファイルはほかのエディタでも活用できます。

非公開・ローカルの手順のために

音声の文字起こしは、対応する Apple Speech バックエンド、または任意でダウンロードした Whisper や Parakeet のモデルを使い、Apple デバイス上で実行します。Vox.md のアカウントや Obsidian のプラグインは不要です。キャプチャ内容は選択したフォルダに書き込み、ご自身のストレージプロバイダがそのフォルダを同期する場合があります。次をお読みください。 プライバシーポリシー モデル、権限、任意の位置情報、外部サービスの詳細を確認してください。

Vox.md を試す・サポートを受ける

無料ダウンロードには15分の文字起こしと10回の成功したキャプチャ配信が含まれます。無制限利用は永久ライセンスの購入で使えます。現在の地域別価格は、Apple が App Store に表示します。次を入手してください。 App Store の Vox.mdについては、次をお読みください。 設定ガイド、または 開発者に問い合わせる.

Vox.md はオープンソースです。実装とライセンスは、次で確認できます。 GitHub リポジトリ。この公開ウェブサイトは製品情報とドキュメントを提供します。キャプチャの操作は、インストール済みアプリの画面、ショートカット、文書化された URL スキームを通じてローカルで実行します。
