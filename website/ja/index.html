L041 · how.md

##3つの停留所。 私たちの停留所はありません。

一瞬の考えを残すのに、保管庫を開き、ノートを探し、書き込む場所を選ぶのは手間がかかりすぎます。ルートを一度設定したら、あとはキャプチャするだけ。

  1. 01あなたのフォルダ

    保管庫を接続

    Obsidian の保管庫、または Files 内の書き込み可能なフォルダを選択します。Vox.md は、すでに所有している Markdown ファイルをそのまま扱います。

  2. 02あなたのポケット

    何でもキャプチャ

    入力、リンクの貼り付け、メディアやファイルの追加、書類のスキャン、スケッチ、非公開の音声メモの録音。音声はその場で文字起こしします。

  3. 03あなたのファイル

    ルートがファイルに振り分ける

    ノートを作成、ローリングノートを更新、既存のノートを指定。先頭、末尾、見出しの下へ配置できます。

停留所2.5：誰かのクラウド。省略しました。同期は、選択したフォルダがすでに使っている仕組みが、そのプロバイダの規約に従って行います。

##ルートの設定は一度だけ。 あとは話すだけ。

ルートは、キャプチャの処理方法と書式に加え、保管庫、対象ノート、挿入位置、添付ファイル、再試行の動作、任意の1回限りの現在の位置を記憶します。

ルートの例
ルートファイルファイル内の位置出力書式
デイリーノート · タスクJournal/{date}.md## Tasks の下端- {text}
会議メモMeetings/{date}.md## Notes の下### {time} · {title}
読むものリストInbox/Reading.mdファイルの先頭### {time}
アイデアProjects/Ideas.mdファイルの末尾> {text}
新しいノートInbox/{timestamp}.md新しいファイルYAML フロントマター＋本文
既存のノート Projects/Ideas.md
保管庫にすでにある文書に、そのまま追加できます。
ローリングノート Journal/{period}.md
日、週、月、四半期、年単位のノート。 デイリーノートと見出しへの挿入を設定。
新規メモ Inbox/{timestamp}.md
キャプチャのたびに、まっさらなファイルを作ります。
正確な挿入位置 Top · Bottom · Heading
どのレベルの見出しの下にも挿入。見出しがなければ作成できます。
入り口 寺院 Markdown · YAML · Tokens
繰り返すキャプチャの書式を、整え直さず一定に保ちます。

メタデータなしで発生時点の地図リンクを1つ出力するか、フロントマターとインラインフィールドを有効にできます。 ガイドを読む。

L214 · faq.md

##よくある 質問

Vox.md は選択した Markdown フォルダに直接書き込みます。Obsidian とよく合いますが、必須ではありません。項目を選ぶと回答が開きます。

Vox.md は Obsidian で使えますか？

はい。ルートを作成し、Obsidian の保管庫を保存先に選択してください。Vox.md は標準の Markdown、ウィキリンク、添付ファイルの埋め込みを保管庫に直接書き込みます。Obsidian のプラグインは不要です。 Vox.md と Obsidian の標準キャプチャを比較。 デイリーノートへのキャプチャ手順を設定。

何をキャプチャできますか？

入力画面は、テキスト、ウェブリンク、写真、ファイル、書類のスキャン、スケッチ、音声を受け付けます。スキャンには抽出テキストを含められ、音声はローカルで文字起こしできます。

キャプチャはどこに送れますか？

各ルートの保存先は、新しいノートの作成、日単位などのローリングノートの更新、既存の Markdown ファイルへの書き込みに対応しています。ルート自体を変えずに、1回のキャプチャだけ別のノートを一時指定することもできます。

Vox.md は見出しの下に挿入できますか？

はい。ルートは先頭や末尾への追加、レベル1から6までの見出しの下への挿入に対応しています。見出しがない場合、配信を止めるか自動作成するかを選べます。また、新しい項目を見出しの直下に入れるか、その見出しのセクション末尾に入れるかも指定できます。

Obsidian なしでも使えますか？

はい。ルートには Files が公開する書き込み可能なフォルダを使えます。出力は通常の添付ファイルを伴うプレーンな Markdown なので、ノートが Vox.md に縛られることはありません。

Vox.md はノートや音声をアップロードしますか？

キャプチャ内容を Vox.md のサーバーに送信することはありません。ドラフトと音声処理はデバイス内にとどまり、完成したファイルは選択したフォルダに書き込みます。そのフォルダが同期プロバイダに属する場合、プロバイダが自身の規約に従って扱います。 オフライン設定の要件を確認。

メタデータを追加せず、テンプレートで位置情報を使えますか？

はい。そのルートの「現在地を使用」をオンにし、「位置情報メタデータを書き込む」はオフのまま、次を追加してください。 {location} をエントリーの書式に追加します。Vox.md は、フロントマターやインラインの位置情報フィールドを追加せず、1回限りの取得による地図リンクを挿入します。 位置情報の完全ガイドを読む。

アプリの外からもキャプチャできますか？

はい。Vox.md にはウィジェット、ショートカットアクション、共有拡張機能、音声キーボードがあります。これらの入口は、同じローカルキャプチャシステムにつながっています。

Vox.md の料金は？

Vox.md は、15分の文字起こしと10回の成功したキャプチャ配信を無料で提供します。文字起こしとキャプチャの無制限利用は1回限りの永久ライセンス購入で利用でき、サブスクリプションや広告はありません。Markdown に送る音声の文字起こしは、文字起こし枠を使い、キャプチャ枠を重ねて消費しません。地域の現在の価格は App Store に表示されます。
