プライバシーポリシー

施行日：2026年2月9日 · 最終更新日：2026年10月26日

要するに

Vox.md は、キャプチャのドラフト、添付ファイル、文字起こし、ノートへのルートをデバイス内に保持します。完成したファイルは選択した保存先にのみ送り、キャプチャ内容を Vox.md のサーバーに送信することはありません。製品版は、後述する大まかな自社向け導入分析を送信します。

概要

本プライバシーポリシーは、iOS および macOS アプリケーションとその拡張機能の利用時に、Vox.md（以下「当方」「本アプリ」）が情報をどう扱うかを説明します。音声、文字起こし、キー入力、キャプチャのドラフト、添付ファイル、書き出すファイルの内容、利用者が入力したテキストはローカルで処理します。ファイルは選択した場所にのみ書き込まれます。選択したストレージプロバイダは、自身の規約に従ってそれらを同期する場合があります。

収集しない情報

Vox.md は、以下の情報を開発者、分析、広告、追跡のために収集しません。後述する大まかな導入メタデータは、自動的にデバイス外へ送信される場合があります。キャプチャ内容がデバイス外へ出るのは、後述する同期フォルダへの書き込みや地図プロバイダのリンクを開くなど、利用者が選んだ機能を通じてだけです。

  • 録音や音声データ
  • 文字起こしテキストや文字起こし履歴
  • キー入力、入力したテキスト、キーボードの入力内容
  • 氏名、メールアドレス、電話番号などの個人情報
  • 開発者、分析、広告、追跡のための位置情報
  • ローカルキャプチャ用に明示的に選択した写真、スキャン、スケッチ、音声、ファイル
  • ファイル名、フォルダのパス、テンプレートのテキスト、書き出したノートの内容、モデルファイルのパス
  • 広告識別子、生の IP アドレスの保存、サードパーティの追跡識別子

プライバシーに配慮した導入分析

製品版では、導入手順、設定のつまずき、購入や復元の結果を把握するため、少数の自社向けイベントを送信します。開発版での設定テストには明示的な有効化が必要です。これらのイベントは意図的に大まかにしており、広告やアプリ横断の追跡には使いません。

導入分析には、次が含まれる場合があります。

  • ファネルの進行状況の集計にのみ使う匿名の Vox.md インストール ID
  • 導入開始、マイク許可完了、モデル設定完了、購入画面の表示、購入や復元の結果、導入完了などのイベント名
  • アプリのバージョン、ビルド番号、プラットフォーム、実験のバリアント
  • マイクの許可状況、モデルエンジンとサイズ区分、ファイル書き出し形式・モード、無料時間と成功したキャプチャの使用量区分、購入画面の文脈など、大まかな設定状態

これらの分析に、音声、文字起こし、音声入力のテキスト、キー入力、ファイル・フォルダのパス、テンプレートのテキスト、モデルのファイルパス、氏名、メールアドレス、生の日付、生の IP アドレス、デバイス名が含まれることはありません。

デバイス上の処理

音声からテキストへの文字起こしは、すべてデバイス上で完結します。対応する iOS 26 デバイスでは、「自動」が Apple のシステム管理 Speech フレームワークを使います。ローカルの Whisper や Parakeet のモデルを任意でダウンロードすることもできます。マイクが取得した音声は、選択したデバイス上のバックエンドで処理し、ネットワーク接続を通じて送信することは一切ありません。

ルートでキャプチャテキストの処理を明示的に有効にすると、対象となる入力テキスト、デバイス上の OCR、音声の文字起こしを、Apple Intelligence でローカルに整形・整文できます。デバイス上のインテリジェンスが利用できない場合、定型の整形または元テキストに切り替えます。Vox.md はキャプチャしたテキストを、自社サーバーやサードパーティの AI API に送信しません。

文字起こし結果、キャプチャのドラフト、再試行リクエストは、アプリのサンドボックス化されたコンテナと共有 App Group 内にローカル保存します。アクセスできるのは、アプリ、キーボード、ウィジェット、共有拡張機能など、署名された Vox.md の構成要素だけです。Vox.md のサービスやサーバーからアクセスすることはできません。

キーボードの拡張機能

Vox.md には、デバイス上のすべてのアプリで音声文字入力を可能にするカスタムキーボード拡張機能が含まれます。Apple は、キーボード拡張機能について次の開示を求めています。

  • 現在のキーボードの手順には、「フルアクセスを許可」が必要です。 キーボードが共有 App Group の状態を使い、メインの Vox.md アプリと録音を連携できるようにします。
  • Vox.md は、キー入力、音声入力のテキスト、文字起こし、マイク音声のアップロード、販売、分析にフルアクセスを使いません。キーボードが、これらの内容を Vox.md やサードパーティのサーバーに送信することはありません。
  • キーボード拡張機能は、デバイス上の共有 App Group コンテナを通じて、署名された Vox.md アプリの構成要素と通信します。

マイクの使用

Vox.md は、音声文字起こし用の音声を取得するため、マイクへのアクセスを求めます。マイクの音声は、

  • Apple Speech、または任意でダウンロードした Whisper/Parakeet モデルでローカル処理
  • ローカル文字起こしにファイルが必要な場合にのみ、一時的に書き込まれます
  • サーバー、API、サードパーティサービスへの送信は一切なし
  • ルートで音声を保持するか、キャプチャのドラフトに音声録音を挿入するよう明示的に設定しない限り、文字起こし後に削除されます

位置情報の利用

Vox.md には、明示的に使う2つの位置情報機能があります。独立した「現在の位置」キャプチャバーアクションは、位置を1回取得し、ローカルのドラフトに Google Maps リンクを挿入します。別の機能であるルートの「現在の位置」は既定でオフで、iOS/iPadOS、共有シート、ショートカットとインテント、音声やキーボードによるルート録音、ウィジェットとコントロール、Markdown に送る Apple Watch キャプチャ、Mac で、ルートごとに有効化できます。ルートは、この1回の取得結果を次に利用できます。 {location} のエントリーテンプレート用リンクを、追加のメタデータを書き込まずに使えます。「位置情報メタデータを書き込む」は別途有効化します。Watch の「録音のみ」は引き続き Files への未処理音声の書き出しであり、Markdown に位置を出力せず、位置情報も取得しません。

有効なルートは、キャプチャ元に応じて、送信時、呼び出し時、録音停止時に、発生時点の位置を1回取得します。既定は「正確な」です。「都市」の精度では、結果を保持する前に緯度と経度を小数点以下2桁に丸め、施設名を削除します。すべての派生フィールド、テンプレートリンク、プロバイダリンクは、同じプライバシー処理済みの座標を使います。Vox.md は、継続的な位置監視、バックグラウンドでの位置追跡、分析やログへの位置情報の記録、Vox.md のサーバーへの位置情報の送信を行いません。

有効なメタデータに場所、市区町村、地域、国が必要な場合、Vox.md は Apple のシステム逆ジオコーダを使います。トークンだけで現在の位置を使う場合、この照会は行いません。このサービスは無料で API キーも不要ですが、Apple の規約に基づき、Apple へのネットワークリクエストが発生する場合があります。逆ジオコーディングに失敗してもキャプチャは妨げられず、座標のみのメタデータを使えます。Vox.md は、Apple Maps、Google Maps、OpenStreetMap のリンクを、それらのプロバイダに接続せず整形できます。リンクを開いたときにだけ、その中の正確または丸め済みの座標が該当プロバイダに渡ります。

位置を取得できない場合、操作可能な画面では、再試行、キャンセル、今回だけ位置なしで送信、またはそのルートで「常に位置なしで送信」の保存を選べます。保存した動作はルート設定でリセットできます。無人実行の「確認」リクエストでは、発生時に位置を取得できなかった結果を保持して後で判断できるようにし、再試行時に新しい位置を取得しません。保留中や失敗したリクエストでは、ローカルでの復元に必要な、すでにプライバシー処理済みの結果を保持する場合があります。Markdown に書き込んだ座標は、選択したノートの一部になります。選択したファイル同期プロバイダが、そのファイルを自身の規約に従って処理する場合があります。

設定例とキャプチャ元ごとの動作は、次を参照してください。 現在の位置、 {location}、およびメタデータ.

音声のモデル

Vox.md には音声モデルの重みを同梱していません。Apple の対応言語アセットは iOS が管理します。任意の Whisper、Parakeet、音声の無音検出モデルは、利用者が選んだ後にだけダウンロードを開始し、デバイス内に保存します。モデルの準備やダウンロードにアカウントや個人情報は不要です。

サードパーティのサービス

Vox.md は、サードパーティの分析 SDK、広告ネットワーク、クラッシュ報告 SDK、アプリ横断の追跡サービスと連携しません。利用者が開始した Whisper と Parakeet のモデルダウンロードは、直接または FluidAudio 経由で、Hugging Face がホストするモデル配布基盤に接続します。モデルのリクエストに、キャプチャのドラフト、入力テキスト、音声、文字起こし、添付ファイル、ファイルのパス、位置情報が含まれることはありません。ただし、プロバイダは自身の規約に基づき、通常の HTTPS 接続データと要求されたモデル識別子を受け取る場合があります。

キャプチャエディタは、名言をまとめて次から取得します。 ZenQuotes API から取得し、デバイス上のキャッシュから順に表示します。このリクエストに、キャプチャのドラフト、入力テキスト、音声、添付ファイル、ファイルのパス、位置情報、インストール識別子、分析データが含まれることはありません。ほかの HTTPS サービスと同様、ZenQuotes は自身の規約に従って IP アドレスやユーザーエージェントなどの技術的な接続データを受け取る場合があります。自社向けの導入イベントは Vox.md の Cloudflare Worker に直接送信し、上記の厳格な許可リストに従って、その D1 データベースに保存します。

データの保存と削除

文字起こし履歴、キャプチャのドラフト、取り込み準備中の添付ファイル、ダウンロード済みモデル、テンプレート、設定、無料利用の記録を含むキャプチャ内容とアプリのローカルデータは、デバイス内、または明示的に選んだファイル保存先に保存されます。内容を含まない成功キャプチャの利用記録には、最大10件の成功したリクエストの件数とランダムな識別子だけを記録します。ローカルアプリデータが残っている間、再試行で重複して利用枠を消費しないためです。キャプチャしたテキスト、ファイル名、保存先、添付ファイルのメタデータは含まず、システムのキーチェーンには保存せず、Vox.md に送信することもありません。

このポリシー変更より前のバージョンでは、機能を持たず内容も含まない無料利用枠の項目が、システムのキーチェーンに残っている場合があります。現行版はその項目にアクセスしません。キーチェーンアクセスで削除しても、キャプチャ、文字起こし、購入には影響しません。

ローカルの最近のキャプチャ一覧には、結果、キャプチャ元、ルートの識別子と表示名、保存先の識別子と表示名、ノートの相対パス、添付数、タイムスタンプ、大まかな失敗分類という配信メタデータだけを含めます。ノートのテキスト、リンク、座標、位置ラベルやテンプレート、ブックマーク、絶対パス、添付ファイル名を複製することはありません。保留中や失敗したキャプチャには、ローカル復元に必要な内容だけを保持します。これには、すでにプライバシー処理済みの位置のスナップショットや、永続化した取得不能の結果が含まれる場合があります。配信成功後、復元可能なキャプチャリクエストは、識別子とタイムスタンプだけの削除済み記録に直ちに置き換えます。完了した Watch キューの項目も同様に内容を除去し、更新時には古い完了リクエストも無害化します。

ローカルに保存した利用者のコンテンツや設定は、次の方法で削除できます。

  • アプリ内の履歴画面から、個別の文字起こしや最近のキャプチャのメタデータを削除
  • 設定からダウンロード済みモデルを削除
  • Vox.md とそのローカルアプリデータを削除します。無料利用枠もリセットされます。対象となる StoreKit 購入は引き続き Apple から復元できます。

子どものプライバシー

Vox.md は、13歳未満の子どもを含め、いかなる人からも、個人情報であると認識しながら収集することはありません。上記のプライバシーに配慮した導入分析は、子どもの特定や連絡を目的とせず、音声、文字起こし、キー入力、利用者が入力した内容を一切含みません。

このポリシーの変更

当方は、本プライバシーポリシーを随時更新する場合があります。変更は、「最終更新日」を改めてこのページに反映します。
