スピーチ時間計算ツール: 語数から分へ、そして実際のペース

原稿を貼り付けて話す時間を調べたり、3分、5分、10分に必要な語数を求めたり、リハーサルの文字起こしから実際のペースを測ったりできます。すべてこのページ内で実行され、アップロードは一切ありません。

作成者
Cody Bontecou
更新日
2026年11月25日
必要条件
最新のブラウザならどれでも使えます（iPhone の Safari を含む）。任意: 原稿用の Obsidian と、リハーサルをデバイス上で文字起こしするための iPhone、iPad、Mac 版 Vox.md。
短く答えると

1分あたり130〜150語という計画用のペースでは、1,000語で約7〜8分（6:40〜7:42）、5分のスピーチには約650〜750語が必要です。この2つのペースは本ページのプリセットであり、実測の平均ではありません。一度リハーサルをして、ご自身のペースを測れば実際の数値がわかります。

この 計算ツール には3つのモードがあります。原稿から時間、時間から語数、そしてリハーサルの文字起こしから実際のペースを測るモードです。語数カウンターは Markdown を聞き手に聞こえるとおりに読むため、見出し、箇条書き、リンクのアドレス、 [[wikilinks]] や、Obsidian から貼り付けたフロントマターは語数に含まれません。処理はすべてこのページ内で行われます。テキストはアップロードされず、ページはネットワークリクエストも行いません。

2. かんたん換算表

3. 一般的な話す速さと出典

唯一の正しい話す速さはなく、出典のない数値は推測にすぎません。以下は、出典そのものから確認できた速さです。いずれも特定の状況を表すもので、あなたの話の目標値ではありません。

設定項目出典に記載の速さソース
指定された話題での初対面同士の電話会話（英語の Switchboard 会話2,438件）: 両話者の全語数を、経過時間の合計で割った値平均196 WPM、会話ごとに111〜291 WPMYuan、Liberman、Cieri (2006)、Interspeech
同じ会話から、無音と非音声のノイズを除いたもの平均236 WPM、会話ごとに158〜312 WPMYuan、Liberman、Cieri (2006)
成人の音読、77件の研究・参加者5,965人のメタ分析平均183 WPM（95%信頼区間 177〜189）Brysbaert (2019)、Journal of Memory and Language
成人の英語の黙読、190件の研究・参加者18,573人のメタ分析平均でノンフィクション238 WPM、フィクション260 WPMBrysbaert（2019）

これらの数値からわかることと、わからないこと:

  • 本ページのプリセットより高い値です。 130 WPM と150 WPM のプリセットは、間やスライド切り替えのある話を想定した計画用の目安で、調査結果ではなく当社の経験則です。原稿を止まらずに音読する場合は、音読の数値に近くなると考えてください。
  • 数え方によって数値が変わります。 Yuan らは、同じ会話について、経過時間全体で割ると196 WPM、無音を除くと236 WPM になると報告しています。録音の長さには間が含まれるため、モード3で測るペースにも間が含まれます。
  • ペースは言語、話者、状況によって異なります。 Yuan らは、話す速さが発話の長さ、話題、話者同士が知り合いかどうか、話者の年齢によって変わると報告しています。Brysbaert は、子ども、高齢者、第二言語として英語を読む人は読む速さが低くなること、また他の言語の速さは、英語と同じ内容を伝えるのにその言語が何語必要かから予測できることを報告しています。語数は言語間で比較できません。
  • 音読とスピーチは別物です。 音読の数値の元になった研究は朗読の研究であり、プレゼンテーションの研究ではありません。プレゼンテーションの目標ペースを定めた一次資料は見つからなかったため、ここでは示していません。

4. 実際の話が「語数 ÷ WPM」より長くなる理由

語数をペースで割ると、話している時間が出ます。実際の話には、話さない時間もあります。段落間の息継ぎ、スライドが切り替わる間、笑いや聴衆からの質問、水を一口飲む時間などです。計算ツールでは、これらを上乗せできます。

  • 段落ごとの間。 貼り付けた原稿の、空行で区切られたブロックごとに加える秒数です。話す原稿では、2〜3秒の間から始めるのが妥当です。
  • スライドとスライドごとの間。 スライドを切り替えるたびに加える秒数で、聴衆が新しいスライドを見る時間にあたります。3〜5秒を目安にし、読んでもらいたいスライドではもっと長くします。
  • 間のために確保する時間（時間から語数）。 語数を計算する前に、目標の長さから差し引く秒数（1つの数値）です。

これらは当社の計画用の経験則であり、統計ではありません。適切な値は話し方によって変わります。たとえば、1,000語・12段落・10スライドの原稿を130 WPM で、段落ごとに3秒、スライドごとに4秒の間を取ると、話す時間は7:42、段落の間が36秒、スライドの間が40秒（間の合計は1:16）で、合計は8:58です。確実な確認方法は、下記のとおり一度リハーサルして時間を計ることです。

5. リハーサルから自分のペースを測る

話の長さを見積もる確実な方法は、一度リハーサルをして文字起こしし、測定することです。一般的な130 WPM をそのまま信じる必要はありません。ご自身のペースはどのプリセットよりもかなり速くも遅くもなり得ますし、内容への習熟度によっても変わります。

  1. リハーサルを録音する。 本番と同じように、間も含めて話してください。iPhone または iPad では、Apple サポートの ボイスメモで録音する に手順があります。Mac の場合は次を参照してください: Mac のボイスメモで録音を作成する。録音の長さを控えておいてください。この長さはレコーダーから得られます。
  2. 文字起こしを用意する。 ボイスメモは、利用できる場合に文字起こしを表示できます。Apple サポートの次の記事を参照してください: iPhone で文字起こしを表示する、および当社のガイド iPhone でボイスメモを文字起こしする方法。次を使って、デバイス上で録音を文字起こしすることもできます: Vox.md。字幕付きの Zoom や YouTube の録画には、次が使えます: SRT・VTT テキスト変換ツール は字幕ファイルをテキストに変換します。
  3. 貼り付けて測定。 文字起こしをモード3に貼り付け、録音の長さを入力します。文字起こしの語数を分で割って測定した WPM を表示し、プリセットとの比較と、ご自身のペースでの原稿の話す時間を算出します。

数値を信用する前に、文字起こしを実際に話した内容と照らし合わせてください。音声認識は間違えることがあり、聞き逃しや余計な語があれば語数がずれます。話全体をリハーサルし、録音の冒頭と末尾に無音が多ければ削り、原稿を直したらもう一度測定してください。

間はすでに録音に含まれているため、モード3の原稿の時間には加算しません。リハーサルにスライドや聴衆がなかった場合は、本番に備えて少し余裕を見ておきましょう。

6. Vox.md でリハーサルと文字起こし

一度、声に出してリハーサルしましょう。Vox.md は iPhone、iPad、Mac 上で録音を文字起こしし、Markdown を Vault に保存するので、ここで実際のペースを測れます。講演、動画の原稿、ポッドキャストの冒頭などにお使いください。文字起こしは Apple Speech、Whisper、Parakeet を使ってデバイス上で実行されます。次を参照してください: モデルのリファレンス で、それぞれの必要条件を確認できます。Markdown を Obsidian の Vault に原稿と並べて保存しておけば、書き直しながら各稿を比較できます。

録音を取り込む手順は次にあります: iPhone でボイスメモを文字起こしする と Mac で音声ファイルを文字起こしする、および インタビューをプライベートに文字起こしする では話者ラベルを扱っています。ディクテーションだけが必要な場合は次を参照してください: iPhone での音声からテキストへの変換 と Mac の音声入力。Vox.md が提供するのは文字起こしであり、長さではありません。長さはレコーダーから得られ、語数の計算はここで行います。

一度、声に出してリハーサルしましょう。

Vox.md は iPhone、iPad、Mac 上で録音を文字起こしし、Markdown を Vault に保存します。ここで実際のペースを測れます。無料枠は文字起こし15分と、Capture の配信成功10回です。無制限での利用は、サブスクリプション不要の買い切り（生涯）アンロックです。

7. よくある質問

3分、5分、10分のスピーチは何語ですか？

130〜150 WPM では、3分のスピーチは約390〜450語、5分は約650〜750語、10分は約1,300〜1,500語です。遅めと速めのプリセット（100〜170 WPM）全体では、5分は500〜850語です。参考までに、 Brysbaert（2019） が音読で見いだした値だと、5分で約915語になります。間を加え、リハーサルをして、ご自身の数値を調べてください。

1,000語のスピーチは何分ですか？

間を加える前で、130 WPM なら7:42、150 WPM なら6:40です。100 WPM なら10:00、170 WPM なら5:53です。Brysbaert (2019) の音読の平均183 WPM なら5:28です。段落が12、スライドが10なら、次の間を加えてください: 上のセクション.

プレゼンテーションに適した話す速さは？

プレゼンテーションの目標ペースを定めた一次資料は見つかりませんでした。出典のある数値は、他の状況を表しています。 Yuan、Liberman、Cieri (2006) は電話会話の経過時間全体で196 WPM と報告し、Brysbaert (2019) は音読で183 WPM と報告しています。130〜150 WPM のようにゆっくりした計画用のペースなら間やスライド切り替えの余裕を持てますが、確かな答えは、次のようにリハーサルから得たご自身のペースです: ペースを測る.

音読は黙読より時間がかかりますか？

はい、平均では。 Brysbaert（2019） は、英語のノンフィクションについて、音読は183 WPM、黙読は238 WPM（フィクションは260 WPM）と推定しています。この平均値では、同じノンフィクションの文章は音読のほうが約30%長くかかります（238 ÷ 183 ≈ 1.3）。読み手には個人差があるため、ご自身で測定してください。

計算ツールは原稿をアップロードしますか？

いいえ。語数はお使いのデバイス上で、このページ内のスクリプトが数えており、ページはネットワークリクエストを行いません。テキストは保存されず、ページを閉じるか再読み込みすると消去されます。
