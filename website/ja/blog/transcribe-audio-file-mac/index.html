Mac · 音声ファイル · ローカル文字起こし

Mac で音声ファイルをローカルで文字起こしして Markdown にする

まず無料の内蔵機能を紹介し、そのあと、手元のファイルから Obsidian や任意のフォルダ内の Markdown ノートまでをローカルで完結させる流れを説明します。

作成者
Cody Bontecou
更新日
2026年11月22日
必要条件
Vox.md:macOS 14 以降 · ダウンロード済みの音声認識モデル。Apple 内蔵の文字起こし:お使いの Mac と言語については Apple サポートのページをご覧ください。
短く答えると

Apple のボイスメモとメモは、Mac で音声を無料で文字起こしできます。多くの方にはそれで十分です。既存の音声または動画ファイルを Markdown ノートにするには、Mac 版 Vox.md を開き、 オーディオを読み込む… をメニューバーから選び(または「キャプチャ」のワークスペースでファイルを読み込み)、ローカルの Whisper または Parakeet モデルで文字起こしし、テキストを確認してから、ルートのノートに送信します。

以下の Apple に関する詳細は、Apple サポートのページに基づいています Mac のボイスメモで文字起こしを表示する と Mac のメモで音声を録音して文字起こしする(2026年11月22日に確認)。Apple のページは変更されることがあるため、お使いの Mac で確認してください。Vox.md の手順は次に沿っています: Mac のドキュメント.

Mac にすでにある無料の方法

ボイスメモ

Apple のボイスメモのページには、次のボタンをクリックできると書かれています: 文字起こし ボタンを押すとテキストをライブで確認できます。録音済みの項目を選んで同じボタンをクリックすることもできます。録音リストでは、タイトルや文字起こしのテキストを検索できます。文字起こしのテキストは、選択して Control キーを押しながらクリックし、次を選ぶとコピーできます: コピー。Apple によると、macOS 14 以前で作成された録音、または文字起こしに対応していないデバイスで作成された録音を開くと、ボイスメモが自動的に文字起こしを行います。また、音声の文字起こしはすべての国や地域で利用できるわけではありません。

メモ

Apple のメモのページには、ノート内で音声を録音する方法が説明されています。「添付ファイル」ボタンをクリックし、 オーディオを録音を選んで録音し、「文字起こし」ボタンをクリックして文字起こしを表示します。音声の文字起こしは、そのページに Apple が挙げているデバイス言語について、M1 以降の Mac で利用できると書かれています。「文字起こし」ボタンが表示されない場合、Apple によると、お使いの Mac が最小要件を満たしていないか、対応言語を検出できていません。

制限事項

テキストは、コピーして取り出すまでそれらのアプリ内にとどまります。メモでは、音声録音を削除すると文字起こしも削除されると Apple は説明しています。どちらのアプリでどのファイル形式を読み込めるかは Apple のページからは確認できないため、お手元の録音で確かめてください。このガイドではそれについて何も断定しません。

最後の手段として、音声を再生しながらテキストエディタに音声入力する人もいます。これは回避策であり、ファイルの文字起こしではありません。詳しくは Mac の音声入力 をご覧ください。音声入力そのものについての説明です。

どの方法が合っているか

この表には、Apple のページまたは Vox.md のドキュメントに記載されている内容だけを載せています。「記載なし」は、参照元に記載がないという意味です。精度や速度についての主張ではありません。

テキストがボイスメモやメモの中にあれば足りる場合は、そちらをお使いください。Vox.md は、自分で所有するプレーンなファイル、特定のローカルモデル、または Vault にテキストを置きたいときに向いています。

Mac 版 Vox.md を準備する

  1. インストール。 Mac 版 Vox.md には macOS 14 以降が必要です。下の App Store のリンクから入手してください。
  2. モデルをダウンロード。 よくある 設定 → モデル を選び、モデルを1つダウンロードします。Whisper は Tiny(75 MB)から Large v3 Turbo(1.6 GB)まで、Parakeet v2(約 800 MB、英語)、Parakeet v3(約 800 MB、25 言語)から選べます。文字起こしの言語は同じ画面で設定します。対応する Mac では、Whisper は Metal アクセラレーションを使います。ネットワークを使うのはモデルのダウンロードだけです。詳しくは Whisper と Parakeet の比較 をご覧ください。 whisper.cpp は Whisper モデルを実行し、 FluidAudio は Parakeet を実行します。
  3. ルートを選ぶか、新しく作成します。 ルートは、保存先のフォルダまたは Vault と、対象のノートを保持します。対象は、新規ノート、日ごとに追記していくデイリーノート、または既存ノートの見出しの下です。詳しくは ドキュメントのルート.

音声ではなく字幕ファイル(.srt または .vtt)をすでにお持ちですか?文字起こしは不要です: SRT/VTT からテキストまたは Markdown へのコンバーター ブラウザー内で整えます。

Mac 版 Vox.md を入手

ファイルを読み込んで文字起こしする

  1. 読み込み。 Vox.md のメニューバーから次を選びます: オーディオを読み込む…を選ぶか、音声を「キャプチャ」のワークスペースに読み込むかドラッグします。ドキュメントによると、音声ファイルとムービーファイルに対応し、録音と同じローカル文字起こしが行われます。
  2. 「下書きに追加」または「すぐに送信」を選びます。 次を使って、 すぐに送信 文字起こしは完了時に配信されます。 下書きに追加 先に内容を確認できます。名前、数字、日付は音声と照らして確認してください。
  3. 任意:スピーカーの識別。 オンにする項目は、 スピーカーの識別 をルートで使うと、匿名でベストエフォートの話者ラベルが付きます。初回は別のモデルを準備します。実行できない場合は、プレーンな文字起こしが保持され、理由がライブラリに表示されます。
  4. 任意:処理モード。 ルートでは、「オリジナルを保持」、「文章を整える」、「会議メモ」、「タスクチェックリスト」、「カスタム指示」を使えます。Apple Intelligence のモードには、macOS 26 対応のハードウェアが必要です。対応していない場合、「タスクチェックリスト」と「会議メモ」は内蔵フォーマッタを使い、「文章を整える」と「カスタム指示」は元のテキストのままになります。
  5. 送信。 Command-Return を押すと、キャプチャがルートのノートに送信されます。

Markdown ノートを確認する

選択 最後の書き出しを表示 をメニューバーから選ぶか、ライブラリで該当の項目を見つけて Finder で表示し、Obsidian でファイルを開きます。テキストだけが必要な場合は、 最後の文字起こしをコピー。録音から埋めるノートの構成については、次をご覧ください: 会議メモテンプレートジェネレーター.

Mac から外に出るもの

文字起こしは Mac 上で実行され、Vox.md はキャプチャの内容を Vox.md のサーバーに送信しません。モデルのダウンロードでは Hugging Face または FluidAudio のインフラに接続します。保存先フォルダが iCloud などのサービスで同期される場合、そのファイルは当該サービスの規約に従って扱われます。 プライバシーポリシー.

問題の解決

  • 文字起こしがない、または言語が違う。 「設定 → モデル」で、モデルがダウンロード・選択されていることと、言語が設定されていることを確認してください。
  • ノートが作成されない。 ルートの保存先フォルダを確認し、Vox.md にそのフォルダへのアクセス権があるかも確認してください。
  • 長いファイルは時間がかかります。 大きいモデルほど、長い録音では時間がかかります。まず小さいモデルを試してから、比較してください。
  • 無料枠を使い切った。 文字起こし15分と配信成功10回が含まれ、その後は買い切りの永続アンロックです。正式な価格は App Store に表示されるものです。詳しくは 無料利用と永久ライセンス.

録音を、自分で所有するノートに。

まず無料枠で、機密性のない短いクリップから始め、Markdown ファイルを開いてみましょう。
