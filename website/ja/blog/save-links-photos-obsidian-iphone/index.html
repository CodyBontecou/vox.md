iPhone からリンク、写真、スキャンを Obsidian に保存

考えと一緒に、元の資料も残す。リンク、画像、スキャンを、選んだ Markdown の保存先へ送れます。

作成者
Cody Bontecou
更新日
2026年10月26日
必要条件
iOS 17.6+ · 書き込み可能な保管庫フォルダ
短く答えると

Vox.md のキャプチャプレスを書き込み可能な保管庫フォルダに接続し、速い捕獲で URL、写真、ファイル、スキャンを追加して送信します。プリセットがノートと添付ファイルの場所を選びます。配信された Markdown を確認し、Obsidian で添付ファイルが開くか確かめてください。

リンクの保存と記事の保存は、別の作業です。Vox.md はウェブ URL を Markdown リンクとして受け付けます。URL の追加でページ全体をダウンロード・抽出するとは限りません。残したい資料に合ったキャプチャ方法を選んでください。

このガイドの内容
  1. 保管庫の保存先を準備
  2. ウェブリンクを保存
  3. 写真、スクリーンショット、ファイルを追加
  4. 書類をスキャンして OCR を確認
  5. 添付ファイルと同期を確認

1. 保管庫の保存先を準備

「設定」→「キャプチャプリセット」で有効なプリセットを作成または選択し、Files から保存先を接続します。保管庫の Markdown ファイルが入るフォルダを選んでください。別のアプリに公開されていないフォルダには、Obsidian 内で見えているだけでは Vox.md から書き込めません。

最初の例では、新しいノートと「オリジナルを保持」の処理を選びます。専用の受信フォルダを作ると、複数種類のキャプチャを見つけやすくなります。同じファイルに追加したくなったら、後でローリングノートや既存のノートに切り替えられます。

保存先設定で添付ファイルのサブフォルダを指定します。既定は次のとおりです。 attachments。送信前に、解決されたノートのパスと添付ファイルの規則を確認します。デイリー日記には、次に沿って進めてください。 デイリーノートへの振り分けガイド.

2. ウェブリンクを保存する

残したい URL をコピーします。速い捕獲でウェブリンクのコントロールを使い、リンクのテキストとアドレスを確認します。保存した理由を短く加え、送信します。

シンプルなノートには、たとえば次のような Markdown が入ります。

Read before planning the trip:
[Trail information](https://example.com/trail)

上のアドレスは例であり、サイトを推奨するものではありません。実際のページに置き換えてください。リンクは元のページに戻る道を残しますが、そのサイトが変わったり消えたりした場合に内容を保持するものではありません。

Vox.md の共有シートは、ほかのアプリから対応する内容を受け取れます。アプリが共有するものは、URL、テキスト、ファイルなどです。元画面に見えていたすべてが含まれると思い込まず、受け取った内容と選択したプリセットを確認してください。

3. 写真、スクリーンショット、ファイルを追加

  1. 受信ノートやプロジェクトノート用のプリセットを選びます。
  2. 写真・スクリーンショットの選択画面、カメラ、「ファイルを追加」から素材を選びます。
  3. 入力画面で短いタイトルや説明を加えます。
  4. 送信後、Obsidian でノートを開き、埋め込んだ画像やファイルリンクを確認します。

画像は Markdown 出力に埋め込み、その他のファイル形式はリンクにします。たとえば、設定済みの添付パスをノートから次のように参照できます。

4. 書類をスキャンして OCR を確認

キャプチャバーで「書類をスキャン」を選び、スキャナに従います。Vox.md はページ画像を保持し、PDF を作成して、デバイス上で可能な範囲の文字認識を行います。送信前に、特に氏名、日付、金額、手書き文字の認識結果を確認してください。

手帳の写真には、別のテキスト抽出の流れで、手動撮影したページや選択したページを使えます。画像が鮮明でも、OCR は構造を見落としたり単語を読み間違えたりすることがあります。後でテキストを確認する必要があるなら、元画像やスキャンを残してください。

任意の処理による書き換えを避けたい場合は、「オリジナルを保持」を選びます。入力テキストや混在テキストの処理は、プリセットで別途有効化する設定です。次の キャプチャのリファレンス で対応する入力と、次を説明しています。 入力の上限.

添付ファイルと同期を確認

配信後、Obsidian でノートを開き、各リンクをたどって意図したファイルがあるか確認します。ノートが別のデバイスに表示されても、すべての添付ファイルの同期が終わったとは限りません。そのデバイスでも画像や PDF を確認してください。

書き込みに失敗すると、Vox.md 内で保留になる場合があります。別のコピーを作る前に、保存先へのアクセスを修復し、既存のキャプチャを再試行してください。キャプチャ処理自体はローカルでも、クラウドプロバイダに置くファイルは、アクセスや同期に接続が必要な場合があります。

ウェブページ全体を抽出したい場合は、該当するツールを直接比較してください。Obsidian の標準の共有機能は、次に説明されています。 公式 iOS ガイド。ある作業には標準の共有機能を使い、別の作業には Vox.md のプリセットを使えます。
