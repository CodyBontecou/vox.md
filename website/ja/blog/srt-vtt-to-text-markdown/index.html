SRT/VTT からテキストまたは Markdown へのコンバーター

Zoom、Microsoft Teams、YouTube、または文字起こしサービスの字幕ファイルを貼り付けるか開くと、読みやすいテキスト、Markdown 文字起こし、または別の字幕形式が得られます。ファイルはお使いのデバイス上で読み込まれ、アップロードされません。

作成者
Cody Bontecou
更新日
2026年11月23日
必要条件
iPhone の Safari を含む最新のブラウザー。任意: Markdown 出力用の Obsidian、音声から始める場合は iPhone または Mac 用の Vox.md。
短く答えると

.srt または .vtt ファイルを貼り付けるか開き、プレーンテキストか Markdown を選んで、コピーまたはダウンロードします。ファイルはお使いのデバイスから出ません。

このコンバーターは、キュー番号とタイムコードを削除し、行を段落にまとめ、話者名をノート向けの太字の話者ターンに変換します。SRT から VTT、VTT から SRT への変換にも対応しています。ファイルはブラウザーの FileReader API で読み込まれ、このページはネットワークリクエストを送らないため、貼り付けたり開いたりした内容がどこかに送信されることはありません。

1. コンバーターを使う

  1. ファイルを追加します。 内容をボックスに貼り付けるか、次を選びます: .srt, .vtt または .txt ファイル。ツールが形式を検出し、キュー数を表示します。
  2. 出力を選びます。 プレーンテキスト、Markdown、SRT、または VTT。
  3. クリーンアップのオプションを調整します。 行を段落にまとめ、間を置いて新しい段落を開始し、繰り返されるロール行を削除し、タグを取り除き、次のような効果音キューを残すか削除するかを選べます: [Music].
  4. コピーまたはダウンロードします。 ダウンロードでは適切な拡張子が使われます: .txt, .md, .srt または .vtt.

コンバーターには JavaScript が必要です。無効でも、以下の説明は参考資料としてお使いいただけます。

2. SRT と VTT: それぞれの特徴と違い

どちらも、開始時刻、終了時刻、テキストを持つキューを並べたプレーンテキストの字幕形式です。米国議会図書館は次のように説明しています: SubRip（SRT）形式 を、各字幕に連番があり、開始時刻と終了時刻が次の記号で区切られるシンプルなテキスト形式として説明しています: -->、1 行以上のテキスト、空行で構成されます。タイムコードは hours:minutes:seconds,milliseconds。W3C の WebVTT 仕様 は、ブラウザーが字幕に使う新しい形式を定義しています。

.srt.vtt
最初の行最初のキューの番号WEBVTT
ミリ秒の区切り文字カンマ: 00:00:01,000ピリオド: 00:00:01.000
時間常に書き込まれる任意: 00:01.000 は使用できます
キュー番号すべてのキューの連番任意の識別子
キュー設定なし位置や配置をタイムスタンプの後ろに指定できます。例: align:start
話者標準的な記法はなく、次のように書く人がいます: Name:音声スパン: <v Name>text</v>
コメントなしNOTE, STYLE と REGION ブロック

形式を変更するときの変換内容:

  • SRT から VTT: を追加します: WEBVTT ヘッダーを追加し、タイムスタンプ内のカンマをピリオドに変えます。
  • VTT から SRT: ヘッダー、 NOTE, STYLE と REGION ブロックとキュー設定を削除し、ピリオドをカンマに変え、キューを 1 から振り直します。SRT には音声スパンがないため、 <v Name>text</v> は次のようになります: Name: text.
  • 文字エンコーディング: 米国議会図書館によると、SRT には文字エンコーディングの標準がなく、パーサーが検出する必要があります。このコンバーターはファイルを UTF-8 として読み込みます。アクセント付き文字が正しく表示されない場合は、テキストエディターでファイルを開き、先に UTF-8 で保存してください。

3. ファイルの入手先: Zoom、Teams、YouTube

管理者やアカウントの種類によりダウンロードできる内容が変わるため、お使いのプランと設定については各社のページをご確認ください。

Zoom クラウド録画

Zoom のサポート記事 クラウド録画の音声文字起こしについて によると、文字起こしの処理が完了すると、録画とは別の VTT ファイルとして表示されます。これはクラウド録画が対象で、音声文字起こしを有効にしておく必要があります。録画で生成できるファイル形式は次に記載されています: Zoom の録画ファイル形式のガイド.

Microsoft Teams の文字起こし

Microsoft の Teams 文字起こしのダウンロードに関するサポート記事 によると、デフォルトでは主催者と共同主催者が文字起こしを次の形式でダウンロードできます: .docx または .vtt ファイルであること、また IT 管理者のポリシーによりダウンロードできる人が変わる場合があることが記載されています。次を選択してください: .vtt 、ここで開きます。変換前に誤りを修正するには、次を参照してください: Microsoft の Teams 文字起こし編集ガイド.

YouTube 字幕

YouTube ヘルプのページ 字幕の編集と削除について は、自分のチャンネルの動画について YouTube Studio から字幕トラックをダウンロードする方法を説明しています。ダウンロードされるファイル形式は示されていないため、ファイルを貼り付けるか開いて、コンバーターに判別させてください。YouTube の 対応する字幕ファイル形式の一覧 には SubRip（.srt）と WebVTT（.vtt）が含まれます。

使用する権利のある字幕のみをダウンロードしてください。このページは他人の動画を対象としていません。

4. 文字起こしを Obsidian ノートに入れる

  1. Markdown を選びます。 話者名は次のようになります: **Name:**。同じ話者の連続するキューは 1 つのターンにまとめられます。次をオンにしてください: [mm:ss] タイムスタンプを追加 後で録音内の位置を見つけたい場合に使います。
  2. Obsidian プロパティをオンにする で、先頭にブロックを追加します: title, date, source と tags。これは有効な YAML で、次の形式で書かれています: プロパティジェネレーター が書き込みます。Obsidian は 2 つの --- ノートの先頭のマーカーをプロパティとして扱います。参照: プロパティに関する Obsidian ヘルプのページ.
  3. 新しいノートに貼り付け Vault 内、たとえば次の場所に: Meetings フォルダー。次をダウンロードした場合: .md ファイルの場合は、Vault フォルダーに移動してください。
  4. 会議ノートにリンクします。 次でノートを作成: 会議メモテンプレートジェネレーター、次のような行を追加します: Transcript: [[Team sync transcript]] へ。プロパティからリンクする場合、リンクは引用符で囲む必要があります: transcript: "[[Team sync transcript]]".

テキストはエスケープされるため、次のような文字が *, $ と先頭の # Obsidian で書式、数式、タグになることはありません。話者名はファイルから取得されるため、ノートを共有する前に確認してください。

5. 字幕ファイルではなく音声から始める場合

録音しかない場合、字幕ファイルはまったく不要です。Vox.md はデバイス上で文字起こしを行い、Markdown を直接 Vault に書き込みます。次によると: モデルのドキュメント、文字起こしは Apple デバイス上で、対応する iOS 26 デバイスと言語では Apple Speech で、またはダウンロードした任意の Whisper か Parakeet モデルで実行されます。参照: Whisper と Parakeet の比較 で違いを確認してください。話者ラベルは、オプトインのルート手順「 スピーカーの識別。匿名で、ベストエフォートです。

  • Mac で音声ファイルをローカルで文字起こしして Markdown にする
  • Mac のミーティングをローカルで文字起こしして Obsidian へ

Vox.md のドキュメントには SRT や VTT ファイルのインポート/エクスポートに関する記載がないため、このコンバーターは別のツールであり、アプリなしで動作します。

6. よくある質問

ファイルはアップロードされますか?

いいえ。開いたファイルは FileReader API でブラウザー内で読み込まれ、貼り付けたファイルはテキストボックスに残るだけです。変換はこのページ内のスクリプトで行われ、使用中にページがネットワークリクエストを送ることはありません。ページを閉じるか再読み込みすると、テキストは消えます。

行が繰り返されるのはなぜ?

自動字幕はロール形式になることがよくあります。新しいキューが直前の行を繰り返して新しい行を追加するため、同じ言葉が 2、3 回現れます。次をオンにしてください: 繰り返されるロール行を削除。直前のキューの行と同一の行を削除します。話者が本当に同じ行を 2 回続けて話した場合、その繰り返しも削除されるため、人が作成したきれいな字幕ではこのオプションをオフにしてください。

タイムスタンプは残せますか?

はい。プレーンテキストまたは Markdown でタイムスタンプのオプションをオンにすると、各段落の先頭に最初のキューの時刻が次の形式で付きます: [mm:ss]、または [h:mm:ss] 1 時間後に。すべてのキュー時刻が必要な場合は、代わりに SRT または VTT に変換してください。

テキストを SRT に戻すには?

このツールでは対応していません。プレーンテキストにはタイミング情報がないため、SRT にするにはテキストを音声に合わせるツールが必要です。SRT と VTT の相互変換は、どちらの形式にもタイミングが含まれるため、そのまま保持されます。

iPhone で使えますか?

はい。通常のフォームコントロールとブラウザーのファイルピッカーを使用しており、iPhone の Safari で動作するように作られています。コピーは Safari が許可する場合はクリップボードを使い、そうでない場合はテキストを選択するよう促します。
