Obsidian コールアウトジェネレーター: 全種類、エイリアス、折りたたみオプション

種類、タイトル、本文を選び、折りたたみとネストを設定して、正しい > [!type] コールアウトをコピーできます。すべての種類とエイリアス、折りたたみ可能なコールアウトの仕組みも掲載しています。

作成者
Cody Bontecou
更新日
2026年11月27日
必要条件
iPhone の Safari を含む、最新のブラウザならどれでも使えます。任意: コールアウトを使う Obsidian、音声やテキストでノートをキャプチャする iPhone または Mac 用の Vox.md。
短く答えると

コールアウトとは、1行目が次の形になっている引用ブロックです: > [!type] Optional title。以降の各行は次で始まります: > 。次を追加します: + または - を角括弧のすぐ後ろに付けると、折りたたみ可能になります。接頭辞を手で入力せずに作るには、次を使います: コールアウトジェネレーター 以下を参照してください。

> [!warning]- Back up first
> Copy the vault before you change the plugin settings.
>
> Then restart Obsidian.

ジェネレーターは次を追加します: > の接頭辞を全行に付け(ネストでは繰り返し)、コールアウト内の空行を保持し、貼り付けた > を重ねて付けることはありません。すべてこのページ内で処理され、テキストがアップロードされることはなく、ページはネットワークリクエストを行いません。

1. コールアウトを作る

コールアウトジェネレーターには JavaScript が必要です。無効な場合でも、下の構文と種類の表は参考資料として利用できます。

種類

内容

折りたたみ
レイアウト

本当に空の行はコールアウトを終了させるため、残した空行は > として書き出されます。オフにすると空行は削除されます。

作成したコールアウト

これを、ネスト先となる外側のコールアウトの本文の中に貼り付けてください。

プレビュー(おおよそ)

プレビューはおおよその表示です。実際の色、アイコン、余白はテーマによって決まります。

種類ギャラリー

種類を選ぶと、上に読み込まれます。

クリップボードにコピーしました。 コピーに失敗しました。テキストを選択して手動でコピーしてください。 例を読み込みました。 クリアしました。 空欄時の既定のタイトル: {title} これは組み込みの種類ではありません。CSS スニペットで定義しない限り、Obsidian は note のスタイルで表示します。 種類を読み込みました。

2. コールアウトの構文

> [!type] Title
> Body line one.
> Body line two.
  • 種類: 引用ブロックの1行目は、感嘆符に続けて角括弧で種類を書きます: > [!info]. Obsidian ヘルプ の種類の識別子は大文字と小文字を区別せず、未対応の種類は次にフォールバックします: note.
  • タイトル: 角括弧の後ろのテキストがタイトルになります。なければ、Obsidian は種類の識別子をタイトルケースで表示します。たとえば > [!tip] は「Tip」と表示されます。
  • 本文: 以降の各行は次で始まります: > 。本文には Markdown、ウィキリンク、埋め込みを入れられます。
  • タイトルのみ: 本文は省略できます: > [!tip] Remember to save は完全なコールアウトです。

3. すべてのコールアウトの種類とエイリアス

Obsidian ヘルプに載っている組み込みの種類です。各エイリアスは所属する種類と一緒に記載しています。例: tldr を abstract.

種類エイリアス主な用途
noteなし一般的な補足です。未知の種類が最終的に使うスタイルでもあります。
abstractsummary, tldrノート冒頭の要約です。
infoなし背景情報です。
todoなしこれから行うことです。
tiphint, importantアドバイスや要点です。
successcheck, done完了した手順や、良い結果です。
questionhelp, faq未解決の疑問や、よくある質問です。
warningcaution, attention注意が必要なことです。
failurefail, missingうまくいかなかったことや、足りないものです。
dangererror重大なリスクやエラーメッセージです。
bugなし既知の不具合です。
exampleなし実例です。
quotecite出典付きの引用です。

種類とエイリアスは Obsidian ヘルプに基づいています。「主な用途」の列は目安であり、Obsidian が定めたものではありません。既定の外観では、種類ごとに色とアイコンが異なり、テーマで変更できます。

4. 折りたたみ可能なコールアウト: + と -

閉じ括弧のすぐ後ろにプラスまたはマイナスを付けます:

> [!faq]+ Open by default
> This callout is foldable and starts expanded.

> [!faq]- Closed by default
> This callout is foldable and starts collapsed.

Obsidian ヘルプでは、 + は折りたたみ可能で初期状態は展開、 - は折りたたみ可能で初期状態は折りたたみです。どちらもなければ、コールアウトは折りたためません。 + または - は Markdown の一部なので、ファイルに残ります。

5. ネストしたコールアウト、リスト、コード、埋め込み

ネストしたコールアウトにするには、階層ごとに次をもう1つ追加します: > を階層ごとに追加します:

> [!question] Can callouts be nested?
> > [!example] Yes
> > Add one more > for each level.

ジェネレーターの「別のコールアウトの中にネストする」設定は、追加の > を各行に付け、最大3階層まで対応します。結果は外側のコールアウトの本文の中に貼り付けてください。

リスト、コードなどの Markdown は本文に入れ、各行に次の接頭辞を付けます: > の接頭辞を各行に付けます。Obsidian ヘルプによると、本文には Markdown、ウィキリンク、埋め込みを入れられ、既存のコンテンツ(リストやコードブロックを含む)も、選択して次の コールアウトを挿入 コマンドを実行します。リストやコードブロックをジェネレーターの本文欄に貼り付けると、接頭辞が自動で付きます:

> [!info] Checklist
> - [ ] first
> - [ ] second
>
> ```
> code line
> ```

6. CSS スニペットによるカスタムのコールアウトの種類

独自に作った種類は note のスタイルで表示されます。Obsidian ヘルプによると、カスタムのコールアウトは CSS スニペットまたはコミュニティプラグインで定義します。例:

.callout[data-callout="custom-question-type"] {
  --callout-color: #000000;
  --callout-icon: lucide-alert-circle;
}

ヘルプページによると、 --callout-color は有効な CSS の色ならどれでも指定でき、 --callout-icon には lucide.dev のアイコン ID または SVG 要素を指定します。その後、次を書きます: > [!custom-question-type] をノートに書きます。同じ名前をジェネレーターのカスタムの種類欄にも入力してください。

7. GitHub のアラートと Obsidian のコールアウト

GitHub にもアラートという似た機能があります。 GitHub ドキュメント は次の5つを挙げています: NOTE, TIP, IMPORTANT, WARNING と CAUTION.

> [!NOTE]
> Useful information that users should know, even when skimming content.

そのページには、折りたたみ、カスタムタイトル、カスタムの種類のどれも記載がありません。Obsidian のコールアウトにはこの3つすべてがあります。1行目は同じ見た目なので、基本的な > [!note] または > [!warning] は多くの場合どちらでも動作しますが、Obsidian 専用の種類(たとえば [!bug]、 +/- の折りたたみやタイトルは、GitHub のドキュメントにはありません。両方で読まれるファイルでは、GitHub の5種類だけにして、余計な指定は付けないでください。

8. Vox.md で音声やテキストを Obsidian にキャプチャ

Vox.md は、キャプチャした内容を Obsidian の保管庫フォルダに Markdown ノートとして保存します。キャプチャ用のアプリであり、コールアウトを自動で書き込むわけではありません。このページのジェネレーターで作って貼り付けるか、上の構文を直接入力して、後から追加してください。文字起こしを本文にするには、テキストをジェネレーターに貼り付けると接頭辞が付きます。

関連するツールとガイド: Markdown チェックリストメーカー と Markdown 表メーカー はコールアウトの中に入れる内容に、 プロパティジェネレーター、 デイリーノートのテンプレート と 会議メモのテンプレート はノートの構造に、 キャプチャテンプレート は接頭辞とパスに、 iPhone で Obsidian に音声ノートを送る.

Vox.md で音声やテキストのノートを保管庫にキャプチャ

Vox.md は端末上で文字起こしし、Markdown を Obsidian の保管庫に保存します。録音、文字起こし、キャプチャには Vox.md Unlimited が必要です。週間または年間のサブスクリプション(対象アカウントは7日間の無料トライアル付き)か、買い切りのライフタイム購入のどちらかです。価格は App Store にお住まいの地域の金額で表示されます。

9. よくある質問

コールアウトが表示されないのはなぜですか?

次の3点を確認してください。1行目は次で始まる必要があります: > そして [!type]、感嘆符を付け、角括弧の内側にスペースを入れないでください。本文の各行にもそれぞれ次が必要です: >。次のない空行は、 > は引用ブロックを終了させるため、その後の行は通常のテキストになります。次のように書いてください: >。それでも通常の引用ブロックとして表示される場合は、次の間にスペースや入力ミスがないか確認してください: > と [!.

コールアウトにタイトルなしは可能ですか?

少し違います。タイトルを省くと、Obsidian は代わりに種類の識別子をタイトルケースで表示します。タイトルを隠すには CSS が必要です。Obsidian ヘルプによると、タイトルを隠すなどの追加スタイルは標準の CSS セレクターで指定できます。タイトル欄を空にした場合、ジェネレーターはタイトルを空のままにするので、既定のタイトルになります。

Admonition プラグインと標準のコールアウト、どちらを使うべき?

標準のコールアウトはプラグイン不要で、このページの > [!type] の構文です。Admonition プラグインは独自の構文を持つ別のコミュニティプラグインで、このページでは扱いません。Obsidian ヘルプによると、カスタムのコールアウトの種類はコミュニティプラグインから提供されることもあります。

コールアウトは Obsidian モバイルや Publish でも使えますか?

Obsidian ヘルプによると、コールアウトは Obsidian Publish でネイティブにサポートされています。コールアウトのページではモバイルについて触れていないため、このページでは対応の有無を断定しません。

ジェネレーターはテキストをアップロードしますか?

いいえ。このページ内のスクリプトがお使いの端末上でコールアウトを作成し、ページはネットワークリクエストを一切行いません。何も保存されず、ページを再読み込みすると消えます。
