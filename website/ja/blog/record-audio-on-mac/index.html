Mac で音声を録音する方法:自分の声やアプリの音

まず Apple 内蔵のレコーダーと各 Apple サポートのページ、その後にアプリの音声、保存した音声ファイル、任意のデバイス上の文字起こしのためのローカルなルートを紹介します。

作成者
Cody Bontecou
更新日
2026年11月26日
必要条件
macOS 14 以降 · マイクへのアクセス · 書き込み可能なフォルダ
短く答えると

自分の声を録音するには、どちらも内蔵の QuickTime Player(ファイル → 新規オーディオ録音)またはボイスメモを使います。アプリが再生する音、またはアプリとマイクの音を一緒に録音するには、アプリの音声をキャプチャできるツールが必要です。Mac 版 Vox.md は Mac 上でこれを行い、音声を Markdown ノートと文字起こしと一緒に保存できます。

以下のメニュー名は Apple サポートのページに基づいており、各セクションにリンクがあります。メニューは macOS のバージョンによって多少異なる場合があります。Vox.md の手順は次に従っています: Mac ワークスペースのドキュメント および ミーティングキャプチャのドキュメント.

QuickTime Player で音声を録音する

これらの手順は Apple の次のページに従っています: Mac の QuickTime Player で音声を録音する.

  1. QuickTime Player を開き、 ファイル → 新規オーディオ録音.
  2. 録音ボタンの横にある矢印をクリックして、オプションメニューを開きます。 マイクで、入力が複数ある場合は選びます。 品質で設定を選びます。Apple によると、最高品質では非圧縮ファイルになり、多くの容量を使う場合があります。
  3. 次の 録音 ボタンで開始し、 停止 ボタンをクリックします。Apple によると、ボタンを Option キーを押しながらクリックすると一時停止でき、もう一度クリックすると再開します。
  4. 選択 ファイル → 保存 録音に名前を付けて、保存先を選びます。

QuickTime Player は文字起こしを作成しません。また、Apple のページで説明されているのはマイクの選択で、アプリの音のキャプチャではありません。

Mac のボイスメモで録音する

Apple による Mac で録音を作成する の手順です。

  1. ボイスメモアプリを開きます。
  2. 次の 録音 ボタンをクリックします。内蔵マイク、対応するヘッドセット、外付けマイクで録音できます。
  3. をクリックします: 一時停止 で一時停止し、 再開 で再開します。
  4. をクリックします: 完了 録音を保存します。

ボイスメモで iCloud をオンにし、各デバイスで同じ Apple アカウントを使うと、録音が Mac、iPhone、iPad に表示されます。Apple の次のページを参照してください: すべての Apple デバイスで録音を見る。メモをテキストに変換するには、次を参照してください: iPhone でボイスメモを文字起こしする。Apple は次のページで文字起こし表示についても説明しています: Mac でボイスメモの文字起こしを表示する.

Shift-Command-5 で画面と音声を録画する

Apple による Mac でスクリーンショットや画面収録を撮る では、次を押すよう案内されています: Shift-Command-5 を押して「スクリーンショット」を開き、ツールを表示します。画面収録のツールを選び、次に オプション ポップアップメニューを開きます。 マイクで、使いたいマイクにチェックマークが付くように選択します。オフにするには なし を選択するとオフになります。オプションメニューでは、録音の保存先なども設定できます。

Apple のページでは、オーディオのオプションとしてマイクが説明されています。アプリ自体の音の録音については説明がないため、このガイドではツールバーで可能とは述べていません。

アプリが再生する音を録音する

上記の内蔵レコーダーは、Apple ではマイクの観点で説明されています。講義のストリーミング、通話、動画など、特定のアプリが再生する音が必要な場合は、アプリの音声をキャプチャできるソフトウェアが必要です。以下のルートでは仮想オーディオドライバを使いません。

macOS では、この機能にプライバシーの許可が必要です。Apple の説明は次にあります: Mac で画面とシステムオーディオの録音へのアクセスを制御する:Mac では一部のアプリが画面と音声を録画でき、どのアプリに許可するかは次で管理します: システム設定 → プライバシーとセキュリティ → 画面とシステムオーディオの録音.

Vox.md の場合。 ミーティングモードでは、Apple の ScreenCaptureKit フレームワーク シングルアプリケーションモードで使います:

  1. 入力モードを次から切り替えます: マイク への ミーティング.
  2. 録音を開始します。macOS にコンテンツピッカーが表示されるので、アプリケーションをちょうど 1 つ選びます。
  3. マイクは別のトラックとして録音され、Vox.md が自身の音声を録音することはありません。
  4. 停止を押します。各トラックは Mac 上で文字起こしされ、両方を再生用にミックスしたものが録音の音声として保存されます。

これは選んだ 1 つのアプリとマイクの音で、Mac が出すすべての音ではありません。ミーティングのキャプチャは一時停止できません。ルート、話者ラベル、復元を含む完全な設定については、次を参照してください: Mac のミーティングをローカルで文字起こしして Obsidian へ.

録音する前に確認を。 録音に関する法律や職場のルールは場所によって異なります。他の人を録音するときは、その人に伝えて同意を得てください。これは法的助言ではありません。

Vox.md で自分の声をノートに録音する

自分の声については、Mac 版 Vox.md はマイクの音を単体のファイルではなくノートに録音します。

  1. キャプチャのワークスペースで、 下書きに追加 を録音の前に選ぶと、文字起こしがすぐに送信されず、確認のためにコンポーザーに入ります。
  2. 録音します。 一時停止 と 再開 をステータスバーで使うと、1 つのノートを複数回に分けて録音できます。一時停止中の音声は録音に含まれません。
  3. ルートで、 オーディオを保存 への ノートと同じ場所 または 添付フォルダ のいずれかにして、音声ファイルを残します。参照: オーディオの保存.
  4. 保存した音声は、Obsidian の記法でノートに埋め込めます。例: ![[recording.m4a]].

Whisper または Parakeet モデルをダウンロードすると、Vox.md はデバイス上で文字起こしも行います。 モデルのリファレンス はサイズと言語を掲載しており、 Whisper と Parakeet の比較 が選ぶ助けになります。他のアプリに声でテキストを入力したいだけなら、次を参照してください: Mac の音声入力。設定の詳細は次にあります: Mac ワークスペースのドキュメント。無料枠については、次に記載があります: 無料利用と永久ライセンス.

音が出ない、または無音のファイル

  • 入力デバイス。 選択 Appleメニュー → システム設定 → サウンド → 入力 で、使いたいデバイスを選びます。Apple の次のページを参照してください: Mac でサウンド入力の設定を変更する.
  • マイクの許可。 次を開く: システム設定 → プライバシーとセキュリティ → マイクで、アプリをオンにします。Apple の次のページを参照してください: Mac でマイクへのアクセスを制御する.
  • アプリの音。 次を開く: プライバシーとセキュリティ → 画面とシステムオーディオの録音。録音するアプリをオンにします。参照: Apple のページ。Vox.md のミーティングモードでは、アプリの再生中に両方のレベルメーターが動くことを確認してください。
