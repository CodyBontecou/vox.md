Core Templates プラグイン: ファイルをテンプレートフォルダに保存し、次のコマンドで挿入します: Templates: Insert template. {{title}} はノート名になり、日付には波括弧内の Moment.js 形式が使われます。

Templater プラグイン: ファイルを Templater のテンプレートフォルダに保存し、次のコマンドで挿入します: Templater: Open insert template modal。または、フォルダテンプレートとして使います。コア Templates プラグインは <% %> コマンドを実行しません。

プレーン Markdown: Vox.md のトークンを 1 重波括弧で書いた見出しとフィールドです。Obsidian はこれらのトークンを入力したまま残します。ルートがこのファイルを保管庫テンプレートとして使うと、Vox.md がトークンを埋めます。参照: 録音からノートを作成.

Vox.md の新しいノートのパス
Meetings/{date}-{hour}{minute}.md

2. テンプレートを Obsidian に追加

Core Templates プラグイン。 設定 → コアプラグインで Templates をオンにしてから、次を設定します: Template folder location（例: Templates）。テンプレートをそこに .md ファイルとして保存します。新しいノートで、コマンドパレットから Templates: Insert template を実行し、テンプレートを選びます。Obsidian は {{title}}, {{date}} と {{time}} を、テンプレートの挿入時に置き換えます。コロンの後に書式を付けたもの（例: {{date:YYYY-MM-DD}}）は Moment.js のトークンを使います。参照: Templates プラグインのヘルプ および Moment.js の書式トークン.

Templater プラグイン。 コミュニティプラグインから Templater をインストールし、次を設定します: Template folder location。テンプレートは次のコマンドで挿入します: Templater: Open insert template modal。フォルダ Meetings/ 内のすべての新しいノートにこのテンプレートを適用するには、次の設定 Trigger Templater on new file creationをオンにし、 Template matching mode をフォルダテンプレートに設定して、 Meetings フォルダをこのファイルに割り当てます。 Templater の設定ドキュメント ではフォルダテンプレートを解説しています。また、 date モジュール では次の関数を説明しています: tp.date.now.

プロパティ。 フロントマターは --- の行の間に書かれ、ノートのプロパティになります。プロパティ内のリンクは引用符で囲む必要があるため、project フィールドは次のように書かれています: "[[Project name]]"。参照先： プロパティ （Obsidian ヘルプ）

3. 会議ごとに 1 つのノート

会議は 1 つのフォルダ（例: Meetings/）にまとめ、ファイル名に日付と開始時刻を入れます: Meetings/2026-11-19 1430 Design review.md。この順序の名前なら日付順に並び、同じ日の 2 つの会議が 1 つのファイルを共有することもありません。

オンにする項目は、 デイリーノートへのリンク （ジェネレーター内）。すると次の行が追加されます: Daily note: 。この行はその日のノートにリンクします。リンクは YYYY-MM-DD。デイリーノートで別の日付フォーマットを使っている場合は、それに合わせて変更してください。 デイリーノートテンプレートジェネレーター は、フォーマットから決まるファイル名をプレビューします。その日の会議もデイリーノートに一覧したい場合は、そこからリンクしてください。 Obsidian のデイリーノートに追記 では、Vox.md でデイリーノートに項目を追加する方法を紹介しています。

4. アクションアイテムとフォローアップ

各アクションアイテムは Obsidian のタスクとして書き（例: - [ ] Send the release notes）、完了したら - [x] としてチェックを付けます。参照: 基本的な書式の構文。担当者を先頭に書くと、各行が「誰が何をするか」として読めます。

オプションのスタイルでは、期限をコミュニティ製の Tasks プラグイン: 📅 の後に YYYY-MM-DDが続く形式で追加します。ジェネレーターは会議の日付を入れるので、実際の期限に変更してください。Tasks プラグインがない場合、絵文字と日付はただのテキストになりますが、タスクとしては問題なく機能します。

すべての会議の未完了項目を 1 か所に集めるには、ノートに Tasks のクエリを追加します:

```tasks
not done
path includes Meetings
```

このクエリは、パスに次の文字列を含むノートから未完了のタスクを一覧表示します: Meetings。すでに Dataview を使っているなら、Dataview でも同様のリストを作成できます。

5. 録音からノートを作成

テンプレートで用意できるのは見出しです。ノートそのものは Vox.md が作成できます。会議を録音し、デバイス上で文字起こしして、ルート経由で Markdown ファイルを保管庫に保存します。

  1. 録音する。 Mac では、Vox.md は 1 つの通話アプリとマイクを別々のトラックとして録音できます。手順: Mac のミーティングをローカルで文字起こしして Obsidian へ。対面の会議では、iPhone または iPad のマイクで録音します。参照: iPhone の音声メモを Obsidian に保存.
  2. 保存先を選ぶ。 ルートで保管庫を選び、 新しいノートを選んで、次のようなパスを入力します: Meetings/{date}-{hour}{minute}.md. {date} は 2026-11-19 と {hour}{minute} は 1430として書き込まれます。これらは Moment.js の書式ではなく、Vox.md のトークンです。 Obsidian キャプチャテンプレート で、ほかのパスの例を確認できます。
  3. モードを選ぶ。 ルートの処理モードを 会議メモに設定します。このモードは ## Notes セクションを作成し、文字起こしにアクションアイテムが含まれる場合は ## Action Items チェックリストも作成します。対応ハードウェア上の macOS 26 または iOS 26 では Apple Intelligence を使い、それ以外の場合は一定の結果を返す整形機能が構成を組み立てます。

会議メモは、議題、参加者、決定事項を自動で記入するわけではありません。メモの上にそれらの見出しを置きたい場合は、ジェネレーターで プレーン Markdown を選び、メモとアクションアイテムのチェックを外して、結果を保管庫に保存します。次に、そのファイルをルートの保管庫テンプレートとして選択します。Vox.md はテンプレート内の 1 重波括弧のトークンを埋め、処理済みの文字起こしをその下に書き込みます。このレイアウトに頼る前に、最初のノートを確認してください。 ルートのドキュメント では、保存先とテンプレートについて説明しています。

会議の参加者全員に録音と文字起こしをしていることを伝え、事前に同意を得てください。ルールは地域や職場によって異なります。参照: 録音していることを伝える.

6. よくある質問

Core Templates と Templater のどちらを使うべきですか？

Core Templates は Obsidian に付属し、タイトル、日付、時刻に対応します。Templater はスクリプト、日付のオフセット、フォルダテンプレートを追加するコミュニティプラグインなので、 Meetings/ 内の新しいノートに自動でテンプレートを適用できます。このページのフィールドだけで足りるなら、Core Templates で十分です。

なぜ {{date}} は後から変わらないのですか？

Obsidian は、テンプレートを挿入したときにテンプレート変数を一度だけ置き換えます。その後のノートにはプレーンテキスト（例: 2026-11-19）が残り、そのまま保持されます。会議の記録としては、これが望ましい動作です。

Vox.md で自分の Obsidian テンプレートを使えますか？

一部対応しています。ルートでは、保管庫内の Markdown ファイルをテンプレートとして使えます。Vox.md が埋めるのは、独自の 1 重波括弧トークン（例: {date}）と、Templater の日付コマンド tp.date.now と tp.file.creation_dateです。その他の Templater コマンド（例: tp.file.title）は実行せず、コア Templates の変数（例: {{title}}）も展開しないため、ルートのテンプレートにはこれらを含めないでください。Vox.md のルートにはプレーン Markdown の出力を使ってください。

ジェネレーターは選択内容をどこかに送信しますか？

いいえ。テンプレートはこのページ内のスクリプトで作成されます。最後の選択内容はブラウザのローカルストレージに保存されるので次回も残り、「リセット」で消去できます。
