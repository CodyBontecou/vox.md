Mac · 音声入力 · ローカル文字起こし

Mac での音声入力の方法と、プライベートなローカルの選択肢

音声入力を数ステップで設定し、動かないときの対処を確認し、ローカルモデルと Markdown ノートのどちらが合うかを判断しましょう。

作成者
Cody Bontecou
更新日
2026年11月22日
必要条件
Vox.md: macOS 14 以降。Apple の音声入力が使えるかどうかは、お使いの Mac、macOS のバージョン、言語によって異なります。
短く答えると

System Settings > Keyboard で Apple の音声入力をオンにし、任意のテキストフィールドで Dictation ショートカットを押します。ローカルの Whisper や Parakeet モデルを選びたい場合や、音声入力を Markdown ノートに送りたい場合は、Vox.md のグローバルショートカットを割り当てます。

以下の Apple の手順は、Apple サポートのページに基づいています: Mac で音声入力を使う(2026 年 11 月 22 日に確認)。メニュー名は macOS のバージョンによって異なる場合があるため、お使いのバージョンについてはそのページを確認してください。Vox.md の手順は次に従っています: グローバルキーバインド と モデル ドキュメント。

Mac で音声入力をオンにする方法

  1. 選択 Appleメニュー > システム設定、続けてクリックします: キーボード (サイドバー内)。
  2. 移動先: 音声入力 を開き、オンにします。
  3. ショートカット: 同じ場所で、次をクリックします: ショートカット ポップアップメニューから、音声入力を開始するショートカットを選びます。Apple のページにはデフォルトの記載がないため、お使いの Mac での設定を確認してください。
  4. 言語: クリック: 編集 の横にある言語欄で、言語と地域を選びます。音声入力中は、カーソルの横にある言語をクリックするか、キーボードに Globe キーがあればそれを押して切り替えられます。
  5. マイク： 次を使います: マイク入力元 ポップアップメニューで、音声入力に使うマイクを選びます。Automatic の場合、Mac は最も使われそうなデバイスを聞き取ると Apple は説明しています。
  6. 音声入力を開始: テキストフィールドをクリックし、ファンクションキーの行にマイクキーがあればそれを押すか、Dictation ショートカットを使うか、次を選びます: 編集 > 音声入力を開始.
  7. 停止: Escape キー、マイクキー(ある場合)、または Dictation ショートカットを押します。

処理と制限について Apple が述べていること。 Apple によると、一般的なテキストの音声入力が「デバイス上で処理され、Siri サーバーに送信されない」かどうかは、Keyboard 設定で確認できます。音声入力がオフラインで動作するとはページに書かれていません。また Apple は、長さを問わずタイムアウトなしでテキストを音声入力でき、30 秒間音声が検出されないと自動的に停止するとも述べています。音声録音を Apple と共有するかどうかは任意です(オーディオ録音を共有)。Apple は、音声入力がすべての言語や地域で利用できるわけではなく、機能が異なる場合があると述べています。Apple の次のページもご覧ください: Dictation ページ およびそこからリンクされている macOS の機能提供状況ページをご覧ください。音声コントロールがオンのとき、標準の macOS 音声入力は利用できないと Apple は説明しています。

Apple の音声入力か、ローカルの音声入力アプリか

Apple の音声入力はすでに Mac に入っていて、多くの人には十分です。音声モデルを選びたい、文字起こしを設計上 Apple のサーバーに置きたくない、あるいは音声を Markdown として保存したいときは、ほかの方法を検討してください。表では、ドキュメントに基づき 3 つの構成を比較しています。精度や速度についての主張はしていません。

Vox.md で Mac のあらゆるアプリに音声入力する

トランスクリプト Clipboard はグローバルショートカットです。押して、話して、もう一度押します。Vox.md は Mac 上で文字起こしし、テキストをクリップボードに入れるので、Command-V で貼り付けます。最前面のアプリに自動で入力することはありません。ノートも Library の項目も作成せず、音声も保存しません。

  1. インストールして、モデルをダウンロードします。 Mac 用の Vox.md をインストールします(macOS 14 以降)。次の モデル 画面で、モデルをダウンロードします。Whisper は Tiny(75 MB)から Large v3 Turbo(1.6 GB)まで、英語用の Parakeet v2、または 25 言語対応の Parakeet v3(それぞれ約 800 MB)があります。ダウンロードはすべてご自身で開始し、あとでモデルを削除することもできます。Whisper は対応する Mac で Metal アクセラレーションを使用します。文字起こしの言語は同じ画面で選択します。次をご覧ください: Whisper と Parakeet の比較 (選び方について)。
  2. ショートカットを割り当てます。 よくある 設定 > グローバルキーバインド そして次を割り当てます: トランスクリプト Clipboard。ショートカットはデフォルトでオフです。ショートカットには修飾キー以外のキーと Control、Option、Command のいずれかが必要で、Shift を加えることもできます。競合するショートカットは Vox.md が拒否します。
  3. 録音する。 テキストを入れたい場所をクリックし、ショートカットを押して、話します。
  4. 停止します。 同じショートカットをもう一度押します。メニューバーに文字起こしの完了が表示されるまで待ちます。
  5. 貼り付けます。 Command-V を押します。

もう一度テキストが必要な場合は、次を選びます: 最後の文字起こしをコピー (Vox.md のメニューバーから)。メニューバーの操作は次に一覧があります: メニューバーのドキュメント。iPhone でこれに相当するのはキーボードです。次をご覧ください: iPhone 音声入力キーボードのガイド と iPhone で音声からテキストへの変換を使う方法.

Obsidian のノートや Markdown ファイルに音声入力する

言葉を別のアプリではなくノートに残したいときに選びます。次の 設定 > グローバルキーバインドで、次にショートカットを割り当てます: 選択中のルート または特定の Route に割り当てます。すると文字起こしはその Route に従い、そこで設定したデイリーノート、見出しの位置、処理モードが使われます。これは貼り付けではなく、Vox.md が Route の保存先にテキストを届けます。Route は次で設定します: デイリーノートテンプレートのガイド と キャプチャテンプレートのガイド。音声入力ではなく通話の録音については、次をご覧ください: Mac の会議を Obsidian へ。無料枠には 10 回の Capture 配信の成功が含まれます。

Mac の中に残るもの

Vox.md は、キャプチャの内容を Vox.md のサーバーに送信しません。文字起こしは Mac 上で実行されます。ネットワークを使うのは、ご自身で開始するモデルのダウンロードだけで、Hugging Face または FluidAudio のインフラを利用します。文字起こし自体は Mac 上で実行されます。ノートが iCloud などの同期サービスのフォルダに保存される場合、そのファイルはそのサービス自身の規約に従って扱われます。次をご覧ください: プライバシーポリシー と オフライン文字起こしの設定。Vox.md が使うのは次のものです: whisper.cpp (Whisper 用)と FluidAudio (Parakeet 用)。

Mac の音声入力が動かない

Apple の音声入力の確認事項

Apple のページ Mac の音声入力が思いどおりに動かない場合 次が挙げられています:

  • Keyboard 設定で Dictation がオンになっていることを確認してください。
  • 正しい言語と地域を選びます。音声入力はすべての言語や地域で利用できるわけではありません。
  • 正しい Dictation キーボードショートカットを使っているか確認してください。別のショートカットが同じキーを使っている場合は、Keyboard > Dictation で Dictation ショートカットを変更します。
  • Mac に内蔵マイクがない場合は、外部マイクが接続され、サウンドまたは Keyboard 設定で選択されていること、入力音量が十分であることを確認してください。
  • マイクがふさがれていないこと、小さすぎず大きすぎない音量ではっきり話していること、周囲の雑音がないことを確認してください。
  • インターネット接続が必要な場合があります。音声入力がデバイス上で処理されるかどうかは Keyboard 設定で確認してください。

Vox.md の確認事項

  • ショートカットが反応しない。 ショートカットはデフォルトでオフです。Settings > Global Keybinds で割り当ててください。競合するショートカットは Vox.md が拒否するため、別のキーの組み合わせを選んでください。
  • 文字起こしが出ない。 Models 画面でモデルがダウンロードされ、選択されていることを確認します。
  • 言語が違う。 Models 画面で言語を選びます。
  • 貼り付けるものがない。 メニューバーに文字起こしの完了が表示されるまで待ってから、Command-V を押すか、Copy Last Transcript を選びます。

よくある質問

Mac の音声入力はオフラインで使えますか?

Apple の「音声入力を使う」ページにはそのような記載はありません。一般的なテキストの音声入力がデバイス上で処理され、Siri サーバーに送信されないかどうかは、Keyboard 設定で確認できるとしています。トラブルシューティングのページには、インターネット接続が必要な場合があると書かれています。モデルをダウンロードした後、Vox.md は Mac 上で文字起こしを行います。

時間制限はありますか?

Apple によると、長さを問わずタイムアウトなしでテキストを音声入力でき、30 秒間音声がないと音声入力は停止します。Vox.md の無料枠には 15 分の文字起こしが含まれ、その後は買い切りの生涯アンロックとなります。

ショートカットは変更できますか?

はい、どちらでも変更できます。Apple の音声入力では、System Settings > Keyboard > Dictation の Shortcut ポップアップメニューを使います。Vox.md では、Settings > Global Keybinds で、修飾キー以外のキーと Control、Option、Command のいずれかを組み合わせて割り当てます。

Vox.md にアカウントは必要ですか?

いいえ。

ローカルモデルで Mac に音声入力。

無料枠は 15 分の文字起こしと 10 回の Capture 配信の成功です。それ以降は、お住まいの地域の App Store 価格で表示される買い切りの生涯アンロックで、制限が解除されます。
