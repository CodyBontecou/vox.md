Mac のミーティングをローカルで文字起こしして Obsidian へ

通話アプリを選び、録音して停止すれば、保管庫に Markdown ノートができます。何が Mac に残り、何が Mac の外に出るかも確認しましょう。

作成者
Cody Bontecou
更新日
2026年11月18日
必要条件
macOS 14以降 · ダウンロード済みの音声モデル · 書き込み可能な保管庫フォルダ
短く答えると

Vox.md for Mac は、1つのアプリの音声とマイクを別々のトラックとして録音し、両方を Mac 上で文字起こしして、話者ラベル付きの Markdown ノートを Obsidian の保管庫または任意のフォルダに保存できます。ミーティングボットもアカウントもありません。

このガイドでは、保管庫内の Meetings/ に書き込むルートから完成したノートまで、実際に動作する設定を1つ順に説明します。手順は Mac のミーティングキャプチャのドキュメント と、出荷されているアプリの動作に沿っています。以下の Markdown は説明用の例であり、実際の通話を録音したものではありません。

このガイドの内容
  1. 必要なもの
  2. ミーティング用のルートを準備する
  3. 通話を録音する
  4. 停止、文字起こし、配信
  5. 録音が中断された場合
  6. 録音することを相手に伝える
  7. ミーティングノートの方式を比較する
  8. 長い通話の前に知っておきたい制限

1. 必要なもの

  • macOS 14以降を搭載した Mac と、iPhone 版と同じ App Store のページからインストールした Vox.md Mac アプリ。
  • マイクへのアクセス を Vox.md に許可します。自分の声を録音するために必要です。
  • 画面とシステムオーディオの録音へのアクセス。 ミーティングキャプチャは、Apple の ScreenCaptureKit フレームワーク を使って、選んだアプリの音声を録音します。macOS から確認された場合は許可してください。両方の権限は「システム設定」→「プライバシーとセキュリティ」で確認できます。この設定については、Apple のサポート記事を参照してください: Mac で画面とシステムオーディオの録音へのアクセスを制御する.
  • ダウンロード済みの Whisper または Parakeet モデル。 Mac のモデル画面を開いてモデルをダウンロードし、文字起こしの言語を設定します。サイズと言語の一覧は モデルのリファレンス はサイズと言語を掲載しており、 Whisper と Parakeet の比較 は選択に役立ちます。Whisper は次を通じて動作します: whisper.cpp 、Parakeet は FluidAudio.
  • 書き込み可能なフォルダ（Obsidian の保管庫や、その中の Meetings フォルダなど）。
  • 普通の録音だけが必要ですか?次を参照してください: Mac で音声を録音する方法.

「会議メモ」モードが文字起こしの再構成に使う Apple Intelligence の処理（任意）には、macOS 26 を搭載した対応 Mac が必要です。使えない場合は Vox.md が代わりに決定的なフォーマッタを使うため、ルートはそのまま動作します。

2. ミーティング用のルートを準備する

ルートは、キャプチャの処理方法と Markdown の書き込み先を決めます。Mac のバージョンによっては、設定でルートが「キャプチャプリセット」と表示されます。

  1. Mac アプリで設定を開き、次のような名前で新しいルートを作成します: ミーティング.
  2. 保存先でVaultをフォルダとして選びます。ノートの対象には次を選びます: 新しいノート — こうすると、ミーティングごとに専用のファイルが作られます。
  3. 次のようなパステンプレートを入力します: Meetings/{date}-{hour}{minute}.md。時刻を含めると、同じ日の2つのミーティングが別々のノートになります。パスとトークンのその他のレシピは Obsidian キャプチャテンプレート を参照してください。
  4. 次の項目で処理方法を選びます: モード. オリジナルを保持 は、認識されたままのラベル付き文字起こしを配信します。 会議メモ は、 ## Notes セクションを作成し、テキストにアクションアイテムが含まれる場合は ## Action Items チェックリストも作成します。議題や決定事項の見出しも必要ですか？ 議事録テンプレートを生成.
  5. 任意: スピーカーの識別 は、複数のリモート参加者が話す場合にオンにします。話者モデルは、このルートで初めて使うときにダウンロードされます。
  6. 任意で オーディオを保存 を設定すると、ノートと同じ場所または添付ファイルフォルダに録音を残せます。テキストだけが必要ならオフのままにします。

3. 通話を録音する

  1. 通話にはそれぞれのアプリで参加します: Zoom、Microsoft Teams、FaceTime、または Google Meet を開いたブラウザ。
  2. Vox.md のキャプチャウィンドウで、 ミーティング ルートを選択します。
  3. オーディオソースを次に切り替えます: ミーティング。既定値は マイク。アプリのバージョンによって、この操作はキャプチャウィンドウ内、またはメニューバーの「キャプチャ」→「オーディオソース」にあります。
  4. 録音を開始します。macOS のコンテンツピッカーが表示されるので、アプリケーションを1つだけ選びます。Vox.md 自身の音声は録音されません。ブラウザでの通話ならブラウザを選びます。ブラウザの音声はまとめて録音されるため、音が出る他のタブはミュートしてください。
  5. 録音中は、ステータスバーにシステムとマイクのライブレベルメーター、各ソースの状態、キャプチャの警告が表示されます。人が話したときに両方のメーターが動くことを確認してください。

ミーティングキャプチャは一時停止できません。マイク録音には一時停止と再開がありますが、ミーティングは開始から停止まで続きます。途中で別のアプリに切り替えることもできません。その場合は停止して、新しい録音を始めてください。

Vox.md を無料でダウンロード

録音、文字起こし、Capture には Vox.md Unlimited が必要です。対象のアカウントは7日間の無料トライアル付きの週額または年額サブスクリプション、または買い切りの永久ライセンスを選べます。価格は App Store に地域ごとに表示されます。

4. 停止、文字起こし、配信

通話が終わったら「停止」を押します。Vox.md は選んだモデルを使って2つのトラックを Mac 上で別々に文字起こしし、共通のタイムライン上で交互に並べます。マイクのトラックのラベルは You、アプリケーションのトラックには Speaker 2などのリモート話者のラベルが付きます。「オリジナルを保持」の場合、短いミーティングでは次のようなノート本文になることがあります（説明用の例）:

You:
Thanks for joining. Can we start with the launch checklist?

Speaker 2:
Sure. The release notes are ready, but we still need screenshots.

You:
I’ll take the screenshots by Friday.

「スピーカーの識別」をオンにすると、Vox.md はリモートのトラックを Speaker 2 と Speaker 3などのさらに多くのラベルに分けようとします。これらのラベルは匿名で、ベストエフォートです。識別を実行できない場合は通常の文字起こしが残り、アプリにその理由が表示されます。

トラックが分かれているからこそ、 You ラベルが機能します。あなたの声はマイクのトラックから、他の参加者の声はアプリのトラックから届くため、Vox.md は1つに混ざった録音から通話のどちら側が何を言ったかを推測する必要がありません。それでもラベルが間違うことはあります。たとえば、ヘッドホンを使っていないと、マイクがスピーカーの音を拾うことがあります。

次に起きることは、録音を始める前に選んだ録音オプションによって異なります:

  • 下書きに追加 は、文字起こしをキャプチャのコンポーザーに入れます。確認・編集してから Command-Return を押し、ルートに送ります。
  • すぐに送信 は、文字起こしが終わるとすぐに、ルートを通してノートを配信します。

文字起こしは、他の録音と同様にクリップボードの設定にも従います。両方のトラックを再生用にミックスした音声が録音のオーディオとして保持され、ルートの「オーディオを保存」設定でオーディオを残す場合にのみノートと一緒に保存されます。一度 Obsidian でノートを開き、パスとラベルが想定どおりか確認してください。

5. 録音が中断された場合

両方のトラックは、復旧用マニフェスト付きの耐久性のあるチャンクとしてディスクに書き込まれます。ストリームが止まった、マイクが抜けた、Vox.md が強制終了された場合でも、それまでに録音されたチャンクを確定して文字起こしできます。復旧は録音キューが再開したとき、たとえば次に Vox.md を開いたときに実行されます。

不完全なキャプチャから作られたノートは、どの部分が欠けていたかを示す警告行で始まるため、文字起こしに抜けがある可能性がわかります。

6. 録音することを相手に伝える

録音に関する法律や職場のポリシーは、地域や組織によって異なります。全員の同意を求めるものもあります。録音と文字起こしをすることを他の参加者に伝え、始める前に同意を得てください。これは法的助言ではありません。ご自身に適用されるルールを確認してください。

7. ミーティングノートの方式を比較する

ミーティングノートのツールは、大きく3つのグループに分かれます。製品はそれぞれ異なり、変化もするため、この表は特定の製品ではなく方式を説明しています。Granola、Otter、Fireflies などのアプリを比較する場合は、音声がどこで処理され、ノートがどこに保存されるかを各ベンダーのドキュメントで確認してください。

8. 長い通話の前に知っておきたい制限

  • 録音ごとに1つのアプリ。 ミーティングキャプチャは、1つのアプリケーションとマイクを録音します。
  • ラベルはベストエフォートです。 話者ラベルはクリーンで分離された音声に左右され、話者の識別では声が統合されたり分割されたりすることがあります。
  • 品質はモデルと言語によって異なります。 大きいモデルほどストレージと時間を多く使います。重要な文言は、頼る前に音声と照らし合わせて確認してください。
  • 録音には Vox.md Unlimited が必要です。 対象のアカウントは7日間の無料トライアルを利用できます。詳しくは プランと価格.
  • Mac の外に出るものもあります。 録音と文字起こしはデバイス上で行われ、文字起こしのために音声がアップロードされることはありません。Whisper または Parakeet モデルのダウンロードでは Hugging Face に接続します。詳しくは プライバシーポリシーを参照してください。話者モデルも1回限りのダウンロードです。保管庫を iCloud Drive や Obsidian Sync で同期している場合、完成したノートはそのサービスの規約に従って同期されます。Vox.md はファイルを書き込むだけで、同期するかどうかはあなたが選びます。

代わりに、声ですばやく入力する方法をお探しですか？Mac の トランスクリプト Clipboard キーバインドは、ローカルの文字起こしをコピーし、ノートを作成せずに任意のアプリへ貼り付けられるようにします。次をご覧ください: Mac の音声入力 と グローバルキーバインド.

すでに録音がありますか? Mac で音声ファイルを文字起こしする。 Zoom または Teams の文字起こしを .srt または .vtt ファイルですでにお持ちですか? SRT/VTT から Markdown へのコンバーター をブラウザー内でノートに変換します。
