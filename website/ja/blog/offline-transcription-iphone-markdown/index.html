iPhone · ローカル文字起こし · Markdown

iPhone で音声をオフラインで Markdown に文字起こし

必要になる前に、音声バックエンドとローカルの保存先を準備します。文字起こしとファイル同期は、別々に選んでください。

作成者
Cody Bontecou
更新日
2026年10月26日
必要条件
準備済みバックエンド · 書き込み可能なフォルダ
短く答えると

Vox.md は、利用可能な Apple Speech バックエンド、または明示的にダウンロードした Whisper や Parakeet のモデルを使い、デバイス上で文字起こしを行います。オフラインで Markdown として保存するには、ローカルで使える書き込み可能なフォルダも必要です。接続を切る前に、両方を準備してください。

「ローカル文字起こし」は、認識処理をどこで実行するかを表します。モデルがすでにインストールされていること、すべての言語に対応していること、クラウド連携フォルダをオフラインで使えることを約束するものではありません。このガイドは、ご自身の端末で行う設定と確認を説明するものであり、すべての対応デバイスで機内モードをテストした報告ではありません。

このガイドの内容
  1. 音声バックエンドを準備する
  2. Markdown の保存先を選ぶ
  3. 音声を録音・読み込み
  4. 手順全体をオフラインで確認
  5. プライバシーと利用可否の制約を理解する

1. 接続中に音声バックエンドを準備

Vox.md のモデル設定で、デバイスと言語に対応するバックエンドを選びます。「自動」は、対応する iOS 26 デバイスと言語では Apple Speech を優先します。任意の Whisper と Parakeet のモデルは、選んだときにダウンロードします。

オフラインになる前に、モデルのダウンロードやシステム言語の準備を完了してください。「自動」が、代替の Whisper や Parakeet を通知なくダウンロードすることはありません。すでに自分で選んでダウンロードした代替モデルだけを使えます。準備済みのバックエンドがなければ、接続を切っても使えるようにはなりません。

Whisper と Parakeet を明示的に選んだ場合、録音停止後に文字起こしします。ライブ Apple Speech は、対応デバイスで暫定テキストと確定テキストを表示できます。Markdown の文字起こしを作るのに、ライブプレビューは必須ではありません。

モデルの選択によって、ストレージ使用量、処理時間、対応言語、認識品質が変わります。次を確認してください。 モデルのリファレンス を確認し、大きなモデルが対応している、あるいは1つの選択肢ですべての言語を認識できると決めつけないでください。

2. Markdown の保存先を選ぶ

キャプチャプレスを作成または選択し、Files でフォルダに保存先を接続します。最初のテストには、出力を見分けやすい新しいノートを選んでください。任意の書き換えをせず文字起こしを使いたい場合は、「オリジナルを保持」の処理から始めると便利です。

保存先がローカルで使え、書き込みを許可しているか確認してください。Files にフォルダ名が表示されていても、内容がダウンロード済みとは限りません。Obsidian の保管庫を選ぶ場合、選択画面から Vox.md がアクセスできる必要があります。Vox.md は Obsidian Sync サービスに直接接続しません。

フォルダの詳しい設定は、次に沿って進めてください。 iPhone の音声メモを Obsidian に保存。通常の書き込み可能な Markdown フォルダでも使えます。文字起こしに Obsidian は不要です。

Vox.md を無料でダウンロード

15分の文字起こしと10回の成功したキャプチャ配信を試せます。無制限利用は1回限りの永久ライセンス購入です。新規設定がオフラインで完了することを前提にせず、購入やモデルの準備は接続中に行ってください。

Apple のボイスメモから始める場合は、次に沿って進めてください。 ボイスメモの文字起こしと音声書き出しの選択画面 を録音の読み込み前に確認してください。

3. 音声を録音または読み込み

  1. 速い捕獲を開き、準備済みの保存先を持つプリセットを選択します。次を選んでください。 下書きに追加 を録音開始前に音声コントロールで選ぶと、最初の文字起こしを確認できます。
  2. 短い音声メモを録音するか、次を使用します。 オーディオまたはビデオを読み込む を音声コントロールで選ぶと、対応する既存のファイルを選択できます。
  3. 選択したバックエンドの認識が終わるのを待ち、ドラフトで文字起こしを確認してから送信します。
  4. 配信が完了したことを確かめ、保存先で Markdown ファイルを開きます。

短い録音から、たとえば次のようなノート本文ができます。

Review the outline before the next meeting.

実際の言葉と句読点は、認識と処理によって異なります。参照が必要なら元の音声を保持し、重要な文字起こしと照合してください。任意の整文機能には、別のデバイス要件と代替動作があります。デバイス上で文字起こしできても、対応するすべての端末で Apple Intelligence の処理を使えるわけではありません。

手順全体をオフラインで確認

接続中のキャプチャが成功したら、接続を切って小さなテストを繰り返します。機内モードを使う場合は、Wi-Fi もオフになっていることを確認してください。

  1. 選択したバックエンドの準備が済み、保存先をローカルで利用できることを確認します。
  2. 接続を切り、新しい短い録音を行って、文字起こしを待ちます。
  3. 文字起こしを確認して送信します。接続を切ったまま、完成した Markdown ファイルを確認してください。
  4. 準備ができたら再接続し、ほかのデバイスへの同期は別途確認してください。

成功とは、認識とローカルへの書き込みの両方が完了したことです。ドラフトに文字起こしが見えていれば、認識できたことは確認できます。ただし、キャプチャがキューに入っただけでは、保存先への書き込みが成功したとはいえません。配信に失敗したら、録音のコピーを増やすのではなく、復元可能なキャプチャを保持し、フォルダへのアクセスを直してから再試行してください。

プライバシーと利用可否の制約を理解する

Vox.md は文字起こしのために音声をアップロードしません。完成した文字起こしや保持した音声を、利用者が意図してクラウド連携フォルダに保存した場合、そのプロバイダが自身の規約に従って同期できます。プロバイダ経由で同期したくないファイルは、ローカルの保存先に置いてください。

録音の長さ、空き容量、音質、モデルの対応状況が、実際の結果に影響します。このガイドは、文字起こしの速度や精度を一律に保証するものではありません。機微な内容や影響の大きい表現は、使う前に確認してください。

Watch の録音では、 文字起こしと配信は、引き続きペアリングした iPhone が行います。端末が使えない間に Watch で録音を保持するのは、配信の遅延であり、Watch 単独の文字起こしではありません。

準備は一度だけ。
接続を切る前に確認してください。

短い録音とアクセス可能なローカルフォルダから始めて、Markdown の出力全体を確認してください。
