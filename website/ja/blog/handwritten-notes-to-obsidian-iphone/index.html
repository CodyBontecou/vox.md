iPhone · テキストを抽出 · 書類をスキャン

iPhone から手書きノートを Obsidian へ

ノートのページを、iPhone 上で認識して、検索やリンクができる Markdown として Vault に取り込みます。

作成者
Cody Bontecou
更新日
2026年11月20日
必要条件
iOS 17.6+ · 書き込み可能な保管庫フォルダ
短く答えると

iPhone で紙のノートをテキストとして Obsidian に取り込むには、Vox.md の テキストを抽出 でページを撮影し、Capture の下書きでデバイス上のテキスト認識を確認して、Vault に書き込む Route へ送信します。ページ画像や PDF も欲しい場合は 書類をスキャン を使います。

Obsidian 内で描きたいですか、それとも紙をデジタル化したいですか? Obsidian 内でスタイラスを使って書きたい場合(iPad の Apple Pencil など)は、次のようなコミュニティプラグインがあります: Ink (プラグイン) と Excalidraw (プラグイン) はそのためのものです。手書きや描画をインクファイルとして Vault 内に保存します。対応内容は各プラグインのページで確認してください。このガイドが扱うのは別のケースで、紙に書いたものを、検索やリンクができる Markdown の文章として残したい場合です。

1. Obsidian で書く場合と紙をデジタル化する場合

4つの方法でほとんどのニーズをカバーできます。Vault に作られるものはそれぞれ異なります。

方法得られるもの向いている用途
スタイラス用プラグイン (Ink、Excalidraw)インクまたは描画ファイルObsidian 内で手書きやスケッチをする
Apple のライブテキストによるコピー&ペースト自分で貼り付けるプレーンテキスト写真からの単発スニペット
Vox.md のジャーナル文字抽出編集できる Markdown テキスト、ページ画像なし検索やリンクをしたい紙のノート
Vox.md 書類をスキャンページ画像、PDF、ベストエフォートのテキスト原本としても残したいページ

コピー&ペーストの方法については Apple が次で説明しています: iPhone でライブテキストを使う。Apple 標準のメモアプリでもできます: テキストや書類をスキャンする。ただし結果は移動するまでメモに残ります。Vox.md はテキストを Vault 内のファイルに直接送ります。

2. 始める前に

  • Vault 内のフォルダ。 設定で、Route を Vault または別の Files フォルダに接続します。Obsidian プラグインもアカウントも不要です。
  • 手書きノート用の Route。 たとえば、次のような New Note パス: Inbox/Handwritten、または次の下に挿入する ローリングノート ## Notebook の見出しの下に、デイリーノートへ追記します。 デイリーノートのガイド で見出しの位置を確認してください。
  • カメラの許可 。Vox.md に対して、初めてページを撮影するときに iOS が確認します。

3. ページを撮影する

  1. Capture コンポーザーを開き、設定した Route を選びます。
  2. キャプチャバー で次を選びます: テキストを抽出、続いて ジャーナルのページを撮影.
  3. ページごとにシャッターを押します。カメラは押したときだけ撮影します。一度に最大10ページまで撮影できます。
  4. デバイス上のテキスト抽出バナーが終わるまで待ちます。

撮影のコツ: 均一な光を使い、ページを平らに置き、文字がフレームいっぱいになるようにして、1回の撮影につき1ページにします。

音声キャプチャまたは文字起こしの実行中は テキストを抽出 を使えません。先にそちらを完了してください。

4. 認識されたテキストを確認する

認識されたテキストは編集可能な Markdown として Capture の下書きに追加されるため、送信前に修正できます。特に名前、日付、数字、取り消し線の入った単語を確認してください。

Vox.md は Apple の Vision テキスト認識を高精度レベルで使い、言語補正と自動言語検出を行います(Apple の Recognizing Text in Images(画像内のテキストの認識))。手書き認識は読みやすさや言語によって精度が変わるため、編集が必要になることを想定してください。

ジャーナル文字抽出はテキストのみを追加します。ページ画像は添付されません。

5. 原本ページを残す

選択 書類をスキャン は、ページそのものが重要な場合に使います。署名、図、スケッチ、法律や金融関係のページなどです。システムの書類スキャナを使い、ページ画像を保存し、PDF を作成し、デバイス上でベストエフォートのテキストを追加します。誤りが含まれることがあるため、送信前にそのテキストを確認してください。

画像と PDF は、ノートの隣に添付ファイルとして書き込まれます。添付ファイルのパスと Obsidian で開けるものについては、次を参照してください: リンク、写真、スキャンを Obsidian に保存する と Obsidian のヘルプ: 対応ファイル形式.

6. 適切なノートへ振り分ける

Route はテキストの送り先を決めます。新規ノート、毎日または毎週のローリングノート、既存ノートの先頭、末尾、または見出しの下です。プレフィックスやテンプレートで次を追加できます: {date} とタイムスタンプを追加できます。以下に3つのレシピを示します。表示されている Markdown は例であり、実際の出力は Route によって異なります。

ノートブックのセッションごとに1つのノート

次のようなパスの New Note Route を使います: Inbox/Handwritten/{date}-{hour}{minute}.md と、次を追加します: source: paper を静的メタデータとして使います。capture では次のような結果になります:

---
source: paper
---
Project kickoff, notebook p. 14
- Ask Dana about the budget
- Send draft by Friday

デイリーノートの見出しの下に追記

期間を毎日にした ローリングノート Route を使い、見出しを選んで、次を入力します: Handwritten のレベル2で、そのセクションの末尾に挿入します。Vox.md に見出しを追加させたい場合は、見出しがない場合の動作を 見出しを作成 に設定します。するとノートには次が追加されます:

## Handwritten
- **09:42** Call the dentist
- Idea: weekly review on Sunday

会議パッドのメモを会議ノートへ

パッドを撮影して Existing Note Route に送るか、次のような New Note パスに送ります: Meetings/{date}-{hour}{minute}.md。これらのノートにアジェンダや決定事項の見出しを付けるには、 議事録テンプレートを生成してください。他の構成については次を参照してください: Obsidian キャプチャテンプレート.

任意の処理: Route の Apple Intelligenceを使用 トグルはデフォルトでオフで、オンにするまで何も実行されません。オンにすると、写真から抽出したテキストもテキストとして扱われるため、処理モード（文章を整える、タスクチェックリスト、会議メモ）を認識したテキストに適用できます。 適用対象 は 音声とテキスト（デフォルト）、音声のみ、テキストのみ から選びます。Apple Intelligence の処理には対応する iOS 26 のハードウェアが必要です。ない場合、タスクチェックリスト は組み込みの整形に切り替わり、会議メモ は認識したテキストをそのまま残します。参照: ルートと設定.

7. すでにある写真

すでにノートを撮影済みの場合は、次を選びます: テキストを抽出 次に ジャーナルの写真を選択 を選び、ライブラリから画像を選択します。同じ認識が実行されます。制限は2つあります。1回の capture につき最大10ページで、ライブラリ全体の一括インポートはできないため、未処理分は10枚ずつ処理してください。まっすぐで明るい写真が最適です。 キャプチャのリファレンス 入力の制限について、および capture 方法の選び方 選択肢を比較している場合。

8. プライバシー

テキスト認識は iPhone 上で実行され、ページの内容は Vox.md のサーバーには送信されません。Markdown がその後どこへ行くかは、iCloud Drive や他の Files プロバイダなど、選んだフォルダのプロバイダによって決まり、同期もそちらが行います。詳細は プライバシーポリシー.

9. トラブルシューティング

  • 「それらのジャーナル画像にテキストが見つかりませんでした。」 より明るく、まっすぐな写真を試し、文字がフレームいっぱいに入るようにしてください。
  • 単語が間違っている、または文字化けしている。 言語検出は自動で、手書きの文字には個人差があります。明るい場所でページを撮り直すか、下書きのテキストを修正してください。
  • テキストを抽出 がグレーアウトしている。 音声 capture または文字起こしが実行中です。先に完了してください。
  • ノートに見出しがありません。 Route の見出しがない場合の動作を 見出しを作成 に設定するか、見出しを自分でノートに追加してください。
