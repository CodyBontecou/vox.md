Mac と iPhone で使えるオンデバイスの Otter.ai 代替

クラウドボット方式とオンデバイス収録を比べ、Vox.md が向いている場面と Otter のほうが適している場面を確認できます。

スケール
macOS 14 以降または iOS 17.6 以降 · 音声認識モデルのダウンロードが必要

Apple デバイス上で動作し、通話に参加せず、Markdown を自分のフォルダや Obsidian の Vault に保存するミーティングと音声の文字起こしがほしいなら、Vox.md は選択肢のひとつです。チームで共有するワークスペース、Web ポータル、Android や Windows が必要な場合は、Otter か別のクラウドツールを使い続けてください。

Otter のしくみの概要

Otter のヘルプセンターによると、会議アシスタントの Otter Notetaker（旧称 OtterPilot）は、Zoom、Microsoft Teams、Google Meet のミーティングに参加します。カレンダーを連携すると、ミーティングリンク付きの予定に参加でき、ミーティングリンクを貼り付けて追加することもできます。匿名では参加できず、ゲスト参加者としてミーティングに表示され、ホストの承認が必要な場合があります。詳しくは Otter Notetaker の概要 と Otter Notetaker をミーティングに手動で追加する.

Otter の 料金ページ には複数のプラン（執筆時点では Basic、Pro、Business、Enterprise）が掲載されています。各プランについて、月あたりの文字起こし時間、1 回の会話の最大長、同時ミーティング数が示されています。これらの上限はプランによって異なり、変更されることがあるため、決める前に Otter の料金ページで最新の上限を確認してください。同じページには、Mac、Windows、iOS、Android 用の Otter アプリ、Chrome 拡張機能、Web 録音も掲載されています。

代替を探す主な理由

以下は読者が抱きそうな理由であり、Otter ユーザーに関する統計ではありません:

  • 通話に見えるボットが入る。 機密性の高い通話や気軽な通話に、余分な参加者を入れたくない人もいます。
  • プランの上限。 月間の文字起こし時間や 1 回あたりの会話の長さはプランによって異なり、利用の多い月や長いセッションは、お使いのプランに収まらないことがあります。
  • 音声が処理される場所。 録音を自分のコンピュータやスマートフォンの中にとどめたい人もいます。
  • ノートは普通のファイル。 ベンダーのアプリ内の文字起こしではなく、フォルダや Obsidian の Vault に Markdown ファイルがほしい人もいます。

どれにも当てはまらなければ、乗り換える必要はないかもしれません。

オンデバイスの選択肢としての Vox.md

Mac では、 入力モードを次に切り替えます: ミーティング。Vox.md は Apple の ScreenCaptureKit フレームワーク を使って 1 つのアプリの音声とマイクを 2 つの別トラックとして録音し、両方を Mac 上で Whisper（ whisper.cpp）または Parakeet（ FluidAudio）。マイクのラベルは次のとおりです: 利用者。任意の スピーカーの識別 は、複数のリモート音声に匿名でベストエフォートのラベルを付けます。通話にボットは入らず、アカウントも不要です。macOS は画面とシステム音声の録音へのアクセスを求めます。これについては Apple が次で説明しています: Mac で画面とシステムオーディオの録音へのアクセスを制御する。詳細は Mac のミーティング収録ドキュメント および ミーティングの手順ガイド.

iPhone では、 対面での録音や、音声・動画のインポートができ、デバイス上で文字起こしし、必要に応じて話者ラベルを付けられます。参照: iPhone の音声メモを Obsidian へ と Mac で音声ファイルを文字起こしする.

メモは標準的な Markdown ファイルで、Obsidian の Vault か、ルートで選んだ「ファイル」のフォルダに保存されます。 会議メモ モードでは次を書き込みます: ## Notes セクションを作成し、テキストにアクションアイテムが含まれる場合は ## Action Items チェックリスト。利用可能な場合は Apple Intelligence を使い、それ以外は決定的なフォーマッタを使います。議題や決定事項などの見出しについては、 議事録テンプレートを生成してください.

料金: 無料ダウンロードには 15 分の文字起こしと 10 回の配信成功が含まれ、無制限での利用は買い切りの生涯購入でサブスクリプションはありません。参照: 無料利用と永久ライセンス、現地の価格は App Store をご覧ください。

知っておきたい Vox.md の制限: ミーティングの収録は一時停止できず、一度に 1 つのアプリだけを録音します。話者ラベルは匿名でベストエフォートです。精度はモデルと音声に左右されます。 Whisper と Parakeet の比較 はモデル選びに役立ちます。

Otter を使い続けたほうがよい場合

  • Windows や Android が必要な場合。 Vox.md は Apple のデバイスでのみ動作します。Otter は料金ページで Windows と Android のアプリを掲載しています。
  • Web ポータルやチームのワークスペースが必要な場合。 Vox.md には共有ワークスペース、Web ポータル、共同編集のリアルタイム文字起こしはありません。ノートは自分で共有するファイルです。
  • 自分が出席しないミーティングにアシスタントを参加させたい場合。 カレンダーから参加するノートテイカーは、Vox.md にはありません。お使いの Mac から直接録音するためです。
  • ミーティングは Otter ですでにうまくいっています 、そして文字起こし時間や長さの扱いがプランに合っていると感じられる場合です。

ミーティング 1 件で試す

  1. Mac の App Store から Vox.md をダウンロードします。
  2. 「モデル」画面を開き、Whisper か Parakeet のモデルをダウンロードします。接続が必要なのはこの 1 回だけです。参照: Whisper と Parakeet の比較.
  3. 作成: ミーティング Vault 内のフォルダに書き込むルート。メモとアクション項目が必要な場合は「会議メモ」モードを使います。
  4. 参加者全員の同意を得たうえで短いテスト通話を録音します。入力モードは次に設定します: ミーティング を設定し、通話アプリを選びます。
  5. Markdown ノートを開き、ラベルと文面が実際の発言と合っているか確認します。

詳しい手順は次のとおりです: Mac のミーティングをローカルで文字起こしして Obsidian へ。Zoom や Teams の字幕ファイルしかない場合は、 SRT や VTT を Markdown に変換 はブラウザ上で動作します。

録音のマナーと同意

録音に関する法律や職場のルールは場所によって異なります。録音と文字起こしを行うことを他の参加者に伝え、事前に同意を得てください。これは法的助言ではありません。参照: 録音することを相手に伝える.

よくある質問

モデルのダウンロード後はオフラインで使えますか？

はい。録音と文字起こしはデバイス上で行われます。Whisper や Parakeet のモデルのダウンロードには一度だけ接続が必要で、話者モデルも一度だけのダウンロードです。クラウド同期されるフォルダに保存した場合は、そのサービスの規約に従って同期されます。

Zoom に参加しますか？

いいえ。通話には何も参加しません。Mac では、Vox.md が選んだアプリ（たとえば Zoom）の音声とマイクを録音します。

既存の Otter のエクスポートや音声ファイルをインポートできますか？

音声ファイルや動画ファイルをインポートして、ローカルで文字起こしできます。ドキュメントには Otter のエクスポートのインポートについて記載がないため、それについては何も主張しません。字幕ファイルの場合は、 SRT/VTT コンバーター はブラウザ上で動作します。

Windows で動きますか？

いいえ。Vox.md は Apple デバイス専用です。iOS と iPadOS 17.6 以降、macOS 14 以降、watchOS 10 以降に対応しています。
