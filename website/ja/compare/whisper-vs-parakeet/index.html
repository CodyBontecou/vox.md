iPhone と Mac での Whisper と Parakeet:どのローカルモデルを選ぶ?

言語、ストレージ、話し方で選び、同じクリップを 2 つのバックエンドに通して Markdown を比較しましょう。

英語では速度が重要なら Parakeet v2、25 の欧州言語には Parakeet v3 を使います。Parakeet にない言語や Auto Detect には Whisper を使います。何もダウンロードしたくない場合は、iOS 26 対応デバイスで自動のままにすると Apple Speech が使われます。

このページはVox.mdが公開しています。2026年11月20日時点でアプリに記載されている内容に基づいて各選択肢を比較しています。当社では独自の精度・速度テストを実施していないため、以下の速度や精度の数値は、提供元の発表を引用し、その旨を明記しています。あなたの声については、 ご自身の音声でテストする が本当の答えです。

Whisper と Parakeet とは

Whisper は OpenAI の音声認識モデルファミリーです。リポジトリでは、複数の音声タスクで学習された Transformer のシーケンス・ツー・シーケンスモデルとして説明され、コードと重みは MIT ライセンスで公開されています。次をご覧ください: github.com/openai/whisper と論文 「Robust Speech Recognition via Large-Scale Weak Supervision」。Vox.md は Whisper を次で実行します: whisper.cpp.

Parakeet TDTモデル はNVIDIAによるものです。モデルカードによると、6億パラメータのFastConformerエンコーダーとTDTデコーダーを備え、CC-BY-4.0のもとで公開されています: parakeet-tdt-0.6b-v2 は英語で、 parakeet-tdt-0.6b-v3 は 25 の欧州言語に対応しています。Vox.md は Parakeet を次で実行します: FluidAudio。Apple デバイス上でローカルのオーディオモデルを動かす Swift SDK で、Core ML を使用します。

3 つ目の選択肢は Apple 自身の Speech フレームワークです。iOS 26 では、Apple が次を文書化しています: SpeechAnalyzer オンデバイス認識用です。Vox.md の自動モードは、対応するデバイスと言語ではこれを優先します。

言語

  • Vox.md の Whisper: 自動検出、英語、スペイン語、フランス語、ドイツ語、イタリア語、ポルトガル語、オランダ語、ポーランド語、ロシア語、中国語、日本語、韓国語、アラビア語、ヒンディー語、トルコ語、ベトナム語、タイ語、ウクライナ語、スウェーデン語、デンマーク語、ノルウェー語、フィンランド語。
  • Parakeet v3: ブルガリア語、クロアチア語、チェコ語、デンマーク語、オランダ語、英語、エストニア語、フィンランド語、フランス語、ドイツ語、ギリシャ語、ハンガリー語、イタリア語、ラトビア語、リトアニア語、マルタ語、ポーランド語、ポルトガル語、ルーマニア語、スロバキア語、スロベニア語、スペイン語、スウェーデン語、ロシア語、ウクライナ語。
  • Parakeet v2: 英語のみ。

Vox.md では、中国語、日本語、韓国語、アラビア語、ヒンディー語、トルコ語、ベトナム語、タイ語、ノルウェー語に対応しているのは Whisper だけです。Parakeet v3 は、ブルガリア語、クロアチア語、チェコ語、エストニア語、ギリシャ語、ハンガリー語、ラトビア語、リトアニア語、マルタ語、ルーマニア語、スロバキア語、スロベニア語など、Vox.md の Whisper 一覧にない複数の言語に対応します。自動はシステム言語に従い、Apple がそのロケールに対応している場合は Whisper の一覧の言語も対象になります。

速度と精度:公表されている情報

これらの数値は各発行元自身の測定で、2026年11月20日に確認したものです。Vox.md の結果ではなく、iPhone や Mac での動作を予測するものでもありません。

  • Parakeet v2 モデルカード (NVIDIA): Hugging Face Open ASR Leaderboard のデータセットで平均単語誤り率 6.05%(貪欲デコード、外部言語モデルなし)。モデルカードによると、RTFx はバッチサイズ 128 で約 3,380 で、「データセットの音声の長さやバッチサイズによって変わる場合があります」とのことです。この数値の GPU は明記されていません。
  • Parakeet v3 モデルカード (NVIDIA): 同じリーダーボードのデータセットで平均 WER 6.34%、多言語セットでは平均 11.97% (Fleurs)、7.83% (MLS)、11.98% (CoVoST)。
  • Whisper リポジトリ (OpenAI): 次の turbo モデルは、最適化された次のように説明されています: large-v3 文字起こしが高速で精度低下は最小限、速度は約 8 倍です。比較対象: large、「A100 での英語音声の文字起こし」で測定。
  • FluidAudio の README: は、M4 Pro での Parakeet v3 のバッチ文字起こしで、リアルタイム係数が約 190 倍と報告しています。

この Open ASR リーダーボード はさらに多くのモデルとデータセットを掲載しています。内容は変わるため、最新の数値はそちらで確認してください。リーダーボードのデータセットはあなたの録音ではありません。結果は、デバイス、アクセント、背景ノイズ、マイク、音声の長さ、選ぶモデルサイズによって変わります。データセンターの GPU で測った速度倍率は、スマートフォンについてはほとんど参考になりません。出典のない「X 倍高速」という主張は慎重に扱ってください。

ストレージとダウンロード

Whisper モデルは 75 MB(Tiny)から 1.6 GB(Large v3 Turbo)まであります。Parakeet の各モデルは約 800 MB です。自動ではご自身でモデルを用意する必要はなく、対応デバイスでは Apple の言語アセットが準備されることがあります。

ダウンロードは依頼したときだけ行われ、進行中にキャンセルでき、後で削除できます。ダウンロードには一度だけネットワーク接続が必要です。選択したバックエンドの準備ができた後は、文字起こしはローカルで実行されます。

iPhone と Mac の違い

  • iPhone: 自動(iOS 26 対応デバイスと対応言語では Apple Speech)、Whisper、Parakeet が利用できます。iOS では自動が既定です。
  • Mac: Models 画面では、Whisper または Parakeet モデルのダウンロード、選択、削除と、文字起こし言語の変更ができます。Whisper は対応する Mac で Metal アクセラレーションを使います。Whisper Base は従来の Mac の既定です。
  • 一時停止での自動停止(どのバックエンドでも可): 約 ~1 MB のオプションの声の停止検出モデルを使うと、話し終えた後にライブ録音を自動で止められます。 設定 → モデルで、 音声自動停止機能 をオンにし、 休憩時間 を選びます(0.5、0.75、1、1.5、2 秒)。アプリでは Automatic、Whisper、Parakeet のいずれでも使えると説明されているため、選択の決め手にはなりません。停止までの時間はおおよそです。参照: 音声キーボードガイド.

Mac のモデル画面については次をご覧ください: Mac の履歴とモデル。通話の録音については次をご覧ください: Mac の会議を Obsidian へ.

両方をご自身の音声でテスト

実際に録音するタイプの音声から 60〜120 秒のクリップを用意してください。気になる名前、数字、アクセントを含めます。機密性のない音声を選んでください。無料枠(文字起こし 15 分、配信成功 10 回)で実行できます。

  1. インターネットに接続した状態で、次を開きます: 設定 → モデル で、比較したい 2 つの候補(たとえば Parakeet v3 と Whisper Small)をダウンロードします。ご自身の言語に対応していないオプションは除外してください。
  2. 次を作成または選択してください: ルート 書き込み可能な Markdown フォルダを指定し、結果が見つけやすいよう新しいノートをターゲットにします。処理にはオリジナルを保持を使うと、AI による書き換えなしで認識されたテキストがノートに入ります。
  3. Quick Capture の音声コントロールで、次を選択します: 下書きに追加。下書きに追加は、完了した文字起こしを送信せずに 1 つの下書きに追記します。
  4. 次で 1 つ目のモデルを選択します: 設定 → モデル、その後クリップを録音するか、次を使います: オーディオまたはビデオを読み込む 既存のファイルで。1 つのファイルをインポートするのが最適です。両方のモデルがまったく同じ音声を聞くことになるためです。
  5. 下書きに短いラベル行(モデル名など)を入力します。次で 2 つ目のモデルを選択してください: 設定 → モデル そして同じクリップをもう一度インポートします。
  6. タップする項目は、 送信 ルートで両方の文字起こしを 1 つの Markdown ノートに配信します。(すぐに送信 は、各文字起こしを完了した時点で個別に配信するため、ノートは 2 つになります。)
  7. ノートを開き、音声と照らし合わせてください。固有名詞、数字、日付、句読点、抜けや重複したフレーズを確認します。また、お使いのデバイスで各文字起こしにかかった時間も記録してください。
  8. 使わないモデルは次で削除してください: 設定 → モデル ストレージを空けるために。

自動がお使いの端末で利用できる場合は、3 回目の実行として追加します。自動を選び、同じクリップをインポートしてください。次をご覧ください: インポートした音声の文字起こし インポートの詳細は オフライン文字起こしの設定 と、接続なしでワークフローを確認する方法は次をご覧ください:

プライバシー

文字起こしはお使いのデバイス上で実行されます。WhisperまたはParakeetモデルをダウンロードする際は、直接またはFluidAudio経由でHugging Faceに接続します。詳細は次をご覧ください: プライバシーポリシー。このダウンロードでキャプチャの内容が送信されることはありません。ノートをクラウド連携フォルダに保存した場合、完成したファイルはそのプロバイダーが独自の規約に基づいて同期します。

制限事項

  • 万能の勝者はいません。最適な選択は、言語、声、マイク、デバイス、そしてストレージ使用量の許容度によって変わります。
  • 上記の公表数値は、各発行元が自社のデータセットとハードウェアで測定したものです。
  • Apple Speech には、対応する iOS 26 デバイスと言語が必要です。それ以外の場合、自動はダウンロード済みのローカルモデルのみを使用します。
  • どのバックエンドを選んでも、重要な文字起こしは音声と照らし合わせて確認してください。

よくある質問

Parakeet は Whisper より優れていますか?

一概にはそうではありません。NVIDIA は Open ASR Leaderboard のデータセットで Parakeet の低い英語単語誤り率を公表していますが、あなたのアクセント、マイク、部屋の環境までは反映されません。Parakeet は英語と欧州言語に向き、Whisper はより多くの言語に対応します。両方をご自身のクリップでテストしてください。

Parakeet は他の言語に対応していますか?

Parakeet v2 は英語のみです。Parakeet v3 は上記の 25 の欧州言語に対応します。Vox.md では、中国語、日本語、韓国語、アラビア語、ヒンディー語、トルコ語、ベトナム語、タイ語、ノルウェー語には対応していません。これらには Whisper を使ってください。

iPhone で Whisper をオフラインで実行できますか?

はい、モデルを一度ダウンロードした後なら可能です。接続中に Settings → Models で Whisper モデルをダウンロードすれば、以降の文字起こしは端末上で実行されます。Markdown をオフラインで保存するには、ローカルで利用できる書き込み可能なフォルダも必要です。

そもそもモデルをダウンロードする必要はありますか?

自動で問題なければ不要です。iOS 26 対応デバイスと対応言語では Apple Speech を使い、ライブテキストが表示されます。お使いの言語やデバイスが非対応の場合や、テストでより良い結果が出た場合に、Whisper または Parakeet をダウンロードしてください。
