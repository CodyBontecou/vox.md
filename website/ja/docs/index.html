    01 / はじめに

    新しいノートの囲い込みを作らず、Markdown にキャプチャ

    Vox.md はローカルを優先したクイックキャプチャアプリです。Files で選んだ Obsidian の保管庫や、その他の書き込み可能なフォルダに、標準の Markdown と添付ファイルを書き込みます。Vox.md のアカウント、プラグイン、ホスト型のノートデータベースは不要です。

    音声の手順全体については、 iPhone の音声メモを Obsidian に送るガイドに沿って進めてくださいで、フォルダの選択から生成された Markdown の確認までを説明しています。

    キャプチャ方法を選ぶなら、次をお読みください。 iPhone のキャプチャ方法を選ぶガイド または Vox.md と Obsidian の標準機能を比較.

    プラットフォーム必要なもの利用できるもの
    iPhone と iPadiOS/iPadOS 17.6+速い捕獲、キーボード、共有シート、ウィジェット、ショートカット、ライブアクティビティ、履歴、設定
    MacmacOS 14+キャプチャ画面、録音・読み込み、ルート、モデル、履歴、メニューバー、グローバルキーバインド
    Apple WatchwatchOS 10+ローカル録音、ルート選択、同期キュー、録音のみの配信、コンプリケーション
    コントロールセンターのコントロールiOS 18+速い捕獲とルート連動の録音操作
    Apple Speech の自動バックエンド対応する iOS 26 デバイスと言語システム管理によるデバイス上のライブ・一括文字起こし
    Apple Intelligence の処理対応する iOS/macOS 26 デバイス代替動作を備えた、デバイス上の整文、構造化出力、独自の指示

    基本の手順。 ルートを選び、保存先を接続し、速い捕獲で入力やコンテンツの追加を行って送信します。ルートが、処理、整形、ノート内への配置を決めます。

    最初のキャプチャを作る

    1. Vox.md を開く。アプリは、内容が保持される Markdown 入力画面を直接開きます。
    2. ルートを選択。組み込みのデフォルトルートは削除できませんが、無効にはできます。少なくとも1つのルートを有効に保ち、保存先を指定してください。
    3. 保存先を設定する。タップする項目は、 目的地設定で、Obsidian の保管庫か Files のフォルダを選び、新しいノート、ローリングノート、既存のノートから指定します。
    4. 内容を追加。Markdown を入力するか、リンク、写真、ファイル、スキャン、スケッチ、位置情報、音声録音を追加します。
    5. 送信をタップ。Vox.md は、選択したルートに保存し、次を表示します。 捕獲 送信。失敗した作業や待機中の作業は、復元できる状態で保持されます。

    権限とシステムへのアクセス

    • マイク： 音声録音、ローカル文字起こし、キーボードリスニング、音声キャプチャに使います。速い捕獲は、録音開始前でも、画面を初めて開いたときにこの許可を求める場合があります。
    • 音声認識： 対応するシステム上の Apple Speech。
    • Files のフォルダへのアクセス： 保存先、テンプレート、読み込み、Watch の録音のみの出力。
    • カメラと選択した写真： はメディア、スクリーンショット、手帳の写真、スキャンを追加する場合にのみ必要です。
    • 使用中の位置情報： は、独立した「現在の位置」キャプチャバーコマンド、または位置取得を有効にしたルートが発生時点の位置を1回取得する必要がある場合に限ります。Vox.md は継続的な位置追跡やバックグラウンドでの追跡を行いません。
    • 通知： 任意の配信状況。操作していないときの Apple Watch の失敗も含みます。
    • キーボードのフルアクセスを許可： が、Vox.md キーボードのデバイス上での共有アプリ連携に必要です。次を参照してください。 キーボードの設定.
    02 / 速い捕獲

    テキスト、メディア、ファイル、音声を扱う、内容が保持される1つの入力画面

    速い捕獲は、iOS と iPadOS の主な作業画面です。ルートメニューで現在の手順を変え、保存先メニューで、このドラフトの配信先をプレビューまたは一時的に上書きします。下部バーからライブラリと設定も開け、ソフトウェアキーボードの表示・非表示も切り替えられます。

    保持されるドラフトと安全な配信

    • テキスト、添付ファイル、選択したルート、保存先の上書き、キャプチャ元は、中断や再起動後も保持されます。
    • 編集は短いデバウンスの後に保存され、アプリをバックグラウンドに移すと、すぐに保存します。
    • 送信の進行中に編集を続けても、新しい編集内容は破棄せず、新しいドラフトに保持します。
    • 配信前に保存先の設定が必要です。入力画面には次を表示します。 設定されていない目的地 を表示し、必要に応じて設定アクションを示します。
    • 再試行可能なキャプチャリクエストはローカルに逐次記録するため、権限、ファイルプロバイダ、同期の失敗後にも再試行できます。
    • 入力画面が空の間は、ルートを選択したりファイルを添付した後も、テキストを加えるまでキャッシュ済みの名言を表示します。名言の取得リクエストにドラフトの内容が含まれることはありません。

    やりたいこと別の手順は、次を参照してください。 リンク、写真、スキャンを Obsidian に保存.

    キャプチャの種類

    テキストと Markdown

    選択範囲を扱える Markdown エディタに直接入力し、既存のテキストを貼り付け、ほかのデータとテキストを組み合わせられます。

    ウェブリンク

    HTTP または HTTPS の URL を、Markdown のリンク形式で追加します。

    写真とカメラ

    写真やスクリーンショットを選ぶか、新しく撮影します。画像は取り込み準備され、配信先のノートに埋め込まれます。

    ファイル

    Files から複数の項目を選択します。画像は埋め込みになり、音声は音声データのまま、その他のファイルは Obsidian 形式のリンクになります。

    書類のスキャン

    VisionKit でページをスキャンします。Vox.md はページ画像を保持し、PDF を作成して、デバイス上で可能な範囲の OCR を行います。

    手帳の OCR

    手動シャッターで手帳を最大10ページ撮影するか、手帳の写真を選択します。高精度の Vision OCR は言語を自動検出します。

    スケッチ一覧

    白い PencilKit キャンバスに黒いペンで描きます。Vox.md は、編集可能な描画データと PNG プレビューを保存します。

    現在の位置アクション

    位置を1回取得し、検証済みの Google Maps 用 Markdown リンクをドラフトに挿入します。この独立したキャプチャバーアクションは、ルートごとの2つの位置設定をどちらも変更しません。

    音声と読み込んだ音声

    入力画面で録音するか音声・動画を読み込み、ローカルで文字起こしして、結果をドラフトに追加するか、すぐに送信します。

    アクセシビリティ：OCR は「このデバイスでテキストを抽出中」の進行バナーを表示します。VoiceOver は、各キャプチャの手順で OCR の進行状況と完了、「キャプチャを送信しました」「文字起こしをキャプチャに追加しました」を読み上げます。

    キャプチャバー

    「設定」→「キャプチャバー」で、アクションの並べ替えや非表示を設定できます。既定ではすべて表示されます。

    アクション動作
    メディア追加スケッチ、カメラ、写真、スクリーンショット、ウェブリンクの選択肢を開きます。
    ファイル追加Files から複数のファイルを選択し、ドラフトとともに取り込み準備します。
    スキャンドキュメント複数ページのスキャン、PDF、ページ画像、可能な範囲の OCR を取得します。
    テキスト抽出OCR を中心にしたキャプチャ用に、手帳ページのキャプチャと手帳写真の選択を提供します。
    九エディタでの直前の操作を取り消します。
    形式 Markdown太字、斜体、ハッシュタグ、見出し1から見出し6を適用します。
    Markdown リンク挿入する内容は、 [link text](url) し、編集可能な部分を選択します。
    内部リンクObsidian 形式の次を挿入します。 [[Target]] ウィキリンク。
    二日目設定今日、明日、今週末を選べます。任意の時刻指定と、±15m、±30m、±1h の調整が可能です。挿入する内容は、 (@yyyy-MM-dd) 、または時刻指定の形式を使います。
    チェックリストMarkdown のタスク接頭辞を適用します。 - [ ].
    弾丸リストMarkdown の箇条書き接頭辞を適用します。
    パスタクリップボードのテキストを現在の選択範囲に貼り付けます。
    スケッチ編集可能な PencilKit スケッチのキャプチャを開きます。
    現在の位置位置を1回取得し、Google Maps リンクを挿入します。
    タイムスタンプを挿入ローカルの日時を次の形式で挿入します。 h:mm a yyyy-MM-dd.
    入力日付挿入する内容は、 yyyy-MM-dd.
    テキストケース変更小文字、大文字、文頭を大文字、各単語の先頭を大文字、スラッグ化の変換を提供します。

    整形は現在の選択範囲に従い、改行を正規化し、不正な選択範囲を補正して、絵文字などの合成文字を途中で分割しないようにします。

    インラインの音声コントロール

    • 音声ボタンをタップして開始・停止します。約0.45秒長押しすると、詳しい操作が表示されます。
    • 録音中は、 一時停止 ボタンが音声ボタンの横に表示されます。1回タップすると一時停止し、もう1回で再開します。最終的なノートは1件の録音のままで、一時停止中の音声と時間は含まれません。再開するまで、文字起こしのライブプレビューと音声の自動停止も一時停止します。
    • 下書きに追加 は、完成した文字起こしを末尾に追加します。 すぐに送信 は、選択したルートとその保存先を使って実行します。
    • 既定では「すぐに送信」を選択 は iOS と Mac のキャプチャ画面で使えます。iOS の音声アクションを次から開くと、 voxboard://capture?action=voice は、その録音を「下書きに追加」に切り替えます。
    • この オーディオ の設定では、指定した場合に元の録音をドラフトの一部として保持します。
    • オーディオ輸入 は音声や動画ファイルを受け付け、同じローカル文字起こしパイプラインを使います。
    • スピーカーの識別 は、録音や読み込んだ音声に対する、任意のルート音声処理ステップです。初回に別の話者モデルを準備し、ローカルで可能な範囲の匿名ラベルを加えます。実行できない場合は、ライブラリに理由を表示し、プレーンな文字起こしを保持します。
    • 「自動」は録音中、確定済みおよび暫定の Apple Speech テキストを、編集可能な入力画面に直接表示できます。Whisper や Parakeet のモデルを明示的に選んだ場合、文字起こしは録音停止後に行われます。
    • 文字起こしに失敗しても、元の録音は失われず、復元できる状態で残ります。
    • 継続的なキーボードリスニングは、明示的に有効にした場合だけ、アプリの起動をまたいで維持します。アプリでの単発録音は、音声セッションを待機状態に戻します。

    キャプチャ入力の上限

    1件のリクエストに含められる上限は、 100,000文字 の共有テキスト、 共有10項目、および 250 MB の合計ステージング容量に対応します。写真とスクリーンショットは最大10項目、手帳のキャプチャは最大10ページを選択できます。Vox.md は上限を超えた項目を通知なく落とすのではなく、超過を拒否します。

    03 / ルート

    フォルダだけでなく、手順全体を保存

    ルートは、キャプチャの意味、テキストを処理するか、メタデータと音声の扱い、Markdown の正確な書き込み先を保存します。ルートは、入力テキスト、リンク、メディア、スキャン、ファイル、スケッチ、音声、ショートカット、ウィジェット、共有シート、Watch、Mac に適用されます。

    ルートを作成・管理する

    • 「設定」→「ルート」で、カスタムルートの作成、名前変更、有効化、無効化、アイコン選択、削除を行えます。
    • 検索可能なアイコン選択画面で、記号を執筆、音声、タスク、個人、仕事に分類しています。
    • 無効なルートは、通常の選択画面には表示されません。組み込みのデフォルトルートは削除できません。
    • 組み込みのデフォルトルートは、波形の記号と、次のプロンプトを使います。 アイデア、タスク、リンク、ファイル、スキャン、録音をキャプチャ。, type: capture メタデータ、文章を整えるへの処理、入力テキスト処理オフ、音声保存オフ。
    • 新しいカスタムルートは、次の状態で始まります。 カスタムルートは、スライダーのアイコンと次を使います。 何をキャプチャしますか？ というプロンプトを使い、独自の指示を選択した状態で始まりますが、入力・混在テキストの処理はオフです。

    処理モード

    モード結果代替動作
    オリジナルを保持AI による書き換えをせず、キャプチャしたテキストを保持します。元のテキストを配信します。
    文章を整える意味と Markdown を保ち、大文字・小文字や句読点を整えます。デバイス上の補助処理を使えない場合の元テキスト。
    タスクチェックリストMarkdown を出力 - [ ] タスク項目です。一定の結果を返すチェックリスト整形機能。
    会議メモ生成する内容は、 ## Notes セクションと、存在する場合は、 ## Action Items.一定の構造を持つ会議ノート。
    カスタム指示利用できる場合、デバイス上の Apple Intelligence で指示に従います。指示をローカルで実行できない場合の元のテキスト。

    音声の文字起こしは、選択したルートのモードを使います。 テキストキャプチャのためのアプリケーション は別途有効化する設定で、既定ではオフです。入力した Markdown、OCR、その他のテキストを含む混在キャプチャの処理を許可します。オフのままなら、自分で書いた Markdown が予期せず書き換わることを防げます。処理済みの正確なリクエストは配信前に保存するため、再試行で変更後の設定を使って処理し直すことはありません。

    メタデータ

    • 静的メタデータは、次の形式で1つずつ入力します。 key: value の組を1行ずつ指定します。例： tags: [journal, idea].
    • ノートのフロントマター は、文書スコープでメタデータを書き込みます。
    • エントリーのインラインフィールド 書き込む内容は、 key:: value フィールドをローリングノートの各項目の横に書き込みます。
    • 利用できる場合、デバイス上の補助処理が、固定のルートメタデータに加えて、タイトル、タグ、カテゴリ、整形済みテキストを追加できます。

    任意の位置情報

    現在の位置は既定でオフで、ルートごとに設定します。有効にすると、Vox.md はキャプチャの発生時に位置を1回取得します。iOS/iPadOS、共有シート、ディープリンク・入力画面、Mac、入力画面を開くシステムアクションでは送信時、直接キューに入れるテキスト・リンク・ファイルのインテントでは呼び出し時、即時音声、キーボード経由のルート録音、ウィジェット・コントロールの録音、通常のキャプチャ配信に送る Apple Watch 録音では停止時です。Watch の「録音のみ」は、Markdown の位置出力を持たない Files への未処理音声書き出しであり、位置を取得しません。Vox.md は、継続的な位置監視やバックグラウンドでの位置追跡を一切行いません。

    設定項目動作
    現在地を使用このルートで発生時点の位置を1回取得し、次を利用できるようにします。 {location}。メタデータを自動的に書き込むことはありません。
    正確（既定）プライバシー処理済みの発生時点の位置を保持し、選択したメタデータで必要な場合には、施設名を含められます。
    都市緯度と経度を小数点以下2桁に丸め、施設名のラベルを省きます。すべての派生フィールドとリンクが、その丸めた座標を使います。
    位置情報メタデータを書き込むに加え、構造化メタデータや高度なメタデータを別途有効化します。 {location} のエントリーテンプレート用リンク。
    構造化フィールド座標、緯度、経度、場所、市区町村、地域、国、Apple Maps、Google Maps、OpenStreetMap、 geo: URI、精度、タイムスタンプ、ソース、キャプチャ ID。
    高度な YAML テンプレートノートのフロントマターに、検証済みで範囲を制限した YAML を使います。無関係なフロントマターは置き換えられず、エントリーのインラインフィールドには使えません。

    「位置情報メタデータを書き込む」が有効な場合、文書スコープは、キャプチャ ID をキーとして、設定したフロントマターのコレクションに各結果を追加します。1つのノートに複数の位置を残せますが、冪等な再試行で同じ位置を重複して追加することはありません。一方、エントリースコープでは、選択した構造化フィールドを次の形式で出力します。 key:: value を、そのキャプチャ項目の横に書き込みます。

    場所、市区町村、地域、国は、有効なメタデータフィールドが必要とする場合だけ、Apple のシステム逆ジオコーダを使います。トークンだけの位置利用では、逆ジオコーディングを行いません。このサービスは無料で API キーも不要ですが、ネットワーク接続を使う場合があります。照会に失敗してもキャプチャは続行し、座標だけのメタデータを使います。エントリーの接頭辞、接尾辞、保管庫内の Markdown テンプレートでは、次を使えます。 {location} を使い、メタデータ出力を有効にせず、ルートで使えるプライバシー処理済みの位置から、クリック可能な Google Maps リンクを挿入します。「現在の位置」がオフか取得不能の場合、トークンは空になります。プロバイダのリンクを作るだけでは、Apple、Google、OpenStreetMap に接続しません。リンクを開くと、そのリンク内に保存された正確または丸め済みの座標が、該当プロバイダに渡ります。

    新しいルートと、以前無効だったルートは、両方の設定をオフに保ちます。すでに位置メタデータを書き込んでいたルートは、更新後も両方をオンに保ち、従来の出力を維持します。

    現在の位置の完全ガイド

    参照先： 現在の位置、 {location}、およびメタデータ で、設定パターン、例、キャプチャ元ごとの取得タイミング、移行時の動作、プライバシー、トラブルシューティングを確認してください。

    位置を取得できない場合

    操作可能な画面では、再試行、キャンセル、今回だけ位置なしで送信、または次を選べます。 常に位置なしで送信 をそのルートで選べます。保存した選択は、ルートの位置設定でリセットします。無人実行の、 尋ねる キャプチャは、利用者が判断するまで、発生時に位置を取得できなかった結果を保持します。再試行や復元で、後の位置を再取得することはありません。

    Markdown の保存先

    各ルートには、Obsidian の保管庫または書き込み可能な Files フォルダを起点とする保存先が1つあります。

    新しいノート

    次のようなトークンを使い、キャプチャごとに独立した Markdown ファイルを作成します。 {timestamp}, {date}, {time}, {year}, {YR}, {month}, {day}, {id8}、および {id}.

    ローリングノート

    日、週、月、四半期、年単位のノートに追加します。パスには、次も使えます。 {period} と {week}。新しい保存先の既定は、 Journal/{period}.md で日単位の期間を使います。

    既存のノート

    選択した保管庫やフォルダの中にある Markdown ファイルを選びます。Vox.md は、対象が安全にそのルート内に収まっていることを確認します。

    ルートのレシピ全体は、次を参照してください。 テキストと音声を Obsidian のデイリーノートに追加.

    受信ノート、日記、タスク用テンプレートのレシピを使う でエントリーの書式を一定に保ちます。

    挿入位置、見出し、テンプレート

    • 底 で末尾に追加します。 TOP で先頭に追加します。 ヘッド は、レベル1から6までの指定した見出しの下に挿入します。
    • 見出しがない場合は、次を選択します。 エラー表示 または 創出ヘッド.
    • 保管庫内の Markdown テンプレートファイル、再利用可能な入り口 寺、または独自の接頭辞・接尾辞を使います。
    • エントリーの書式で使えるものは、 {date}, {time}, {hour}, {minute}, {second}, {timestamp}, {year}, {YR}, {month}, {day}, {week}, {source}, {id8}, {id}、および {location}.
    • 既定の添付ファイル用サブフォルダは、 attachments.
    • 保護回復は既定でオフで、表示可能な次の内容を書き込みます。 vox-capture HTML コメントを書き込み、重複した再試行を検出できるようにします。
    • Vox.md は、絶対パス、バックスラッシュ、パストラバーサル、安全でない名前、シンボリックリンクによる範囲外へのアクセスを拒否します。

    1回のキャプチャに限る上書き

    保存先のコントロールでは、ルートの既定値、このキャプチャだけを先頭や末尾に配置、今回限りの入り口 寺の適用、同じ保管庫の別のノートの選択ができます。 ルートの保存先のデフォルトを使用 は、上書きを解除します。これらの選択は現在のドラフトだけに作用し、ルートを変更しません。

    音声の保持と互換性のための書き出し

    • 音声の保存モードは、 オフ, ノートと同じ場所、または 添付フォルダ.
    • Markdown には、次のような Obsidian 構文で、保持した音声を先頭や末尾に埋め込めます。 ![[recording.m4a]].
    • 統合された Markdown 保存先がない従来の直接音声設定では、 メモをファイルに保存 は TXT、MD、JSON、YAML、新規ファイル作成と追記、モデルや言語などのファイル名トークン、Markdown テンプレート、Obsidian Bases の設定、選択可能な YAML プロパティ、任意の次の機能に対応しています。 .md 拡張子を YAML に使います。
    • 互換性書き出し設定は、統合されたキャプチャ保存先がルートにない、直接音声実行にのみ適用します。
    04 / モデルと文字起こし

    システムのバックエンドか、任意のローカルモデルを選ぶ

    文字起こしはすべて Apple デバイス上で行われます。iOS の既定は「自動」です。任意の Whisper と Parakeet のモデルファイルは、利用者が指定した場合だけダウンロードし、選択、ダウンロード中のキャンセル、後からの削除ができます。

    オフラインの文字起こし手順を準備する をローカルバックエンドと書き込み可能な保存先で使います。

    利用できる文字起こしの選択肢

    選択肢おおよそのサイズ最も合う用途
    自動システムが管理対応する iOS 26 デバイスと言語では Apple Speech を優先し、利用者が明示的にダウンロードしたローカルモデルにのみ切り替えます。
    Whisper Tiny75 MBWhisper で最小のダウンロード容量と最速の選択肢。
    Whisper Base142 MBバランスのよい小型ローカルモデル。以前の Mac の既定。
    Whisper Small466 MBより高い精度。ストレージと処理の負担も増えます。
    Whisper Medium1.5 GB多言語対応の大きな Whisper モデル。
    Whisper Large v3 Turbo1.6 GB利用できる中で最大の Whisper モデル。
    Parakeet v2~800 MB英語向けに最適化した Core ML/FluidAudio モデル。
    Parakeet v3~800 MB25言語に対応した Core ML/FluidAudio モデル。

    「自動」の仕組み

    • 対応する iOS 26 デバイスでは、「自動」が選択言語の Apple システム管理 Speech 認識器を確認し、必要に応じて言語アセットを準備します。
    • システム言語 はデバイスの言語に従います。録音が別の言語なら、その言語を明示的に選んでください。
    • 「自動」が通知なく代替の Whisper や Parakeet をダウンロードすることはありません。以前に利用者がダウンロードを選んだモデルだけを使えます。
    • ライブ Apple Speech は、安全に挿入できる確定済みテキストと、まだ変わり得る暫定テキストを区別します。
    • Whisper と Parakeet を明示的に選ぶ場合は、セグメント終了後に一括で文字起こしします。

    言語

    • Whisper: 自動検出、英語、スペイン語、フランス語、ドイツ語、イタリア語、ポルトガル語、オランダ語、ポーランド語、ロシア語、中国語、日本語、韓国語、アラビア語、ヒンディー語、トルコ語、ベトナム語、タイ語、ウクライナ語、スウェーデン語、デンマーク語、ノルウェー語、フィンランド語。
    • 自動： システム言語に加え、Apple がそのロケールに対応している場合は、Whisper に明示的に掲載された言語を使えます。
    • Parakeet v2: 英語。
    • Parakeet v3: ブルガリア語、クロアチア語、チェコ語、デンマーク語、オランダ語、英語、エストニア語、フィンランド語、フランス語、ドイツ語、ギリシャ語、ハンガリー語、イタリア語、ラトビア語、リトアニア語、マルタ語、ポーランド語、ポルトガル語、ルーマニア語、スロバキア語、スロベニア語、スペイン語、スウェーデン語、ロシア語、ウクライナ語。Parakeet では言語を自動検出します。

    Parakeet キーボードの自動停止

    任意の約1 MB の 声の停止検出 モデルは、明示的に選んだ Parakeet v2 または v3 のキーボード録音を、無音の後に停止できます。次を有効にしてください。 無音の後に Parakeet を停止する で約0.5、0.75、1、1.5、2秒から選択します。補助モデルが利用可能になると、既定では0.75秒の無音で停止する設定が有効になります。「自動」と Whisper は、引き続き手動で停止します。

    ローカル音声の動作

    • Whisper の入力は、16 kHz、モノラル、16ビットの音声に正規化します。
    • iOS の継続リスニングは10分の循環バッファを使い、セグメント開始時に2秒のプリロールを含めます。
    • Whisper が使うのは、 whisper.cpp。Parakeet は FluidAudio と Core ML を使います。Whisper は Mac で Metal による高速化を使います。
    • モデルのダウンロードにはネットワーク接続が必要ですが、選択したバックエンドの準備後は、ローカルで文字起こしできます。
    05 / iOS キーボード

    編集中のテキスト欄にそのまま音声入力

    Vox.md のキーボードは、メッセージ、メモ、メール、Safari、Slack など、標準の iOS キーボードを受け付けるアプリで使えます。KeyboardKit レイアウトの上に音声ツールバーが表示され、非公開の共有 App Group を通じてメインの Vox.md アプリと通信します。

    キーボードを設定する

    1. Vox.md で文字起こしを準備。対応デバイスでは「自動」を選んだまま使うか、「設定」→「モデル」で Whisper または Parakeet をダウンロードして選択します。
    2. キーボードを追加。iOS の「設定」→「一般」→「キーボード」→「キーボード」→「新しいキーボードを追加」を開き、Vox.md を選択します。
    3. 「フルアクセスを許可」を有効にする。現在のキーボードの手順では、共有 App Group の状態を使い、メインアプリと録音を連携するために必要です。
    4. キーボードを切り替える。テキスト欄を開き、地球儀キーで Vox.md を選んで、マイクをタップします。
    ここでのフルアクセスの役割

    iOS の権限名は広い意味を持っています。Vox.md は、デバイス上のアプリとキーボードの連携、状態の共有、任意の触覚フィードバックに使用します。Vox.md は、キー入力、音声入力のテキスト、文字起こし、マイク音声を Vox.md のサーバーにアップロードすることはありません。次を参照してください。 プライバシーポリシー.

    音声ツールバーと挿入

    • ツールバーには、現在のバックエンド、状態、録音時間、リアルタイムの波形、マイク・停止アクションが表示されます。
    • 前後のコントロールで、利用可能なダウンロード済みバックエンドを順に切り替えます。
    • リスニングが有効でない場合、キーボードは Vox.md を一度開いてリスニングを開始し、元のテキスト欄に戻ることができます。
    • 「自動」では、話している間に確定した文字起こしの差分を挿入します。暫定の単語は、Apple が確定するまで表示のみにとどまります。
    • Whisper または Parakeet では、停止またはセグメントの自動停止後に、完成した文字起こしを挿入します。
    • 挿入が中断または一時停止された場合、待機中のテキストを永続化し、次にキーボードが表示されたときに再試行します。
    • ツールバーには、次のような状態が表示されます。 オープン Vox.md, 翻訳...、および フルアクセスを有効にする.

    キーボードのカスタマイズ

    • 触覚フィードバック は既定で有効です。Vox.md の設定で変更できます。
    • 英語、ドイツ語、スペイン語、フランス語、イタリア語、ポルトガル語、オランダ語、スウェーデン語、デンマーク語、ノルウェー語では、長押しで代替文字の候補を表示できます。
    • Parakeet を明示的に選んだ場合、「設定」→「モデル」から、無音に基づく自動停止を追加できます。
    • 15分の無料文字起こし枠は、アプリ内の録音や読み込みに加え、キーボードの音声入力にも適用されます。
    06 / システム連携

    共有シート、ホーム画面、ロック画面、ショートカットからキャプチャを開始

    共有拡張機能

    iOS の共有シートのアクション名は、 Vox.mdにキャプチャ。テキスト、HTTP/HTTPS URL、画像、ファイル、動画を、共通の項目数とアセット容量の上限内で受け付けます。ルートと保存先を選び、任意のメモを加えて送信します。そのルートで現在の位置を使う場合、共有機能はメタデータ出力の有無にかかわらず、この送信操作時に発生時点の位置を1回取得します。内容は非公開の App Group に取り込み準備され、永続的なキューに入れられ、配信のために Vox.md で開かれます。メインアプリが必要な配信では、次を使います。 オープン Vox.md.

    ホーム画面とロック画面のウィジェット

    速い捕獲

    内容が保持される Markdown ドラフトを開きます。中・大サイズのウィジェットには、ノート、写真、スクリーンショット、カメラ、ファイル、リンク、スキャン、スケッチ、音声のアクションがあります。

    速記録

    設定した録音手順を開始し、対応するホーム画面・ロック画面の表示形式で、準備完了、リスニング中、無効の状態を示します。

    ウィジェットの安全設定

    設定でロック画面の録音ボタンをオフにすると、すぐに録音を開始せず、オフの状態が表示されます。

    コントロールセンター、ライブアクティビティ、Dynamic Island

    • iOS 18+ では、コントロールセンターから利用可能な Vox.md のキャプチャ・録音コントロールを追加できます。インストール済みのバージョンで表示されるルートと設定を指定してください。
    • 録音コントロールを使う前に、Vox.md でマイク、モデル、保存先の設定を完了してください。iOS とアプリのバージョンによっては、録音時にアプリが開きます。バックグラウンドでのキャプチャに頼る前に、お使いのデバイスで短い録音を試してください。
    • この ライブアクティビティモニタ の設定で、ロック画面と Dynamic Island の録音状態と録音・停止操作を制御します。
    • ライブアクティビティには、録音中、タイマー、処理中、準備完了、録音、停止の状態を表示します。
    • ライブアクティビティは iOS 17 から利用でき、コントロールセンターのコントロールには iOS 18 が必要です。

    ショートカットと App Intents

    ルートは、ショートカットや対応コントロールで選択可能なエンティティとして表示されます。「現在地を使用」が有効な場合、直接キューに入れるテキスト・リンク・ファイルのインテントは呼び出し時に、速い捕獲を開くアクションは送信時に、録音アクションは録音停止時に位置を取得します。メタデータ出力の有無で、このタイミングは変わりません。無人実行の次のリクエストでは、 尋ねる リクエストで位置を取得できない場合、発生時点で取得不能だった結果を保持し、再取得せずに後で対応を選べるようにします。インストール済みの Vox.md で使える操作を選んでください。キャプチャの操作には次があります。

    • 速いキャプチャー
    • 記録 捕獲
    • スクリーンショットを撮影
    • テキストをキャプチャ Markdown
    • キャプチャリンク to Markdown
    • ファイルをキャプチャ Markdown

    アクションボタンの録音設定

    Vox.md を一度開き、マイクの許可、文字起こしバックエンドの準備、ルートと保存先の接続を行います。ショートカットで利用可能な Vox.md のキャプチャアクションを追加し、ルートを選択します。「設定」→「アクションボタン」→「ショートカット」に割り当てる前に、端末のロックを解除した状態で実行し、意図したノートに保存されるか確認してください。

    利用可能なアクションとバックグラウンド録音の動作は、インストール済みのバージョンと iOS によって異なります。デバイスのショートカットに表示されるアクションを使ってください。録音にアプリの起動が必要なら、Vox.md を開いて録音します。選択画面にショートカットがあるだけでは、ロック中の端末から録音できる保証にはなりません。

    ディープリンク

    Vox.md が登録するのは、 voxboard:// の URL スキーム。クエリの値は URL エンコードしてください。

    URL動作
    voxboard://capture内容が保持される速い捕獲入力画面を開きます。
    voxboard://capture?action=photos写真の選択画面を開きます。その他のアクション： screenshots, camera, files, scan, sketch, link、および voice.
    voxboard://capture?text=...長さを制限したテキストを含むドラフトを開きます。
    voxboard://capture?url=https%3A%2F%2F...HTTP/HTTPS リンクを含むドラフトを開きます。
    voxboard://capture?route=...有効なルートを選びます。対応するアクション、テキスト、URL と組み合わせられます。
    voxboard://capture-request?id=...システム拡張やインテントが作成した永続リクエストを引き受けます。
    voxboard://listenキーボードのリスニング開始手順を起動します。
    voxboard://record従来の録音開始方法を、リスニングに転送します。
    voxboard://widget-record従来のウィジェットからの録音開始方法。

    不明または重複したパラメータ、不正な UUID、安全でないルート識別子、HTTP 以外の URL、共通上限を超えたテキストは拒否します。

    07 / Apple Watch

    Watch でローカル録音し、iPhone 経由で配信

    Apple Watch から Obsidian への設定ガイドに沿って進む で、ルート選択、転送、配信の確認を行えます。

    録音の手順

    • Watch アプリには、準備完了、録音中、一時停止中、同期中、待機中、文字起こし中、保存中、送信済み、対応が必要、の状態を表示します。
    • 録音、一時停止・再開、停止、キャンセル、同期、更新を使います。一時停止すれば、ノートを分割せずに考えを整理できます。一時停止中はタイマーも止まり、その時間は録音に含まれません。キャンセルは同期ではなく、ローカル録音を明示的に削除します。
    • 録音はローカルに逐次記録され、中断やクラッシュの後に復元されます。
    • 録音は、iPhone が配信または破棄を確認するまで Watch に残ります。
    • 「現在地を使用」が有効で、通常のキャプチャ配信を使うルートでは、Watch が録音停止時に Watch 側で位置を1回取得し、プライバシー処理済みの結果をルートのスナップショットとともに転送します。iPhone 自身の位置に置き換えることはありません。「録音のみ」は Markdown への出力面を持たず、未処理の音声を書き出すため、位置取得を行いません。

    Watch のルート

    Watch の次の項目から、有効な iPhone ルートを選択します。 ルート カードを使います。Vox.md は、安全なスナップショットを録音とともに転送します。iPhone が利用できない場合、要求した選択は保留となり、最後に確認済みのルートが有効なままになります。

    iPhone の Watch 録音キュー

    iPhone のキューには、録音時刻、長さ、ルート、処理状態、配信操作が表示されます。失敗した項目は、再試行、ルートの変更、破棄、文字起こしなしのキャプチャが可能です。破棄すると、保持されていた音声と待機中の配信が削除されます。

    「録音のみ」の出力

    • ルートの出力を次に設定します。 録音のみ で、文字起こし、AI 処理、文字起こし枠の消費をせず、M4A 音声を Files のフォルダにコピーします。
    • 既定のファイル名テンプレートは、 recording-{timestamp}-{id8}.
    • ルートを使う前に、iPhone で録音フォルダを一度選択してください。
    • iOS により、バックグラウンド配信が遅れる場合があります。Vox.md を強制終了すると、アプリを再び開くまで配信できません。

    コンプリケーションとウィジェット

    この 音声ノートレコード コンプリケーションは、円形、長方形、インライン、コーナーの各ファミリーに対応しています。Watch のローカル録音を開くか切り替え、タイマーや状態に応じたラベルを表示します。

    08 / Mac コンパニオン

    macOS でも同じキャプチャシステムを使う

    Mac アプリには、キャプチャ、ライブラリ、設定があり、iOS と同じローカルモデル、ルート、ルート処理、書き出し、再試行のアーキテクチャを共有します。

    キャプチャのワークスペース

    • Markdown の入力と編集、貼り付け、ファイル・画像・音声のドラッグ＆ドロップ。
    • 内蔵カメラ、外部カメラ、連係カメラの入力を使います。
    • スキャンや PDF の読み込み、マウス・トラックパッド・接続したタブレットでのスケッチ作成、リンク、ウィキリンク、期限、テキスト変換の追加ができます。
    • 録音に使う項目は、 下書きに追加 または すぐに送信。必要に応じて、ドラフトモードで音声を保持します。
    • 一時停止 と 再開 をステータスバーからマイク録音に適用します。一時停止中の音声は含まれないため、1つの完成ノートを何回かに分けて録音できます。会議キャプチャは一時停止しません。
    • 音声や動画を読み込み、ローカルで文字起こし。
    • Command-Return を押してキャプチャを送信します。「現在地を使用」が有効なルートは、メタデータ出力の有無にかかわらず、送信時または録音停止時に Mac で位置を1回取得します。
    • 保存先の設定バナーとルートの詳細画面に、選択したルートが解決するノートと挿入位置が表示されます。

    ステムを分けたミーティングのキャプチャ

    入力モードの選択を、次から切り替えます。 マイク への ミーティング を使い、Mac のアプリが再生する音声と自分のマイクを、明確に分かれた2つの音声トラックとして録音します。Vox.md は ScreenCaptureKit の単一アプリケーションモードを使うため、アプリを1つだけ正確に指定し、Vox.md 自体をキャプチャすることはありません。

    • 録音中は、ステータスバーにシステム音声とマイクのリアルタイム音量メーター、入力元ごとの状態、キャプチャの警告を表示します。
    • 両方の音声トラックは、復元用マニフェストとともに永続化されるチャンクとして書き込まれます。ストリームの停止、マイクの取り外し、強制終了などの中断が起きても、安全に確定処理され、会議を文字起こしできます。中断されたセッションは、次に録音キューが再開するときに自動的に復元されます。
    • 停止後、各音声トラックをデバイス上で個別に文字起こしし、共通のタイムラインに結果を交互に並べます。自分のマイクは、次のように表示されます。 利用者、アプリケーションの音声トラックにはリモート話者のラベルを付けます。任意の話者識別を使うと、複数のリモート音声をさらに分けられます。
    • 両方の音声トラックをミックスした再生用音声を、録音の音声として保持します。完成した文字起こしは、ほかの録音と同様、ルート、「下書きに追加」または「すぐに送信」、クリップボードの設定に従います。

    グローバルキーバインド

    「設定」→「グローバルキーバインド」で次の操作にショートカットを割り当てられます。 トランスクリプト Clipboard, 選択中のルート、または有効な任意のルートを指定できます。ショートカットは既定でオフで、修飾キー以外のキーに Control、Option、Command のいずれかを組み合わせる必要があります。Shift も追加でき、競合は拒否します。有効なショートカットをもう一度押すと、録音を停止します。

    トランスクリプト Clipboard は、ノート、ライブラリ項目、保持する音声を作成しません。Mac の任意のアプリにすばやく音声入力するための機能です。

    メニューバーとアプリの表示

    • 表示方法の選択肢は、 ドック + メニューバー （既定）、 メニューバーのみ, ドックのみ、および 隠し.
    • メニューバーに、録音中、文字起こし中、書き出し中の状態を表示します。
    • メニューには、録音開始、停止して文字起こし、音声の読み込み…、直前の文字起こしをコピー、直前の書き出しを表示、ルート選択、キャプチャを表示、ライブラリを表示、データフォルダを表示、Vox.md を終了、があります。
    • Mac アプリで Control-B を押すと、クリックできる操作の上にキーボードのヒントを表示します。

    Mac の履歴とモデル

    ローカル履歴の検索、再読み込み、消去、コピー、削除、整形済み・未加工の文字起こし詳細の表示、配信済みノートの Finder 表示ができます。モデル画面では、Whisper または Parakeet のモデルのダウンロード、選択、削除と、文字起こし言語の変更ができます。Whisper は対応する Mac で Metal による高速化を使います。

    09 / ライブラリ、設定、プライバシー

    作業の復元、ローカルデータの管理、無制限利用の解除

    iOS の統合ライブラリ

    • ライブラリでは、ローカル音声の文字起こしとキャプチャ配信の記録を、検索可能な1つのリストにまとめます。
    • 未加工のテキスト、整形済みテキスト、タイトル、タグ、カテゴリを検索し、引いて更新できます。
    • 整形済みまたは未加工の文字起こしテキストのコピー、文字起こしのメタデータと本文の編集、共有シート経由での Markdown コピーの書き出しができます。
    • 文字起こしを1件削除するか、ローカル履歴をすべて消去します。履歴を消去しても、保存先にすでに書き込んだ Markdown ノートや添付ファイルは削除されません。
    • 待機中のキャプチャを再試行し、大まかなキャプチャ元、ルート、保存先、ノートのパス、添付数、時刻、結果、失敗の分類を確認します。
    • 文字起こしの編集項目には、タイトル、タグ、カテゴリ、整形済みテキスト、未加工の文字起こしがあります。

    個人活動の国

    「設定」→「アクティビティ」→「統計」で、これまでの利用状況を確認できます。録音とキャプチャの総数、録音時間、添付数に加え、直近7日間のグラフと、キャプチャ元の内訳（アプリ、キーボード、共有シート、ウィジェット、ショートカット、Apple Watch、Mac、ディープリンク、ファイル読み込み、音声）を表示します。

    • 統計は配信済みのキャプチャのみを集計します。新しい操作の後は、引いて更新してください。
    • 利用記録はデバイス内に残り、キャプチャした内容、ファイル名、保存先は記録しません。

    無料利用と永久ライセンスの解除

    • 無料利用には次が含まれます。 15分の文字起こし と 10回の成功したキャプチャ配信.
    • 文字起こし時間を消費済みの音声テキストを Markdown に送っても、別のキャプチャ利用枠を重ねて消費することはありません。
    • 書き込みの失敗と冪等な再試行は、成功したキャプチャ配信枠を消費しません。
    • 無制限利用は1回限りの永久ライセンス購入で、サブスクリプション、更新料、広告はありません。地域別の App Store 価格が正式な価格です。米国価格は個人用 $19.99、ファミリー用 $39.99、ファミリーへのアップグレード $19.99 で、ほかのストアでは購買力に応じた価格を設定しています。
    • 「購入を復元」で、対象となる購入を復元できます。条件を満たす旧有料版の利用者は、従来の権利として無制限利用を引き継ぎます。
    • 内容を含まない App Group の利用記録が、ローカルアプリデータの残る間、再試行での重複消費を防ぎます。キーチェーンには保存しません。ローカルアプリデータを削除すると、無料枠が新しく始まります。

    ローカルにとどまるもの

    キャプチャ内容

    ドラフト、テキスト、リンク、テンプレート、ルート、添付ファイル、音声、OCR、文字起こしは Vox.md のサーバーに送信しません。

    加工

    Apple Speech、Whisper、Parakeet、Vision OCR、対応する Apple Intelligence の処理は、デバイス上で実行します。

    あなたの保存先

    完成したファイルは、選択したフォルダにのみ保存されます。サードパーティのファイルプロバイダが、自身の規約に従って同期する場合があります。

    • 配信成功後、復元可能なキャプチャリクエストは内容を含まない受領記録となり、完了した Watch キューの項目には、大まかな最終配信フィールドだけを残します。どちらにも、座標、ラベル、プロバイダ URL、位置テンプレート、ルートの内容を保持しません。
    • 完了したキャプチャ履歴には、配信メタデータを保存します。ノートのテキスト、URL、座標、位置ラベルやテンプレート、ブックマーク、絶対パス、添付ファイル名は保存しません。
    • 保留中や失敗した項目は、ローカル復元に必要なものだけを保持します。ルートのスナップショットと、すでにプライバシー処理済みの位置または取得不能の結果が含まれる場合があります。
    • 製品版の導入分析は、既定で無効です。アプリには、サードパーティの分析 SDK、広告ネットワーク、アプリ横断の追跡機能は含みません。
    • 入力画面は、ドラフトの内容や識別子を送らずに、ZenQuotes から名言を取得してキャッシュします。

    データの取り扱い、保持期間、サードパーティサービスの詳細は、次をお読みください。 プライバシーポリシー.

    10 / トラブルシューティング

    よくある設定・配信の問題

    キャプチャを送信できない

    保存先のコントロールを開き、選択したルートを設定します。フォルダを移動したかアクセス権が期限切れの場合は、保管庫やフォルダを選び直してください。待機中の作業はライブラリに残っています。

    キーボードに「フルアクセスを有効にする」と出る

    iOS の「設定」→「一般」→「キーボード」→「キーボード」→ Vox.md を開き、「フルアクセスを許可」を有効にします。アプリに一度戻り、Vox.md が共有リスニングの手順を再開できるようにしてください。

    「自動」を利用できない

    Apple Speech の「自動」には、対応する iOS 26 デバイスと言語が必要です。Whisper または Parakeet のモデルを選んでダウンロードし、明示的に選択するか、「自動」に戻すと、利用者が承認した代替モデルとして使えます。

    文字起こしに失敗

    選択したモデルのダウンロードが完了し、言語が適切か確認してください。Vox.md は、可能な場合に復元用の元音声を保持するため、別のモデルを選んで再試行できます。

    見出しを指定したルートが失敗する

    ルートの保存先を編集し、見出しのテキストとレベルを確認します。見出しがないときに停止せず作成したい場合は、「創出ヘッド」を選んでください。

    Watch の録音が待機中

    iPhone で Vox.md の Watch 録音を開きます。更新や再試行を行い、求められた場合は有効なルートを選んでください。バックグラウンドの引き継ぎができるよう、アプリをインストールしたままにします。強制終了すると、再び開くまでバックグラウンド配信できません。

    {location} は空で出力されます

    配信するルートで「現在地を使用」をオンにします。検出されたエントリー接頭辞、接尾辞、再利用可能な入り口 寺では、入力画面のワンタップ修正で、メタデータを有効にせず設定できます。保管庫内のテンプレートファイルには、手動でルートを設定する必要があります。権限を使えない場合や、位置なしでキャプチャを続行した場合、トークンは意図的に空になります。次を参照してください。 位置情報の完全ガイド.

    ルートの位置情報を取得できない

    再試行は、元の対話的な送信を解決している間だけ使います。代わりに、キャンセル、今回だけ位置なしで送信、そのルートで常に位置なしで送信、を選べます。保存した選択は、ルートの位置設定でリセットできます。無人実行でキューに入ったリクエストは、元の取得不能の結果を保持し、新しい位置を取得しません。

    まだ解決しませんか？

    「設定」→「デバッグログを表示」を開き、「フィードバックを送信」を使うと、アプリのバージョン、プラットフォーム、OS、デバイスの詳細を含められます。次に参加することもできます。 Isolated Tech の Discord.
