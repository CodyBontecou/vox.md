    Ubicación actual, {location}, y Metadatos

    Usa una única ubicación del momento de origen en el formato de entrada sin añadir automáticamente YAML ni campos en línea. Obtener la ubicación y generar metadatos son decisiones explícitas e independientes en cada ruta.

    Actualizado el 21 de agosto de 2026 Obtención puntual Sin seguimiento en segundo plano Guía completa de funciones
    01 / Descripción general

    Obtener la ubicación no implica generar metadatos

    Cada Ruta tiene dos controles de ubicación independientes. Usar ubicación actual determina si la ruta solicita una ubicación en el momento de origen. Escribir metadatos de ubicación decide si esa instantánea obtenida también se escribe como metadatos iniciales o campos en línea.

    ControlQué significaQué no significa
    Permiso de ubicación del sistemaPermite que Vox.md solicite la ubicación mientras se usa la app o una interfaz de captura compatible.No activa la ubicación para ninguna Ruta.
    Usar ubicación actualSolicita una ubicación para esta ruta y la pone a disposición de {location}.No escribe automáticamente YAML ni metadatos en línea.
    Escribir metadatos de ubicaciónEscribe los campos estructurados seleccionados o el YAML avanzado validado a partir de la instantánea obtenida.No controla si {location} puede generar.
    La señal de intención es la ruta, no el permiso

    Conceder permiso Mientras se usa solo abre el acceso del sistema operativo. Vox.md sigue solicitando la ubicación únicamente para la acción independiente Ubicación actual de la Barra de captura o para una Ruta en la que hayas activado Usar ubicación actual.

    02 / Configuración

    Configura Ubicación actual para una ruta

    1. Abre Rutas.En iPhone o iPad, abre Ajustes → Rutas. En Mac, abre Ajustes y elige Rutas.
    2. Edita la ruta.Elige la ruta que debe usar su ubicación de origen. El ajuste pertenece a esa ruta y no afecta a las demás.
    3. Abre Ubicación.Activa Usar ubicación actual. Mantén Escribir metadatos de ubicación desactivado para el comportamiento solo con tokens.
    4. Elige la precisión.Usa exacto para la posición de origen o ciudad para coordenadas redondeadas a dos decimales, sin etiqueta de punto de interés.
    5. Elige el comportamiento si no está disponible.Preguntar, Enviar sin ubicación o Cancelar captura determinan qué ocurre cuando no se puede obtener la posición de origen.
    6. añadir {location} si lo deseas.Coloca el token en una plantilla de entrada, un prefijo o sufijo de entrada personalizado o una plantilla Markdown de la bóveda.

    El primer uso puede mostrar la solicitud de permiso de ubicación del sistema operativo. Si antes se denegó el permiso, activa el acceso a ubicación para Vox.md en los ajustes del sistema de iOS, iPadOS o macOS.

    03 / Configuraciones habituales

    Elige la mínima información de ubicación que necesites

    Resultado deseadoUsar ubicación actualEscribir metadatos de ubicaciónTemplos
    Sin ubicación de rutaApagadoApagadoNo uses {location}, o se deja vacío.
    Solo enlace que se puede pulsarActivadoApagadoañadir {location}. No se escriben campos de ubicación.
    Solo metadatosActivadoActivadoOmitir {location}. Solo se escriben los campos configurados.
    Enlace y metadatosActivadoActivadoañadir {location} y configura los campos de metadatos.

    Desactivar Usar ubicación actual impide tanto generar el token como producir metadatos para esa ruta, aunque las opciones anteriores de formato de metadatos sigan configuradas para usarlas más tarde.

    04 / Token de plantilla

    Usar {location} Sin cambiar los metadatos de la nota

    Cuando Usar ubicación actual está activado y la instantánea de origen está disponible, {location} genera un enlace Markdown de Google Maps validado:

    [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    El token funciona en plantillas de entrada reutilizables, prefijos y sufijos de entrada personalizados y plantillas Markdown de la bóveda. Usa las mismas coordenadas de exacto o ciudad seleccionadas para la ruta.

    Ejemplo solo con tokens

    Para un sufijo como:

    Captured from {location}

    Vox.md puede producir:

    Captured from [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    Con Escribir metadatos de ubicación desactivado, este enlace es el único contenido de ubicación que añade la ruta. No se añaden locations: como colección ni location.*:: como campos.

    Corrección con un toque en el editor

    Si un prefijo o sufijo de entrada efectivo, o una plantilla de entrada reutilizable, usa {location} mientras la ruta seleccionada tiene Ubicación actual desactivada, el editor explica que el token se dejará vacío y ofrece Usar ubicación actual para [Route]. Esa acción activa Ubicación actual para la ruta y deja intencionadamente Escribir metadatos de ubicación desactivado, para que el próximo envío pueda resolver el token sin cambiar los metadatos de la nota. Los archivos de plantilla activos de la bóveda solo se leen durante la entrega, así que su contenido no puede activar esta sugerencia del editor; activa Ubicación actual manualmente cuando una plantilla de bóveda use el token.

    Cuando el token está vacío

    {location} se convierte en una cadena vacía cuando Ubicación actual está desactivada, no hay ubicación disponible o la captura continúa sin ubicación. Ten en cuenta la puntuación y las etiquetas circundantes al diseñar líneas de plantilla opcionales.

    Acción independiente de la Barra de captura

    La captura rápida Ubicación actual inserta directamente un enlace puntual de Google Maps en el borrador actual. Es independiente de las Rutas y no cambia Usar ubicación actual ni Escribir metadatos de ubicación.

    05 / Salida de metadatos

    Escribe campos estructurados solo cuando lo decidas

    Activa Escribir metadatos de ubicación cuando la nota deba recibir campos de ubicación legibles por máquinas además del enlace, o en lugar del {location} como enlace.

    Metadatos iniciales de la nota

    Añade cada ubicación a una colección llamada locations de forma predeterminada, con el ID de captura como clave. Se conservan los metadatos iniciales existentes que no estén relacionados.

    Campos de entrada en línea

    Escribe al estilo de Dataview location.key:: value junto a la entrada capturada. No se añade ninguna colección de metadatos iniciales.

    Campos estructurados

    Selecciona y renombra coordenadas, latitud, longitud, lugar, ciudad, región, país, enlaces de proveedores, URI geo, precisión, marca de tiempo, origen e ID.

    YAML avanzado

    Usa una plantilla YAML validada y acotada para los metadatos iniciales de la nota. YAML avanzado no está disponible para los campos de entrada en línea.

    Ejemplo de metadatos iniciales estructurados

    ---
title: Field Notes
locations:
  - id: "aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee"
    coordinates: [45.501235, -73.567890]
    place: "Café & Main"
    appleMapsURL: "https://maps.apple.com/?ll=45.501235%2C-73.567890&q=Caf%C3%A9%20%26%20Main"
    timestamp: "2023-11-14T22:13:20.000Z"
    source: "app"
---

    Las notas periódicas pueden conservar varias capturas en la colección. La protección frente a reintentos está integrada en la combinación de ubicaciones: un reintento con el mismo ID de captura no puede añadir la misma ubicación dos veces. Si la clave de colección elegida ya contiene un valor incompatible escrito por el usuario, Vox.md se detiene en lugar de sobrescribirlo.

    Ejemplo de entrada en línea

    location.id:: aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
location.coordinates:: [45.501235, -73.567890]
location.place:: "Café & Main"

Captured text

    Marcadores de YAML avanzado

    Las plantillas avanzadas pueden usar marcadores como {{coordinates}}, {{latitude}}, {{longitude}}, {{place}}, {{city}}, {{region}}, {{country}}, {{appleMapsURL}}, {{googleMapsURL}}, {{openStreetMapURL}}, {{geoURI}}, {{accuracy}}, {{timestamp}}, {{source}}, y {{id}}. Previsualiza la configuración en los ajustes de la ruta antes de guardar.

    06 / Precisión y etiquetas

    exacto y ciudad usan una instantánea coherente

    PrecisiónCoordenadasEtiquetasEnlaces y campos
    exactoConserva la posición de origen con seis decimales visibles.Puede incluir una etiqueta de punto de interés cuando un campo de metadatos seleccionado la necesita.Todos los valores derivados usan las coordenadas de exacto.
    ciudadRedondea la latitud y la longitud a dos decimales antes de conservar la instantánea.Elimina las etiquetas de puntos de interés; la ciudad, región y país pueden conservarse.Todas las URL de proveedores, URI geo, tokens y campos usan las coordenadas redondeadas.

    El geocodificador inverso del sistema de Apple solo se usa cuando Escribir metadatos de ubicación está activado y un campo estructurado o marcador avanzado seleccionado necesita lugar, ciudad, región o país. Una ruta solo con tokens omite la geocodificación inversa. Si falla la consulta de etiquetas, la salida basada en coordenadas sigue disponible.

    07 / Fuentes de captura

    La instantánea pertenece al origen de la captura

    Ubicación actual se evalúa en el punto donde se origina la captura. Los reintentos y la recuperación reutilizan ese resultado persistente en lugar de obtener una ubicación más reciente sin avisar.

    Fuente de capturaPunto de obtención
    Captura rápida en iPhone y iPadEnvío
    Hoja para compartirEnvío en la extensión para compartir
    Intents de texto, enlace y archivo que se ponen directamente en colaInvocación del intent
    Atajos, widgets, controles y enlaces profundos que abren Rápido capturaEnvío en el editor
    Atajo, widget, control, voz inmediata y grabación de ruta desde el tecladoFin de la grabación
    Entrega normal de Captura de Apple WatchFin de la grabación en el Watch; iPhone no sustituye la ubicación por la suya
    Captura en MacEnvío, o fin de la grabación para la entrega inmediata de voz

    Solo grabación del Watch exporta audio M4A sin procesar a Archivos, sin superficie Markdown, así que no solicita ubicación aunque la ruta use Ubicación actual para otros fines.

    08 / No disponible y recuperación

    Elige cómo gestiona cada Ruta una posición no disponible

    • preguntar: las capturas interactivas permiten reintentar, cancelar, enviar una vez sin ubicación o elegir Enviar siempre sin ubicación para esa ruta.
    • Enviar sin ubicación: continúa la entrega sin valor de token ni salida de metadatos.
    • Cancelar captura: detiene la entrega en vez de crear una nota sin la ubicación de origen solicitada.
    • Restablecer una opción guardada: usa Restablecer elección de ubicación no disponible en los ajustes de ubicación de la ruta.

    Una solicitud desatendida con Preguntar almacena su resultado no disponible del momento de origen para revisarlo más tarde. Reintentar una captura en cola o fallida nunca sustituye ese resultado por una ubicación posterior. El trabajo pendiente solo conserva la instantánea ajustada por privacidad o el resultado no disponible necesarios para la recuperación local.

    09 / Rutas existentes

    Las actualizaciones conservan el comportamiento anterior de los metadatos

    La separación entre obtención y salida mantiene la compatibilidad durante la migración:

    • Rutas nuevas: Usar ubicación actual y Escribir metadatos de ubicación empiezan ambos desactivados.
    • Rutas con ubicación activada anteriormente: ambos controles siguen activados tras la actualización, conservando los metadatos que esas rutas ya escribían.
    • Rutas con ubicación desactivada anteriormente: ambos controles siguen desactivados; la actualización no introduce ninguna salida de metadatos nueva.

    Para convertir una ruta que ya escribe metadatos al comportamiento solo con tokens, deja Usar ubicación actual activado y desactiva Escribir metadatos de ubicación. El Markdown existente no se reescribe ni elimina.

    10 / Privacidad y conservación

    Una instantánea explícita, nunca seguimiento en segundo plano

    • Vox.md no supervisa la ubicación continuamente ni realiza seguimiento de ubicación en segundo plano.
    • La ubicación no se envía a servidores de Vox.md, sistemas de análisis o publicidad ni servicios de IA de terceros.
    • Las URL de tokens y proveedores se generan localmente. Apple Maps, Google Maps u OpenStreetMap solo reciben las coordenadas cuando abres su enlace.
    • El geocodificador inverso del sistema de Apple puede hacer una solicitud de red únicamente cuando los metadatos seleccionados necesitan una etiqueta de lugar. La ubicación solo con tokens omite esta consulta.
    • Tras una entrega correcta, las solicitudes recuperables se reducen a recibos sin contenido, y el historial de Capturas completadas no conserva coordenadas, etiquetas, URL de proveedores ni plantillas de ubicación.
    • Si se escriben metadatos de ubicación o un enlace de token en Markdown, pasan a formar parte del archivo que elegiste. Tu proveedor de sincronización de archivos puede procesarlo según sus propias condiciones.
    El permiso puede seguir activado mientras las rutas siguen siendo privadas

    Puedes dejar disponible el permiso del sistema para la acción independiente Ubicación actual y aun así mantener desactivado Usar ubicación actual en todas las Rutas.

    Consulta la Política de privacidad para conocer todos los detalles de tratamiento y conservación de datos.

    11 / Resolución de problemas

    Resuelve problemas habituales de ubicación y plantillas

    {location} se deja vacío

    Confirma que la plantilla de entrada, el prefijo, el sufijo o la plantilla de bóveda efectivos usen exactamente el token en minúsculas {location}. Después activa Usar ubicación actual para la ruta de entrega. La corrección con un toque del editor puede hacerlo para el formato de entrada en línea detectado sin activar metadatos; los archivos de plantilla activos de la bóveda requieren configurar la ruta manualmente. Si se deniega el permiso o la posición no está disponible, revisa el comportamiento de la ruta ante la falta de ubicación y los ajustes de ubicación del sistema.

    Un enlace funciona, pero no aparecen metadatos

    Es lo esperado en una configuración solo con tokens. Abre los ajustes de ubicación de la ruta y activa Escribir metadatos de ubicación; después elige metadatos iniciales de la nota o campos de entrada en línea y selecciona los campos deseados.

    Aparecen metadatos, pero no aparece ningún enlace en la entrada

    La salida de metadatos no inserta un enlace automáticamente. Añade {location} al formato de entrada efectivo o a la plantilla Markdown de la bóveda.

    Falta el lugar o la ciudad

    Confirma que el campo de etiqueta esté seleccionado. El geocodificador inverso de Apple puede fallar aunque las coordenadas sigan disponibles. La precisión ciudad elimina intencionadamente las etiquetas de puntos de interés.

    La entrega de metadatos iniciales informa de una colisión

    La clave de colección configurada, locations de forma predeterminada, debe ser una lista de ubicaciones compatible. Renombra la colección en los ajustes de la ruta o ajusta los metadatos iniciales escritos por el usuario. Vox.md no sobrescribe un valor incompatible.

    Un reintento tiene una ubicación antigua o no disponible

    Es intencionado. La solicitud conserva el resultado del momento de origen para que un reintento posterior no pueda atribuir sin avisar otra ubicación de captura. Inicia una captura nueva cuando necesites una instantánea nueva.

    El permiso de ubicación está concedido, pero la ruta no la solicita

    El permiso del sistema solo habilita el acceso. Edita esa ruta y activa Usar ubicación actual. El permiso por sí solo nunca activa la función para una ruta.
