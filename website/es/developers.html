API de información pública

Consulta datos del producto y documentación

La API de información pública de Vox.md ofrece información del producto y enlaces a documentación publicada. Su consulta es gratuita y no requiere cuenta, clave de API, flujo OAuth ni pago. Estos endpoints devuelven información ya disponible en este sitio web público. Lee la Contrato OpenAPI 3.1 para consultar esquemas de respuesta tipados, identificadores de operación, errores y descripciones.

Obtén información del producto

GET https://vox.isolated.tech/api/v1/product devuelve el nombre del producto, la descripción, los sistemas operativos compatibles, la ficha del App Store, la URL de documentación y la URL de asistencia. La compilación obtiene estos datos de los datos estructurados de la página de inicio.

curl https://vox.isolated.tech/api/v1/product

Ver JSON del producto

Encuentra un documento

GET https://vox.isolated.tech/api/v1/documents enumera títulos, resúmenes y URL de páginas públicas. Úsalo para encontrar la guía de funciones, política, artículo de blog o página de asistencia pertinente antes de solicitar el contenido.

curl https://vox.isolated.tech/api/v1/documents

Ver JSON del índice de documentos

Lee la página como Markdown

Solicita cualquier página de la lista con Accept: text/markdown para su contenido principal. Las solicitudes con Accept: text/html siguen recibiendo HTML. Ambas representaciones incluyen Vary: Accept. La guía para agentes explica qué casos de uso encajan con Vox.md y remite a detalles de las funciones.

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

Errores, caché y métodos

Los endpoints JSON admiten GET y HEAD. Las rutas de API desconocidas devuelven HTTP 404 con application/problem+json, un identificador estable code, una explicación y una pista para la recuperación. Los métodos no admitidos devuelven HTTP 405 y Allow: GET, HEAD. Las respuestas públicas de metadatos permiten la lectura entre orígenes y anuncian una duración de caché de cinco minutos. No intervienen credenciales ni datos específicos del usuario.

Automatiza la app instalada

La captura, la transcripción, el acceso local a la bóveda y la escritura de notas se ejecutan en la app Apple instalada. Usa el esquema documentado Integraciones de Atajos y esquema URL con permiso del propietario del dispositivo. La API de información pública no expone acciones de captura, grabaciones, transcripciones, notas privadas ni carpetas de destino. Contacta con asistencia de Vox.md si tienes preguntas.
