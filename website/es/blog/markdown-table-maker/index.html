Creador de tablas Markdown para Obsidian: pega desde Excel, Sheets o CSV

Pega filas de Excel, Google Sheets, Numbers, CSV o TSV y copia una tabla con barras válida, con la barra de [[Note|Alias]] y ![[image.png|300]] escapada, saltos de línea resueltos y alineación por columna.

Por
Cody Bontecou
Actualizado
26 de noviembre de 2026
Requiere
Cualquier navegador moderno, incluido Safari en iPhone. Opcional: Obsidian para las tablas, y Vox.md para iPhone o Mac para capturar el texto en una nota.
La respuesta breve

Una tabla Markdown es una fila de encabezado, una fila delimitadora de guiones y luego una fila por línea, con las celdas separadas por |. Pega tus celdas en el creador de tablas de abajo para obtener una, o empieza con este ejemplo.

| Name | Owner | Status |
| --- | --- | --- |
| Draft | Ana | Done |
| Review | Lee | Open |

El creador también corrige lo que los generadores genéricos pasan por alto en Obsidian: escapa la barra dentro de [[Note|Alias]] y ![[image.png|300]] como \|, y convierte un salto de línea dentro de una celda en <br> o un espacio. Se ejecuta por completo en esta página: tus datos nunca se suben y la página no hace ninguna solicitud de red.

    2. Sintaxis de tablas Markdown

    | Name   | Qty | Price |
| :----- | :-: | ----: |
| Apple  |   3 |  1.20 |
| Pear   |  12 |  0.80 |

    La especificación de GitHub Flavored Markdown define una tabla como una fila de encabezado, una fila delimitadora que separa el encabezado de los datos, y cero o más filas de datos. Las celdas se separan con barras.

    • Fila delimitadora. Sus celdas contienen solo guiones, con dos puntos opcionales a la izquierda, a la derecha o en ambos extremos para fijar alineación izquierda, derecha o centrada. Ayuda de Obsidian dice que añadas dos puntos a la fila de encabezado para alinear el texto, y que la fila de encabezado debe contener al menos dos guiones.
    • Barras exteriores. Las barras de ambos lados son opcionales según la especificación. Obsidian Help recomienda incluirlas para mayor legibilidad, y el creador siempre las escribe.
    • Relleno. Según Obsidian Help, las celdas no necesitan una alineación perfecta. El diseño “Pad columns” del creador alinea el código fuente solo para que sea más fácil de leer; “Compact” lo omite.
    • Recuentos coincidentes. La especificación dice que la fila de encabezado debe tener el mismo número de celdas que la fila delimitadora. Si no es así, las líneas no son una tabla y se muestran como un párrafo. Una fila de datos con menos celdas recibe celdas vacías, y las celdas sobrantes se ignoran.
    • Dentro de una celda. La especificación permite formato en línea pero no contenido de nivel de bloque, así que una lista o un encabezado no caben en una celda. Obsidian Help dice que puedes usar su sintaxis de formato básico para dar estilo al contenido de una tabla.
    • El final de una tabla. La especificación dice que la tabla se interrumpe en la primera línea vacía, o al comenzar otra estructura de nivel de bloque.

    El creador escribe al menos tres guiones en cada celda delimitadora. Eso cumple el mínimo de dos de Obsidian y los tres que Documentación de GitHub exige.

    3. Tablas en Obsidian

    • Insertar tabla. Obsidian Help dice que puedes insertar una tabla con el comando Insert Table desde la Command Palette. Para crear una a partir de datos que ya tienes, pégalos en el creador de arriba.
    • Alias y tamaños de imagen. Un alias de wikilink como [[Note|Alias]] y un tamaño de imagen como ![[image.png|300]] contienen ambos una barra vertical. Obsidian Help dice que dentro de una tabla debes añadir una \ antes de la barra, así que escribe [[Note\|Alias]] y ![[image.png\|300]]. El creador lo hace por ti; un escape que ya hayas escrito no se duplica.
    • Cualquier otra barra. La especificación GFM dice que una barra dentro de una celda debe escaparse con una barra invertida, incluso dentro de un fragmento de código. El creador escapa cada barra sin escapar como \|.
    • Saltos de línea. Una fila se escribe en una sola línea, así que un salto de línea dentro de una celda tiene que convertirse en otra cosa. El creador escribe un HTML <br> o une las líneas con un espacio si lo eliges. Ni la sección Tables de Obsidian Help ni GitHub Docs describen los saltos de línea en las celdas, así que comprueba que <br> se muestra en tu propia bóveda, y elige la opción de espacio si no quieres etiquetas en el código fuente.
    • Complementos. Existen plugins de la comunidad que ayudan a editar tablas. Esta página no evalúa ni respalda ninguno de ellos.

    Para listas de tareas consulta el Generador de listas de verificación en Markdown; para las propiedades al inicio de una nota, el generador de propiedades. Una tabla funciona bien para una lista de decisiones y responsables en una nota de la plantilla de notas de reunión.

    4. Desde Excel, Google Sheets o CSV

    Selecciona las celdas en tu hoja de cálculo, cópialas y pégalas en el cuadro de arriba. Si las celdas se pegan con tabulaciones entre ellas, el creador lo detecta. También detecta comas, puntos y coma y barras, y lee campos CSV entre comillas, de modo que "Lee, Sam" sigue siendo una celda y "" entre comillas se convierte en una comilla. Usa el menú Separator si la detección es incorrecta. Marca o desmarca “The first row is the header” para decidir si la primera fila pasa a ser la fila de encabezado; sin ella, se añade una fila de encabezado vacía, porque una tabla Markdown necesita una.

    • Celdas combinadas. La especificación y ambas páginas de ayuda describen una fila como una lista de celdas separadas por barras, y ninguna describe una forma de combinar celdas. Pon el valor en cada celda que abarcaba la combinación antes de copiar.
    • Fórmulas. El creador solo lee el texto que pegas. Si las celdas pegadas muestran fórmulas en lugar de sus resultados, copia los valores en tu app de hoja de cálculo y vuelve a pegar.
    • Filas desiguales. Si una fila tiene un número de celdas distinto al del encabezado, el creador avisa con el número de línea de esa fila y completa la tabla con celdas vacías. Una fila con más celdas que el encabezado ensancha la tabla en lugar de descartar datos.
    • Revertir y reparar. Pega una tabla Markdown existente para realinearla, o establece Output as en CSV o TSV para exportarla. El creador avisa, con un número de línea, cuando falta la fila delimitadora, cuando su número de celdas no coincide con el del encabezado o cuando una línea en blanco terminaría la tabla.

    Los dos puntos de alineación de una tabla Markdown pegada se conservan, y puedes cambiar cada columna con los menús Column alignment.

    5. Diferencias entre GitHub y Obsidian

    Obsidian Help y GitHub Docs describen tablas con barras que tienen una fila de encabezado, guiones y dos puntos de alineación opcionales. Las diferencias que señalan las páginas son pequeñas:

    TemaAyuda de ObsidianGitHub Docs y la especificación GFM
    GuionesLa fila de encabezado debe contener al menos dos guionesGitHub Docs: al menos tres guiones en cada columna del encabezado
    Línea en blanco antes de la tablaLa sección Tables no menciona ningunoGitHub Docs: debes incluir una línea en blanco antes de tu tabla
    Barra literal en una celdaAñade una \ antes de la barra en alias y tamaños de imagenEscápala como \|, incluso dentro de un fragmento de código
    Barras exterioresOpcional, recomendado para la legibilidadOpcional

    Para estar seguro en ambos sitios, escribe tres o más guiones, deja una línea en blanco encima de la tabla y escapa todas las barras. Eso es lo que hace el creador. Un alias de wikilink es sintaxis de Obsidian; en GitHub es solo texto con una barra. La guía del creador de listas de tareas trata las diferencias en las listas de tareas de la misma manera.

    Para destacar una tabla o una nota sobre ella, envuélvela en un callout: el Generador de callouts de Obsidian añade la > prefijos por ti.

    6. Lleva tablas y notas a tu bóveda con Vox.md

    Vox.md no crea tablas por sí mismo, y el creador de arriba funciona sin la app. Lo que hace Vox.md es capturar texto en Obsidian: Quick Capture te permite pegar texto existente, y una Route lo entrega en un destino Markdown. Consulta el Rápido captura y Rutas documentación.

    1. Crea tu tabla arriba y pulsa Copy.
    2. En Vox.md en iPhone, iPad o Mac, abre Quick Capture y pega la tabla en el editor de texto.
    3. Envíalo con una Route que conserve el texto original. La documentación enumera Conservar original como el modo de procesamiento que conserva el texto capturado sin reescritura con IA, y dicen que el texto capturado se entrega sin cambios cuando Usar Apple Intelligence está desactivado, que es su valor predeterminado. Procesar texto escrito es un ajuste opcional en cada Route.
    4. El destino de la Route decide dónde llega: una nota nueva, una nota continua como tu nota diaria, o una nota existente, al final, al principio o bajo un encabezado elegido.

    Deja una línea en blanco encima de la tabla pegada si el destino ya tiene texto encima. Para una receta de Route, consulta plantillas de captura, y para convertir primero un archivo de subtítulos de Zoom, Teams o YouTube en una nota de transcripción, consulta SRT y VTT a Markdown.

    7. Preguntas

    ¿Por qué mi tabla no se muestra en Obsidian?

    Comprueba tres cosas. Debe haber una fila delimitadora de guiones justo debajo del encabezado, y las filas de encabezado y delimitadora deben tener el mismo número de celdas; de lo contrario, la especificación muestra las líneas como un párrafo. Obsidian Help dice que la fila de encabezado debe contener al menos dos guiones. Y deja una línea en blanco antes de la tabla, algo que GitHub Docs exige y que en Obsidian no cuesta nada. Pega la tabla en el creador: avisa, con un número de línea, cuando falta la fila delimitadora o cuando los recuentos no coinciden.

    ¿Cómo añado un salto de línea en una celda?

    Mantén la fila en una sola línea y usa un HTML <br> dentro de la celda, que es lo que el creador escribe para una celda de varias líneas. Las páginas citadas no describen los saltos de línea en celdas, así que pruébalo en tu bóveda. La otra opción es unir las líneas con un espacio.

    ¿Cómo pongo una barra o un alias de wikilink en una celda?

    Pon una barra invertida antes de la barra: [[Note\|Alias]], ![[image.png\|300]] o a \| b. Obsidian Help lo exige para los alias y el cambio de tamaño de imágenes dentro de tablas, y la especificación GFM lo exige para cualquier barra en una celda.

    ¿Puedo combinar celdas?

    No aparece ninguna sintaxis para ello en la especificación ni en Obsidian Help. Repite el valor en cada celda.

    ¿Cuán ancha puede ser una tabla?

    Ninguna de las páginas citadas indica un máximo de columnas o filas, y el creador no fija ningún límite. Una tabla muy ancha es difícil de leer en el código fuente, así que usa el diseño Compact o divídela en dos tablas.

    ¿El creador sube mis datos?

    No. La tabla la construye un script de esta página, en tu dispositivo, y la página no hace ninguna solicitud de red. No guarda tus datos: al cerrar o recargar la página se borran. El botón Download guarda un archivo desde la página en tu dispositivo.
