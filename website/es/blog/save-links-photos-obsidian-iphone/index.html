iPhone · Hoja para compartir · Captura multimedia

Guarda enlaces, fotos y escaneos en Obsidian desde iPhone

Conserva el material de origen junto a la idea. Envía un enlace, una imagen o un escaneo al destino Markdown que elijas.

Por
Cody Bontecou
Actualizado
26 de octubre de 2026
Requiere
iOS 17.6+ · carpeta de bóveda con escritura permitida
La respuesta breve

Conecta un Capturar Prep de Vox.md a una carpeta de bóveda que permita escribir, añade una URL, foto, archivo o escaneo en Rápido captura y envíalo. El preajuste elige la nota y la ubicación de los adjuntos. Revisa el Markdown entregado y confirma que sus adjuntos se abran en Obsidian.

Guardar un enlace y guardar un artículo son tareas distintas. Vox.md acepta URL web como enlaces Markdown; no supongas que añadir una URL descarga o extrae toda la página. Elige el método de captura según el material que quieras conservar.

En esta guía
  1. Prepara el destino de la bóveda
  2. Guarda un enlace web
  3. Añade una foto, captura de pantalla o archivo
  4. Escanea un documento y revisa el OCR
  5. Comprueba adjuntos y sincronización

1. Prepara el destino de la bóveda

En Ajustes → Preajustes de captura, crea o elige un preajuste activado y conecta su destino mediante Archivos. Selecciona la carpeta que contiene los archivos Markdown de tu bóveda. Si otra app no puede acceder a la carpeta, Vox.md no puede escribir en ella solo porque sea visible dentro de Obsidian.

Para el primer ejemplo, elige Nueva nota y el procesamiento Conservar original. Una carpeta de entrada independiente facilita encontrar capturas mixtas. Más adelante puedes elegir Rolling Note o Nota existente si quieres añadir contenido al mismo archivo.

Establece una subcarpeta para adjuntos en los ajustes de destino; el valor predeterminado es attachments. Comprueba la ruta resuelta de la nota y las reglas de adjuntos antes de enviar. Para un diario, sigue la guía de enrutamiento a notas diarias.

2. Guarda un enlace web

Copia la URL que quieras conservar. En Rápido captura, usa el control de enlace web y revisa el texto del enlace y su dirección. Añade una breve explicación de por qué lo guardaste y toca Envío.

Una nota sencilla podría contener este Markdown ilustrativo:

Read before planning the trip:
[Trail information](https://example.com/trail)

La dirección anterior es un ejemplo, no una recomendación. Sustitúyela por la página real. Un enlace te permite volver a la fuente; no conserva su contenido si el sitio cambia o desaparece.

La hoja para compartir de Vox.md también acepta contenido compatible de otras apps. Lo que una app comparte puede ser una URL, texto o un archivo. Revisa el contenido recibido y el preajuste seleccionado en lugar de suponer que se ha incluido todo lo visible en la pantalla de origen.

3. Añade una foto, captura de pantalla o archivo

  1. Selecciona el preajuste de tu bandeja de entrada o nota de proyecto.
  2. Usa el selector de fotos o capturas de pantalla, la cámara o el control Adicionar archivos para elegir el material.
  3. Añade un título corto o una explicación en el editor.
  4. Envía, abre después la nota en Obsidian y comprueba la imagen insertada o el enlace al archivo.

Las imágenes se insertan en la salida Markdown. Los demás tipos de archivo usan enlaces. Por ejemplo, una nota podría referenciar una ruta de adjunto configurada así:

## Reference
![[attachments/whiteboard.png]]
[[attachments/brief.pdf]]

Estos nombres de archivo y rutas son ilustrativos; la salida real de Vox.md depende de los archivos seleccionados y las reglas de destino. Conserva los archivos referenciados con la bóveda. Mover solo el archivo Markdown a otra carpeta puede romper los enlaces relativos.

4. Escanea un documento y revisa el OCR

Elige Escanear el documento en la Barra de captura y sigue el escáner. Vox.md conserva las imágenes de las páginas, crea un PDF e incluye reconocimiento de texto local con el mejor resultado posible. Revisa las palabras reconocidas antes de enviar, especialmente nombres, fechas, importes y escritura manuscrita.

Para las fotos de diario, el flujo independiente Extraer texto admite páginas capturadas manualmente o seleccionadas. El OCR puede perder estructura o leer mal una palabra incluso cuando la imagen parece clara. Conserva la imagen de origen o el escaneo cuando necesites verificar el texto después.

Elige Conservar original si no quieres que el procesamiento opcional reescriba el texto capturado. El procesamiento de texto escrito y mixto se activa por separado en cada preajuste. La referencia de captura describe las entradas compatibles y la límites de entrada.

Comprueba adjuntos y sincronización

Tras la entrega, abre la nota en Obsidian, sigue cada enlace y confirma que el archivo previsto esté presente. Que una nota aparezca en otro dispositivo no demuestra que todos los adjuntos hayan terminado de sincronizarse. Comprueba también la imagen o el PDF en ese dispositivo.

Una escritura fallida puede quedar pendiente en Vox.md. Corrige el acceso al destino y reintenta la captura existente antes de crear otra copia. Los archivos almacenados con un proveedor en la nube pueden necesitar conexión para acceder o sincronizarse, aunque el procesamiento de la captura sea local.

Si necesitas extraer páginas web completas, compara directamente las herramientas pertinentes. Obsidian documenta sus opciones nativas para compartir en la guía oficial de iOS. Puedes usar las opciones nativas para compartir en una tarea y un preajuste de Vox.md en otra.
