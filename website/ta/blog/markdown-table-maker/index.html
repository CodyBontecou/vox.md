உங்கள் அட்டவணை

    முன்னோட்டம்

    அட்டவணையைக் காண உங்கள் தரவை ஒட்டுங்கள்.

    கிளிப்போர்டுக்குப் பிரதியெடுக்கப்பட்டது. பிரதியெடுக்க இயலவில்லை. உரையைத் தேர்ந்தெடுத்து நீங்களே பிரதியெடுக்கவும். எடுத்துக்காட்டு ஏற்றப்பட்டது. அழிக்கப்பட்டது. பதிவிறக்கம் தொடங்கியது. உங்கள் Markdown அட்டவணை உங்கள் CSV உங்கள் TSV கண்டறிந்தது: {format}. {rows} வரிசைகள், {cols} நெடுவரிசைகள். Markdown அட்டவணை தத்தலால் பிரிக்கப்பட்ட காற்புள்ளியால் பிரிக்கப்பட்ட அரைப்புள்ளியால் பிரிக்கப்பட்ட பைப்பால் பிரிக்கப்பட்ட ஒரு நெடுவரிசை \| ஆகத் தப்பிக்கப்பட்ட பைப்புகள்: {n}, அவற்றில் {m} விக்கிஇணைப்புகள் அல்லது பட இணைப்புகளுக்குள். வரி {line}: பிரிப்பான் வரிசை இல்லை, எனவே தலைப்புக்குப் பிறகு ஒரு பிரிப்பான் வரிசை சேர்க்கப்பட்டது. வரி {line}: பிரிப்பான் வரிசையில் {found} கலங்கள் உள்ளன, ஆனால் தலைப்பில் {expected} உள்ளன. GFM விவரக்குறிப்பு இதை அட்டவணையாகக் கருதாது. வெளியீடு {expected} என்பதைப் பயன்படுத்துகிறது. வரி {line}: {found} கலங்கள், தலைப்பில் {expected} உள்ளன. வெற்றுக் கலங்கள் சேர்க்கப்பட்டன. வரி {line}: {found} கலங்கள், தலைப்பில் {expected} உள்ளன. அட்டவணை {max} நெடுவரிசைகளாக விரிவாக்கப்பட்டது. வரி {line} வெற்றாக உள்ளது. முதல் வெற்று வரியில் அட்டவணை முடிவடையும், எனவே அதற்குப் பிறகு உள்ள வரிசைகள் அட்டவணையின் பகுதியாக இருக்காது. மேலும் {n} வரிசைகளில் கலங்களின் எண்ணிக்கை வேறுபடுகிறது. நெடுவரிசை {n}: {name} இல்லை இடது நடு வலது (தலைப்பு இல்லை)

    2. Markdown அட்டவணை தொடரியல்

    | Name   | Qty | Price |
| :----- | :-: | ----: |
| Apple  |   3 |  1.20 |
| Pear   |  12 |  0.80 |

    இந்த GitHub Flavored Markdown விவரக்குறிப்பு அட்டவணையை ஒரு தலைப்பு வரிசை, தலைப்பை தரவிலிருந்து பிரிக்கும் ஒரு பிரிப்பான் வரிசை, மற்றும் பூஜ்யம் அல்லது அதற்கு மேற்பட்ட தரவு வரிசைகள் என வரையறுக்கிறது. கலங்கள் பைப்புகளால் பிரிக்கப்படுகின்றன.

    • பிரிப்பான் வரிசை. இதன் கலங்களில் ஹைபன்கள் மட்டுமே இருக்கும்; இடது, வலது அல்லது நடு சீரமைப்பை அமைக்க இடது, வலது அல்லது இரு முனைகளிலும் விருப்பமாக ஒரு முக்காற்புள்ளி இருக்கலாம். Obsidian Help ஆவணம் உரையை சீரமைக்க தலைப்பு வரிசையில் முக்காற்புள்ளிகளைச் சேர்க்க வேண்டும் என்றும், தலைப்பு வரிசையில் குறைந்தது இரண்டு ஹைபன்கள் இருக்க வேண்டும் என்றும் கூறுகிறது.
    • வெளிப்புற பைப்புகள். இருபுறமும் உள்ள பைப்புகள் விவரக்குறிப்பில் விருப்பத்தேர்வு. படிக்க எளிதாக இருக்க அவற்றைச் சேர்ப்பது நல்லது என்று Obsidian Help கூறுகிறது; உருவாக்கி எப்போதும் அவற்றை எழுதுகிறது.
    • இடைவெளி நிரப்புதல். Obsidian Help கூற்றுப்படி, கலங்கள் முழுமையாக சீரமைக்கப்பட வேண்டியதில்லை. உருவாக்கியின் “நெடுவரிசைகளை நிரப்பு” அமைப்பு மூலத்தை படிக்க எளிதாக்க மட்டுமே வரிசைப்படுத்துகிறது; “சுருக்கம்” அதைத் தவிர்க்கிறது.
    • பொருந்தும் எண்ணிக்கைகள். தலைப்பு வரிசையில் உள்ள கலங்களின் எண்ணிக்கை பிரிப்பான் வரிசையில் உள்ளதற்குச் சமமாக இருக்க வேண்டும் என்று விவரக்குறிப்பு கூறுகிறது. இல்லையெனில் அந்த வரிகள் அட்டவணை அல்ல; அவை ஒரு பத்தியாகக் காட்டப்படும். குறைவான கலங்கள் உள்ள தரவு வரிசைக்கு வெற்றுக் கலங்கள் சேர்க்கப்படும், கூடுதல் கலங்கள் புறக்கணிக்கப்படும்.
    • கலத்திற்குள். விவரக்குறிப்பு இன்லைன் வடிவமைப்பை அனுமதிக்கிறது, ஆனால் தொகுதி நிலை உள்ளடக்கத்தை அனுமதிக்காது; எனவே கலத்தில் பட்டியலோ தலைப்போ வைக்க முடியாது. அட்டவணையில் உள்ளடக்கத்தை அலங்கரிக்க அதன் அடிப்படை வடிவமைப்பு தொடரியலைப் பயன்படுத்தலாம் என்று Obsidian Help கூறுகிறது.
    • அட்டவணையின் முடிவு. முதல் வெற்று வரியில் அல்லது வேறொரு தொகுதி நிலை அமைப்பின் தொடக்கத்தில் அட்டவணை முடிவடையும் என்று விவரக்குறிப்பு கூறுகிறது.

    உருவாக்கி ஒவ்வொரு பிரிப்பான் கலத்திலும் குறைந்தது மூன்று ஹைபன்களை எழுதுகிறது. அது Obsidian-இன் குறைந்தபட்சம் இரண்டையும், இது கோரும் மூன்றையும் பூர்த்தி செய்கிறது: GitHub Docs ஆவணம் என்பதைக் கோருகிறது.

    3. Obsidian-இல் அட்டவணைகள்

    • Insert Table கட்டளை. Command Palette-இலிருந்து Insert Table கட்டளையைப் பயன்படுத்தி அட்டவணையைச் செருகலாம் என்று Obsidian Help கூறுகிறது. உங்களிடம் ஏற்கனவே உள்ள தரவிலிருந்து ஒன்றை உருவாக்க, மேலே உள்ள உருவாக்கியில் அதை ஒட்டுங்கள்.
    • மாற்றுப்பெயர்கள் மற்றும் பட அளவுகள். விக்கிஇணைப்பு மாற்றுப்பெயர், எடுத்துக்காட்டாக [[Note|Alias]] மற்றும் படத்தின் அளவு, எடுத்துக்காட்டாக ![[image.png|300]] இரண்டிலும் செங்குத்துக் கோடு உள்ளது. அட்டவணைக்குள் இதைச் சேர்க்க வேண்டும் என்று Obsidian Help கூறுகிறது: \ பைப் குறிக்கு முன், எனவே இவ்வாறு எழுதுங்கள்: [[Note\|Alias]] மற்றும் ![[image.png\|300]]. உருவாக்கி இதை உங்களுக்காகச் செய்கிறது; நீங்கள் ஏற்கனவே எழுதிய தப்பிப்பு இரட்டிப்பாகாது.
    • வேறு எந்த பைப்பும். GFM விவரக்குறிப்பு, கலத்தில் உள்ள பைப் குறியை, குறியீட்டுப் பகுதிக்குள்ளும் கூட, பின்சாய்வுக்கோட்டால் தப்பிக்க வேண்டும் என்கிறது. உருவாக்கி தப்பிக்கப்படாத ஒவ்வொரு பைப்பையும் இவ்வாறு தப்பிக்கிறது: \|.

    4. Excel, Google Sheets அல்லது CSV-இலிருந்து

    • இணைக்கப்பட்ட கலங்கள். வரிசை என்பது பைப்புகளால் பிரிக்கப்பட்ட கலங்களின் பட்டியல் என்று விவரக்குறிப்பும் இரு உதவிப் பக்கங்களும் கூறுகின்றன; கலங்களை இணைக்க எந்த வழியையும் அவை விவரிக்கவில்லை. நகலெடுக்கும் முன் இணைப்பு உள்ளடக்கிய ஒவ்வொரு கலத்திலும் மதிப்பை இடுங்கள்.

    Vox.md குரலையும் உரையையும் உங்கள் Obsidian குறிப்புகளில் பதிவு செய்கிறது. பதிவு, Transcription மற்றும் Capture ஆகியவற்றுக்கு Vox.md Unlimited தேவை: தகுதியுள்ள கணக்குகளுக்கு 7 நாள் இலவச சோதனையுடன் வாராந்திர அல்லது ஆண்டு சந்தா, அல்லது ஒருமுறை செலுத்தும் ஆயுள்கால வாங்குதல். App Store உங்கள் உள்ளூர் விலையைக் காட்டும்.

    Obsidian-இல் பதிவு செய்யுங்கள்

    மேலே உள்ள அட்டவணை உருவாக்கி செயலி இல்லாமலும் முழுமையாக வேலை செய்யும்.

    7. கேள்விகள்

    Obsidian-இல் என் அட்டவணை ஏன் சரியாகக் காட்டப்படவில்லை?

    மூன்றைச் சரிபாருங்கள். தலைப்புக்குக் கீழே நேரடியாக ஹைபன்களாலான பிரிப்பான் வரிசை இருக்க வேண்டும்; தலைப்பு மற்றும் பிரிப்பான் வரிசைகளில் கலங்களின் எண்ணிக்கை சமமாக இருக்க வேண்டும், இல்லையெனில் விவரக்குறிப்பு அந்த வரிகளை பத்தியாகக் காட்டும். தலைப்பு வரிசையில் குறைந்தது இரண்டு ஹைபன்கள் இருக்க வேண்டும் என்று Obsidian Help கூறுகிறது. மேலும் அட்டவணைக்கு முன் ஒரு வெற்று வரி விடுங்கள்; அதை GitHub Docs கோருகிறது, Obsidian-இல் அதற்குச் செலவு எதுவும் இல்லை. அட்டவணையை உருவாக்கியில் ஒட்டுங்கள்: பிரிப்பான் வரிசை இல்லாதபோது அல்லது எண்ணிக்கைகள் வேறுபடும்போது வரி எண்ணுடன் எச்சரிக்கும்.

    கலத்தில் வரி முறிவை எவ்வாறு சேர்ப்பது?

    வரிசையை ஒரே வரியில் வைத்து, HTML ஒன்றைப் பயன்படுத்துங்கள் <br> கலத்திற்குள், பல வரிகள் உள்ள கலத்திற்கு உருவாக்கி இதையே எழுதுகிறது. மேற்கோள் காட்டிய பக்கங்கள் கலங்களில் வரி முறிவுகளை விவரிக்கவில்லை, எனவே உங்கள் vault-இல் சோதித்துப் பாருங்கள். மற்றொரு தேர்வு, வரிகளை இடைவெளியால் இணைப்பது.

    கலத்தில் பைப் அல்லது விக்கிஇணைப்பு மாற்றுப்பெயரை எவ்வாறு வைப்பது?

    பைப்புக்கு முன் பின்சாய்வுக்கோடு இடுங்கள்: [[Note\|Alias]], ![[image.png\|300]] அல்லது a \| b. அட்டவணைகளுக்குள் மாற்றுப்பெயர்கள் மற்றும் பட அளவுமாற்றத்திற்கு Obsidian Help இதைக் கோருகிறது, மேலும் கலத்தில் உள்ள எந்த பைப்புக்கும் GFM விவரக்குறிப்பு இதைக் கோருகிறது.

    கலங்களை இணைக்க முடியுமா?

    விவரக்குறிப்பிலும் Obsidian Help-இலும் இதற்கான தொடரியல் எதுவும் இல்லை. அதற்குப் பதிலாக ஒவ்வொரு கலத்திலும் மதிப்பை மீண்டும் எழுதுங்கள்.

    அட்டவணை எவ்வளவு அகலமாக இருக்கலாம்?

    மேற்கோள் காட்டிய பக்கங்கள் எதுவும் நெடுவரிசைகள் அல்லது வரிசைகளின் அதிகபட்ச எண்ணிக்கையைத் தரவில்லை, உருவாக்கியும் வரம்பு எதுவும் வைக்கவில்லை. மிக அகலமான அட்டவணையை மூலத்தில் படிப்பது கடினம், எனவே சுருக்க அமைப்பைப் பயன்படுத்துங்கள், அல்லது அதை இரண்டு அட்டவணைகளாகப் பிரியுங்கள்.

    உருவாக்கி எனது தரவை பதிவேற்றுகிறதா?

    இல்லை. அட்டவணை இந்தப் பக்கத்தில் உள்ள ஒரு ஸ்கிரிப்டால் உங்கள் சாதனத்திலேயே உருவாக்கப்படுகிறது, பக்கம் எந்த நெட்வொர்க் கோரிக்கையும் செய்வதில்லை. அது உங்கள் தரவைச் சேமிப்பதில்லை: பக்கத்தை மூடினாலோ மீண்டும் ஏற்றினாலோ அது அழிந்துவிடும். Download பொத்தான் பக்கத்திலிருந்து ஒரு கோப்பை உங்கள் சாதனத்தில் சேமிக்கிறது.
