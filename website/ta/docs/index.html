    அமைப்புநடத்தை
    தற்போதைய இருப்பிடத்தைப் பயன்படுத்துவழித்தடத்திற்கு தொடக்கநேர இருப்பிடத்தை ஒருமுறை கோரி இதை இயக்கும்: {location}. இது தானாக மெட்டாடேட்டா எழுதாது.
    துல்லியமானது (இயல்புநிலை)தனியுரிமைக்கேற்ப மாற்றிய தொடக்க இருப்பிடத்தை வைத்திருந்து தேவைப்பட்டால் குறிப்பிட்ட இடப்பெயரைச் சேர்க்கும்.
    நகரம்அட்ச, தீர்க்கரேகையை இரண்டு தசமத்திற்கு வட்டமிட்டு இடப்பெயரைத் தவிர்க்கும். பெறப்பட்ட புலம், இணைப்பெல்லாம் வட்டமிட்ட ஆயங்களைப் பயன்படுத்தும்.
    இருப்பிட மெட்டாடேட்டாவை எழுதுஇதனுடன் கட்டமைக்கப்பட்ட அல்லது மேம்பட்ட மெட்டாடேட்டாவைத் தனியே தேர்வுசெய்கிறது: {location} பதிவு வார்ப்புரு இணைப்பு.
    கட்டமைக்கப்பட்ட புலங்கள்ஆயங்கள், அட்சரேகை, தீர்க்கரேகை, இடம், நகரம், பகுதி, நாடு, Apple Maps, Google Maps, OpenStreetMap தேர்ந்தெடுத்து பெயர்மாற்றவும், geo: URI, துல்லியம், நேரமுத்திரை, மூலம், பிடிப்பு ID.

    இருப்பிட மெட்டாடேட்டாவை எழுது இயங்கினால் ஆவண அளவு ஒவ்வொரு முடிவையும் பிடிப்பு ID அடிப்படையில் முன்தரவுத் தொகுப்பில் சேர்க்கும். ஒரே குறிப்பில் பல இருப்பிடங்கள் இருக்கலாம்; அதே கோரிக்கையின் மறுமுயற்சி அதே இருப்பிடத்தை இருமுறை சேர்க்காது. பதிவளவில் தேர்ந்த புலங்கள் இவ்வாறு: key:: value பிடித்த பதிவின் அருகில்.
