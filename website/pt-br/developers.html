API de informações públicas

Conheça dados e documentação do produto

A API de informações públicas do Vox.md fornece informações do produto e links para documentação publicada. A leitura é gratuita e não exige conta, chave API, fluxo OAuth nem pagamento. Esses endpoints retornam informações já disponíveis neste site público. Leia o Contrato OpenAPI 3.1 para esquemas tipados, IDs de operação, erros e descrições.

Obtenha dados do produto

GET https://vox.isolated.tech/api/v1/product retorna o nome do produto, a descrição, os sistemas operacionais compatíveis, a página na App Store, a URL da documentação e a URL de suporte. A compilação obtém esses dados dos dados estruturados da página inicial.

curl https://vox.isolated.tech/api/v1/product

Veja JSON do produto

Encontre um documento

GET https://vox.isolated.tech/api/v1/documents lista títulos, resumos e URLs públicos. Encontre guia, política, artigo ou suporte antes de pedir conteúdo.

curl https://vox.isolated.tech/api/v1/documents

Veja índice de documentos JSON

Leia como Markdown

Solicite uma página listada com Accept: text/markdown para conteúdo principal. Pedidos com Accept: text/html continuam recebendo HTML. Ambas incluem Vary: Accept. O guia de agentes explica usos Vox.md e detalhes.

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

Erros, cache e métodos

Os endpoints JSON aceitam GET e HEAD. Caminhos de API desconhecidos retornam HTTP 404 com application/problem+json, um identificador estável code, explicação e dica de recuperação. Métodos não aceitos retornam HTTP 405 e Allow: GET, HEAD. Respostas públicas permitem leitura entre origens e cache de cinco minutos. Sem credenciais ou dados pessoais.

Automatize app instalado

Captura, transcrição, cofre local e escrita rodam no app Apple instalado. Use o esquema documentado Integrações Atalhos e esquema URL com permissão do dono. API pública não expõe captura, gravações, transcrições, notas ou pastas privadas. Contate suporte Vox.md para dúvidas.
