    Localização atual, {location}, e Metadados

    Use uma única posição obtida no momento da origem para formatar a entrada, sem adicionar automaticamente YAML ou campos inline. A obtenção da posição e a saída de metadados são escolhas explícitas e separadas em cada Rota.

    Atualizado em 21 de agosto de 2026 Aquisição pontual Sem rastreamento em segundo plano Guia completo de funções
    01 / Visão geral

    Obter posição não implica metadados

    Cada Rota tem dois controles de localização separados. Usar localização atual define se a rota solicita uma localização na origem. Gravar metadados de localização define se o instantâneo também vai a metadados iniciais/inline.

    ControleO que significaO que não significa
    Permissão de localização do sistemaPermite ao Vox.md pedir localização durante uso do app ou captura compatível.Não ativa localização em nenhuma Rota.
    Usar localização atualSolicita uma localização para esta rota e a disponibiliza a {location}.Não grava YAML ou metadados inline automaticamente.
    Gravar metadados de localizaçãoGrava campos estruturados selecionados ou YAML avançado validado a partir do instantâneo.Não controla se {location} pode renderizar.
    Intenção está na rota, não na permissão

    Conceder a permissão Durante o uso só abre a porta do sistema operacional. Vox.md continua solicitando posição apenas para a ação independente Localização atual da Barra de captura ou para uma Rota na qual você ativou Usar localização atual.

    02 / Configuração

    Configure Localização atual em uma rota

    1. Abra Rotas.No iPhone/iPad abra Ajustes → Rotas. Mac: Ajustes e Rotas.
    2. Edite a rota.Escolha a rota que usa a posição de origem. Só afeta ela.
    3. Abra Localização.Ative Usar localização atual. Mantenha Gravar metadados de localização desligado para só token.
    4. Escolha a precisão.Use Exato para a posição de origem ou Cidade para coordenadas com duas casas decimais, sem rótulo de ponto de interesse.
    5. Escolha o comportamento quando a localização estiver indisponível.Pergunte, Enviar sem localização ou Cancelar captura determina o que acontece quando não é possível obter a posição do momento da origem.
    6. Adicionar {location} se desejar.Coloque token no modelo de entrada, prefixo/sufixo ou Markdown do cofre.

    O primeiro uso pode mostrar a solicitação de permissão de localização do sistema operacional. Se a permissão foi negada antes, ative o acesso à localização para Vox.md nos ajustes do sistema iOS, iPadOS ou macOS.

    03 / Configurações comuns

    Escolha o mínimo de localização necessário

    Resultado desejadoUsar localização atualGravar metadados de localizaçãoTemplo
    Sem localização na rotaDesativadoDesativadoNão use {location}, ou fica vazio.
    Só link clicávelAtivadoDesativadoAdicionar {location}. Nenhum campo de posição é gravado.
    Só metadadosAtivadoAtivadoOmitir {location}. Só os campos configurados são gravados.
    Link e metadadosAtivadoAtivadoAdicionar {location} e configure os campos.

    Desligar Usar localização atual impede token e metadados mesmo com formato antigo configurado para depois.

    04 / Token do modelo

    Usar {location} Sem alterar metadados da nota

    Com Usar localização atual ativado e o instantâneo da origem disponível, {location} gera link Markdown Google Maps validado:

    [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    O token funciona em Entrada do Templo reutilizáveis, prefixos e sufixos de entrada personalizados e modelos Markdown do cofre. Usa as mesmas coordenadas Exato ou Cidade selecionadas para a rota.

    Exemplo só com token

    Para sufixo como:

    Captured from {location}

    Vox.md pode produzir:

    Captured from [Location](https://www.google.com/maps/search/?api=1&query=45.501235%2C-73.567890)

    Com Gravar metadados de localização desligado, o link é o único conteúdo de posição. Nenhuma coleção locations: nem campos location.*:: são gravados.

    Correção com um toque no editor

    Se prefixo, sufixo ou modelo de entrada efetivo usa {location} com Localização atual desligada, o editor explica o token vazio e oferece Usar localização atual para [Route]. Essa ação ativa Localização atual para a rota, deixando intencionalmente Gravar metadados de localização desativado, para o próximo envio resolver o token sem alterar os metadados da nota. Arquivos de modelo ativos do cofre são lidos apenas durante o envio, portanto seu conteúdo não pode acionar essa dica no editor; ative Localização atual manualmente quando um modelo do cofre usar o token.

    Quando o token está vazio

    {location} vira string vazia com localização desativada, ausente ou envio sem posição. Considere pontuação/rótulos ao criar linhas opcionais.

    Ação independente da Barra

    A captura rápida Localização atual insere link Google Maps pontual no rascunho. Independente de Rotas, não muda Usar localização atual nem Gravar metadados de localização.

    05 / Saída de metadados

    Grave campos estruturados só se escolher

    Ative Gravar metadados de localização para campos legíveis por máquina além ou no lugar do {location} como link.

    Metadados iniciais da nota

    Adiciona cada posição à coleção chamada locations por padrão, com ID da Captura como chave. Metadados iniciais existentes não relacionados são preservados.

    Campos de entrada inline

    Grava campos estilo Dataview location.key:: value junto à entrada capturada. Nenhuma coleção de metadados iniciais é adicionada.

    Campos Estruturados

    Selecione e renomeie coordenadas, latitude, longitude, lugar, cidade, região, país, links de provedores, URI geo, precisão, horário, origem e ID.

    YAML avançado

    Usa um modelo YAML validado e limitado para os metadados iniciais da nota. YAML avançado não está disponível para campos inline de entrada.

    Exemplo de metadados iniciais estruturados

    ---
title: Field Notes
locations:
  - id: "aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee"
    coordinates: [45.501235, -73.567890]
    place: "Café & Main"
    appleMapsURL: "https://maps.apple.com/?ll=45.501235%2C-73.567890&q=Caf%C3%A9%20%26%20Main"
    timestamp: "2023-11-14T22:13:20.000Z"
    source: "app"
---

    Periódicas guardam várias capturas. A proteção contra novas tentativas faz parte da união de localizações: uma nova tentativa com o mesmo ID de Captura não pode adicionar a mesma posição duas vezes. Se a chave de coleção escolhida já contiver um valor incompatível escrito pelo usuário, Vox.md para em vez de sobrescrevê-lo.

    Exemplo de entrada inline

    location.id:: aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
location.coordinates:: [45.501235, -73.567890]
location.place:: "Café & Main"

Captured text

    Variáveis YAML avançadas

    Modelos avançados usam marcadores como {{coordinates}}, {{latitude}}, {{longitude}}, {{place}}, {{city}}, {{region}}, {{country}}, {{appleMapsURL}}, {{googleMapsURL}}, {{openStreetMapURL}}, {{geoURI}}, {{accuracy}}, {{timestamp}}, {{source}}, e {{id}}. Confira a prévia nos ajustes da rota antes de salvar.

    06 / Precisão e rótulos

    Exato e Cidade usam instantâneo consistente

    PrecisãoCoordenadasRótulosLinks e campos
    ExatoMantém a origem exibida com seis casas decimais.Pode incluir ponto de interesse se campo exigir.Todos os valores derivados usam Exato.
    CidadeArredonda latitude e longitude a duas casas antes de guardar.Remove pontos de interesse; cidade, região e país podem ficar.URL, URI geo, token e campos usam coordenadas arredondadas.

    O geocodificador reverso do sistema Apple é usado somente quando Gravar metadados de localização está ativado e um campo estruturado selecionado ou um marcador avançado precisa de lugar, cidade, região ou país. Uma rota apenas por token pula a geocodificação reversa. Se a consulta do rótulo falhar, a saída baseada em coordenadas continua disponível.

    07 / Fontes de captura

    Instantâneo pertence à origem

    Localização atual é avaliada na origem da captura. Novas tentativas e recuperação reutilizam esse resultado persistente em vez de obter silenciosamente uma localização mais recente.

    Origem da capturaMomento da aquisição
    Captura rápida iPhone e iPadEnvie
    CompartilhamentoEnvie no compartilhamento
    Intents texto, link e arquivo em fila diretaInvocação de intent
    Atalhos, widgets, controles e links que abrem Rápida capturaEnvie no editor
    Atalho, widget, controle, voz imediata e rota pelo tecladoParada da gravação
    Envio normal Captura Apple WatchParada da gravação no Watch; iPhone não substitui sua própria localização
    Captura MacEnvie, ou parada da gravação para envio imediato

    Watch Somente gravação exporta M4A bruto para Arquivos sem Markdown; não pede posição mesmo que a rota use em outros casos.

    08 / Indisponível e recuperação

    Defina como cada Rota trata posição ausente

    • Pergunte: capturas interativas permitem tentar novamente, cancelar, enviar uma vez sem posição ou escolher Sempre enviar sem localização para aquela rota.
    • Enviar sem localização: continua sem token ou metadados.
    • Cancelar captura: para o envio em vez de criar sem a posição original solicitada.
    • Redefina escolha salva: use Redefinir escolha de localização indisponível na rota.

    Um pedido Pergunte sem supervisão guarda o resultado indisponível do momento da origem para revisão posterior. Tentar novamente uma captura na fila ou com falha nunca substitui esse resultado por uma localização posterior. O trabalho pendente mantém apenas o instantâneo ajustado à privacidade ou o resultado indisponível necessários à recuperação local.

    09 / Rotas existentes

    Atualizações preservam o comportamento dos metadados

    Separar aquisição e saída protege a migração:

    • Rotas novas: Usar localização atual e Gravar metadados de localização começam desativados.
    • Rotas com localização já ativada: ambos ficam ativos após atualizar, preservando metadados anteriores.
    • Rotas com posição já desligada: ambos ficam desligados; atualizar não cria saída nova.

    Para converter de metadados a token, deixe Usar localização atual e desative Gravar metadados de localização. Markdown existente não muda.

    10 / Privacidade e retenção

    Um instantâneo explícito, sem rastreio em segundo plano

    • Vox.md não monitora continuamente ou rastreia em segundo plano.
    • A localização não vai a servidores Vox.md, análises, publicidade ou IA de terceiros.
    • URLs de token e provedores são locais. Apple Maps, Google Maps ou OpenStreetMap recebe coordenadas só ao abrir o link.
    • O geocodificador reverso do sistema Apple pode fazer uma solicitação de rede somente quando os metadados selecionados precisam de um rótulo de lugar. Localização somente por token pula essa consulta.
    • Após sucesso os pedidos viram recibos sem conteúdo; histórico não mantém coordenadas, rótulos, URLs ou modelos de posição.
    • Metadados/link em Markdown viram parte do arquivo escolhido. Seu provedor pode tratar pelos termos próprios.
    Permissão ativa não impede rotas privadas

    Você pode manter a permissão do sistema disponível para a ação independente Localização atual e ainda deixar o ajuste Usar localização atual desativado em todas as Rotas.

    Veja o Política de Privacidade para tratamento e retenção completos.

    11 / Solução de problemas

    Corrija problemas de posição/modelo

    {location} fica vazio

    Confirme que a Entrada do Templo, o prefixo, o sufixo ou o modelo do cofre efetivamente usado contém o token exato em minúsculas {location}. Em seguida, ative Usar localização atual na rota de envio. A correção com um toque do editor pode fazer isso para a formatação inline de entrada detectada sem ativar os metadados; arquivos de modelo ativos do cofre exigem configuração manual da rota. Se a permissão for negada ou a posição não estiver disponível, confira o comportamento da rota na ausência de posição e os ajustes de localização do sistema.

    Link funciona sem metadados

    Isso é esperado em uma configuração apenas por token. Abra os ajustes de Localização da rota e ative Gravar metadados de localização; depois escolha metadados iniciais da nota ou campos inline de entrada e selecione os campos desejados.

    Metadados aparecem, mas sem link

    Metadados não inserem link automaticamente. Adicione {location} ao formato efetivo ou modelo Markdown do cofre.

    Lugar ou cidade ausente

    Confirme que o campo de rótulo está selecionado. O geocodificador reverso da Apple pode falhar mesmo quando as coordenadas continuam disponíveis. A precisão Cidade remove intencionalmente os rótulos de pontos de interesse.

    Conflito ao enviar metadados iniciais

    A chave da coleção, locations por padrão, deve ser uma lista de localizações compatível. Renomeie a coleção nos ajustes da rota ou ajuste os metadados iniciais existentes escritos pelo usuário. Vox.md não sobrescreverá um valor incompatível.

    Uma nova tentativa tem localização antiga ou indisponível

    Intencional: guarda a origem para não alegar nova posição silenciosamente depois. Nova captura para novo instantâneo.

    Permissão concedida, mas a rota não solicita posição

    Permissão só libera o acesso. Edite a Rota e ative Usar localização atual. Permissão sozinha nunca ativa a rota.
