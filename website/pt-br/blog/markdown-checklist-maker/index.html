Gerador de checklist em Markdown: transforme qualquer lista em tarefas, com datas de vencimento

Cole linhas simples, marcadores, itens numerados ou uma lista de tarefas existente e copie tarefas - [ ] válidas, com aninhamento mantido, data de vencimento opcional e a contagem do que está concluído.

Por
Cody Bontecou
Atualizado
24 de novembro de 2026
Requer
Qualquer navegador moderno, incluindo o Safari no iPhone. Opcional: Obsidian para as checklists e Vox.md para iPhone ou Mac para capturar tarefas por voz.
Resposta curta

Uma tarefa em Markdown é um hífen, um espaço, colchetes, um espaço e o texto. Escreva - [ ] task para uma tarefa em aberto e - [x] done para uma tarefa concluída. Para transformar uma lista inteira em tarefas, cole-a no gerador de checklist abaixo.

- [ ] buy milk
	- [ ] oat
- [ ] call Sam
- [x] send invoice

O gerador remove marcadores, números e caixas de seleção existentes para que nada fique duplicado, mantém o recuo como aninhamento e pode adicionar uma data de vencimento no formato que o seu plugin do Obsidian lê. Ele roda inteiramente nesta página: a lista nunca é enviada, e a página não faz requisições de rede.

2. Sintaxe de checklist em Markdown

- [ ] unchecked task
- [x] checked task
- [ ] parent task
	- [ ] nested task

Cada tarefa é um item de lista: um hífen e um espaço, depois [ ] com um espaço entre os colchetes, depois o texto. Obsidian Help página e GitHub Docs página ambos descrevem como um hífen e um espaço seguidos de [ ]. Para marcar uma tarefa como concluída, o GitHub Docs diz para usar [x].

Os espaços importam. A especificação GitHub Flavored Markdown define o marcador da caixa de seleção como um colchete esquerdo, um caractere de espaço em branco ou a letra x, e um colchete direito, e exige um espaço em branco antes do texto que vem depois. Então [] sem nada dentro, ou - [ ]text sem espaço depois do colchete, não corresponde à definição. O hífen e o espaço dele é que fazem da linha um item de lista.

Listas de tarefas não fazem parte do Markdown básico. A mesma especificação as marca como extensão do CommonMark, e a introdução dela diz que recursos que não estão na especificação original do CommonMark são marcados como extensões. Um renderizador que não implementa a extensão mostra os colchetes como texto literal, que é o motivo habitual de uma caixa de seleção aparecer como [ ] na página.

3. Checklists no Obsidian

Na Ajuda do Obsidian, a página de sintaxe básica de formatação trata das listas de tarefas:

  • Uma tarefa começa com um hífen e um espaço seguidos de [ ].
  • Você pode usar qualquer caractere entre os colchetes para marcar a tarefa como concluída, então [x], [-] e [?] valem como concluída.
  • Você aninha uma lista de tarefas recuando os itens da lista. Use Tab ou Shift+Tab para recuar ou remover o recuo dos itens selecionados.
  • Você pode alternar uma tarefa no modo de leitura selecionando a caixa de seleção dela.

A página de ajuda documenta que qualquer caractere conclui uma tarefa. Ela não descreve uma aparência diferente para cada caractere. Se [-] ou [?] parece diferente de [x] no seu cofre, isso vem de um tema ou snippet de CSS que você instalou, não do Markdown em si.

A linha de progresso do gerador conta da mesma forma: qualquer caractere entre os colchetes que não seja um espaço significa concluída, então [x], [X], [-] e [?] estão concluídas e [ ] está em aberto. Linhas que começam com “done:” ou “x ” são texto comum; a ferramenta não presume que signifiquem uma tarefa concluída.

4. Datas de vencimento: Tasks, Dataview e Reminder

A sintaxe de lista de tarefas do Obsidian não tem data de vencimento própria: a página de ajuda não documenta nenhuma. Três plugins leem uma data escrita no texto da tarefa, cada um no seu formato. O gerador escreve a data em ISO YYYY-MM-DD em todos eles. Sem o plugin, a data é apenas texto.

FormatoLido porLinha de exemplo
Vencimento: 📅 YYYY-MM-DDTasks, que diz que a data deve estar escrita como YYYY-MM-DD (formato ISO)- [ ] send invoice 📅 2026-11-25
Agendada: ⏳ YYYY-MM-DDTasks- [ ] send invoice ⏳ 2026-11-25
Início: 🛫 YYYY-MM-DDTasks- [ ] send invoice 🛫 2026-11-25
Campo inline: [due:: YYYY-MM-DD]Dataview documentação, que lê campos escritos em uma tarefa, como [completion:: 2021-08-15]- [ ] send invoice [due:: 2026-11-25]
Lembrete: (@YYYY-MM-DD) ou (@YYYY-MM-DD HH:mm)plugin obsidian-reminder, cujo README mostra (@2021-08-14) e (@2021-08-14 09:37) em tarefas não marcadas- [ ] send invoice (@2026-11-25 09:30)

Escolha o único plugin que você usa. A página do Dataview também lista atalhos próprios em emoji para datas e diz que esses são os únicos atalhos compatíveis; o gerador escreve a forma com colchetes do Dataview. O README do Reminder diz que você não recebe notificações de lembretes em tarefas que já foram marcadas.

5. Diferenças entre GitHub e Obsidian

O GitHub Docs descreve [ ] para uma tarefa em aberto e [x] para marcar uma como concluída. A especificação GFM define o marcador como um espaço em branco ou a letra x entre os colchetes. O Obsidian aceita qualquer caractere. Então uma tarefa como - [-] skipped ou - [?] unsure está concluída no Obsidian, mas fica fora da definição de marcador da especificação, e um renderizador que segue a especificação pode mostrá-la como texto literal. Se o arquivo também for lido no GitHub, use [ ] e [x] apenas.

O GitHub Docs acrescenta uma regra: se a descrição de uma tarefa começa com um parêntese, coloque uma barra invertida antes dele, como em - [ ] \(Optional) Open a followup issue. O gerador não adiciona a barra invertida por você; ele avisa quando uma tarefa começa com parêntese.

6. Capture tarefas por voz ou texto no iPhone e no Mac com o Vox.md

O modo de processamento Todo Checklist do Vox.md gera tarefas em Markdown no formato - [ ] a partir de uma captura, e seu recurso de reserva é um formatador de checklist determinístico. A voz é transcrita no seu dispositivo. Na Capture Bar, Checklist aplica o prefixo - [ ] , e 2 Data de início insere (@yyyy-MM-dd) ou uma forma com horário. Consulte Rápida captura e Routes e modos de processamento na documentação.

Uma Route pode adicionar os itens à sua nota diária sob um título como ## Tasks; Adicionar a uma nota diária do Obsidian explica a configuração, e o gerador de modelo de nota diária escreve a estrutura da nota. Para itens de ação de uma reunião, veja o modelo de notas de reunião; para uma receita de prefixo de lista de tarefas, veja modelos de captura.

O Vox.md escreve o formato (@yyyy-MM-dd) mostrado na documentação. Ele não escreve datas em emoji do plugin Tasks nem campos do Dataview. Se você usa algum desses, cole as tarefas capturadas no gerador acima e escolha esse formato, ou edite a data depois. Para montar as propriedades no topo de uma nota, use o gerador de propriedades.

7. Perguntas

Por que minha caixa de seleção aparece como texto [ ]?

O renderizador não está exibindo listas de tarefas. Listas de tarefas são uma extensão do CommonMark, então um renderizador sem ela mostra os colchetes. Verifique se a linha começa com um hífen e um espaço, se há um espaço ou x entre os colchetes, e que um espaço vem depois do colchete de fechamento. No Obsidian, uma tarefa em um bloco de código ou em uma célula de tabela pode não ser exibida como caixa de seleção, como acontece com um item de lista.

Como aninho tarefas?

Recue a tarefa filha. No Obsidian, pressione Tab para recuar os itens selecionados e Shift+Tab para remover o recuo deles. O gerador converte 2 ou 4 espaços da sua lista em uma tabulação por nível, ou em 2 ou 4 espaços, se você preferir.

Como marco uma caixa com um caractere diferente de x?

A Ajuda do Obsidian diz que qualquer caractere entre os colchetes marca a tarefa como concluída, então - [-] task e - [?] task estão concluídas. O gerador mantém o caractere que você colou, a menos que você redefina a lista. Para arquivos que também são lidos no GitHub, use [x].

Como adiciono uma data de vencimento que o plugin Tasks lê?

Coloque 📅 e uma data no formato YYYY-MM-DD no fim da tarefa, por exemplo - [ ] send invoice 📅 2026-11-25. Escolha “Plugin Tasks: vencimento” acima para adicioná-la a todas as tarefas. Use ⏳ para uma data agendada e 🛫 para uma data de início.

O gerador envia a minha lista?

Não. A lista é convertida por um script nesta página, no seu dispositivo, e a página não faz requisições de rede. Ela não salva sua lista: fechar ou recarregar a página a apaga.
