Gerador de modelos de notas de reunião para o Obsidian

Escolha as propriedades e seções que quiser e copie ou baixe um modelo escrito na sintaxe do sistema de modelos que você usa.

Por
Cody Bontecou
Atualizado
19 de novembro de 2026
Requer
Obsidian (qualquer plataforma). Opcional: Vox.md para iPhone, iPad ou Mac para preencher notas a partir de uma gravação.

2. Adicione o modelo ao Obsidian

Plugin principal Templates. Ative Templates em Configurações → Plugins principais e depois defina Template folder location, por exemplo Templates. Salve o modelo ali como um arquivo .md . Numa nova nota, execute Templates: Insert template pela paleta de comandos e escolha-o. O Obsidian substitui {{title}}, {{date}} e {{time}} quando você insere o modelo. Um formato depois de dois-pontos, como {{date:YYYY-MM-DD}}, usa tokens do Moment.js. Veja a ajuda do plugin Templates e o guia de tokens de formato do Moment.js.

Plugin Templater. Instale o Templater em Plugins da comunidade e defina Template folder location. Insira o modelo com Templater: Open insert template modal. Para que toda nova nota em Meetings/ receba este modelo, ative Trigger Templater on new file creation, defina Template matching mode como modelos de pasta e associe a pasta Meetings ao arquivo. A documentação de configurações do Templater explica os modelos de pasta, e o módulo de data documenta tp.date.now.

Propriedades. O frontmatter entre as linhas --- vira propriedades da nota. Um link numa propriedade precisa estar entre aspas, por isso o campo do projeto é escrito "[[Project name]]". Veja Propriedades na Ajuda do Obsidian. Para verificar um frontmatter que você já tem, use o gerador e verificador de propriedades.

3. Uma nota por reunião

Mantenha as reuniões numa só pasta, como Meetings/, e coloque a data e a hora de início no nome do arquivo: Meetings/2026-11-19 1430 Design review.md. Nomes nessa ordem ficam ordenados por data, e duas reuniões no mesmo dia nunca dividem um arquivo.

Ative Link para a nota diária no gerador para adicionar uma linha Daily note: com link para a nota daquele dia. O link usa YYYY-MM-DD; se suas notas diárias usam outro formato de data, altere-o para corresponder; o gerador de modelo de nota diária mostra a prévia do nome do arquivo que um formato gera. Para listar também as reuniões do dia na nota diária, crie links a partir dela; adicionar a uma nota diária do Obsidian mostra como o Vox.md pode adicionar entradas a ela.

4. Itens de ação e acompanhamento

Escreva cada item de ação como uma tarefa do Obsidian, - [ ] Send the release notes, e marque-a como - [x] quando estiver concluída; veja Sintaxe básica de formatação. Coloque o responsável primeiro, para que cada linha diga quem faz o quê.

Se seus itens de ação já são uma lista simples, o Gerador de checklist em Markdown as transforma em tarefas e adiciona uma data de vencimento no formato Tasks, Dataview ou Reminder.

O estilo opcional adiciona uma data de vencimento no formato do plugin da comunidade Tasks: 📅 seguido de YYYY-MM-DD. O gerador preenche a data da reunião; troque pela data de vencimento real. Sem o plugin Tasks, o emoji e a data são texto simples e a tarefa continua funcionando.

Para reunir os itens em aberto de todas as reuniões num só lugar, adicione uma consulta do Tasks a uma nota:

```tasks
not done
path includes Meetings
```

A consulta lista tarefas não concluídas de notas cujo caminho contém Meetings. O Dataview pode montar listas parecidas, se você já o usa.

5. Preencha a nota a partir de uma gravação

Um modelo dá os títulos. O Vox.md pode escrever a própria nota: grava a reunião, transcreve no seu dispositivo e salva um arquivo Markdown no cofre por meio de uma Rota.

  1. Grave. No Mac, o Vox.md pode gravar um app de chamadas e o seu microfone em faixas separadas; siga Transcreva reuniões do Mac localmente no Obsidian. Para uma reunião presencial, grave com o microfone do iPhone ou iPad; veja salve voz iPhone no Obsidian.
  2. Escolha o destino. Na Rota, escolha seu cofre, selecione Nova notae informe um caminho como Meetings/{date}-{hour}{minute}.md. {date} é escrito como 2026-11-19 e {hour}{minute} como 1430. São tokens do Vox.md, não formatos do Moment.js. Veja Modelos de captura para Obsidian para mais receitas de caminhos.
  3. Escolha o modo. Defina o modo de processamento da Rota como Notas da reunião. Ele produz uma seção ## Notes e, quando a transcrição contém itens de ação, uma lista de verificação ## Action Items para marcar. Usa o Apple Intelligence em hardware compatível com macOS 26 ou iOS 26; caso contrário, um formatador determinístico monta a estrutura.

O modo Notas da reunião não preenche pauta, participantes nem decisões para você. Se quiser esses títulos acima das notas, escolha Markdown simples no gerador, desmarque Anotações e Itens de ação e salve o resultado no cofre. Depois, selecione esse arquivo como modelo do cofre da Rota. O Vox.md preenche no modelo os tokens entre chaves simples e escreve a transcrição processada abaixo dele. Confira a primeira nota antes de confiar no layout; a documentação de Rotas cobre destinos e modelos.

Se a reunião foi no Zoom ou no Teams e você baixou a transcrição como arquivo .srt ou .vtt, converta-a em Markdown com turnos de fala usando o Conversor de SRT e VTT, depois cole-o sob o ## Transcript título deste modelo.

Avise todos na reunião de que você está gravando e transcrevendo, e peça o consentimento deles antes. As regras variam conforme o lugar e o local de trabalho; veja avise as pessoas de que está gravando.

6. Perguntas

Devo usar o Core Templates ou o Templater?

O Core Templates vem com o Obsidian e cobre título, data e hora. O Templater é um plugin da comunidade que adiciona scripts, deslocamento de datas e modelos de pasta, de modo que uma nova nota em Meetings/ receba o modelo automaticamente. Se você só precisa dos campos desta página, o Core Templates basta.

Por que {{date}} não muda depois?

O Obsidian substitui as variáveis do modelo uma vez, quando você insere o modelo. Depois a nota guarda texto simples, como 2026-11-19, e o mantém. É isso que você quer num registro de reunião.

O Vox.md pode usar meu modelo do Obsidian?

Em parte. Uma Rota pode usar um arquivo Markdown do seu cofre como modelo. O Vox.md preenche seus próprios tokens entre chaves simples, como {date}, e os comandos de data do Templater tp.date.now e tp.file.creation_date. Ele não executa outros comandos do Templater, como tp.file.title, e não expande variáveis do plugin principal Templates, como {{title}}, então deixe-as fora do modelo de uma Rota. Use a saída Markdown simples para uma Rota do Vox.md.

O gerador envia minhas escolhas para algum lugar?

Não. O modelo é montado por um script nesta página. Ele salva suas últimas escolhas no armazenamento local do navegador, para que continuem lá na próxima vez, e Redefinir as apaga.
