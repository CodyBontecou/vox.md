Dates et liens

Les liens vers le jour précédent et suivant, ainsi que la lecture de la date depuis le nom du fichier, nécessitent Templater. La page de Core Templates ne documente aucun décalage de date : ces options sont donc désactivées pour Core Templates.

Avec Templater, les propriétés de date peuvent venir du nom de fichier de la note plutôt que du jour où vous la créez. Les deux options supposent que le nom de fichier correspond au format de date ci-dessous.

Le Markdown simple n’a pas de variables : ces options sont donc désactivées et les propriétés de date restent vides pour que vous les remplissiez.

2. Faire utiliser le modèle par Daily notes

Enregistrez le texte généré comme note dans votre dossier de modèles, par exemple Templates/Daily.md. Ouvrez ensuite Paramètres → Daily notes et, dans les options du plugin, définissez trois réglages :

  1. Format de date : la façon dont Obsidian nomme les notes quotidiennes et construit leur chemin. Copiez la valeur affichée au-dessus de l’aperçu.
  2. Emplacement des nouveaux fichiers : le dossier où Obsidian crée les nouvelles notes quotidiennes, si vous voulez les séparer des autres notes.
  3. Emplacement du fichier modèle : la note que vous venez d’enregistrer.

Obsidian n’utilise le modèle que lorsqu’il crée une nouvelle note quotidienne après ce réglage : les notes existantes ne sont donc pas modifiées. Pour le tester, ouvrez un jour qui n’a pas encore de note. Voir Notes quotidiennes dans l’aide d’Obsidian.

La date, le jour de la semaine et les tags entre les lignes --- deviennent des propriétés de la note ; voir Propriétés. Humeur et énergie sont vides pour que vous les remplissiez en texte.

3. Formats de date et dossiers

Le format de date utilise les tableau des jetons de format Moment.js. Le générateur prévisualise ces tokens courants, en anglais :

YYYYAnnée sur quatre chiffres2026
YYAnnée sur deux chiffres26
MMNuméro du mois, deux chiffres11
MNuméro du mois11
MMMNom court du moisnov.
MMMMNom complet du moisnovembre
DDJour du mois, deux chiffres21
DJour du mois21
dddNom court du jour de la semainesam.
ddddNom complet du jour de la semainesamedi
wwSemaine de l’année, deux chiffres (règles de semaine anglaises : les semaines commencent le dimanche et la semaine 1 contient le 1er janvier)47
QTrimestre4

Le texte entre crochets, comme [Week], est écrit tel quel. Tout autre token Moment n’est pas prévisualisé ; le générateur le signale, et la documentation de Moment.js le décrit.

Une barre oblique dans le format de date crée des sous-dossiers. L’exemple d’Obsidian est YYYY/MMMM/YYYY-MMM-DD, qui produit des notes comme 2023/January/2023-Jan-01 : le dossier de l’année, le dossier du mois, puis le nom du fichier. Si vous définissez aussi un Emplacement des nouveaux fichiers, les dossiers de date se placent à l’intérieur, donc Journal avec YYYY/MM/YYYY-MM-DD donne Journal/2026/11/2026-11-21.md.

Les noms de jours et de mois sont en anglais dans l’aperçu. Obsidian peut les afficher dans votre langue, et les numéros de semaine peuvent suivre les règles de semaine de votre région.

4. Core Templates ou Templater

Templates de base est fourni avec Obsidian. Il prend en charge {{title}}, {{date}} et {{time}}, et un format après deux-points, comme {{date:YYYY-MM-DD}}. {{date}} est la date d’insertion du modèle, et non une date lue depuis le nom de la note. La page d’aide Templates ne documente aucun décalage de date : les liens vers le jour précédent et suivant ne sont donc pas générés pour Core Templates.

Plugin Templater est un plugin communautaire. Sa fonction tp.date.now accepte un format, un décalage facultatif en jours, une date de référence facultative comme le titre de la note, et le format servant à lire cette référence. Les liens vers le jour précédent et suivant du générateur utilisent cette forme :

[[<% tp.date.now("YYYY-MM-DD", -1, tp.file.title, "YYYY-MM-DD") %>]]
[[<% tp.date.now("YYYY-MM-DD", 1, tp.file.title, "YYYY-MM-DD") %>]]

Comme elles lisent le nom du fichier, elles correspondent au jour de la note, même si vous la créez pour un autre jour. Le format du dernier argument doit correspondre au format du nom de fichier. Si le format de date contient des barres obliques, le générateur utilise la partie après la dernière barre oblique, c’est-à-dire le nom du fichier. Voir le module de date.

5. Ajouter à la note du jour depuis iPhone ou Mac

Un modèle donne sa forme à la note. Vox.md peut y ajouter du contenu pendant la journée : dites ou saisissez une pensée, elle est enregistrée dans la note du jour. La voix est transcrite sur votre appareil. Dans une Capture préalable, choisissez une Rolling note avec le Quotidienne avec une période quotidienne et un chemin comme Journal/{period}.md. Avec une période quotidienne, {period} se résout en une date comme 2026-11-21.

Choisir Le chef comme emplacement, puis le titre de votre modèle, par exemple ## Inbox, et les nouvelles entrées s’ajoutent en dessous. Si le titre est absent, choisissez Afficher l'erreur ou Créer un titre. Ajoutez un préfixe d’entrée comme - pour que chaque capture devienne un élément de liste ; la section Inbox du générateur utilise la même puce.

Vox.md n’applique pas votre modèle Obsidian lorsqu’il écrit dans un fichier. Si vous voulez le modèle, ouvrez d’abord la note du jour dans Obsidian, puis envoyez vos captures. Le chemin doit désigner le fichier qu’Obsidian utilise ; conservez donc des noms de fichier YYYY-MM-DD comme noms de fichier, sauf si vous avez vérifié la correspondance. Ajouter du texte et de la voix à une note quotidienne Obsidian couvre toute la configuration, et la Référence des Parcours énumère les options.

6. Questions fréquentes

Pourquoi mon modèle ne s’est-il pas appliqué ?

Obsidian n’utilise le modèle que lorsqu’il crée une nouvelle note quotidienne : les notes existantes restent inchangées. Vérifiez que Emplacement du fichier modèle dans Paramètres → Daily notes désigne la bonne note. Si le modèle contient des <% %> qui restent sous forme de texte, ce sont des commandes Templater : utilisez le modèle de dossier de Templater pour le dossier des notes quotidiennes, ou générez la version Core Templates.

Pourquoi ma note quotidienne est-elle dans le mauvais dossier ?

Deux réglages déterminent le chemin : Emplacement des nouveaux fichiers et les barres obliques dans Format de date. L’aperçu ci-dessus montre les deux ensemble. Si un format comme YYYY/MM/YYYY-MM-DD crée des dossiers d’année et de mois dont vous ne voulez pas, utilisez un format simple et définissez uniquement le dossier.

Puis-je utiliser Dataview ?

Le modèle est en Markdown simple : vous pouvez donc ajouter à la main un bloc de code pour n’importe quel plugin après l’avoir collé. Le générateur n’écrit pas de code de plugin à votre place.

Le générateur envoie-t-il mes choix quelque part ?

Non. Le modèle est construit par un script de cette page. Il enregistre vos derniers choix dans le stockage local de votre navigateur, pour les retrouver la prochaine fois, et Réinitialiser les efface.
