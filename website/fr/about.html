À propos de Vox.md

Capturez dans les notes qui vous appartiennent déjà

Vox.md est une app de capture locale pour les coffres Obsidian et dossiers Markdown. Elle est créée par Cody Bontecou à Isolated Tech. Capturez une idée, un lien, une photo, un fichier, un scan, un croquis ou une note vocale et envoyez-le à une destination précise sans d’abord fouiller vos notes.

Vox.md fonctionne sur iPhone, iPad, Mac et Apple Watch ; les fonctions et versions minimales du système sont documentées dans le guide complet des fonctions. Les préréglages de capture définissent dossier, note, modèle et position d’insertion. L’app écrit Markdown standard et pièces jointes ; vos fichiers restent utiles dans d’autres éditeurs.

Conçu pour les flux privés et locaux

La transcription vocale s’exécute sur l’appareil Apple via un moteur Apple Speech compatible ou un modèle Whisper ou Parakeet téléchargé facultativement. Aucun compte Vox.md ni plugin Obsidian n’est requis. Le contenu capturé est écrit dans le dossier choisi ; votre fournisseur de stockage peut le synchroniser. Lisez la politique de confidentialité pour les détails sur les modèles, autorisations, localisation facultative et services externes.

Essayer Vox.md et obtenir de l’aide

Le téléchargement gratuit comprend 15 minutes de transcription et 10 envois de Capture réussis. L’utilisation illimitée est disponible par achat à vie ; Apple affiche les prix locaux actuels dans l’App Store. Obtenez Vox.md dans l’App Store, lisez le guide de configuration, ou contactez le développeur.

Vox.md est open source. Vous pouvez inspecter l’implémentation et la licence dans le Dépôt GitHub. Ce site public fournit informations produit et documentation ; la capture s’exécute localement dans l’app installée, via son interface, Raccourcis et le schéma URL documenté.
