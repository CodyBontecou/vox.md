API d’information publique

Découvrir les données du produit et sa documentation

L’API d’information publique Vox.md sert des informations produit et liens de documentation publiée. Sa lecture est gratuite, sans compte, clé API, OAuth ni paiement. Ces endpoints renvoient des informations déjà publiques sur ce site. Lisez le Contrat OpenAPI 3.1 pour les schémas de réponse typés, identifiants d’opération, erreurs et descriptions.

Obtenir les informations produit

GET https://vox.isolated.tech/api/v1/product renvoie nom du produit, description, systèmes compatibles, fiche App Store, URL de documentation et d’assistance. La compilation dérive ces données des données structurées de l’accueil.

curl https://vox.isolated.tech/api/v1/product

Voir le JSON du produit

Trouver un document

GET https://vox.isolated.tech/api/v1/documents liste titres, résumés et URL des pages publiques. Repérez ainsi guide, politique, article ou assistance avant de demander le contenu.

curl https://vox.isolated.tech/api/v1/documents

Voir l’index documentaire JSON

Lire la page en Markdown

Demandez toute page listée avec Accept: text/markdown pour son contenu principal. Les requêtes avec Accept: text/html continuent à recevoir du HTML. Les deux représentations incluent Vary: Accept. Le guide pour agents explique les usages adaptés à Vox.md et renvoie aux détails.

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

Erreurs, cache et méthodes

Les endpoints JSON acceptent GET et HEAD. Les chemins d’API inconnus renvoient HTTP 404 avec application/problem+json, un identifiant stable code, une explication et une indication de récupération. Les méthodes non prises en charge renvoient HTTP 405 et Allow: GET, HEAD. Les réponses de métadonnées publiques autorisent la lecture entre origines et annoncent un cache de cinq minutes. Aucune donnée d’identification ni propre à l’utilisateur n’intervient.

Automatiser l’app installée

Capture, transcription, accès local au coffre et écritures s’exécutent dans l’app Apple installée. Utilisez le schéma documenté Intégrations Raccourcis et schéma URL avec l’autorisation du propriétaire de l’appareil. L’API publique n’expose pas les actions de capture, enregistrements, transcriptions, notes privées ou dossiers de destination. Contactez assistance Vox.md pour toute question.
