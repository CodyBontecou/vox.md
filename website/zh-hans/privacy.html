隐私政策

生效：2026 年 2 月 9 日 · 最后更新：2026 年 10 月 26 日

简而言之

Vox.md 将采集草稿、附件、转录文本和笔记路由保留在设备上。完成的文件仅发送到你选择的目标位置，绝不将采集内容发送至 Vox.md 服务器。正式版本发送下述粗粒度第一方引导分析数据。

概览

本隐私政策说明你使用 Vox.md（“我们”“我们的”或“本应用”）的 iOS 和 macOS 应用及其扩展时，我们如何处理信息。音频、转录文本、按键记录、采集草稿、附件、导出文件内容和用户输入文本均在本地处理。文件仅写入你选择的位置；所选存储提供商可能按其自身条款同步这些文件。

我们不收集的信息

Vox.md 不为开发者、分析、广告或跟踪收集以下任何内容。下述粗粒度引导元数据可自动离开设备。采集内容仅通过你选择的功能离开设备，例如写入同步文件夹或打开地图提供商链接，详见下文。

  • 音频录音或语音数据
  • 转录文本或转录历史记录
  • 按键记录、键入文本或键盘输入
  • 姓名、电子邮件或电话号码等个人信息
  • 供开发者、分析、广告或跟踪使用的位置数据
  • 你为本地采集明确选择的照片、扫描件、草图、音频和文件
  • 文件名、文件夹路径、模板文本、导出笔记内容或模型文件路径
  • 广告标识符、原始 IP 地址存储或第三方跟踪标识符

保护隐私的引导流程分析

正式版本会发送少量第一方事件，以了解引导流程、设置阻碍以及购买或恢复结果。开发版本需明确启用，才用于设置测试。这些事件刻意保持粗粒度，不用于广告或跨应用跟踪。

引导流程分析可能包含：

  • 仅用于统计漏斗进度的匿名 Vox.md 安装 ID
  • 事件名称，例如引导开始、麦克风权限完成、模型设置完成、付费墙显示、购买或恢复结果，以及引导完成
  • 应用版本、构建号、平台和实验变体
  • 粗粒度的设置状态，例如麦克风权限状态、模型引擎和大小分组、文件导出格式/模式、免费分钟数和成功采集用量分组，以及付费墙上下文

这些分析数据绝不包含音频、转录文本、听写文本、按键记录、文件/文件夹路径、模板文本、模型文件路径、姓名、电子邮件地址、原始日期、原始 IP 地址或设备名称。

设备端处理

所有语音转文字完全在设备上进行。在受支持的 iOS 26 设备上，自动模式使用 Apple 系统管理的 Speech 框架。你也可主动下载本地 Whisper 或 Parakeet 模型。麦克风采集的音频由所选设备端后端处理，绝不通过网络连接传输。

如果明确为路由启用采集文本处理，符合条件的键入文本、设备端 OCR 和语音转录可通过 Apple Intelligence 在本地整理或格式化。设备端智能不可用时，处理回退到确定性格式或原始文本。Vox.md 不会将采集文本发送至自身服务器或第三方 AI API。

转录结果、采集草稿和重试请求在本地存储于应用沙盒容器及共享 App Group 中。只有签名的 Vox.md 组件，如应用、键盘、小组件和共享扩展可访问这些数据。任何 Vox.md 服务或服务器都无法访问。

键盘扩展

Vox.md 包含自定义键盘扩展，可在设备上各应用中启用语音转文字输入。Apple 要求我们披露以下键盘扩展信息：

  • 当前键盘工作流需要允许完全访问。 它让键盘使用共享 App Group 状态，并与 Vox.md 主应用协调录音。
  • Vox.md 不使用完全访问权限上传、出售或分析按键记录、听写文本、转录文本或麦克风音频。键盘不会将这些内容传输至 Vox.md 或第三方服务器。
  • 键盘扩展通过设备上的共享 App Group 容器与签名的 Vox.md 应用组件通信。

麦克风使用

Vox.md 请求麦克风权限，以采集音频进行语音转录。麦克风音频：

  • 由 Apple Speech 或可选下载的 Whisper/Parakeet 模型在本地处理
  • 仅在本地转录需要文件时临时写入
  • 绝不传输至任何服务器、API 或第三方服务
  • 转录后移除，除非你明确配置路由保留音频，或将语音录音插入采集草稿

位置使用

Vox.md 有两项明确的位置功能。独立的采集栏目前位置操作会请求一次位置，并在本地草稿中插入 Google Maps 链接。另外，目前位置默认关闭，可按路由启用，适用于 iOS/iPadOS、共享表单、快捷指令与意图、语音及键盘驱动的路由录音、小组件与控件、路由到 Markdown 的 Apple Watch 采集，以及 Mac。路由可将这一次位置快照用于 {location} 条目模板链接，而无需写入额外元数据；写入位置元数据需要单独启用。手表仅录音仍是将原始音频导出至文件，不提供 Markdown 位置内容，也不请求位置。

已启用的路由根据采集来源，在发送、调用或停止录音时请求一次发起时位置。准确为默认选项。城市精度会在保留结果前将经纬度四舍五入到小数点后两位，并移除兴趣点名称；所有派生字段、模板链接和提供商链接都使用同一组按隐私设置调整后的坐标。Vox.md 不持续监测位置，不运行后台位置跟踪，不在分析或日志中包含位置，也不将位置发送至 Vox.md 服务器。

如果启用的元数据需要地点、城市、地区或国家，Vox.md 会使用 Apple 系统反向地理编码器。仅令牌的目前位置会跳过该查询。服务免费且无需 API 密钥，但可能按 Apple 条款向 Apple 发起网络请求。反向地理编码失败不会阻止采集；仅坐标元数据仍可用。Vox.md 可在不联系提供商的情况下生成 Apple Maps、Google Maps 和 OpenStreetMap 链接。只有打开链接时，才会向该提供商披露精确或舍入后的坐标。

位置不可用时，交互界面可重试、取消、仅本次不带位置发送，或为该路由保存始终不带位置发送；已保存的行为可在路由设置中重置。无人值守的询问请求会保留发起时位置不可用的结果，供稍后决定，重试时绝不获取更新的位置。待处理和失败的请求可能保留已按隐私设置调整的结果，以供本地恢复。写入 Markdown 的任何坐标都会成为所选笔记的一部分，而你选择的文件同步提供商可能按其自身条款处理该文件。

配置示例和采集来源行为请参阅 目前位置、 {location}，以及元数据.

语音模型

Vox.md 不捆绑语音模型权重。Apple 支持的语言资源由 iOS 管理。可选 Whisper、Parakeet 和语音停顿模型仅在你选择后开始下载，并存储于设备本地。准备或下载模型无需账户或个人信息。

第三方服务

Vox.md 不集成第三方分析 SDK、广告网络、崩溃报告 SDK 或跨应用跟踪服务。用户主动发起的 Whisper 和 Parakeet 模型下载，会直接或通过 FluidAudio 连接 Hugging Face 托管的模型分发设施。模型请求绝不包含采集草稿、键入文本、音频、转录、附件、文件路径或位置，但提供商可能按自身条款接收普通 HTTPS 连接数据及请求的模型标识符。

采集编辑器从以下服务批量请求励志名言： ZenQuotes API ，并从设备端缓存轮换显示。这些请求绝不包含采集草稿、键入文本、音频、附件、文件路径、位置、安装标识符或分析数据。与其他 HTTPS 服务一样，ZenQuotes 可能按其自身条款接收 IP 地址和用户代理等技术连接数据。第一方引导流程事件直接发送至 Vox.md Cloudflare Worker，并依据上述严格白名单存储在其 D1 数据库中。

数据存储与删除

采集内容和本地应用数据——包括转录历史、采集草稿、暂存附件、已下载模型、模板、设置和免费用量记录——存储于设备本地或你明确选择的文件目标位置。不含内容的成功采集台账，仅包含最多十次成功请求的计数和随机标识符，在本地应用数据保留期间防止重试被重复扣额。它不包含采集文本、文件名、目标位置或附件元数据，绝不存入系统钥匙串，也绝不发送给 Vox.md。

本政策变更前发布的版本可能在系统钥匙串中留下一个不再使用且不含内容的免费用量项目。当前版本不会访问它；可通过钥匙串访问将其移除，不影响采集、转录或购买。

本地最近采集列表仅包含投递元数据：结果、来源、路由标识符和显示名称、目标位置标识符和显示名称、相对笔记路径、附件数量、时间戳和粗粒度失败类别。它绝不复制笔记文本、链接、坐标、位置标签或模板、书签、绝对路径或附件文件名。待处理和失败采集仅保留本地恢复所需内容，其中可能包括已按隐私设置调整的位置快照或持久化的不可用结果。成功投递后，可恢复采集请求立即替换为仅含标识符和时间戳的墓碑记录；已完成的手表队列项同样会清理，升级会清除旧版已完成请求中的相关数据。

你可以通过以下方式删除本地存储的用户内容和设置：

  • 在应用内历史视图中删除单条转录或清除最近采集元数据
  • 在设置中移除已下载的模型
  • 移除 Vox.md 及其本地应用数据。这也会重置免费使用额度；符合条件的 StoreKit 购买仍可通过 Apple 恢复。

儿童隐私

Vox.md 不会故意收集任何人的个人信息，包括 13 岁以下儿童。上述保护隐私的引导流程分析无意识别或联系儿童，且绝不包含音频、转录文本、按键记录或用户输入的内容。

本政策的变更

我们可能不时更新本隐私政策。任何变更都会在本页反映，并更新“最后更新”日期。
