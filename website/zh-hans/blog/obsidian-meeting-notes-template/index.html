2. 将模板添加到 Obsidian

Core Templates 插件。 在“设置 → 核心插件”中开启 Templates，然后设置 Template folder location，例如 Templates。将模板以 .md 文件格式保存在那里。在新笔记中，从命令面板运行 Templates: Insert template ，然后选择该模板。Obsidian 会在你插入模板时替换 {{title}}, {{date}} 和 {{time}} 。冒号后的格式，例如 {{date:YYYY-MM-DD}}，使用 Moment.js 令牌。参阅 Templates 插件帮助 以及 Moment.js 格式令牌.

Templater 插件。 从社区插件安装 Templater，并设置其 Template folder location。使用以下命令插入模板： Templater: Open insert template modal。要让 Meetings/ 中的每条新笔记都使用此模板，请开启 Trigger Templater on new file creation，将 Template matching mode 设为文件夹模板，并将 Meetings 文件夹映射到该文件。 Templater 设置文档 介绍了文件夹模板，而 date 模块 记录了 tp.date.now.

属性。 位于 --- 行之间的 frontmatter 会成为笔记属性。属性中的链接必须加引号，所以 project 字段写成 "[[Project name]]"。参阅 属性 见 Obsidian 帮助。若要检查你已有的 frontmatter，请使用 属性生成器和检查器.

3. 每次会议一条笔记

把会议放在同一个文件夹中，例如 Meetings/，并在文件名中写入日期和开始时间： Meetings/2026-11-19 1430 Design review.md。按这种顺序命名的文件会按日期排序，同一天的两场会议也绝不会共用一个文件。

开启 链接到每日笔记 （在生成器中），即可添加一行 Daily note: ，链接到当天的笔记。链接使用 YYYY-MM-DD；如果你的每日笔记使用其他日期格式，请改成一致； 每日笔记模板生成器 可预览某个格式生成的文件名。若还想在每日笔记中列出当天的会议，请从那里链接它们； 追加到 Obsidian 每日笔记 介绍了 Vox.md 如何向每日笔记添加条目。

4. 待办事项与跟进

把每个待办事项写成 Obsidian 任务，例如 - [ ] Send the release notes，完成后将其勾选为 - [x] ；参阅 基本格式语法。把负责人放在最前面，这样每一行读起来就是谁做什么。

如果你的待办事项已经是普通列表, Markdown 清单生成器 会把它们变成任务,并添加 Tasks、Dataview 或 Reminder 格式的截止日期。

如果要的是决策和负责人表格，而不是任务列表，请将电子表格中的行粘贴到 Markdown 表格生成器 然后将结果复制到笔记中。

可选样式会添加截止日期，格式来自社区 Tasks 插件: 📅 后接 YYYY-MM-DD。生成器会填入会议日期；请改为实际截止日期。没有 Tasks 插件时，表情符号和日期只是普通文本，任务仍然有效。

要把所有会议中未完成的事项汇总到一处，请在笔记中添加一个 Tasks 查询：

```tasks
not done
path includes Meetings
```

该查询会列出路径包含 Meetings的笔记中未完成的任务。如果你已经在用 Dataview，它也能生成类似的列表。

5. 用录音填充笔记

模板为你提供标题。Vox.md 可以直接写出笔记：它会录下会议，在你的设备上转录，并通过路线把 Markdown 文件保存到你的仓库。

  1. 录音。 在 Mac 上，Vox.md 可以把一个通话应用和你的麦克风录制为独立的音轨；请按照 在本地将 Mac 会议转录到 Obsidian。对于线下会议，请用 iPhone 或 iPad 的麦克风录音；参阅 将 iPhone 语音笔记保存到 Obsidian.
  2. 选择目标位置。 在路线中选择你的仓库，选择 新笔记，并输入路径，例如 Meetings/{date}-{hour}{minute}.md. {date} 会写成 2026-11-19 和 {hour}{minute} 写成 1430。这些是 Vox.md 令牌，不是 Moment.js 格式。参阅 Obsidian 采集模板 ，了解更多路径示例。
  3. 选择模式。 将路线的处理模式设为 会议记录。它会生成 ## Notes 部分，并在转录文本包含待办事项时生成 ## Action Items 清单。在搭载 macOS 26 或 iOS 26 的兼容硬件上，它使用 Apple Intelligence；否则由确定性的格式器构建结构。

会议记录不会替你填写议程、参会者或决策。如果你想在笔记上方保留这些标题，请在生成器中选择 纯 Markdown ，取消勾选“笔记”和“待办事项”，然后将结果保存到你的仓库。接着把该文件选为路线的仓库模板。Vox.md 会填充模板中的单花括号令牌，并把处理后的转录文本写在模板下方。在依赖这一布局之前，请先检查第一条笔记； 路线文档 介绍了目标位置和模板。

如果会议在 Zoom 或 Teams 上进行,并且你已将其转录稿下载为 .srt 或 .vtt 文件,请将其转换为 Markdown(含发言人轮次),使用 SRT 和 VTT 转换器,然后将其粘贴到 ## Transcript 此模板的标题。

告诉会议中的每个人你正在录音和转录，并事先征得他们的同意。规则因地区和工作场所而异；参阅 告知他人你正在录音.

6. 常见问题

我应该使用 Core Templates 还是 Templater？

Core Templates 随 Obsidian 提供，涵盖标题、日期和时间。Templater 是一个社区插件，增加了脚本、日期偏移和文件夹模板，因此 Meetings/ 中的新笔记可以自动套用模板。如果你只需要本页中的字段，Core Templates 就够了。

为什么 {{date}} 之后不会变化？

Obsidian 只在插入模板时替换一次模板变量。之后笔记中保存的是纯文本，例如 2026-11-19，并会一直保持不变。这正是会议记录所需要的。

Vox.md 可以使用我的 Obsidian 模板吗？

部分可以。路线可以使用仓库中的 Markdown 文件作为模板。Vox.md 会填充它自己的单花括号令牌，例如 {date}，以及 Templater 日期命令 tp.date.now 和 tp.file.creation_date。它不会运行其他 Templater 命令，例如 tp.file.title，也不会展开核心 Templates 变量，例如 {{title}}，所以不要把它们放进路线的模板。Vox.md 路线请使用纯 Markdown 输出。

生成器会把我的选择发送到任何地方吗？

不会。模板由本页面中的脚本生成。它会把你上次的选择保存在浏览器的本地存储中，下次仍会保留；点按“重置”即可清除。

省去打字的麻烦。

录下会议，让 Vox.md 把笔记写入你的仓库。
