SRT 和 VTT 转文本或 Markdown 转换器

粘贴或打开来自 Zoom、Microsoft Teams、YouTube 或转录服务的字幕文件,即可得到可读文本、Markdown 转录稿,或另一种字幕格式。文件在你的设备上读取,绝不上传。

简短回答

粘贴或打开 .srt 或 .vtt 文件,选择“纯文本”或 Markdown,然后复制或下载。文件始终保留在你的设备上。

转换器会移除字幕编号和时间码,将各行合并为段落,并把说话人姓名转为笔记中的粗体说话人轮次。它还能在 SRT 与 VTT 之间互相转换。它使用浏览器的 FileReader API 读取文件,本页不会发出任何网络请求,因此你粘贴或打开的内容不会被发送到任何地方。

1. 使用转换器

  1. 添加文件。 将内容粘贴到框中,或选择一个 .srt, .vtt 或 .txt 文件。工具会检测格式并显示字幕条数。
  2. 选择输出。 纯文本、Markdown、SRT 或 VTT。
  3. 调整清理选项。 合并行为段落、在停顿后另起段落、移除重复的滚动行、去除标签,并保留或丢弃音效提示,例如 [Music].
  4. 复制或下载。 下载时会使用正确的扩展名: .txt, .md, .srt 或 .vtt.

2. SRT 与 VTT:它们是什么以及有何不同

两者都是纯文本字幕格式:一系列字幕条目,每条都有开始时间、结束时间和一些文本。美国国会图书馆将其描述为 SubRip (SRT) 格式 作为一种简单的文本格式,其中每条字幕都有顺序编号、开始和结束时间,二者以 -->,一行或多行文本,以及一个空行。其时间码为 hours:minutes:seconds,milliseconds。W3C 的 WebVTT 规范 定义了浏览器用于字幕的较新格式。

.srt.vtt
第一行第一条字幕的编号WEBVTT
毫秒分隔符逗号: 00:00:01,000句点: 00:00:01.000
小时始终写入可选: 00:01.000 允许
字幕编号每条字幕的顺序编号可选标识符
字幕设置无位置和对齐方式可以跟在时间戳之后,例如 align:start
说话人没有标准标记;人们会写 Name:语音范围: <v Name>text</v>
注释无NOTE, STYLE 和 REGION 块

转换格式时,转换器会执行以下操作:

  • SRT 转 VTT: 添加 WEBVTT 头部,并将时间戳中的每个逗号改为句点。
  • VTT 转 SRT: 会去掉头部、 NOTE, STYLE 和 REGION 块和字幕设置,将句点改为逗号,并从 1 开始重新编号。SRT 没有语音范围,因此 <v Name>text</v> 变为 Name: text.
  • 文本编码: 美国国会图书馆指出,SRT 没有字符编码标准,解析器必须自行检测。转换器按 UTF-8 读取文件。如果带重音的字母显示不正确,请先用文本编辑器打开文件并另存为 UTF-8。

3. 从哪里获取文件:Zoom、Teams 和 YouTube

请查看各厂商针对你的套餐和设置的页面,因为管理员和账户类型会影响你能下载的内容。

Zoom 云录制

Zoom 的支持文章 关于云录制的音频转录 指出,转录稿处理完成后,会作为单独的 VTT 文件与录制一同出现。这适用于云录制,并且必须为其启用音频转录。录制可生成的文件格式列于 Zoom 的录制文件格式指南.

Microsoft Teams 转录文本

Microsoft 关于下载 Teams 转录文本的支持文章 指出,默认情况下,组织者和共同组织者可以将转录稿下载为 .docx 或 .vtt 文件,并且你的 IT 管理员的策略可能会改变谁可以下载它。请选择 .vtt 并在此处打开。若要在转换前修正错误,请参见 Microsoft 关于编辑 Teams 转录文本的指南.

YouTube 字幕

YouTube 帮助页面 关于编辑和删除字幕 介绍了如何从 YouTube Studio 下载您自己频道视频的字幕轨道。它没有说明下载生成的文件格式，因此请粘贴或打开文件，让转换器自动检测。YouTube 的 支持的字幕文件类型列表 包括 SubRip (.srt) 和 WebVTT (.vtt)。

请仅下载你有权使用的字幕。本页不涉及他人的视频。

4. 将转录稿放入 Obsidian 笔记

  1. 选择 Markdown。 说话人姓名变为 **Name:**,同一说话人的连续字幕会合并为一个轮次。启用 添加 [mm:ss] 时间戳 如果你以后想在录音中找到自己所在的位置。
  2. 启用 Obsidian 属性 在顶部添加一个块,包含 title, date, source 和 tags. 它是有效的 YAML,写法遵循 属性生成器 写入。Obsidian 会将两个 --- 标记作为笔记最顶部的属性;参见 Obsidian 帮助中关于属性的页面.
  3. 粘贴到新笔记 在你的库中,例如在 Meetings 文件夹。如果你下载了 .md 文件,请将其移入库文件夹。
  4. 将其链接到会议笔记。 构建笔记,使用 会议记录模板生成器,然后添加一行,例如 Transcript: [[Team sync transcript]] 到它。如果从属性中链接,链接必须加引号: transcript: "[[Team sync transcript]]".

文本会经过转义,因此 *, $ 以及开头的 # 在 Obsidian 中不会变成格式、数学公式或标签。说话人姓名来自文件,分享笔记前请先检查。

5. 从音频而不是字幕文件开始

如果你只有录音,根本不需要字幕文件。Vox.md 在设备上转录,并将 Markdown 直接写入你的库。根据 模型文档,转录在 Apple 设备上运行:在受支持的 iOS 26 设备和语言上使用 Apple Speech,或使用你下载的可选 Whisper 或 Parakeet 模型;参见 Whisper 与 Parakeet 了解区别。说话人标签是 Route 中可选启用的步骤,名为 识别演讲者,它们是匿名的,并且尽力而为。

6. 常见问题

这会上传我的文件吗?

不会。你打开的文件由浏览器通过 FileReader API 读取,粘贴的文件则留在文本框中。转换由本页中的脚本完成,使用时页面不会发出任何网络请求。关闭或刷新页面后,文本即消失。

为什么有重复的行?

自动字幕经常滚动显示:每条新字幕都会重复上一条的内容再加一行新内容,因此相同的词会出现两三次。请启用 移除重复的滚动行. 它会移除与上一条字幕中某行完全相同的行。如果说话人确实连续说了两遍同一句话,该重复也会被移除,因此对于干净的人工字幕请保持关闭此选项。

可以保留时间戳吗?

可以。选择“纯文本”或 Markdown 后,启用时间戳选项,每个段落会以其第一条字幕的时间开头,形式为 [mm:ss]，或 [h:mm:ss] 一小时之后。若要保留每个字幕时间,请改为转换成 SRT 或 VTT。

如何把文本转回 SRT?

本工具不支持这样做。纯文本没有时间信息,因此生成 SRT 需要能将文本与音频对齐的工具。SRT 与 VTT 之间的转换会保留时间信息,因为两种格式都包含时间信息。

能在 iPhone 上使用吗?

可以。它使用普通表单控件和浏览器的文件选择器,并且是为在 iPhone 上的 Safari 中运行而编写的。复制会在 Safari 允许时使用剪贴板,否则会请你选择文本。
