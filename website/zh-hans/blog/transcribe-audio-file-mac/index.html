在 Mac 上本地转录音频文件为 Markdown

先看免费的内置选项，再看一条本地路径：从你已有的文件到 Obsidian 或任意文件夹中的 Markdown 笔记。

作者：
Cody Bontecou
更新于
2026年11月22日
需要
Vox.md：macOS 14 或更高版本 · 已下载的语音模型。Apple 内置转录：请参阅 Apple 支持页面，了解适用于你的 Mac 和语言的情况。
简短回答

Apple 的语音备忘录和备忘录可以在 Mac 上免费转录音频，对许多人来说这就够了。要把现有的音频或视频文件变成 Markdown 笔记，请打开适用于 Mac 的 Vox.md，选择 导入音频… 从菜单栏（或在采集工作区中导入文件），让本地 Whisper 或 Parakeet 模型进行转录，检查文本，然后发送到路由的笔记。

以下 Apple 的详情来自 Apple 支持页面 在 Mac 的语音备忘录中查看转录 和 在 Mac 的备忘录中录制并转录音频，查阅于 2026 年 11 月 22 日。Apple 的页面可能会变化，请针对你的 Mac 核对。Vox.md 的步骤依据 Mac 文档.

Mac 上已有的免费选项

语音备忘录

Apple 的语音备忘录页面说，你可以点按 转录 按钮可在录音时实时查看文本，或选中已完成的录音后点按同一按钮。你可以在录音列表中搜索标题或转录中的文本，也可以选中转录文本后按住 Control 点按并选择 复制。Apple 表示，如果你打开在 macOS 14 或更早版本中、或在不支持转录的设备上制作的录音，语音备忘录会自动转录它；音频转录并非在所有国家或地区都可用。

笔记

Apple 的备忘录页面介绍了在笔记中录音：点按“附件”按钮，选择 录制音频，录音，然后点按“转录”按钮查看转录文本。页面说明，音频转录适用于搭载 M1 或更新芯片的 Mac，并且设备语言需在 Apple 该页面列出的范围内。如果没有出现“转录”按钮，Apple 表示你的 Mac 不满足最低要求，或未检测到受支持的语言。

局限

文本会留在这些 App 内，直到你把它复制出来。Apple 表示，在备忘录中删除音频录音也会删除转录文本。两款 App 能导入哪些文件类型，我们无法从 Apple 的页面查证，请针对你的录音自行检查；本指南对此不作任何说明。

万不得已时，有人会播放音频并对着文本编辑器听写。这只是变通办法，不是文件转录；请参阅 Mac 听写 了解听写本身。

如果文本只需保留在语音备忘录或备忘录中，直接使用它们即可。当你想要一个归你所有的纯文件、指定的本地模型，或让文本进入你的仓库时，才需要 Vox.md。

准备适用于 Mac 的 Vox.md

  1. 安装。 适用于 Mac 的 Vox.md 需要 macOS 14 或更高版本。请通过下方的 App Store 链接获取。
  2. 下载模型。 开放 设置 → 模型 并下载一个：Whisper 从 Tiny (75 MB) 到 Large v3 Turbo (1.6 GB)，Parakeet v2（约 800 MB，英语）或 Parakeet v3（约 800 MB，25 种语言）。在同一屏幕上设置转录语言。Whisper 在受支持的 Mac 上使用 Metal 加速。下载模型是唯一需要联网的步骤。请参阅 Whisper 与 Parakeet 来选择。 whisper.cpp 运行 Whisper 模型，而 FluidAudio 运行 Parakeet。
  3. 选择或创建一个路由。 路由包含目标文件夹或仓库以及目标笔记：新笔记、滚动的每日笔记，或某个标题下的现有笔记。请参阅 文档中的路线.

已经有字幕文件(.srt 或 .vtt)而不是音频?你无需转录任何内容: SRT 和 VTT 转文本或 Markdown 转换器 在浏览器中将其清理干净。

导入并转录文件

  1. 导入。 在 Vox.md 菜单栏中选择 导入音频…，或把音频导入或拖入采集工作区。文档说明音频和影片文件均可接受，并且与录音走相同的本地转录流程。
  2. 选择添加到草稿或立即发送。 使用 立即发送 转录完成后会投递。使用 添加到草稿 你可以先检查。请对照音频核对姓名、数字和日期。
  3. 可选：识别演讲者。 开启 识别演讲者 在路由上获得匿名、尽力而为的说话人标签。它首次会准备一个单独的模型。如果无法运行，会保留纯文本转录，原因显示在资料库中。
  4. 可选：处理模式。 路由可以使用保留原文、润色文本、会议记录、任务清单或自定义指令。Apple Intelligence 模式需要兼容 macOS 26 的硬件。没有时，任务清单和会议记录使用内置格式化器，而润色文本和自定义指令会保留原始文本。
  5. 发送。 按 Command-Return，将采集内容发送到路由的笔记。

检查 Markdown 笔记

选择 显示上次导出 从菜单栏，或在资料库中找到该条目并在 Finder 中显示，然后在 Obsidian 中打开文件。如果只需要文本，请选择 复制上次转录。如需一个可由录音填充的笔记结构，请参阅 会议记录模板生成器.

哪些内容会离开你的 Mac

转录在 Mac 上运行，Vox.md 不会把采集内容发送到 Vox.md 服务器。下载模型会连接 Hugging Face 或 FluidAudio 的基础设施。如果目标文件夹通过 iCloud 或其他服务同步，该服务会按其自身条款处理文件。请参阅 隐私政策.

故障排查

  • 没有转录，或语言不对。 在设置 → 模型中，检查模型已下载并选中，且语言已设置。
  • 没有出现笔记。 检查路由的目标文件夹，并确认 Vox.md 有权访问它。
  • 较长的文件需要一些时间。 较大的模型处理长录音需要更多时间。先试较小的模型，再比较。
  • 免费额度已用完。 其中包含 15 分钟转录和 10 次成功投递，之后一次性买断终身解锁。以 App Store 价格为准；请参阅 免费使用与终身解锁.
