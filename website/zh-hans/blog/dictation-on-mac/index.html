如何在 Mac 上听写，以及一个私密的本地选项

几步设置 Dictation，不工作时修复它，并决定你是想要本地模型还是 Markdown 笔记。

作者：
Cody Bontecou
更新于
2026年11月22日
需要
Vox.md：macOS 14 或更高版本。Apple Dictation 的可用性取决于你的 Mac、macOS 版本和语言。
简短回答

在 System Settings > Keyboard 中开启 Apple Dictation，然后在任何文本栏中按 Dictation 快捷键。如果你想选择本地 Whisper 或 Parakeet 模型，或将听写内容发送到 Markdown 笔记，请分配一个 Vox.md 全局快捷键。

下面的 Apple 步骤取自 Apple 支持页面 在 Mac 上使用 Dictation，阅读于 2026 年 11 月 22 日。不同 macOS 版本的菜单名称可能不同，请查看该页面以获取你的版本。Vox.md 的步骤遵循 全局快捷键 和 模型 文档。

如何在 Mac 上开启听写

  1. 选择 苹果菜单 > 系统设置，然后点击 键盘 在侧边栏中。
  2. 前往 听写 并将其开启。
  3. 快捷键： 在同一位置，点击 快捷键 弹出菜单，选择启动 Dictation 的快捷键。Apple 的页面没有给出默认值，所以请查看你的 Mac 上的设置。
  4. 语言： 点击 编辑 旁边的 Languages，然后选择语言和地区。听写时，你可以点击光标旁的语言来切换，或者如果键盘上有 Globe 键，也可以按它。
  5. 麦克风： 使用 麦克风来源 弹出菜单，选择 Dictation 使用的麦克风。选择 Automatic 时，Apple 表示你的 Mac 会监听你最可能使用的设备。
  6. 开始听写： 点击文本栏，然后按麦克风键（如果你的功能键行有），使用 Dictation 快捷键，或选择 编辑 > 开始听写.
  7. 停止： 按 Escape 键、麦克风键（如果有）或 Dictation 快捷键。

Apple 对处理和限制的说明。 Apple 说你可以在 Keyboard 设置中查看常规文本 Dictation 是否“在你的设备上处理，而不发送到 Siri 服务器”。该页面没有说明 Dictation 可以离线使用。Apple 还说你可以听写任意长度的文本而没有超时，并且在 30 秒内检测不到语音时 Dictation 会自动停止。与 Apple 共享音频录音是可选的（共享音频录音）。Apple 指出 Dictation 并非在所有语言或地区都可用，功能可能有所不同；请参阅 Apple 的 Dictation 页面 以及它所链接的 macOS 功能可用性页面。开启 Voice Control 后，Apple 表示标准的 macOS Dictation 不可用。

Apple Dictation 或本地听写应用

Apple Dictation 已经在你的 Mac 上，对很多人来说足够了。当你想选择语音模型、从设计上不让转录文字进入 Apple 的服务器，或将语音保存为 Markdown 时，再考虑其他方案。该表按文档所述比较三种设置；不涉及准确度或速度方面的说法。

如果你只是偶尔需要对着电子邮件或文档说话，内置 Dictation 就够用了。当你想用特定的本地模型，或希望文字直接进入你的笔记时，值得试试 Vox.md 快捷键。

用 Vox.md 在任何 Mac 应用中听写

转载到 Clipboard 是一个全局快捷键。你按下它，说话，再按一次。Vox.md 在你的 Mac 上转录，并把文字放到剪贴板，你用 Command-V 粘贴。它不会自动输入到最前面的应用中。它不会创建笔记和 Library 项目，也不保留音频。

  1. 安装并下载一个模型。 安装适用于 Mac 的 Vox.md（macOS 14 或更高版本）。在 模特 屏幕上，下载一个模型：从 Tiny（75 MB）到 Large v3 Turbo（1.6 GB）的 Whisper、适用于英语的 Parakeet v2，或支持 25 种语言的 Parakeet v3（各约 800 MB）。每次下载都由你发起，之后也可以删除模型。Whisper 在受支持的 Mac 上使用 Metal 加速。在同一屏幕上选择转录语言。请参阅 Whisper 与 Parakeet 了解如何选择。
  2. 分配快捷键。 开放 设置 > 全局快捷键 并分配 转载到 Clipboard。快捷键默认关闭。快捷键需要一个非修饰键，加上 Control、Option 或 Command，也可以包含 Shift，Vox.md 会拒绝冲突的快捷键。
  3. 录音。 点击你想放置文字的位置，按下快捷键，然后说话。
  4. 停止。 再次按下同一个快捷键。等待菜单栏显示转录已完成。
  5. 粘贴。 按 Command-V。

如果你需要再次获取文字，请选择 复制上次转录 从 Vox.md 菜单栏。菜单栏操作列在 菜单栏文档。iPhone 上的对应方式是键盘；请参阅 iPhone 语音转文字键盘指南 和 如何在 iPhone 上使用语音转文字 或 在 iPad 上.

听写到 Obsidian 笔记或 Markdown 文件中

当文字应该进入笔记而不是另一个应用时选择它。在 设置 > 全局快捷键，为以下操作分配快捷键 所选路线 或指定的路线。之后转录文字会遵循该路线：每日笔记、标题位置以及你在那里设置的处理模式。这不是粘贴；Vox.md 会把文字送达路线的目的地。在以下位置设置路线 每日笔记模板指南 和 采集模板指南。如需录制通话而不是听写，请参阅 将 Mac 会议录入 Obsidian。免费额度包含 10 次成功的 Capture 送达。

听写也是大声排练演讲的快速方式：听写一遍完整演讲，记下所用时间，然后把文本和时间粘贴到 演讲时长计算器 以找出你的真实语速。

留在 Mac 上的内容

Vox.md 不会把采集内容发送到 Vox.md 服务器。转录在你的 Mac 上运行。唯一的网络使用是你自己发起的模型下载，它使用 Hugging Face 或 FluidAudio 的基础设施。转录本身在 Mac 上运行。如果笔记落在通过 iCloud 或其他服务同步的文件夹中，该服务会按自己的条款处理该文件。请参阅 隐私政策 和 离线转录设置。Vox.md 使用 whisper.cpp 用于 Whisper，以及 FluidAudio 用于 Parakeet。

Mac 听写不工作

Apple Dictation 检查项

Apple 的页面 如果 Mac 上的 Dictation 未按预期工作 列出了这些：

  • 确保在 Keyboard 设置中已开启 Dictation。
  • 选择正确的语言和地区。Dictation 并非在所有语言或地区都可用。
  • 请确保使用了正确的 Dictation 键盘快捷键。如果其他快捷键使用了相同的按键，请在 Keyboard > Dictation 中更改 Dictation 快捷键。
  • 如果你的 Mac 没有内置麦克风，请确保已连接外接麦克风，并在 Sound 或 Keyboard 设置中选中，且输入音量足够。
  • 确保麦克风没有被遮挡，以不太小也不太大的音量清晰说话，并避免背景噪音。
  • 你可能需要互联网连接；请在 Keyboard 设置中查看听写是否在你的设备上处理。

Vox.md 检查

  • 快捷键没有反应。 快捷键默认关闭。请在 Settings > Global Keybinds 中分配一个。Vox.md 会拒绝冲突的快捷键，所以请选择其他按键组合。
  • 没有转录文字。 确保已在 Models 屏幕上下载并选择了模型。
  • 语言错误。 在 Models 屏幕上选择语言。
  • 没有可粘贴的内容。 等菜单栏显示转录已完成，然后按 Command-V，或选择 Copy Last Transcript。

常见问题

Mac 听写可以离线使用吗？

Apple 的 Use Dictation 页面没有这样说。它说你可以在 Keyboard 设置中查看常规文本 Dictation 是否在你的设备上处理，而不发送到 Siri 服务器。其故障排除页面说你可能需要互联网连接。下载模型后，Vox.md 在你的 Mac 上转录。

有时间限制吗？

Apple 表示你可以听写任意长度的文本而没有超时，并且 30 秒没有语音时 Dictation 会停止。对于 Vox.md，免费层包含 15 分钟转录，之后是一次性终身解锁。

我可以更改快捷键吗？

可以，两者都可以。对于 Apple Dictation，请使用 System Settings > Keyboard > Dictation 中的 Shortcut 弹出菜单。对于 Vox.md，请在 Settings > Global Keybinds 中分配，使用非修饰键加 Control、Option 或 Command。

Vox.md 需要账户吗？

否。

在你的 Mac 上用本地模型听写。
