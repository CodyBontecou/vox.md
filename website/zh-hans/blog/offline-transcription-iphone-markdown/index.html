iPhone · 本地转录 · Markdown

在 iPhone 上离线将音频转录为 Markdown

需要之前先准备语音后端和本地目标位置。将转录和文件同步视为独立选择。

作者：
Cody Bontecou
更新于
2026 年 10 月 26 日
需要
后端已就绪 · 文件夹可写
简短回答

Vox.md 使用可用的 Apple Speech 后端，或明确下载的 Whisper 或 Parakeet 模型，在设备上转录。离线保存 Markdown 转录文本还需要本地可用、可写的文件夹。断网前请准备好两者。

“本地转录”描述识别运行的位置，不承诺模型已安装、支持所有语言，或云端文件夹离线可用。本指南解释设置及你可在自己手机上执行的检查，并非对每款受支持设备进行飞行模式测试的报告。

本指南中
  1. 准备语音后端
  2. 选择 Markdown 目标位置
  3. 录制或导入音频
  4. 离线检查完整工作流
  5. 了解隐私与可用性限制

1. 联网准备语音后端

打开 Vox.md 模型设置，选择设备和语言可用的后端。自动模式在支持的 iOS 26 设备和语言上优先使用 Apple Speech。可选 Whisper 和 Parakeet 模型会在你选择时下载。

离线前完成模型下载或系统语言准备。自动模式不会悄悄下载 Whisper 或 Parakeet 备用模型，只能使用你已选择下载的备用模型。如果后端未就绪，断网并不会让它变得可用。

明确选择 Whisper 和 Parakeet 时，录音停止后转录。实时 Apple Speech 可在支持设备上显示暂定与定稿文本。生成 Markdown 转录无需实时预览。

模型选择影响存储用量、处理时间、语言覆盖和识别质量。请检查 模型参考 不要假定更大模型受支持，或某个选项能识别所有语言。

2. 选择 Markdown 目标位置

创建或选择采集预设，并通过文件连接文件夹。首次测试使用新笔记目标，方便辨认输出。需要转录文本而无需可选改写时，保留原文处理是不错的起点。

确保目标位置本地可用且允许写入。文件中出现文件夹名，不一定代表内容已下载。若选择 Obsidian 仓库，它必须可通过选择器供 Vox.md 访问；Vox.md 不直接连接 Obsidian Sync 服务。

详细文件夹设置请按照 将 iPhone 语音笔记保存到 Obsidian。普通可写 Markdown 文件夹也适用；转录不要求 Obsidian。

从 Apple 语音备忘录开始？请按照 语音备忘录转录和音频导出选择器 再导入录音。

3. 录制或导入音频

  1. 打开快速捕捉，选择已准备好目标位置的预设。选择 添加到草稿 在开始前于语音控件中选择，以便核对首次转录。
  2. 录制一段简短语音笔记，或使用 导入音频或视频 在语音控件中选择现有的受支持文件。
  3. 等待所选后端完成识别，在草稿中核对转录，再轻点发送。
  4. 检查投递已完成，再在目标位置打开 Markdown 文件。

一段简短录音可能生成以下示例笔记正文：

Review the outline before the next meeting.

实际措辞和标点取决于识别和处理。需要参考时请保留源音频，并对照核对重要转录。可选整理功能有自身的设备要求和回退方式；设备端转录不意味着所有受支持手机都能使用 Apple Intelligence 处理。

离线检查完整工作流

联网采集成功后，断网重复一次小测试。使用飞行模式时，也请确认 Wi-Fi 已关闭。

  1. 确认所选后端已准备好，目标位置在本地可用。
  2. 断网，新录一段简短内容，等待转录。
  3. 核对并发送转录文本。保持断网，检查完成的 Markdown 文件。
  4. 准备好后重新联网，单独检查同步到其他设备的情况。

成功意味着识别和本地写入均已完成。草稿中可见转录文本只证明识别成功；采集已排队尚不能证明目标写入成功。投递失败时，保留可恢复的采集，恢复文件夹访问后重试，不要再复制一份录音。

了解隐私与可用性限制

Vox.md 不上传音频进行转录。如果你有意将生成的转录或保留音频保存到云端文件夹，提供商可按自身条款同步。不想通过提供商同步该文件时，请使用本地目标位置。

长录音、可用存储、音频质量和模型支持影响实际结果。本指南不对转录速度或准确度作普遍承诺。使用前请核对敏感或可能产生重大影响的措辞。

对于手表录音， 仍由配对的 iPhone 执行转录和投递。手机不可用时将录音留在手表上，属于延迟投递，而不是独立的手表转录。
