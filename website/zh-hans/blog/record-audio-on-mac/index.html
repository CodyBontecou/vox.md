如何在 Mac 上录音：你的声音或某个 App 的声音

先介绍 Apple 的内置录音工具及各自的 Apple 支持页面，再介绍用于 App 音频的本地方案、保留的音频文件和可选的设备端转录。

作者：
Cody Bontecou
更新于
2026年11月26日
需要
macOS 14+ · 麦克风访问权限 · 可写入的文件夹
简短回答

要录制你的声音，请使用 QuickTime Player（文件 → 新建音频录制）或 Voice Memos，两者都是内置的。要录制某个 App 播放的声音，或同时录制 App 和你的麦克风，需要能捕获 App 音频的工具。Vox.md for Mac 可在你的 Mac 上做到这一点，并能将音频与 Markdown 笔记和转录文本一起保存。

下面的菜单名称来自 Apple 支持页面，每一节都附有链接。你的菜单可能因 macOS 版本而略有不同。Vox.md 的步骤依据 Mac 工作区文档 以及 会议捕获文档.

使用 QuickTime Player 录音

这些步骤依据 Apple 的 在 Mac 上使用 QuickTime Player 录音.

  1. 打开 QuickTime Player 并选择 文件 → 新建音频录制.
  2. 点按“录制”按钮旁边的箭头以打开选项菜单。在 麦克风，如果有多个输入，请选择输入设备。在 质量，选择一项设置；Apple 指出，最高质量会生成未压缩的文件，可能占用大量存储空间。
  3. 点按 录音 按钮开始，完成后点按 停止 按钮。Apple 表示，你可以按住 Option 键点按该按钮来暂停，再次点按即可继续。
  4. 选择 文件 → 存储 为录音命名并选择保存位置。

QuickTime Player 不会生成转录文本，Apple 的页面介绍的是选择麦克风，而非捕获 App 的声音。

在 Mac 上使用 Voice Memos 录音

Apple 的 在 Mac 上创建录音 提供了这些步骤。

  1. 打开“语音备忘录”App（Voice Memos）。
  2. 点按 录音 按钮。你可以使用内置麦克风、受支持的耳机或外接麦克风录音。
  3. 点按 暂停 暂停，用 继续 以继续。
  4. 点按 完成 以保存录音。

为 Voice Memos 开启 iCloud 并在每台设备上使用同一 Apple 账户后，录音会出现在你的 Mac、iPhone 和 iPad 上；参见 Apple 的 在所有 Apple 设备上查看你的录音。要将备忘录转成文字，请参见 在 iPhone 上转录 Voice Memos。Apple 还在以下页面介绍了转写视图： 在 Mac 上查看 Voice Memos 转写.

用 Shift-Command-5 录制屏幕和声音

Apple 的 在 Mac 上截屏或录制屏幕 表示要按下 Shift-Command-5 以打开“截屏”并显示其工具。选择一种屏幕录制工具，然后打开 选项 弹出式菜单。在 麦克风，选择你想用的麦克风，使其旁边出现勾选标记；选择 无 以将其关闭。选项菜单还涵盖录音保存位置等设置。

Apple 的页面将麦克风描述为音频选项。它没有介绍录制 App 自身的声音，因此本指南不声称工具栏能做到这一点。

录制某个 App 播放的声音

Apple 是从麦克风的角度介绍上述内置录音工具的。如果你需要某个特定 App 播放的声音，例如讲座直播、通话或视频，就需要能够捕获 App 音频的软件。下面的方案不使用虚拟音频驱动程序。

macOS 通过隐私权限控制此功能。Apple 在以下页面作了说明： 在 Mac 上控制对屏幕与系统录音的访问：有些 App 可以录制你 Mac 上的屏幕和音频，你可在以下位置控制是哪些 App： System Settings → 隐私与安全性 → 屏幕与系统音频录制.

Vox.md 如何做到。 Meeting 模式使用 Apple 的 ScreenCaptureKit 框架 ，采用单应用模式：

  1. 将输入模式从 麦克风 到 会议.
  2. 开始录制。macOS 会显示其内容选取器；请只选取一个应用程序。
  3. 你的麦克风会录为单独的轨道，Vox.md 绝不会录制它自己的声音。
  4. 按停止。每条轨道都会在你的 Mac 上转录，两者的回放混音会保留为录音的音频。

这是选定的一个 App 加上你的麦克风，而不是 Mac 发出的所有声音。Meeting 捕获无法暂停。完整设置（包括 Routes、说话人标签和恢复）请参见 在本地将 Mac 会议转录到 Obsidian.

录音前先征求同意。 各地的录音法律和工作场所规定不同。录制他人时请告知对方并征得其同意。这不构成法律意见。

用 Vox.md 将你的声音录入笔记

对于你自己的声音，Vox.md for Mac 从麦克风录入笔记，而不是单独的文件。

  1. 在 Capture 工作区中，选择 添加到草稿 ，这样转录文本会进入编辑区供你审阅，而不是立即发送。
  2. 录制。使用状态栏中的 暂停 和 继续 可将一条笔记分段录制。暂停期间的音频不包含在录音中。
  3. 在 Route 中，将 保存音频 到 笔记旁边 或 附件文件夹 以保留音频文件。参见 音频保留.
  4. 使用 Obsidian 语法将保留的音频嵌入笔记，例如 ![[recording.m4a]].

如果你下载 Whisper 或 Parakeet 模型，Vox.md 还会在你的设备上提供转录文本。 模型参考 列出了大小和语言，并且 Whisper 与 Parakeet 可帮助你选择。如果你只想把语音输入到其他 App 中，请参见 Mac 听写。设置详情见 Mac 工作区文档，免费版的说明见 免费使用与终身解锁.

没有声音或文件静音

  • 输入设备。 选择 苹果菜单 → System Settings → 声音 → 输入 并选择你想用的设备。参见 Apple 的 更改 Mac 上的声音输入设置.
  • 麦克风权限。 在 System Settings → 隐私与安全性 → 麦克风，打开该 App。参见 Apple 的 控制 Mac 上对麦克风的访问.
  • App 声音。 在 隐私与安全性 → 屏幕与系统音频录制，打开录音 App；参见 Apple 的页面。在 Vox.md Meeting 模式中，请检查 App 播放时两个电平表是否都在跳动。
