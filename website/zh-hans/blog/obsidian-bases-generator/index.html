Obsidian Bases 生成器:筛选器、视图和公式

无需先学习架构,即可构建 Obsidian base 的 YAML:选择筛选器、添加视图、复制 .base 文件或代码块,并通过指向 Obsidian 官方文档的链接了解每个键的作用。

作者：
Cody Bontecou
更新于
2026年11月28日
需要
任何现代浏览器均可,包括 iPhone 上的 Safari。可选:启用 Bases 核心插件的 Obsidian,以及用于语音或文本捕获笔记的 iPhone 或 Mac 版 Vox.md。
简短回答

base 是基于笔记的数据库式视图,以 YAML 编写,最多包含五个顶层键: filters, formulas, properties, summaries 和 views。将 YAML 保存为 .base 文件,或将其粘贴到笔记中的 base 代码块。 生成器 下方的工具会为你生成。所需的 Obsidian 版本取决于视图类型: 视图页面 列出了自 1.9 起的 Table 和 Cards、自 1.10 起的 List 和 Map,以及自 1.14 起的 Kanban。

filters:
  and:
    - file.hasTag("project")
properties:
  status:
    displayName: "Status"
views:
  - type: table
    name: "Projects by status"
    groupBy:
      property: status
      direction: ASC
    order:
      - file.name
      - status
      - file.mtime

生成器完全在本页中运行。你输入的任何内容都不会上传,页面也不会发出网络请求。

    2. Bases 语法速览

    这些是 Obsidian 的语法页面 所说明的内容。无需学习其他架构。

    键作用示例
    filters缩小所有视图的笔记范围。file.hasTag("project")
    formulas定义计算属性,用作 formula.name.total: 'price * qty'
    properties各属性的设置。 displayName 设置列标题。displayName: "Status"
    summaries定义你自己的摘要公式,使用 values.自定义,可选
    views针对同一批笔记的视图列表。- type: table
    type (视图)视图的布局。table, cards, list
    name (视图)视图的名称。name: "Projects"
    filters (视图)仅用于此视图的筛选器。file.inFolder("Work")
    groupBy (视图)按某个 property 位于 direction.direction: DESC
    order (视图)按顺序显示的属性。- file.name
    limit (视图)限制行数。limit: 10
    summaries (视图)将属性映射到摘要。price: Sum

    生成器不会写入所有有文档说明的键。语法页面还介绍了 groupOrder,视图还可以保存额外状态(例如排序列),这些由 Obsidian 自行管理。如有需要,可手动添加:YAML 由你随意编辑。

    3. 筛选器:and、or、not

    筛选器是对每条笔记判断真假的文本语句,或是带有以下键的对象: and, or 或 not 其中包含更多筛选器的列表。全局 filters 适用于所有视图。视图自身的 filters 仅适用于该视图,两者以 AND 组合。

    filters:
  or:
    - file.hasTag("meeting")
    - file.inFolder("Meetings")

    没有 from 或 source 键。没有筛选器时,base 会包含库中的所有文件,因此除非你有意如此,否则请务必设置筛选器。

    语句内的文本值需要加引号,因此 YAML 需要嵌套引号: 'status == "done"'。生成器会自动为你处理。函数筛选器,例如 file.hasTag(), file.inFolder() 和 file.hasLink() 位于 函数页面.

    4. 公式和摘要

    下的每个条目 formulas 会成为可在每个视图中使用的属性,写作 formula.name。公式可以使用其他公式,但不允许循环引用,因此公式不能引用自身。结果以 YAML 字符串存储,所以表达式要放在引号内。

    formulas:
  formatted_price: 'if(price, price.toFixed(2) + " dollars")'

    视图的 summaries 将属性映射到摘要。语法页面列出了以下默认值:

    • 数字: Average, Min, Max, Sum, Range, Median, Stddev
    • 日期: Earliest, Latest, Range
    • 布尔值: Checked, Unchecked
    • 任一: Empty, Filled, Unique

    关于日期运算,语法页面说明 file.mtime > now() - "1 week" 对最近一周内修改过的文件为 true。

    5. 这意味着什么

    在筛选器或公式中, this 是显示该 base 的文件。语法页面说明:当 base 在主内容区打开时,它就是 base 文件本身;当 base 嵌入笔记或 Canvas 时,它是嵌入它的文件;当 base 位于侧边栏时,它是主内容区中的当前文件。该页面给出了 file.hasLink(this.file) ,以此复现反向链接面板。

    6. 可复制的示例

    以下是生成器预设的纯代码形式,无需 JavaScript 即可使用。请将文件夹、标签和属性名称替换为你自己的。将文本保存为 .base 文件,或将其包裹在 base 代码块。请参阅 创建 base 了解相关命令,并使用以下方式嵌入已保存的文件: ![[Name.base]] 或 ![[Name.base#View]] 来选择默认视图。

    阅读清单

    filters:
  and:
    - file.inFolder("Reading")
    - 'status == "to read"'
properties:
  status:
    displayName: "Status"
views:
  - type: cards
    name: "Reading list"
    order:
      - file.name
      - status

    按状态划分的项目

    filters:
  and:
    - file.hasTag("project")
properties:
  status:
    displayName: "Status"
views:
  - type: table
    name: "Projects by status"
    groupBy:
      property: status
      direction: ASC
    order:
      - file.name
      - status
      - file.mtime

    带有某标签且本周修改过的笔记

    filters:
  and:
    - file.hasTag("project")
    - 'file.mtime > now() - "1 week"'
views:
  - type: table
    name: "Modified this week"
    order:
      - file.name
      - file.mtime

    此笔记的反向链接

    filters:
  and:
    - file.hasLink(this.file)
views:
  - type: table
    name: "Backlinks"
    order:
      - file.name
      - file.folder

    用 Vox.md 捕获的语音笔记

    filters:
  and:
    - file.inFolder("Vox")
    - file.hasTag("voice")
views:
  - type: table
    name: "Voice notes"
    order:
      - file.ctime
      - file.name
      - file.tags

    该 order list 用于选择列。排序是在 Obsidian 的视图工具栏中更改的视图设置,因此示例中没有写入排序。

    8. 故障排除

    • 该 base 会显示所有笔记。 未设置来源筛选器。base 默认包含整个库,因此请添加 file.inFolder() 或 file.hasTag() 筛选器。
    • 某个属性列是空白的。 名称不匹配(包括大小写),或者笔记的 frontmatter 中没有该属性。请检查笔记的属性和列名。
    • YAML 错误。 请检查缩进(使用空格)和引号。包含文本的筛选器需要嵌套引号: 'status == "done"'.
    • map 视图为空。 根据视图页面,map 布局需要 Maps 插件。

    9. 常见问题

    Bases 是核心插件吗?

    可以。 Obsidian 帮助 写道:“Bases 是一个核心插件,可让你创建类似数据库的笔记视图。”

    Bases 还是 Dataview?

    二者互相独立。Dataview 是拥有自己查询语言的社区插件。base 是 Obsidian 自行读取的 YAML,没有 from 键:通过筛选器来缩小笔记范围。本页不会进一步比较它们的功能。

    我可以手动编辑 YAML 吗?

    可以。 .base 文件是 YAML 文本,各个键在语法页面中有说明。你可以用任意编辑器打开生成的文件,也可以将代码块粘贴到笔记中并在那里编辑。

    生成器会上传我的数据吗?

    不会。本页中的脚本在你的设备上构建 YAML,页面不会发出任何网络请求。刷新页面会清除所有内容。
