iPhone · 语音备忘录 · Markdown

将 iPhone 语音备忘录转录为 Markdown

Apple 转录够用时，就从它开始。需要 Vox.md 本地转录和 Markdown 目标位置时，再导入音频。

作者：
Cody Bontecou
更新于
2026 年 10 月 30 日
需要
已保存录音 · 后端已就绪
简短回答

要将 iPhone 语音备忘录转成文本，先检查语音备忘录是否已有转录。如果复制即可完成任务，就直接复制。若要使用 Vox.md 设备端转录和 Markdown 路由，请将录音导出到文件，把音频导入 Vox.md，核对转录并保存到所选文件夹。

本指南从 Apple 语音备忘录中的现有录音开始。要直接在 Vox.md 中新录音，请使用 语音笔记存入 Obsidian 指南。操作说明基于文档与源代码审阅，并非新执行的设备导出。

本指南中
  1. 试用 Apple 转录文本
  2. 导出录音
  3. 准备 Vox.md
  4. 导入并核对
  5. 验证 Markdown 文件
  6. 检查限制与恢复

1. 检查语音备忘录是否已有文本

Apple 文档列出了支持转录的 iPhone、语言和地区。在语音备忘录中选择录音，打开其 更多 菜单，查找 查看转录 或 拷贝转录文本。如果只需要文本，复制完整转录或所选文本，再粘贴到笔记即可。

仅为复制 Apple 已提供的转录文本，你不需要另装应用。请查阅 Apple 转录指南 了解当前可用情况。缺少某个选项可能与设备、系统、语言或地区支持有关；这并不能证明音频已损坏。

2. 需要 Vox.md 转录时导出音频

Apple 的 语音备忘录导出说明 说明如何选择录音、打开 更多 → 共享，并选择 存储到文件。选择能再次找到的文件夹，再保存。

普通导出为 .m4a 录音。某些选项可以用不同形式保留可编辑图层或效果。此工作流先使用普通的扁平化音频导出；本指南并不保证每一种分层或可编辑导出都适用于每个转录后端。请保留原始语音备忘录。

共享音频文件与复制 Apple 转录文本不同。将音频导入 Vox.md 会再次运行其所选转录后端；不会导入 Apple 的转录文本，也不保证措辞一致。

3. 准备后端和 Markdown 目标位置

获取 iPhone 版 Vox.md

  1. 在 Vox.md 中选择支持设备和录音语言的转录后端。联网完成所需模型下载。
  2. 创建或选择带可写 Markdown 文件夹的采集预设。使用 新笔记 用于首次导入，方便辨认生成文件。
  3. 选择 保留原文 处理，适合只要识别文本、不需要可选 AI 改写时。
  4. 在快速捕捉语音控件中选择 添加到草稿 在导入前选择，以便核对首次转录。

保留原文保留识别文本，不会让识别变成逐字准确或毫无错误。自动模式、Apple Speech 和下载模型有不同设备与语言要求。请检查 模型参考 以及已安装应用当前的购买或访问要求，再进行较长音频的导入。

使用 Obsidian 时，请选择通过文件开放的实际仓库文件夹。Vox.md 不直接连接 Obsidian Sync 服务。普通可写 Markdown 文件夹也适用。

4. 导入已保存录音并核对草稿

  1. 开放 导入音频或视频 位于快速捕捉的语音控件中。
  2. 从文件中选择导出的录音，等待导入和转录完成。
  3. 选择添加到草稿后，在编辑器中核对转录。对照源音频修正姓名、日期、数字和其他重要措辞。
  4. 确认所选预设和目标位置，然后轻点 发送.

请使用转录导入控件，不要通过通用文件附件操作附加文件。笔记中的音频附件本身不是转录文本。

使用 立即发送 改为选中时，完成的转录可通过所选预设继续，不经过相同的草稿核对步骤。首次检查先设置添加到草稿。开始导入前结束任何正在进行的录音。

5. 检查实际 Markdown 文件

等待投递完成。在文件或 Obsidian 中打开目标位置，确认文件、文本和文件名。编辑器中可见转录仅证明识别生成了文本，不证明文件夹写入成功。

虚构录音可能生成以下笔记正文：

Review the garden plan on Saturday.
Bring the updated measurements.

这是示例输出，不是真实录音或准确度测试。文件名、元数据和格式由预设控制。新导入的日期或文件名不自动等于原始语音备忘录的录音日期。需要时请有意补充该上下文。

一次新笔记导入成功后，请按照 每日笔记指南 用于滚动目标位置，或 模板方案 用于收件箱或任务条目。将旧录音发送到每日日志前，请匹配目标笔记的日期和路径。

限制、隐私和导入失败

  • 无法导入： 完成当前录音，检查应用访问要求，确认所选预设已启用。
  • 识别失败： 检查后端是否就绪、语言、本地存储及文件音频能否解码。保留原件，先尝试简短普通音频导出，再处理较长或特殊文件。
  • 投递待处理： 恢复文件夹访问权限，然后重试保留下来的失败投递。重新导入同一备忘录可能产生第二条采集记录。
  • 还需要原始音频： 单独配置并验证音频保留。不要仅因预设生成文本，就假定它保存音频附件。

Vox.md 在设备上运行转录。首次准备后端可能需要下载，文件提供程序可能需要联网获取源文件或写入目标位置。如果将音频或 Markdown 保存在同步文件夹中，该提供商会自行处理同步。完整的断网工作流请按照 离线准备与验证指南.

此路由不是语音备忘录资料库自动同步、批量归档导入器，也不承诺保留 Apple 的编辑、图层、转录时间或录音元数据。先从一段录音开始，保留原件，验证保存的文本后再扩展工作流。
