视频转文字 · iPhone · iPad · Mac

在 iPhone 或 Mac 上把视频转写成文字，无需上传

视频已经在你的手机或 Mac 上，就在那里转写。无需上传，得到的是属于你的 Markdown 笔记，而不是只能复制的文本框。

作者：
Cody Bontecou
更新于
2026年11月25日
需要
Vox.md：iOS 或 iPadOS 17.6+ 或 macOS 14+ · 除非可用 Apple Speech，否则需要已下载的语音模型 · 带目标文件夹的路线
简短回答

iPhone 或 iPad： 把视频放进“文件”，打开 Vox.md，点按 导入音频或视频 在语音控件中，选择文件，检查文字，然后发送。 Mac： 选择 导入音频… 在菜单栏中，或从采集工作区导入文件。无论哪种方式，视频都会在你的设备上用 Apple Speech（自动，在受支持的 iOS 26 设备上）、Whisper 或 Parakeet 转写，并保存为 Markdown 笔记。

它不做什么。 Vox.md 不接受 YouTube、TikTok 或其他视频链接，也不生成 SRT 或 VTT 字幕。如果你已有字幕文件，只想得到干净的文字，请使用 SRT 和 VTT 转换器。Vox.md 的步骤遵循 快速捕捉 和 Mac 文档和应用的行为。

你需要准备什么

  • 一段你有权转写的视频，例如屏幕录制、手机视频、你录制的讲座或演讲，或你拥有的已导出 Zoom 或 Teams 录制。
  • 一个 MP4 或 MOV 文件。 这些是本指南涵盖的格式。
  • 带目标位置的路线：Obsidian 库或“文件”中的文件夹。请参阅 路线 （见文档）。
  • 一个就绪的转写后端。 自动在受支持的 iOS 26 设备和语言上使用 Apple Speech；否则请下载 Whisper 或 Parakeet。请参阅 模特.
  • 需要方案。 录音、转录和导入需要按周或按年订阅（符合条件的账户可享 7 天免费试用），或一次性终身购买。请参阅 方案与价格；价格以 App Store 为准。

在 iPhone 或 iPad 上

1. 把视频放进“文件”

如果视频在“照片”中，请先把它共享到“文件”。Apple 的 iPhone 使用手册介绍了 共享照片和视频 以及 “文件”App；在共享表单中，找到“存储到文件”操作并选择一个文件夹。

重要： 把“照片”中的视频直接共享到 Vox.md 共享扩展（采集到 Vox.md）会把它作为文件附加到采集内容。它 不 转写它。要转写视频，你需要应用内的 导入音频或视频 控件，它会打开“文件”选取器。

2. 导入并转写

  1. 打开 Vox.md 的快速捕捉，选择你想要的路线。
  2. 在语音控件中，选择 添加到草稿 以便在投递前检查文字，或 立即发送 以便在转写完成时投递。
  3. 轻点 导入音频或视频 并在“文件”选取器中选择该文件。
  4. 等待转写完成，然后对照视频检查人名、数字和术语。
  5. 轻点发送。

大文件。 开始前，请让视频下载到设备上，而不是只存在 iCloud 中。 离线指南中的导入来源检查 说明了如何确认文件可以打开。

先用一段短视频试试。

获取 Vox.md

在 Mac 上

选择 导入音频… 从 Vox.md 菜单栏，或从采集工作区导入文件。文件选取器接受音频和影片文件。之后的步骤与 在 Mac 上转录音频文件，因此这里不再重复。

可选：只保留音轨。 在 QuickTime Player 中， 文件 → 导出为 → 仅音频 会生成音频文件。Apple 的 QuickTime Player 使用手册 介绍了导出选项。将视频导入 Vox.md 并不需要这一步。

按视频语言选择模型

自动 / Apple Speech。 在受支持的 iOS 26 设备和语言上，自动优先使用 Apple Speech。它只会回退到你明确下载的本地模型。

Whisper。 大小从 Tiny（75 MB）到 Large v3 Turbo（1.6 GB）不等。模型越大，占用的存储和处理资源越多。 whisper.cpp 是 Whisper 模型的开源运行时。

Parakeet。 Parakeet v2（约 800 MB）支持英语。Parakeet v3（约 800 MB）支持 25 种语言。它们通过以下运行时运行： FluidAudio.

要在它们之间做选择，请阅读 Whisper 与 Parakeet 并用你自己视频中的一段短片测试。详情见 模型文档.

不止一位说话者？

开启 识别演讲者 在路线上设置。它为可选功能，适用于受支持的导入，并尽力添加匿名标签，如“Speaker 1”和“Speaker 2”，你可以手动重命名。如果标注失败，会保留纯文本转写，资料库会显示原因。请参阅 私密转写访谈.

笔记是什么样子

笔记的版式来自你的路线：标题、前缀或时间戳，然后是转写文本。示例（虚构文字）：

## Video transcript
10:42 AM 2026-11-25

Welcome to the walkthrough. First we open the settings screen.

路线可以使用保留原文、润色文本、会议记录、任务清单或自定义指令。Apple Intelligence 模式需要兼容的硬件。没有时，任务清单和会议记录使用内置格式化器，润色文本则保留原文。如果你用视频排练演讲，请把转写文本粘贴到 演讲时长计算器 来检查你的语速。

什么时候它不是合适的工具

  • 不支持链接。 Vox.md 不接受 YouTube、TikTok 或其他视频链接。你需要文件本身。
  • 没有字幕。 它保存的是文字，而不是带时间的 SRT 或 VTT 文件。要清理你已有的字幕文件，请使用 SRT 和 VTT 转换器.
  • 权限。 只转写你拥有或获准使用的视频，并取得被录制者的同意。

故障排查

  • 导入呈灰色或被拒绝。 请先完成当前录音。导入同样需要 Vox.md Unlimited。
  • 文件无法打开。 请确保它已下载到设备，而不只是在 iCloud 中。
  • 没有转录文字。 请确认模型已完整下载并已选中。
  • 语言错误。 设置转写语言；如果选的是 Parakeet v2（英语），请改选 Parakeet v3 或 Whisper。

更多解决办法： 文档中的故障排除.

常见问题

免费吗？

录音、转录和采集需要 Vox.md Unlimited：符合条件的账户可选择带 7 天免费试用的按周或按年订阅，或一次性终身购买。App Store 会显示你所在地区的价格。

视频会被上传吗？

不会。采集内容不会发送到 Vox.md 服务器，转写在你的设备上运行。下载模型时会连接 Hugging Face。请参阅 隐私政策.

可以转写 YouTube 视频吗？

不能。Vox.md 不接受链接。

会生成字幕吗？

不会。它生成的是 Markdown 笔记，而不是 SRT 或 VTT 文件。

支持哪些格式？

本指南涵盖 MP4 和 MOV。
