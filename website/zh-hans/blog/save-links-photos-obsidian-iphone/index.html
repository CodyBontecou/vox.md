从 iPhone 将链接、照片和扫描件保存到 Obsidian

将源材料放在想法旁边。把链接、图片或扫描件发送到你选择的 Markdown 目标位置。

作者：
Cody Bontecou
更新于
2026 年 10 月 26 日
需要
iOS 17.6+ · 可写仓库文件夹
简短回答

将 Vox.md 采集预设连接到可写仓库文件夹，在快速捕捉中添加 URL、照片、文件或扫描件，再发送。预设选择笔记和附件位置。检查投递的 Markdown，确认附件能在 Obsidian 中打开。

保存链接和保存文章是不同任务。Vox.md 将网页 URL 作为 Markdown 链接接收；不要假定添加 URL 就会下载或提取整页。请按要保存的材料选择采集方式。

本指南中
  1. 准备仓库目标位置
  2. 保存网页链接
  3. 添加照片、截图或文件
  4. 扫描文档并核对 OCR
  5. 检查附件与同步

1. 准备仓库目标位置

在设置 → 采集预设中创建或选择已启用预设，通过文件连接其目标位置。选择包含仓库 Markdown 文件的文件夹。如果该文件夹未对其他应用开放，Vox.md 不会仅因它在 Obsidian 内可见就能写入。

第一个示例选择新笔记和保留原文处理。单独的收件箱文件夹便于查找混合采集。以后要将内容加入同一文件时，可选择滚动笔记或现有笔记。

在目标位置设置中指定附件子文件夹；默认是 attachments。发送前检查解析后的笔记路径和附件规则。每日日志请按照 每日笔记路由指南.

2. 保存网页链接

复制要保留的 URL。在快速捕捉中使用网页链接控件，核对链接文字和地址。简短说明保存原因，然后发送。

一条简单笔记可能包含以下示例 Markdown：

Read before planning the trip:
[Trail information](https://example.com/trail)

上方地址仅为示例，不是资源推荐。请替换为实际页面。链接提供返回来源的路径；如果网站更改或消失，它不会保留来源内容。

Vox.md 共享表单也接受其他应用的受支持内容。应用共享的可能是 URL、文本或文件。请检查收到的内容和所选预设，不要假定来源屏幕上的所有可见内容都已包含。

3. 添加照片、截图或文件

  1. 选择收件箱或项目笔记的预设。
  2. 使用照片或截图选择器、相机或添加文件控件选择材料。
  3. 在编辑器中添加简短标题或说明。
  4. 发送后在 Obsidian 中打开笔记，检查嵌入图片或文件链接。

图片嵌入 Markdown 输出，其他文件类型使用链接。例如笔记可这样引用已配置的附件路径：

## Reference
![[attachments/whiteboard.png]]
[[attachments/brief.pdf]]

这些是示例文件名和路径；Vox.md 实际输出取决于所选文件和目标位置规则。请将引用文件与仓库放在一起。只把 Markdown 文件移到其他文件夹可能破坏相对链接。

4. 扫描文档并核对 OCR

在采集栏选择扫描文档，按扫描器操作。Vox.md 保留页面图像、创建 PDF，并尽力进行设备端文本识别。发送前核对识别文字，尤其是姓名、日期、金额和手写内容。

对于日志照片，独立的提取文本流程支持手动拍摄或选择的页面。即使图像清晰，OCR 也可能遗漏结构或误读词语。以后需核对文本时，请保留源图片或扫描件。

不希望可选处理改写采集文本时，请选择保留原文。键入和混合文本处理需在预设中单独启用。 采集参考 介绍支持的输入，以及 输入限制.

检查附件与同步

投递后在 Obsidian 中打开笔记，逐个打开链接，确认所需文件存在。笔记出现在另一设备上，不证明每个附件都已同步完成。也请在该设备上检查图片或 PDF。

写入失败后可在 Vox.md 中保持待处理状态。创建副本前，先修复目标位置访问并重试现有采集。即使采集处理本身在本地进行，云端提供商存储的文件仍可能需要联网才能访问或同步。

如果需要提取完整网页，请直接比较相关工具。Obsidian 在以下文档中介绍其原生共享选项： 官方 iOS 指南。可为一项任务用原生共享，为另一项任务用 Vox.md 预设。

保留上下文。
放在笔记旁边。

试采集一个链接或一张图片，再检查完整文件和附件输出。
