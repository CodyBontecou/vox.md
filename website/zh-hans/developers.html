公开信息 API

查找产品信息与文档

Vox.md 公开信息 API 提供产品信息及已发布文档的链接。免费读取，无需账户、API 密钥、OAuth 流程或付款。这些端点返回的信息均已在本公开网站提供。请阅读 OpenAPI 3.1 契约 查看带类型的响应架构、操作标识符、错误和说明。

获取产品信息

GET https://vox.isolated.tech/api/v1/product 返回产品名称、说明、支持的操作系统、App Store 页面、文档 URL 和支持 URL。构建过程从首页结构化数据中提取这些信息。

curl https://vox.isolated.tech/api/v1/product

查看产品 JSON

查找文档

GET https://vox.isolated.tech/api/v1/documents 列出公开页面标题、摘要和 URL。请求内容前，可据此查找相关功能指南、政策、博客文章或支持页面。

curl https://vox.isolated.tech/api/v1/documents

查看文档索引 JSON

以 Markdown 阅读页面

使用以下方式请求任一列出的页面： Accept: text/markdown 作为主要内容。带有以下内容的请求： Accept: text/html 仍会收到 HTML。两种表示均包含 Vary: Accept。该 代理指南 说明哪些使用场景适合 Vox.md，并指向功能详情。

curl -H 'Accept: text/markdown' https://vox.isolated.tech/docs/

错误、缓存和方法

JSON 端点支持 GET 和 HEAD。未知 API 路径返回 HTTP 404，并附带 application/problem+json、稳定的 code、说明和恢复提示。不支持的方法返回 HTTP 405 和 Allow: GET, HEAD。公开元数据响应允许跨域读取，并声明五分钟缓存有效期。不涉及凭据或用户特定数据。

自动操作已安装应用

采集、转录、本地仓库访问和笔记写入在已安装的 Apple 应用中运行。请使用文档所述的 快捷指令与 URL 协议集成 需经设备所有者许可。公开信息 API 不公开采集操作、录音、转录、私密笔记或目标文件夹。联系 Vox.md 支持 咨询问题。
