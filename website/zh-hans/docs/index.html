    01 / 入门

    采集到 Markdown，不另建笔记孤岛

    Vox.md 是本地优先的快速采集应用。它将标准 Markdown 和附件写入 Obsidian 仓库，或你通过文件选择的其他可写文件夹。无需 Vox.md 账户、插件或托管笔记数据库。

    完整语音工作流请 按照 iPhone 语音笔记存入 Obsidian 指南操作，从选择文件夹到检查生成的 Markdown。

    正在选择采集方式？请阅读 iPhone 采集选择指南 或 比较 Vox.md 与原生 Obsidian.

    平台要求可用内容
    iPhone 和 iPadiOS/iPadOS 17.6+快速捕捉、键盘、共享表单、小组件、快捷指令、实时活动、历史记录和设置
    MacmacOS 14+采集工作区、录音/导入、路由、模型、历史、菜单栏和全局快捷键
    Apple WatchwatchOS 10+本地录音、路由选择、同步队列、仅录音投递和复杂功能
    控制中心控件iOS 18+快速捕捉与识别路由的录音控件
    Apple Speech 自动后端受支持的 iOS 26 设备和语言系统管理的设备端实时和批量转录
    Apple Intelligence 处理兼容的 iOS/macOS 26 设备设备端整理、结构化输出和带回退的自定义指令

    基本工作流。 选择路由、连接目标位置，在快速捕捉中键入或添加内容，再轻点发送。路由决定内容如何处理、格式化及放入笔记。

    进行首次采集

    1. 打开 Vox.md。应用直接打开持久化 Markdown 编辑器。
    2. 选择路由。内置默认路由不可删除，但可停用。至少保持一个路由启用，并为它设置目标位置。
    3. 设置其目标位置。轻点 设定目的地，选择 Obsidian 仓库或文件文件夹，然后选择新笔记、滚动笔记或现有笔记。
    4. 添加内容。键入 Markdown，或添加链接、照片、文件、扫描件、草图、位置或语音录音。
    5. 轻点发送。Vox.md 保存到所选路由，并报告 抓捕 送。失败或排队中的工作仍可恢复。

    权限与系统访问

    • 麦克风： 语音录制、本地转录、键盘聆听和音频采集。快速捕捉可能在首次打开工作区时、开始录音前显示此请求。
    • 语音识别： 受支持系统上的 Apple Speech。
    • 文件文件夹访问权限： 目标位置、模板、导入和手表仅录音输出。
    • 相机与所选照片： 仅在添加媒体、屏幕截图、日记照片或扫描件时。
    • 使用期间的位置权限： 仅用于独立的采集栏目前位置命令，或已启用位置的路由需要一次发起时位置时。Vox.md 从不持续或在后台跟踪位置。
    • 通知： 可选的投递状态，包括无人值守时的 Apple Watch 失败记录。
    • 键盘允许完全访问： 是 Vox.md 键盘使用共享设备端应用工作流所必需的。参阅 键盘设置.
    02 / 快速捕捉

    一个持久编辑器，容纳文本、媒体、文件和语音

    快速捕捉是 iOS 和 iPadOS 主工作区。路由菜单更改当前工作流；目标位置菜单预览或临时覆盖此草稿的投递位置。底栏也可打开资料库和设置，并显示或收起软件键盘。

    持久草稿与安全投递

    • 文本、附件、所选路由、目标位置覆盖设置和采集来源在应用挂起及重启后保留。
    • 编辑在短暂防抖延迟后保存，应用切到后台时立即触发保存。
    • 发送过程中继续编辑时，新编辑会保存在新草稿中，不会丢弃。
    • 投递前必须配置目标位置。编辑器会显示 目的地未配置 并在需要时提供设置操作。
    • 可安全重试的采集请求记录于本地日志，因此权限、文件提供商或同步失败后可以重试。
    • 空编辑器会显示缓存的励志名言，直到添加文本；即使已选择路由或附加文件也一样。名言请求绝不包含你的草稿。

    以任务为中心的操作演示请参阅 将链接、照片和扫描件保存到 Obsidian.

    采集类型

    文本与 Markdown

    在支持感知选区的 Markdown 编辑器中直接写作，粘贴现有文本，并将文本与其他载荷组合。

    网页链接

    以 Markdown 链接格式添加 HTTP 或 HTTPS URL。

    照片与相机

    选择照片或截图，或拍摄新照片。图片会暂存，并嵌入投递的笔记。

    文件

    选择多个文件项目。图片变为嵌入内容，音频保留为音频载荷，其他文件使用 Obsidian 风格链接。

    文档扫描

    用 VisionKit 扫描页面。Vox.md 保留页面图像、创建 PDF，并尽力进行设备端 OCR。

    日志 OCR

    手动按快门采集最多 10 页日志，或选择日志照片。准确的 Vision OCR 使用自动语言检测。

    草图

    在白色 PencilKit 画布上用黑色画笔绘图。Vox.md 存储可编辑绘图数据和 PNG 预览。

    目前位置操作

    请求一次位置，并在草稿中插入经过验证的 Google Maps Markdown 链接。此独立采集栏操作不更改任何按路由设置的位置控件。

    语音与导入音频

    在编辑器中录音或导入音频/视频，本地转录，再将结果加入草稿或立即发送。

    无障碍：OCR 显示“正在此设备上提取文本”进度横幅；VoiceOver 会在采集流程中播报 OCR 进度与完成状态、“采集已发送”和“转录已添加到采集”。

    采集栏

    设置 → 采集栏可调整操作顺序或隐藏操作。默认所有操作都可见。

    操作行为
    添加媒体打开草图、相机、照片、截图和网页链接选项。
    添加文件从文件中选择多个文件，与草稿一同暂存。
    扫描文件采集多页扫描、PDF、页面图像，并尽力进行 OCR。
    摘取文本提供采集日志页面和选择日志照片，用于侧重 OCR 的采集。
    九 个撤销上一次编辑器操作。
    格式 Markdown应用粗体、斜体、井号标签，或标题 1 至标题 6。
    Markdown 链接插入 [link text](url) 并选中可编辑部分。
    内部链接插入 Obsidian 风格的 [[Target]] wikilink。
    两日期设置使用今天、明天或本周末；可选时间；以及 ±15m、±30m 或 ±1h 调整。插入 (@yyyy-MM-dd) 或带时间的形式。
    检查名单应用 Markdown 任务前缀 - [ ].
    子弹列表应用 Markdown 项目符号前缀。
    面包将剪贴板文本粘贴到当前选区。
    草图打开可编辑的 PencilKit 草图采集。
    目前位置请求一次位置，并插入 Google Maps 链接。
    插入时刻表将本地时间和日期插入为 h:mm a yyyy-MM-dd.
    插入日期插入 yyyy-MM-dd.
    修改案例文本提供小写、大写、句首大写、每词首字母大写和转为 slug。

    格式处理尊重当前选区、规范化换行、限制无效选区范围，并避免拆开 emoji 等组合字符。

    内嵌语音控件

    • 轻点语音按钮开始或停止。长按约 0.45 秒显示详细控件。
    • 录音时， 暂停 按钮位于语音按钮旁边——轻点一次暂停，再点一次继续。最终笔记仍为一段录音，不包含暂停期间的音频和时长。暂停也会停止实时转录预览和语音自动停止功能，直到你继续录音。
    • 添加到草稿 追加完成的转录文本。 立即发送 运行所选路由及其目标位置。
    • 默认选择立即发送 位于 iOS 和 Mac 采集工作区中。通过以下方式打开 iOS 语音操作： voxboard://capture?action=voice 将该录音切换为添加到草稿。
    • 该 音频 选项可按要求将源录音保留为草稿的一部分。
    • 音频进口 接受音频或影片文件，并使用相同的本地转录管线。
    • 识别演讲者 是针对录音和导入音频、需主动启用的路由语音处理步骤。首次使用会准备独立说话人模型，在本地尽力添加匿名标签；无法运行时保留纯转录，并在资料库显示原因。
    • 自动模式可在录音时，直接在可编辑的编辑器中显示 Apple Speech 已定稿和暂定的文本。明确选择的 Whisper 和 Parakeet 模型在录音停止后转录。
    • 转录失败不会破坏源录音；它仍可恢复。
    • 只有明确启用时，持续键盘聆听才会跨启动保留。一次性应用录音会将音频会话恢复为空闲状态。

    采集输入限制

    每次请求最多包含 100,000 个字符 共享文本， 10 个共享项目，以及 250 MB 的暂存资源总量。照片和截图选择器最多接受 10 项；日志采集最多接受 10 页。Vox.md 会拒绝超限输入，而不会悄悄丢弃项目。

    03 / 路由

    保存完整工作流，不只是文件夹

    路由保存采集的含义、是否处理文本、如何处理元数据和音频，以及 Markdown 的确切写入位置。路由适用于键入文本、链接、媒体、扫描件、文件、草图、语音、快捷指令、小组件、共享表单、手表和 Mac。

    创建和管理路由

    • 打开设置 → 路由，创建、重命名、启用、停用自定义路由，为其选择图标或删除。
    • 可搜索图标选择器将符号分为写作、语音、任务、个人和工作类别。
    • 已停用的路由不在常规选择器中显示。内置默认路由不可删除。
    • 内置默认路由使用波形符号，提示为 采集想法、任务、链接、文件、扫描件或录音。, type: capture 元数据、整理行文处理，关闭键入文本处理，关闭音频保存。
    • 新的自定义路由初始为 自定义路由，使用滑块图标和 想采集什么？ 提示，初始选择自定义指令，但关闭键入/混合文本处理。

    处理模式

    模式结果回退行为
    保留原文保留采集文本，不进行 AI 改写。投递原始文本。
    润色文本整理大小写和标点，同时保留含义与 Markdown。设备端增强不可用时保留原文。
    任务清单生成 Markdown - [ ] 任务项。确定性的清单格式器。
    会议记录生成 ## Notes 节，以及存在时的 ## Action Items.确定的会议笔记结构。
    自定义指令可用时使用设备端 Apple Intelligence 遵循你的指令。指令无法在本地运行时保留原文。

    语音转录使用所选路由模式。 应用于捕捉文本 是默认关闭、需单独启用的选项，允许处理键入的 Markdown、OCR 和其他带文本的混合采集。保持关闭可防止意外改写已编写的 Markdown。投递前保存确切的已处理请求，因此重试不会依据变化后的设置重新处理。

    元素

    • 将静态元数据输入为一个 key: value 键值对，每行一对，例如 tags: [journal, idea].
    • 笔记 frontmatter 在文档范围写入元数据。
    • 行内条目字段 写入 key:: value 字段放在滚动笔记的每个条目旁边。
    • 可用时，设备端增强可在静态路由元数据之外添加标题、标签、类别和整理后文本。

    主动启用的位置功能

    目前位置默认关闭，且属于各个路由。启用后，Vox.md 在采集发起时请求一次位置：iOS/iPadOS、共享表单、深层链接/编辑器、Mac 及打开编辑器的系统操作在发送时请求；直接入队的文本、链接和文件意图在调用时请求；即时语音、键盘驱动路由录音、小组件/控件录音或通过普通采集投递的 Apple Watch 录音在停止时请求。手表仅录音是原始音频文件导出，没有 Markdown 位置内容，也不请求位置。Vox.md 绝不持续监测位置，绝不运行后台位置跟踪。

    设置项行为
    使用当前位置为此路由请求一次发起时位置，并支持 {location}。它不会自动写入元数据。
    准确（默认）保留按隐私设置调整的原始定位结果，所选元数据需要时可包含兴趣点名称。
    城市将经纬度四舍五入到小数点后两位，并省略兴趣点名称。所有派生字段和链接使用这些舍入坐标。
    写入位置元数据单独启用结构化或高级元数据，除此之外还可使用任何 {location} 条目模板链接。
    结构化字段选择并重命名坐标、纬度、经度、地点、城市、地区、国家、Apple Maps、Google Maps、OpenStreetMap、 geo: URI、精度、时间戳、来源和采集 ID。
    高级 YAML 模板为笔记 frontmatter 使用经过验证且有边界限制的 YAML。它无法替换无关 frontmatter，也不适用于行内条目字段。

    启用写入位置元数据后，文档范围将各结果按采集 ID 追加至配置的 frontmatter 集合。同一笔记可保留多个位置，而幂等重试不会重复追加同一位置。条目范围则将所选结构化字段渲染为 key:: value 放在该采集条目旁边。

    只有启用的元数据字段需要时，地点、城市、地区和国家才使用 Apple 系统反向地理编码器。仅令牌位置会跳过反向地理编码。该服务免费且无需 API 密钥，但可能需要网络连接；查询失败时，采集继续使用仅坐标元数据。条目前后缀和仓库 Markdown 模板可使用 {location} 从路由可用且已按隐私设置调整的快照插入可点击的 Google Maps 链接，无需启用元数据输出；目前位置关闭或不可用时，令牌为空。生成提供商链接不会联系 Apple、Google 或 OpenStreetMap。打开链接会向该提供商披露链接中保存的同一组精确或舍入后的坐标。

    新路由和此前停用位置的路由保持两项控件关闭。原来写入位置元数据的路由在升级后保持两项开启，以保留现有输出。

    完整目前位置指南

    参阅 目前位置、 {location}，以及元数据 了解设置方案、示例、采集来源时机、迁移行为、隐私和故障排查。

    位置不可用

    交互界面可重试、取消、仅本次不带位置发送，或选择 始终不带位置发送 为该路由设置。在路由位置设置中重置已保存的选择。无人值守的 询问 采集会持久保留发起时位置不可用的结果，直到你决定；重试和恢复绝不重新获取稍后位置。

    Markdown 目标位置

    每个路由都有一个以 Obsidian 仓库或可写的文件文件夹为根的目标位置。

    新笔记

    为每次采集创建独立 Markdown 文件，可使用令牌，例如 {timestamp}, {date}, {time}, {year}, {YR}, {month}, {day}, {id8}，以及 {id}.

    滚动笔记

    追加到每日、每周、每月、每季度或每年笔记。路径也支持 {period} 和 {week}。新目标位置的默认值为 Journal/{period}.md 以每日为周期。

    现有笔记

    选择所选仓库或文件夹内已有的 Markdown 文件。Vox.md 会验证目标始终安全地位于该根目录内。

    完整路由方案请参阅 向 Obsidian 每日笔记追加文本和语音.

    使用收件箱、日志或任务模板方案 以保持条目格式可预测。

    放置位置、标题和模板

    • 底部 追加； 顶部 前置插入； 头条 插入到所选的 1 至 6 级标题下。
    • 如果缺少标题，请选择 显示错误 或 创建头条.
    • 使用仓库中的实时 Markdown 模板文件、可复用条目模板，或自定义前后缀文本。
    • 条目格式支持 {date}, {time}, {hour}, {minute}, {second}, {timestamp}, {year}, {YR}, {month}, {day}, {week}, {source}, {id8}, {id}，以及 {location}.
    • 默认附件子文件夹为 attachments.
    • 保护回归，默认关闭，会写入可见的 vox-capture HTML 注释，以便检测重复重试。
    • Vox.md 拒绝绝对路径、反斜杠、路径遍历、不安全名称和符号链接越界。

    单次采集覆盖设置

    目标位置控件可使用路由默认值、将本次采集放在顶部或底部、应用一次性条目模板，或选择同一仓库中的另一笔记。 使用路线的目标位置默认设置 移除覆盖设置。这些选择仅影响当前草稿，绝不修改路由。

    音频保留与兼容导出

    • 音频保存模式为 关闭, 笔记旁边，或 附件文件夹.
    • Markdown 可在顶部或底部嵌入保留音频，使用 Obsidian 语法，例如 ![[recording.m4a]].
    • 对于未使用统一 Markdown 目标位置的旧版直接语音配置， 将笔记保存到文件 支持 TXT、MD、JSON 和 YAML；新建文件或追加；包含模型和语言的文件名令牌；Markdown 模板；Obsidian Bases 选项；可选 YAML 属性；以及可选的 .md 扩展名，用于 YAML。
    • 兼容导出设置仅适用于路由没有统一采集目标位置时的直接语音运行。
    04 / 模型与转录

    选择系统后端或可选本地模型

    所有转录都在 Apple 设备上运行。自动是 iOS 默认模式。可选的 Whisper 和 Parakeet 模型文件仅在你请求时下载，可选择、在下载中取消或之后删除。

    准备离线转录工作流 使用本地后端和可写目标位置。

    可用转录选项

    选项大致大小最适合
    自动化系统管理在受支持的 iOS 26 设备和语言上优先使用 Apple Speech；仅回退到你明确下载的本地模型。
    Whisper Tiny75 MB下载最小、速度最快的 Whisper 选项。
    Whisper Base142 MB均衡的小型本地模型；旧版 Mac 默认模型。
    Whisper Small466 MB更高准确度，代价是更多存储和处理开销。
    Whisper Medium1.5 GB较大的多语言 Whisper 模型。
    Whisper Large v3 Turbo1.6 GB可用的最大 Whisper 选项。
    Parakeet v2~800 MB针对英语优化的 Core ML/FluidAudio 模型。
    Parakeet v3~800 MB支持 25 种语言的 Core ML/FluidAudio 模型。

    自动模式如何工作

    • 在受支持的 iOS 26 设备上，自动模式检查 Apple 系统管理的所选语言语音识别器，并在需要时准备语言资源。
    • 系统语言 遵循设备语言。录音使用其他语言时，请选择具体语言。
    • 自动模式绝不悄悄下载 Whisper 或 Parakeet 备用模型。它只能使用你之前选择下载的模型。
    • 实时 Apple Speech 区分可安全插入的已定稿文本与仍可能变化的暂定文本。
    • 明确选择 Whisper 和 Parakeet 时，音频段结束后批量转录。

    语言

    • Whisper: 自动检测、英语、西班牙语、法语、德语、意大利语、葡萄牙语、荷兰语、波兰语、俄语、中文、日语、韩语、阿拉伯语、印地语、土耳其语、越南语、泰语、乌克兰语、瑞典语、丹麦语、挪威语和芬兰语。
    • 自动： 系统语言，以及 Whisper 明确列出的语言，前提是 Apple 支持该语言区域。
    • Parakeet v2: 英语。
    • Parakeet v3: 保加利亚语、克罗地亚语、捷克语、丹麦语、荷兰语、英语、爱沙尼亚语、芬兰语、法语、德语、希腊语、匈牙利语、意大利语、拉脱维亚语、立陶宛语、马耳他语、波兰语、葡萄牙语、罗马尼亚语、斯洛伐克语、斯洛文尼亚语、西班牙语、瑞典语、俄语和乌克兰语。Parakeet 工作流会自动检测语言。

    Parakeet 键盘自动停止

    可选的约 1 MB 语音休息检测器 模型可在静音后停止明确选择的 Parakeet v2 或 v3 键盘录音。启用 让 Parakeet 在停顿后停止 ，选择约 0.5、0.75、1、1.5 或 2 秒。辅助模型可用后默认启用，暂停阈值为 0.75 秒。自动和 Whisper 仍需手动停止。

    本地音频行为

    • Whisper 输入会规范化为 16 kHz 单声道、16 位音频。
    • iOS 持续聆听使用 10 分钟环形缓冲区，音频段开始时包含两秒预录。
    • Whisper 使用 whisper.cpp；Parakeet 使用 FluidAudio 和 Core ML。Whisper 在 Mac 上使用 Metal 加速。
    • 模型下载需要网络连接，但所选后端就绪后，转录在本地运行。
    05 / iOS 键盘

    直接在正在编辑的文本框中听写

    Vox.md 键盘可用于信息、备忘录、邮件、Safari、Slack 及其他接受标准 iOS 键盘的应用。语音工具栏位于 KeyboardKit 布局上方，通过私有共享 App Group 与 Vox.md 主应用通信。

    设置键盘

    1. 在 Vox.md 中准备转录。在受支持设备上保持选择自动，或在设置 → 模型中下载并选择 Whisper 或 Parakeet。
    2. 添加键盘。打开 iOS 设置 → 通用 → 键盘 → 键盘 → 添加新键盘，选择 Vox.md。
    3. 开启允许完全访问。当前键盘工作流需要此权限，以使用共享 App Group 状态，并与主应用协调录音。
    4. 切换键盘。打开文本框，用地球键选择 Vox.md，再轻点麦克风。
    完全访问在这里做什么

    iOS 对该权限的描述很宽泛。Vox.md 将它用于设备端应用/键盘工作流、共享状态和可选触感反馈。Vox.md 不会将按键记录、听写文本、转录文本或麦克风音频上传至 Vox.md 服务器。请参阅 隐私政策.

    语音工具栏与插入

    • 工具栏显示当前后端、状态、录音时长、实时波形和麦克风/停止操作。
    • 上一个和下一个控件可循环切换可用的已下载后端。
    • 如果尚未开始聆听，键盘会打开 Vox.md 一次，开始聆听，并可让你返回原始文本框。
    • 自动模式会在你说话时插入已定稿的转录增量；暂定词语仅供显示，直到 Apple 将其定稿。
    • 使用 Whisper 或 Parakeet 时，停止或自动停止该段后才会插入完整转录。
    • 插入中断或挂起时，待处理文本会持久保存，在下次键盘出现时重试。
    • 工具栏报告的状态包括 开放 Vox.md, 转载...，以及 启用完全访问.

    键盘自定义

    • 触觉反馈 默认启用，可在 Vox.md 设置中更改。
    • 英语、德语、西班牙语、法语、意大利语、葡萄牙语、荷兰语、瑞典语、丹麦语和挪威语支持长按显示替代字符。
    • 明确选择 Parakeet 的用户可在设置 → 模型中添加基于停顿的自动停止。
    • 15 分钟免费转录额度同时适用于键盘听写、应用录音和导入。
    06 / 系统集成

    从共享表单、主屏幕、锁屏或快捷指令开始采集

    共享扩展

    iOS 共享表单操作名为 采集到 Vox.md。它接受文本、HTTP/HTTPS URL、图像、文件和影片，受共享项目与资源限制约束。选择路由和目标位置，可选添加备注，然后发送。如果路由使用目前位置，共享会在此次发送时请求一次发起时位置，无论是否启用元数据输出。内容暂存于私有 App Group，持久排队，并在 Vox.md 中打开以投递。如果投递需要主应用，请使用 开放 Vox.md.

    主屏幕与锁屏小组件

    快速捕捉

    打开持久化 Markdown 草稿。中型和大型小组件提供笔记、照片、截图、相机、文件、链接、扫描、草图和语音操作。

    快速记录

    启动配置的录音流程，并在支持的主屏幕和锁屏系列中反映就绪、聆听或停用状态。

    小组件安全设置

    在设置中关闭锁屏录音按钮，即可显示关闭状态，而不立即开始录音。

    控制中心、实时活动和灵动岛

    • 在 iOS 18+ 上，从控制中心添加可用的 Vox.md 采集和录音控件。配置已安装版本提供的路由和选项。
    • 使用录音控件前，请先在 Vox.md 中完成麦克风、模型和目标位置设置。根据 iOS 和已安装应用的版本，录音操作可能会打开应用。依赖后台采集前，请先在设备上测试一段简短录音。
    • 该 实时活动监控 设置控制锁屏和灵动岛上的录音状态及录音/停止操作。
    • 实时活动状态包括录音中、计时器、处理中、就绪、录音和停止。
    • 实时活动从 iOS 17 起可用；控制中心控件需要 iOS 18。

    快捷指令与 App Intents

    路由在快捷指令和受支持控件中显示为可选实体。启用使用当前位置后，直接入队的文本、链接和文件意图在调用时请求位置；打开快速捕捉的操作在发送时请求；录音操作在停止录音时请求。元数据输出不改变这一时机。如果无人值守的 询问 请求无法获取位置时，会保留其发起时位置不可用的结果，以供稍后决定，而不会重新获取。请使用已安装 Vox.md 版本提供的操作。采集操作包括：

    • 快速捕获
    • 记录捕获
    • 拍摄一个屏幕
    • 收集文本到 Markdown
    • 抓住链接 Markdown
    • 捕捉文件 Markdown

    操作按钮录音设置

    先打开 Vox.md，授予麦克风权限、准备转录后端并将路由连接到目标位置。在快捷指令中添加可用的 Vox.md 采集操作并选择路由。手机解锁时运行快捷指令，确认保存到预期笔记，再通过设置 → 操作按钮 → 快捷指令分配它。

    可用操作和后台录音行为取决于已安装版本及 iOS。使用设备快捷指令中显示的操作。如果录音需要应用打开，请打开 Vox.md 录音。快捷指令出现在选择器中，并不保证可在锁定手机上录音。

    深层链接

    Vox.md 注册了 voxboard:// URL 协议。查询值请使用 URL 编码。

    URL行为
    voxboard://capture打开持久化快速捕捉编辑器。
    voxboard://capture?action=photos打开照片选择器。其他操作： screenshots, camera, files, scan, sketch, link，以及 voice.
    voxboard://capture?text=...打开带有限长度文本的草稿。
    voxboard://capture?url=https%3A%2F%2F...打开带 HTTP/HTTPS 链接的草稿。
    voxboard://capture?route=...选择已启用路由。它可与受支持的操作、文本或 URL 组合。
    voxboard://capture-request?id=...领取系统扩展或意图创建的持久请求。
    voxboard://listen启动键盘聆听启动流程。
    voxboard://record旧版录音入口已重定向到聆听。
    voxboard://widget-record旧版小组件录音入口。

    未知或重复参数、格式错误的 UUID、不安全路由标识符、非 HTTP URL 和超过共享限制的文本会被拒绝。

    07 / Apple Watch

    在手表本地录音，再通过 iPhone 投递

    按照 Apple Watch 到 Obsidian 设置指南操作 了解路由选择、传输和投递检查。

    录音工作流

    • 手表应用显示就绪、录音中、已暂停、同步中、已排队、转录中、保存中、已发送和需要关注等状态。
    • 使用录音、暂停/继续、停止、取消、同步和刷新。暂停让你整理思路而不拆分笔记——暂停期间计时器冻结，且该时段不计入录音。取消会明确删除本地录音，而非同步。
    • 录音在本地以日志方式记录，中断或崩溃后可恢复。
    • 录音会保留在手表上，直到 iPhone 确认投递或丢弃。
    • 对于启用使用当前位置且通过普通采集投递的路由，手表会在录音停止时请求一次源自手表的位置，并将按隐私设置调整后的结果随路由快照一同传输。iPhone 绝不替换为自身位置。仅录音会跳过位置，因为它只导出原始音频，没有 Markdown 内容。

    手表上的路由

    从手表的以下位置选择已启用的 iPhone 路由： 路线 卡片。Vox.md 随录音传输安全快照。如果 iPhone 不可用，请求的选择会保持待定，最近确认的路由仍处于活动状态。

    iPhone 上的手表录音队列

    iPhone 队列显示录音时间、时长、路由、处理状态和投递操作。失败项目可重试、更换路由、丢弃或不带转录文本进行采集。丢弃会移除保留的音频和排队投递。

    仅录音输出

    • 将路由输出设为 仅录音 将 M4A 音频复制到文件文件夹，不进行转录或 AI 处理，也不消耗转录额度。
    • 默认文件名模板为 recording-{timestamp}-{id8}.
    • 使用路由前，先在 iPhone 上选择一次录音文件夹。
    • iOS 可能延迟后台投递。强制退出 Vox.md 会阻止投递，直到再次打开应用。

    复杂功能与小组件

    该 音频记录 复杂功能支持圆形、矩形、行内和角落系列。它可打开或切换手表本地录音，并显示计时器或随状态变化的标签。

    08 / Mac 配套应用

    在 macOS 上使用同一采集系统

    Mac 应用有采集、资料库和设置页面，并共享 iOS 所用的本地模型、路由、路由、导出和重试架构。

    采集工作区

    • 键入和编辑 Markdown，粘贴或拖放文件、图像和音频。
    • 使用内置、外接或连续互通相机设备的相机输入。
    • 导入扫描件或 PDF，用鼠标、触控板或连接的数位板画草图，并添加链接、wikilink、截止日期和文本转换。
    • 使用以下方式录音： 添加到草稿 或 立即发送；可选在草稿模式下保留音频。
    • 暂停 和 继续 在状态栏操作麦克风录音。暂停音频不计入录音，因此一条最终笔记可以分段录制。会议采集不支持暂停。
    • 导入音频或视频进行本地转录。
    • 按 Command-Return 发送采集。启用使用当前位置的路由会在发送或停止录音时请求一次 Mac 发起的位置，无论是否启用元数据输出。
    • 目标位置设置横幅和路由检查器显示所选路由解析出的笔记及放置位置。

    分轨采集会议

    将输入模式选择器从 麦克风 到 会议 将 Mac 上某个应用播放的声音和自己的麦克风录为两路清晰分离的音轨。Vox.md 以单应用模式使用 ScreenCaptureKit，因此你只选择一个应用，且绝不会采集 Vox.md 自身。

    • 录音时，状态栏显示系统和麦克风实时电平表、各来源状态，以及采集警告。
    • 两路音轨都以持久分块和恢复清单写入，因此即使中断——数据流停止、麦克风拔出或强制退出——也能安全收尾，会议仍可转录。下次录音队列恢复时，会自动恢复中断的会话。
    • 停止后，各音轨在设备上独立转录，结果在同一时间线上交错排列：你的麦克风显示为 你，应用音轨则标记为远端说话人。可选的说话人识别还能进一步区分多个远端声音。
    • 两路音轨的回放混音保存为录音音频，完成的转录与其他录音一样，遵循你的路由、添加到草稿或立即发送及剪贴板设置。

    全局快捷键

    设置 → 全局快捷键可为以下操作分配快捷键： 转载到 Clipboard, 所选路线，或任意已启用路由。快捷键默认关闭，需要非修饰键加 Control、Option 或 Command，也可包含 Shift，且会拒绝冲突。再次按活动快捷键可停止录音。

    转载到 Clipboard 不创建笔记、资料库项目或保留音频。它用于向任意 Mac 应用快速听写。

    菜单栏与应用可见性

    • 可见性选项为 门户 + 菜单 （默认）， 菜单 只 酒吧, 只用Dock，以及 隐藏.
    • 菜单栏显示录音、转录和导出状态。
    • 菜单操作包括开始录音、停止 + 转录、导入音频…、复制上次转录、显示上次导出、路由选择、显示采集、显示资料库、显示数据文件夹和退出 Vox.md。
    • 在 Mac 应用中按 Control-B，在可点击控件上显示键盘提示。

    Mac 历史与模型

    搜索、重新载入、清除、复制或删除本地历史；打开整理后和原始转录详情；在 Finder 中显示已投递笔记。模型界面可下载、选择和删除 Whisper 或 Parakeet 模型，并更改转录语言。Whisper 在受支持的 Mac 上使用 Metal 加速。

    哪些内容留在本地

    采集内容

    草稿、文本、链接、模板、路由、附件、音频、OCR 和转录文本不会发送到 Vox.md 服务器。

    处理

    Apple Speech、Whisper、Parakeet、Vision OCR 和受支持的 Apple Intelligence 处理在设备上运行。

    你的目标位置

    完成的文件仅存入你选择的文件夹。第三方文件提供商可能按其自身条款同步。

    • 成功投递后，可恢复采集请求变为不含内容的回执，已完成手表队列项仅保留粗粒度最终投递字段。两者都不保留坐标、标签、提供商 URL、位置模板或路由载荷。
    • 已完成采集历史仅存储投递元数据，不存储笔记文本、URL、坐标、位置标签或模板、书签、绝对路径或附件文件名。
    • 待处理和失败项目仅保留本地恢复所需内容，可能包括路由快照及其已按隐私设置调整的位置或不可用结果。
    • 正式版引导分析默认禁用。应用不包含第三方分析 SDK、广告网络或跨应用跟踪器。
    • 编辑器从 ZenQuotes 获取并缓存励志名言，不发送草稿内容或标识符。

    完整的数据处理、保留和第三方服务详情请阅读 隐私政策.

    10 / 故障排查

    常见设置与投递问题

    采集无法发送

    打开目标位置控件，配置所选路由。如果文件夹已移动或访问权限过期，请重新选择仓库/文件夹。排队工作仍可在资料库中找到。

    键盘提示启用完全访问

    打开 iOS 设置 → 通用 → 键盘 → 键盘 → Vox.md，开启允许完全访问。返回应用一次，让 Vox.md 恢复共享聆听工作流。

    自动模式不可用

    Apple Speech 自动模式需要受支持的 iOS 26 设备和语言。选择并下载 Whisper 或 Parakeet 模型，再明确选择它，或返回自动模式让它成为用户批准的备用模型。

    转录失败

    确认所选模型已完整下载，且语言适用。Vox.md 会尽可能保留可恢复的源音频，让你更换模型后重试。

    标题路由失败

    编辑路由目标位置，确认标题文本和级别。如果希望投递时创建缺少的标题而不是停止，请选择创建标题。

    手表录音已排队

    在 iPhone 上打开 Vox.md，再打开手表录音。刷新或重试，按提示选择有效路由，保持应用已安装且可用于后台交接。强制退出会阻止后台投递，直到重新打开。

    {location} 渲染为空

    为执行投递的路由开启使用当前位置；对于检测到的条目前缀、后缀和可复用条目模板，编辑器的一键修复可完成此操作，而不启用元数据。实时仓库模板文件需要手动设置路由。如果权限不可用，或采集选择不带位置继续，令牌会按设计渲染为空。请参阅 完整位置指南.

    路由位置不可用

    仅在仍处理原始交互式发送时使用重试。也可取消、仅本次不带位置发送，或为该路由始终不带位置发送。已保存的选择可在路由位置设置中重置。排队的无人值守请求保留原始不可用结果，不会获取更新的位置。

    仍有困难？

    打开设置 → 查看调试日志，再使用发送反馈，即可包含应用版本、平台、系统和设备详情。你也可以加入 Isolated Tech 的 Discord 社区.
