L041 · how.md

##三站。 没有一站属于我们。

打开仓库、查找笔记、选择正确位置，对转瞬即逝的想法来说太费事。设置一次路由，然后直接采集。

  1. 01你的文件夹

    连接仓库

    选择 Obsidian 仓库或文件中的任意可写文件夹。Vox.md 使用你已有的 Markdown 文件。

  2. 02你的口袋

    采集任何内容

    写字、粘贴链接、添加媒体或文件、扫描文档、画草图，或录制私密语音笔记。语音就在这里转录。

  3. 03你的文件

    路由负责归档

    创建笔记、更新滚动笔记，或定位现有笔记。放在顶部、底部或标题下。

第 2.5 站：别人的云。跳过。同步沿用文件夹原有方式，受提供商条款约束。

L077 · files.md

##它是 只需 文件。

无需插件，无需 Vox.md 云账户，没有专有格式。Vox.md 将可读的 Markdown 和 Obsidian 风格链接写入你控制的文件夹，笔记绝不会被锁在应用里。

  • .md标准 Markdown 格式的键入笔记与语音转录
  • [[ ]]Obsidian 能识别的 wikilink 与嵌入附件
  • img照片、文件和带提取文本的文档扫描件。 媒体采集指南
  • url从任何可共享的地方保存链接
  • draw可编辑草图
  • voice从编辑器或键盘使用私密语音；绝不上传音频。 iPhone 语音笔记指南
  • ---带日期、时间、来源和标识符令牌的可复用 Markdown 或 YAML

L214 · faq.md

##开放 问题

Vox.md 直接使用你选择的 Markdown 文件夹。Obsidian 很合适，但不是必需的。勾选一项查看答案。

Vox.md 能配合 Obsidian 使用吗？

可以。创建路由并选择 Obsidian 仓库作为目标位置。Vox.md 将标准 Markdown、wikilink 和附件嵌入直接写入仓库。不需要 Obsidian 插件。 比较 Vox.md 与 Obsidian 原生采集功能。 设置每日笔记采集工作流。

可以采集什么？

编辑器接受文本、网页链接、照片、文件、文档扫描件、草图和语音。扫描件可包含提取文本，语音可在本地转录。

采集内容可以送到哪里？

每个路由都有目标位置，可创建新笔记、更新每日或周期滚动笔记，或写入现有 Markdown 文件。单次采集可临时选择另一笔记而不更改路由。

Vox.md 可以在标题下插入吗？

可以。路由可前置插入、追加，或插入到一级至六级标题下。你可选择缺少标题时停止投递还是自动创建，以及新条目直接位于标题下，还是放在该标题所在节末尾。

不用 Obsidian 也可以吗？

可以。路由可使用文件中开放的任何可写文件夹。输出是带普通附件的纯 Markdown，因此笔记不会被锁定在 Vox.md 中。

Vox.md 会上传笔记或音频吗？

任何采集内容都不会发送到 Vox.md 服务器。草稿和语音处理留在设备上，完成的文件写入所选文件夹。如果文件夹属于同步提供商，该提供商按其自身条款处理。 检查离线设置要求。

能否在模板中使用位置而不添加元数据？

可以。为该路由开启使用当前位置，保持写入位置元数据关闭，并添加 {location} 到其条目格式中。Vox.md 会插入一次性地图链接，而不添加 frontmatter 或行内位置字段。 阅读完整位置指南。

可以在应用外采集吗？

可以。Vox.md 提供小组件、快捷指令操作、共享扩展和语音键盘。这些入口都连接同一本地采集系统。

Vox.md 多少钱？

Vox.md 免费提供 15 分钟转录和 10 次成功采集投递。一次终身购买即可无限转录和采集，无订阅、无广告。发送到 Markdown 的语音转录使用转录额度，不再消耗第二次采集额度。App Store 显示你所在地区的当前价格。

把下一个想法放入 文件中。

一次连接仓库或本地文件夹。下一个想法就能直接进入所选笔记、标题和格式。
