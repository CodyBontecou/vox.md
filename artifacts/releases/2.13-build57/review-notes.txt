Vox.md 2.13 is a maintenance release with refreshed product information and current one-time purchase options.

No account or demo credentials are required.

To test capture, launch Vox.md, create or select a Capture Preset, and choose a writable folder in Files as the destination. Type a short note, send it, and confirm that the Markdown file is written. You may use an existing Markdown folder or vault; no third-party app is required.

To test voice, grant microphone access and record from the Capture screen. Stop recording, preview the result, and send it with the selected preset. Speech transcription runs on device. Optional Whisper and Parakeet models require an explicit download. Captured audio remains available if transcription is unavailable or no speech is detected.

To test the keyboard, enable the Vox.md keyboard in iOS Settings and allow Full Access so it can coordinate with the main app through the shared App Group. Open a text field that accepts custom keyboards, switch to Vox.md, and dictate.

New users can try 15 minutes of transcription and 10 successful Capture deliveries. A one-time in-app purchase unlocks unlimited use; eligible previous purchases can be restored. Failed file deliveries remain available for retry.

Optional Deliver to URL is off by default. It delivers only to an HTTPS endpoint explicitly configured by the user; URL Deliveries provides retry and discard controls.
