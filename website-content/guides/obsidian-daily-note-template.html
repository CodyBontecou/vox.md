2. Make Daily notes use it

Save the generated text as a note in your templates folder, for example Templates/Daily.md. Then open Settings → Daily notes and, under the plugin options, set three things:

  1. Date format: how Obsidian names daily notes and builds their path. Copy the value shown above the preview.
  2. New file location: the folder where Obsidian creates new daily notes, if you want them apart from other notes.
  3. Template file location: the note you just saved.

Obsidian uses the template only when it creates a new daily note after you set it, so existing notes are not changed. To test it, open a day that has no note yet. See Daily notes in Obsidian Help.

The date, weekday and tags between the --- lines become note properties; see Properties. Mood and energy are empty so you can fill them in as text. To list your daily notes by those properties, query them with a base: the Obsidian Bases generator builds one. To check or build other properties, use the properties generator and checker. To fill the Tasks section from a list you already have, use the Markdown checklist maker.

The date format uses Moment.js format tokens. The generator previews these common ones, in English:

TokenMeaningExample

MMMonth number, two digits11

MMMShort month nameNov
MMMMFull month nameNovember
DDDay of the month, two digits21
DDay of the month21
dddShort weekday nameSat
ddddFull weekday nameSaturday
wwWeek of the year, two digits (English week rules: weeks start on Sunday and week 1 contains January 1)47
QQuarter4

Text in square brackets, such as [Week], is written as it is. Any other Moment token is not previewed; the generator lists it, and the Moment.js documentation covers it.

A slash in the date format creates subfolders. Obsidian’s own example is YYYY/MMMM/YYYY-MMM-DD, which makes notes such as 2023/January/2023-Jan-01: the year folder, the month folder, then the file name. If you also set a New file location, the date folders go inside it, so Journal with YYYY/MM/YYYY-MM-DD gives Journal/2026/11/2026-11-21.md.

Day and month names are English in the preview. Obsidian may show them in your language, and week numbers can follow your locale’s week rules.

4. Core Templates vs Templater

Core Templates ships with Obsidian. It supports {{title}}, {{date}} and {{time}}, and a format after a colon, such as {{date:YYYY-MM-DD}}. {{date}} is the date the template is inserted, not a date read from the note’s name. The Templates help page documents no date offsets, so previous and next day links are not generated for core Templates.

Templater is a community plugin. Its tp.date.now takes a format, an optional offset in days, an optional reference date such as the note’s title, and the format used to read that reference. The generator’s previous and next day links use that form:

[[<% tp.date.now("YYYY-MM-DD", -1, tp.file.title, "YYYY-MM-DD") %>]]
[[<% tp.date.now("YYYY-MM-DD", 1, tp.file.title, "YYYY-MM-DD") %>]]

Because they read the file name, they match the day of the note, even if you create it for another day. The format in the last argument has to match your file name format. If the date format has slashes, the generator uses the part after the last slash, which is the file name. See the Templater date module.

5. Add to today’s note from iPhone or Mac

A template gives the note its shape. Vox.md can add to it during the day: speak or type a thought and it is saved into the day’s note. Voice is transcribed on your device. In a Capture Preset, choose a Rolling Note with the Daily period and a path such as Journal/{period}.md. With a daily period, {period} resolves to a date such as 2026-11-21.

Choose Heading placement and the heading from your template, such as ## Inbox, and new entries go beneath it. If the heading is missing, choose Show Error or Create Heading. Add an entry prefix such as - to make each capture a list item; the Inbox section in the generator uses the same bullet.

Vox.md does not apply your Obsidian template when it writes to a file. If you want the template, open today’s note in Obsidian first, then send captures. The path must point at the file Obsidian uses, so keep YYYY-MM-DD file names unless you have checked the match. Append text and voice to an Obsidian daily note covers the full setup, and the Routes reference lists the options.

6. Questions

Why didn’t my template apply?

Obsidian uses the template only when it creates a new daily note, so notes that already exist are unchanged. Check that Template file location in Settings → Daily notes points at the right note. If the template has <% %> commands that stay as text, they are Templater commands: use Templater’s folder template for the daily notes folder, or generate the core Templates version.

Why is my daily note in the wrong folder?

Two settings decide the path: New file location and slashes in Date format. The preview above shows both together. If a format such as YYYY/MM/YYYY-MM-DD makes year and month folders you did not want, use a plain format and set only the folder.

Can I use Dataview?

The template is plain Markdown, so you can add a code block for any plugin by hand after you paste it. The generator does not write plugin code for you.

Does the generator send my choices anywhere?

No. The template is built by a script in this page. It saves your last choices in your browser’s local storage, so they are still there next time, and Reset clears them.
